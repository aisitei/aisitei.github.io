더 이상 "일률적"이지 않다: Microsoft Windows 11 미리 보기 버전, 앱별 카메라, 마이크, 위치 권한 개별 관리 가능

2026-11-01

앱 권한 관리 강화

Microsoft는 10월 30일 블로그 게시물을 통해 Windows Insider 프로그램 회원들에게 Windows 11 25H2 Beta 26220.9836 및 Windows 11 Experimental(Future Platforms) 프리뷰 빌드 29698.1000에서 앱 권한 관리를 더욱 세분화할 것을 요청했습니다.

Microsoft의 공식 업데이트 로그에 따르면, 위 Windows 11 프리뷰 버전에서 Microsoft는 개인 정보 보호 기능을 보완하여 이제 데스크톱 앱별로 카메라, 마이크, 위치 권한을 개별적으로 관리할 수 있게 되었습니다.

NeoWin 미디어 보도에 따르면, 기존 데스크톱 앱이 이러한 민감한 권한을 제어할 때 사용자는 장치 수준의 마스터 스위치를 통해서만 일괄적으로 제어할 수 있었고, 어떤 프로그램이 카메라를 호출하거나 위치 정보를 얻고 있는지 판단하기 어려웠습니다.

하지만 위 Windows 11 프리뷰 버전에서는 사용자가 데스크톱 앱의 카메라, 마이크 및 위치 접근 상황을 개별적으로 확인하고 허용 또는 거부를 선택할 수 있습니다. Microsoft는 이러한 변경의 목표가 사용자가 어떤 앱이 민감한 리소스를 요청하는지 더 명확하게 이해하여, 더욱 세밀하고 직관적인 개인 정보 보호 관리 경험을 제공하는 것이라고 밝혔습니다.

총평

Microsoft는 Windows 11 프리뷰 빌드를 통해 데스크톱 앱의 개인 정보 보호 권한 관리를 대폭 강화했습니다. 이제 사용자는 개별 앱별로 카메라, 마이크, 위치 접근 권한을 세밀하게 제어할 수 있어, 어떤 앱이 민감한 정보를 사용하는지 명확히 파악하고 관리할 수 있게 되었습니다. 이는 기존의 장치 전체 제어 방식보다 훨씬 직관적이고 사용자 중심적인 개인 정보 보호 경험을 제공할 것입니다.

操作系统核心功能升级

  • 精细化应用权限管控：微软在Windows 11的预览版中，大幅增强了隐私保护能力。
  • 资源管理粒度提升：桌面应用现在可以针对摄像头、麦克风和位置信息这三类敏感资源进行单独的权限管理。

用户体验与功能改进

  • 解决痛点：此前，用户只能通过设备级的总开关统一控制敏感权限，难以判断具体是哪个程序在调用资源。
  • 实现逐个查看和控制：升级后，用户可以逐一查看每个桌面应用对摄像头、麦克风及位置的访问请求情况，并选择允许或拒绝，从而获得更细粒度的隐私管理体验。

涉及的预览版版本

  • Windows 11 25H2 Beta 26220.9836
  • Windows 11 Experimental（Future Platforms）预览版 Build 29698.1000

此次改动旨在让用户更清晰地了解哪些应用正在请求敏感资源，从而提升整体的隐私透明度和控制力。

总结

微软已在Windows 11的多个预览版中发布了重大更新，核心功能是实现桌面应用的精细化权限管理。用户现在可以为摄像头、麦克风和位置信息分别设置开关，告别总开关模式，显著提升了操作系统层面的隐私保护透明度和控制粒度。

アプリの権限管理強化

Microsoftは、10月30日のブログ投稿を通じて、Windows Insiderプログラムのメンバーに対し、Windows 11 25H2 Beta 26220.9836およびWindows 11 Experimental (Future Platforms) のプレビュービルド 29698.1000において、アプリの権限管理をより細分化することを要請しました。

Microsoftの公式アップデートログによると、上記のWindows 11プレビューバージョンでは、プライバシー機能が補強され、デスクトップアプリごとにカメラ、マイク、位置情報へのアクセス権を個別に管理できるようになりました。

これまで、既存のデスクトップアプリがこれらの機密性の高い権限を使用する場合、ユーザーはデバイスレベルのマスタースイッチを通じて一括で制御することができましたが、どのプログラムがカメラを呼び出しているのか、あるいは位置情報を取得しているのかを判断することは困難でした。

しかし、今回のWindows 11プレビューバージョンでは、ユーザーがデスクトップアプリのカメラ、マイク、および位置情報へのアクセス状況を個別に確認し、許可または拒否を選択できるようになりました。Microsoftは、この変更の目的として、ユーザーがどのアプリが機密リソースを要求しているのかをより明確に理解し、より詳細で直感的なプライバシー管理体験を提供することを目指したと説明しています。

総評

Microsoftは、Windows 11プレビュービルドを通じて、デスクトップアプリのプライバシー権限管理を大幅に強化しました。これにより、ユーザーは個々のアプリごとにカメラ、マイク、位置情報へのアクセス権を細かく制御できるようになり、どのアプリが機密情報を利用しているかを明確に把握し、管理することが可能になりました。これは、従来のデバイス全体での制御方式よりも遥かに直感的で、ユーザー中心のプライバシー体験を提供するものとなります。

Enhanced App Permission Management

In a blog post published on October 30th, Microsoft requested enhanced granularity in app permission management for Windows Insider Program members using builds such as Windows 11 25H2 Beta 26220.9836 and Windows 11 Experimental (Future Platforms) preview build 29698.1000.

According to Microsoft's official update logs, these Windows 11 preview versions include enhanced privacy features that allow users to manage camera, microphone, and location permissions individually for each desktop application.

Previously, as reported by NeoWin Media, when existing desktop apps utilized sensitive permissions, users could only control them globally through a device-level master switch. This made it difficult to determine which specific program was calling the camera or accessing location data.

However, in these Windows 11 preview versions, users can now individually check and choose whether to allow or deny access for a desktop app's use of the camera, microphone, and location services. Microsoft stated that the goal of this change is to provide users with a clearer understanding of which apps are requesting sensitive resources, thereby offering a more detailed and intuitive privacy management experience.

Summary

Microsoft has significantly strengthened privacy permission management for desktop applications within Windows 11 preview builds. Users can now finely control access permissions—including camera, microphone, and location—on an individual app-by-app basis. This enhancement provides a much more intuitive and user-centric approach to data privacy compared to the previous device-wide control methods.
