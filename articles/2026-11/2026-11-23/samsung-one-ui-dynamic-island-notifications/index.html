Samsung 📱 스마트폰

Samsung, One UI 9.5에 Apple iOS 다이내믹 아일랜드 스타일의 새로운 실시간 알림 도입 예정, Galaxy S27 시리즈 스마트폰과 함께 출시 전망

2026-11-23

Now Bar 실시간 알림 기능

SamMobile이 Samsung One UI 9.5 베타 버전을 분석한 결과, Samsung이 Galaxy S27 시리즈 스마트폰을 위해 새로운 Now Bar 실시간 알림 기능을 테스트 중인 것으로 확인되었습니다.

새로운 Now Bar는 화면 상단 중앙 전면 카메라 펀치홀 주변에 캡슐 형태의 인터페이스로 표시됩니다. 사용자가 캡슐을 탭하면 타이머, 손전등 상태, 미디어 제어 등의 기능이 확장되어 표시되며, 좌우 스와이프 제스처를 통해 다른 백그라운드 활동을 전환할 수 있습니다. 전체적으로 Apple iPhone의 Dynamic Island 디자인과 유사합니다.

타이머 및 음악 플레이어만 지원하는 일부 Android 모방 기능과 달리, Samsung의 새로운 디자인은 기존 Live Notifications(실시간 알림) 프레임워크를 기반으로 작동합니다. 현재 이 프레임워크는 여러 타사 앱을 지원하고 있어, 이번 변경은 단순히 타이머와 같은 시스템 기능의 표시 방식을 바꾸는 것을 넘어 더 많은 애플리케이션 시나리오로 확장될 수 있습니다. 하지만 현재 관련 디자인은 테스트 단계에 있으며, Samsung은 공식 출시 전에 캡슐의 모서리 곡률 및 간격과 같은 세부 사항을 조정할 시간이 있습니다.

Moment effects

또한, SamMobile은 Now Bar 설정에서 Moment effects(순간 특수 효과)라는 새로운 페이지를 발견했으며, 현재 Sports(스포츠) 다운로드 옵션이 나열되어 있습니다.

이 기능은 Google Sports의 지원을 받으며, 사용자가 팔로우하는 팀이 득점하거나 승리할 때 시스템이 전면 카메라 펀치홀 주변에 짧은 애니메이션을 재생하여 스포츠 경기 정보를 더욱 직관적인 방식으로 보여줍니다. Samsung이 이 페이지를 Moment effects라고 명명한 것을 고려할 때, 향후 날씨, 여행 및 기타 실시간 알림 특수 효과가 추가될 가능성도 배제할 수 없습니다.

총평

Samsung은 Galaxy S27 시리즈에 Apple의 Dynamic Island와 유사한 Now Bar 실시간 알림 기능을 테스트 중입니다. 이 기능은 캡슐 형태로 전면 카메라 펀치홀 주변에 표시되며, 타이머, 미디어 제어 등 다양한 시스템 및 타사 앱 정보를 직관적으로 제공합니다. 또한, Moment effects 기능을 통해 스포츠 경기 결과와 같은 실시간 정보를 애니메이션으로 표시하여 사용자 경험을 향상시킬 것으로 기대됩니다.

One UI 9.5 新功能预览

根据外媒 SamMobile 对 Samsung One UI 9.5 测试版的拆解发现，Samsung 正在为下一代旗舰机型 Galaxy S27 系列测试一套全新的实时通知系统——Now Bar。

Now Bar 设计与交互特点

  • 外观设计： Now Bar 将以胶囊形界面显示在屏幕顶部中央，位于前置摄像头开孔周围。
  • 核心功能： 用户点击该区域后，可展开显示计时器、手电筒状态和媒体控制等多种功能。
  • 操作体验： 支持通过左右滑动切换不同的后台活动信息。
  • 设计参考： 整体设计灵感来源于 Apple iPhone 的“动态岛”（Dynamic Island）概念。

系统底层技术与扩展性

  • 运行基础： 新版 Now Bar 仍基于现有的 Live Notifications（实时通知）框架运行，而非仅限于仿制计时器和音乐播放器的功能。
  • 应用广度： 该框架目前已支持多款第三方应用，意味着 Now Bar 的调整旨在扩展到更广泛的应用场景，而不仅仅是改变系统核心功能的显示方式。
  • 开发状态： 目前相关设计仍处于测试阶段，Samsung 尚未确定最终的圆角和间距等细节。

“瞬间特效”（Moment effects）功能

  • 新增设置页： 在 Now Bar 的设置中发现了一个名为 Moment effects（瞬间特效）的新页面。
  • 体育赛事支持： 目前该功能已列出 Sports（体育）下载选项，由 Google Sports 提供支持。
  • 视觉呈现： 当用户关注的球队得分或获胜时，系统会在前置摄像头开孔周围播放简短动画，使体育信息以更直观的方式展示给用户。
  • 未来潜力： 考虑到命名为 Moment effects，未来该功能有潜力进一步加入天气、旅行以及其他实时通知特效。

总结

Samsung 在 One UI 9.5 中引入了 Now Bar，旨在通过胶囊形的界面和左右滑动操作，提供类似动态岛的沉浸式实时通知体验。这一系统不仅在基础功能（如计时器、媒体控制）上进行了升级，更重要的是基于 Live Notifications 框架扩展到了 Moment effects 等高级模块，预示着未来通知系统的视觉化和智能化程度将大幅提升。

Now Barによるリアルタイム通知機能

SamMobileがSamsung One UI 9.5ベータ版を分析した結果、SamsungがGalaxy S27シリーズ向けに新しい「Now Bar」というリアルタイム通知機能をテストしていることが確認されました。

この新しいNow Barは、画面上部中央の前面カメラパンチホール周辺にカプセル型のインターフェースとして表示されます。ユーザーがこのカプセルをタップすると、タイマー、ライトの状態、メディア制御などの機能が展開して表示され、左右のスワイプジェスチャーによって他のバックグラウンドアクティビティに切り替えることができます。全体的なデザインはApple iPhoneのDynamic Islandと類似しています。

従来のAndroidのエミュレーション機能の中には、タイマーや音楽プレイヤーのみをサポートするものもありますが、Samsungの新しいデザインは既存のLive Notifications（リアルタイム通知）フレームワークに基づいて動作します。このフレームワークは複数のサードパーティ製アプリをサポートしているため、今回の変更は単にタイマーなどのシステム機能の表示方法を変えるだけでなく、より多くのアプリケーションシナリオへと拡張する可能性があります。ただし、現時点での関連デザインはテスト段階であり、Samsungは公式リリース前にカプセルの角の曲率や間隔といった詳細な調整を行う時間があります。

Moment effects（瞬間エフェクト）

また、SamMobileはNow Barの設定内に「Moment effects（瞬間特有のエフェクト）」という新しいページを発見しました。現在、このページにはSports（スポーツ）のダウンロードオプションがリストされています。

この機能はGoogle Sportsのサポートを受けており、ユーザーがフォローしているチームが得点したり勝利したりした際に、システムが前面カメラパンチホール周辺に短いアニメーションを再生し、スポーツの結果情報をより直感的な方法で表示します。SamsungがこのページをMoment effectsと名付けたことを考慮すると、将来的には天気や旅行、その他のリアルタイム通知特有のエフェクトが追加される可能性も否定できません。

まとめ

SamsungはGalaxy S27シリーズにおいて、AppleのDynamic Islandに似た「Now Bar」というリアルタイム通知機能をテストしています。このカプセル型のインターフェースは、タイマーやメディア制御など、多様なシステムおよびサードパーティ製アプリの情報を提供します。さらに、「Moment effects」機能により、スポーツの結果などのリアルタイム情報をアニメーションで表示することで、ユーザー体験の向上を目指していると見られます。

Now Bar Real-time Notification Feature

Analysis by SamMobile of the Samsung One UI 9.5 beta version revealed that Samsung is testing a new Now Bar real-time notification feature for the Galaxy S27 series smartphone.

The new Now Bar appears as a capsule-shaped interface located above the screen, around the front camera punch-hole. When users tap the capsule, various functions—such as timers, flashlight status, and media controls—expand and become visible. Users can switch between different background activities using left and right swipe gestures. Overall, the design is similar to Apple's Dynamic Island.

Unlike some Android mock features that only support timers and music players, Samsung’s new design operates based on the existing Live Notifications framework. Since this framework currently supports multiple third-party applications, this change has the potential to expand beyond simply changing how system functions like timers are displayed, accommodating a wider range of application scenarios. However, the related designs are currently in the testing phase, giving Samsung time to adjust details such as the corner curvature and spacing of the capsule before an official release.

Moment effects

Additionally, SamMobile discovered a new page called "Moment effects" within the Now Bar settings, which currently lists Sports download options.

This feature is supported by Google Sports and allows the system to play short animations around the front camera punch-hole when a user's followed team scores or wins, presenting sports information in a more intuitive way. Given that Samsung named this page "Moment effects," it is possible that future real-time notification special effects for weather, travel, and other categories could be added.

Summary

Samsung is testing the Now Bar real-time notification feature on the Galaxy S27 series, a design similar to Apple's Dynamic Island. This capsule-shaped interface appears around the front camera punch-hole and provides intuitive access to various system and third-party app information, including timers and media controls. Furthermore, the Moment effects function is expected to enhance user experience by displaying real-time data, such as sports scores, using dynamic animations.
