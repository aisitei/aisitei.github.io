Huawei 싱망 OSTA O1 Pro 바 타입 스마트폰 주요 사양 공개: 기린 9030S, 무선충전 유지, 충전기 미포함

2026-11-18

소개

Huawei의 새로운 서브 브랜드인 Brightin Star의 첫 번째 제품인 OSTA O1 Pro 바 타입 스마트폰이 Huawei 몰에 출시되었으며, 11월 20일 공식 발표될 예정입니다.

디스플레이 및 디자인

  • 6.39인치 1.5K LTPS 바 타입 디스플레이
  • 화면 비율: 16:9.5
  • 1.05mm의 극도로 얇은 4면 베젤
  • 두께: 6.68mm
  • 무게: 200g

성능 및 배터리

  • 프로세서: Kirin 9030S
  • 최대 저장 용량: 16GB RAM + 1TB 스토리지
  • 배터리: 7000mAh
  • 충전: 66W 유선 충전 + 무선 충전
  • 보안: 측면 지문 인식

카메라

  • 메인 카메라: 200MP 1/1.28인치 RYYB 센서
  • 페리스코프 망원 카메라: 50MP 3.7배 RYYB 센서
  • 추가 렌즈: 홍펑(红枫) 렌즈
  • 초광각 렌즈는 탑재되지 않습니다.

구성품

OSTA O1 Pro 패키지에는 충전 어댑터가 포함되어 있지 않으며, 1.8m 길이의 패브릭 데이터 케이블만 제공됩니다.

총평

Huawei의 새로운 Brightin Star 브랜드의 첫 스마트폰인 OSTA O1 Pro는 6.39인치 1.5K LTPS 바 타입 디스플레이와 Kirin 9030S 프로세서를 탑재했습니다. 7000mAh 대용량 배터리와 66W 유선 및 무선 충전을 지원하며, 200MP 메인 카메라와 50MP 페리스코프 망원 카메라를 포함한 강력한 카메라 시스템을 갖추고 있습니다.

新品发布与品牌信息

  • Huawei全新子品牌星芒的首款产品OSTA O1 Pro阔直板手机已上架Huawei商城，并计划于 11 月 20 日正式发布。

核心硬件规格

  • **屏幕方面：** 配备 6.39 英寸 1.5K LTPS 바 타입 显示屏，采用 16:9.5 比例，极窄四等边设计。
  • **机身参数：** 机身厚度为 6.68mm，重量为 200g。
  • **处理器与存储：** 内置麒麟 9030S 处理器，顶配版本支持 16GB+1TB 的大容量存储。

续航与充电系统

  • 新机配备超大容量 7000mAh 电池。
  • 支持 66W 有线快充和无线充电功能。
  • 指纹识别采用侧边指纹设计。

影像系统配置

  • **主摄：** 搭载 200Mp 分辨率的 1/1.28" RYYB 主摄像头。
  • **长焦镜头：** 配备 50Mp 3.7X RYYB 潜望式长焦镜头和红枫镜头。
  • （注：该机型未配备超广角摄像头。）

配件与开箱细节

  • 根据实物开箱信息，OSTA O1 Pro 的包装盒内不附带充电头，仅包含一条 1.8 米长的编织数据线。

总结

Huawei全新子品牌星芒首次推出的OSTA O1 Pro是一款配置强大的阔直板手机，其核心亮点在于搭载麒麟 9030S处理器、7000mAh超大电池以及200Mp主摄系统。该机型在屏幕和存储方面均有突出表现，但用户需注意包装盒内不包含充电头。

まとめ

Huaweiの新ブランド「Brightin Star」初のスマートフォンであるOSTA O1 Proは、6.39インチ 1.5K LTPSバータイプディスプレイとKirin 9030Sプロセッサを搭載しています。7000mAhの大容量バッテリーに加え、66Wの有線・ワイヤレス充電に対応し、200MPのメインカメラと50MPペリスコープ望遠カメラを備えた強力なカメラシステムが特徴です。

Introduction

The OSTA O1 Pro bar-type smartphone, which is the first product from Huawei's new sub-brand Brightin Star, has been launched on the Huawei Mall and is scheduled for an official announcement on November 20th.

Display and Design

  • 6.39-inch 1.5K LTPS bar-type display
  • Screen ratio: 16:9.5
  • Extremely thin 4-sided bezel of 1.05mm
  • Thickness: 6.68mm
  • Weight: 200g

Performance and Battery

  • Processor: Kirin 9030S
  • Maximum storage capacity: 16GB RAM + 1TB storage
  • Battery: 7000mAh
  • Charging: 66W wired charging + wireless charging
  • Security: Side-mounted fingerprint sensor

Camera

  • Main camera: 200MP 1/1.28-inch RYYB sensor
  • Periscope telephoto camera: 50MP 3.7x RYYB sensor
  • Additional lens: Hongfeng lens (红枫)
  • The ultra-wide angle lens is not included.

Included Items

The OSTA O1 Pro package does not include a charging adapter; only a 1.8m fabric data cable is provided.

Overall Review

OSTA O1 Pro, the first smartphone under Huawei's new Brightin Star brand, features a 6.39-inch 1.5K LTPS bar-type display and is powered by the Kirin 9030S processor. It boasts a large 7000mAh battery with support for 66W wired and wireless charging, complemented by a powerful camera system including a 200MP main camera and a 50MP periscope telephoto camera.

Summary

The OSTA O1 Pro is the inaugural smartphone from Huawei's Brightin Star sub-brand. Key features include a 6.39-inch 1.5K LTPS display, Kirin 9030S processor, and a massive 7000mAh battery supporting 66W charging. The device emphasizes photography with a powerful camera setup featuring a 200MP main sensor and a 50MP periscope telephoto lens.
