Android OS를 Windows 11로 교체: 개발자가 OnePlus 폴더블 스마트폰을 개조하여 터치 기능 구현

2026-11-18

Windows 11 on ARM64 구동

개발자 Kevin Shroff는 11월 2일 Reddit 커뮤니티에 OnePlus 폴더블 디스플레이 폰 OnePlus Open에서 Windows 11 on ARM64 시스템을 네이티브로 구동하는 최신 포팅 결과를 게시했습니다.

가상 머신 방식과 달리, 이 시스템은 휴대폰 내부 저장소에 설치되어 장치 하드웨어에서 직접 실행됩니다. 개발자는 테스트 기기에서 Android 시스템을 제거했으며, 현재 Windows 11이 주 시스템으로 부팅된다고 밝혔습니다. 관련 이미지는 다음과 같습니다.

포팅 개발 과정에서 Shroff는 부팅 펌웨어를 커스터마이징하고 하드웨어 인식, 전원 관리 및 드라이버 등을 적용했습니다. 현재 터치 조작이 가능하며, 휴대폰의 16GB RAM과 8개 프로세서 코어 전체를 사용할 수 있습니다.

하지만 이번 포팅은 아직 완벽한 수준에 도달하지 못했습니다. 현재 Wi-Fi, 셀룰러 네트워크, Bluetooth, 오디오 및 카메라를 사용할 수 없으며, GPU 그래픽 가속도 구현되지 않았습니다. 프로젝트는 여전히 개발 단계에 있으며, 직접 플래시할 수 있는 설치 패키지는 아직 제공되지 않습니다.

Windows 11 ARM64 on OnePlus Open 프로젝트는 GitHub에서 확인할 수 있습니다.

Google 임원이 Gemini AI를 통해 Apple iPhone Duo에서 Microsoft Win11을 성공적으로 실행했습니다.

총평

개발자 Kevin Shroff가 OnePlus Open에서 Windows 11 on ARM64를 네이티브로 구동하는 데 성공했습니다. 이 시스템은 휴대폰 내부 저장소에 직접 설치되어 하드웨어에서 실행되며, 터치 조작과 16GB RAM, 8개 코어 프로세서 활용이 가능합니다. 다만, Wi-Fi, 셀룰러, Bluetooth, 오디오, 카메라 및 GPU 가속 기능은 아직 지원되지 않아 개발이 더 필요한 상황입니다.

移动设备操作系统移植

  • 开发者 Kevin Shroff 在 Reddit 上展示了将 Windows 11 on ARM64 系统成功移植到 OnePlus Open 可折叠屏手机上，实现了原生运行。

技术实现与硬件适配细节

  • **运行模式：** 该系统并非通过虚拟机方案运行，而是直接安装在手机内部存储中，直接于设备硬件之上启动。
  • **开发工作：** Shroff 定制了启动固件，并完成了对硬件识别、电源管理和驱动的适配工作。
  • **性能调用：** 目前已实现触控操作，并且能够调用设备的 16GB 内存及全部 8 个处理器核心资源。

当前功能限制与项目状态

  • **未实现功能：** 本次移植仍处于开发阶段，目前尚未支持 Wi-Fi、蜂窝网络、蓝牙、音频和摄像头等关键功能。
  • **图形加速：** GPU 图形加速功能也尚未实现。
  • **可用性：** 项目尚未提供可直接刷入的安装包。

总结

开发者 Kevin Shroff 成功将 Windows 11 on ARM64 系统移植至 OnePlus Open，并在设备上实现了原生运行。尽管目前仍存在 Wi-Fi、蓝牙和图形加速等功能缺失的问题，但该项目展示了在高端折叠屏手机上运行桌面级操作系统的巨大潜力，并已开源其开发进度。

OnePlus OpenでのWindows 11 on ARM64動作

開発者のKevin Shroff氏が、Redditコミュニティにおいて、OnePlusの折りたたみ式ディスプレイ搭載スマートフォン「OnePlus Open」でWindows 11 on ARM64システムをネイティブに動作させる最新の移植結果を発表しました。

このシステムは仮想マシン方式ではなく、スマートフォンの内部ストレージに直接インストールされ、デバイスハードウェアから直接実行されるのが特徴です。開発者はテスト機からAndroidシステムを削除し、現在Windows 11がメインOSとして起動していると報告しています。

Shroff氏は、移植開発の過程でブートファームウェアのカスタマイズ、ハードウェア認識、電源管理、ドライバーの実装を行いました。現在のところ、タッチ操作が可能であり、スマートフォンの持つ16GB RAMおよび8コアプロセッサ全体を活用できています。

しかしながら、この移植はまだ完成されたレベルには達していません。現在、以下の機能が利用できない状態です。

  • Wi-Fi
  • セルラーネットワーク
  • Bluetooth
  • オーディオおよびカメラ
  • GPUグラフィックアクセラレーションの実装

プロジェクトは依然として開発段階にあり、直接フラッシュできるインストールパッケージはまだ提供されていません。なお、「Windows 11 ARM64 on OnePlus Open」のプロジェクトはGitHubで確認できます。

また、別の関連情報として、Googleの社員がGemini AIを利用し、Apple iPhone Duo上でMicrosoft Win11を正常に実行した事例も報告されています。

まとめ

開発者のKevin Shroff氏が、OnePlus OpenにおいてWindows 11 on ARM64をネイティブな形で動作させることに成功しました。このシステムはハードウェアから直接起動し、タッチ操作や16GB RAM、8コアプロセッサの利用が可能ですが、Wi-Fi、セルラー通信、Bluetooth、カメラなどの主要機能やGPUアクセラレーションは未実装であり、さらなる開発が必要な段階です。

Windows 11 on ARM64 Operation

Developer Kevin Shroff posted the latest porting results to the Reddit community on November 2nd, demonstrating native operation of Windows 11 on ARM64 system on the OnePlus Open foldable display phone.

Unlike virtual machine methods, this system is installed directly onto the phone's internal storage and runs natively from the device hardware. The developer stated that he removed the Android operating system from the test device, allowing Windows 11 to boot as the primary system. An image related to the process was provided.

During the porting development process, Shroff customized the booting firmware and implemented hardware recognition, power management, and drivers. Currently, touch operation is possible, utilizing the phone's full capacity of 16GB RAM and 8 processor cores.

However, this porting effort has not yet reached a perfect state. Currently, the system cannot utilize Wi-Fi, cellular networks, Bluetooth, audio, or the camera, and GPU graphics acceleration has not been implemented. The project remains in the development stage, and an installable package that can be flashed directly is not yet available.

The Windows 11 ARM64 on OnePlus Open project can be viewed on GitHub.

Separately, a Google executive successfully ran Microsoft Win11 on an Apple iPhone Duo using Gemini AI.

Assessment

Developer Kevin Shroff successfully achieved native operation of Windows 11 on ARM64 on the OnePlus Open. This system is installed directly onto the phone's internal storage and runs from the hardware, enabling touch interaction and utilizing the full capacity of 16GB RAM and 8-core processors. However, features such as Wi-Fi, cellular connectivity, Bluetooth, audio, camera, and GPU acceleration are not yet supported, indicating that further development is required.

Summary

Developer Kevin Shroff successfully ported Windows 11 on ARM64 to run natively on the OnePlus Open using internal storage. The system currently supports touch input and utilizes the device's full 16GB RAM and 8-core processor capacity. Despite this significant achievement, key functionalities like Wi-Fi, cellular networking, Bluetooth, camera, and GPU acceleration are not yet implemented, confirming that the project is still in an early development phase.
