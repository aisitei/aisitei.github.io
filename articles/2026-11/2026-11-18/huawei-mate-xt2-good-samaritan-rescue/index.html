Huawei 📱 스마트폰

Huawei Mate XT 2 삼단 폴더블 스마트폰, HarmonyOS 7.0.0.115 업데이트로 StarLight 기술 기반 '선한 사마리아인 구조' 기능 추가

2026-11-18

업데이트 개요

IT之家 11월 17일 소식에 따르면, 오늘 저녁 Huawei Mate 90 시리즈 휴대폰에 HarmonyOS 7.0.0.115 버전이 배포된 것 외에도, Huawei Mate XT 2 3단 폴더블폰 역시 새로운 버전으로 업그레이드되었습니다. 이번 업데이트의 용량은 10GB를 초과하며, StarLight 기술을 기반으로 "선한 사마리아인 구조(好心人救援)" 기능이 추가되었습니다.

주요 업데이트 내용

  • HEIF 형식 이미지를 JPG 형식으로 일괄 변환하는 기능을 지원합니다. 여러 장의 이미지를 한 번에 선택하여 효율적으로 변환할 수 있습니다 (갤러리 > 사진 페이지 또는 특정 앨범 내 > HEIF 형식 이미지 다중 선택 > 더 보기 > JPG 형식으로 변환).
  • 대규모 모델(Large Model) 강화 기능이 추가되었습니다. 사진, 야경, 인물, 대구경 모드에서 촬영 후, 어두운 환경 및 인물 사진을 지속적으로 최적화하여 선명도와 질감을 심층적으로 향상시킵니다 (카메라 설정 > AI 초고화질 강화 > "대규모 모델 강화" 다운로드, 어두운 환경에서 촬영된 사진은 갤러리 인터페이스에서 마법봉 아이콘을 클릭하여 해당 모델을 활성화할 수 있습니다).

기타 개선 사항

  • 화면 녹화 주석 기능에 듀얼 클릭 전환 기능이 추가되었습니다. 화면 녹화 시 라이브 카드(실황 카드)를 통해 주석 스위치를 켜고, 주석 캡슐을 듀얼 클릭하면 "터치 주석"과 "화면 조작" 간에 전환되어 더욱 편리한 사용 경험을 제공합니다 (이 기능 사용 시 스타일러스 펜 연결을 해제해야 합니다).
  • "선한 사마리아인 구조" 기능이 추가되었습니다. StarLight 연결 기술을 기반으로 긴급 정보 전달을 지원하며, 긴급 상황에서 주변 사람들에게 도움을 요청하거나, 수신된 구조 요청 정보를 통해 주변의 구조 요청자에게 도움을 제공할 수 있습니다 (전원 버튼 5회 연속 누르기 > "주변 사람에게 도움 요청" 클릭 > 관련 설정 스위치 켜기).
  • 멀티모달 기반 대규모 모델이 1.0.0.405 버전으로 업데이트되었습니다 (참고: 대규모 모델 업데이트로 인해 이번 업데이트 패키지 용량이 큽니다).
  • 시스템 확장 특성이 동기화되어 업데이트되었으며, 특성 기능이 강화되어 사용자 경험이 향상되었습니다.

참고로, Huawei는 현재 순차적으로 업그레이드를 배포하는 방식을 자주 사용하고 있으므로, 아직 업데이트를 받지 못한 사용자는 계속 기다려야 합니다.

총평

Huawei Mate XT 2 3단 폴더블폰은 HarmonyOS 7.0.0.115 버전으로 업데이트되며, 10GB 이상의 대규모 패치와 함께 다양한 기능 개선이 이루어졌습니다. 특히 StarLight 기술 기반의 "선한 사마리아인 구조" 기능과 대규모 모델을 활용한 카메라 성능 강화가 주목할 만합니다. 또한, HEIF 이미지 일괄 변환 및 화면 녹화 주석 기능 개선으로 사용자 편의성이 향상되었습니다.

系统版本更新与推送

  • Huawei Mate 90 系列手机已推送 HarmonyOS 7.0.0.115 版本。
  • 华为 Mate XT 2 三折叠手机迎来了新版本升级，包体大小突破 10GB。
  • （注意：由于系统更新常采用分批方式，未收到更新的用户需继续等待。）

AI摄影与图像处理增强

  • 新增“大模型增强”功能：在拍照、夜景、人像和大光圈模式下拍摄后，可深度优化暗光和人像照片的清晰度和质感。该功能可在图库界面通过魔法棒图标触发。
  • 媒体格式支持优化：支持批量将 HEIF 格式图片转换为 JPG 格式，操作路径为“图库 > 照片页或某一相册内 > 多选 HEIF 格式图片 > 更多 > 转为 JPG 格式”。

安全通信与交互功能升级

  • 新增“好心人救援”功能：基于星闪连接技术实现紧急信息传递，用户可在紧急情况向周边发起求助，或通过接收到的求救信息提供援助。（触发方式：连按 5 次电源键 > 点击“求助周边人”）
  • 录屏批注优化：新增双击切换功能，实况卡片打开批注开关后，双击批注胶囊即可在“触摸批注”与“操作屏幕”间快速切换。

系统底层核心升级

  • 多模态基础大模型更新至 1.0.0.405 版本（本次更新包体积较大）。
  • 同步更新了系统扩展特性，增强了整体功能和用户体验。

总结

此次针对 Huawei Mate XT 2 的系统升级重点在于提升AI能力、强化安全连接和优化用户交互体验。通过引入“大模型增强”功能和基于星闪技术的“好心人救援”，极大地丰富了设备的实用性和可靠性，同时在媒体处理和录屏批注方面也进行了多项细节改进。

アップデート概要

IT之家が11月17日に報じたところによると、Huawei Mate 90シリーズ向けにHarmonyOS 7.0.0.115バージョンが配布されたほか、Huawei Mate XT 2の3段折りたたみスマートフォンも新しいバージョンにアップグレードされました。今回のアップデートは容量が10GBを超え、「Starlight」技術を基盤とした「良心なサマリア人構造（好心人救援）」機能が追加されています。

主要な更新内容

  • HEIF形式の画像をJPG形式へ一括変換する機能に対応しました。複数の画像を選択し、効率的に変換することが可能です（ギャラリー > 写真ページまたは特定のアルバム内 > HEIF形式画像の複数選択 > その他 > JPG形式に変換）。
  • 「Large Model」強化機能が追加されました。写真、夜景、人物、広角モードで撮影した後、暗い環境や人物写真を継続的に最適化し、鮮明度と質感を深く向上させます（カメラ設定 > AI超高画質強化 > 「Large Model強化」をダウンロード。暗い環境で撮影した写真は、ギャラリーインターフェースで魔法の杖アイコンをクリックして該当モデルを有効にできます）。

その他の改善点

  • 画面録画のアノテーション機能にデュアルクリック切り替え機能が追加されました。画面録画時、「ライブカード（実況カード）」からアノテーションスイッチをオンにし、アノテーションカプセルをデュアルクリックすることで、「タッチアノテーション」と「画面操作」の間を切り替えることができ、より便利な使用体験を提供します（この機能を使用する際はスタイラスペン接続を解除する必要があります）。
  • 「良心なサマリア人構造」機能が追加されました。Starlight接続技術に基づき緊急情報伝達をサポートし、緊急事態において周囲の人に助けを求めたり、受信した救助要請情報を通じて周辺の要請者へ支援を提供できます（電源ボタンを5回連続長押し > 「周囲の人に助けを求める」をクリック > 関連設定スイッチをオンにする）。
  • マルチモーダルベースのLarge Modelが1.0.0.405バージョンに更新されました（注：Large Modelのアップデートにより、今回のアップデートパッケージは容量が大きくなっています）。
  • システム拡張特性が同期され、特性機能が強化されたことでユーザー体験が向上しました。

なお、Huaweiは現在、順次アップグレードを配布する形式をとることが多いため、まだアップデートを受け取っていないユーザーは引き続き待機が必要です。

まとめ

Huawei Mate XT 2の3段折りたたみスマートフォンは、HarmonyOS 7.0.0.115バージョンへの大型パッチ（10GB超）とともに大幅な機能改善が施されました。特に注目すべきは、Starlight技術を活用した「良心なサマリア人構造」機能と、Large Modelを駆使したカメラ性能の強化です。また、HEIF画像のバッチ変換や画面録画のアノテーション機能改善など、日常的な利便性も向上しています。

Update Overview

According to IT之家 news on November 17, not only was version HarmonyOS 7.0.0.115 rolled out for the Huawei Mate 90 series phones this evening, but the Huawei Mate XT 2 triple-foldable phone also received an upgrade to a new version. This update package exceeds 10GB and introduces a "Good Samaritan Rescue" feature based on StarLight technology.

Key Updates

  • The system now supports batch conversion of HEIF format images to JPG format. Users can efficiently convert multiple selected images at once (Gallery > Photo page or specific album > Select multiple HEIF images > More > Convert to JPG format).
  • A Large Model enhancement feature has been added. After taking photos in Portrait, Nightscape, and Wide-angle modes, the system continuously optimizes dark environments and portraits, significantly improving clarity and texture (Camera Settings > AI Ultra High Definition Enhancement > Download "Large Model Enhancement." Photos taken in dark environments can activate this model by clicking the magic wand icon in the Gallery interface).

Other Improvements

  • The screen recording annotation feature now includes a dual-click switching function. When recording the screen, users can turn on the annotation switch via Live Card and toggle between "Touch Annotation" and "Screen Interaction" by double-clicking the annotation capsule, providing a more convenient user experience (Note: This feature requires disconnecting the stylus pen).
  • The "Good Samaritan Rescue" feature has been added. Based on StarLight connection technology, it supports emergency information transmission. In an emergency, users can request help from nearby people or provide assistance to other rescuers through received distress signals (Pressing the power button 5 times continuously > Click "Request Help to Nearby People" > Turn on related setting switch).
  • The multimodal-based Large Model has been updated to version 1.0.0.405 (Note: The update package size is large due to the Large Model update).
  • System extension capabilities have been synchronized and updated, enhancing overall user experience through improved feature functionality.

Please note that Huawei frequently uses a phased rollout method for updates, so users who have not yet received the update may need to wait.

Summary

The Huawei Mate XT 2 triple-foldable phone has been updated to HarmonyOS 7.0.0.115, featuring a large patch exceeding 10GB with various improvements. Key highlights include the StarLight technology-based "Good Samaritan Rescue" function and enhanced camera performance utilizing Large Models. Furthermore, user convenience is improved through HEIF image batch conversion and upgraded screen recording annotation features.
