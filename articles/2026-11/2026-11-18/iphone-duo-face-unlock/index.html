iPhone Duo, 외부 화면 얼굴 잠금 해제 기능 추가

2026-11-18

업데이트

Apple은 오늘 iPhone 및 iPad 사용자에게 iOS/iPadOS 27.3 개발자 미리 보기 Beta 2 업데이트(내부 빌드 번호: 24C5049d)를 배포했습니다. 이번 업데이트는 지난 Beta/RC 버전 출시 이후 13일 만입니다.

새로운 기능

새로운 시스템에서 Apple은 iPhone Duo 폴더블 디스플레이 폰에 "전면 카메라를 사용하여 잠금 해제" 옵션을 추가했습니다. 이 기능을 활성화하면 사용자는 외부 화면을 사용하는 동안 2D 얼굴 인식만으로 Touch ID 없이 기기를 잠금 해제할 수 있습니다.

이 기능은 외부 화면 잠금 해제에만 지원되며, Apple Pay 결제나 계정 비밀번호 자동 완성에는 사용할 수 없습니다. 휴대폰의 내부 화면을 펼치면 시스템은 여전히 Touch ID 또는 비밀번호를 사용하여 기기를 잠금 해제하도록 요구합니다.

또한, "설정" 앱의 "Touch ID 및 비밀번호"에서 얼굴 인식 잠금 해제 기능을 활성화할 수 있습니다. 실제 사용 시 이 기능은 잘 작동하지만, 모든 2D 얼굴 인식 잠금 해제와 마찬가지로 조명이 좋지 않은 환경에서는 효과가 떨어집니다. Apple은 또한 "닫을 때 잠금" 기능을 추가했습니다. 사용자가 iPhone Duo를 닫으면 디스플레이 내용이 외부 화면으로 전환되지 않고 기기가 즉시 잠깁니다.

업데이트 방법

  • 공개 베타 버전: Apple 베타 소프트웨어 프로그램에 등록한 후 "설정" > "일반" > "소프트웨어 업데이트" > "베타 업데이트"를 통해 업그레이드할 수 있습니다.
  • 개발자 미리 보기 버전: Apple 개발자 프로그램에 로그인하여 등록한 후 "설정" > "일반" > "소프트웨어 업데이트"를 통해 업그레이드할 수 있습니다.

총평

Apple은 iOS/iPadOS 27.3 개발자 미리 보기 Beta 2 업데이트를 통해 iPhone Duo 폴더블 폰에 "전면 카메라를 사용하여 잠금 해제" 기능을 추가했습니다. 이 기능은 외부 화면에서 2D 얼굴 인식을 통해 기기를 잠금 해제할 수 있게 해주며, "닫을 때 잠금" 기능도 추가되어 폴더블 폰 사용성을 개선했습니다.

Apple 最新系统更新与功能亮点

Apple 已向 iPhone 和 iPad 用户推送了 iOS / iPadOS 27.3 开发者预览版 Beta 2 更新（内部版本号：24C5049d），本次更新距离上次发布间隔 13 天。

针对折叠屏设备的增强功能

  • 外屏前置摄像头解锁： 为 iPhone Duo 可折叠设备新增了“使用前置摄像头解锁”选项。用户在外屏状态下，可仅依靠 2D 面部识别进行解锁，无需依赖触控 ID。
  • 合盖锁定功能： 新增了“合盖时锁定”功能，当用户合上 iPhone Duo 时，设备将直接锁定，而非将显示内容转移到外屏。

系统使用限制与安全设置

  • 解锁范围限制： 前置摄像头解锁功能仅支持外屏解锁，不能用于 Apple Pay 支付或自动填充账号密码。当手机展开内屏时，仍需使用触控 ID 或密码进行解锁。
  • 开启路径与注意事项： 用户可在“设置”App 的「触控 ID 与密码」中开启面部识别解锁功能；但该功能在光线较差的环境下效果不佳。

Beta 版本获取渠道

  • 公开测试版： 需注册 Apple Beta 版软件计划，通过【设置】>【通用】>【软件更新】>【Beta 版更新】升级。
  • 开发预览版： 需登录注册 Apple 开发者计划，通过【设置】>【通用】>【软件更新】进行升级。

总结

本次 Apple 推出的 iOS / iPadOS 27.3 Beta 2 版本主要为折叠屏设备带来了前置摄像头解锁和合盖锁定等新功能。开发者需注意，这些新安全功能有使用场景限制（如仅支持外屏解锁），且仍受限于环境光线条件。用户可通过公开或开发计划渠道获取该版本的预览版。

アップデート

Appleは本日、iPhoneおよびiPadユーザー向けに、iOS/iPadOS 27.3 Developer Preview Beta 2のアップデート（内部ビルド番号：24C5049d）をリリースしました。このアップデートは、前回のBeta/RCバージョンリリースから13日ぶりとなります。

新機能

新しいシステムでは、AppleがiPhone Duo折りたたみディスプレイフォン向けに「フロントカメラを使用したロック解除」オプションを追加しました。この機能を有効にすると、ユーザーは外部画面を使用している間、Touch IDなしで2D顔認識のみを使用してデバイスのロックを解除できます。

この機能は外部画面でのロック解除に限定されており、Apple Pay決済やアカウントパスワードの自動入力には使用できません。また、携帯電話の内部画面を開くと、システムは引き続きTouch IDまたはパスワードを使用してデバイスのロック解除を要求します。

さらに、「設定」アプリ内の「Touch IDおよびパスコード」から顔認識によるロック解除機能を有効にできます。実際の使用ではこの機能は正常に動作しますが、すべての2D顔認識ロック解除と同様に、照明条件が悪い環境では効果が低下する可能性があります。Appleはまた、「閉じたときのロック」機能も追加しました。ユーザーがiPhone Duoを閉じると、ディスプレイの内容が外部画面に切り替わることなく、デバイスが即座にロックされます。

アップデート方法

  • パブリックベータ版： Appleのベータソフトウェアプログラムに登録した後、「設定」 > 「一般」 > 「ソフトウェアアップデート」 > 「ベータアップデート」からアップグレードできます。
  • 開発者プレビュー版： Appleの開発者プログラムにログインして登録した後、「設定」 > 「一般」 > 「ソフトウェアアップデート」からアップグレードできます。

まとめ

Appleは、iOS/iPadOS 27.3 Developer Preview Beta 2アップデートをリリースし、iPhone Duo折りたたみスマートフォン向けに「フロントカメラを使用したロック解除」機能を追加しました。これにより、外部画面使用時の利便性が向上するほか、「閉じたときのロック」機能も追加され、折りたたみ端末のユーザビリティが改善されています。

Update

Apple today rolled out the iOS/iPadOS 27.3 Developer Preview Beta 2 update (internal build number: 24C5049d) for iPhone and iPad users. This update is released 13 days after the previous Beta/RC version.

New Features

In the new system, Apple has added a "Use Front Camera to Unlock" option for the iPhone Duo foldable display phone. When this feature is enabled, users can unlock the device using only 2D facial recognition while utilizing the external screen, eliminating the need for Touch ID.

This functionality is supported only for unlocking the external display and cannot be used for Apple Pay payments or automatic account password completion. If the user opens the phone's internal screen, the system still requires Touch ID or a passcode to unlock the device.

Additionally, users can activate the facial recognition unlock feature in "Settings" under "Touch ID & Passcode." While this function works well in practice, like all 2D facial recognition unlocks, its effectiveness decreases in poorly lit environments. Apple also introduced a "Lock When Closed" feature. When the user closes the iPhone Duo, the device will immediately lock without transitioning the display content to the external screen.

How to Update

  • Public Beta Version: Users can upgrade by registering for the Apple beta software program and navigating through "Settings" > "General" > "Software Update" > "Beta Update."
  • Developer Preview Version: Users must log into the Apple Developer Program and navigate through "Settings" > "General" > "Software Update" to upgrade.
