Xiaomi 브라우저 확장 프로그램 지원

Xiaomi 인터넷 공식 웨이보에 따르면, Xiaomi 브라우저 모바일 및 Pad 버전이 이제 확장 프로그램을 지원합니다. 광고 차단, 웹 페이지 번역, AI 어시스턴트, 스크립트 관리 기능을 메뉴에서 바로 사용할 수 있습니다.

IT之家는 지난 6월 Xiaomi 직원 @劣人潘이 이 기능을 예고하며, 적절한 시기에 플러그인을 지원하는 브라우저 버전을 출시할 것이라고 언급했음을 확인했습니다.

Xiaomi 브라우저 모바일 버전은 20.32 이상, Pad 버전은 20.6 이상으로 업데이트해야 확장 프로그램 기능을 사용할 수 있습니다. 확장 프로그램 외에도 이번 업데이트를 통해 Xiaomi 브라우저의 AI 검색에 '인터랙티브 스퀘어' 기능이 추가되어 다운로드 없이 바로 사용할 수 있습니다.

사실 브라우저 플러그인 기능은 이번에 처음 등장한 것이 아니라 Xiaomi HyperOS 4 시스템과 함께 처음 공개되었습니다. 2026년 8월 중순, 한 디지털 블로거는 HyperOS 4 브라우저가 이미 플러그인 기능을 지원하며, 사용자가 브라우저 메뉴에서 개인 센터로 들어가 '플러그인' 입구에서 추천 플러그인을 찾아 설치할 수 있다고 공유했습니다.

참고로 HyperOS 4 베타 버전은 2026년 8월 14일 저녁부터 Xiaomi 17 시리즈, Redmi K90 시리즈 및 Xiaomi Pad 8 시리즈 등 기종에 순차적으로 배포되기 시작했습니다.

공개된 확장 프로그램 인터페이스를 보면, 추천 확장 프로그램에는 몰입형 번역, AdGuard 광고 차단기, 유다오 링동 번역 등이 포함되어 있으며, 인기 확장 프로그램에는 FetchV, uBlock Origin Lite 등이 있습니다.

이 기능은 출시 초기에는 시스템에 내장된 추천 플러그인만 지원하며, 사용자가 직접 타사 플러그인 패키지를 설치하는 것은 아직 지원되지 않아 데스크톱 브라우저와는 여전히 차이가 있습니다.

총평

Xiaomi 브라우저가 모바일 및 Pad 버전에서 확장 프로그램 기능을 공식 지원하기 시작했습니다. 이 기능은 광고 차단, 웹 페이지 번역, AI 어시스턴트 등을 포함하며, Xiaomi HyperOS 4 시스템에서 처음 선보였습니다. 현재는 시스템 내장 추천 플러그인만 지원하며, 타사 플러그인 설치는 아직 불가능합니다.

浏览器核心功能升级：支持扩展程序

  • Xiaomi浏览器手机和Pad版本现已支持插件（扩展程序）功能，用户可一键开启广告拦截、网页翻译、AI助手及脚本管理等多种增强功能。

产品更新要求与新增功能

  • 系统版本要求： 手机端需升级至 v20.32 及以上版本；Pad 端需升级至 v20.6 及以上版本才能体验扩展程序。
  • AI搜索增强： 除插件外，Xiaomi浏览器的AI搜索还同步新增了“互动广场”功能，用户无需下载即可使用。

历史发展与系统集成背景

浏览器插件能力并非首次出现，其最早的植入是在Xiaomi澎湃 HyperOS 4 系统中。

  • HyperOS 4 早期曝光： 早在2026年8月中旬，有数码博主分享称HyperOS 4的浏览器已支持插件功能。
  • Beta版推送时间线： HyperOS 4 Beta 版于2026年8月14日晚开始分批次推送，首批覆盖Xiaomi 17系列、REDMI K90系列及Xiaomi Pad 8系列等机型。

扩展程序生态与使用范围

此次更新展示了丰富的插件选择和功能模块。

  • 内置推荐插件示例： 包括沉浸式翻译、AdGuard广告拦截器、有道灵动翻译等。
  • 热门扩展插件示例： 如FetchV、uBlock Origin Lite等。

当前功能限制与改进空间

需要注意的是，该功能上线初期仅支持系统内置的推荐插件，目前暂不支持用户自行安装第三方插件包，这与桌面端浏览器仍存在一定的差距。

总结

Xiaomi宣布其浏览器已正式支持扩展程序，显著提升了浏览体验。此次更新不仅提供了广告拦截、网页翻译等实用功能，还新增了AI搜索的“互动广场”。该功能的推出体现了小米在系统层面的持续迭代能力，并与HyperOS 4系统的插件化趋势保持一致。

Xiaomiブラウザの拡張機能サポート開始

Xiaomi Internetの公式Weiboによると、Xiaomiブラウザのモバイル版およびPad版が、ついに拡張機能をサポートすることが発表されました。これにより、広告ブロック、ウェブページ翻訳、AIアシスタント、スクリプト管理などの機能がメニューから直接利用可能になります。

IT之家は、以前、Xiaomiの従業員である@劣人潘氏がこの新機能を予告し、適切な時期にプラグインをサポートするブラウザバージョンをリリースすると述べていたことを確認しています。

拡張機能を利用するには、以下のアップデートが必要です。

  • モバイル版：20.32以上
  • Pad版：20.6以上

また、今回のアップデートでは拡張機能の追加以外にも、XiaomiブラウザのAI検索に「インタラクティブ・スクエア」機能が追加され、ダウンロードなしで利用できるようになりました。

新機能の背景と制限事項

なお、このブラウザプラグイン機能は今回初めて登場したわけではなく、以前からXiaomi HyperOS 4システムと共に公開されていました。2026年8月中旬には、あるデジタルブロガーがHyperOS 4搭載のブラウザがすでにプラグイン機能をサポートしており、ユーザーがブラウザメニュー内の「個人センター」にある「プラグイン」入口から推奨プラグインを探してインストールできると共有しています。

ちなみに、HyperOS 4ベータ版は、2026年8月14日夕方より、Xiaomi 17シリーズ、Redmi K90シリーズ、Xiaomi Pad 8シリーズなどの機種に順次配布が開始されています。

公開されている拡張機能インターフェースを見ると、推奨される拡張機能には以下のものが含まれています。

  • 没入型翻訳
  • AdGuard広告ブロッカー
  • 友道令堂（Yudao Lingdong）翻訳など

また、人気の拡張機能としてはFetchVやuBlock Origin Liteなどが挙げられています。

ただし、現時点ではこの機能はシステムに組み込まれた推奨プラグインのみをサポートしており、ユーザーが独自にサードパーティのプラグインパッケージをインストールすることはまだできないため、デスクトップブラウザとは依然として差があります。

まとめ

XiaomiブラウザがモバイルおよびPadバージョンにおいて公式に拡張機能サポートを開始しました。この新機能により、広告ブロックやウェブページ翻訳などの高度な機能を利用できるようになりました。本機能はXiaomi HyperOS 4システムで初めて紹介されたものであり、現在利用できるのはシステム内蔵の推奨プラグインのみであり、サードパーティ製プラグインのインストールには制限があります。

Xiaomi Browser Extension Support

According to the official Xiaomi Internet Weibo, both the mobile and Pad versions of the Xiaomi browser now support extensions. Users can directly access features such as ad blocking, web page translation, AI assistants, and script management from the menu.

IT之家 reported that in June, a Xiaomi employee (@劣人潘) had previously announced this feature, stating that they would release a browser version supporting plugins at an appropriate time.

To use the extension functionality, users must update to specific versions: 20.32 or higher for the mobile version and 20.6 or higher for the Pad version. In addition to extensions, this update also adds an 'Interactive Square' feature to Xiaomi Browser's AI search, allowing it to be used immediately without needing a download.

It should be noted that browser plugin functionality is not entirely new; it was first revealed alongside the Xiaomi HyperOS 4 system. In mid-August 2026, a digital blogger shared that the HyperOS 4 browser already supported plugins, allowing users to go to 'Personal Center' within the browser menu and find recommended plugins under the 'Plugins' section for installation.

For reference, the HyperOS 4 beta version began rolling out sequentially starting the evening of August 14, 2026, on devices such as the Xiaomi 17 series, Redmi K90 series, and Xiaomi Pad 8 series.

The publicly revealed extension interface includes recommended extensions like immersive translation, AdGuard ad blocker, and Yudao Lingdong translator. Popular extensions include FetchV and uBlock Origin Lite.

Currently, this feature only supports system-embedded recommended plugins, and users cannot yet install third-party plugin packages, which remains a difference compared to desktop browsers.

Summary

Xiaomi has officially begun supporting extension functionality in both the mobile and Pad versions of its browser. This feature includes tools like ad blocking, web page translation, and AI assistants, having first been showcased within the Xiaomi HyperOS 4 system. Currently, while the function is available via updates (Mobile: 20.32+, Pad: 20.6+), it only supports recommended plugins built into the system, and installing third-party packages remains unsupported.
