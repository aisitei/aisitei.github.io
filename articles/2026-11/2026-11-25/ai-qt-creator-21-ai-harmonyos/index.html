Qt Creator 21 공식 출시: AI 에이전트 통합 강화, Huawei HarmonyOS 기기 지원 추가

2026-11-25

소개

Qt 팀은 11월 23일(현지 시간) 최신 통합 개발 환경(IDE)인 Qt Creator 21을 발표했습니다.

이번 업데이트는 AI Agent와 IDE의 협업 능력을 강화하는 데 중점을 두었으며, 새로운 Profile 성능 분석 모드를 도입하고 C++/QML 디버깅, Git 버전 관리, CMake 프로젝트 관리 및 코드 편집 경험을 개선했습니다.

AI 기능

  • Qt Creator 21은 Agentic AI Chat(ACP) 통합 및 MCP 서버를 기본으로 활성화합니다.
  • MCP 서버에 Bearer Token 인증 메커니즘이 기본으로 추가되어 외부 Agent가 Qt Creator MCP에 연결할 때 요청에 권한 토큰을 추가해야 합니다.
  • 새로운 MCP 서버는 여러 도구를 추가했으며, 사용자가 설정에서 각 도구의 활성화 상태를 개별적으로 구성할 수 있습니다.
  • Agentic AI Chat은 레지스트리의 Agent 자동 업데이트, 이전에 사용했던 작업 영역에 대한 새 세션 생성, 단일 세션 및 각 상호 작용 라운드의 토큰 사용량 및 비용 정보 표시를 지원하도록 업그레이드되었습니다.
  • 사용자는 Agent 전환, 세션 삭제, 필터링 및 즐겨찾기 기능을 통해 모델을 더 편리하게 선택할 수 있습니다.

성능 분석

Qt Creator 21은 새로운 Profile 모드를 추가하고 기존 QML Profiler를 대체하는 새로운 Qt Profiler를 통합했습니다. 새로운 버전은 성능 분석 대시보드를 제공하여 애플리케이션의 여러 성능 지표를 평가하고 특정 문제에 대한 수정 제안을 제공합니다. 분석 트레이스는 독립 문서로 열 수 있으며, Windows 및 macOS 플랫폼의 호출 스택 샘플러와 Qt Tracepoints를 지원합니다.

디버깅

새로운 버전은 실험적인 C++/QML 공동 디버깅 엔진을 추가하여 병합된 호출 스택 정보를 생성할 수 있습니다. 사용자는 실행 구성의 Debug 설정에서 C++와 QML을 동시에 선택할 수 있습니다. 또한, Qt Creator 21은 모듈식 디버거 백엔드를 도입하여 테스트 및 확장을 용이하게 합니다.

편집기 및 버전 관리

새로운 버전은 .qdoc 파일 편집기 및 렌더링 미리 보기를 추가하고, 코드 주석, 텍스트 파일 및 Git 커밋 메시지에 대한 맞춤법 검사를 지원하며, Git 병합 충돌 마커의 표시 방식을 개선했습니다. FakeVim도 여러 수정 사항을 받았으며, 일부 Vimscript 및 플러그인 기능에 대한 지원을 추가했습니다.

Git 도구

Qt Creator 21은 Changes 탐색 뷰를 새로 추가하여 수정된 파일을 확인하고 차이 비교, 스테이징, 되돌리기, 로그 보기 및 주석 달기 등의 작업을 수행할 수 있습니다. 단일 파일 차이는 이제 실시간 편집을 지원하며, 새로 추가된 Git Log 탐색 뷰는 커밋 관계 그래프를 표시하고 커밋과 관련된 파일 통계 정보를 확인하며, 커밋 보기, 브랜치 전환 및 Cherry-pick 등의 작업을 수행할 수 있습니다.

CMake

새로운 버전은 CMake 파서가 업데이트되어 CMake 4.2를 지원하며, cmake-format을 대체할 수 있는 내장 CMake 파일 들여쓰기 기능을 새로 추가했습니다. 또한, CMake 편집기는 Outline 뷰와 드롭다운 탐색을 지원하며, CMake Presets는 Qt Creator 전용 runSettings 및 runDevice 확장을 추가했습니다.

장치 지원

Qt Creator 21은 HarmonyOS 실험적 지원과 SSH를 통해 연결된 원격 Windows 장치 지원을 새로 추가했으며, IDE에서 Podman으로 관리되는 컨테이너를 사용할 수 있도록 허용합니다. Android 지원은 Logcat 뷰를 새로 추가했으며, Xcode 27 환경에서의 iOS 장치 실행 문제도 해결되었습니다.

물론, Qt Creator 21의 HarmonyOS 지원은 현재 실험 단계에 있습니다. Qt 공식 발표(올해 10월)된 Qt 6.12와 함께, 개발자들은 새로운 Qt Creator와 Qt 6.12를 사용하여 관련 HarmonyOS 애플리케이션을 개발할 수 있습니다.

총평

Qt Creator 21은 AI Agent와의 협업 강화, 새로운 Profile 성능 분석 모드 도입, 그리고 C++/QML 디버깅, Git 버전 관리, CMake 프로젝트 관리 및 코드 편집 경험 개선에 중점을 둔 업데이트입니다. 특히 HarmonyOS에 대한 실험적 지원을 추가하여 개발자들에게 새로운 플랫폼 개발 기회를 제공합니다. 이번 업데이트는 Qt Online Installer를 통해 상업용 및 오픈소스 사용자 모두에게 무료로 제공됩니다.

AI与开发环境增强

  • Agentic AI Chat (ACP) 集成： 默认启用 ACP 和 MCP 服务器，并为 MCP 服务器增加了 Bearer Token 身份验证机制。
  • AI 功能升级： 支持自动更新注册表中的 Agent、创建新会话，并能显示单次会话及每轮交互的 Token 使用量和成本信息。用户可切换 Agent、删除会话，并通过筛选和收藏功能管理模型。

性能分析与调试优化

  • 新增 Profile 模式： 集成了全新的 Qt Profiler（取代了 QML Profiler），提供性能分析仪表板，对应用多项指标进行评分并给出修复建议。
  • 高级性能追踪： 支持分析轨迹作为独立文档打开，同时支持 Windows 和 macOS 平台的调用栈采样器以及 Qt Tracepoints。
  • 联合调试引擎： 增加了实验性的 C++/QML 联合调试引擎，可生成合并后的调用栈信息；用户可在运行配置的 Debug 设置中同时选择 C++ 和 QML。

版本控制与项目管理

  • Git 功能增强： 新增 Changes 导航视图，支持查看已修改文件、差异比较、暂存、还原和日志查看等操作。新增 Git Log 导航视图，可展示提交关系图和文件统计信息，并执行 Cherry-pick 等操作。
  • CMake 支持升级： 更新了 CMake 解析器以支持 CMake 4.2；新增内置 CMake 文件缩进器（替代 cmake-format），并在 CMake 编辑器中增加了 Outline 视图和下拉导航功能。
  • 文档与注释编辑： 新增 .qdoc 文件编辑器及渲染预览，支持对代码注释、文本文件和 Git 提交信息进行拼写检查；改进了 Git 合并冲突标记的显示方式。

设备支持与跨平台能力

  • 新兴平台支持： 增加了 HarmonyOS 的实验性支持（目前结合 Qt 6.12 可用于开发）；新增通过 SSH 连接的远程 Windows 设备支持，并在 IDE 中可以使用由 Podman 管理的容器。
  • 移动端优化： Android 支持新增 Logcat 视图；修复了 iOS 设备在 Xcode 27 环境下的运行问题。

其他工具和可用性改进

  • 调试器后端： 引入了模块化调试器后端，方便测试和扩展。
  • 编辑器体验： FakeVim 获得多项修复，并增加了对部分 Vimscript 和插件功能的支持。
  • 获取方式： Qt Creator 21 已通过 Qt Online Installer 提供更新，商业版和开源版用户均可免费升级。

总结

Qt Creator 21 是一个重大版本更新，核心亮点在于深度整合了 AI Agent 能力和专业的性能分析工具集。新版本显著增强了开发者的工作流效率，通过改进 Git、CMake 等项目管理功能，并扩展了对 HarmonyOS、Android 和远程设备的兼容性，为开发者提供了更全面、更强大的集成开发环境。

概要

Qtチームは、2023年11月23日（現地時間）に最新の統合開発環境（IDE）であるQt Creator 21を発表しました。今回のアップデートでは、AIエージェントとIDEの協働能力強化に重点が置かれており、新しいProfile性能分析モードの導入に加え、C++/QMLデバッグ、Gitバージョン管理、CMakeプロジェクト管理、コード編集体験など、多くの機能改善が行われています。

AI機能

  • Qt Creator 21は、Agentic AI Chat (ACP) の統合とMCPサーバーをデフォルトで有効化しています。
  • MCPサーバーにはBearer Token認証メカニズムが標準搭載され、外部エージェントがQt Creator MCPに接続する際には、リクエストに権限トークンを追加する必要があります。
  • 新しいMCPサーバーは複数のツールを追加し、ユーザーは設定から各ツールの有効/無効を個別に構成できます。
  • Agentic AI Chatはアップグレードされ、レジストリのエージェント自動更新、以前使用したワークスペースに対する新規セッション作成、単一セッションおよび各インタラクションラウンドのトークン使用量とコスト情報の表示をサポートします。
  • ユーザーは、エージェントの切り替え、セッションの削除、フィルタリング、お気に入り機能を通じて、モデルをより便利に選択できるようになりました。

パフォーマンス分析

Qt Creator 21には新しいProfileモードが追加され、既存のQML Profilerに代わる新しいQt Profilerが統合されました。新バージョンは性能分析ダッシュボードを提供し、アプリケーションの複数のパフォーマンス指標を評価するとともに、特定の問題に対する修正提案を行います。分析トレースは独立したドキュメントとして開くことができ、WindowsおよびmacOSプラットフォームのコールスタックサンプラーとQt Tracepointsをサポートしています。

デバッグ

新バージョンには、実験的なC++/QML共同デバッグエンジンが追加され、統合されたコールスタック情報を生成できます。ユーザーは実行構成のDebug設定から、C++とQMLの両方を同時に選択することが可能です。さらに、Qt Creator 21はモジュール式なデバッガーバックエンドを導入し、テストや拡張性を容易にしました。

エディタおよびバージョン管理

新バージョンでは、.qdocファイルのエディタとレンダリングプレビューが追加されました。また、コードコメント、テキストファイル、Gitコミットメッセージに対するスペルチェックをサポートし、Gitマージコンフリクトマーカーの表示方法も改善されています。FakeVimも多くの修正を受け、一部のVimscriptやプラグイン機能へのサポートが追加されました。

Gitツール

Qt Creator 21には「Changes」ナビゲーションビューが新設され、変更されたファイルの確認、差分比較、ステージング、ロールバック、ログ表示、コメント付けなどの操作が可能になりました。単一ファイル差分はリアルタイム編集をサポートし、新しく追加されたGit Logナビゲーションビューでは、コミット関係グラフの表示や、コミットに関連するファイル統計情報の確認、コミットの閲覧、ブランチ切り替え、Cherry-pickといった作業が実行できます。

CMake

新バージョンでは、CMakeパーサーが更新され、CMake 4.2をサポートしています。また、cmake-formatに代わる組み込みのCMakeファイルインデント機能が追加されました。さらに、CMakeエディタはOutlineビューとドロップダウンナビゲーションに対応し、CMake PresetsにはQt Creator専用のrunSettingsおよびrunDevice拡張が追加されています。

デバイスサポート

Qt Creator 21は、HarmonyOSの実験的なサポートと、SSH経由で接続されたリモートWindowsデバイスのサポートを追加しました。また、IDE内でPodmanによって管理されるコンテナを使用できるようになりました。AndroidサポートにはLogcatビューが追加され、Xcode 27環境でのiOSデバイス実行に関する問題も解決されています。

なお、Qt Creator 21のHarmonyOSサポートは現在実験段階です。開発者は、今年の10月に公式発表されたQt 6.12とともに、新しいQt CreatorとQt 6.12を使用して関連するHarmonyOSアプリケーションを開発できます。

まとめ

Qt Creator 21は、AIエージェントとの協働強化、新しいProfile性能分析モードの導入、そしてC++/QMLデバッグ、Gitバージョン管理、CMakeプロジェクト管理、コード編集体験の改善に重点を置いた大規模なアップデートです。特にHarmonyOSに対する実験的なサポートを追加したことで、開発者に対して新たなプラットフォーム開発機会を提供します。本アップデートは、Qt Online Installerを通じて、商用およびオープンソースユーザー双方に無料で提供されます。

Introduction

The Qt team announced its latest Integrated Development Environment (IDE), Qt Creator 21, on November 23rd (local time). This update focuses on strengthening collaboration between AI Agents and the IDE, introducing a new Profile performance analysis mode, and improving the experience for C++/QML debugging, Git version control, CMake project management, and general code editing.

AI Features

  • Qt Creator 21 natively integrates Agentic AI Chat (ACP) and an MCP server.
  • The MCP server now includes a Bearer Token authentication mechanism, requiring external Agents to add authorization tokens when connecting to the Qt Creator MCP.
  • The new MCP server adds multiple tools, which users can individually configure for activation in the settings.
  • Agentic AI Chat has been upgraded to support automatic Agent updates from the registry, creating new sessions for previously used workspaces, and displaying token usage/cost information for single sessions and each interaction round.
  • Users can now more conveniently select models using features like Agent switching, session deletion, filtering, and favorites.

Performance Analysis

Qt Creator 21 introduces a new Profile mode and integrates the new Qt Profiler, which replaces the existing QML Profiler. The new version provides a performance analysis dashboard to evaluate multiple application metrics and offers suggested fixes for specific issues. Analysis traces can be opened as independent documents and support call stack samplers and Qt Tracepoints on both Windows and macOS platforms.

Debugging

The new version adds an experimental C++/QML co-debugging engine, which generates merged call stack information. Users can select both C++ and QML simultaneously in the Debug settings of a run configuration. Furthermore, Qt Creator 21 introduces a modular debugger backend to facilitate testing and extension.

Editor and Version Control

The new version adds a .qdoc file editor and rendering preview, supports spell checking for code comments, text files, and Git commit messages, and improves the display method for Git merge conflict markers. FakeVim also received several updates, adding support for some Vimscript and plugin functionality.

Git Tools

Qt Creator 21 introduces a new Changes navigation view that allows users to view modified files, perform diff comparisons, stage changes, revert, view logs, and add annotations. Single file diff now supports real-time editing. The newly added Git Log view displays the commit relationship graph, provides file statistics related to commits, and enables tasks such as viewing commits, switching branches, and cherry-picking.

CMake

The new version features an updated CMake parser that supports CMake 4.2, and introduces built-in CMake file indentation functionality to replace cmake-format. Additionally, the CMake editor now supports Outline view and dropdown navigation. CMake Presets add Qt Creator specific runSettings and runDevice extensions.

Device Support

Qt Creator 21 adds experimental support for HarmonyOS and remote Windows device support via SSH. It also allows users to utilize containers managed by Podman within the IDE. Android support includes a new Logcat view, and issues running iOS devices in the Xcode 27 environment have been resolved.

It is important to note that Qt Creator 21's HarmonyOS support is currently experimental. With Qt 6.12 (officially announced by Qt this October), developers can use the new Qt Creator and Qt 6.12 to develop related HarmonyOS applications.

Summary

Qt Creator 21 focuses on enhancing collaboration with AI Agents, introducing a new Profile performance analysis mode, and improving core development experiences across C++/QML debugging, Git version control, CMake project management, and code editing. The update provides developers with opportunities to build for new platforms through experimental HarmonyOS support. This release is available free of charge to both commercial and open-source users via the Qt Online Installer.
