Huawei HarmonyOS 7 시스템 '스타 플래시 이어폰' 기능 출시, 스마트폰 기본 음악 앱 + 재생 제어 센터에서 체험 가능

2026-11-02

HarmonyOS 7.0.0.111 업데이트

Huawei는 10월 말 Mate 80/70/60, Pura 80/70 등 시리즈 모델에 최신 HarmonyOS 7.0.0.111 버전 업데이트를 배포했습니다. 이번 업데이트를 통해 iPhone 듀얼 기기 상호 연결, 라이브 윈도우 공유 등의 기능이 추가되었습니다.

스타라이트 이어 모니터링 기능

IT之家의 실제 테스트 결과, 일부 모델(Mate 80 Pro Max 등, Mate 90 시리즈 등은 이전부터 지원)이 해당 버전으로 업데이트된 후 "스타라이트 이어 모니터링" 기능이 추가된 것을 확인했습니다. 이 기능은 노래방 모드에서 녹음된 소리가 휴대폰에 업로드되는 동시에 헤드폰으로 녹음된 소리를 재생하여 실시간으로 자신의 노래방 효과를 들을 수 있도록 지원합니다.

사실 이어 모니터링 기능은 이번이 처음은 아닙니다. 올해 7월경 출시된 시스템 버전에서 Huawei는 유선 헤드폰 연결만 지원하는 이어 모니터링 기능을 선보였습니다. 이번 111 버전 업데이트를 통해 더 많은 모델에서 스타라이트 헤드폰과 함께 사용할 수 있게 되었습니다. 현재 이 기능은 Huawei Music, QQ Music 등(NetEase Cloud Music은 이 기능을 지원하지 않음)에서 지원되며, FreeBuds 7 헤드폰과 함께 사용해야 합니다. 사용 방법은 다음과 같습니다.

  • 휴대폰의 StarLight™ 스위치를 켭니다: 설정 > StarLight 및 Bluetooth;
  • 페어링된 기기 목록에서 StarLight™ 아이콘이 있는 헤드폰 이름을 클릭하면 StarLight 연결이 완료됩니다.
  • 노래방 앱에 진입하면 헤드폰이 자동으로 노래방 모드로 전환되며, 수동 조작이 필요 없습니다. 또는 휴대폰 상태 표시줄을 아래로 내려 음악 앱을 열고 재생 제어 센터로 진입한 후 왼쪽으로 스와이프하여 재생 제어 가사 화면으로 이동하고 왼쪽 하단의 이어 모니터링 기능을 클릭하여 음향 효과를 선택한 후 이어 모니터링 기능을 켤 수도 있습니다.

총평

Huawei는 HarmonyOS 7.0.0.111 업데이트를 통해 iPhone 듀얼 기기 상호 연결 및 라이브 윈도우 공유 기능을 추가했습니다. 특히, "스타라이트 이어 모니터링" 기능이 확장되어 FreeBuds 7 헤드폰과 함께 무선으로 실시간 노래방 모니터링이 가능해졌습니다. 이 기능은 Huawei Music, QQ Music 등에서 지원되며, 사용 편의성을 높였습니다.

系统版本升级与覆盖机型

  • Huawei已于10月底向部分机型推送了最新的鸿蒙 HarmonyOS 7.0.0.111 版本。
  • 本次更新支持的机型系列包括 Mate 80 / 70 / 60、Pura 80 / 70 等。

新增核心互联功能

  • 升级版本带来了与 iPhone 的双机互联功能。
  • 新增了实况窗分享等实用功能。

“星闪耳返”功能详解

本次更新重点优化并上线了“星闪耳返”功能，使用户在 K 歌模式下可以实时听到自己的演唱效果。

  • **功能描述：** 当开启 K 歌模式时，录制的声音会同时通过耳机播放，支持用户实时监测自己的K歌表现。
  • **兼容性提升：** 该耳返功能已从最初仅支持有线耳机，升级到支持更多机型搭配星闪（Star Flash）无线耳机使用。

“星闪耳返”的使用要求与步骤

  • **适用硬件：** 需搭配 FreeBuds 7 耳机使用。
  • **支持应用：** 目前该功能已支持 Huawei音乐、全民 K 歌等应用（注意，网易云音乐不支持此功能）。
  • **开启方法一（快捷入口）：** 打开手机的星闪™开关（设置 > 星闪和蓝牙），点击已配对设备内带星闪™图标的耳机名称完成连接。进入K歌应用后，耳机将自动切换至 K 歌模式。
  • **开启方法二（状态栏操作）：** 可下拉手机状态栏，打开音乐 App，进入播控中心，左滑到播控歌词界面，点击左下角耳返功能并选择音效后打开。

总结

华为通过推送 HarmonyOS 7.0.0.111 版本，为 Mate 80/70/60 等系列机型带来了多项升级，核心亮点是增强了与 iPhone 的互联体验和实况窗分享功能。特别值得关注的是“星闪耳返”功能的全面优化，它不仅提升了 K 歌娱乐体验的沉浸感，也扩大了无线耳机的使用兼容范围。

HarmonyOS 7.0.0.111 アップデート

Huaweiは、Mate 80/70/60やPura 80/70などのシリーズモデルに対し、最新のHarmonyOS 7.0.0.111バージョンを10月末に展開しました。今回のアップデートにより、iPhoneとのデュアルデバイス連携機能や、ライブウィンドウ共有といった新機能が追加されています。

スターライトイヤモニタリング機能

IT之家による実際のテストの結果、一部のモデル（Mate 80 Pro Maxなど。なお、Mate 90シリーズなどは以前から対応しています）において、このバージョンへのアップデートに伴い「スターライトイヤモニタリング」機能が追加されていることが確認されました。この機能は、カラオケモードで録音された音声がスマートフォンにアップロードされると同時に、ヘッドホンを通じて録音した音声を再生し、リアルタイムで自身の歌唱エフェクトを確認できるようにサポートします。

イヤモニタリング機能自体が今回初めてではありません。今年7月頃にリリースされたシステムバージョンでは、Huaweiは有線ヘッドホン接続のみに対応する形でこの機能を発表していました。今回の111バージョンアップデートにより、より多くのモデルでスターライトヘッドホンと組み合わせて使用できるようになりました。現在、この機能はHuawei MusicやQQ Musicなど（NetEase Cloud Musicは対応していません）で利用可能であり、FreeBuds 7ヘッドホンとの併用が必要です。具体的な使用手順は以下の通りです。

  • スマートフォンのStarLight™スイッチをオンにする：設定 > StarLightおよびBluetooth
  • ペアリングされたデバイスリストから、StarLight™アイコンがあるヘッドホンの名前をクリックすると、StarLight接続が完了します。
  • カラオケアプリに入ると、自動的にヘッドホンがカラオケモードに切り替わり、手動操作は不要です。または、スマートフォンのステータスバーを下に引き、音楽アプリを開いて再生コントロールセンターに進み、左にスワイプして再生コントロールの歌詞画面へ移動した後、左下のイヤモニタリング機能をクリックし、音響エフェクトを選択してから、イヤモニタリング機能をオンにすることも可能です。

まとめ

HuaweiはHarmonyOS 7.0.0.111アップデートを通じて、iPhoneとのデュアルデバイス連携やライブウィンドウ共有機能を追加しました。特に注目すべきは、「スターライトイヤモニタリング」機能が拡張され、FreeBuds 7ヘッドホンと組み合わせてワイヤレスでリアルタイムのカラオケモニタリングが可能になった点です。この機能はHuawei MusicやQQ Musicなどのアプリで利用でき、ユーザーの利便性を大幅に向上させています。

HarmonyOS 7.0.0.111 Update

Huawei has rolled out the latest HarmonyOS 7.0.0.111 update to series models, including the Mate 80/70/60 and Pura 80/70, toward the end of October. This update introduces new functionalities such as iPhone dual device interconnection and live window sharing.

Starlight Ear Monitoring Feature

According to tests conducted by IT之家, models such as the Mate 80 Pro Max (while the Mate 90 series has supported this feature previously) were confirmed to have gained "Starlight Ear Monitoring" after updating to this version. This function supports real-time listening of karaoke effects through headphones while the recorded sound is being uploaded from the karaoke mode.

The ear monitoring capability itself is not new. Huawei first introduced wired headphone connection support for ear monitoring in a system version around July of this year. The 111 version update expands compatibility, allowing use with Starlight Headphones across more models. Currently, this feature is supported within apps like Huawei Music and QQ Music (it does not support NetEase Cloud Music) and must be used with FreeBuds 7 headphones. The usage steps are as follows:

  • Turn on the StarLight™ switch on the phone: Settings > StarLight & Bluetooth;
  • Tapping the headphone name, which displays a StarLight™ icon, in the paired device list completes the StarLight connection.
  • When entering a karaoke app, the headphones automatically switch to karaoke mode without manual operation. Alternatively, you can swipe down from the phone's status bar, open a music app, enter the playback control center, swipe left to access the playback control lyrics screen, and click "Ear Monitoring" in the bottom left corner to select an acoustic effect before enabling the function.

Summary

The HarmonyOS 7.0.0.111 update from Huawei adds features like iPhone dual device interconnection and live window sharing. Notably, the "Starlight Ear Monitoring" feature has been expanded, allowing wireless real-time karaoke monitoring with FreeBuds 7 headphones. This function is supported by apps such as Huawei Music and QQ Music, significantly improving user convenience.
