보안 아키텍처 Secure Exclaves 소개

Apple은 오늘 Apple Silicon 칩의 보안 아키텍처인 Secure Exclaves(보안 격리 구역)에 대한 기술 문서를 발표했습니다. 이 문서는 Secure Exclaves가 카메라 및 마이크로폰에서 수집된 데이터를 처리할 때 원본 오디오 및 비디오 정보가 운영체제, 애플리케이션, 심지어 Apple 자체에도 접근되지 않도록 하는 메커니즘을 설명합니다.

Apple 보안 엔지니어링 및 아키텍처 팀(SEAR)과 코어 운영체제 팀(Core OS)은 11월 12일 Apple 보안 연구 블로그에 "Secure Exclaves and Ambient Sensing"이라는 제목의 글을 게시하여 Secure Exclaves의 설계 원리, 기본 아키텍처 및 실제 적용 시나리오를 소개했습니다.

Apple은 기기가 점점 더 지능적인 환경 감지 기능을 갖추게 되면서 카메라와 마이크로폰이 주변 환경 정보를 지속적으로 처리해야 한다고 밝혔습니다. 예를 들어, 기기는 사용자가 근처에 있는지, 특정 음성 명령을 감지하는지, 현재 누가 기기를 사용하고 있는지 등을 식별해야 합니다. 이러한 기능은 민감한 오디오 및 비디오 데이터를 처리해야 하지만, 기기가 이러한 정보를 지속적으로 녹화하거나 저장해야 한다는 의미는 아닙니다.

이를 위해 Apple은 Secure Exclaves를 도입하여 카메라 및 마이크로폰 데이터 처리 과정을 독립적이고 격리된 실행 환경에 두었습니다. Apple의 설명에 따르면, 환경 감지 모드에서 원본 오디오 및 비디오 데이터는 주 운영체제, 애플리케이션 또는 Apple 자체로 전달되지 않으며, 처리 완료 후 폐기됩니다. 시스템은 특정 소리가 감지되었는지, 등록된 사용자가 식별되었는지, 사용자의 위치 등 필요한 메타데이터만 외부로 제공합니다.

Secure Exclaves의 주요 구성 요소

Secure Exclaves는 주로 데이터 격리, 제어된 통신 인터페이스 및 보안 지시 메커니즘의 세 가지 측면을 중심으로 구축됩니다.

데이터 격리

데이터 격리 측면에서 Secure Exclaves는 주 운영체제와 다른 프로세서 실행 환경에서 실행되며, Apple 맞춤형 L4 마이크로커널을 사용합니다. Apple은 또한 보안 페이지 테이블 모니터(SPTM)를 통해 메모리 접근 권한을 관리하여 주 운영체제 커널도 Secure Exclaves 전용 메모리의 데이터를 읽을 수 없도록 합니다.

통신 인터페이스

통신 측면에서 Apple은 Swift로 작성된 Secure IPC라는 통신 메커니즘을 개발했으며, 미리 정의된 인터페이스를 통해 서로 다른 구성 요소 간의 데이터 교환을 제한합니다. 각 격리 구역은 명시적으로 승인된 리소스에만 접근할 수 있으며, 감사된 필수 정보만 주 운영체제로 전달될 수 있습니다.

보안 지시 메커니즘

보안 지시 측면에서 Apple은 카메라 및 마이크로폰 데이터가 격리 환경을 언제 떠날 수 있는지 관리하는 전용 Exclave Indicator Controller(격리 구역 지시 컨트롤러)를 설계했습니다. 애플리케이션이 센서 데이터에 대한 완전한 접근이 필요할 때, 시스템은 먼저 해당 표시등 또는 화면 알림이 표시되었는지 확인하고, 규정된 가시 시간 동안 유지된 후에만 데이터 전송을 허용합니다.

Secure Exclaves의 적용 사례

Apple은 또한 HomeView에서 Secure Exclaves의 적용을 소개했습니다. 이 기기는 카메라와 마이크로폰을 통해 최대 6명의 등록된 사용자를 식별하고, 사용자가 기기 근처에 있는지 판단할 수 있습니다. 카메라 격리 구역은 얼굴을 감지하고 관련 데이터를 생성하며, 마이크로폰 격리 구역은 오디오 정보를 처리한 후 독립적인 신경망 엔진 격리 큐를 통해 추론을 수행합니다.

최종적으로 시스템은 사용자 식별, 위치 및 식별 신뢰도와 같은 메타데이터만 주 운영체제로 전달하며, 원본 이미지나 오디오는 제공하지 않습니다. 운영체제는 이를 바탕으로 캘린더, 메시지, Apple Music 등 기능의 표시 내용을 조정할 수 있습니다.

IT之家는 Secure Exclaves가 iPhone 18 Pro, iPhone 18 Pro Max 및 iPhone Duo의 카메라, 마이크로폰 화면 표시 기능과 MacBook Neo 및 HomeView의 카메라 표시 기능에도 적용된다는 점에 주목했습니다.

Apple은 iPhone 18 Pro의 "Hey Siri" 음성 호출 기능을 예로 들어 이 메커니즘이 어떻게 작동하는지 설명했습니다. 기기는 먼저 AOP(Always-On Processor)를 통해 저전력으로 호출어를 감지하고, 가능한 "Hey Siri" 명령이 감지되면 오디오 버퍼를 오디오 격리 구역으로 전달하여 Siri 격리 구역에서 2차 인식을 수행합니다.

호출어를 확인하기 전까지 주 운영체제는 Siri를 호출해야 한다는 알림만 받을 뿐 오디오 데이터는 얻지 못합니다. 사용자가 능동적인 상호작용 상태로 진입하고, 시스템이 마이크로폰 표시 마크 표시 및 보안 검사를 완료한 후에만 오디오가 Siri 서비스로 전송되는 것이 허용됩니다.

Apple은 화면 표시 기능이 운영체제만 담당하는 것이 아니라고 설명했습니다. 화면 표시점을 사용하는 기기의 경우, 독립적인 디스플레이 격리 구역이 화면에 실제로 표시되는 픽셀(색상, 모양, 지속 시간, 밝기 포함)을 확인하여 표시 마크가 사용자에게 실제로 보이는지 확인하고, 악성 소프트웨어가 표시 마크를 숨기거나 위조하여 사용자를 오도하는 것을 방지합니다.

Secure Exclaves의 기반 기술

기반 기술 측면에서 Apple은 Secure Exclaves의 마이크로커널이 Capability 메커니즘을 사용하여 권한을 관리하며, 시스템 구성 요소는 기본적으로 다른 구성 요소나 하드웨어 리소스에 접근할 권한이 없으며, 명시적인 승인을 받은 후에만 상호작용할 수 있다고 밝혔습니다.

Apple은 또한 마이크로커널에 대한 형식 검증을 수행하여 수학적 방법을 통해 C 언어 구현이 미리 정의된 기능 사양을 준수하는지 확인하고, 기존 소프트웨어 테스트로는 발견하기 어려운 하위 수준의 논리적 문제를 찾아냅니다. 그러나 Apple은 현재 형식 검증이 점진적으로 진행되고 있으며, 마이크로커널의 모든 부분을 포괄하지는 않는다고 강조했습니다.

총평

Apple의 Secure Exclaves는 사용자 프라이버시 보호를 강화하기 위한 혁신적인 보안 아키텍처입니다. 이 시스템은 카메라 및 마이크로폰 데이터를 격리된 환경에서 처리하여 원본 정보가 운영체제나 애플리케이션에 노출되지 않도록 합니다. 데이터 격리, 제어된 통신, 그리고 시각적 표시 메커니즘을 통해 민감한 환경 감지 기능이 안전하게 작동하도록 설계되었습니다.

Secure Exclaves는 주로 데이터 격리, 제어된 통신 인터페이스 및 보안 지시 메커니즘의 세 가지 측면을 중심으로 구축됩니다.

Secure Exclaves의 적용 사례

Apple은 또한 HomeView에서 Secure Exclaves의 적용을 소개했습니다. 이 기기는 카메라와 마이크로폰을 통해 최대 6명의 등록된 사용자를 식별하고, 사용자가 기기 근처에 있는지 판단할 수 있습니다. 카메라 격리 구역은 얼굴을 감지하고 관련 데이터를 생성하며, 마이크로폰 격리 구역은 오디오 정보를 처리한 후 독립적인 신경망 엔진 격리 큐를 통해 추론을 수행합니다.

호출어를 확인하기 전까지 주 운영체제는 Siri를 호출해야 한다는 알림만 받을 뿐 오디오 데이터는 얻지 못합니다. 사용자가 능동적인 상호작용 상태로 진입하고, 시스템이 마이크로폰 표시 마크 표시 및 보안 검사를 완료한 후에만 오디오가 Siri 서비스로 전송되는 것이 허용됩니다.

Apple은 화면 표시 기능이 운영체제만 담당하는 것이 아니라고 설명했습니다. 화면 표시점을 사용하는 기기의 경우, 독립적인 디스플레이 격리 구역이 화면에 실제로 표시되는 픽셀(색상, 모양, 지속 시간, 밝기 포함)을 확인하여 표시 마크가 사용자에게 실제로 보이는지 확인하고, 악성 소프트웨어가 표시 마크를 숨기거나 위조하여 사용자를 오도하는 것을 방지합니다.

Secure Exclaves의 기반 기술

기반 기술 측면에서 Apple은 Secure Exclaves의 마이크로커널이 Capability 메커니즘을 사용하여 권한을 관리하며, 시스템 구성 요소는 기본적으로 다른 구성 요소나 하드웨어 리소스에 접근할 권한이 없으며, 명시적인 승인을 받은 후에만 상호작용할 수 있다고 밝혔습니다.

Apple은 또한 마이크로커널에 대한 형식 검증을 수행하여 수학적 방법을 통해 C 언어 구현이 미리 정의된 기능 사양을 준수하는지 확인하고, 기존 소프트웨어 테스트로는 발견하기 어려운 하위 수준의 논리적 문제를 찾아냅니다. 그러나 Apple은 현재 형식 검증이 점진적으로 진행되고 있으며, 마이크로커널의 모든 부분을 포괄하지는 않는다고 강조했습니다.

총평

Apple의 Secure Exclaves는 사용자 프라이버시 보호를 강화하기 위한 혁신적인 보안 아키텍처입니다. 이 시스템은 카메라 및 마이크로폰 데이터를 격리된 환경에서 처리하여 원본 정보가 운영체제나 애플리케이션에 노출되지 않도록 합니다. 데이터 격리, 제어된 통신, 그리고 시각적 표시 메커니즘을 통해 민감한 환경 감지 기능이 안전하게 작동하도록 설계되었습니다.
