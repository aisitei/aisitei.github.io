구글, Gemini Decision 1 모델 기반의 빠른 멀티모달 의사결정 Gemini Decisions API 출시

2026-11-13

Gemini Decisions API 소개

Google은 Gemini Decision 1 모델로 구동되는 Gemini Decisions API를 발표했습니다. 이 API는 텍스트, 이미지, 비디오, PDF 콘텐츠에 대해 최대 1,000개의 예/아니오 판단, 옵션 선택 및 표준 평가를 단 한 번의 빠른 처리 과정으로 수행할 수 있습니다.

주요 기능 및 활용

Gemini Decisions API는 도구 선택, 정책 검사, 모델 라우팅, 컨텍스트 품질 평가와 같은 의사 결정 작업을 위해 설계되었습니다. 개발자는 텍스트, 이미지, 오디오, 비디오, PDF를 포함하는 멀티모달 콘텐츠(최대 256K 토큰 지원)를 입력하고, 해당 콘텐츠에 대해 최대 1,000개의 독립적인 질문을 할 수 있습니다.

성능 및 비용

  • Gemini Decision 1은 단 한 번의 순방향 계산으로 후보 옵션에 점수를 매기고 확률 및 신뢰도 점수를 반환합니다.
  • 전체 처리 과정의 지연 시간은 150~250밀리초입니다.
  • 입력 가격은 100만 토큰당 0.10달러이며, 출력 토큰에는 비용이 부과되지 않습니다.

아키텍처 및 유연성

이 API는 Gemini의 네이티브 멀티모달 아키텍처를 기반으로 구축되었습니다. 개발자는 동일한 입력 내에서 다양한 모달리티의 콘텐츠를 결합할 수 있습니다. 예를 들어, 통화 녹음과 계정 메타데이터를 결합하거나, 스캔한 PDF 청구서와 손상된 사진을 함께 사용할 수 있습니다. 또한, 이미지 및 비디오 입력의 해상도를 조정하여 시각적 세부 정보와 토큰 비용을 제어할 수 있습니다.

가용성

현재 Gemini Decisions API는 Google AI Studio에서 제공되며, 개발자는 프로토타입 개발을 위한 무료 크레딧을 받을 수 있습니다.

총평

Google의 Gemini Decisions API는 Gemini Decision 1 모델을 기반으로 텍스트, 이미지, 비디오, PDF 등 다양한 형식의 콘텐츠를 빠르게 분석하여 최대 1,000가지의 의사 결정을 지원합니다. 이 API는 도구 선택, 정책 검토 등 복잡한 의사 결정 작업을 효율적으로 처리하며, 개발자는 다양한 모달리티를 결합하여 유연하게 활용할 수 있습니다.

产品发布与核心定位

  • 谷歌宣布推出 Gemini Decisions API，这是一个由全新 Gemini Decision 1 模型驱动的快速多模态决策API。
  • 该API专为复杂的决策任务设计，能够对输入内容进行非判断、选项选择和标准评估。

关键功能与应用场景

  • **核心能力：** 在一次快速处理过程中，可对文本、图像、视频和 PDF 内容执行至多 1000 项相互独立的问题或评估。
  • **主要用途：** 适用于工具选择、策略检查、模型路由以及上下文质量评估等复杂的决策任务。

输入内容与多模态支持

  • 开发者可以输入包含文本、图像、音频、视频和 PDF 的多模态内容，最高支持 256K Tokens。
  • API基于Gemini原生多模态架构构建，允许用户在同一份输入中组合不同模态的内容（例如：通话录音与账户元数据；扫描版PDF理赔文件与受损照片）。

开发者接入信息

总结

Gemini Decisions APIの概要

Googleは、Gemini Decision 1モデルを搭載した「Gemini Decisions API」を発表しました。このAPIを利用することで、テキスト、画像、動画、PDFコンテンツに対して、最大1,000件の「はい/いいえ」判定、オプション選択、および標準的な評価を、単一の高速処理プロセスで実行することが可能です。

主な機能と活用事例

Gemini Decisions APIは、ツール選択、ポリシーチェック、モデルルーティング、コンテキスト品質評価といった意思決定タスクのために設計されています。開発者は、テキスト、画像、音声、動画、PDFを含むマルチモーダルコンテンツ（最大256Kトークンをサポート）を入力し、そのコンテンツに対して最大1,000件の独立した質問を投げかけることができます。

性能とコスト

  • Gemini Decision 1は、単一の順方向計算（フォワードパス）で候補オプションにスコアリングを行い、確率および信頼度スコアを返します。
  • 全体の処理レイテンシは150〜250ミリ秒です。
  • 入力トークンの料金は100万トークンあたり0.10ドルであり、出力トークンには費用がかかりません。

アーキテクチャと柔軟性

本APIは、Geminiのネイティブなマルチモーダルアーキテクチャを基盤として構築されています。開発者は、単一の入力内で多様なモダリティのコンテンツを組み合わせることが可能です。例えば、通話録音データとアカウントメタデータを結合したり、スキャンしたPDF請求書と破損した写真などを組み合わせて使用できます。また、画像や動画の入力解像度を調整することで、視覚的な詳細度とトークンコストの両方を制御することが可能です。

利用可能性

現在、Gemini Decisions APIはGoogle AI Studioを通じて提供されており、開発者はプロトタイプ開発のために無料クレジットを利用できます。

Introduction to Gemini Decisions API

Google has announced the Gemini Decisions API, powered by the Gemini Decision 1 model. This API can perform up to 1,000 yes/no judgments, option selections, and standard evaluations on text, images, video, and PDF content in a single, rapid processing pass.

Key Features and Use Cases

The Gemini Decisions API is designed for decision-making tasks such as tool selection, policy checking, model routing, and context quality evaluation. Developers can input multimodal content—including text, images, audio, video, and PDFs (supporting up to 256K tokens)—and ask up to 1,000 independent questions about that content.

Performance and Cost

  • Gemini Decision 1 scores candidate options and returns probability and confidence scores in a single forward pass.
  • The latency for the entire processing process is between 150–250 milliseconds.
  • The input cost is $0.10 per million tokens, and no cost is charged for output tokens.

Architecture and Flexibility

This API is built on Gemini's native multimodal architecture. Developers can combine content from various modalities within the same input. For example, they can combine a call recording with account metadata, or use scanned PDF invoices alongside damaged photos. Furthermore, developers can control visual detail and token costs by adjusting the resolution of image and video inputs.

Availability

The Gemini Decisions API is currently available through Google AI Studio, where developers can receive free credits for prototyping.

Overview

Google's Gemini Decisions API utilizes the Gemini Decision 1 model to rapidly analyze various content formats, including text, images, video, and PDFs, supporting up to 1,000 decisions. This API efficiently handles complex decision-making tasks like tool selection and policy review, allowing developers flexible use by combining diverse modalities.
