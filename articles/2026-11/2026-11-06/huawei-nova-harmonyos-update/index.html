Huawei nova 12/13 시리즈 HarmonyOS 7.0.0.111 업데이트, iPhone 듀얼 스마트폰 상호 연결 및 통신 공유 기능 지원

2026-11-06

업데이트 개요

Huawei는 오늘 nova 12 시리즈 및 nova 13 시리즈 스마트폰에 HarmonyOS 7.0.0.111SP10 버전 업그레이드를 제한 없이 제공한다고 발표했습니다. (설정 > "소프트웨어 업데이트" 검색 > 업데이트 확인) 또한, 6.1.0.145 및 4.2.0.208 버전에서 7.0.0.111SP10으로 업그레이드할 수 있는 체험 활동 업그레이드 경로도 함께 제공됩니다.

새 버전에서는 iPhone 듀얼 기기 상호 연결, 상호 통신 공유 등의 기능이 추가되었습니다. 전체 업데이트 로그는 다음과 같습니다.

주요 기능 업데이트

  • 통신 공유 기능이 업그레이드되어, 휴대폰과 HarmonyOS 7이 탑재된 휴대폰, 태블릿, HarmonyOS 컴퓨터 간에 다중 사용자 상호 통신 공유를 지원합니다. 터치하거나 동일한 Huawei 계정으로 로그인하여 네트워크를 공유함으로써 상호 네트워크를 구축할 수 있으며, 모바일 네트워크 신호가 약하거나 네트워크 부하가 큰 상황에서 더 빠르고 안정적인 네트워크 경험을 제공합니다.
  • iPhone의 "HarmonyOS Starlink Interconnection" 앱을 통해 iPhone과 상호 연결하여 메시지 상호 흐름 / 기기 상호 찾기 / 네트워크 공유 기능을 구현할 수 있습니다.
  • 실시간 창 공유 기능이 새로 추가되었습니다. 실시간 창 카드를 왼쪽으로 스와이프한 후 공유 버튼을 클릭하면 Huawei Share, MeeTime 등의 시나리오를 통해 연락처에 공유할 수 있습니다. (일부 앱 실시간 창 지원)
  • 앱이 핵심 정보를 플로팅 창, 플로팅 캡슐, 고정 스크롤바, 배너 카드 형태로 화면에 상주시켜 실시간 모니터링 및 편리한 조작을 가능하게 합니다. 예를 들어, 주식 동향을 실시간으로 추적하여 모든 시나리오에서 가벼운 모니터링을 구현할 수 있습니다. (일부 앱 지원)

시스템 최적화

  • 일부 시나리오에서 시스템 안정성이 최적화되었습니다.
  • 카메라 촬영 후 썸네일 미리보기를 클릭하는 사용 경험이 최적화되었습니다.
  • 갤러리 안정성 및 일부 인터페이스의 표시 효과가 최적화되었습니다.
  • 일부 Bluetooth 시나리오의 사용 경험이 최적화되었습니다.

총평

Huawei HarmonyOS 7.0.0.111SP10 업데이트는 nova 12 및 nova 13 시리즈 사용자에게 통신 공유 기능 강화와 iPhone과의 상호 연결을 포함한 다양한 신규 기능을 제공합니다. 또한, 실시간 정보 표시 및 공유 기능이 개선되었으며, 전반적인 시스템 안정성과 카메라, 갤러리, Bluetooth 사용 경험이 최적화되었습니다.

系统升级与版本开放

  • Huawei官方宣布，nova 12 系列和 nova 13 系列手机已不限量开放 HarmonyOS 7.0.0.111SP10 版本升级。
  • 用户可通过“设置 > 搜索‘软件更新’ > 检查更新”进行升级。
  • 同时开放了多条升级链路的尝鲜活动，包括从 6.1.0.145 和 4.2.0.208 到 HarmonyOS 7.0.0.111SP10 的升级路径。

跨设备互联与通信共享

  • **增强的通信共享功能：** 支持手机与搭载 HarmonyOS 7 的平板、鸿蒙电脑之间进行多人互助通信共享，可通过碰一碰或登录同一华为账号建立网络，以提升在信号弱或负载大的场景下的网络体验。
  • **iPhone互联支持：** 新版本下放了与 iPhone 双机互联和互助通信共享功能。用户可通过 iPhone 的“鸿蒙星河互联”应用实现消息相互流转、设备查找及网络共享。

核心功能增强与实时交互

  • **实况窗分享：** 新增了实况窗分享功能，用户可通过点击左滑后的分享按钮，将内容分享至联系人（支持部分应用）。
  • **全场景信息常驻：** 支持应用将关键信息以悬浮窗口、悬浮胶囊、固定滚动条或横幅卡片等形态常驻屏幕，便于实时关注和便捷操作，例如实现股票动态的轻量化盯盘（部分应用支持）。

系统优化与稳定性提升

  • **系统稳定性：** 优化了部分场景的整体系统稳定性。
  • **用户体验优化：** 改进了相机拍摄后点击缩略图预览的使用流程。
  • **基础功能优化：** 优化了图库的稳定性及多个界面的显示效果，并提升了部分蓝牙场景的使用体验。

总结

本次HarmonyOS 7.0.0.111SP10版本升级为nova 12和nova 13系列用户带来了全面的系统增强。核心亮点在于强化了跨设备互联能力，特别支持与iPhone的深度协同，并新增实况窗分享等功能。此外，系统在多场景下的稳定性、相机预览和蓝牙体验等方面也进行了全面优化。

アップデート概要

Huaweiは本日、nova 12シリーズおよびnova 13シリーズのスマートフォンに対し、HarmonyOS 7.0.0.111SP10バージョンへのアップグレードを無制限で提供すると発表しました。（設定 > 「ソフトウェアアップデート」を検索 > アップデートを確認）また、6.1.0.145および4.2.0.208バージョンから7.0.0.111SP10へアップグレードできる体験版のアップグレードパスも同時に提供されます。

新バージョンでは、iPhoneとのデュアルデバイス連携や相互通信共有などの機能が追加されています。全体のアップデートログは以下の通りです。

主な機能更新

  • 通信共有機能が強化され、スマートフォンとHarmonyOS 7を搭載したタブレット、およびHarmonyOSコンピューター間でマルチユーザーの相互通信共有が可能になりました。同じHuaweiアカウントでログインするかタッチするだけでネットワークを共有し、相互ネットワークを構築でき、モバイルネットワークの電波が弱い状況やネットワーク負荷が高い状況でも、より高速かつ安定したネットワーク体験を提供します。
  • iPhoneの「HarmonyOS Starlink Interconnection」アプリを通じて、iPhoneと連携することで、メッセージの相互フロー、デバイスの相互検索、およびネットワーク共有機能を実現できます。
  • リアルタイムウィンドウ共有機能が新しく追加されました。リアルタイムウィンドウカードを左にスワイプし、共有ボタンをクリックすると、Huawei ShareやMeeTimeなどのシナリオを通じて連絡先に共有することが可能です。（一部アプリで対応）
  • アプリの主要な情報をフローティングウィンドウ、フローティングカプセル、固定スクロールバー、バナーカードといった形で画面上に常駐させることができ、リアルタイムでのモニタリングと便利な操作が可能になります。例えば、株価の動向をリアルタイムで追跡し、あらゆるシナリオで軽量な監視を実現できます。（一部アプリに対応）

システム最適化

  • いくつかのシナリオにおいて、システムの安定性が最適化されました。
  • カメラ撮影後にサムネイルプレビューをクリックする際のユーザー体験が最適化されました。
  • ギャラリーの安定性や一部インターフェースの表示効果が最適化されました。
  • 一部のBluetoothシナリオにおける使用体験が最適化されました。

まとめ

Huawei HarmonyOS 7.0.0.111SP10へのアップデートは、nova 12およびnova 13シリーズのユーザーに対し、通信共有機能の大幅な強化とiPhoneとの連携など、多様な新機能を提供します。また、リアルタイム情報の表示・共有機能が改善され、全体的なシステム安定性やカメラ、ギャラリー、Bluetoothの使用体験も最適化されています。

Update Overview

Huawei announced today that it is providing the HarmonyOS 7.0.0.111SP10 upgrade to nova 12 and nova 13 series smartphones without restrictions (Settings > Search "Software Update" > Check for update). Additionally, an experiential upgrade path is provided to allow users to upgrade from versions 6.1.0.145 and 4.2.0.208 to 7.0.0.111SP10.

The new version introduces features such as dual-device interconnection with iPhone and enhanced intercommunication sharing. The full update log is detailed below.

Key Feature Updates

  • Enhanced Communication Sharing: The communication sharing feature has been upgraded to support multi-user intercommunication sharing among phones, tablets, and HarmonyOS computers running HarmonyOS 7. Users can establish an interconnected network by touching or logging in with the same Huawei account, providing a faster and more stable network experience when mobile network signals are weak or network load is high.
  • iPhone Interconnection: Through the "HarmonyOS Starlink Interconnection" app for iPhone, users can interconnect devices to implement message flow sharing, device finding, and network sharing features.
  • Real-Time Window Sharing: A new real-time window sharing feature has been added. By swiping the real-time window card to the left and clicking the share button, users can share content with contacts through scenarios like Huawei Share or MeeTime (requires support from some apps).
  • Floating Information Display: Apps can now keep key information visible on the screen in the form of floating windows, floating capsules, fixed scrollbars, or banner cards. This enables real-time monitoring and convenient operation. For example, users can track stock trends in real time to achieve light monitoring across various scenarios (requires support from some apps).

System Optimization

  • System stability has been optimized in certain operational scenarios.
  • The user experience when clicking the thumbnail preview after taking a photo has been optimized.
  • Gallery stability and display effects in several interfaces have been optimized.
  • The user experience for specific Bluetooth scenarios has been optimized.

Summary

The Huawei HarmonyOS 7.0.0.111SP10 update delivers significant enhancements to the nova 12 and nova 13 series, focusing on expanded communication sharing capabilities and robust interconnection with iPhone. Key improvements include enhanced real-time information display and sharing functions. Furthermore, overall system stability has been optimized, alongside improved user experiences for camera, gallery, and Bluetooth functionalities.
