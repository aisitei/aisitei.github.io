Apple Siri AI 스케줄링 규칙 공개: 영어 요청의 약 2%는 로컬 AI 모델로 처리, 타이머 등 고빈도 작업 포함

2026-11-11

Siri AI 업데이트

IT之家 11월 10일 소식에 따르면, 정보원 @itspdfu는 오늘(11월 10일) X 플랫폼에 게시물을 올려 Apple이 iOS/macOS 27.3 첫 개발자 프리뷰 베타 버전에서 Siri AI에 'Skimmer'라는 전처리 모듈을 도입했으며, 영어 요청의 약 2%를 처음으로 로컬에서 처리하도록 라우팅했다고 밝혔습니다.

정보원은 macOS 27.3 프리뷰 버전에서 인터넷 연결 상태일 때 Siri AI 영어 요청의 약 2%가 로컬 모델로 처리된다고 지적했습니다. 이는 주로 "타이머 설정", "음악 재생", "전화 걸기"와 같이 사용 빈도가 높고 구조가 비교적 고정된 명령을 포함하여 지연 시간을 줄이고 컴퓨팅 파워를 절약하며 개인 정보를 보호합니다. IT之家는 관련 스크린샷을 첨부했습니다.

백그라운드 실행 메커니즘과 관련하여, 이 정보원은 새로운 Siri AI의 기기 내 처리 과정에 Apple이 'Skimmer'라는 전처리 모듈을 도입했다고 분석했습니다. 이 모듈은 정규 표현식을 통해 사용자 요청과 미리 설정된 "도구 흐름"을 매칭하며, 규칙에 일치하면 Siri는 더 복잡한 AI 추론 단계로 넘어가지 않고 해당 작업을 직접 실행할 수 있습니다.

관련 규칙 파일은 macOS 시스템 디렉토리 IntelligenceFlowPlannerSupport.framework 아래에서 언어 환경별로 확인할 수 있으며, 파일명은 Enigma.json입니다.

이에 대해 사용자 @lolrepeatlol은 댓글을 통해 Siri AI의 답변이 때때로 이전 버전 Siri와 유사한 이유를 알 것 같다고 말했습니다. 예를 들어 "오늘 비가 언제 그치나요?"라고 물었을 때, Siri는 여전히 "한 시간 안에 비가 올 수 있습니다"와 같은 기계적인 답변을 할 수 있습니다.

총평

Apple은 iOS/macOS 27.3 개발자 프리뷰 베타에서 Siri AI에 'Skimmer' 전처리 모듈을 도입하여 일부 영어 요청을 기기 내에서 처리하도록 했습니다. 이는 "타이머 설정", "음악 재생" 등 자주 사용되는 고정된 명령에 적용되어 지연 시간을 줄이고 개인 정보 보호를 강화합니다. 이 변화는 Siri의 응답 속도와 효율성을 개선하는 데 기여할 것으로 보입니다.

Apple Siri AI本地化处理升级

根据消息源爆料，在 Apple 的 iOS / macOS 27.3 首个开发者预览版 Beta 中，苹果公司为 Siri AI 引入了重要的前置模块，旨在提升设备端的响应速度和用户隐私保护。

Siri AI本地化处理机制

  • 核心功能： 在联网状态下，约 2% 的英文 Siri 请求将路由到本地模型进行处理。
  • 新增模块： Apple 引入了名为 Skimmer 的前置模块来管理设备端的处理流程。
  • 工作原理： Skimmer 通过正则表达式匹配用户请求与预设的“工具流程”（tool flows）。一旦规则命中，Siri 可直接执行相应操作，无需进入复杂的 AI 推理环节。

支持的高频指令范围

本地处理主要覆盖高频、结构相对固定的日常指令，包括但不限于：

  • 设置定时器（“设置定时器”）
  • 播放音乐（“播放音乐”）
  • 拨打电话（“拨打电话”）

技术细节与优化目标

此次本地化处理的引入带来了多重优化效果，并提供了详细的技术文件路径：

  • 性能提升： 降低了操作延迟，节省了设备算力。
  • 隐私保护： 将部分请求在本地完成处理，增强用户隐私性。
  • 规则文件位置： 相关规则文件可在 macOS 系统目录 `IntelligenceFlowPlannerSupport.framework` 下的语言环境文件夹内查看，文件名为 `Enigma.json`。

总结

苹果在 iOS/macOS 27.3 Beta 版本中为 Siri AI 集成了 Skimmer 前置模块，实现了约 2% 的英文请求本地化处理。这一升级通过利用正则表达式匹配高频指令（如设置定时器、播放音乐），旨在显著降低延迟、节省算力并增强用户隐私保护能力。

Siri AIのアップデート：ローカル処理機能の導入

IT之家が11月10日のニュースで報じたところによると、情報源@itspdfuは本日（11月10日）、Xプラットフォームに投稿し、AppleがiOS/macOS 27.3の最初の開発者プレビューベータ版において、Siri AIに「Skimmer」という前処理モジュールを導入したことを明らかにしました。これにより、英語のリクエストの一部（約2%）が初めてローカルで処理されるようになりました。

同情報源によると、macOS 27.3のプレビュー版では、インターネット接続時にSiri AIによる英語リクエストの約2%がローカルモデルによって処理されます。これは主に、「タイマー設定」「音楽再生」「電話をかける」といった使用頻度が高く、構造が比較的固定されているコマンドを含みます。この機能により、レイテンシ（遅延時間）の削減、計算能力の節約、そして個人情報の保護強化が実現します。IT之家は関連するスクリーンショットも添付しています。

バックグラウンド実行メカニズムに関して、同情報源は、Appleが新しいSiri AIのオンデバイス処理プロセスに「Skimmer」という前処理モジュールを導入したと分析しました。このモジュールは正規表現を用いてユーザーのリクエストと事前に設定された「ツールフロー（tool flow）」を照合します。ルールに一致した場合、Siriはより複雑なAI推論ステップを経由することなく、該当タスクを直接実行できるようになります。

関連するルールファイルは、macOSのシステムディレクトリ内のIntelligenceFlowPlannerSupport.framework以下で、言語環境別に確認でき、ファイル名はEnigma.jsonとなっています。

これに対し、ユーザー@lolrepeatlolはコメント欄で、Siri AIの回答が時折以前のバージョンのSiriと似た理由を理解した気がすると述べています。例えば、「今日雨はいつ止みますか？」と尋ねた場合でも、Siriは依然として「1時間以内に雨が降る可能性があります」といった機械的な回答をする可能性があるとのことです。

まとめ

AppleはiOS/macOS 27.3の開発者プレビューベータ版において、Siri AIに「Skimmer」という前処理モジュールを導入しました。この機能により、「タイマー設定」や「音楽再生」など頻繁に使用される固定的なコマンドの一部がデバイス上でローカル処理されるようになります。これにより、レイテンシの削減と個人情報保護の強化が図られ、Siriの応答速度と効率性の向上が期待されます。

Siri AI Update

According to news from IT之家 on November 10th, an insider account (@itspdfu) posted on X today (November 10th), revealing that Apple has introduced a preprocessing module called 'Skimmer' into Siri AI within the iOS/macOS 27.3 Developer Preview Beta version.

The source pointed out that in the macOS 27.3 preview, approximately 2% of English Siri AI requests are processed locally when connected to the internet. This local processing primarily covers high-frequency and structurally fixed commands, such as:

  • "Setting a timer"
  • "Playing music"
  • "Making a call"

The benefits of this approach include reducing latency, saving computing power, and enhancing personal data privacy. IT之家 attached relevant screenshots detailing the feature.

Technical Mechanism

Regarding the background execution mechanism, the source analyzed that Apple has implemented 'Skimmer' as a preprocessing module for Siri AI's on-device processing. This module uses regular expressions to match user requests against predefined "tool flows." When a rule matches, Siri can execute the task directly without proceeding through more complex AI inference stages.

The relevant rules files can be found in the macOS system directory under IntelligenceFlowPlannerSupport.framework for various language environments; the file name is Enigma.json.

In a comment, user @lolrepeatlol suggested that this explains why Siri AI's responses sometimes resemble those of previous versions. For instance, if asked, "When will the rain stop today?", Siri might still give a mechanical response like, "It may rain within an hour."

Summary

Apple has integrated the 'Skimmer' preprocessing module into Siri AI in the iOS/macOS 27.3 Developer Preview Beta. This feature enables local processing for certain English requests, specifically targeting frequently used and fixed commands like setting timers or playing music.

This shift is designed to improve Siri's response speed and efficiency while simultaneously enhancing personal data privacy by keeping routine tasks on the device.
