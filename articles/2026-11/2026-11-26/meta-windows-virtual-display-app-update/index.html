Meta, Windows용 Virtual Display 스트리밍 앱 업데이트: 카메라 및 마이크 PC 전달, 양방향 입력 전달 등 기능 추가

2026-11-26

주요 업데이트

Meta는 Windows 플랫폼용 Virtual Display 스트리밍 앱을 업데이트하여 Quest 헤드셋과 PC 간의 협업 기능을 더욱 강화했습니다. 이번 업데이트에는 카메라 및 마이크 PC 포워딩, USB 유선 스트리밍, 양방향 입력 포워딩 기능이 추가되었습니다.

카메라 및 마이크 포워딩

  • Windows 시스템에서 Quest 헤드셋의 전면 패스스루 카메라를 사용하여 현재 시야를 다른 사람과 공유할 수 있습니다.
  • 호환되는 애플리케이션에서 비디오 입력 소스로 선택할 수 있습니다.
  • Discord, Zoom과 같은 Windows 앱에서 가상 전면 카메라를 활용하여 Meta 아바타로 영상 통화를 할 수 있습니다.

USB 유선 스트리밍

  • 무선 연결의 대안으로 제공됩니다.
  • 네트워크 환경이 좋지 않거나, 공용 Wi-Fi에서 기기 간 통신이 제한될 때, 또는 인터넷 접속이 어려운 여행 중 유용합니다.
  • USB로 기기를 처음 연결할 때 QR 코드 스캔이나 PIN 입력 없이 직접 연결할 수 있습니다.

양방향 입력 포워딩

  • Virtual Display를 통해 Windows에 연결할 때, PC에 페어링된 마우스와 키보드를 사용하여 Quest 헤드셋의 Horizon OS 시스템을 동시에 조작할 수 있어 작업 효율성을 높일 수 있습니다.

총평

이번 Meta Virtual Display 업데이트는 Quest 헤드셋과 PC 간의 연결성과 활용도를 크게 향상시켰습니다. 특히 카메라 및 마이크 포워딩, USB 유선 스트리밍, 양방향 입력 포워딩 기능은 사용자의 편의성과 생산성을 높이는 데 기여할 것으로 보입니다. 외신은 이러한 업데이트가 Meta VR Glasses의 출시를 위한 사전 작업이며, 생산성을 주요 사용 시나리오로 설정한 Meta의 전략과도 연결된다고 분석했습니다.

Windows平台串流功能增强

Meta更新了其Windows平台的Virtual Display串流应用，旨在大幅提升Quest头显与PC之间的协同工作能力。本次更新主要围绕输入、视频传输和连接稳定性进行了优化。

多维度的设备输入与转发

  • 摄像头与麦克风转发：用户现在可以将Quest头显的前向透视摄像头作为视频源分享给他人，或将其选作兼容应用的视频输入。
  • 虚拟形象支持：在Discord、Zoom等Windows应用中，用户可以使用Meta的虚拟形象进行视频通话。
  • 双向输入转发：通过Virtual Display连接时，用户可以利用PC配对的鼠标键盘来操作Quest头显原生的Horizon OS系统，提高了处理效率。

增强的网络连接与稳定性

  • USB有线串流支持：新增了USB有线串流功能，作为无线连接的替代方案。
  • 适用场景：该模式特别适用于网络环境较差、公共Wi-Fi限制设备通信或用户无法接入互联网的场景。
  • 便捷性提升：首次通过USB连接时，用户无需扫描二维码或输入PIN码，可实现直接连接。

面向生产力的应用拓展

这些功能将Meta VR头显定位为重要的生产力工具。除了基本的串流和控制外，系统支持了虚拟形象的调用，使其在远程协作和视频会议等场景中具备更强的实用性。

未来硬件展望：Meta VR Glasses

  • 应用潜力：外媒指出，这些更新为Meta VR Glasses铺路，表明生产力已成为该机的主要使用场景之一。
  • 扩展显示能力：Meta VR Glasses本身支持DisplayPort输入，这意味着它可作为Mac、Windows PC或游戏主机的外接显示设备来使用。

总结

本次更新的核心在于通过增强串流应用的稳定性和功能性，将Quest头显从娱乐设备推向了更专业的生产力工具。新增的USB有线连接和双向输入转发等功能，极大地提升了用户在各种网络环境下使用VR进行工作协作的能力，并为Meta VR Glasses作为外接显示设备的潜力打下了基础。

主なアップデート内容

MetaがWindowsプラットフォーム向けのVirtual Displayストリーミングアプリを更新し、QuestヘッドセットとPC間の連携機能をさらに強化しました。今回のアップデートでは、カメラおよびマイクのPCフォワーディング機能、USB有線ストリーミング機能、そして双方向入力フォワーディング機能が追加されています。

カメラ・マイクのPCフォワーディング

  • Windowsシステム上で、Questヘッドセットのフロントパススルーカメラを使用して現在の視界を他者と共有することが可能になりました。
  • 互換性のあるアプリケーションにおいて、ビデオ入力ソースとしてこの機能を選択できます。
  • DiscordやZoomといったWindowsアプリ内で仮想フロントカメラを活用し、Metaアバターを通じてビデオ通話を行うことができます。

USB有線ストリーミング

  • ワイヤレス接続の代替手段として提供されます。
  • ネットワーク環境が不安定な場合や、公共Wi-Fiなどでのデバイス間通信が制限される状況、あるいはインターネット接続が困難な旅行先で特に有用です。
  • USB経由でデバイスを初めて接続する際も、QRコードのスキャンやPIN入力なしに直接接続できるようになりました。

双方向入力フォワーディング

  • Virtual Displayを通じてWindowsに接続している際、PCにペアリングされたマウスとキーボードを使用して、QuestヘッドセットのHorizon OSシステムを同時に操作することができ、作業効率の大幅な向上が期待できます。

総評

今回のMeta Virtual Displayアップデートは、QuestヘッドセットとPC間の接続性と実用性を大きく向上させました。特にカメラ・マイクフォワーディング、USB有線ストリーミング、双方向入力フォワーディング機能の追加は、ユーザーの利便性と生産性の向上に大きく貢献すると考えられます。海外メディアからは、これらのアップデートがMeta VR Glassesの市場投入に向けた準備段階であり、Metaが「生産性」を主要なユースケースとして位置づけている戦略と関連しているとの分析が出ています。

まとめ

今回のアップデートにより、QuestヘッドセットはPCとの連携において飛躍的な進化を遂げました。カメラ・マイクの共有やUSB有線接続による安定性の確保に加え、外部デバイスからの入力（マウス/キーボード）が双方向で可能になったことで、VR空間での作業効率と実用性が大幅に向上しました。これらの機能強化は、Metaが単なるエンターテイメント機器としてではなく、「生産性を高めるツール」としてVR市場を捉えていることを示しています。

Key Updates

Meta has updated its Virtual Display streaming app for the Windows platform, significantly enhancing collaboration between Quest headsets and PCs. This update introduces several new features, including camera and microphone PC forwarding, USB wired streaming, and bi-directional input forwarding.

Camera and Microphone Forwarding

  • Users can share their current view using the front passthrough camera of the Quest headset within Windows systems.
  • The feed can be selected as a video input source in compatible applications.
  • It allows users to participate in video calls with Meta avatars in Windows apps like Discord and Zoom, utilizing the virtual front camera.

USB Wired Streaming

  • This feature serves as an alternative to wireless connectivity.
  • It is particularly useful when network conditions are poor, device communication is restricted on public Wi-Fi, or when traveling without reliable internet access.
  • The system supports direct USB connection upon initial setup, eliminating the need for QR code scanning or PIN entry.

Bi-directional Input Forwarding

  • When connecting to Windows via Virtual Display, users can operate the Quest headset's Horizon OS system simultaneously using a mouse and keyboard paired with their PC, thereby boosting overall work efficiency.

Summary

The Meta Virtual Display update substantially improves connectivity and utility between Quest headsets and PCs. The addition of camera/mic forwarding, USB wired streaming, and bi-directional input forwarding are expected to greatly enhance user convenience and productivity. Industry reports suggest these updates serve as preparatory steps for the launch of future Meta VR Glasses, aligning with Meta's strategic focus on professional and productive use cases.
