IT之家 iOS/안드로이드 버전 9.55 출시: iPhone Duo 등 대화면 기기 경험 향상

2026-11-26

안녕하세요, IT之家 앱 iOS / Android 버전 9.55가 정식 출시되었습니다. 지금 바로 다운로드하여 업데이트하세요!

이번 업데이트의 가장 중요한 개선 사항은 정보 피드 대화면 레이아웃의 진화입니다. 'IT之家 - MADE FOR iPhone Duo'에서 예고했듯이, Android 및 iOS 버전 모두 뉴스, 커뮤니티 정보 피드의 반응형 레이아웃 개선을 완료했습니다. 넓은 화면에서 목록이 너비에 따라 자동으로 1, 2, 3...열 레이아웃으로 전환되어 화면 공간을 낭비하지 않습니다.

참고: 목록 자동 적응형 레이아웃은 페이지 분할(분할 화면) 표시와 충돌하지 않습니다. 대부분의 장치에서 분할 화면 시 왼쪽 목록 너비를 드래그하여 조정할 수 있으며, 너비 조건이 충족되면 자동으로 열 수가 전환됩니다. 분할 화면을 끄고 목록이 화면을 가득 채우도록 하려면 [설정 - 인터페이스 및 상호작용 - 분할 화면 표시]에서 설정할 수 있습니다 (Android 설정 경로는: 설정 - 실험실 - 페이지 분할 화면 표시이며, 일부 장치에서는 시스템 설정에서 조정해야 할 수 있습니다).

HarmonyOS 버전도 추후 목록 반응형 레이아웃을 지원할 예정입니다. 물론, 일부 사용자분들이 이러한 레이아웃에 익숙하지 않을 수 있다는 점을 고려하여, 다음 버전에서는 전환 스위치를 제공할 예정입니다.

이 외에도 iOS 버전은 iPhone Duo에 대한 더 많은 세부적인 개선 사항을 적용하여 사용 경험을 더욱 향상시켰습니다. 또한 iPhone Duo의 반으로 접힌 외부 화면 사용 상태를 인식하여, 작은 꼬리 장치 형태가 2개 더 추가되었습니다 (총 몇 가지일까요?).

전체 업데이트 기록은 아래를 참조하세요. 현재 iOS 최신 버전은 우여곡절 끝에 오늘 아침 정식 출시되었습니다. Android 버전은 각 스토어에 제출되어 승인 대기 중이며, 앱 내 업데이트를 통해서도 업그레이드할 수 있습니다.

iOS / iPad OS 버전 9.55

  • 추가: 기능 - 대화면 장치에서 와이드 스크린 다중 열 지원 (목록 등 페이지에서 다중 열 레이아웃 사용)
  • 추가: 기능 - iPhone Duo, 작은 꼬리에서 반으로 접힌 외부 화면 스타일 지원
  • 개선: 기능 - iPhone Duo, 상세 페이지 댓글/좋아요 수 배지가 댓글 아이콘 하단에 표시되도록 변경
  • 개선: 기능 - iPhone Duo, 상세 페이지 도구 모음의 뒤로 가기 버튼이 상단에 표시되도록 변경
  • 수정: 기능 - 분할 화면 전환 후 답글 등 팝업 페이지가 올바르게 숨겨지지 않는 문제
  • 수정: 기능 - 분할 화면 모드에서 기사 상세 페이지에서 제스처로 댓글 영역을 스크롤할 수 없는 문제
  • 수정: 인터페이스 - 분할 화면 전환 후 기사 상세 페이지 등에서 뒤로 가기 버튼이 표시되지 않을 수 있는 문제
  • 수정: 인터페이스 - 분할 화면 전환 후 검색 페이지의 검색창 너비가 올바르게 설정되지 않을 수 있는 문제
  • 수정: 인터페이스 - 분할 화면 전환 후 충돌이 발생할 수 있는 문제
  • 수정: 인터페이스 - 특정 상황에서 투고 페이지의 팝업 텍스트가 잘 보이지 않을 수 있는 문제
  • 수정: 인터페이스 - 인터페이스 크기 변경 시 하단 도구 모음 UI 표시 이상 문제
  • 수정: 인터페이스 - iPad, 매직 키보드 사용 시 파란색 선택 상자가 나타나는 문제
  • 수정: 인터페이스 - iPad, 몰입형 읽기 모드 활성화 후 기사에서 홈 목록으로 돌아갈 때 맨 위로 돌아갈 수 있는 문제
  • 수정: 인터페이스 - iPad, 뉴스 듣기 플로팅 창이 메인 창을 드래그한 후 비정상적으로 표시되는 문제
  • 수정: 인터페이스 - iPad, 오프라인 읽기/창작 선언 등 인터페이스가 완전히 표시되지 않을 수 있는 문제
  • 수정: 인터페이스 - iPad, 홈 페이지 더보기 팝업/컬럼 편집 인터페이스 버튼이 너무 크게 표시되는 문제
  • 수정: 인터페이스 - iPad, 기사 상세 페이지 하단 도구 모음 간격이 너무 좁은 문제
  • 수정: 인터페이스 - iPhone Duo, 검색 엔진 선택, 푸시 알림, 하단 도구 모음 페이지, 커뮤니티 비디오 페이지가 가려질 수 있는 문제
  • 수정: 인터페이스 - iPhone Duo, 뉴스 체험 비디오 페이지, 라이브 페이지, 커뮤니티 비디오 페이지 전체 화면 버튼이 작동하지 않는 문제
  • 수정: 인터페이스 - iPhone Duo, 몰입형 읽기 모드에서 수직 도구 모음이 숨겨지는 문제
