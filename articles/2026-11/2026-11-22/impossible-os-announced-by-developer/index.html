남아프리카 개발자, Win32 및 Linux 바이너리 프로그램과 호환되는 독자 개발 OS 'Impossible OS' 발표: 2년 후 공개 예정

2026-11-22

서론

운영체제를 처음부터 개발하는 것은 숙련된 엔지니어링 팀에게도 어려운 작업이지만, 남아프리카 공화국의 개발자이자 기업가인 데릭 페인(Derek Payne)은 이 작업을 홀로 수행하기로 결정했습니다.

현지 시간으로 20일, 외신 TechSpot은 페인이 최근 현대 x86-64 PC를 위한 새로운 운영체제인 Impossible OS를 공개했다고 보도했습니다. 이 운영체제는 Windows 11의 디자인을 참고했으며, 완전히 오픈소스 코드를 기반으로 개발되었습니다.

Impossible OS의 목표

프로젝트의 공식 선언문에 따르면, Impossible OS의 목표는 Win32 API 기반 소프트웨어를 네이티브로 실행하는 동시에 Linux 바이너리 프로그램과 호환되는 것입니다.

페인은 Impossible OS가 "또 다른 Linux 배포판"이 아니라, Ring 0 커널, UEFI 부트로더, 데스크톱 그래픽 인터페이스 등 핵심 구성 요소를 포함하는 자체적인 하위 아키텍처를 가진 독립적인 운영체제임을 강조했습니다.

호환성 및 개발 언어

호환성 측면에서 Impossible OS는 커널 네이티브 API를 통해 Win32 소프트웨어를 지원하며, 내장된 호환성 레이어를 활용하여 Linux ELF 바이너리 프로그램을 실행합니다. 시스템의 주요 코드는 페인이 C 언어와 x86-64 어셈블리어로 작성할 예정이며, 처음부터 다시 작성할 필요가 없는 부분에는 검증된 성숙한 오픈소스 라이브러리를 적절히 사용할 것입니다.

개발 현황 및 출시 예정

현재 Impossible OS의 코드량은 1,443,321줄에 달하며, 실제 하드웨어에서 정식으로 사용되기까지는 시간이 더 필요합니다. 페인은 첫 번째 공개 알파 버전이 2028년 8월 8일에 출시될 예정이라고 밝혔습니다.

페인은 독립 개발자가 단기간에 기업의 완전한 엔지니어링 팀과 경쟁하기 어렵다는 점을 인정했지만, 이러한 어려움이 그의 도전을 포기하게 만들지는 않았습니다. 프로젝트 완료 시점에 대해서는 "다음 달부터 시간의 끝까지"라고 농담했습니다.

프로젝트 주소: https://github.com/rizonesoft/impossible-os

총평

데릭 페인이라는 한 개발자가 Windows 11 디자인을 참고하여 완전히 오픈소스 기반의 새로운 운영체제인 Impossible OS를 개발하고 있습니다. 이 운영체제는 Win32 소프트웨어와 Linux 바이너리를 모두 지원하는 것을 목표로 하며, 2028년 8월 8일에 첫 알파 버전 출시를 예정하고 있습니다. 독립 개발자의 도전적인 프로젝트로, 향후 개발 진행 상황이 주목됩니다.

项目概述与目标

  • Impossible OS：由南非开发者德里克·佩恩（Derrick Payne）独立开发的一款全新操作系统。
  • 定位：面向现代 x86-64 PC 平台，其设计灵感借鉴自 Windows 11。
  • 核心理念：该系统并非“又一个 Linux 发行版”，而是一套拥有自身底层架构的独立操作系统。

技术架构与兼容性

  • 系统组件：包含 Ring 0 内核、UEFI 引导程序和桌面图形界面等核心组件，而非简单的发行版集合。
  • Win32 支持：通过内核原生 API 实现对基于 Win32 API 开发的软件的支持。
  • Linux 兼容性：利用内置兼容层运行 Linux ELF 二进制程序。
  • 开发语言：系统主体代码主要由佩恩使用 C 语言和 x86-64 汇编编写，同时会采用成熟开源库处理非必要重写部分。

开发进度与发布时间线

  • 当前状态：Impossible OS 的代码量已达到 1,443,321 行。
  • 正式目标：系统仍需时日才能在真实硬件上投入使用。
  • 首个公开 Alpha 版本：计划于 2028 年 8 月 8 日发布。

总结

德里克·佩恩独立开发了 Impossible OS，这是一款面向 x86-64 PC 的新系统，目标是实现对 Win32 API 和 Linux 二进制程序的双重兼容性。尽管其技术难度极高，但该项目已达到百万行代码规模，并设定了 2028 年 8 月的 Alpha 版本发布时间。

序論

オペレーティングシステムをゼロから開発することは、熟練したエンジニアリングチームにとっても容易ではない作業ですが、南アフリカ共和国の開発者であり起業家であるデレク・ペイン（Derek Payne）は、このタスクを単独で実行することを決めました。

現地時間20日、外信TechSpotによると、ペインが最新のx86-64 PC向けの新しいOS「Impossible OS」を発表したとのことです。このOSはWindows 11のデザインを参照しつつ、完全にオープンソースコードに基づいて開発されています。

Impossible OSの目標

プロジェクトの公式声明によれば、Impossible OSの目標は、Win32 APIベースのソフトウェアをネイティブで実行できると同時に、Linuxバイナリプログラムとの互換性を持つことです。

ペイン氏は、Impossible OSが単なる「別のLinuxディストリビューション」ではなく、Ring 0カーネル、UEFIブートローダー、デスクトップグラフィックインターフェースなど、コアコンポーネントを含む独自のサブアーキテクチャを持つ独立したOSであることを強調しています。

互換性と開発言語

互換性の面では、Impossible OSはカーネルネイティブAPIを通じてWin32ソフトウェアをサポートし、組み込まれた互換性レイヤーを活用してLinux ELFバイナリプログラムを実行します。システムの主要なコードは、ペイン氏がC言語とx86-64アセンブリ言語で記述する予定であり、最初から書き直す必要のない部分は、検証された成熟したオープンソースライブラリを適切に利用するとのことです。

開発状況とリリース予定

現在、Impossible OSのコード量は1,443,321行に達しており、実際のハードウェアで正式に使用されるまでにはさらなる時間が必要です。ペイン氏は、最初の公開アルファバージョンが2028年8月8日にリリースされる予定だと発表しました。

ペイン氏は、独立開発者が短期間で企業の完全なエンジニアリングチームと競争することは難しいことを認めつつも、この困難さが自身の挑戦を諦めさせることはないと述べています。プロジェクトの完了時期については、「来月から時間の終わりまで」と冗談交じりに語っています。

まとめ

デレク・ペイン氏という一人の開発者が、Windows 11のデザインを参考にしつつ、完全にオープンソースに基づいた新しいOS「Impossible OS」を開発しています。このOSはWin32ソフトウェアとLinuxバイナリの両方をサポートすることを目指しており、最初のアルファバージョンが2028年8月8日にリリースされる予定です。独立した開発者による非常に野心的なプロジェクトであり、今後の進捗に注目が集まっています。

Introduction

Developing an operating system from scratch is a difficult task even for highly skilled engineering teams, but Derek Payne, a developer and entrepreneur based in South Africa, decided to undertake this challenge alone.

On the 20th (local time), foreign media TechSpot reported that Payne unveiled Impossible OS, a new operating system designed for modern x86-64 PCs. The OS draws design inspiration from Windows 11 and is built entirely on open-source code.

Goals of Impossible OS

According to the project's official declaration, the goal of Impossible OS is twofold: it must run Win32 API-based software natively while also maintaining compatibility with Linux binary programs.

Payne emphasized that Impossible OS is not merely "another Linux distribution." Instead, it is an independent operating system featuring its own sub-architecture, including a Ring 0 kernel, UEFI bootloader, and desktop graphical interface.

Compatibility and Development Language

In terms of compatibility, Impossible OS supports Win32 software through a kernel native API and utilizes an embedded compatibility layer to run Linux ELF binary programs. The core system code will be written by Payne in C language and x86-64 assembly. For components that do not require rewriting from scratch, the project plans to use mature, verified open-source libraries.

Development Status and Release Schedule

Currently, Impossible OS contains 1,443,321 lines of code, but more time is required before it can be officially used on real hardware. Payne announced that the first public alpha version is scheduled for release on August 8, 2028.

While acknowledging that an independent developer struggles to compete with a full corporate engineering team in a short period, this difficulty has not deterred him from his challenge. Regarding the project's completion date, he humorously stated: "From next month until the end of time."

Project repository: https://github.com/rizonesoft/impossible-os

Summary

Derek Payne is developing Impossible OS, a completely open-source operating system for x86-64 PCs that references the Windows 11 design. The OS aims to achieve dual compatibility by supporting both Win32 software and Linux binaries. This ambitious project by an independent developer has announced its first public alpha release date of August 8, 2028.
