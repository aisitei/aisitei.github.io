Apple 스마트 홈 허브 HomeView, HomeKit 보안 카메라로 활용 가능… 출시 시기는 미정

Apple HomeView, HomeKit 보안 카메라 기능 탑재

IT之家 11월 2일 보도에 따르면, IT 매체 Appleinsider는 어제 Apple의 첫 스마트 홈 허브인 HomeView가 HomeKit 보안 카메라로 사용되어 사용자 가정에 보안 기능을 제공할 수 있다고 보도했습니다.

정보 유출자 pdfu는 HomeView Software 27.2의 설정 현지화 파일에서 HomeView 화면에 있는 카메라가 집안 환경을 모니터링하는 데 사용될 수 있음을 발견했습니다. 이 기능이 활성화되면 가족 구성원은 카메라의 실시간 영상 또는 녹화된 영상을 볼 수 있습니다.

또한 HomeView는 다양한 카메라 모니터링 상태를 선택할 수 있으며, IT之家가 정리한 자세한 내용은 다음과 같습니다.

  • 끄기: HomeView는 움직임을 감지하거나 비디오를 녹화하지 않으며, 비디오 라이브 스트리밍도 제공하지 않습니다.
  • 활동 감지: 기기가 움직임을 감지하고 사용자에게 알림을 보내지만, 비디오를 녹화하지 않으며 카메라를 통한 비디오 라이브 스트리밍도 허용하지 않습니다.
  • 비디오 라이브 스트리밍: 가족 구성원은 카메라의 실시간 영상을 볼 수 있지만, 녹화는 진행되지 않습니다.
  • 비디오 라이브 스트리밍 및 녹화 허용: 비디오 라이브 스트리밍과 자동 녹화 기능이 동시에 활성화됩니다. 가족 구성원은 언제든지 실시간 화면을 시작하거나 녹화된 비디오를 볼 수 있습니다.

사용자는 자신의 상황에 따라 카메라의 켜짐/꺼짐 시간을 설정할 수도 있습니다. 예를 들어, 집에 사람이 있을 때는 카메라가 녹화를 중지하고, 외출 시에만 라이브 스트리밍 또는 녹화 기능을 켜도록 설정할 수 있습니다. 하지만 Apple은 현재 위 기능을 테스트 중이며, 즉시 출시될 가능성은 낮다는 점에 유의해야 합니다.

총평

Apple의 첫 스마트 홈 허브 HomeView는 HomeKit 보안 카메라 기능을 통합하여 가정 보안을 강화할 것으로 예상됩니다. 이 기기는 움직임 감지, 실시간 스트리밍, 녹화 등 다양한 모니터링 모드를 제공하며, 사용자 맞춤형 시간 설정도 가능합니다. 현재 이 기능은 테스트 단계에 있어 즉시 출시될 가능성은 낮습니다.

新品功能爆料：HomeView作为智能安全摄像头

据科技媒体 Appleinsider 报道，Apple 首款智能家庭中枢 HomeView 可具备充当 HomeKit 安全摄像头的能力，为用户家庭提供更全面的安全防护。

软件发现与技术细节

  • 爆料人士 pdfu 在 HomeView Software 27.2 的设置本地化文件中发现了相关功能。
  • 该功能允许通过 HomeView 屏幕上的摄像头监控家中的环境，并支持内部成员查看实时画面或录像。

HomeView 四种核心监控模式

用户可以根据需求选择四种不同的摄像头监控状态：

  • 关闭： HomeView 不会进行运动侦测、视频录制或提供视频直播。
  • 检测活动： 设备可检测到运动并向用户发送提醒，但不会进行视频录制，也不允许通过摄像头进行视频直播。
  • 视频直播： 家庭成员可以查看摄像头的实时画面，但不包含自动录像功能。
  • 视频直播并允许录像： 同时启用视频直播和自动录像功能，用户可随时观看实时画面或回顾已录制视频。

高级设置与使用场景

除了基础模式外，用户还可以进行时间管理设置，例如可以设定摄像头仅在家中有人时停止录像，而在家庭成员外出时才开启直播或录像功能。

产品发布状态提示

需要注意的是，Apple 目前仍在测试上述各项安全监控功能，因此短期内大规模推出的可能性较低。

总结

苹果通过 HomeView 智能家庭中枢整合了摄像头安全监控能力，支持从简单的活动侦测到实时的视频直播和录像回溯等多种模式。该功能极大地提升了HomeKit生态的安全性，但目前仍处于测试阶段，用户需关注后续官方发布消息。

Apple HomeViewにHomeKitセキュリティカメラ機能が搭載される

IT之家による11月2日の報道によると、テックメディアのAppleinsiderは、Apple初のスマートホームハブであるHomeViewが、HomeKitセキュリティカメラとして使用され、ユーザーの家庭に高度なセキュリティ機能を提供できると報じました。

情報リーカーのpdfu氏が公開した「HomeView Software 27.2」の設定ローカライズファイルから、HomeViewの画面上のカメラが家庭環境の監視に使用できることが発見されました。この機能が有効になると、家族構成員はカメラのリアルタイム映像または録画された映像を閲覧できるようになります。

また、HomeViewでは様々なカメラ監視の状態を選択することができ、IT之家がまとめた詳細は以下の通りです。

  • オフ： HomeViewは動きを検知したりビデオを録画したりすることはなく、ライブストリーミングも提供しません。
  • アクティビティ検出： デバイスの動きを検知しユーザーに通知を行いますが、ビデオの録画やカメラ経由でのライブストリーミングは許可されません。
  • ビデオライブストリーミング： 家族構成員がカメラのリアルタイム映像を視聴できますが、録画は行われません。
  • ビデオライブストリーミングおよび録画許可： ビデオライブストリーミングと自動録画機能が同時に有効になります。家族構成員はいつでもリアルタイム画面を開始したり、録画されたビデオを閲覧したりすることが可能です。

ユーザーは自身の状況に合わせてカメラのオン/オフ時間帯を設定することもできます。例えば、在宅時は録画を停止し、外出時のみライブストリーミングや録画機能を有効にするといった設定が可能です。ただし、Appleはこの機能が現在テスト段階にあり、すぐに市場に投入される可能性は低い点に留意が必要です。

まとめ

Apple初のスマートホームハブHomeViewは、HomeKitセキュリティカメラの機能を統合することで家庭の安全性を高めることが期待されます。本デバイスは、動き検知、リアルタイムストリーミング、録画といった多様な監視モードを提供し、ユーザーによる時間帯ごとのカスタマイズも可能です。なお、この機能は現在テスト段階にあるため、市場への即時展開は見込めません。

HomeView to Integrate HomeKit Security Camera Features

According to a report from IT Zhome on November 2nd, the tech media outlet AppleInsider reported that Apple's first smart home hub, HomeView, can function as a HomeKit security camera, thereby providing enhanced security features for users' homes.

Leaker pdfu discovered in the localization files for HomeView Software 27.2 that the camera on the HomeView screen can be utilized to monitor the indoor environment. When this feature is activated, family members will have the ability to view either real-time or recorded video from the camera.

Furthermore, HomeView supports selecting various camera monitoring states. The detailed modes are as follows:

  • Off: HomeView does not detect movement, record videos, or provide live video streaming.
  • Activity Detection: The device detects movement and sends alerts to the user, but it does not record video nor allow video live streaming through the camera.
  • Video Live Streaming: Family members can view the camera's real-time feed, but no recording takes place.
  • Live Streaming and Recording Enabled: Both live video streaming and automatic recording functions are simultaneously activated. Family members can start viewing the live screen or review recorded videos at any time.

Users can also set specific on/off times for the camera based on their situation. For instance, they could configure the camera to stop recording when people are present at home and only enable live streaming or recording when the house is empty. However, it should be noted that Apple is currently testing this functionality, making an immediate release unlikely.

Summary

Apple's first smart home hub, HomeView, is expected to enhance home security by integrating HomeKit security camera capabilities. The device offers multiple monitoring modes—including movement detection, real-time streaming, and recording—along with customizable scheduling options for users. Currently, this feature is in the testing phase, suggesting that an immediate public release is unlikely.
