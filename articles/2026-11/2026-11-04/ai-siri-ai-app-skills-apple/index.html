Siri AI, 앱 간 작업 수행: Apple, "앱 스킬" 개방으로 한 문장으로 여러 앱 작업 연결

2026-11-04

Siri AI의 새로운 '앱 스킬'

IT之家 11월 4일 소식에 따르면, IT 매체 9to5Mac은 오늘(11월 4일) 블로그 게시물을 통해 Apple이 타사 개발자에게 Siri AI의 새로운 '앱 스킬(App Skills)'을 개방하여 앱이 Siri에게 더 복잡한 다단계 작업을 지시할 수 있도록 했다고 보도했습니다. 관련 기능은 iOS 27.3, macOS 27.3 및 동시 시스템 업데이트와 함께 출시될 예정이며, 현재 새 시스템 버전은 개발자 테스트 단계에 있습니다.

이 매체는 이번 Siri 업그레이드가 주로 앱 조정 능력을 확장한다고 지적했습니다. Siri는 사용자가 무엇을 원하는지 이해할 뿐만 아니라, 앱이 제공하는 스킬에 따라 해당 앱 작업을 호출하고 연결하여 실행할 수 있습니다. 초기에는 제한된 사전 설정 모드만 지원했던 Siri AI와 비교하여, 새로운 메커니즘은 타사 앱의 접근 범위를 더욱 확대하고 복잡한 요청에 대한 더 명확한 실행 경로를 제공합니다.

보도에 따르면 개발자 문서를 인용하여, 사용자는 Siri에게 "특정 채팅 앱을 통해 내가 즐겨찾는 운동화를 파트너에게 보내줘"라고 요청할 수 있습니다. Siri는 즐겨찾기 내용을 찾고, 파트너를 식별하고, 연락처에서 상대방을 찾아 지정된 앱을 통해 운동화 정보를 전송하여, 원래 여러 앱을 전환해야 했던 작업을 연결하여 완료합니다.

또 다른 변화는 일부 상황에서 사용자가 더 이상 앱 이름을 명확하게 말할 필요가 없다는 것입니다. 예를 들어, 차량 호출 앱의 '실시간 활동'이 실행 중일 때 사용자가 "탑승 주소 변경"을 요청하면, Siri는 현재 상황을 결합하여 요청이 어떤 앱에 해당하는지 판단할 수 있습니다. IT之家는 관련 스크린샷을 첨부했습니다.

이 매체는 Siri가 단일 명령에 응답하는 것에서 벗어나 Apple 및 타사 앱과 협력하여 연속적인 작업을 완료하는 방향으로 나아가고 있다고 해석했습니다. 그러나 위에서 언급한 기능은 아직 모든 사용자에게 공식적으로 출시되지 않았으며, 실제 적용 범위와 경험은 향후 버전 및 앱 통합 상황을 기다려야 검증될 것입니다.

총평

Apple은 Siri AI의 '앱 스킬'을 타사 개발자에게 개방하여, Siri가 여러 앱을 연동하여 복잡한 다단계 작업을 수행할 수 있도록 기능을 확장합니다. 이 기능은 iOS 27.3 및 macOS 27.3 업데이트와 함께 제공될 예정이며, 사용자는 앱 이름을 명시하지 않고도 상황에 맞는 명령을 내릴 수 있게 됩니다. 이는 Siri가 단일 명령 처리에서 벗어나 연속적인 작업을 조율하는 방향으로 진화하고 있음을 보여줍니다.

Siri AI核心升级：开放应用技能

  • Apple宣布向第三方开发者开放全新的“应用技能”（App Skills），允许应用程序指导Siri执行更复杂、多步骤的任务。
  • 此次升级旨在扩展Siri的应用协调能力，使Siri不仅能理解用户意图，还能调用和串联多个应用的相应操作。

系统版本与功能定位

  • 相关功能将随iOS 27.3和macOS 27.3等同期系统更新推出。
  • 目前新版系统仍处于开发者测试阶段，尚未正式面向所有用户发布。
  • 本次升级的核心目标是让Siri从响应单项指令，迈向协调Apple及第三方应用完成连续任务。

增强的应用协同与使用场景

  • **复杂任务串联：** 用户可以发出如“通过某款聊天应用，把我收藏的运动鞋发给我的伴侣”等请求。Siri将自动执行查找内容、识别联系人、并通过指定应用发送信息等一系列操作。
  • **情境感知能力提升：** 在部分场景下，用户无需明确说出应用名称。例如，当网约车应用的“实时活动”正在运行时，用户只需提出“更改乘车地址”，Siri即可结合当前情境判断请求对应哪款应用。

总结

Apple通过开放“应用技能”功能对Siri AI进行重大升级，使其具备了跨应用的复杂任务协调能力。该功能预计随iOS 27.3和macOS 27.3推出，允许用户通过单一指令完成原本需要切换多个应用的连续操作。虽然目前仍处于测试阶段，但这一变化标志着Siri正向更智能、更具情境感知力的自动化助手方向发展。

Siri AIの新たな「App Skills」機能

IT之家が11月4日のニュースで報じたところによると、ITメディア9to5Macは同日（11月4日）、Appleがサードパーティの開発者向けにSiri AIの新しい「App Skills」（アプリスキル）を開放したと報道しました。これにより、アプリケーションがSiriに対してより複雑な多段階のタスクを指示できるようになります。

この関連機能は、iOS 27.3およびmacOS 27.3といったシステムアップデートとともにリリースされる予定で、現在、新しいシステムバージョンは開発者テスト段階にあります。

アプリ連携能力の大幅な拡張

同メディアは、今回のSiriのアップグレードが主に「アプリ間の調整能力」を拡張するものだと指摘しています。Siriは単にユーザーが何を望んでいるかを理解するだけでなく、各アプリが提供するスキルを呼び出し、それらを組み合わせて実行することが可能になります。

初期には限定的な事前設定モードしかサポートしていなかったSiri AIと比較して、この新しいメカニズムはサードパーティ製アプリへのアクセス範囲を大幅に拡大し、複雑なリクエストに対するより明確な実行パスを提供します。

具体的な利用シナリオ

開発者ドキュメントを引用した報道によると、ユーザーはSiriに対して「特定のチャットアプリを通じて、お気に入りのスニーカーをパートナーに送って」といった指示を出すことができます。この場合、Siriは以下のプロセスを自動で実行し、複数のアプリを切り替える必要があった作業を一連の流れとして完了させます。

  • お気に入り（商品情報）の検索
  • パートナーの特定と連絡先からの照合
  • 指定されたアプリを通じたスニーカー情報の送信

また、別の変化として、特定の状況下ではユーザーがアプリ名を明確に言う必要がなくなる点も挙げられます。例えば、配車アプリの「ライブアクティビティ」が実行されている状態で、「乗車場所を変更して」と依頼した場合、Siriは現在の状況を組み合わせて、どのアプリに関連するリクエストかを判断することができます。

同メディアは、Siriが単一のコマンドに応答する段階から脱却し、Appleおよびサードパーティ製アプリと協働して連続的なタスクを完了させる方向へと進化していると分析しています。ただし、上記機能はまだすべてのユーザーに正式リリースされているわけではなく、実際の適用範囲や体験については今後のバージョンアップやアプリ統合状況を待って検証される必要があります。

まとめ

AppleはSiri AIの「App Skills」機能をサードパーティ開発者に開放することで、Siriが複数のアプリを連携させ、複雑な多段階タスクを実行できる能力を拡張しました。この機能はiOS 27.3およびmacOS 27.3アップデートで提供され、ユーザーはアプリ名を明示することなく状況に応じた指示が可能になります。これは、Siriが単なるコマンド処理から脱却し、連続的な作業を調整する方向に進化していることを示すものです。

Siri AI's New 'App Skills'

According to reports from IT之家 on November 4th, the tech media outlet 9to5Mac published a blog post today detailing that Apple has opened its new "App Skills" for third-party developers. This feature allows apps to issue more complex, multi-step commands to Siri.

The related functionality is scheduled to launch with iOS 27.3 and macOS 27.3 system updates, alongside the corresponding operating system update. Currently, this new system version is in the developer testing phase.

Enhanced App Orchestration

The report highlights that this Siri upgrade primarily expands app orchestration capabilities. Instead of merely understanding what a user wants, Siri can now call and connect specific skills provided by an app to execute complex tasks. Compared to previous versions of Siri AI, which initially supported only limited pre-set modes, the new mechanism significantly broadens third-party app accessibility and provides clearer execution paths for intricate requests.

The report cited developer documentation, providing examples such as a user requesting: "Send my favorite sneakers to my partner through a specific chat application." Siri would then connect multiple apps—finding the favorite items, identifying the partner, locating them in contacts, and transmitting the sneaker information via the designated app—completing a task that previously required manual switching between several different applications.

Another notable change is that users may no longer need to explicitly name an application in certain contexts. For instance, if 'Live Activity' for a ride-hailing service is running, and the user requests "Change pickup address," Siri can combine the current context to determine which app the request pertains to.

The media outlet interpreted this shift as Siri moving beyond responding to single commands toward completing continuous tasks by collaborating with both Apple and third-party applications. However, it was noted that these features have not been officially rolled out to all users yet, and their actual scope and user experience will need validation in future versions and app integrations.

Summary

Apple is expanding Siri AI's functionality by opening "App Skills" to third-party developers. This allows Siri to execute complex, multi-step tasks by orchestrating multiple apps together. The feature is slated for release with iOS 27.3 and macOS 27.3 updates, enabling users to issue context-aware commands without needing to specify the app name, marking a major evolution from single command processing to continuous task management.
