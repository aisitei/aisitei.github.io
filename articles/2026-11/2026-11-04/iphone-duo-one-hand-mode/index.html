외부 스크린이 너무 넓어 닿지 않나요? Apple iOS 27.3 베타 버전, iPhone Duo 한 손 조작 경험 개선

2026-11-04

접근성 기능 도입

IT매체 MacRumors는 오늘(11월 4일) Apple이 첫 폴더블 iPhone Duo의 iOS 27.3 첫 번째 개발자 베타 버전에서 '편리한 접근'(Reachability) 기능을 도입했다고 보도했습니다. 사용자는 화면을 가로로 스와이프하여 화면 콘텐츠를 왼쪽 또는 오른쪽으로 이동시킬 수 있으며, 이를 통해 엄지손가락으로 닿기 어려운 인터페이스 영역을 가까이 가져와 한 손 조작 경험을 개선할 수 있습니다.

해당 매체는 iPhone Duo가 10월 23일 출시된 후 일부 리뷰어들이 초광각 외부 화면이 한 손 사용을 어렵게 한다고 지적했다고 언급했습니다. Apple은 이후 소프트웨어 업데이트를 통해 편리한 접근 기능을 도입하겠다고 밝혔으며, 이 약속이 현재 베타 버전에서 실현되었습니다.

다른 iPhone 모델들이 화면 상단에 손이 닿기 쉽도록 인터페이스를 아래로 이동시키는 것과 달리, iPhone Duo의 편리한 접근 기능은 화면을 가로로 이동시키는 방식을 채택했습니다. 사용자는 '설정 → 손쉬운 사용 → 편리한 접근'에서 이 기능을 활성화한 후, 화면 측면을 짧게 스와이프하면 인터페이스가 왼쪽 또는 오른쪽으로 이동합니다.

이 기능은 현재 iOS 27.3 개발자 베타 버전에서만 제공되며, 아직 모든 사용자에게 공식적으로 배포되지는 않았습니다. 보도에 따르면 공개 베타 버전은 며칠 내에 출시될 예정이며, 정식 버전은 12월에 발표될 계획입니다.

총평

Apple은 iPhone Duo의 넓은 외부 화면으로 인한 한 손 조작의 어려움을 해결하기 위해 iOS 27.3 베타 버전에서 '편리한 접근' 기능을 도입했습니다. 이 기능은 화면 콘텐츠를 가로로 이동시켜 사용자가 엄지손가락으로 쉽게 접근할 수 있도록 돕습니다. 현재 개발자 베타 버전으로 제공되며, 12월 정식 출시가 예정되어 있습니다.

操作系统与新品功能更新

科技媒体 MacRumors 报道，在 iOS 27.3 首个 Beta 开发者预览版中，Apple 为其首款折叠 iPhone Duo 引入了重要的辅助功能——“便捷访问”（Reachability）。

核心功能：便捷访问（Reachability）

  • **功能目的：** 通过横向滑动屏幕内容，将原本难以触及的界面区域移动到靠近拇指的位置，从而显著改善用户的单手操作体验。
  • **背景需求：** 此功能旨在解决 iPhone Duo 发售后部分评测者反映的超宽外屏设计增加了单手使用的难度的问题。

使用机制与设置

与其他 iPhone 通过下移界面来方便用户触及屏幕上方不同区域的方式不同，iPhone Duo 的便捷访问采用了横向移动方案。

  • **开启路径：** 用户需在“设置 → 辅助功能 → 便捷访问”中进行开启。
  • **操作方式：** 激活后，用户只需对屏幕侧边进行短促滑动，即可让整个界面向左或向右移动。

版本发布与兼容性

  • **当前状态：** 该功能目前仅随 iOS 27.3 开发者测试版提供，尚未面向所有用户正式推送。
  • **后续计划：** 报道预计公开测试版将在未来几天推出；而完整的正式版则计划于 12 月份发布。

总结

Apple 在 iOS 27.3 Beta 版本中为 iPhone Duo 引入了“便捷访问”功能，通过横向移屏的方式解决了超宽外屏在单手操作上的可用性问题。该功能允许用户通过侧边滑动将屏幕内容移动至易触及区域，极大地提升了设备的辅助体验。目前此功能仅限开发者测试版，预计将在未来数周内逐步推送给更多用户。

アクセシビリティ機能の導入

ITメディアのMacRumorsは、Appleが初のフォルダブルiPhone DuoのiOS 27.3開発者ベータ版において、「リーチアビリティ（Reachability）」というアクセシビリティ機能を搭載したと報じました。この機能を使用すると、画面を左右にスワイプすることでコンテンツ全体を移動させることができ、親指だけで届きにくいインターフェース領域を近づけることで、片手操作の体験が向上します。

MacRumorsによると、iPhone Duoは10月23日に発売された後、一部のリビューワーから超広角の外画面が片手での使用を難しくしているという指摘がありました。これを受け、Appleはソフトウェアアップデートでリーチアビリティ機能の導入を発表し、この約束が現在のベータ版で実現されました。

他のiPhoneモデルがインターフェースを画面上部から下に移動させる方式を採用しているのに対し、iPhone Duoのリーチアビリティ機能は画面全体を左右に移動させる方法を採用しています。ユーザーはこの機能を「設定」→「アクセシビリティ」→「リーチアビリティ」で有効化し、画面側面を短くスワイプすることで、インターフェースが左または右に移動します。

この機能は現在iOS 27.3開発者ベータ版でのみ提供されており、まだすべてのユーザーに正式に配布されているわけではありません。報道によれば、パブリックベータ版は数日中にリリースされる予定で、正式バージョンは12月に発表される計画です。

まとめ

Appleは、iPhone Duoの広い外部画面による片手操作の困難さを解消するため、iOS 27.3ベータ版に「リーチアビリティ」機能を導入しました。この機能は、画面コンテンツを左右に移動させることで、ユーザーが親指だけで容易にアクセスできるように支援します。現在開発者ベータ版で提供されており、正式バージョンは12月にリリースされる予定です。

Introducing Accessibility Feature

IT media outlet MacRumors reported on November 4th that Apple has introduced a 'Reachability' feature in the first developer beta version of iOS 27.3 for the foldable iPhone Duo. Users can now swipe across the screen horizontally to move content either left or right, bringing interface areas that are difficult to reach with thumbs closer, thereby improving the one-handed operation experience.

The outlet mentioned that after the launch of the iPhone Duo on October 23rd, some reviewers pointed out that the ultra-wide external display made single-handed use challenging. Apple subsequently announced it would introduce a Reachability feature through a software update, and this promise has now been realized in the current beta version.

Unlike other iPhone models that move the interface down to make it easier to reach from the top of the screen, the iPhone Duo's Reachability feature adopts a horizontal swiping method. Users can activate this function in 'Settings → Accessibility → Reachability,' and then swipe briefly across the side of the screen to shift the interface left or right.

This feature is currently only available in the iOS 27.3 developer beta version and has not yet been officially rolled out to all users. According to reports, a public beta version is expected within days, with the official release planned for December.

Summary

Apple introduced the 'Reachability' accessibility feature in the iOS 27.3 developer beta to address the difficulty of one-handed operation caused by the wide external screen on the iPhone Duo. This function allows users to horizontally swipe the screen content, bringing difficult-to-reach interface elements closer for easier thumb access. While currently limited to the developer beta, it is scheduled for official release in December.
