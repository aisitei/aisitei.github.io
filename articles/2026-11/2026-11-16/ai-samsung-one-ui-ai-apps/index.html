Samsung One UI 9.5, 시스템 레벨 AI 에이전트 도입

IT之家 11월 15일 소식에 따르면, 어제 IT 매체 Sammobile은 Samsung One UI 9.5 시스템이 고급 Galaxy 스마트폰과 태블릿에 시스템 레벨 AI 에이전트를 도입하여 Galaxy AI의 기능을 더욱 확장할 것이라고 보도했습니다.

IT之家는 원본 보도를 통해 Samsung이 AI 비서를 시스템 내장 앱과 깊이 통합하는 것을 목표로 하는 Personal Agent Core 기능을 설계 중임을 확인했습니다. 기존 음성 비서와 달리, 이 기능은 자연어 대화를 통해 여러 단계의 작업 흐름을 관리하고, 능동적으로 후속 서비스를 제공할 수 있습니다.

예를 들어, 이 기능은 이메일, 택배 배송, 예약 정보를 하나의 중앙 인터페이스에 통합하여 사용자에게 통일된 일일 정보 개요를 제공할 수 있으며, 이는 Now Brief 기능의 자연스러운 확장처럼 보입니다. 사용자는 단순히 일정을 확인하는 것을 넘어, 비서에게 캘린더를 확인하고, 연락처에 만남을 주선하고, 상대방의 답변을 추적하며, 계획이 확정되면 관련 일정을 캘린더 앱에 자동으로 추가하도록 할 수 있습니다.

이 기능은 또한 Google 및 One UI 앱을 결합하여 중요한 정보를 추출할 수 있습니다. 연락처, 이메일, 메시지 및 녹음된 통화 내용을 통합하여 과거 대화에서 회의 약속 및 할 일 목록을 식별합니다.

또한, 사용자는 자연어를 통해 기기 설정 조정, 미디어 재생 제어, 메모 관리, 이메일 및 메시지 전송, 알람 및 알림 설정 등을 할 수 있습니다. 이 AI 시스템은 통화 녹음, 강의 및 회의 녹음을 명확한 텍스트 기록으로 변환하고 실행 가능한 요약을 생성할 수 있습니다.

총평

Samsung One UI 9.5는 고급 Galaxy 기기에 시스템 레벨 AI 에이전트인 Personal Agent Core를 도입하여 Galaxy AI 기능을 대폭 강화할 예정입니다. 이 AI 에이전트는 자연어 대화를 통해 복잡한 작업을 관리하고, 이메일, 택배, 예약 정보 등을 통합하여 사용자에게 맞춤형 정보를 제공합니다. 또한, Google 및 One UI 앱과 연동하여 중요한 정보를 추출하고, 통화 및 회의 녹음을 텍스트로 변환하고 요약하는 등 다양한 편의 기능을 제공할 것으로 기대됩니다.

系统升级与核心概念

据报道，Samsung One UI 9.5 系统将为高端 Galaxy 手机和平板电脑带来系统级的 AI 智能体功能，旨在进一步拓展 Galaxy AI 的能力。

  • 新功能名称： Personal Agent Core 功能。
  • 核心定位： 将 AI 助手与系统自带应用进行深度整合，超越传统语音助手的限制。

多步骤工作流管理

该智能体能够通过自然语言对话来管理复杂的、多步骤的工作流程，并具备主动提供后续跟进服务的能力。

  • 信息中心化： 可将电子邮件、快递配送状态和预订信息整合在一个统一的界面。
  • 日程自动化： 用户无需手动查看日历，可让助手检查日历、向联系人安排会面，并跟踪对方的回复；一旦计划确认，系统会自动将其添加到日历应用中。

跨应用数据提取与聚合

Personal Agent Core 能够结合 Google 和 One UI 的多项应用，从用户过往的对话记录和日常数据中自动识别关键信息。

  • 数据来源整合： 整合了联系人、电子邮件、消息以及录音通话内容。
  • 智能提取目标： 从历史对话中主动识别会议约定（Meeting Agreements）和待办事项（To-dos）。

设备控制与日常任务执行

用户可以通过自然语言指令，实现对设备的全面控制和各种日常提醒的设置。

  • 系统操作： 调整设备设置、管理笔记。
  • 通讯与媒体： 发送电子邮件和消息；控制媒体播放；设置闹钟和提醒。

语音内容处理与总结

该 AI 系统具备强大的音频处理能力，能够将复杂的录音材料转化为可执行的文字记录。

  • 转换范围： 适用于通话录音、讲座以及会议录音。
  • 输出结果： 将语音内容转换为清晰的文本记录（Transcript），并自动生成可供用户参考和执行的摘要。

总结

Samsung One UI 9.5 的 Personal Agent Core 代表了 AI 助手从简单的指令执行器向系统级智能体演进的关键一步。它通过深度整合日历、邮件、通话记录等多个数据源，实现了复杂工作流的自动化管理和主动跟进服务。这一升级旨在提供一个高度集成的个人信息中心，极大地提升用户在日常任务处理上的效率。

Samsung One UI 9.5、システムレベルAIエージェントを導入

IT之家が11月15日のニュースで報じたところによると、ITメディアSammobileは、SamsungのOne UI 9.5システムが高度なGalaxyスマートフォンおよびタブレットに「システムレベルAIエージェント」を搭載し、Galaxy AIの機能をさらに拡張すると報じました。

IT之家による元の報道では、SamsungがAIアシスタントをOS内蔵アプリと深く統合することを目指した「Personal Agent Core」という機能群を設計中であることが確認されています。この機能は従来の音声アシスタントとは異なり、自然言語の対話を通じて複数のステップにわたるワークフローを管理し、能動的に後続サービスを提供することが可能です。

例えば、この機能はメール、宅配便の配送情報、予約情報を単一の中央インターフェースに統合し、ユーザーに対して統一された日々の情報概要を提供できます。これは「Now Brief」機能の自然な拡張と見られます。ユーザーは単にスケジュールを確認するだけでなく、エージェントに対し以下のタスクを実行させることが可能です。

  • カレンダーの確認
  • 連絡先を使った面会の手配
  • 相手からの返信状況の追跡
  • 計画が確定した場合、関連予定を自動的にカレンダーアプリに追加させること

さらに、このエージェントはGoogleおよびOne UIの各種アプリと連携し、重要な情報を抽出することができます。連絡先、メール、メッセージ、録音された通話内容などを統合することで、過去の会話から会議のアポイントメントやToDoリストを自動で識別します。

また、ユーザーは自然言語を用いて、以下のような多様な操作を行うことができます。

  • デバイス設定の調整
  • メディア再生の制御
  • メモの管理
  • メールやメッセージの送信
  • アラームや通知の設定

このAIシステムは、通話録音や講義・会議の録音を明確なテキスト記録に変換し、実行可能な要約（アクションアイテム）を生成することも可能です。

まとめ

Samsung One UI 9.5では、高度なGalaxyデバイス向けに「Personal Agent Core」というシステムレベルAIエージェントが導入され、Galaxy AIの機能が大幅に強化されます。このエージェントは自然言語対話を通じて複雑なタスクを管理し、メールや予約情報などの多様なサービスを統合してユーザーにパーソナライズされた情報を提供します。さらに、GoogleおよびOne UIアプリとの連携による重要情報の抽出や、通話・会議録音のテキスト化と要約機能など、幅広い利便性が期待されています。

Samsung One UI 9.5 to Introduce System-Level AI Agent

According to news from IT之家 on November 15, the IT media outlet Sammobile reported that Samsung's One UI 9.5 system will expand Galaxy AI functionality by introducing a system-level AI agent to advanced Galaxy smartphones and tablets.

IT之家 confirmed through its original report that Samsung is developing a feature called Personal Agent Core, which aims to deeply integrate an AI assistant into the system. Unlike existing voice assistants, this function can manage multi-step workflows and proactively provide follow-up services through natural language conversation.

For example, the feature could consolidate email, parcel delivery, and reservation information into a single central interface, providing users with a unified daily information overview—a natural extension of the Now Brief functionality. Users would be able to go beyond simply checking schedules; they could instruct the assistant to check calendars, arrange meetings in contacts, track responses from counterparts, and automatically add confirmed plans to the calendar app.

This feature can also extract critical information by combining Google and One UI apps. It integrates data from contacts, emails, messages, and recorded calls to identify meeting appointments and to-do lists from past conversations.

Furthermore, users will be able to perform actions using natural language, such as adjusting device settings, controlling media playback, managing notes, sending emails and messages, and setting alarms and notifications. This AI system can convert call recordings, lectures, and meeting recordings into clear text transcripts and generate actionable summaries.

Summary

Samsung One UI 9.5 is set to significantly enhance Galaxy AI by introducing Personal Agent Core, a system-level AI agent for advanced Galaxy devices. This AI agent manages complex tasks via natural language conversation and provides personalized information by integrating data from emails, deliveries, and reservations. It is expected to offer various conveniences, including extracting key details by linking Google and One UI apps, and converting/summarizing call and meeting recordings into actionable text.
