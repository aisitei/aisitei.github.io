Samsung, Galaxy S26 등 스마트폰에 Apple식 '프라이빗 클라우드' 도입 위해 SPAC 프레임워크 구상 중

2026-11-28

Samsung의 새로운 클라우드 AI 프레임워크, SPAC

IT매체 Android Authority는 One UI 9.5의 첫 번째 베타 테스트 버전 코드를 분석하여 Apple의 'Private Cloud Compute(PCC)'와 유사한 설계 철학을 가진 'SPAC'이라는 새로운 프레임워크를 발견했습니다.

Apple의 PCC는 Apple Intelligence를 위한 클라우드 기반 AI 개인 정보 보호 아키텍처입니다. iPhone이 로컬에서 처리하기 어려운 복잡한 작업을 수행할 때 Apple은 전용 서버에서 요청을 처리하여 개인 데이터 획득 및 보존 기회를 기술적으로 최소화하고 사용자가 더 강력한 클라우드 AI를 사용할 수 있도록 합니다.

Galaxy AI의 경우, Samsung은 현재 클라우드 처리에 대해 주로 정책적인 약속을 하고 있습니다. 예를 들어, 사진 편집기는 이미지가 "서버로 전송되어 처리되지만 Samsung에 저장되지 않는다"고 명시합니다. SPAC 프레임워크는 이러한 모순을 해결할 것으로 기대됩니다.

SPAC의 작동 방식 및 개인 정보 보호

코드 분석에 따르면, SPAC은 Arcane이라는 서버 측 게이트웨이를 통해 토큰, 인증 및 사기 탐지 서비스와 함께 익명화된 클라우드 Galaxy AI 요청을 처리하는 것으로 보입니다. 사용자 요청은 여전히 클라우드 서버로 전송되지만, 요청 내용은 익명화되고 암호화되며, Samsung이 요청을 특정 사용자 신원과 연결하기 어렵게 만듭니다.

개인 정보 보호 측면에서 코드 세부 사항을 보면, SPAC은 여러 메커니즘을 통해 사용자 개인 정보를 보호할 것입니다. 제한된 사용자 요청은 먼저 타사 중계를 통해 전달되며, Samsung은 요청 내용을 처리할 수 있지만 요청 출처를 알기 어렵습니다.

휴대폰은 데이터를 전송하기 전에 Samsung 서버가 변조되지 않은 공식 소프트웨어를 실행하고 있는지 확인합니다. 관련 서버 소프트웨어는 특정 사용자를 대상으로 프로그램을 교체하는 것을 방지하기 위해 은밀하게 변경하기 어려운 공개 기록에 기록될 수 있습니다. 또한, 휴대폰은 사용자가 실제 Galaxy 사용자임을 증명하면서도 구체적인 신원을 노출하지 않는 일회성 패스를 받을 것으로 보입니다.

지원 AI 모델 및 기능

코드는 또한 SPAC이 여러 AI 모델에 연결될 수 있음을 보여줍니다.

  • Google의 Gemma 4
  • Alibaba의 Qwen 3.6
  • Black Forest Labs의 FLUX.2 klein 4B
  • Stable Diffusion 모델

사진 편집기 코드에는 OpenAI의 텍스트-음성 변환 모델, Samsung 자체 개발 Gauss, Meta의 V-JEPA도 나타났지만, 현재 이러한 모델이 실제로 사용되고 있는지는 확인할 수 없습니다.

기능적인 측면에서 SPAC은 미래에 상당히 광범위한 Galaxy AI 시나리오를 포괄할 수 있습니다.

  • AI 선택
  • 클라우드 사진 복구 및 확대
  • 실시간 음성 번역
  • 요약
  • 어조 조정
  • 이모티콘 제안
  • 작문 보조
  • Now Brief
  • "Bixby work"라는 기능 등

이러한 기능들이 점차 SPAC으로 이전된다면, Galaxy AI의 클라우드 기능은 기능 강도를 유지하면서 더 강력한 개인 정보 보호를 얻을 수 있을 것으로 기대됩니다.

현재 상태

그러나 이 기능은 현재 Galaxy S26 Ultra에서 실제로 활성화되지 않았습니다. 테스터들이 작문 보조, AI 선택, 노트 보조, Now Brief 및 동시 통역과 같은 기능을 사용했을 때 SPAC이 호출되는 것을 발견하지 못했습니다. 기존 기능은 여전히 Samsung의 기존 클라우드 서비스 또는 로컬 처리를 사용합니다.

총평

Samsung은 Apple의 PCC와 유사한 클라우드 AI 프레임워크인 SPAC을 개발 중입니다. SPAC은 사용자 요청을 익명화하고 암호화하여 개인 정보 보호를 강화하며, 다양한 AI 모델을 통합하여 Galaxy AI 기능을 확장할 것으로 예상됩니다. 현재는 개발 단계에 있으며, Galaxy S26 Ultra에서는 아직 활성화되지 않았습니다.

核心技术框架：SPAC与云端AI架构

科技媒体 Android Authority 通过分析 One UI 9.5 首个 Beta 测试版代码，发现了一个名为 SPAC 的全新框架。该框架旨在为 Galaxy AI 提供更强的云端处理能力，其设计思路与 Apple 的“私有云计算”（PCC）高度相似。

  • SPAC目的：解决 Samsung 目前在云端处理承诺上（如照片编辑器说明数据将发送到服务器但不会存储）存在的政策和技术矛盾。
  • 功能定位：允许用户请求发送至云端服务器进行匿名化、加密处理，从而增强 Galaxy AI 的云端能力同时保障隐私。

先进的隐私保护机制

SPAC 框架在代码细节中展示了多重机制来保护用户数据和身份信息，确保数据传输过程中的安全性。

  • 匿名化处理：请求内容会被加密并进行匿名化处理，使 Samsung 难以将请求与具体用户身份关联起来。
  • 第三方中继转发：受限的用户请求会先经由第三方进行转发，即使 Samsung 能处理请求内容，也难以获知请求的原始来源。
  • 设备和软件验证：手机在发送数据前，需验证 Samsung 服务器是否运行未经篡改的官方软件；同时，用户将获得一次性通行证来证明其是真实的 Galaxy 用户，但不会暴露具体身份。

技术架构与模型接入

该框架依赖特定的服务器网关和多种AI模型进行处理。

  • 核心组件：通过名为 Arcane 的服务器端网关，配合 token、身份验证和欺诈检测等服务来处理云端请求。
  • 支持的模型生态：SPAC 预计可以接入多个主流 AI 模型，包括：
    • 谷歌的 Gemma 4
    • 阿里巴巴的 Qwen 3.6
    • Black Forest Labs 的 FLUX.2 klein 4B 和 Stable Diffusion 模型
  • 其他潜在模型：照片编辑器代码中还出现了 OpenAI 的文本转语音模型、Samsung 自研的 Gauss，以及 Meta 的 V-JEPA。

广阔的应用场景覆盖

SPAC 框架未来有望支持 Galaxy AI 非常广泛的功能，提升用户体验的同时增强隐私保护。

  • 核心功能：包括AI选择、云端照片修复与放大、实时语音翻译、摘要生成、语气调整、表情符号建议、写作辅助、Now Brief 等。
  • 新增能力：还可能支持“Bixby work”等新功能，实现更全面的云端 AI 赋能。

当前状态与局限性

尽管功能强大，但该框架目前尚未在实际设备上全面启用。

  • 测试现状：目前尚无法确认 SPAC 是否已被用于所有模型；测试人员在使用写作助手、AI 选择、笔记助手和同声传译等功能时，均未发现 SPAC 被调用。
  • 适用机型限制：该功能尚未在 Galaxy S26 Ultra 上实际启用，现有功能仍依赖 Samsung 既有的云端服务或本地处理能力。

总结

SPAC 是三星为下一代 Galaxy AI 设计的隐私增强型云端计算框架，其核心目标是在提供强大的AI能力（接入 Gemma 4、Qwen 3.6 等多模型）的同时，通过匿名化和第三方中继等机制解决数据隐私顾虑。虽然功能覆盖广阔，但该框架目前仍处于代码分析阶段，尚未在 Galaxy S26 Ultra 上全面投入使用。

Samsungの新しいクラウドAIフレームワーク「SPAC」

ITメディアAndroid Authorityが、One UI 9.5の初期ベータテストコードを分析した結果、Appleの「Private Cloud Compute (PCC)」と類似した設計思想を持つ「SPAC」という新しいフレームワークを発見しました。

AppleのPCCは、Apple IntelligenceのためのクラウドベースなAIプライバシーアーキテクチャです。iPhoneがローカルで処理するのが難しい複雑なタスクを実行する際、Appleは専用サーバーでリクエストを処理します。これにより、個人データの取得や保存の機会を技術的に最小限に抑えつつ、ユーザーがより強力なクラウドAIを利用できるようにしています。

一方、Galaxy AIの場合、Samsungはこれまで主にポリシー上の約束に基づいてクラウド処理を行ってきました。例えば、写真編集機能では「画像はサーバーに送信されて処理されますが、Samsungには保存されません」と明記されています。SPACフレームワークは、こうした矛盾点を解決するものと期待されています。

SPACの動作原理とプライバシー保護

コード分析によると、SPACはArcaneというサーバーサイドゲートウェイを介して、トークン、認証、不正検出サービスとともに匿名化されたクラウドGalaxy AIリクエストを処理する仕組みのようです。ユーザーのリクエストは依然としてクラウドサーバーに送信されますが、その内容は匿名化および暗号化され、Samsung側がリクエストを特定のユーザーの身元と結びつけることが困難になります。

プライバシー面からコードの詳細を見ると、SPACは複数のメカニズムを通じてユーザーの個人情報を保護します。制限されたユーザーのリクエストはまずサードパーティの中継を経由して送信されるため、Samsungはリクエスト内容を処理できても、その出所を知ることが難しくなります。

さらに、スマートフォンはデータを送信する前に、Samsungサーバーが改ざんされていない公式ソフトウェアを実行しているかを確認します。関連するサーバーソフトウェアは、特定のユーザーを対象にプログラムが置き換えられるのを防ぐため、秘密裏に変更することが難しい公開記録に登録される可能性があります。また、スマートフォンは、ユーザーが実際のGalaxyユーザーであることを証明しつつも、具体的な身元を漏洩しない「ワンタイムパス」を受け取ることが想定されています。

サポートAIモデルと機能

コードからは、SPACが複数のAIモデルに接続できることも確認されています。

  • GoogleのGemma 4
  • AlibabaのQwen 3.6
  • Black Forest LabsのFLUX.2 klein 4B
  • Stable Diffusionモデル

写真編集機能のコードには、OpenAIのテキスト音声変換モデル、Samsungが独自開発したGauss、MetaのV-JEPAなども現れていますが、これらのモデルが現在実際に使用されているかどうかは確認できません。

機能的な側面から見ると、SPACは将来的に非常に広範囲なGalaxy AIシナリオを網羅できる可能性があります。

  • AI選択
  • クラウド写真の復元および拡大
  • リアルタイム音声翻訳
  • 要約
  • トーン調整
  • 絵文字提案
  • ライティングアシスト（文章作成補助）
  • Now Brief
  • 「Bixby work」などの機能

これらの機能が徐々にSPACに移行することで、Galaxy AIのクラウド機能は、機能的な強度を維持しつつ、より強力なプライバシー保護を実現できると期待されています。

現在の状況

ただし、この機能は現時点ではGalaxy S26 Ultraで実際に有効化されていません。テスターがライティングアシスト、AI選択、ノートアシスト、Now Brief、同時通訳などの機能を使用した際、SPACが呼び出されることは確認されませんでした。既存の機能は引き続きSamsungの従来のクラウドサービスまたはローカル処理を利用しています。

まとめ

Samsungは、AppleのPCCに匹敵するクラウドAIフレームワーク「SPAC」を開発中です。SPACは、ユーザーのリクエストを匿名化および暗号化することでプライバシー保護を強化し、多様なAIモデルを統合してGalaxy AI機能を拡張することが期待されています。現時点では開発段階であり、Galaxy S26 Ultraでの利用はまだ開始されていません。

Samsung's New Cloud AI Framework, SPAC

The IT media outlet Android Authority analyzed the code for the first beta test version of One UI 9.5 and discovered a new framework called 'SPAC,' which shares a design philosophy similar to Apple's 'Private Cloud Compute (PCC).'

Apple's PCC is a cloud-based AI privacy architecture designed for Apple Intelligence. When an iPhone performs complex tasks that cannot be handled locally, Apple processes the request on dedicated servers, technically minimizing opportunities to acquire or retain personal data and allowing users to utilize more powerful cloud AI.

For Galaxy AI, Samsung currently makes policy commitments regarding cloud processing. For instance, the photo editor specifies that images "are sent to the server for processing but are not stored by Samsung." The SPAC framework is expected to resolve this contradiction.

How SPAC Works and Privacy

According to code analysis, SPAC appears to process anonymized cloud Galaxy AI requests through a server-side gateway called Arcane, along with token, authentication, and fraud detection services. While user requests are still sent to the cloud server, the content of the request is anonymized and encrypted, making it difficult for Samsung to link the request to a specific user identity.

Regarding privacy, code details show that SPAC will protect user personal information through multiple mechanisms. Limited user requests are first passed via third-party intermediaries; while Samsung can process the content of the request, it is difficult for them to know the source of the request.

Furthermore, the phone verifies whether the Samsung server running the data transfer is uncompromised official software. The relevant server software could be recorded in a public ledger that makes covert modification—such as replacing the program targeting specific users—difficult. Additionally, the phone is expected to receive a one-time pass that proves the user is an actual Galaxy user without revealing their specific identity.

Supported AI Models and Features

The code also shows that SPAC can connect to multiple AI models:

  • Google's Gemma 4
  • Alibaba's Qwen 3.6
  • Black Forest Labs' FLUX.2 klein 4B
  • Stable Diffusion model

Although the photo editor code also contained references to OpenAI's text-to-speech models, Samsung's self-developed Gauss, and Meta's V-JEPA, it is currently unclear if these models are actually in use.

Functionally, SPAC can encompass a wide range of future Galaxy AI scenarios:

  • AI selection
  • Cloud photo restoration and enlargement
  • Real-time voice translation
  • Summarization
  • Tone adjustment
  • Emoji suggestion
  • Writing assistance
  • Now Brief
  • Features like "Bixby work"

If these features gradually transition to SPAC, it is expected that Galaxy AI's cloud functions will gain stronger privacy while maintaining functional capability.

Current Status

However, this feature has not yet been activated on the Galaxy S26 Ultra. Testers did not find SPAC being called when using features such as writing assistance, AI selection, note assistance, Now Brief, or simultaneous interpretation. Existing functions still utilize Samsung's existing cloud services or local processing.

Summary

Samsung is developing SPAC, a cloud AI framework similar to Apple's PCC. SPAC aims to enhance privacy by anonymizing and encrypting user requests while expanding Galaxy AI capabilities through the integration of various AI models. While it has broad potential functionality, it remains in development and is not yet active on the Galaxy S26 Ultra.
