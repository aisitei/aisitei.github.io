Huawei 📱 스마트폰

Huawei Mate XT 2 삼단 폴더블 스마트폰, HarmonyOS 7.0.0.109 SP8 업데이트로 통신 공유 기능 업그레이드 및 다중 사용자 상호 공유 지원

2026-10-02

시스템 업데이트

Huawei Mate 90 시리즈 및 전방위 신제품 발표회가 끝난 후, Mate XT 2 Ultimate Design 트리플 폴더블 폰의 시스템 업데이트가 진행되었습니다. 업데이트 로그에 따르면, 새로운 버전은 잠금 화면에 3D 공간 배경화면을 추가하고, 통신 공유 기능이 다중 사용자 상호 통신 공유를 지원하는 등의 기능을 포함합니다.

주요 업데이트 내용

  • 3D 공간 배경화면 기능이 추가되어 사진 속 요소와 심도 시계, 투시 시계를 결합하여 공간감 있는 잠금 화면 배경화면을 제공합니다. (설정 > 바탕화면 및 개인 설정 > 배경화면 > 3D 공간 배경화면)
  • 통신 공유 기능이 업그레이드되어 휴대폰과 HarmonyOS 7이 탑재된 휴대폰, 태블릿, HarmonyOS PC 간에 다중 사용자 상호 통신 공유를 지원합니다. 터치하거나 동일한 Huawei 계정으로 로그인하여 네트워크를 공유하고 상호 네트워크를 구축함으로써, 모바일 네트워크 신호가 약하거나 네트워크 부하가 큰 환경에서 더 빠르고 안정적인 네트워크 경험을 제공합니다.
  • 정적/동적 사진 모두 3D 동적 사진으로 생성할 수 있으며, 다양한 공간 이동 효과를 추가하여 새로운 시야를 제공합니다. (갤러리에서 사진을 선택하여 크게 보기 > 오른쪽 상단 3D 동적 사진 아이콘 클릭)
  • 다크 모드가 일출/일몰에 따라 자동으로 전환되도록 지원합니다. (설정 > 디스플레이 및 밝기 > 다크 모드 > 일출/일몰)

카메라 최적화

  • 사진 색상 표현이 최적화되어 사진 색상이 더욱 자연스러워졌습니다.
  • 사진 밝기 표현이 최적화되어 저조도 환경에서의 촬영 경험이 향상되었습니다.
  • 망원, 야경 등 시나리오에서의 촬영 효과가 최적화되어 이미지 품질이 향상되었습니다.
  • 카메라 안정성 및 일부 인터페이스 표시 효과가 최적화되어 사용 경험이 향상되었습니다.

시스템 기능

  • 시스템 화면 꺼짐 디스플레이에 화면 꺼짐 추적 내비게이션 기능이 추가되었습니다. 이 기능을 켜면 화면 꺼짐 디스플레이 인터페이스에 "지도" 등 일부 앱의 추적 내비게이션 정보가 표시됩니다. (설정 > 바탕화면 및 개인 설정 > 화면 꺼짐 디스플레이 설정 > 화면 꺼짐 추적 내비게이션)
  • 멀티모달 기본 대규모 모델 추론 속도가 최적화되어 날씨 요약, Xiaoyi 응답, 텍스트 다듬기 등 지능형 기능의 사용 경험이 더욱 향상되었습니다. (참고: 대규모 모델 업데이트가 포함되어 이번 업데이트 패키지 용량이 큽니다.)

성능 최적화

  • 일부 게임의 프레임률이 최적화되어 게임의 유동성이 향상되었습니다.
  • 일부 타사 앱의 사용 경험이 최적화되었습니다.
  • 전체 시스템 안정성이 최적화되어 장치 작동이 더욱 안정적입니다.

기타

시스템 확장 특성이 동기화되어 업데이트되었으며, 특성 기능이 강화되어 사용자 경험이 향상되었습니다.

업데이트 안내

Huawei HarmonyOS 시스템은 일반적으로 순차적으로 푸시되므로, 푸시를 받지 못한 경우 계속 기다려야 합니다. 빠른 업데이트를 원하는 일부 사용자는 "설정 - 소프트웨어 업데이트 - 업데이트 확인"을 통해 버전을 다운로드하여 업데이트를 시도할 수 있습니다.

총평

Huawei Mate XT 2 Ultimate Design은 이번 시스템 업데이트를 통해 잠금 화면의 3D 공간 배경화면, 다중 사용자 통신 공유 등 다양한 신규 기능을 추가했습니다. 카메라 성능과 시스템 안정성도 크게 향상되었으며, 특히 대규모 모델 추론 속도 최적화로 AI 기능의 사용 경험이 개선되었습니다. 전반적으로 사용자 편의성과 기기 성능을 강화하는 데 중점을 둔 업데이트입니다.

系统核心功能与互联升级

  • 通信共享增强：手机与搭载 HarmonyOS 7 的设备（包括平板、鸿蒙电脑）支持多人互助通信共享，用户可通过“碰一碰”或登录同一 Huawei 账号建立互助网络，提升弱信号或高负载场景下的网络稳定性。
  • 系统扩展特性同步更新：对系统扩展特性进行了增强和优化，以提高整体用户体验。

界面与个性化定制

  • 3D 空间壁纸：锁屏新增 3D 空间壁纸功能，可将照片中的元素与景深时钟、透视时钟结合，提供丰富的视觉效果和玩法（设置 > 桌面和个性化 > 壁纸 > 3D 空间壁纸）。
  • 熄屏显示优化：系统熄屏显示新增“循迹导航”功能，开启后可在熄屏界面显示地图等应用的循迹导航信息。
  • 深色模式自动切换：支持随日出日落自动切换深色模式（设置 > 显示和亮度 > 深色模式 > 日出日落）。

摄影与媒体处理能力提升

  • 3D 动态照片生成：用户现在可以对静态或动态照片生成 3D 动态照片，并添加多种空间运镜效果，解锁全新视角（图库内选择某照片 > 点击右上角 3D 动态照片图标）。
  • 拍照优化：提升了拍照色彩表现的自然度、亮度表现以增强暗光拍摄体验。同时优化了长焦、夜景等场景下的成像质量。
  • 相机使用体验：优化了相机的稳定性和部分界面显示效果。

智能与性能优化

  • 多模态大模型推理加速：优化了基础大模型的推理速度，提升了天气摘要、小艺帮接和文本润色等智能功能的使用体验。
  • 系统流畅性增强：优化了部分游戏的帧率，提升游戏流畅度；同时优化了部分第三方应用的使用体验。
  • 整体稳定性提升：全面优化了整机系统稳定性，并对拍照色彩、亮度及长焦/夜景等进行了多项性能优化。

注意事项

本次更新包体积较大，用户需注意系统推送可能采取分批方式进行，未收到推送请耐心等待；如急于升级，可尝试通过“设置-软件更新-检查更新”手动下载。

总结

此次 Mate XT 2 系统更新重点围绕提升全场景体验和智能化能力。新版本带来了多项视觉增强功能，包括支持多人互助通信共享的 HarmonyOS 7 升级、3D 空间壁纸以及更强大的 3D 动态照片生成能力。同时，系统在相机性能、大模型推理速度和整体稳定性方面进行了全面优化，旨在为用户提供更稳定、更具沉浸感的移动设备使用体验。

システムアップデート

Huawei Mate 90シリーズおよび全方位の新製品発表会を経て、Mate XT 2 Ultimate Designのトリプルフォールダブルスマートフォンにシステムアップデートが適用されました。更新ログによると、新しいバージョンには、ロック画面への3D空間背景壁紙の追加や、通信共有機能におけるマルチユーザー間の相互通信共有サポートなどの新機能が含まれています。

主なアップデート内容

  • 3D空間背景壁紙機能が追加され、写真内の要素と深度時計、パースペクティブ時計を組み合わせた立体感のあるロック画面の背景を提供します。（設定 > ホーム画面および個人設定 > 背景壁紙 > 3D空間背景壁紙）
  • 通信共有機能がアップグレードされ、スマートフォンとHarmonyOS 7搭載のタブレット、HarmonyOS PCの間でマルチユーザー間の相互通信共有をサポートします。デバイスにタッチするか、同一のHuaweiアカウントでログインすることでネットワークを共有し、相互ネットワークを構築でき、モバイルネットワークの電波が弱い環境やネットワーク負荷が高い環境でも、より高速かつ安定したネットワーク体験を提供します。
  • 静止画・動的画像ともに3Dダイナミック写真として生成可能になり、様々な空間移動エフェクトを追加して新しい視点を提供します。（ギャラリーで写真を選択して拡大 > 右上隅の3Dダイナミック写真アイコンをクリック）
  • ダークモードが日の出/日没に合わせて自動的に切り替わるようサポートされます。（設定 > ディスプレイと明るさ > ダークモード > 日出/日没）

カメラ最適化

  • 写真の色表現が最適化され、より自然な色合いの写真が得られるようになりました。
  • 写真の明るさ表現が最適化され、低照度環境での撮影体験が向上しました。
  • 望遠や夜景など、特定のシナリオにおける撮影効果が最適化され、画像品質が向上しています。
  • カメラの安定性および一部インターフェース表示エフェクトが最適化され、ユーザーエクスペリエンスが改善されました。

システム機能

  • システムの画面オフディスプレイに、画面オフ追跡ナビゲーション機能が追加されました。この機能をオンにすると、画面オフディスプレイのインターフェースに「マップ」など一部アプリの追跡ナビゲーション情報が表示されます。（設定 > ホーム画面および個人設定 > 画面オフディスプレイ設定 > 画面オフ追跡ナビゲーション）
  • マルチモーダル基盤大規模モデル（LLM）の推論速度が最適化され、天気要約、Xiaoyiへの応答、テキストの洗練などのインテリジェント機能の使用体験がさらに向上しました。（注：大規模モデルのアップデートが含まれているため、今回のアップデートパッケージ容量が大きくなっています。）

パフォーマンス最適化

  • 一部ゲームのフレームレートが最適化され、ゲームの流動性が向上しました。
  • 一部サードパーティ製アプリの使用体験が最適化されました。
  • 全体システム安定性が最適化され、デバイスの動作がより安定しました。

その他

システムの拡張特性が同期されアップデートされ、特性機能が強化されたことでユーザーエクスペリエンスが向上しています。

アップデート案内

Huawei HarmonyOSシステムは通常、順次プッシュされるため、通知を受け取れない場合でもしばらく待つ必要があります。迅速なアップデートを希望するユーザーは、「設定 - ソフトウェアアップデート - アップデート確認」からバージョンをダウンロードして更新を試みることができます。

まとめ

今回のHuawei Mate XT 2 Ultimate Designのシステムアップデートでは、ロック画面に3D空間背景壁紙やマルチユーザー対応通信共有など、多様な新機能が追加されました。さらに、カメラ性能とシステム安定性が大幅に向上し、特に大規模モデルの推論速度最適化によりAI機能の使用体験が改善されています。全体として、ユーザー利便性とデバイス性能の両面を強化することに重点を置いたアップデートとなっています。

System Update

Following the Huawei Mate 90 series and comprehensive new product announcements, a system update was rolled out for the Mate XT 2 Ultimate Design triple-foldable phone. According to the update log, the new version includes features such as a 3D spatial background wallpaper for the lock screen and enhanced communication sharing that supports multi-user inter-communication.

Key Update Details

  • A 3D spatial background feature has been added, providing immersive lock screen wallpapers that combine elements from photos with depth clocks and perspective clocks. (Settings > Wallpaper & Personalization > Wallpaper > 3D Spatial Wallpaper)
  • The communication sharing function has been upgraded to support multi-user inter-communication sharing among the phone, devices running HarmonyOS 7, tablets, and HarmonyOS PCs. By touching or logging in with the same Huawei account, users can share a network and establish an interconnected network, providing a faster and more stable network experience in environments where mobile network signals are weak or network load is high.
  • Both static and dynamic photos can now be generated as 3D dynamic photos, adding various spatial movement effects to offer new perspectives. (In the Gallery, select a photo > Click the 3D Dynamic Photo icon in the upper right corner)
  • Dark Mode now supports automatic switching based on sunrise/sunset times. (Settings > Display & Brightness > Dark Mode > Sunrise/Sunset)

Camera Optimizations

  • Photo color reproduction has been optimized, resulting in more natural photo colors.
  • Photo brightness representation has been optimized, enhancing the shooting experience in low-light environments.
  • Image quality has been improved through optimizations for various scenarios, including telephoto and night photography effects.
  • The user experience has been enhanced by optimizing camera stability and certain interface display effects.

System Features

  • A screen-off tracking navigation feature has been added to the system's screen-off display. When enabled, this feature displays tracking navigation information for some apps, such as "Maps," on the screen-off display interface. (Settings > Wallpaper & Personalization > Screen Off Display Settings > Screen Off Tracking Navigation)
  • The inference speed of the multimodal core large model has been optimized, further improving the user experience with intelligent features like weather summaries, Xiaoyi responses, and text refinement. (Note: The inclusion of a large model update makes this update package size substantial.)

Performance Optimization

  • Frame rates for certain games have been optimized, enhancing gaming fluidity.
  • The user experience for some third-party applications has been optimized.
  • Overall system stability has been optimized, making device operation more stable.

Other

System extension characteristics have been synchronized and updated, strengthening feature capabilities to improve the overall user experience.

Update Guide

Huawei HarmonyOS systems typically push updates sequentially, so users who do not receive a push notification should continue waiting. Users desiring a faster update can attempt to download and install the version via "Settings - Software Update - Check for Updates."

Summary

The Huawei Mate XT 2 Ultimate Design received a comprehensive system update introducing several new features, including 3D spatial lock screen wallpapers and multi-user communication sharing. Key improvements include optimized camera performance across various scenarios and enhanced overall system stability. Notably, the optimization of large model inference speed significantly improves the user experience for AI-powered functions.
