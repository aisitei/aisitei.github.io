Apple 최초의 폴더블 iPhone Duo 잠금 화면, 원클릭 활성화 지원하는 미니멀리스트 집중 모드 탑재 예정

2026-10-07

디자인

Apple의 첫 폴더블 아이폰인 iPhone Duo에 대한 추가 정보가 X 플랫폼의 @itspdfu를 통해 10월 4일 공개되었습니다. 여기에는 잠금 화면의 집중 모드(Focus Mode) 제어 기능 재설계에 대한 내용이 포함되어 있습니다.

소식통은 iOS 27.1 베타 버전을 분석하여 Apple이 iPhone Duo의 외부 화면에 맞춰 집중 모드 인터페이스를 조정하고 있음을 발견했습니다.

iPhone Duo는 더 작고 낮은 외부 화면을 탑재하고 있어, 기존 집중 모드 컨트롤은 공간을 많이 차지합니다. 새로운 디자인은 텍스트 라벨을 삭제하고 아이콘만 남겨 잠금 화면을 더욱 간결하게 만들고 작은 디스플레이 영역에 맞도록 조정합니다.

잠금 화면 상태에서 사용자는 집중 모드 버튼을 클릭하여 기능을 활성화/비활성화할 수 있습니다. 현재 버전에서는 이 버튼이 집중 모드 설정 페이지로 이동하여 사용자가 상태를 전환하기 위해 추가 조작을 해야 합니다.

잠금 해제 후, iPhone Duo 외부 화면의 집중 모드 아이콘은 시계 위로 이동합니다. 현재 이 아이콘은 화면 상단 시계 옆에 표시되지만, 새로운 레이아웃은 아이콘을 오른쪽 시계 및 재배치된 Dock 바와 구분합니다.

웹 브라우징

소식통은 어제(10월 5일) iPhone Duo에서 실행되는 Safari 브라우저가 Device Posture API와 Viewport Segments API를 지원하여 폴더블 디스플레이 또는 듀얼 스크린 장치에 웹 페이지를 적응시키는 기본 지원을 제공한다고 밝혔습니다.

개발자는 시뮬레이터에서 설정 > 앱 > Safari > 고급 > 기능 플래그로 이동하여 위 두 기능을 활성화하여 테스트할 수 있습니다. 이는 웹 페이지가 장치의 현재 펼쳐진 상태, 접힌 상태 및 듀얼 스크린 분할 상태에 따라 페이지 레이아웃, 콘텐츠 분포 및 상호 작용 방식을 동적으로 조정할 수 있음을 의미합니다.

총평

Apple의 첫 폴더블 아이폰인 iPhone Duo는 외부 화면에 최적화된 집중 모드 인터페이스와 웹 브라우징 기능을 제공할 예정입니다. 작은 외부 화면에 맞춰 집중 모드 컨트롤은 아이콘 기반으로 재설계되며, Safari는 폴더블 및 듀얼 스크린 장치에 웹 페이지를 동적으로 적응시키는 API를 지원합니다. 이는 폴더블 기기의 사용자 경험을 향상시키기 위한 Apple의 노력을 보여줍니다.

Apple iPhone Duo 外屏与系统UI优化

  • 消息源通过挖掘iOS 27.1测试版，发现Apple正在为iPhone Duo的外屏进行专注模式（Focus Mode）界面调整。
  • 新设计针对更小、更矮的外屏尺寸进行了适配，核心变化包括：
    • 删除文字标签，仅保留图标，使锁屏界面更加简洁。
    • 优化了使用流程：用户在锁屏状态下直接点击专注模式按钮即可启用/禁用，无需跳转至设置页面进行额外操作。
  • 外屏的专注模式图标位置调整：解锁后，该图标将移至时钟上方，与右侧的时钟及重新定位的Dock栏保持区分。

Safari浏览器开发者功能增强

  • iPhone Duo上的Safari浏览器支持了两个关键底层API：Device Posture API（设备姿态 API）和 Viewport Segments API（视口分段 API）。
  • 这些API为网页内容适配折叠屏或双屏幕设备提供了底层技术支持。
  • 开发者可通过模拟器测试此功能，路径为设置 > 应用 > Safari > 高级 > 功能标志。
  • 通过该机制，网页能够根据设备当前的展开、折叠状态及双屏分区情况，动态调整其页面布局、内容分布和交互方式。

产品与系统信息

  • 本次泄露的细节主要围绕Apple首款折叠iPhone Duo机型展开。
  • 相关功能更新是在iOS 27.1测试版本中观察到的。

总结

消息源透露了关于Apple首款折叠屏手机iPhone Duo的多项新细节，重点在于其系统级和软件层面的优化。在用户界面上，Apple改进了外屏的专注模式交互流程，使其更简洁、操作更便捷。同时，通过引入Device Posture API等底层技术支持，Safari浏览器增强了网页内容的自适应能力，为折叠屏设备带来了强大的开发兼容性。

デザイン

Apple初の折りたたみ式iPhone「iPhone Duo」に関する追加情報が、Xプラットフォームの@itspdfuを通じて10月4日に公開されました。この情報には、ロック画面のフォーカスモード（Focus Mode）制御機能の再設計が含まれています。

複数の情報筋によると、iOS 27.1ベータ版を分析した結果、AppleがiPhone Duoの外側ディスプレイに合わせてフォーカスモードインターフェースを調整していることが判明しました。

iPhone Duoはより小型で低い外部画面を採用しているため、従来のフォーカスモードコントロールではスペースを多く占めていました。新しいデザインでは、テキストラベルを削除しアイコンのみを残すことでロック画面がさらに簡素化され、小さなディスプレイ領域に適合するように調整されています。

ロック画面の状態では、ユーザーはフォーカスモードボタンをクリックすることで機能を有効/無効に切り替えることができます。現在のバージョンでは、このボタンを押すとフォーカスモード設定ページへ移動し、状態を切り替えるために追加の操作が必要でした。

また、ロック解除後のiPhone Duoの外側画面におけるフォーカスモードアイコンは、時計の上に配置されるようになります。現在はこのアイコンは画面上部の時計の隣に表示されていますが、新しいレイアウトでは右側の時計および再配置されたDockバーと区別されます。

ウェブブラウジング

情報筋によると、iPhone Duoで動作するSafariブラウザは、Device Posture APIとViewport Segments APIをサポートし、折りたたみディスプレイまたはデュアルスクリーンデバイスにおいてWebページに基本的な適応機能を提供することが明らかになりました（10月5日）。

開発者はシミュレーター内の「設定 > アプリ > Safari > 詳細 > 機能フラグ」から上記2つの機能を有効化してテストすることができます。これは、ウェブページがデバイスの現在の展開状態、折りたたみ状態、およびデュアルスクリーン分割状態に応じて、レイアウト、コンテンツの配置、インタラクション方法を動的に調整できることを意味します。

まとめ

Apple初の折りたたみ式iPhone「iPhone Duo」は、外部画面に最適化されたフォーカスモードインターフェースと高度なウェブブラウジング機能を提供することが期待されます。具体的には、小さな外側ディスプレイに合わせてフォーカスモードコントロールがアイコンベースで再設計され、SafariはWebページをフォールディングおよびデュアルスクリーン環境下で動的に適応させるAPIをサポートします。これらの変更は、Appleが折りたたみデバイスのユーザー体験（UX）を大幅に向上させようとする取り組みを示しています。

Design

Additional information regarding Apple's first foldable iPhone, the iPhone Duo, was revealed on October 4th via @itspdfu on the X platform. This leak included details about a redesigned Focus Mode control for the lock screen.

Sources analyzing the iOS 27.1 beta version found that Apple is adjusting the Focus Mode interface specifically for the external display of the iPhone Duo.

Because the iPhone Duo features a smaller, lower external screen, the existing Focus Mode controls take up too much space. The new design aims to simplify the lock screen by removing text labels and retaining only icons, making it suitable for the compact display area.

When on the lock screen, users can activate or deactivate Focus Mode by tapping a dedicated button. Currently, this action moves the user to a Focus Mode settings page, requiring additional steps to change the status.

After unlocking the device, the Focus Mode icon on the iPhone Duo's external screen will move above the clock. While the current icon is positioned next to the top clock, the new layout separates this icon from both the right-side clock and the repositioned Dock bar.

Web Browsing

Sources reported yesterday (October 5th) that Safari on the iPhone Duo will support the Device Posture API and Viewport Segments API. This provides fundamental support for adapting web pages to foldable displays or dual-screen devices.

Developers can test these two features by navigating to Settings > Apps > Safari > Advanced > Feature Flags in the simulator and enabling them. This capability means that web pages can dynamically adjust their layout, content distribution, and interaction methods based on the device's current state—whether it is open, closed, or split into a dual-screen view.

Summary

The iPhone Duo is set to feature an optimized Focus Mode interface for its external screen and enhanced web browsing capabilities. The Focus Mode control has been redesigned to be icon-based to fit the smaller external display, while Safari supports APIs that allow web pages to dynamically adapt their layout across foldable and dual-screen configurations. These changes highlight Apple's efforts to improve the overall user experience on foldable devices.
