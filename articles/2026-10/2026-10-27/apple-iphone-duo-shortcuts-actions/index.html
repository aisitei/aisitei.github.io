새로운 자동화 트리거

iPhone Duo에 새로운 단축어 자동화 트리거 조건이 추가되어 기기가 펼쳐지거나 접힐 때 미리 설정된 작업을 자동으로 실행할 수 있게 되었습니다.

비디오 블로거 스티븐 로블레스(Stephen Robles)가 이 기능을 발견했으며, 이 트리거 조건은 '펼치거나 접기'로 명명되었고 디스플레이 관련 자동화 옵션 아래에 있습니다. 지난 9월, 코드 분석가 pdfu는 이미 iPhone Duo 시뮬레이터에서 이 기능을 찾아낸 바 있습니다.

이 기능의 유용한 활용법 중 하나는 휴대폰을 펼칠 때 자동으로 다른 배경화면으로 전환하고, 접을 때 다시 원래 배경화면으로 되돌리는 것입니다.

이번에 추가된 트리거 조건은 '단축어'의 '개인 자동화'에 속합니다. 개인 자동화는 특정 시간, 특정 위치 도착, 앱 실행 등 이벤트 기반으로 작업을 실행하는 방식으로, 기기에 특화되어 iCloud에 백업되지만 다른 기기와는 동기화되지 않습니다. 새로운 개인 자동화를 생성하면 이벤트 발생 시 자동화 실행 요청 알림을 받게 되며, 묻지 않고 직접 실행되도록 편집할 수도 있습니다.

폴더블 전용 기능

자동화 트리거 조건 외에도 iOS 27.1은 폴더블 형태에 특화된 여러 기능을 추가했습니다. 여기에는 반쯤 접힌 상태에서 자동으로 활성화되는 탁상시계 호버 제어판, 내부 화면에서 최대 3개의 앱을 동시에 나란히 실행할 수 있는 고급 창 관리 시스템, 가상 키보드 분리 및 풀 사이즈 트랙패드 시뮬레이션 등이 포함됩니다.

총평

iPhone Duo에 기기 펼침/접힘 상태에 따라 동작하는 새로운 단축어 자동화 트리거가 추가되었습니다. 이 기능은 배경화면 자동 전환 등 다양한 개인 맞춤형 설정을 가능하게 합니다. 또한 iOS 27.1은 폴더블 기기 전용으로 반쯤 접힌 상태의 탁상시계 제어판, 고급 창 관리 시스템, 가상 키보드 분리 등 여러 기능을 도입하여 폴더블 사용 경험을 향상시켰습니다.

折叠设备自动化新功能

  • 新增触发条件： iPhone Duo 增加了“展开或折叠”的快捷指令自动化触发条件，允许用户在设备物理状态变化时自动执行预设操作。
  • 实用示例： 可设置手机展开时自动切换壁纸，合上时再切回原壁纸等场景应用。

iOS 27.1 折叠形态专属功能升级

除了自动化触发条件外，iOS 27.1 还为折叠设备带来了多项专有优化和增强功能：

  • 半折叠状态控制： 支持自动激活的台钟悬停控制面板。
  • 进阶窗口管理： 内屏最多支持三个 App 同时并排运行，提升了多任务处理能力。
  • 输入设备优化： 增加了虚拟键盘分离功能和全尺寸触控板模拟等操作体验增强。

个人自动化（Personal Automation）机制

此次新增的触发条件属于“快捷指令”中的“个人自动化”，其运行机制基于特定事件，具有以下特点：

  • 触发依据： 自动化是基于设备事件（如到达某个位置、一天中的某一时间或打开特定 App）来运行操作的。
  • 数据特性： 该功能属于特定于设备的个人设置，会备份到 iCloud 但不会同步到其他设备。
  • 使用模式： 用户创建后，在事件发生时会收到通知请求运行自动化，也可将其设置为直接运行，无需询问确认。

总结

本次更新的核心亮点在于将设备的物理状态（展开/折叠）深度整合到iOS的“个人自动化”系统中，极大地扩展了快捷指令的应用场景。同时，iOS 27.1为iPhone Duo等折叠形态设备带来了多项专属优化，包括三App并排运行、悬停控制面板和虚拟键盘分离等功能，显著提升了设备的实用性和操作流畅度。

新しい自動化トリガー機能

iPhone Duoに、ショートカットの自動化トリガー条件として新しいオプションが追加されました。これにより、デバイスを開いたり閉じたりする動作を検知し、事前に設定したタスクを自動で実行することが可能になりました。

この機能はビデオブロガーのStephen Robles氏によって発見され、「展開または折りたたみ」という名前が付けられ、ディスプレイ関連の自動化オプションの下に配置されています。なお、コード分析家のpdfu氏は以前よりiPhone Duoシミュレーター上でこの機能を特定しています。

このトリガーの具体的な活用例として、スマートフォンを開いたときに自動的に背景画像を別のものに切り替え、閉じたときに元の背景画像に戻すといった設定が挙げられます。

今回追加されたトリガー条件は、「ショートカット」内の「個人用自動化」に分類されます。個人用自動化とは、特定の時間、特定の位置への到着、アプリの実行など、イベントに基づいた方法でタスクを実行する機能です。この設定はデバイス固有でありiCloudにバックアップされるものの、他のデバイスとは同期されません。新しい個人用自動化を作成すると、イベント発生時に自動化の実行を促す通知を受け取ることができ、さらに「尋ねずに直接実行」するように編集することも可能です。

折りたたみ式デバイス専用機能

自動化トリガー条件以外にも、iOS 27.1では折りたたみ式フォームファクタに特化した複数の機能が追加されました。これには以下のものが含まれます。

  • 半開状態のときに自動的にアクティブになる卓上時計ホバーコントロールパネル
  • 内部ディスプレイで最大3つのアプリを同時に並列実行できる高度なウィンドウ管理システム
  • 仮想キーボードの分離およびフルサイズのトラックパッドシミュレーション機能

まとめ

iPhone Duo向けに、デバイスの開閉状態に応じて動作する新しいショートカット自動化トリガーが追加され、背景画像の自動切り替えなど、より高度なパーソナライゼーションが可能になりました。さらにiOS 27.1は、折りたたみ式デバイス専用として、半開時の卓上時計コントロールパネルや高度なウィンドウ管理システム、仮想キーボードの分離といった複数の機能を取り入れ、折りたたみ端末の利用体験を大幅に向上させています。

New Automation Trigger

iPhone Duo has received a new automation trigger condition for Shortcuts, allowing users to automatically execute pre-set tasks when the device is unfolded or folded.

The feature was discovered by video blogger Stephen Robles and is named 'Fold or Unfold,' located under display-related automation options. Previously, code analyst pdfu had already identified this function within the iPhone Duo simulator last September.

One useful application of this new trigger is automatically switching to a different wallpaper when unfolding the phone, and reverting to the original wallpaper when folding it back up.

This newly added trigger condition belongs to 'Personal Automation' within Shortcuts. Personal Automation executes tasks based on events such as specific times or arrival at a certain location. While this feature is device-specific and backed up to iCloud, it does not synchronize with other devices. When creating a new personal automation, users receive an alert when the event occurs, but they can also edit the settings to allow the automation to run directly without prompting.

Foldable Exclusive Features

In addition to the automation trigger condition, iOS 27.1 introduces several features specifically tailored for foldable form factors. These include:

  • A hover control panel/desktop clock that automatically activates when the device is partially folded.
  • An advanced window management system allowing up to three apps to run side-by-side on the inner screen simultaneously.
  • Virtual keyboard separation and simulation of a full-size trackpad.

Summary

iPhone Duo now features a new Shortcuts automation trigger that responds to the device's fold/unfold state, enabling personalized settings such as automatic wallpaper transitions. Furthermore, iOS 27.1 enhances the foldable user experience by introducing several dedicated functions, including a partially folded desktop clock control panel, advanced window management, and virtual keyboard separation.
