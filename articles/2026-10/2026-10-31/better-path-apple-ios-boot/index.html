더 나은 길을 닦다: 개발자가 Microsoft Surface Duo 2에서 iPhone Duo 전용 Apple iOS 27 시스템을 성공적으로 부팅

2026-10-31

소개

IT之家 10월 30일 소식에 따르면, iOS 26을 플래싱한 후, 블로거 @none25smu는 X 플랫폼에 게시물을 업데이트하여 Microsoft Surface Duo 2에 iPhone Duo 전용 iOS 27 시스템을 성공적으로 플래싱했다고 공개했습니다.

기술적 진전

개발자는 iOS 27의 iPhone Duo 레이아웃이 장치가 두 가지 디스플레이 유형을 각각 인식해야 한다고 밝혔습니다. 31은 폴더블 상태의 커버 디스플레이에 해당하고, 32는 펼친 상태의 언폴드 디스플레이에 해당합니다. 시스템 하단에서 이 두 가지 디스플레이 유형을 올바르게 인식해야만 SpringBoard(iOS 홈 화면 시스템)가 해당 Duo 듀얼 스크린 레이아웃을 활성화할 수 있습니다.

현재 상태 및 과제

개발자가 공개한 화면을 보면, 현재 인터페이스 확대/축소 비율에 여전히 문제가 있어 전체 디스플레이 크기가 확연히 크게 나타납니다. 개발자 역시 현재 화면의 확대/축소 비율이 너무 높다고 농담했습니다.

총평

이번 진전은 이 포팅 프로젝트가 기존의 시스템 부팅 및 하드웨어 가속 최적화 단계를 넘어 시스템 네이티브 수준의 폴더블 와이드 스크린 인터페이스 적응 단계로 나아갔음을 의미합니다. 그러나 일상적인 사용에는 아직 상당한 거리가 있습니다.

跨平台系统移植重大进展

  • 开发者@none25smu在X平台上展示了成功将专为 iPhone Duo 设计的 iOS 27 系统刷入微软 Surface Duo 2 设备。

核心技术适配与显示屏识别

此次移植项目已从早期的系统点亮和硬件加速优化阶段，进一步推进至适配原生级折叠宽屏界面。

  • 为了启用 SpringBoard（iOS 主屏幕系统）的 Duo 듀얼 스크린布局，系统底层必须正确识别两种显示屏类型：
  • 31：对应设备处于折叠状态时的外屏（Cover Display）。
  • 32：对应设备展开状态时的内屏（Unfolded Display）。

当前界面表现与局限性

尽管项目取得了显著进展，但目前系统仍存在明显的适配问题，距离日常使用尚有较大差距。

  • 从开发者公布的画面来看，当前的整体显示尺寸明显偏大，界面缩放比例存在一定问题。

总结

该报道展示了iOS 27系统成功移植到Surface Duo 2上的重大技术进展。核心突破在于系统底层实现了对折叠屏设备两种不同状态（Cover Display和Unfolded Display）的识别，从而激活了Duo双屏布局。尽管目前界面缩放比例等问题仍需优化，但该项目已显著推进至原生级宽屏适配阶段。

概要

IT之家が10月30日のニュースで報じたところによると、ブロガーの@none25smu氏がXプラットフォーム上で、Microsoft Surface Duo 2に対し、iPhone Duo専用のiOS 27システムを正常にフラッシュしたことを公開しました。これは、以前のiOS 26からアップグレードされたものです。

技術的な進展

開発者は、iOS 27のiPhone Duoレイアウトが、デバイスが二種類のディスプレイタイプをそれぞれ認識する必要があることを明らかにしました。具体的には、以下の2つの状態に対応しています。

  • 31：折りたたまれた状態のカバーディスプレイ
  • 32：展開した状態のアンフォールドディスプレイ（メイン画面）

システムがこれらの二種類のディスプレイタイプを正しく認識できなければ、SpringBoard（iOSのホーム画面システム）はDuoデュアルスクリーンレイアウトを有効にすることができません。

現在の状況と課題

開発者が公開した画面を確認すると、現在インターフェースのスケーリング比率にまだ問題があり、全体のディスプレイサイズが著しく大きく表示されています。開発者自身も、現在の画面の拡大/縮小比率が高すぎるとジョークで述べています。

総評

今回の進展は、この移植プロジェクトが単なる既存システムの起動やハードウェアアクセラレーションの最適化段階を超え、システムネイティブレベルでの折りたたみ式ワイドスクリーンインターフェースへの適応段階に進んだことを意味します。しかしながら、日常的な使用にはまだかなりの道のりがある状況です。

まとめ

本記事は、ブロガーがMicrosoft Surface Duo 2に対しiOS 27をフラッシュし、iPhone Duo専用のデュアルディスプレイシステムの実証に成功したことを報じています。この進展により、デバイスが折りたたみ状態と展開状態の両方の画面タイプを認識できることが確認されました。ただし、現在インターフェースのスケーリング比率に問題があり、実用化にはさらなる最適化が必要な段階にあることが示されています。

Introduction

According to a report from IT之家 on October 30th, blogger @none25smu updated a post on the X platform, revealing that they successfully flashed an iOS 27 system specifically for the iPhone Duo onto the Microsoft Surface Duo 2.

Technical Progress

The developer stated that the iOS 27 iPhone Duo layout requires the device to recognize two distinct display types. These are designated as 31, corresponding to the cover display in a folded state, and 32, corresponding to the unfolded display. The SpringBoard (the iOS home screen system) can only activate this Duo dual-screen layout if it correctly recognizes both of these display types from the bottom of the system.

Current Status and Challenges

The screenshots released by the developer show that there are still issues with the interface scaling ratio, causing the overall displayed size to appear significantly larger. The developer even joked that the current screen's scaling ratio is too high.

Overall Assessment

This advancement signifies that the porting project has moved beyond optimizing system booting and hardware acceleration stages, progressing into the stage of adapting a native foldable wide-screen interface at the system level. However, there is still a considerable distance to go before it can be used for daily operation.

Summary

Blogger @none25smu successfully flashed an iOS 27 system onto the Microsoft Surface Duo 2. This development shows that the core challenge—getting SpringBoard to recognize and activate dual-screen layouts (folded cover display and unfolded main display)—has been addressed. While the project has advanced significantly toward a native foldable wide-screen interface, current issues persist with the interface scaling ratio, indicating that substantial work remains before daily usability is achieved.
