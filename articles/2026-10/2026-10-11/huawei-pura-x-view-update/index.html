Huawei Pura X View 바 타입 스마트폰, HarmonyOS 7.0.0.109 SP10 업데이트로 다중 사용자 상호 통신 공유 기능 지원

2026-10-11

업데이트 개요

Huawei는 오늘 Pura X View 스마트폰에 HarmonyOS 7.0.0.109 SP10 버전 업데이트를 우선적으로 배포했습니다. 약 4.83GB 용량의 이번 업데이트는 다중 사용자 통신 공유, 화면 꺼짐 추적 내비게이션 등의 새로운 기능을 제공합니다.

주요 업데이트 내용

  • 통신 공유 기능이 업그레이드되어, HarmonyOS 7이 탑재된 다른 스마트폰, 태블릿, HarmonyOS PC와 다중 사용자 통신 공유를 지원합니다. 기기를 터치하거나 동일한 Huawei 계정으로 로그인하여 네트워크를 공유하고 상호 지원 네트워크를 구축함으로써, 모바일 네트워크 신호가 약하거나 네트워크 부하가 큰 환경에서 더 빠르고 안정적인 네트워크 경험을 제공합니다.
  • 시스템 화면 꺼짐 디스플레이에 화면 꺼짐 추적 내비게이션 기능이 추가되었습니다. 이 기능을 활성화하면 화면 꺼짐 디스플레이 화면에서 "지도" 등 일부 앱의 추적 내비게이션 정보를 표시할 수 있습니다 (설정 > 홈 화면 및 개인 설정 > 화면 꺼짐 디스플레이 설정 > 화면 꺼짐 추적 내비게이션).
  • 멀티모달 기반 대규모 모델 추론 속도를 최적화하여 날씨 요약, Xiaoyi 응답, 텍스트 다듬기 등 스마트 기능의 사용 경험을 더욱 향상시켰습니다 (참고: 대규모 모델 업데이트가 포함되어 이번 업데이트 패키지 용량이 큽니다).
  • 일부 시나리오에서의 촬영 효과를 최적화하고 색상 재현 정확도를 높였습니다.
  • 일부 게임의 프레임 속도를 최적화하여 게임의 유창성을 향상시켰습니다.
  • 일부 타사 앱의 사용 경험을 최적화했습니다.
  • 일부 시나리오에서 알림 진동 효과를 최적화했습니다.
  • 두 번 탭하여 화면 켜기 기능을 최적화했습니다.
  • 전체 시스템 안정성을 최적화하여 기기 작동을 더욱 안정적으로 만들었습니다.
  • 시스템 확장 특성을 동기화하여 기능성을 강화하고 사용자 경험을 향상시켰습니다.

업데이트 방법 및 주의사항

Huawei HarmonyOS 시스템은 일반적으로 순차적으로 배포되므로, 아직 업데이트를 받지 못한 사용자는 계속 기다려야 합니다. 빠른 업데이트를 원하는 일부 사용자는 "설정 - 소프트웨어 업데이트 - 업데이트 확인"을 통해 버전을 다운로드하고 업그레이드를 시도할 수 있습니다.

총평

이번 HarmonyOS 7.0.0.109 SP10 업데이트는 Pura X View 사용자에게 다중 사용자 통신 공유 및 화면 꺼짐 추적 내비게이션과 같은 혁신적인 기능을 제공합니다. 또한, 대규모 모델 추론 속도 최적화를 통해 스마트 기능의 사용 경험을 향상시키고, 카메라 성능 및 시스템 안정성 개선을 통해 전반적인 사용자 만족도를 높였습니다.

系统核心升级与版本信息

Huawei今日面向Pura X View手机推送了HarmonyOS 7.0.0.109 SP10版本升级，本次更新包体大小约为4.83GB。

通信互联与用户体验增强

  • 多人互助通信共享：支持手机与搭载 HarmonyOS 7 的平板、鸿蒙电脑之间进行多设备协作网络建立。用户可通过碰一碰或登录同一Huawei账号，在移动网络信号弱或负载大时获得更稳定快速的网络体验。
  • 熄屏循迹导航：新增功能，允许在设备的熄屏显示界面（如“地图”）展示循迹导航信息。

智能功能与AI优化

  • 多模态基础大模型推理优化：进一步提升了天气摘要、小艺帮接和文本润色等智能功能的整体使用体验。
  • 系统扩展特性更新：同步更新了系统扩展特性，增强了各项功能并提升用户体验。

性能与稳定性提升

  • 影像优化：优化了部分场景的拍摄效果，提高了色彩还原的准确性。
  • 流畅度优化：优化了部分游戏的帧率，提升了游戏运行的流畅性。
  • 应用体验优化：提升了部分第三方应用的使用体验；优化了双击亮屏功能。
  • 系统稳定性：全面优化了整机系统的稳定性，确保设备运行更稳定。

部署与注意事项

  • 本次更新涉及大模型和多项优化，包体积较大。
  • HarmonyOS 系统常采取分批推送方式，用户未收到通知需耐心等待；可通过“设置-软件更新-检查更新”手动尝试升级。

总结

此次 HarmonyOS 7.0.0.109 SP10 版本为 Pura X View 带来了全面的系统升级和功能增强。核心亮点包括跨设备的多人互助通信共享能力、熄屏循迹导航的加入，以及对多模态大模型推理速度的大幅优化。整体更新旨在提升设备的网络稳定性、使用流畅度和智能化水平。

アップデート概要

Huaweiは本日、Pura X Viewスマートフォン向けに、HarmonyOS 7.0.0.109 SP10バージョンのアップデートを優先的に展開しました。容量約4.83GBの今回のアップデートでは、マルチユーザー通信共有や画面オフ時の追跡ナビゲーションなど、複数の新機能が提供されます。

主な更新内容

  • 通信共有機能のアップグレード： HarmonyOS 7を搭載した他のスマートフォン、タブレット、HarmonyOS PCと「マルチユーザー通信共有」に対応しました。デバイスにタッチするか、同じHuaweiアカウントでログインすることでネットワークを共有し、相互サポートネットワークを構築します。これにより、モバイルネットワークの電波が弱い環境やネットワーク負荷が高い環境でも、より高速かつ安定したネットワーク体験を提供します。
  • 画面オフ時の追跡ナビゲーション機能追加： システムの画面オフディスプレイに「画面オフ時の追跡ナビゲーション」機能が追加されました。この機能を有効にすると、「マップ」などの一部アプリにおいて、画面オフの状態でもトラッキングナビゲーション情報を表示できます（設定 > ホーム画面とパーソナライゼーション > 画面オフディスプレイ設定 > 画面オフ追跡ナビゲーション）。
  • 大規模モデルの推論速度最適化： マルチモーダルベースの大規模モデルの推論速度が最適化され、天気予報の要約、Xiaoyiへの応答、テキストの洗練など、スマート機能の使用体験がさらに向上しました（注：大規模モデルのアップデートが含まれているため、今回のアップデートパッケージは容量が大きくなっています）。
  • 撮影効果の一部シナリオにおける最適化と色再現精度の向上を実現しました。
  • 一部ゲームのフレームレートを最適化し、ゲームプレイの流暢性を高めました。
  • 一部サードパーティ製アプリの使用体験を最適化しました。
  • 特定のシナリオにおける通知バイブレーション効果が最適化されました。
  • 「ダブルタップで画面オン」機能が最適化されました。
  • システム全体の安定性が向上し、デバイスの動作がより安定しました。
  • システムの拡張特性を同期することで、機能性を強化しユーザーエクスペリエンスを向上させました。

アップデート方法と注意事項

Huawei HarmonyOSシステムは通常、段階的に展開されるため、まだアップデートを受け取っていないユーザーは引き続き待機する必要があります。迅速なアップデートを希望される方は、「設定 - ソフトウェアアップデート - アップデートの確認」からバージョンをダウンロードし、アップグレードを試みてください。

Update Overview

Huawei has prioritized the distribution of the HarmonyOS 7.0.0.109 SP10 version update for the Pura X View smartphone. This update, which has a capacity of approximately 4.83GB, introduces new features such as multi-user communication sharing and screen-off tracking navigation.

Key Update Features

  • The communication sharing function has been upgraded to support multi-user communication sharing across other smartphones, tablets running HarmonyOS 7, and HarmonyOS PCs. By touching the device or logging in with the same Huawei account, users can share a network and establish an interoperable network, providing a faster and more stable network experience in environments with weak mobile network signals or high network load.
  • Screen-off tracking navigation has been added to the system's screen-off display. When this feature is activated, it allows users to view tracking navigation information for certain apps (such as "Maps") on the screen-off display (Settings > Home Screen & Personalization > Screen-Off Display Settings > Screen-Off Tracking Navigation).
  • The user experience of smart features has been enhanced by optimizing large model inference speed based on multimodal capabilities, improving functions such as weather summaries, Xiaoyi responses, and text refinement. (Note: The inclusion of a large model update contributes to the size of this update package.)
  • Optimized shooting effects in certain scenarios and increased color reproduction accuracy.
  • Improved gaming fluidity by optimizing frame rates for specific games.
  • Optimized the user experience for certain third-party applications.
  • Optimized notification vibration effects in some scenarios.
  • Optimized the "wake screen by double tap" function.
  • Enhanced overall system stability, making device operation more reliable.
  • Strengthened functionality and improved user experience by synchronizing system extension characteristics.

Installation Instructions and Notes

Since the Huawei HarmonyOS system is typically rolled out sequentially, users who have not yet received the update should continue to wait. Users wishing for a quicker update can attempt to download and upgrade the version via "Settings - Software Update - Check for Updates."

Summary

The HarmonyOS 7.0.0.109 SP10 update provides Pura X View users with innovative features, including multi-user communication sharing and screen-off tracking navigation. Furthermore, the optimization of large model inference speeds enhances the user experience of smart functions, while improvements to camera performance and system stability boost overall user satisfaction.
