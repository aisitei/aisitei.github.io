Microsoft Edge 155 안정 버전 출시: AI 탭 정리 기능 강화, JPEG XL 이미지 디코딩 지원

2026-10-11

주요 업데이트

Microsoft는 10월 8일 데스크톱용 Microsoft Edge 155 안정화 버전을 출시했습니다. 버전 번호는 155.0.4283.45입니다. 새 버전에는 JPEG XL 이미지 디코딩 지원이 추가되었으며, 탭 및 작업 공간의 스마트 정리 기능이 확장되었습니다.

AI 기능 강화

기능 업데이트 측면에서 Microsoft Edge 155는 AI 탭 정리 기능을 강화했습니다. 이제 탭과 작업 공간을 그룹화하는 방법뿐만 아니라 그룹 이름, 시각적 스타일 및 태그도 추천합니다. 사용자는 edge://settings/privacy/services에서 관련 설정을 조정할 수 있습니다.

이미지 지원

새 버전은 JPEG XL (image/jxl) 이미지를 디코딩할 수 있습니다. 이 형식은 점진적 디코딩, 넓은 색 영역, HDR(High Dynamic Range), 높은 비트 심도 및 애니메이션을 지원하여 브라우저가 해당 이미지 콘텐츠를 직접 표시하는 데 도움이 됩니다.

실시간 번역

실시간 번역과 관련하여 Microsoft는 실시간 비디오 번역 기능을 곧 중단할 예정입니다. 이 변경 사항은 단계적으로 적용되므로 일부 사용자는 현재 이 기능을 계속 사용할 수 있습니다. LiveVideoTranslationEnabled 정책은 향후 업데이트에서 더 이상 사용되지 않습니다.

웹 플랫폼 변경 사항

이번 업데이트는 CSS의 symbols(), margin-trim 등의 기능과 창 관리 API 확장을 포함한 여러 웹 플랫폼 변경 사항도 제공합니다. 해당 권한을 가진 웹 애플리케이션은 창 최대화, 최소화 및 복원을 제어할 수 있습니다.

보안

보안 측면에서 Microsoft는 Edge 155에 Chromium 프로젝트의 최신 보안 업데이트가 포함되었다고 밝혔습니다. 당시 공식 보안 설명 페이지에는 특정 CVE 번호가 아직 나열되지 않았습니다.

기타 변경 사항

또한 Edge 155는 웹 unload 이벤트 핸들러의 기본 비활성화 적용 범위를 100% 페이지 로드로 확대했습니다. Microsoft는 개발자들에게 페이지 수명 주기 관리에 적합한 대체 메커니즘으로 마이그레이션할 것을 권고했습니다.

총평

Microsoft Edge 155는 JPEG XL 이미지 디코딩 지원을 추가하고 AI 기반 탭 정리 기능을 강화하여 사용자 편의성을 높였습니다. 웹 플랫폼 기능이 확장되고 Chromium 프로젝트의 최신 보안 업데이트가 적용되었지만, 실시간 비디오 번역 기능은 중단될 예정입니다.

版本更新与核心信息

  • 微软于 10 月 8 日发布了桌面稳定版 Microsoft Edge 155 更新，完整版本号为 155.0.4283.45。

AI 增强的生产力功能

  • Edge 155 显著增强了 AI 标签页整理功能，不仅能建议如何分组标签页和工作区，还能推荐具体的组名称、视觉样式及标签。用户可在 edge://settings/privacy/services 中进行相关设置调整。

媒体与图像解码支持

  • 新版 Edge 支持解码 JPEG XL（image/jxl）图片格式。该格式的引入增强了浏览器对高级图像的支持，包括渐进式解码、广色域、高动态范围（HDR）、高位深及动画等内容。

网页平台与开发能力扩展

  • 本次更新支持多项前沿网页功能，包括 CSS 的 symbols () 和 margin-trim 等特性。
  • 窗口管理 API 得到扩展，具备相应权限的网页应用现在可以控制窗口的最大化、最小化和恢复操作。

安全与服务变更

  • **安全性：** Edge 155 纳入了 Chromium 项目的最新安全更新，增强了浏览器的整体防护能力。
  • **功能弃用：** 微软宣布将分阶段停止实时视频翻译功能，相关的 `LiveVideoTranslationEnabled` 策略将在未来版本中被弃用。
  • **开发者警告：** Edge 155 将网页 unload 事件处理器默认停用的覆盖范围扩大至 100% 页面加载，开发人员需迁移到适合页面生命周期管理的替代机制。

总结

Microsoft Edge 155 版本带来了多项重大更新，核心亮点包括增强的 AI 标签页整理功能和对 JPEG XL 等先进图像格式的支持。同时，该版本也扩展了网页平台能力（如 CSS 和窗口管理 API），并提醒开发者注意页面生命周期事件的处理方式，同时也预告了实时视频翻译功能的逐步淘汰。

主なアップデート

Microsoftは、10月8日にデスクトップ版のMicrosoft Edge 155安定版をリリースしました。バージョン番号は155.0.4283.45です。新バージョンでは、JPEG XL画像デコードのサポートが追加され、タブおよびワークスペースのスムーズな整理機能が拡張されています。

AI機能の強化

機能アップデートとして、Microsoft Edge 155はAIによるタブ整理機能を大幅に強化しました。単にタブやワークスペースをグループ化する方法を提供するだけでなく、グループ名、視覚的スタイル、タグまで推奨するようになりました。ユーザーは、edge://settings/privacy/servicesから関連設定を調整できます。

画像サポートの追加

新バージョンでは、JPEG XL（image/jxl）形式の画像をデコードできるようになりました。このフォーマットは、以下の高度な機能をサポートしており、ブラウザがこれらのコンテンツを直接表示するのに役立ちます。

  • プログレッシブデコーディング
  • 広色域 (Wide Color Gamut)
  • HDR（ハイダイナミックレンジ）
  • 高ビット深度およびアニメーション

リアルタイム翻訳機能の変更

リアルタイム翻訳に関して、Microsoftはまもなくリアルタイムビデオ翻訳機能を廃止する予定です。この変更は段階的に適用されるため、一部のユーザーは引き続き利用できる場合がありますが、今後のアップデートでLiveVideoTranslationEnabledポリシーは使用されなくなります。

ウェブプラットフォームの変更点

今回のアップデートには、CSSのsymbols()やmargin-trimなどの機能追加や、ウィンドウ管理APIの拡張を含む複数のウェブプラットフォームの変更が含まれています。これらの権限を持つWebアプリケーションは、ウィンドウの最大化、最小化、復元を制御できるようになります。

セキュリティ

セキュリティ面では、MicrosoftがEdge 155にChromiumプロジェクトの最新のセキュリティアップデートが組み込まれていると発表しました。なお、当時の公式なセキュリティ説明ページには、特定のCVE番号はまだ記載されていませんでした。

その他の変更点

また、Edge 155では、Webのアンロードイベントハンドラ（unload event handler）のデフォルトでの無効化適用範囲が、全ページの読み込み（100%ページローダー）に拡大されました。Microsoftは開発者に対し、ページライフサイクル管理に適した代替メカニズムへの移行を推奨しています。

まとめ

Microsoft Edge 155は、JPEG XL画像デコードのサポートを追加し、AIを活用したタブ整理機能の強化によりユーザー利便性を向上させました。ウェブプラットフォーム機能が拡張され、Chromiumプロジェクトによる最新セキュリティアップデートも適用されていますが、リアルタイムビデオ翻訳機能は廃止される予定です。

Key Updates

Microsoft released the stable version of Microsoft Edge for desktop on October 8th. The version number is 155.0.4283.45. This new version adds support for JPEG XL image decoding and expands smart organization features for tabs and workspaces.

Enhanced AI Features

In terms of functional updates, Microsoft Edge 155 enhances its AI tab organization capabilities. It now not only suggests ways to group tabs and workspaces but also recommends group names, visual styles, and tags. Users can adjust the relevant settings at edge://settings/privacy/services.

Image Support

The new version can decode JPEG XL (image/jxl) images. This format supports progressive decoding, wide color gamut, HDR (High Dynamic Range), high bit depth, and animation, which helps the browser directly display this image content.

Real-Time Translation Changes

Regarding real-time translation, Microsoft plans to discontinue its live video translation feature soon. Since this change will be implemented gradually, some users may still be able to use the function for now. The LiveVideoTranslationEnabled policy will no longer be used in future updates.

Web Platform Changes

This update also includes several web platform changes, such as support for CSS functions like symbols() and margin-trim, along with expanded Window Management APIs. Web applications with the necessary permissions can now control window maximization, minimization, and restoration.

Security

On the security front, Microsoft announced that Edge 155 includes the latest security updates from the Chromium project. At the time of writing, specific CVE numbers were not listed on the official security explanation page.

Other Changes

Additionally, Edge 155 expands the scope of default disabling for web unload event handlers to cover 100% of page loads. Microsoft recommends that developers migrate to alternative mechanisms suitable for page lifecycle management.

Summary

Microsoft Edge 155 improves user convenience by adding support for JPEG XL image decoding and enhancing AI-based tab organization features. While web platform functionality is extended and the latest Chromium security updates are applied, users should note that the real-time video translation feature will be discontinued.
