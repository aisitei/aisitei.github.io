iOS 27.0.1이 설치된 Apple iPhone 18 Pro, "완벽 탈옥" 성공: 재부팅 후에도 최고 권한 유지

2026-10-18

iOS 27.0.1 아이폰 18 Pro '완벽 탈옥' 시연

IT之家 10월 17일 소식, IT 매체 decrypt는 오늘(10월 17일) 블로그 게시물을 통해 어제(16일) 파리 Hexacon 공격 보안 컨퍼런스에서 보안 회사 Calif.io가 iOS 27.0.1 시스템이 설치된 iPhone 18 Pro 모델에서 "완벽 탈옥"을 공개적으로 시연했으며, 재부팅 후에도 최고 권한이 유지되었다고 보도했습니다.

IT之家 주: 탈옥(jailbreak)은 Apple의 iOS 서명 검증, 앱 샌드박스, 보호된 부팅 체인 등의 제한을 우회하여 사용자가 시스템 최고 권한을 얻고, 이를 통해 App Store 이외의 앱을 설치하고, 전체 파일 시스템에 접근하며, 시스템 인터페이스를 깊이 있게 맞춤 설정하고, 심지어 사전 설치된 소프트웨어를 삭제할 수 있도록 하는 것을 의미합니다.

컴퓨터에 다시 연결하거나 취약점을 다시 트리거해야 하는 일반적인 탈옥과 달리, "완벽 탈옥"(untethered jailbreak)은 장치 재부팅 후에도 탈옥 상태가 유지되는 것을 의미합니다.

현장 시연에서 연구원들은 휴대폰을 재부팅하고 일반 비밀번호로 잠금 해제한 후, root 사용자 권한으로 SSH 세션을 직접 열었으며, 터미널 정보는 시스템 버전이 iOS 27.0.1임을 확인했습니다.

해당 매체는 최신 iPhone의 보안 설계가 매우 복잡하여 공격자가 일반적으로 여러 취약점을 연결하여 먼저 앱 샌드박스를 탈출하고, 커널을 제어하며, 포인터 인증 코드와 같은 하드웨어 수준의 보호를 우회해야 한다고 지적했습니다. 또한 재부팅 후에도 권한을 유지하려면 Apple의 부팅 코드 검증에 대응해야 하므로 이번 시연이 많은 관심을 불러일으켰습니다.

그러나 대중은 당분간 이 탈옥을 직접 재현할 수 없습니다. Calif.io는 아직 이용한 취약점의 이름, 기술 세부 정보 또는 다운로드 가능한 도구를 공개하지 않았으며, 관련 내용은 "적절한 시기에 발표될 것"이라고만 밝혔습니다. 이 회사는 컨퍼런스 기간 동안 Signal 원클릭 공격 및 iMessage 관련 시연을 포함한 다른 프로젝트도 선보였습니다.

총평

보안 회사 Calif.io가 iOS 27.0.1이 설치된 iPhone 18 Pro에서 재부팅 후에도 최고 권한이 유지되는 '완벽 탈옥'을 시연했습니다. 이는 현대 iPhone의 복잡한 보안 설계를 고려할 때 매우 주목할 만한 성과입니다. 다만, 해당 취약점의 세부 정보나 도구는 아직 공개되지 않아 일반 사용자가 직접 재현할 수는 없습니다.

安全大会重大突破：完美越狱演示

科技媒体 decrypt 报道，在巴黎举行的 Hexacon 攻击性安全大会上，安全公司 Calif.io 公开展示了一次重大的 iOS 安全漏洞利用演示。

  • 事件时间与地点：10 月 16 日，巴黎 Hexacon 大会。
  • 演示设备与系统：一台运行 iOS 27.0.1 系统的 iPhone 18 Pro 机型。
  • 核心成果：成功展示了“完美越狱”（untethered jailbreak），即在设备重启后仍能维持最高权限（root 用户）。

技术细节与安全意义

此次演示的价值在于其极高的技术门槛，远超常规越狱。

  • “完美越狱”定义：指越狱状态在设备重启后依然存在，不同于需要重新连接电脑或再次触发漏洞的传统方式。
  • 现场验证：研究人员在演示中成功重启手机、使用密码解锁后，直接以 root 用户身份打开了 SSH 会话，并确认系统版本为 iOS 27.0.1。
  • 安全挑战性：该演示表明攻击者不仅需要串联多个漏洞（逃出沙盒、控制内核），更关键的是必须绕过 Apple 对启动代码的校验，以确保权限在重启后依然持久存在。

越狱技术背景知识

文章对“越狱”进行了专业定义，帮助读者理解此次事件的技术深度。

  • 越狱（Jailbreak）定义：突破 Apple 对 iOS 的签名校验、应用沙盒和受保护启动链等限制，使使用者获得系统最高权限。
  • 高权限带来的能力：包括安装非 App Store 应用、访问完整文件系统、深度定制系统界面以及删除预装软件等。

其他展示项目与后续计划

除了核心的越狱演示，Calif.io 在大会期间还展示了多个安全利用案例。

  • 其他演示内容：包括 Signal 一键攻击和 iMessage 相关漏洞演示。
  • 信息发布状态：目前公众无法自行复现该越狱；该公司尚未公布所利用的漏洞名称、技术细节或可下载工具，表示相关内容将在适当时候发布。

总结

Calif.io 在巴黎 Hexacon 大会上成功演示了在 iPhone 18 Pro (iOS 27.0.1) 上实现“完美越狱”，展示出极高的安全利用水平。此次突破的核心在于解决了权限持久化问题，即在设备重启后仍能维持 root 权限。该事件不仅提升了行业关注度，也再次凸显了现代移动操作系统复杂的安全防护机制和持续的漏洞挖掘价值。

iOS 27.0.1 iPhone 18 Proでの「完全脱獄」実演

IT之家が10月17日に報じたところによると、ITメディアのdecryptは、セキュリティ会社Calif.ioがパリで開催されたHexacon攻撃防御カンファレンス（10月16日）において、iOS 27.0.1がインストールされたiPhone 18 Proモデルで「完全脱獄」（untethered jailbreak）を公開実演したと伝えました。

このデモンストレーションでは、デバイスの再起動後も最高権限（root権限）が維持されることが確認されました。

技術的な背景：脱獄とは何か

IT之家は、まず「脱獄」（jailbreak）の概念を解説しています。これは、AppleによるiOS署名検証、アプリサンドボックス、保護されたブートチェーンといった制限を回避し、ユーザーがシステム最高権限を獲得することを意味します。

この権限を得ることで、以下のことが可能になります。

  • App Store以外からのアプリのインストール
  • 全ファイルシステムへのアクセス
  • システムのインターフェースの深いカスタマイズ
  • プリインストールされているソフトウェアの削除

一般的に脱獄は、コンピュータに再接続したり、脆弱性を再度トリガーしたりする必要がありますが、「完全脱獄」（untethered jailbreak）とは、デバイスを再起動した後も脱獄状態が維持されることを指します。

実演の内容と技術的意義

現地でのデモンストレーションでは、研究者たちは以下の手順を実行しました。

  • 携帯電話の再起動
  • 通常のパスワードによるロック解除
  • rootユーザー権限でのSSHセッションを直接開く

ターミナル情報から、システムのバージョンがiOS 27.0.1であることが確認されました。この実演は、現代iPhoneのセキュリティ設計がいかに複雑であるかを浮き彫りにしています。攻撃者は通常、複数の脆弱性を連結させる必要があり、まずアプリサンドボックスからの脱出を行い、カーネルを制御し、さらにはポインター認証コードのようなハードウェアレベルの保護を回避しなければなりません。

特に注目されたのは、再起動後も権限を維持するためにはAppleのブートコード検証に対応する必要がある点であり、この点が今回のデモンストレーションに大きな関心を集めました。

利用上の制限と今後の展望

しかしながら、一般ユーザーがこの脱獄をすぐに再現することはできません。Calif.ioは、使用した脆弱性の名称、技術的な詳細、またはダウンロード可能なツールをまだ公開しておらず、「適切な時期に発表される」と述べるに留まっています。

なお、同社はこのカンファレンス期間中、Signalのワンクリック攻撃やiMessage関連の実演を含む他のプロジェクトも披露しました。

まとめ

セキュリティ会社Calif.ioは、iOS 27.0.1が搭載されたiPhone 18 Proに対し、再起動後も最高権限を維持する「完全脱獄」のデモンストレーションを行いました。これは、現代の複雑なiPhoneのセキュリティ設計を考慮すると非常に画期的な成果です。ただし、使用された脆弱性の詳細やツールは未公開であり、現時点では一般ユーザーによる再現は不可能です。

iOS 27.0.1 iPhone 18 Pro 'Perfect Jailbreak' Demonstration

According to a report from IT之家 on October 17th, the tech media outlet decrypt reported that at the Hexacon security conference in Paris yesterday (October 16th), the security company Calif.io publicly demonstrated a "perfect jailbreak" on an iPhone 18 Pro model running iOS 27.0.1. The demonstration reportedly maintained root privileges even after rebooting.

IT之家 notes that jailbreaking refers to bypassing Apple's restrictions, such as iOS signature verification, app sandboxing, and the protected boot chain. This allows users to gain system root access, enabling them to install apps outside the App Store, access the entire file system, deeply customize system interfaces, and even delete pre-installed software.

Unlike typical jailbreaks that require reconnecting a computer or re-triggering a vulnerability, an "untethered jailbreak" means the jailbroken state persists even after the device is rebooted.

Demonstration Details

  • During the live demonstration, researchers rebooted the phone and unlocked it with a standard passcode.
  • They then opened an SSH session directly using root user privileges.
  • The terminal information confirmed that the system version was iOS 27.0.1.

The report highlighted that modern iPhone security design is extremely complex, requiring attackers to typically chain multiple vulnerabilities—first escaping the app sandbox, then controlling the kernel, and finally bypassing hardware-level protections like pointer authentication codes. The demonstration was particularly noteworthy because maintaining privileges after a reboot requires addressing Apple's boot code verification.

However, the public cannot replicate this jailbreak anytime soon. Calif.io has not yet disclosed the name of the vulnerability used, technical details, or downloadable tools, stating only that related information "will be announced in due course." During the conference, the company also showcased other projects, including a Signal one-click attack and iMessage-related demonstrations.

Summary

The security firm Calif.io demonstrated an "untethered jailbreak" on an iPhone 18 Pro running iOS 27.0.1, maintaining root privileges even after the device was rebooted. This achievement is highly significant given the complex security architecture of modern iPhones. However, because the specific vulnerabilities and tools used have not been disclosed, general users cannot replicate this process at this time.
