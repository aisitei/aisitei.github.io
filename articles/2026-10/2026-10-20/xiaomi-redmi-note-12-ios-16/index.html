Redmi Note 12 4G에 iOS 16 포팅 성공

IT之家 10월 19일 소식에 따르면, 한 네티즌 Makr가 Xiaomi Redmi Note 12 4G 스마트폰에 iOS 16 시스템을 성공적으로 포팅했다고 공유했습니다.

이는 테마, 런처 또는 에뮬레이터가 아니라 Apple의 오픈소스 XNU 커널(Apple이 Darwin 시스템에 사용하는 하이브리드 커널)과 iPhone X의 오리지널 사용자 인터페이스를 직접 이식한 것이라고 합니다. 시스템 설정의 "정보" 페이지에는 시스템 버전이 iOS 16.7.16, 모델은 iPhone X로 표시되며, 터치 및 볼륨 버튼 모두 정상적으로 작동합니다.

현재 이 프로젝트는 오픈소스화되었습니다(프로젝트 주소).

참고로, 2023년 3월 Xiaomi는 "third time's a charm"이라는 주제로 발표 행사를 개최하여 해외 사용자들에게 Redmi Note 12 시리즈 스마트폰을 선보였습니다. 이번에 해외 사용자들을 위해 출시된 Redmi Note 12 시리즈는 Redmi Note 12(4G 버전), Redmi Note 12 5G, Redmi Note 12 Pro, Redmi Note 12 Pro+의 네 가지 신제품으로 구성되었습니다.

이 중 Redmi Note 12는 6.67인치 FHD+ 해상도 디스플레이를 탑재하고 120Hz 주사율을 지원하며, Snapdragon 685 모바일 플랫폼과 5000mAh 배터리를 장착했고, 후면에는 5000만 화소 메인 카메라를 갖췄습니다. Redmi Note 12 5G는 전작과 기본 사양이 동일하며, 프로세서만 Snapdragon 4 Gen1 모바일 플랫폼으로 변경되었습니다.

IT之家의 이전 보도에 따르면, 개발자 j0sh1x는 10월 7일 복고풍 하드웨어 포팅 프로젝트를 공개하며 HTC HD2에서 iOS 7을 성공적으로 실행한 결과를 선보였고, 관련 XNU 커널 및 하드웨어 지원 코드를 공개했습니다. 공개된 정보에 따르면, 이 프로젝트는 현재 iOS 사용자 모드 구성요소를 HTC HD2에서 실행할 수 있으며, 터치스크린도 작동합니다.

系统移植与技术突破

  • 一位网友成功将一部Xiaomi Redmi Note 12 4G手机刷入了iOS 16系统，该项目已开源。
  • 此次移植并非简单的主题或模拟器，而是直接移植了Apple开源的XNU内核（用于Darwin系统的混合内核）和iPhone X的原版用户界面。
  • 成功运行的系统设置“关于本机”页面显示：系统版本号为iOS 16.7.16，机型为iPhone X，且触摸和音量键均能正常使用。
  • 此前，开发者j0sh1x曾在2023年公布了复古硬件移植项目，展示了在HTC HD2上成功运行iOS 7的成果，并公开了相关XNU内核及硬件支持代码，使iOS用户态组件和触摸屏得以工作。

文章展示了跨品牌、跨系统的技术移植能力，一位用户成功将iOS 16系统刷入Xiaomi Redmi Note 12 4G手机，使用了XNU内核和iPhone X的UI界面。此外，文章回顾了Redmi Note 12系列四款机型的核心参数，并提及了此前开发者在老旧硬件上移植操作系统的技术成果。

Redmi Note 12 4GへのiOS 16移植に成功

IT之家が10月19日のニュースで報じたところによると、あるネットユーザーのMakr氏が、Xiaomi Redmi Note 12 4Gスマートフォンに対してiOS 16システムを移植することに成功したと共有しました。

この移植は、単なるテーマやランチャー、エミュレーターによるものではなく、AppleがDarwinシステムで使用するハイブリッドカーネルであるオープンソースのXNUカーネルと、iPhone Xのオリジナルのユーザーインターフェースを直接移植したものです。システムの「情報」ページには、システムバージョンがiOS 16.7.16、モデルがiPhone Xとして表示され、タッチ操作やボリュームボタンも正常に機能することが確認されています。

このプロジェクトはオープンソース化されており、関連情報は公開されています。

iOS 16 Successfully Ported to Redmi Note 12 4G

According to a report on IT之家 dated October 19, a netizen named Makr shared that they successfully ported the iOS 16 system onto the Xiaomi Redmi Note 12 4G smartphone.

This was not achieved using themes, launchers, or emulators; rather, it involved directly porting Apple's open-source XNU kernel (the hybrid kernel used by Apple in the Darwin system) and the original user interface from the iPhone X. The device's "About" page displays the system version as iOS 16.7.16 and the model as iPhone X, and both the touch screen and volume buttons function normally.

The project has been open-sourced (project address).

Related Xiaomi Redmi Note 12 Series Information

For context, in March 2023, Xiaomi held a presentation event themed "third time's a charm," unveiling the Redmi Note 12 series smartphones to international users. The Redmi Note 12 series released for global markets includes four new models:

  • Redmi Note 12 (4G version)
  • Redmi Note 12 5G
  • Redmi Note 12 Pro
  • Redmi Note 12 Pro+

Among these, the Redmi Note 12 features a 6.67-inch FHD+ resolution display with 120Hz refresh rate support, is equipped with the Snapdragon 685 mobile platform and a 5000mAh battery, and has a 50MP main camera on the rear.

The Redmi Note 12 5G shares basic specifications with its predecessor, with only the processor changed to the Snapdragon 4 Gen1 mobile platform.

Previous Porting Efforts

In previous reports from IT之家, developer j0sh1x revealed a retro hardware porting project on October 7. The results showed successful execution of iOS 7 on the HTC HD2, and related XNU kernel and hardware support code were made public. According to the disclosed information, this project currently allows running iOS user mode components on the HTC HD2, including touchscreen functionality.

Summary

A netizen successfully ported iOS 16 onto a Xiaomi Redmi Note 12 4G using a direct port of Apple's XNU kernel and the iPhone X UI. The project is open-source and shows accurate system details like iOS 16.7.16 and an iPhone X model designation. This development follows previous successful hardware porting efforts, such as running iOS 7 on the HTC HD2.
