Apple iOS 27.2 베타 3의 새로운 기능: iPhone 18 Pro 등 다이내믹 아일랜드에서 주변 스마트 홈 제품 직접 제어 가능

2026-10-09

HomeKit 통합

Aaron Perris는 10월 6일 X 플랫폼을 통해 iOS 27.2 Beta 3 업데이트에서 Apple이 HomeKit에 새로운 코드를 도입하여 iPhone 18 Pro와 같은 모델 사용자가 다이내믹 아일랜드에서 주변 스마트 홈 액세서리를 직접 제어할 수 있게 되었다고 밝혔습니다.

새로운 HomeKit 코드에는 "근접 관리자(proximity manager)"가 포함되어 있어, 사용자가 호환되는 스마트 홈 장치에 가까이 가면 다이내믹 아일랜드에 관련 제어 옵션이 자동으로 표시됩니다. 사용자는 "홈" 앱을 열 필요 없이 다이내믹 아일랜드에서 조명, 온도 등 홈 설정을 빠르게 조절할 수 있습니다.

기술 분석가 Aaron (@aaronp613)은 X 플랫폼에서 이 기능의 AI 시뮬레이션 효과를 공유하며 다이내믹 아일랜드가 스마트 홈 제어 인터페이스를 어떻게 표시하는지 보여주었습니다.

Apple TV 기능

정보원 @itspdfu는 Apple TV에 대한 관련 정보도 공유했습니다. 사용자는 이모티콘 외에도 Apple TV 드라마 및 영화의 캐릭터를 선택할 수 있을 것으로 보입니다. 관련 캐릭터에는 《테드 래소》의 테드 래소와 《세브란스: 단절》의 마크 S가 포함됩니다.

총평

iOS 27.2 Beta 3 업데이트를 통해 Apple은 HomeKit 기능을 강화하여 iPhone 18 Pro 사용자가 다이내믹 아일랜드에서 스마트 홈 기기를 더욱 편리하게 제어할 수 있게 됩니다. 또한 Apple TV는 이모티콘 외에 드라마 및 영화 캐릭터를 선택할 수 있는 새로운 기능을 추가할 예정입니다.

移动操作系统与生态系统更新

  • HomeKit智能家居集成：消息源爆料，在iOS 27.2 Beta 3版本中，Apple为HomeKit引入了新的“近距离管理器”（proximity manager）代码。该功能允许iPhone 18 Pro等机型用户直接在灵动岛上控制附近的兼容智能家居配件，无需打开“家庭”App即可快速调节灯光、温度等设置。
  • Apple TV娱乐体验增强：除了表情符号外，用户现在可以在Apple TV中选择剧集和电影中的角色进行互动。分享的示例包括《Ted Lasso》中的Ted Lasso以及《Severance》中的Mark S。

关键技术规格与功能亮点

  • HomeKit新机制：新增“近距离管理器”，实现用户靠近智能家居设备时，灵动岛自动显示相关控制选项。
  • 兼容机型示例：适用于iPhone 18 Pro等支持动态岛的Apple设备。

总结

本次爆料主要聚焦于iOS 27.2 Beta 3版本中的两大新特性。核心亮点是HomeKit功能深度集成至灵动岛，通过“近距离管理器”实现了更便捷、无需打开App的智能家居控制体验。此外，Apple TV也升级了角色互动功能，极大地丰富了用户在娱乐内容消费时的交互乐趣。

HomeKitの統合

Aaron Perris氏が10月6日にXプラットフォームを通じて、AppleがiOS 27.2 Beta 3アップデートでHomeKitに新しいコードを導入したと発表しました。これにより、iPhone 18 Proなどのモデルを使用しているユーザーは、Dynamic Islandから周辺のスマートホームアクセサリーを直接制御できるようになります。

この新しいHomeKit機能には「近接管理（proximity manager）」が組み込まれており、ユーザーが対応するスマートホームデバイスに近づくと、関連する制御オプションがDynamic Island上に自動的に表示されます。これにより、ユーザーは「ホーム」アプリを開くことなく、照明や温度などのホーム設定をDynamic Islandから迅速に調整することが可能になります。

技術アナリストのAaron氏（@aaronp613）は、Xプラットフォーム上でこの機能のAIシミュレーション効果を共有し、Dynamic Islandがスマートホーム制御インターフェースをどのように表示するかを実演しました。

Apple TVの新機能

情報源である@itspdfuからは、Apple TVに関する関連情報も共有されています。ユーザーは絵文字だけでなく、Apple TVのドラマや映画のキャラクターを選択できるようになる見込みです。具体的な例としては、『テッド・ラッソ』のテッド・ラッソや、『セレバンス：断絶』のマークSなどが挙げられています。

まとめ

iOS 27.2 Beta 3アップデートにより、AppleはHomeKit機能を大幅に強化し、iPhone 18 ProなどのユーザーがDynamic Islandからより便利にスマートホーム機器を制御できるようになります。また、Apple TVには絵文字機能に加え、ドラマや映画のキャラクターを選択できる新しい機能が追加される予定です。

HomeKit Integration

Aaron Perris announced via X platform on October 6th that Apple has introduced new code for HomeKit in the iOS 27.2 Beta 3 update, allowing users of models like the iPhone 18 Pro to directly control surrounding smart home accessories from the Dynamic Island.

The new HomeKit code includes a "proximity manager," which automatically displays relevant control options on the Dynamic Island when the user gets near compatible smart home devices. This allows users to quickly adjust home settings, such as lighting and temperature, directly from the Dynamic Island without needing to open the "Home" app.

Tech analyst Aaron (@aaronp613) shared an AI simulation effect of this feature on X platform, demonstrating how the Dynamic Island can display a smart home control interface.

Apple TV Features

Sources also shared related information regarding Apple TV. It appears that users will be able to select characters from Apple TV dramas and movies, in addition to emojis. Featured characters include Ted Lasso from "Ted Lasso" and Mark S from "The Savantes: Severance."

Summary

With the iOS 27.2 Beta 3 update, Apple is enhancing HomeKit functionality, enabling iPhone 18 Pro users to control smart home devices more conveniently directly from the Dynamic Island. Additionally, Apple TV will introduce a new feature allowing users to select characters from dramas and movies, expanding beyond just emojis.
