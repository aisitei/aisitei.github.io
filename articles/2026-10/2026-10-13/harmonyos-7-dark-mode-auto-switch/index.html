Huawei 📱 스마트폰

HarmonyOS 7, 또 다른 인기 기능 추가: Huawei Pura X View 스마트폰 "109" 버전, 일출/일몰에 따른 다크 모드 자동 전환 지원

2026-10-13

업데이트 내용

Huawei는 최근 Pura X View 스마트폰에 HarmonyOS 7.0.0.109 SP10 업데이트를 선제적으로 배포했습니다. 약 4.83GB 용량의 이번 업데이트는 다인원 상호 협력 통신 공유, 화면 꺼짐 추적 내비게이션 등의 기능을 제공합니다.

IT之家의 테스트 결과, 공식 업데이트 로그 외에도 사용자들이 오랫동안 요청했던 기능인 '일출 및 일몰에 따른 다크 모드 자동 전환' 기능이 추가된 것을 확인했습니다.

참고로, Huawei HarmonyOS는 이전부터 이 기능을 지원했지만, 시스템 설정에 직접 포함되지 않고 사용자가 스마트 라이프 앱의 "장면" 기능을 통해 직접 설정해야 했습니다. 이러한 조작의 어려움 때문에 많은 사용자가 이 기능이 시스템 설정에 내장되기를 희망했습니다.

현재 시스템 설정 내 일출 및 일몰에 따른 다크 모드 자동 전환 기능은 모든 기종에 전면적으로 적용되지 않았습니다. 다른 기종의 사용자들은 에디터가 정리한 "장면" 설정을 참고하여 스마트 라이프 앱에서 이 기능을 경험할 수 있습니다.

총평

Huawei Pura X View는 HarmonyOS 7.0.0.109 SP10 업데이트를 통해 다인원 통신 공유 및 화면 꺼짐 내비게이션 등 새로운 기능을 선보였습니다. 특히, 사용자들이 오랫동안 요청했던 일출 및 일몰에 따른 다크 모드 자동 전환 기능이 시스템 설정에 통합되어 사용자 편의성이 향상되었습니다. 이 기능은 현재 일부 기종에만 적용되었으며, 다른 기종 사용자들은 스마트 라이프 앱을 통해 설정할 수 있습니다.

新增核心功能亮点

新版本带来了多项实用功能，包括：

  • 多人互助通信共享功能。
  • 熄屏循迹导航等增强体验。

用户关注的深色模式优化

文章重点讨论了用户呼声极高的“深色模式随日出日落自动切换”特性。

  • 该功能在 HarmonyOS 系统中此前是支持的，但目前尚未直接内置于系统设置。
  • 用户需要通过智慧生活 App 的“场景”功能进行自定义设置，操作门槛较高，导致部分用户希望该功能能全量上线到系统设置中。
  • 目前，系统设置中的深色模式随日出日落自动切换功能尚未全面开放给所有机型用户。

总结

本次 HarmonyOS 7.0.0.109 SP10 版本升级为 Pura X View 带来了多人互助通信和熄屏循迹导航等新功能。同时，文章也指出了深色模式随日出日落自动切换这一高需求特性目前仍需通过智慧生活 App 的“场景”进行复杂设置，尚未实现系统级的全量化便捷体验。

更新内容

Huaweiは最近、Pura X Viewスマートフォン向けにHarmonyOS 7.0.0.109 SP10のアップデートを先行配信しました。容量約4.83GBとなる今回のアップデートでは、「複数人との協働通信共有」や「画面オフ追跡ナビゲーション」といった機能が提供されています。

IT之家によるテストの結果、公式な更新ログに記載されている機能に加え、ユーザーから長年要望されていた「日の出・日没に合わせたダークモード自動切り替え」機能が追加されたことが確認されました。

なお、Huawei HarmonyOSはこの機能以前からサポートしていましたが、システム設定内に直接組み込まれておらず、ユーザーはスマートライフアプリの「シーン」機能を通じて手動で設定する必要がありました。この操作性の難しさから、多くのユーザーがシステム設定への内蔵を望んでいました。

現在、システム設定内の日の出・日没に合わせたダークモード自動切り替え機能は、全ての機種に完全に適用されているわけではありません。他の機種のユーザーは、エディターがまとめた「シーン」設定などを参考にし、スマートライフアプリからこの機能を利用することができます。

Update Details

Huawei has proactively rolled out the HarmonyOS 7.0.0.109 SP10 update for the Pura X View smartphone. This update, which has a size of approximately 4.83GB, introduces features such as multi-person collaborative communication sharing and screen-off tracking navigation.

According to IT之家's testing results, in addition to the official update log, users confirmed the addition of 'automatic dark mode switching based on sunrise and sunset,' a feature that has been long requested by the community.

It is worth noting that while Huawei HarmonyOS previously supported this function, it was not directly included in the system settings. Instead, users had to set it up manually through the "Scene" feature within the Smart Life app. Due to the difficulty of this setup process, many users hoped for its integration into the core system settings.

Currently, the automatic dark mode switching based on sunrise and sunset function in the system settings has not been fully applied across all device models. Users with other devices can experience this feature by referencing the "Scene" settings compiled by editors within the Smart Life app.

Overall Review

The Huawei Pura X View introduces new features, such as multi-person communication sharing and screen-off navigation, through the HarmonyOS 7.0.0.109 SP10 update. Notably, the automatic dark mode switching based on sunrise and sunset—a feature long requested by users—has been integrated into the system settings, significantly improving user convenience. While this function is currently only applied to select devices, owners of other models can set it up using the Smart Life app.

Summary

Huawei released HarmonyOS 7.0.0.109 SP10 for the Pura X View, adding features like multi-person collaborative communication and screen-off tracking navigation. The most significant update is the integration of automatic dark mode switching based on sunrise/sunset into system settings, greatly improving usability. Although this feature is currently limited to certain devices, users with other models can still access it via the Smart Life app's "Scene" function.
