새로운 단축어 기능 업데이트

Apple은 9월 29일 지원 문서를 업데이트하여 iOS 27, iPadOS 27, macOS 27 등의 시스템에서 '단축어(Shortcuts)' 앱에 35개 이상의 개선 및 신규 작업을 추가했습니다.

이번 업데이트의 가장 큰 특징은 '모델 사용(Use Model)' 명령에 집중되어 있으며, 향상된 Apple Intelligence 모델을 호출하고 네트워크를 통해 단축어 내 모든 콘텐츠의 최신 정보를 가져올 수 있습니다.

총평

Apple은 iOS, iPadOS, macOS용 단축어 앱에 35개 이상의 새로운 기능과 개선 사항을 추가했습니다. 특히 '모델 사용' 명령을 통해 향상된 Apple Intelligence 모델을 활용하고 네트워크에서 최신 정보를 가져올 수 있게 되었습니다. 또한, 복잡한 논리 구성, Markdown 지원, 그룹 메시지 전송 등 다양한 편의 기능이 추가되어 사용자 경험이 크게 향상될 것으로 보입니다.

操作系统与AI核心功能增强

  • “使用模型”（Use Model）指令：可调用增强版 Apple 智能模型，并能通过网络获取快捷指令中的最新信息。
  • 逻辑构建升级：“如果”现在支持“否则如果”，用于创建更复杂的自动化逻辑。
  • 自然语言描述能力：用户可以使用自然语言来描述和创建快捷指令（适用于 iOS、iPadOS 和 macOS）。
  • 自动化集成与同步：自动化功能已直接集成到快捷指令中，包括共享的快捷指令，并可在设备间同步。

通讯与信息管理优化

  • “发送信息”支持向群聊发送消息。
  • “查找信息”现在可以按发送者进行筛选。
  • 通知功能新增：增加了“当我收到来自‘新闻’的通知时”等触发条件。
  • 信息清理操作增强：新增了“删除对话”、“打开收件箱”以及在“信息”App 中搜索的功能。

内容提取与媒体处理能力

  • 照片管理升级：增加了“自动增强照片”、“隐藏照片”和“将项目添加到列表”等功能，并支持查找、删除相簿。
  • 文本识别增强：“从图像中提取文本”现在可以从图像中提取表格或列表信息。
  • 多格式数据处理：新增了“扫描二维码或条形码”功能，可以直接处理文件（适用于 iOS、iPadOS 和 macOS）。
  • 屏幕内容获取优化：改进后的“获取屏幕上的内容”会返回结构更清晰的屏幕内容信息。

系统环境与网络交互

  • 位置服务增强：新增了引用用户家庭和工作地点的能力（适用于 iOS、iPadOS 和 visionOS）。
  • 行程规划升级：“获取行程时间”增加了“避开收费站”和“避开高速公路”的选项。
  • 网络信息获取：新增了“获取网络详细信息”，支持以太网接口；并可查找当前 VPN 或获取已存储内容。
  • 音量控制扩展：现在可以设置闹钟、计时器和系统声音的音量（适用于 iOS 和 iPadOS）。

生产力与组织工具增强

  • 备忘录支持Markdown：新增了“创建备忘录”和“在备忘录中追加文本”功能，均支持 Markdown 格式。
  • 列表管理优化：增加了“编辑列表”、“创建群组/分区”以及相应的删除操作。
  • 键盘与截屏触发：新增了基于“当我的键盘连接时”（适用于 iOS 和 iPadOS）和“当截屏存储时”（适用于 iOS、iPadOS 和 macOS）的自动化触发条件。

总结

Apple为iOS 27、iPadOS 27和macOS 27更新了“快捷指令”应用，集成了超过35项操作改进。本次升级的核心亮点是深度整合增强版 Apple 智能模型（Apple Intelligence），使自动化流程能够获取实时网络信息并具备更强的逻辑判断能力。通过优化内容处理、系统环境感知以及生产力工具，极大地提升了用户利用快捷指令进行日常任务自动化的效率和广度。

Appleは、サポートドキュメントを更新し、iOS 27、iPadOS 27、macOS 27などのシステムにおいて、「ショートカット（Shortcuts）」アプリに35以上の改善点と新規アクションを追加しました。

今回のアップデートの最大の焦点は「モデルの使用（Use Model）」コマンドにあり、強化されたApple Intelligenceモデルを呼び出し、ネットワーク経由でショートカット内のすべてのコンテンツの最新情報を取得できるようになります。

New Shortcuts Feature Updates

Apple updated its support documentation on September 29th, adding over 35 improvements and new actions to the 'Shortcuts' app across systems like iOS 27, iPadOS 27, and macOS 27.

The most significant feature of this update focuses on the "Use Model" command. This allows users to call enhanced Apple Intelligence models and retrieve the latest information from all content within Shortcuts via a network connection.

Below is a list of related improvements and new actions:

  • Notifications (When receiving notifications in "News")
  • Keyboard (When connected, for iOS and iPadOS)
  • Screenshots (When saved, for iOS, iPadOS, and macOS)
  • "Send Tabback"
  • "Mark as Read"
  • "Delete Message"
  • "Delete Conversation"
  • "Open Inbox"
  • "Search in Messages App"
  • "Edit List"
  • "Create Group"
  • "Delete Group"
  • "Create Section"
  • "Delete Section"
  • "Get Current VPN"
  • "Find VPN"
  • "Get Saved Content"
  • "Save Content"
  • "Delete Saved Content"
  • "Add Item to List"
  • "Get Selected Text"
  • "Set Photo as Favorite"
  • "Hide Photo"
  • "Auto-Enhance Photo"
  • "Find Album"
  • "Delete Album"
  • "Open Photo"
  • "Use Model" supports enhanced Apple Intelligence models. *
  • "Use Model" can now retrieve the latest information via a network connection. *
  • "If" now supports "Otherwise If," allowing for complex logic construction.
  • "Create Note" and "Add Text to Note" now support Markdown.
  • "Add Text to Note" can now add text or insert it at the beginning of a specific section within a note.
  • "Send Message" now supports sending messages in group chats.
  • "Find Message" can now be filtered by sender.
  • "Get Screen Content" now returns more clearly structured screen content information.
  • "Extract Text from Image" can now extract tables or lists from an image.
  • "Scan QR Code or Barcode" can now process files directly (for iOS, iPadOS, and macOS).
  • "Set Volume" can now set the volume for alarms, timers, and system sounds (for iOS and iPadOS).
  • "Get Network Details" now supports Ethernet interfaces.
  • "Location" can now reference the user's home and work locations (for iOS, iPadOS, and visionOS).
  • "Get Route Time" has added "Avoid Toll Roads" and "Avoid Highways" options (for iOS, iPadOS, and visionOS).
  • Create Shortcuts using natural language descriptions (for iOS, iPadOS, and macOS) *.
  • Automation functionality is now directly integrated into Shortcuts, including shared shortcuts.
  • Automation functionality now syncs across devices.
  • Existing shortcuts are automatically summarized with Apple Intelligence features in the Shortcuts editor. *

The asterisk (*) symbol on this article indicates that some Apple Intelligence features are not yet available in all countries and regions, and that Siri AI remains in beta status on systems like iOS 27.

Summary

Apple has significantly updated the Shortcuts app for iOS, iPadOS, and macOS by adding over 35 new actions. Key enhancements include the "Use Model" command, which leverages enhanced Apple Intelligence models to fetch real-time network data. Furthermore, users benefit from improved logic construction (e.g., 'Otherwise If'), Markdown support in notes, and expanded functionality for messaging, photos, and location services.
