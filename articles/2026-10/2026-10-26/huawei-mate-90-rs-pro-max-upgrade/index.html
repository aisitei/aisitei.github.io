Huawei Mate 90 RS/Pro Max 컬렉션 에디션 HarmonyOS 7.0.0.111SP13 업그레이드, Xunying Z10 모듈 카메라 연결 최적화

2026-10-26

시스템 업데이트

Huawei Mate 90 RS Ultimate Design 및 Mate 90 Pro Max Collector's Edition에 HarmonyOS 7.0.0.111SP13 버전 업데이트가 배포되었습니다. 시스템 패키지 크기는 약 722.38MB이며, 스마트 사진 편집 기능 중 인물 사진 추천 기능이 업그레이드되어 편집 후 정밀 보정 효과를 2차 조정할 수 있습니다. 또한, MeeTime에서 대면 빠른 그룹 생성을 지원합니다.

Huawei Mate 90 RS Ultimate Design 및 Mate 90 Pro Max Collector's Edition의 이번 업데이트 내용은 다음과 같습니다.

  • 스마트 사진 편집 기능 중 인물 사진 추천 기능이 업그레이드되어 편집 후 정밀 보정 효과를 2차 조정할 수 있습니다.
  • 대면 빠른 그룹 생성을 지원합니다. 주변 친구들과 동일한 그룹 입장 코드를 선택하거나 '탭하여 초대' 기능을 통해 빠르게 동일한 그룹 채팅에 참여할 수 있습니다 (참여하는 모든 기기가 해당 기능을 지원해야 합니다).
  • 불꽃놀이 촬영, 망원 등 특정 시나리오에서 카메라 촬영 안정성을 최적화하여 이미지 품질 및 촬영 경험을 향상시켰습니다.
  • 일부 데스크톱 시나리오의 안정성을 최적화했습니다.
  • Xiaoyi 입력기 키보드 입력 경험을 최적화했습니다.
  • 통신 공유 장치 연결 경험을 최적화했습니다.
  • 전체 시스템 안정성을 최적화하여 장치 작동을 더욱 안정적으로 만들었습니다.
  • 시스템 확장 기능을 동기화하여 업데이트하고, 기능 특성을 강화하며, 사용자 경험을 향상시켰습니다.

이번 Mate 90 RS / Pro Max Collector's Edition의 새 버전 업데이트 로그는 이전에 Mate 90 시리즈 휴대폰에 일괄 배포된 "7.0.0.111 SP12" 버전과 동일합니다. 그러나 사용자 피드백에 따르면, 이 버전은 Huawei Ruijing Z10 모듈 카메라와의 연결 경험을 실제로 최적화했습니다. 이전에는 일부 사용자들이 111 SP12 버전 업데이트 후 Ruijing Z10에 연결할 수 없다는 피드백을 제공했습니다 (확률적으로 재현됨).

이전 보도에 따르면, Huawei Ruijing Z10 모듈 카메라는 코드명 "King Kong"으로, Hongfeng 등 다양한 센서를 통합하고 휴대폰 SoC와의 협업을 지원합니다. 소프트웨어, 하드웨어, 칩 AI 협업 및 지능형 융합 AF를 통해 빠르고 정확하며 안정적인 AF를 구현합니다. 또한, 독립적인 광학 손떨림 보정 모듈을 탑재하고 Kirin 칩과 협업하여 플래그십 수준의 손떨림 보정 경험을 제공합니다.

총평

이번 HarmonyOS 7.0.0.111SP13 업데이트는 Huawei Mate 90 RS Ultimate Design 및 Mate 90 Pro Max Collector's Edition 사용자에게 스마트 사진 편집 기능 개선, MeeTime 그룹 채팅 기능 추가, 카메라 안정성 향상 등 다양한 최적화를 제공합니다. 특히 Huawei Ruijing Z10 모듈 카메라와의 연결 안정성 개선은 이전 버전에서 발생했던 문제를 해결하여 사용자 경험을 크게 향상시킬 것으로 기대됩니다.

系统版本升级与设备范围

  • 本次更新推送给的机型为 Huawei Mate 90 RS 非凡大师和 Mate 90 Pro Max 典藏版。
  • 新版本为 HarmonyOS 7.0.0.111SP13，系统包大小约为 722.38MB。

摄影与影像功能增强

  • **智慧修图能力升级：** 提升了人像大片的主动推荐能力，并支持用户在修图后进行二次调节精修效果。
  • **拍摄稳定性优化：** 针对烟花和长焦等场景进行了相机优化，旨在提升成像质量与整体拍摄体验。

社交与系统交互优化

  • **快速建群功能：** 支持当面快速建立群聊，用户可以通过选择相同的进群口令或使用“碰一碰”邀请的方式快速进入同一群组（参与方需支持该功能）。
  • **桌面及输入法体验：** 优化了桌面部分场景的稳定性，并提升了小艺输入法键盘的操作体验。
  • **连接与稳定优化：** 优化了通信共享设备连接体验，并对整机系统进行了全面的稳定性优化。

专业模块兼容性与技术细节

本次更新版本与此前 Mate 90 系列手机统一推送的“7.0.0.111 SP12”版本保持一致，但特别解决了用户反馈的睿影 Z10 模块连接问题。

  • **Huawei 睿影 Z10 模块（代号“金刚”）兼容性增强：** 更新优化了与该专业相机模块的连接体验。
  • **Z10 核心技术：** 该模块集成了红枫等多种传感器，支持通过软硬芯 AI 协同和智能融合对焦，实现快速、准确、稳定的对焦；同时具备独立光学防抖（OIS）模块，可与麒麟芯片协同，提供旗舰级的防抖体验。

总结

本次 HarmonyOS 7.0.0.111SP13 版本升级主要聚焦于提升用户日常使用和专业拍摄的流畅度与稳定性。除了增强了智慧修图能力和支持当面快速建群等功能外，更重要的是解决了关键配件如 Huawei 睿影 Z10 模块的连接兼容性问题，确保了高端影像体验的持续稳定。

System Update

A HarmonyOS 7.0.0.111SP13 update has been rolled out to the Huawei Mate 90 RS Ultimate Design and Mate 90 Pro Max Collector's Edition. The system package size is approximately 722.38MB. Key enhancements include an upgraded smart photo editing feature that allows for secondary adjustments to precise correction effects after editing, as well as support for quick in-person group creation within MeeTime.

The specific details of this update for the Huawei Mate 90 RS Ultimate Design and Mate 90 Pro Max Collector's Edition are as follows:

  • The smart photo editing feature has been upgraded, allowing users to make secondary adjustments to precise correction effects after editing a portrait.
  • Supports quick in-person group creation. Users can quickly join the same group chat by selecting an existing group entry code with nearby friends or using the 'Tap to Invite' function (all participating devices must support this feature).
  • Optimized camera shooting stability and improved image quality/shooting experience for specific scenarios, such as fireworks photography and telephoto shots.
  • Improved stability for some desktop scenarios.
  • Optimized the input experience for the Xiaoyi IME keyboard.
  • Optimized the connection experience for communication sharing devices.
  • Overall system stability has been optimized to make device operation more reliable.
  • Synchronized system extensions, enhancing feature characteristics and improving user experience.

The update log for this new version of the Mate 90 RS / Pro Max Collector's Edition is identical to the "7.0.0.111 SP12" version previously rolled out across the Mate 90 series phones. However, according to user feedback, this version specifically optimizes the connection experience with the Huawei Ruijing Z10 module camera. Previously, some users reported connectivity issues with the Ruijing Z10 after updating to the 111 SP12 version (reproducible probabilistically).

Previous reports indicated that the Huawei Ruijing Z10 module camera is code-named "King Kong." It integrates various sensors, such as Hongfeng, and supports collaboration with the phone's SoC. It achieves fast, accurate, and stable AF through cooperation between software, hardware, chip AI, and intelligent fusion AF. Furthermore, it is equipped with an independent Optical Image Stabilization module and collaborates with the Kirin chip to provide a flagship-level stabilization experience.

Summary

This HarmonyOS 7.0.0.111SP13 update provides multiple optimizations for Huawei Mate 90 RS Ultimate Design and Mate 90 Pro Max Collector's Edition users, including enhanced smart photo editing, new MeeTime group chat functionality, and improved camera stability. Crucially, the update addresses connectivity issues with the Huawei Ruijing Z10 module camera that were reported in previous versions, significantly enhancing the overall user experience.
