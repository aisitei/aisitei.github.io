"글로벌 2위 이미지 편집 AI 모델": Microsoft MAI-Image-2.7-Preview 공개, Google, Meta, xAI 압도

2026-10-29

소개

Microsoft는 10월 27일 MAI-Image-2.7-Preview 모델을 출시했다고 발표했습니다. Microsoft AI CEO 무스타파 술레이만(Mustafa Suleyman)은 "MAI-Image가 이제 전 세계 이미지 편집 모델 중 2위를 차지했습니다!"라고 밝혔습니다.

술레이만은 트위터를 통해 Artificial Analysis의 이미지 편집 순위에서 Microsoft의 MAI-Image 시리즈 모델이 Google, Meta, xAI, GPT-Image-2.5-Flare를 다시 한번 제치고 전 세계 이미지 편집 모델 중 2위에 올랐다고 언급했습니다. 이 모델은 OpenAI의 GPT Image 2.5 Sunburst (max) 다음으로 높은 순위를 기록했습니다.

기능 및 특징

MAI-Image-2.7-Preview 모델은 현재 "원본 이미지 + 텍스트 명령 → 편집된 이미지 출력" 기능을 중점적으로 제공하며, 텍스트-이미지 생성 기능은 아직 공개되지 않았습니다. 이 모델은 기존 사진, 디자인 시안, 스크린샷 또는 영상 자료를 제어하여 편집하는 데 특화되어 있습니다.

Microsoft는 이 모델이 전체 스타일 변경, 조명 재조정, 화면 내 텍스트/기호 수정, 자료 복구 및 강화, 그리고 사물, 빛, 환경 간의 관계를 이해해야 하는 복잡한 편집과 같이 "수정하기 어려운" 작업을 처리할 수 있다고 강조했습니다.

성능 향상

Microsoft에 따르면, MAI-Image-2.7은 이전 세대인 MAI-Image-2.6에 비해 Artificial Analysis가 평가한 10가지 모든 사용 사례와 7가지 편집 작업에서 성능이 향상되었습니다. 특히 강화 복구, 추론 편집, 장면 스타일, 텍스트 기호의 네 가지 범주에서 최첨단 수준에 도달했습니다.

장면 및 스타일 편집 분야에서 가장 큰 폭의 개선을 보였으며, 차순위 모델보다 24 Elo 포인트 더 높았습니다. Artificial Analysis의 AA-Image-Editing v2.1 순위에서 이 모델은 1,193 Elo 포인트로 2위를 차지했으며, OpenAI의 GPT Image 2.5 Sunburst (max) 다음입니다.

접근성 및 향후 계획

사용자들은 현재 Arena, Artificial Analysis, MAI Playground에서 이 모델을 경험할 수 있으며, 현재는 이미지 편집 기능만 제공됩니다. Microsoft는 텍스트-이미지 생성 기능이 "곧 출시될 것"이라고 밝혔지만, 구체적인 날짜는 공개하지 않았습니다.

이 모델은 현재 Preview 버전이며, Microsoft는 아직 공개 API, 가격 책정 및 공식 상용화 시기를 발표하지 않았습니다. 모델 가중치도 공개되지 않아 자체 호스팅은 불가능합니다. Playground의 지역별 가용성도 제한될 수 있습니다.

총평

Microsoft의 MAI-Image-2.7-Preview는 Artificial Analysis 순위에서 전 세계 이미지 편집 모델 중 2위를 차지하며 뛰어난 성능을 입증했습니다. 이 모델은 기존 이미지의 복잡한 편집 작업에 특화되어 있으며, 특히 스타일 변경, 조명 재조정, 텍스트 수정 등에서 큰 개선을 보였습니다. 현재는 미리보기 버전으로 제공되며, 텍스트-이미지 생성 기능과 상용화 계획은 추후 공개될 예정입니다.

模型核心定位与行业排名

  • 微软发布了 MAI-Image-2.7-Preview 模型，并宣布其为全球排名的图像编辑模型第二名。
  • 据报道，该模型在 Artificial Analysis 的图像编辑榜上击败了 Google、Meta、xAI 和 GPT-Image-2.5-Flare 等竞争对手。
  • MAI-Image-2.7 目前仅次于 OpenAI 的 GPT Image 2.5 Sunburst (max)。

模型功能与应用场景

  • 该模型目前主打“输入原图 + 文字指令 $\rightarrow$ 输出编辑后的图片”，是一个面向已有照片、设计稿、截图或影视素材的**可控编辑模型**。
  • 它强调处理复杂的图像编辑任务，包括：整体换风格、重新打光、修改画面中的文字/符号、修复增强素材，以及理解物体、光线与环境关系的复杂编辑。

性能提升与技术指标

  • 相较于上一代 MAI-Image-2.6，MAI-Image-2.7 在 Artificial Analysis 的全部 10 个用例和 7 类编辑动作中均有提升。
  • 模型在增强修复、推理编辑、场景风格和文字符号四类达到了品类前沿水平。
  • 在场景与风格编辑方面，其领先幅度最大，比次优模型高出 24 个 Elo。
  • 在 AA-Image-Editing v2.1 榜单上，MAI-Image-2.7 以 1,193 Elo 排第 2 位。

使用与商业化限制

  • 用户目前可在 Arena、Artificial Analysis 和 MAI Playground 等平台体验该模型。
  • 微软表示文生图功能“即将推出”，但尚未公布具体日期。
  • 请注意，MAI-Image-2.7 目前仍是 Preview 版本，尚未公布公开 API、定价和正式商用时间；模型权重也未开放，无法自托管。

总结

微软发布的 MAI-Image-2.7-Preview 模型是一款强大的图像编辑工具，目前在行业内排名第二，擅长处理复杂且需要理解物理关系（如光线、环境）的精细化编辑任务。虽然其功能强大，但用户当前只能体验图像编辑功能，文生图和正式商用 API 等服务尚未开放。

概要

Microsoftは、MAI-Image-2.7-Previewモデルを10月27日にリリースしたと発表しました。Microsoft AI CEOのMustafa Suleyman氏によると、このMAI-Imageシリーズは、世界の画像編集モデルの中で第2位にランクインしています。

Suleyman氏はTwitterを通じて、Artificial Analysisによる画像編集ランキングにおいて、MAI-ImageシリーズがGoogle、Meta、xAI、GPT-Image-2.5-Flareを抑え、世界トップクラスの性能を誇ることを明らかにしました。このモデルは、OpenAIのGPT Image 2.5 Sunburst (max)に次ぐ高順位を記録しています。

機能と特徴

MAI-Image-2.7-Previewモデルが現在重点的に提供しているのは、「元の画像 + テキストコマンド → 編集された画像出力」という機能です。なお、テキストから画像を生成する機能はまだ公開されていません。

このモデルは、既存の写真、デザイン案、スクリーンショット、または動画資料を制御して編集することに特化しています。Microsoftは、本モデルが以下のような「編集が難しい」とされる複雑なタスク処理が可能であることを強調しました。

  • 全体的なスタイル変更
  • 照明の再調整（ライティング）
  • 画面内のテキストや記号の修正
  • 資料の復元と強化
  • 物体、光、環境間の関係性を理解した編集

性能向上

Microsoftによると、MAI-Image-2.7は、前世代モデルであるMAI-Image-2.6と比較して、Artificial Analysisが評価する10のユースケースおよび7の編集タスクすべてにおいて性能が向上しています。特に以下の4つのカテゴリで最先端レベルに到達したとされています。

  • 強化復元
  • 推論編集
  • シーンスタイル
  • テキスト記号

このモデルは、シーンおよびスタイルの編集分野で最も大きな改善を見せ、次点モデルよりも24 Eloポイント高い評価を得ました。Artificial AnalysisのAA-Image-Editing v2.1ランキングでは、1,193 Eloポイントを獲得し、OpenAIのGPT Image 2.5 Sunburst (max)に次ぐ第2位となりました。

利用方法と今後の計画

ユーザーは現在、Arena、Artificial Analysis、MAI Playgroundを通じてこのモデルを体験できますが、現時点では画像編集機能のみが提供されています。Microsoftはテキストから画像を生成する機能が「間もなくリリースされる」としていますが、具体的な日程は公表していません。

なお、本モデルは現在Previewバージョンであり、公開API、価格設定、および公式な商用化時期についてはまだ発表されていません。また、モデルの重み（ウェイト）も公開されていないため、ユーザー自身でのホスティングは不可能です。Playgroundの利用地域も制限される可能性があります。

まとめ

MicrosoftのMAI-Image-2.7-Previewは、Artificial Analysisランキングにおいて世界トップクラスの画像編集モデルとして第2位に位置づけられるなど、高い性能を証明しました。本モデルは特に既存画像の複雑な編集作業（スタイル変更やライティング調整、テキスト修正など）に強みを持っていますが、現時点ではプレビュー版であり、テキスト-画像生成機能や商用化計画については今後の発表を待つ必要があります。

Introduction

Microsoft announced the release of its MAI-Image-2.7-Preview model on October 27th. Mustafa Suleyman, Microsoft AI CEO, stated that "MAI-Image has now ranked second among global image editing models!"

Suleyman mentioned on Twitter that Microsoft's MAI-Image series model achieved the second spot globally in image editing models, surpassing Google, Meta, xAI, and GPT-Image-2.5-Flare in Artificial Analysis's ranking. The model ranked just below OpenAI's GPT Image 2.5 Sunburst (max).

Features and Capabilities

The MAI-Image-2.7-Preview model currently focuses on the "Original Image + Text Prompt → Edited Image Output" functionality; text-to-image generation is not yet available. This model specializes in controlling and editing existing photos, design drafts, screenshots, or video materials.

Microsoft emphasized that this model can handle "difficult-to-edit" tasks, such as:

  • Overall style changes
  • Adjusting lighting
  • Correcting text/symbols within a scene
  • Restoring and enhancing data
  • Complex edits requiring understanding the relationship between objects, light, and environment

Performance Improvements

According to Microsoft, MAI-Image-2.7 shows performance improvements across all 10 use cases and 7 editing tasks evaluated by Artificial Analysis compared to its predecessor, MAI-Image-2.6. It has reached a state-of-the-art level in four specific categories: enhanced restoration, inferential editing, scene style, and text symbols.

The model showed the largest improvement in scene and style editing fields, scoring 24 Elo points higher than the next ranked model. In Artificial Analysis's AA-Image-Editing v2.1 ranking, this model achieved second place with 1,193 Elo points, trailing only OpenAI's GPT Image 2.5 Sunburst (max).

Accessibility and Future Plans

Users can currently experience the model at Arena, Artificial Analysis, and MAI Playground; however, only image editing functionality is available at this time. Microsoft stated that text-to-image generation capability will be "coming soon," but did not provide a specific date.

The model is currently in Preview version status. Microsoft has not yet announced the public API, pricing, or official commercialization timeline. Furthermore, the model weights are not released, making self-hosting impossible. Regional availability of the Playground may also be limited.

Summary

Microsoft's MAI-Image-2.7-Preview demonstrates outstanding performance, securing second place globally in image editing models according to Artificial Analysis rankings. The model is highly specialized for complex edits on existing images, showing significant improvements particularly in style changes, lighting adjustments, and text correction. While currently available only as a preview version focused on editing, Microsoft plans to release text-to-image generation and commercialization details later.
