Cloudflare, Qwen 기반 오픈소스 멀티모달 의사결정 모델 Clef 출시

IT之家 10월 2일 소식, 현지 시간 10월 1일, Cloudflare는 Qwen 기반의 오픈소스 멀티모달 의사결정 모델 Clef(클레프)를 출시했습니다. 이 모델은 Clef와 Clef-flash 두 가지 모델로 구성됩니다.

Jev 의사결정 지수(Jev Decision Index) 벤치마크 평가(Decision Index 0.2.1)에서 Clef는 선두를 차지했습니다. 이 두 모델은 Jev-API와 완벽하게 호환되어 개발자들이 쉽게 테스트하고 검증할 수 있습니다.

또한 Cloudflare는 새로운 강화 학습 제품을 발표했습니다. 이 제품을 통해 고객은 특정 비즈니스 시나리오에 맞춰 Clef를 맞춤형으로 미세 조정할 수 있습니다.

Clef는 Qwen을 기반 모델로 사용하며, Clef는 Qwen3.8-27B를, Clef-flash는 Qwen3.5-9B를 기반으로 합니다.

Clef는 시각 인코더를 기본으로 탑재하여 이미지 입력을 직접 분석하고 시각적 콘텐츠를 판별 및 분류할 수 있습니다. 현재 Jev는 순수 텍스트 분류만 지원합니다. Clef는 컨텍스트 창을 64k(Jev는 32k)로 확장하여 개발자가 모델에 더 풍부한 시스템 입력 상태를 로드하여 보다 포괄적인 종합 판단을 내릴 수 있도록 합니다.

Cloudflare는 Clef가 높은 정확도와 강력한 종합 성능을 갖추고 있으며, 여러 벤치마크 테스트에서 동급 모델과 견줄 만하거나 능가하는 경쟁력을 보여주었다고 밝혔습니다. 벤치마크 테스트의 자세한 내용은 아래 표를 참조하십시오.

총평

Cloudflare는 Qwen 기반의 오픈소스 멀티모달 의사결정 모델 Clef와 Clef-flash를 출시했습니다. 이 모델들은 Jev 의사결정 지수 벤치마크에서 선두를 차지했으며, Jev-API와 완벽하게 호환됩니다. Clef는 시각 인코더를 내장하여 이미지 분석이 가능하고, 컨텍스트 창을 64k로 확장하여 더 풍부한 입력 상태를 처리할 수 있습니다.

产品发布与核心定位

Cloudflare 于当地时间 10 月 1 日推出了名为 Clef（谱号）的开源多模态决策模型，旨在为开发者提供高精度的综合判定能力。该系列包含两款模型：Clef 和 Clef-flash。

技术架构与性能指标

  • 基座模型选择：Clef 选用 Qwen 作为基础模型；具体型号包括 Clef 基于 Qwen3.8-27B，Clef-flash 基于 Qwen3.5-9B。
  • 行业评测表现：在 Jev 决策指数（Jev Decision Index）的基准评测中（Decision Index 0.2.1），Clef 模型处于领先地位。

多模态与上下文处理能力

  • 视觉输入解析：Clef 原生配备了视觉编码器，能够直接解析图像输入并对视觉内容进行判别分类，这是现有 Jev 仅支持纯文本分类的升级。
  • 上下文窗口拓展：模型将上下文窗口扩展至 64k（相比之下，原 Jev 为 32k），允许开发者为模型载入更丰富的系统输入状态，从而实现更全面的综合判定。

开发工具与定制化服务

  • API兼容性：Clef 与 Clef-flash 两款模型完全兼容 Jev-API，方便开发者进行测试验证。
  • 强化学习微调：Cloudflare 还发布了全新的强化学习产品，允许客户针对自身的具体业务场景对 Clef 进行定制化微调。

总结

本次 Cloudflare 发布 Clef 模型系列，标志着其在多模态决策AI领域迈出重要一步。通过整合 Qwen 等先进基座模型并原生支持视觉编码器，Clef 显著提升了模型的输入广度和判定深度。同时，提供定制化微调和兼容 Jev-API 的能力，极大地增强了该模型在企业级业务场景中的落地潜力。

Cloudflare、Qwenベースのオープンソースマルチモーダル意思決定モデルClefを発表

IT之家が10月2日に報じたところによると、Cloudflareは、Qwenを基盤としたオープンソースのマルチモーダル意思決定モデル「Clef（클레프）」をリリースしました。このモデル群は、「Clef」と「Clef-flash」の2つのバージョンで構成されています。

本モデルは、Jev Decision Index（ジェブ・ディシジョン・インデックス）ベンチマーク評価（Decision Index 0.2.1）においてトップクラスの性能を示しました。また、この2つのモデルはJev-APIと完全に互換性があるため、開発者が容易にテストおよび検証を行うことが可能です。

Clefの技術的特徴と機能

Cloudflareは、新しい強化学習製品も発表しており、これにより顧客は特定のビジネスシナリオに合わせてClefをカスタマイズし、ファインチューニングすることが可能になります。

ClefはQwenを基盤モデルとして使用しています。具体的なベースモデルは以下の通りです。

  • Clef： Qwen3.8-27Bをベースに採用
  • Clef-flash： Qwen3.5-9Bをベースに採用

技術的な主な特徴として、以下のような点が挙げられます。

  • マルチモーダル対応： Clefはビジュアルエンコーダーを標準搭載しているため、画像入力を直接分析し、視覚的なコンテンツの判別や分類を行うことができます（なお、現行のJevは純粋なテキスト分類のみをサポートしています）。
  • 拡張されたコンテキストウィンドウ： コンテキストウィンドウを64kに拡張しました（対照的にJevは32kです）。これにより、開発者はモデルにより豊かで包括的なシステム入力ステートをロードし、より総合的な判断を下すことが可能になります。

性能と利用可能性

Cloudflareによると、Clefは高い精度と強力な総合性能を備えており、複数のベンチマークテストにおいて、同クラスのモデルに匹敵するか、それを上回る競争力を持っているとのことです。

  • https://huggingface.co/Cloudflare/clef

まとめ

Cloudflareは、Qwenを基盤とした高性能なオープンソースマルチモーダル意思決定モデル「Clef」と「Clef-flash」を発表しました。これらのモデルはJev Decision Indexベンチマークでトップの成績を収め、Jev-APIとの完全な互換性を誇ります。特に、ビジュアルエンコーダーによる画像分析能力と、64kに拡張されたコンテキストウィンドウが特徴であり、より複雑で包括的な判断を下すことが可能になりました。

Cloudflare Launches Clef, an Open-Source Multimodal Decision Model Based on Qwen

According to news from IT之家 on October 2nd (local time Oct 1st), Cloudflare has released Clef, an open-source multimodal decision model based on Qwen. This offering consists of two models: Clef and Clef-flash.

Model Capabilities and Technical Specifications

Clef achieved the top spot in the Jev Decision Index (Decision Index 0.2.1) benchmark evaluation. Both models are fully compatible with the Jev-API, allowing developers to easily test and validate them.

  • Base Model: Clef uses Qwen as its foundational model.
  • Specific Versions: Clef is based on Qwen3.8-27B, while Clef-flash is based on Qwen3.5-9B.

Clef features a built-in visual encoder, enabling it to directly analyze image inputs and classify or discern visual content. Currently, Jev only supports pure text classification. Furthermore, Clef expands the context window to 64k (compared to Jev's 32k), allowing developers to load richer system input states for more comprehensive judgment.

Developer Tools and Performance

In addition to the model release, Cloudflare also announced a new reinforcement learning product. This tool allows customers to fine-tune Clef specifically for their unique business scenarios.

Cloudflare stated that Clef possesses high accuracy and robust comprehensive performance, demonstrating competitiveness comparable to or exceeding existing models across various benchmark tests.
