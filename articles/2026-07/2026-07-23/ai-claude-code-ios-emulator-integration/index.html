Mac용 Claude Code에 iOS 에뮬레이터 통합, AI를 활용한 앱 빌드 및 테스트 가능

2026-07-23

공지 내용

7월 22일 IT홈(IT之家)의 보도에 따르면, @ClaudeDevs 공식 계정이 오늘(7월 22일) X 플랫폼을 통해 Mac 데스크톱 버전 Claude Code에 iOS 에뮬레이터가 내장되었음을 발표했습니다. 이를 통해 별도의 화면 녹화나 접근성 권한 없이도 iOS 앱을 구축, 실행 및 테스트할 수 있습니다.

주요 기능

공식 측은 해당 기능이 현재 공개 베타 버전으로 출시되어 개발자들이 체험해 볼 수 있다고 밝혔습니다. 새로운 Claude Code는 macOS 접근성 권한이나 화면 녹화 권한 없이도 iOS 에뮬레이터를 직접 구동하여 프로젝트를 실행하고, 상호작용하며 반복적으로 개선할 수 있도록 지원합니다.

투명성 및 보안

투명성과 관련하여 공식 측은 iOS 에뮬레이터의 기기 스크린샷이 Anthropic으로 전송되며, 표준 대화 보관 설정에 따라 저장된다고 설명했습니다. 또한 Anthropic은 사용자가 Claude를 사용하는 기기에 실제 계정으로 로그인하지 말 것을 권장하고 있습니다.

총평

Claude Code의 Mac 데스크톱 버전에 iOS 에뮬레이터가 통합되어 추가적인 시스템 권한 없이도 편리한 iOS 앱 개발 환경을 제공합니다. 현재 공개 베타로 운영 중이며, 보안을 위해 실제 계정 로그인을 지양할 것을 권고하고 있습니다.

Claude Code 集成 iOS 模拟器功能

Anthropic 在 X 平台宣布，Mac 桌面版 Claude Code 已内置集成 iOS 模拟器。该功能旨在让开发者能够更便捷地构建、运行和测试 iOS 应用。

技术特性与权限简化

该功能目前以公测版形式上线，其核心优势在于降低了操作门槛：

  • 无需 macOS 辅助功能（Accessibility）权限。
  • 无需屏幕录制授权即可驱动模拟器。
  • 支持在 Claude Code 中直接进行交互和项目迭代。

数据安全与隐私说明

关于数据的透明度，官方明确了以下相关信息：

  • iOS 模拟器的设备截图会发送给 Anthropic。
  • 数据将根据标准的对话保留设置进行保存。
  • Anthropic 建议用户不要在用于 Claude 的设备上登录真实账户。

总结

Anthropic 为 Mac 版 Claude Code 推出了集成 iOS 模拟器的公测功能，显著降低了开发者测试 iOS 应用时的权限门槛。该更新简化了开发流程，但用户仍需注意相关的数据传输规则并遵循官方关于账号安全的建议。

お知らせ

7月22日付のITホーム（IT之家）の報道によると、@ClaudeDevs公式アカウントが本日（7月22日）、Xプラットフォームを通じてMacデスクトップ版「Claude Code」にiOSエミュレータが内蔵されたことを発表しました。これにより、特別な画面録画やアクセシビリティ権限を必要とせずに、iOSアプリの構築、実行、テストが可能になります。

主な機能

公式側は、この機能が現在公開ベータ版としてリリースされており、開発者が体験できることを明らかにしました。新しいClaude Codeは、macOSのアクセシビリティ権限や画面録画権限を必要とせず、iOSエミュレータを直接駆動することでプロジェクトを実行・操作し、反復的に改善するためのサポートを提供します。

透明性とセキュリティ

透明性に関して、公式側はiOSエミュレータのデバイススクリーンショットがAnthropicに送信され、標準的な会話保存設定に従って保存されると説明しています。また、Anthropicはユーザーに対し、Claudeを使用するデバイスで実際の個人アカウントにログインしないことを推奨しています。

総評

Claude CodeのMacデスクトップ版にiOSエミュレータが統合されたことで、追加のシステム権限なしでも便利なiOSアプリ開発環境が提供されます。現在は公開ベータとして運用されており、セキュリティ確保のため実アカウントでのログインを控えるよう推奨されています。

まとめ

Announcement

According to a report by IT Home on July 22, the official @ClaudeDevs account announced via the X platform that an iOS emulator has been integrated into the Mac desktop version of Claude Code. This integration allows developers to build, run, and test iOS applications without requiring separate screen recording or accessibility permissions.

Key Features

The feature is currently available in a public beta for developers to experience. The updated Claude Code enables users to run projects, interact with them, and iteratively improve them directly within the environment.

  • No macOS Accessibility permissions required
  • No Screen Recording permissions required
  • Direct interaction and iterative testing of iOS apps

Transparency and Security

Regarding transparency, officials stated that screenshots from the iOS emulator are sent to Anthropic and stored according to standard conversation retention settings. Furthermore, Anthropic recommends that users do not log into their actual accounts on devices where they use Claude for these development tasks.

Summary

The integration of an iOS emulator into the Mac version of Claude Code provides a more streamlined environment for developers by removing the need for additional system permissions. While currently in public beta, users are advised to follow specific security protocols regarding account logins while utilizing the tool.
