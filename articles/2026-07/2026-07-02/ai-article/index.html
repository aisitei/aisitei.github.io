Xiaomi HyperOS(小米澎湃 OS) 3 업데이트: 2026 월드컵 일정 위젯 추가 및 갤러리 AI 편집 도구 통합

2026-07-02

업데이트 개요

IT홈 뉴스에 따르면, Xiaomi HyperOS(Xiaomi澎湃 OS) 3가 오늘 업데이트를 발표했습니다.

슈퍼 샤오아이, Xiaomi 슈퍼 아일랜드, 위젯 등 실용적인 스포츠 도구가 추가되어 언제 어디서나 최신 경기 정보를 파악할 수 있으며, 앨범 내 AI 도구 통합을 통해 사진 편집이 더욱 편리해졌습니다.

스포츠 서비스 강화

슈퍼 샤오아이(Super Xiaoai)에 경기 예약 및 질의응답 기능이 추가되어 다양한 경기 상황을 빠르게 조회하고 한 번의 클릭으로 경기를 예약할 수 있습니다.

  • 버전 요구사항: 슈퍼 샤오아이 7.12 이상
  • 데이터 제공처: China Mobile Lingxi

Xiaomi 슈퍼 아일랜드

Xiaohongshu, Zhibaba의 스포츠 서비스와 호환되어 경기 점수가 슈퍼 아일랜드에 상시 표시됩니다.

  • 버전 요구사항: Xiaohongshu ≥9.34.0; Zhibaba ≥7.2.1
  • 데이터 제공처: 각 앱(Xiaohongshu, Zhibaba)의 권한을 통해 제공

위젯 및 AI 도구

  • 2026 월드컵 일정 데스크톱 위젯이 추가되어 최신 경기 상황 정보를 실시간으로 동기화합니다. (데이터 제공: Tencent Sports)
  • AI 사진 편집 전용 구역이 최적화되어 모든 AI 편집 도구를 한데 모아 편리하게 찾고 사용할 수 있습니다.
  • 지능형 미화 알고리즘이 강화되어 노출 불균형이 있는 사진을 한 번에 수정하고 자연스러운 빛과 그림자의 질감을 복원합니다. (앨범 편집 버전 2.4.0.2.1 이상 요구)

기능 개선 및 오류 수정

  • 녹음기 자동 이어 녹음: 마이크가 다른 앱에 의해 점유될 때 녹음을 자동으로 중단하고, 점유가 끝나면 다시 녹음을 시작합니다.
  • 파일 관리 페이지: 그룹 펼치기/접기 애니메이션이 더욱 부드러워졌습니다.
  • 테마 배경화면 목록 페이지: 스와이프 조작감이 매끄러워졌습니다.
  • 메모 검색 페이지: 메모를 더 쉽게 검색할 수 있습니다.

기타 수정 사항:

  • 일부 상황에서 휴대폰 백업 목록에 WeChat이 표시되지 않는 문제 해결
  • 일부 상황에서 파일 압축 해제 진행률 표시 오류 해결
  • 일부 상황에서 시계 벨소리 사용자 설정 불가 문제 해결
  • 일부 상황에서 캘린더 표시 이상 문제 해결
  • 일부 상황에서 날씨 위치 파악 실패 문제 해결
  • 일부 상황에서 AI 배경화면 생성 불가 문제 해결

업데이트 안내

이번 업데이트는 '그레이(Gray)에서 전체'로 이어지는 단계적 배포 방식을 채택하고 있으며, 모든 사용자가 즉시 업데이트를 받을 수 있는 것은 아니므로 인내심을 갖고 기다려 주시기 바랍니다.

총평

이번 Xiaomi HyperOS 3 업데이트는 스포츠 정보 제공을 위한 다양한 기능과 AI 기반 사진 편집 도구의 통합 및 강화에 중점을 두었습니다. 또한 녹음기 자동 이어 녹음 등 사용자 편의성을 높이는 시스템 최적화와 여러 버그 수정이 포함되었습니다.

赛事相关功能更新

Xiaomi HyperOS 3 推出了多项针对体育赛事的实用工具，涵盖查询、预约及实时比分展示：

  • 超级小爱：新增赛事预约与问答功能，支持快速查询赛况并一键预约比赛（要求版本 $\ge$ 7.12）。
  • Xiaomi超级岛：适配小红书（$\ge$ 9.34.0）和直播吧（$\ge$ 7.2.1），支持赛事比分常驻显示。
  • 桌面小部件：新增 2026 世界杯赛程小部件，提供实时同步的赛况资讯。

AI 工具与多媒体优化

相册功能进行了深度整合，并提升了录音等基础工具的易用性：

  • 相册 AI 修图：优化置顶 AI 修图专区，聚合相关工具；增强智能美化算法，支持一键修复曝光失衡照片（要求版本 $\ge$ 2.4.0.2.1）。
  • 录音机：新增自动续录功能，当麦克风被其他应用占用时自动暂停并在释放后恢复。

系统交互与 Bug 修复

本次更新优化了多个系统的流畅度及基础功能的稳定性：

  • 界面体验：文件管理页面分组动画更顺滑，主题壁纸滑动手感提升，笔记搜索更加便捷。
  • Bug 修复：修复了微信备份列表显示、文件解压进度条错误、自定义时钟铃声、日历展示异常、天气定位失败以及 AI 壁纸无法生成等问题。

总结

Xiaomi HyperOS 3 本次更新重点强化了赛事相关功能、AI 修图工具及系统交互体验。同时修复了包括微信备份和天气定位在内的多个已知 Bug，并采取“灰度到全量”的逐步推送机制。

アップデート概要

ITホームのニュースによると、Xiaomi HyperOS 3のアップデートが発表されました。

実用的なスポーツツール（Super Xiaoai、Xiaomi Super Island、ウィジェットなど）の追加により、いつでもどこでも最新の試合情報を把握できるようになり、アルバム内のAIツール統合によって写真編集の利便性が向上しました。

スポーツサービスの強化

Super Xiaoaiに試合予約および質疑応答機能が追加され、さまざまな試合状況を素早く確認し、ワンクリックで試合を予約できるようになります。

  • バージョン要件：Super Xiaoai 7.12以上
  • データ提供元：China Mobile Lingxi

Xiaomi Super Island

XiaohongshuやZhibabaのスポーツサービスと互換性があり、試合のスコアがSuper Islandに常時表示されます。

  • バージョン要件：Xiaohongshu ≥9.34.0、Zhibaba ≥7.2.1
  • データ提供元：各アプリ（Xiaohongshu、Zhibaba）の権限を通じて提供

ウィジェットおよびAIツール

  • 2026年ワールドカップのスケジュール用デスクトップウィジェットが追加され、最新の試合状況をリアルタイムで同期します。（データ提供：Tencent Sports）
  • AI写真編集専用エリアが最適化され、すべてのAI編集ツールを一箇所にまとめて便利に検索・使用できるようになりました。
  • 知能的な美化アルゴリズムが強化され、露出の不均衡がある写真を一括で修正し、自然な光と影の質感を復元します。（アルバム編集バージョン 2.4.0.2.1以上が必要）

機能改善およびバグ修正

  • レコーダーの自動再開：マイクが他のアプリによって占有されている際に録音を一時停止し、占有が終了すると自動的に録音を再開します。
  • ファイル管理ページ：グループの展開/折りたたみのモーションがよりスムーズになりました。
  • テーマ壁紙リストページ：スワイプ操作の感触が向上しました。
  • メモ検索ページ：メモをより簡単に検索できるようになりました。

その他の修正事項：

  • 特定の状況下で、携帯電話のバックアップリストにWeChatが表示されない問題を解決
  • 一部のケースにおけるファイル解縮時の進捗表示エラーを修正
  • 特定の条件下で時計の着信音設定ができない問題を解決
  • カレンダーの表示異常を修正
  • 天気の位置特定に失敗する問題を解決
  • AI壁紙の生成に失敗する問題を解決

アップデート案内

今回のアップデートは「Grayから全ユーザーへ」という段階的な配信方式を採用しており、すべてのユーザーが即座に更新を受け取れるわけではないため、お待ちいただく場合があります。

まとめ

今回のXiaomi HyperOS 3アップデートでは、スポーツ情報の提供に向けた機能拡充とAIベースの画像編集ツールの統合・強化に重点を置いています。また、レコーダーの自動再開などの利便性向上や、複数のバグ修正を含むシステム最適化が行われました。

Update Overview

According to IT Home News, Xiaomi has released an update for Xiaomi HyperOS 3.

The update introduces practical sports tools such as Super Xiaoai, Xiaomi Super Island, and widgets to provide real-time match information anytime, anywhere. Additionally, the integration of AI tools within the album makes photo editing more convenient.

Sports Service Enhancements

Super Xiaoai now includes features for match booking and Q&A, allowing users to quickly check various game situations and book matches with a single click.

  • Version Requirement: Super Xiaoai 7.12 or higher
  • Data Provider: China Mobile Lingxi

Xiaomi Super Island

The system is now compatible with sports services from Xiaohongshu and Zhibaba, ensuring that match scores are displayed on the Super Island at all times.

  • Version Requirement: Xiaohongshu ≥9.34.0; Zhibaba ≥7.2.1
  • Data Provider: Provided through permissions from each respective app (Xiaohongshu, Zhibaba)

Widgets and AI Tools

  • A desktop widget for the 2026 World Cup schedule has been added to sync real-time match information. (Data provided by Tencent Sports)
  • The dedicated zone for AI photo editing has been optimized, gathering all AI editing tools in one place for easier access.
  • The intelligent beautification algorithm has been enhanced to correct exposure imbalances and restore natural light and shadow textures in a single step. (Requires Album version 2.4.0.2.1 or higher)

System Optimizations and Bug Fixes

Several usability improvements have been implemented:

  • Recorder Auto-Resume: Recording automatically pauses when the microphone is occupied by another app and resumes once it becomes available.
  • File Management Page: The expand/collapse animations for groups are now smoother.
  • Theme Wallpaper List Page: Swipe operations feel smoother.
  • Notes Search Page: Searching for notes has become easier.

Other fixes include:

  • Resolved an issue where WeChat was not displayed in the phone backup list under certain conditions.
  • Fixed an error displaying file decompression progress in some cases.
  • Resolved an issue where ringtones could not be customized in certain situations.
  • Fixed display issues with the calendar in some scenarios.
  • Resolved failures to determine weather location in some instances.
  • Fixed an issue where AI wallpapers could not be generated in some cases.

Rollout Information

This update is being deployed using a staged rollout method (from "Gray" to "All"). Not all users will receive the update immediately, so patience is requested during the rollout process.

Summary

The Xiaomi HyperOS 3 update focuses on enhancing sports information delivery and integrating advanced AI-driven photo editing tools. It also includes significant system optimizations for user convenience and a variety of bug fixes across various system components.
