현재 스마트폰 AI의 한계와 StepX Neo의 등장

오늘날 우리가 스마트폰에서 사용하는 대부분의 AI 기능은 사용자가 직접 요청할 때만 작동하는 수준에 머물러 있습니다. 메뉴 깊숙이 숨겨진 번역 도구, 특정 앱을 먼저 실행해야만 작동하는 사진 편집기, 혹은 질문에 답은 하지만 실제 행동으로 이어지지 않는 챗봇이 그 예입니다. 즉, 한 번에 하나의 작은 작업만을 수행하기 위해 사용자가 일일이 요청해야 하는 방식입니다.

2023년 전직 Microsoft 직원들이 설립한 중국의 AI 기업 StepFun은 이러한 접근 방식이 스마트폰을 구축하는 올바른 방향이 아니라고 판단했습니다. 그들의 해답은 StepX Neo입니다. 이는 내장된 AI 에이전트가 스스로 멀티스텝(multi-step) 및 엔드투엔드(end-to-end) 작업을 처리하는 세계 최초의 대중용 에이전트 스마트폰입니다. 사용자는 반복적인 프롬프트를 입력하거나 별도의 앱을 열 필요가 없습니다.

StepX Neo를 차별화하는 핵심 요소

StepX Neo의 핵심은 전용 에이전트인 Step Amoo이며, 이는 기기의 커스텀 에이전트 운영체제인 Step AOS에 직접 내장되어 있습니다. Step Amoo는 일반적인 챗봇처럼 대화할 수 있는 봇으로, 모든 주요 작업에서 네트워크 연결 없이 오프라인 상태로 작동합니다.

이 OS의 에이전트 기반 특성은 사용자의 단일 자연어 요청을 받아 앱, 웹 도구, 기기 내장 도구들을 결합하여 완성된 결과를 만들어내는 것을 의미합니다. 또한 시간이 지남에 따라 사용자의 선호도를 학습하므로, 과거 예약 기록을 바탕으로 반려동물 동반 항공편을 우선적으로 선택하거나 자주 가는 식당을 자동으로 예약하는 등의 기능을 수행합니다.

해외 여행 시 StepX Neo는 32개 언어(지역 방언 포함)에 대해 실시간 대화, 문자 메시지, 전화 통화는 물론 거리의 표지판이나 식당 메뉴판, 박물관 포스터의 텍스트까지 번역할 수 있습니다.

또한 셀룰러 신호가 없는 오지에서도 지역 교통편 일정 확인, 주변 이벤트 검색, 저장된 여행 일정 확인이 가능합니다. 빈번하게 여행하는 사용자를 위해 에이전트가 세관 양식을 자동으로 작성하고, 목적지의 비자 요구 사항을 알리며, 항공 상세 정보를 바탕으로 체크인 시간을 안내하는 기능도 제공합니다.

Step AOS와 에이전트 네이티브 경로

Step AOS는 StepFun이 '원자적 능력 엔진(atomic capability engine)'을 활용해 구축한 자체 에이전트 운영체제입니다. 이 엔진은 기기의 기능을 통신, 앱, 파일, 시스템 도구의 네 가지 그룹으로 분리하고 MCP 표준을 사용하여 에이전트가 작업을 완수하기 위해 이들을 자유롭게 조합할 수 있게 합니다. StepFun에 따르면 이 계층은 Android 위에 앱을 얹은 형태가 아니라 Android, Linux, RTOS의 요소들을 결합하여 새롭게 구축되었습니다.

또한 Step AOS는 NUI라고 불리는 음성 및 시각 입력 레이어를 갖추고 있으며, 이는 사용자가 기기를 조작하는 방식에서 "원하는 것을 말하는" 방식으로의 전환을 목표로 합니다.

에이전트의 신뢰성을 높이기 위해 세 가지 지원 시스템이 구축되었습니다.

  • Memory: 사용자 데이터와 에이전트 데이터를 분리하는 두 영역 메모리 설정으로, 캡처-이해-보관 파이프라인을 거칩니다.
  • Decision-making: 요청의 난이도에 따라 가벼운 요청은 빠르고 작은 모델로, 어려운 요청은 더 강력한 모델로 배분하는 계층적 의사결정 레이어입니다.
  • Security: 신뢰 실행(trusted execution) 기반의 보안 프레임워크로, 전체 감사 추적과 필요한 시점에만 부여되고 즉시 회수되는 권한 관리, 실수에 대한 원터치 실행 취소 기능을 포함합니다.

이 모든 기능은 모바일 기기의 연산 한계 내에서 구동되도록 설계된 파운데이션 모델인 Step Edge를 통해 작동합니다. Step Edge는 29개의 벤치마크에서 유사한 에지(edge) 모델들과 대등한 성능을 보여준다고 합니다.

StepEdge는 StepFun이 2023년 4월부터 개발해 온 "1+N" 모델 라인업의 일부이며, StepX Neo는 이러한 모델 연구와 에지 AI, 그리고 하드웨어가 하나로 통합된 결과물입니다.

실질적인 활용을 위해 StepFun은 Ctrip, Alipay, Didi, Meituan, WPS, CapCut과 파트너십을 맺고 여행, 결제, 차량 호출, 로컬 서비스, 사무 업무 및 콘텐츠 제작 분야의 통합을 완료했습니다. 이는 "에이전트 네이티브" 스마트폰이 단순히 약속만 하는 것이 아니라 실제로 차량 예약이나 비디오 편집을 끝까지 수행할 수 있는지 검증하는 시험대가 될 것입니다.

현재 StepX의 출시 시기나 가격에 대한 구체적인 정보는 아직 공개되지 않았습니다.

총평

StepX Neo는 단순한 기능 추가를 넘어, 스스로 판단하고 실행하는 '에이전트' 중심의 운영체제(Step AOS)를 탑재한 혁신적인 스마트폰입니다. 특히 오프라인 환경에서의 작동과 멀티스텝 작업 수행 능력을 통해 사용자 경험을 한 단계 끌어올리는 것을 목표로 합니다. 다양한 플랫폼과의 통합을 통해 실제 실생활에서 강력한 자동화 성능을 입증할 수 있을지 귀추가 주목됩니다.

Current Limitations of Smartphone AI and the Emergence of StepX Neo

Most AI features currently available on smartphones are limited to reactive functions that only activate when a user explicitly requests them. Examples include translation tools hidden deep within menus, photo editors that require specific apps to be opened first, or chatbots that provide answers but do not translate those responses into actual actions. In short, these systems require users to manually prompt the device for every small, individual task.

StepFun, a Chinese AI company founded in 2023 by former Microsoft employees, determined that this approach is not the correct direction for smartphone development. Their solution is StepX Neo. It is touted as the world's first mass-market agent smartphone featuring an embedded AI agent capable of handling multi-step and end-to-end tasks independently. Users no longer need to input repetitive prompts or open separate applications to complete complex workflows.

Key Differentiators of StepX Neo

The core of StepX Neo is its dedicated agent, Step Amoo, which is integrated directly into the device's custom operating system, Step AOS. Unlike standard chatbots, Step Amoo functions as an interactive bot that operates offline for all primary tasks.

The agent-based nature of this OS means it can take a single natural language request and combine apps, web tools, and built-in device tools to produce a finished result. Furthermore, the system learns user preferences over time; for example, it can prioritize pet-friendly flights based on past booking history or automatically book a reservation at a frequently visited restaurant.

When traveling abroad, StepX Neo supports real-time translation for conversations, text messages, and phone calls across 32 languages (including regional dialects). It can also translate text found on street signs, restaurant menus, and museum posters.

Even in remote areas without cellular signals, the device can check local transportation schedules, search for nearby events, and display saved travel itineraries. For frequent travelers, the agent provides features such as automatically filling out customs forms, notifying users of visa requirements at their destinations, and providing check-in times based on flight details.

Step AOS and Agent Native Path

Step AOS is a proprietary agent operating system built by StepFun using an "atomic capability engine." This engine categorizes device functions into four groups—communication, apps, files, and system tools—and utilizes the MCP standard to allow the agent to freely combine these elements to complete tasks. According to StepFun, this layer is not simply an app layer on top of Android but is reconstructed by combining elements from Android, Linux, and RTOS.

Additionally, Step AOS features a Natural User Interface (NUI) consisting of voice and visual input layers, aiming to shift the user experience from "operating the device" to "stating what you want."

To enhance agent reliability, three support systems have been established:

  • Memory: A dual-zone memory configuration that separates user data from agent data through a capture-understand-store pipeline.
  • Decision-making: A hierarchical decision-making layer that routes simple requests to fast, small models and complex tasks to more powerful models.
  • Security: A trusted execution-based security framework including full audit trails, just-in-time permission management (granted only when needed and revoked immediately after), and a one-touch undo feature for errors.

All these features operate through Step Edge, a foundation model specifically designed to run within the computational limits of mobile devices. Step Edge reportedly performs on par with similar edge models across 29 benchmarks.

StepEdge is part of the "1+N" model lineup that StepFun has been developing since April 2023. StepX Neo represents the integration of this model research, edge AI, and hardware into a single product.

To ensure practical utility, StepFun has established partnerships with Ctrip, Alipay, Didi, Meituan, WPS, and CapCut to complete integrations for travel, payments, ride-hailing, local services, office work, and content creation. This "agent-native" smartphone serves as a testing ground to prove that the device can actually complete tasks like booking a vehicle or editing a video from start to finish.

Specific details regarding the release date and pricing of StepX have not yet been disclosed.

Summary

StepX Neo moves beyond simple feature additions by introducing Step AOS, an agent-centric operating system designed for multi-step, end-to-end task execution. By utilizing the Step Amoo agent and the Step Edge foundation model, the device aims to provide a seamless experience where complex tasks—including offline navigation and automated travel logistics—can be completed through single natural language commands.

現在のスマートフォンAIの限界とStepX Neoの登場

現在、スマートフォンで利用可能なほとんどのAI機能は、ユーザーが直接リクエストした際にのみ動作するレベルに留まっています。メニューの奥深くに隠された翻訳ツールや、特定のアプリを起動しなければ機能しない写真編集機、あるいは質問には答えるものの実際の行動にはつながらないチャットボットなどがその例です。つまり、一度に一つの小さなタスクを実行するために、ユーザーが一つひとつ手動で操作を求める仕組みとなっています。

2023年に元Microsoftの従業員らによって設立された中国のAI企業StepFunは、このようなアプローチはスマートフォンの構築における正しい方向ではないと判断しました。彼らが提示する解決策がStepX Neoです。これは、内蔵されたAIエージェントが自らマルチステップ（multi-step）およびエンドツーエンド（end-to-end）のタスクを処理する、世界初の普及型エージェントスマートフォンです。ユーザーは繰り返しのプロンプトを入力したり、別のアプリを開く必要がありません。

StepX Neoを差別化する核心要素

StepX Neoの核となるのは専用エージェントのStep Amooであり、これはデバイスのカスタムエージェントOSであるStep AOSに直接組み込まれています。Step Amooは一般的なチャットボットのように対話ができるボットであり、すべての主要なタスクにおいてネットワーク接続のないオフライン状態で動作します。

このOSのエージェントベースの特性は、ユーザーの単一の自然言語によるリクエストを受け取り、アプリ、ウェブツール、デバイス内蔵ツールを組み合わせることで完成された結果を作り出すことを意味します。また、時間の経過とともにユーザーの好みを学習するため、過去の予約記録に基づいてペット同伴の航空便を優先的に選択したり、頻繁に行くレストランを自動的に予約したりするなどの機能を実行します。

海外旅行時、StepX Neoは32の言語（地域方言を含む）に対して、リアルタイムの会話、テキストメッセージ、電話通話はもちろん、街の標識やレストランのメニュー、美術館のポスターのテキストまで翻訳することが可能です。

さらに、セルラー信号のない人里離れた場所でも、現地の交通機関のスケジュール確認、周辺イベントの検索、保存された旅行日程の確認などが可能です。頻繁に旅行するユーザーのために、エージェントが税関申告書を自動的に作成し、目的地のビザ要件を通知し、航空便の詳細情報に基づいてチェックイン時間を案内する機能も提供します。

Step AOSとエージェント・ネイティブな経路

Step AOSは、StepFunが「原子能力エンジン（atomic capability engine）」を活用して構築した独自のエージェントOSです。このエンジンはデバイスの機能を通信、アプリ、ファイル、システムツールの4つのグループに分離し、MCP標準を使用してエージェントがタスクを完了するためにこれらを自由に組み合わせられるようにします。StepFunによると、このレイヤーはAndroidの上にアプリを載せた形ではなく、Android、Linux、RTOSの要素を組み合わせて新たに構築されたものです。

また、Step AOSはNUIと呼ばれる音声および視覚入力レイヤーを備えており、これはユーザーがデバイスを操作する手法から「欲しいことを話す」方法への転換を目指しています。

エージェントの信頼性を高めるため、3つのサポートシステムが構築されています。

  • Memory：ユーザーデータとエージェントデータを分離する2つの領域メモリ設定により、キャプチャ・理解・保存のパイプラインを経由します。
  • Decision-making：リクエストの難易度に応じて、軽いリクエストは高速で小型のモデルへ、難しいリクエストはより強力なモデルへと振り分ける階層的な意思決定レイヤーです。
  • Security：信頼実行（trusted execution）に基づくセキュリティフレームワークで、完全な監査追跡、必要な時のみ付与され即座に回収される権限管理、ミスに対するワンタッチ実行取消機能が含まれます。

これらのすべての機能は、モバイルデバイスの演算制限内で動作するように設計された基盤モデルであるStep Edgeを通じて動作します。Step Edgeは29のベンチマークにおいて、他のエッジ（edge）モデルと同等の性能を示しているとのことです。

StepEdgeはStepFunが2023年4月から開発してきた「1+N」モデルラインナップの一部であり、StepX Neoはこれらのモデル研究とエッジAI、そしてハードウェアが一つに統合された成果物です。

実用的な活用のため、StepFunはCtrip、Alipay、Didi、Meituan、WPS、CapCutとパートナーシップを締結し、旅行、決済、配車、ローカルサービス、事務作業、コンテンツ制作の分野における統合を完了しました。これは「エージェント・ネイティブ」スマートフォンが単に約束するだけでなく、実際に車両予約や動画編集を最後まで遂行できるかを検証する試験の場となるでしょう。

現在、StepXの発売時期や価格に関する具体的な情報はまだ公開されていません。
