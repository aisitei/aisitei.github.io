Samsung, 더 많은 Galaxy 스마트폰에 One UI 9.0 베타 확대 준비

2026-07-26

One UI 9.0 베타 프로그램 확대 소식

Samsung이 One UI 9.0 베타 프로그램을 출시한 지 두 달이 넘었으나, 현재까지는 Galaxy S26 시리즈에만 한정되어 제공되고 있습니다. 하지만 최근 테스트 서버에서 Galaxy S25 시리즈를 위한 첫 번째 One UI 9.0 내부 테스트 빌드가 포착되면서, 다른 모델로의 확대가 곧 시작될 것으로 보입니다.

특히 Galaxy S25 Ultra용 첫 번째 내측 빌드는 펌웨어 버전 S938NKSUBZZG8로 확인되었습니다. 해당 빌드가 Samsung의 한국 서버에서 발견됨에 따라, 국내에서도 조만간 베타 프로그램 신청이 가능해질 것으로 예상됩니다.

추가 지원 기기 예측

Galaxy S25 시리즈 외에도 다음 단계의 One UI 9.0 베타 프로그램 확대 과정에서 다음과 같은 기기들이 포함될 가능성이 높습니다.

  • Galaxy Z Fold 7
  • Galaxy Z Flip 7
  • 일부 중급형 A-series 스마트폰

업데이트 속도 및 안정 버전 전망

베타 프로그램이 Galaxy S26 모델을 넘어 확장되면, Samsung은 매우 빠른 속도로 베타 단계를 마무리할 것으로 보입니다. 이는 과거 One UI 8.5 베타 프로그램이 확대되기 시작했을 때 보여준 신속한 진행 속도를 바탕으로 예측한 결과입니다.

안정 버전의 경우 이번 주 초 최신 Galaxy 폴더블 기기에 먼저 적용되었습니다. 다만, 구형 Galaxy 기기를 위한 정확한 배포 일정은 아직 공개되지 않았으며, 일부 유출 정보에 따르면 2026년 9월경부터 본격적인 업데이트가 시작될 수 있다는 전망이 나오고 있습니다.

총평

Samsung의 One UI 9.0 베타 프로그램이 Galaxy S25 시리즈를 포함한 더 넓은 기기군으로 확대될 조짐을 보이고 있으며, 이는 곧 국내에서도 관련 소식이 들려올 것임을 시사합니다. 향후 폴더블 모델과 A-series까지 업데이트 범위가 확장될 것으로 예상되며, 구형 기기의 안정 버전 배포는 내년 하반기부터 본격화될 가능성이 높습니다.

One UI 9.0 测试计划扩大消息

Samsung 发布 One UI 9.0 测试程序已超过两个月，但目前仅限于 Galaxy S26 系列。然而，近期在测试服务器上发现了面向 Galaxy S25 系列的首个 One UI 9.0 内测版本，预示着该计划将很快扩展至其他机型。

特别是针对 Galaxy S25 Ultra 的首个内测版本已确认为固件版本 S938NKSUBZZG8。由于该版本在 Samsung 的韩国服务器中被发现，预计国内用户近期也将能够申请相关测试计划。

预计新增支持设备

除了 Galaxy S25 系列外，在下一阶段的 One UI 9.0 测试程序扩展过程中，以下机型极有可能被包含在内：

  • Galaxy Z Fold 7
  • Galaxy Z Flip 7
  • 部分中端 A系列智能手机

更新速度及稳定版本展望

当测试程序从 Galaxy S26 机型扩展后，Samsung 预计将以非常快的速度完成 Beta 阶段。这一预测是基于以往 One UI 8.5 测试计划在扩大范围时表现出的快速进展。

关于稳定版本，本周初已率先应用于最新的 Galaxy 折叠屏设备。然而，针对旧款 Galaxy 设备的准确发布时间尚未公布，根据部分泄露信息，预计从 2026 年 9 月左右开始进入正式更新阶段。

总结

Samsung 的 One UI 9.0 测试计划正逐步扩大至包括 Galaxy S25 系列在内的更多机型。未来折叠屏及 A系列也将纳入更新范围，而旧款设备的稳定版本预计将于 2026 年下半年开始大规模推送。

One UI 9.0 ベータプログラムの拡大に関する最新情報

SamsungはOne UI 9.0ベータプログラムをリリースしてから2ヶ月以上が経過していますが、これまではGalaxy S26シリーズに限定して提供されていました。しかし、最近テストサーバーにてGalaxy S25シリーズ向けの最初のOne UI 9.0内部テストビルドが確認されたため、他のモデルへの展開も間もなく開始される見込みです。

特にGalaxy S25 Ultra向けの最初の内部ビルドは、ファームウェアバージョン「S938NKSUBZZG8」として確認されています。このビルドがSamsungの韓国サーバーで発見されたことから、韓国国内でも近いうちにベータプログラムへの応募が可能になると予想されます。

追加サポートデバイスの予測

Galaxy S25シリーズに加え、次段階のOne UI 9.0ベータプログラム拡大プロセスにおいて、以下のデバイスが含まれる可能性が高いと予測されています。

  • Galaxy Z Fold 7
  • Galaxy Z Flip 7
  • 一部のミドルレンジAシリーズスマートフォン

アップデート速度および安定版の展望

ベータプログラムがGalaxy S26モデルを超えて拡大されると、Samsungは非常に速いスピードでベータ段階を完了させる見込みです。これは、過去にOne UI 8.5ベータプログラムが拡大し始めた際に示された迅速な進行速度に基づいた予測です。

安定版については、今週初めに最新のGalaxy折りたたみ式デバイスに先行して適用されました。ただし、旧型のGalaxyデバイス向けの正確な配布スケジュールはまだ公開されておらず、一部のリーク情報によれば、2026年9月頃から本格的なアップデートが開始される可能性があると報じられています。

まとめ

SamsungのOne UI 9.0ベータプログラムは、Galaxy S25シリーズや折りたたみ式モデル、Aシリーズなど、より幅広いデバイスへと拡大する兆しを見せています。最新の折りたたみデバイスにはすでに安定版が適用され始めており、旧型モデルへの本格的な展開は2026年後半から始まる見通しです。

One UI 9.0 Beta Program Expansion News

Although it has been over two months since Samsung launched the One UI 9.0 beta program, it has currently been limited to the Galaxy S26 series. However, with the first internal test build for the Galaxy S25 series recently spotted on the test server, expansion to other models is expected to begin soon.

Specifically, the first internal build for the Galaxy S25 Ultra was identified as firmware version S938NKSUBZZG8. As this build was discovered on Samsung's Korean servers, it is anticipated that beta program applications will become available in Korea shortly.

Predicted Additional Supported Devices

In addition to the Galaxy S25 series, the following devices are likely to be included in the next phase of the One UI 9.0 beta expansion:

  • Galaxy Z Fold 7
  • Galaxy Z Flip 7
  • Some mid-range A-series smartphones

Update Speed and Stable Version Outlook

Once the beta program expands beyond the Galaxy S26 models, Samsung is expected to complete the beta stages at a very rapid pace. This prediction is based on the swift progress observed when the One UI 8.5 beta program began its expansion.

Regarding stable versions, they were applied to the latest Galaxy foldable devices earlier this week. However, no specific distribution schedule has been released for older Galaxy devices; some leaked information suggests that full updates may begin in earnest around September 2026.

Summary

The One UI 9.0 beta program is showing signs of expanding to the Galaxy S25 series, with foldables and A-series models expected to follow soon. While newer devices are moving through the beta phase quickly, stable updates for older models may not be widely available until late 2026.
