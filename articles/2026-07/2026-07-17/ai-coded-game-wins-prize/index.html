코드 100% AI 작성: 9년 경력의 iOS 개발자, 15일 만에 배달 게임 제작해 2.5만 달러 상금 획득

2026-07-17

개요

IT소식에 따르면, 기술 매체 Wccftech는 7월 13일 게시물을 통해 9년 경력의 iOS 개발자가 2주 동안 AI가 작성한 코드로만 제작한 'Capybara 배달' 게임을 공개했다고 전했습니다. 이 게임은 Cursor Vibe Jam 2026 이벤트에서 25,000달러(현재 환율로 약 17만 위안)의 상금을 획득했습니다.

개발 과정

해당 개발자 u/Ieocoout은 7월 10일 Reddit 커뮤니티에 게시물을 올려, 단 한 줄의 코드도 직접 작성하지 않고 100% AI를 활용하여 15일 만에 게임을 제작했으며, 그 결과 25,000달러의 상금을 받았다고 밝혔습니다.

Vibe Jam 2026은 독립 개발자 Pieter Levels가 주최하는 연례 'Vibe Coding(분위기 프로그래밍 / 의도 기반 프로그래밍)' 게임 개발 대회입니다. 이 대회는 전 세계 많은 개발자가 Claude Code 등 AI 도구를 활용하여 전체 코드를 생성하는 프로젝트를 겨런 장으로, 큰 관심을 끌고 있습니다.

비용 및 기술 스택

개발자는 약 27,000줄의 코드를 작성하기 위해 100달러를 결제하여 Claude Code 5x 플랜을 Max 20x 플랜으로 업그레이드했습니다. 또한 게임의 질감(Texture)과 삽화 제작을 위해 무료 체험판인 GPT images 2 모델과 Grok 모델을 활용했습니다.

AI와의 상호작용 과정에서 개발자는 단 한 줄의 코드도 직접 작성하지 않았으며, 총 188회의 커밋을 통해 Claude를 호출하여 약 27,000줄의 코드를 생성했습니다. 게임의 로고, 삽화, 질감 및 3D 모델 역시 모두 AI로 제작되었습니다. 개발자 본인은 프롬프트 작성, 기획, 테스트 및 AI가 처리하지 못한 부분의 보완 작업에 집중했습니다.

맵 구성 및 멀티플레이어

개발자에 따르면 AI를 통한 3D 지도 생성에 어려움이 있어, 편집기를 사용하여 수동으로 유럽 스타일의 도시를 구축했으며 몇 시간의 작업 끝에 플레이 가능한 환경을 조성했습니다. 멀티플레이어 모드는 단일 글로벌 도시와 로비를 채택했으며, Cloudflare의 실시간 WebSocket을 통해 플레이어 위치와 아이템 더미 정보를 전달합니다.

총평

한 iOS 개발자가 Claude Code 등 AI 도구를 100% 활용하여 단 15일 만에 게임을 제작하고 상금을 획득했습니다. 이 과정에서 코딩은 모두 AI가 담당했으며, 개발자는 기획과 프롬프트 설계 및 기술적 보완에 집중하는 방식으로 협업했습니다.

参赛背景与获奖信息

一名拥有 9 年经验的 iOS 开发者在 Vibe Jam 2026 活动中，凭借一款 100% 由 AI 生成代码的 Capybara 外卖游戏夺得 2.5 万美元（约合 17 万人民币）的奖金。该项目是在短短 15 天内完成的。

开发过程与技术工具

  • 核心工具：使用 Claude Code 生成了约 2.7 万行代码，并利用 GPT images 2 和 Grok 模型处理游戏的纹理、插画及 3D 模型。
  • 投入成本：开发者花费 100 美元将 Claude Code 套餐升级至 Max 20x 以支持大规模开发。
  • 工作量：在整个过程中共进行了 188 次提交，且游戏中的标识、插画、纹理和 3D 模型均由 AI 生成。

AI 交互与技术挑战

开发者在创作过程中全程未手写任何代码，其核心职责包括提示词编写、项目规划、测试以及修复 AI 处理不到位的开发缺口。针对 AI 生成 3D 地图困难的挑战，开发者通过手动在编辑器中搭建欧洲风格城市来解决；多人模式则采用 Cloudflare 上的实时 WebSocket 技术来传输玩家位置与物品信息。

总结

一名 iOS 开发者利用 Claude Code 等 AI 工具，在 15 天内完成了一款全由 AI 生成代码的 Capybara 外卖游戏并赢得 2.5 万美元奖金。该案例展示了“Vibe Coding”模式下，AI 在快速原型开发和多媒体内容生成中的强大能力。

Overview

According to reports from IT news outlets, tech media Wccftech revealed on July 13 that an iOS developer with nine years of experience released a game titled "Capybara Delivery," which was created using only AI-generated code over a two-week period. The game won a $25,000 prize (approximately 170,000 yuan) at the Cursor Vibe Jam 2026 event.

Development Process

The developer, u/Ieocoout, posted on the Reddit community on July 10, stating that they produced the game in just 15 days without writing a single line of code manually by utilizing AI 100%. As a result, they secured the $25,000 prize.

Vibe Jam 2026 is an annual game development competition hosted by independent developer Pieter Levels. The event focuses on "Vibe Coding" (intent-based programming), where developers worldwide compete to generate entire projects using AI tools such as Claude Code, garnering significant attention in the industry.

Cost and Tech Stack

To generate approximately 27,000 lines of code, the developer paid $100 to upgrade their Claude Code plan from 5x to the Max 20x plan. Additionally, they utilized GPT images 2 (free trial) and Grok models to create the game's textures and illustrations.

During the interaction with AI, the developer did not write a single line of code manually. They generated approximately 27,000 lines of code through 188 calls to Claude. All assets, including the logo, illustrations, textures, and 3D models, were also created by AI. The developer focused on prompt engineering, planning, testing, and refining parts that the AI could not handle independently.

Map Construction and Multiplayer

The developer noted difficulties in generating 3D maps through AI alone; consequently, they used an editor to manually construct a European-style city, creating a playable environment after several hours of work. The multiplayer mode features a single global city and lobby, utilizing Cloudflare's real-time WebSockets to transmit player positions and item pile information.

Summary

An experienced iOS developer successfully created a game in just 15 days by leveraging AI tools like Claude Code for 100% of the coding tasks. By shifting their focus from manual programming to planning, prompt design, and technical oversight, the developer was able to win a $25,000 prize at a major competition.
