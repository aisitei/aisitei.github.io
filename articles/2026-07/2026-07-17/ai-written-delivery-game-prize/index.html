코드 100% AI 작성: 9년 차 iOS 개발자, 15일 만에 배달 게임 제작해 2만 5천 달러 상금 획득

2026-07-17

개요

IT_Home의 보도에 따르면, 기술 매체 Wccftech는 7월 13일 게시물을 통해 9년 경력의 iOS 개발자가 2주 동안 100% AI가 작성한 코드로 제작한 'Capybara 배달' 게임을 공개했다고 밝혔습니다. 해당 개발자는 Cursor Vibe Jam 2026 이벤트에서 25,000달러(현재 환율로 약 17만 위안)의 상금을 획득했습니다.

개발 과정

사용자 u/Ieocoout은 7월 10일 Reddit 커뮤니티에 게시물을 올려, 단 한 줄의 코드도 직접 작성하지 않고 100% AI에게 맡긴 상태에서 15일 만에 'Capybara 배달' 게임을 성공적으로 제작했으며, 이를 통해 25,000달러의 상금을 받았다고 밝혔습니다.

대회 정보

Vibe Jam 2026은 독립 개발자 Pieter Levels가 주최하는 연례 'Vibe Coding(분위기 프로그래밍 / 의도 기반 프로그래밍)' 게임 개발 대회입니다. 이 대회는 Claude Code 등 AI 도구를 활용하여 전체 코드를 생성하는 프로젝트를 전 세계 개발자들이 겨루는 장으로, 많은 참여를 이끌어냈습니다.

비용 및 도구

개발자는 약 27,000줄의 코드를 작성하기 위해 100달러를 결제하여 Claude Code 5x 플랜을 Max 20x 플랜으로 업그레이드했습니다. 또한 게임의 텍스처와 삽화를 처리하기 위해 무료 체험판인 GPT images 2 모델과 Grok 모델을 활용했습니다.

AI 상호작용 및 에셋

개발자는 전체 과정에서 직접 코드를 작성하지 않았으며, 총 188회의 커밋을 통해 Claude를 호출하여 약 27,000줄의 코드를 생성했습니다. 또한 게임의 로고, 삽화, 텍스처 및 3D 모델 모두 AI로 제작되었습니다. 개발자 본인은 프롬프트 작성, 기획, 테스트 및 AI가 처리하지 못한 부분의 보완을 담당했습니다.

기술적 과제 및 멀티플레이어

개발자는 AI를 통한 3D 지도 생성이 어렵다는 점을 언급했습니다. 이에 따라 프로젝트는 에디터를 사용하여 유럽 스타일의 도시를 수동으로 구축했으며, 몇 시간에 걸쳐 플레이 가능한 도시 환경을 조성했습니다. 멀티플레이어 모드는 단일 글로벌 도시와 로비를 채택했으며, Cloudflare의 실시간 WebSocket을 통해 플레이어 위치와 아이템 정보 등을 전달합니다.

총평

한 iOS 개발자가 Claude Code 등 AI 도구를 활용해 100% AI 코드로 구성된 게임을 단 2주 만에 제작하고 상금을 획득했습니다. 이 과정에서 코드 생성뿐만 아니라 그래픽, 모델링 등 다양한 요소에 AI를 도입했으며, 기술적 한계는 수동 작업과 외부 서비스를 결합하여 해결했습니다.

项目概况

一名拥有 9 年经验的 iOS 开发者在 Vibe Jam 2026 大赛中，凭借一款由 AI 全程编写代码制作的 Capybara 外卖游戏赢得了 2.5 万美元（约合 17 万元人民币）的奖金。该赛事由 Pieter Levels 举办，旨在展示“Vibe Coding”（氛围编程/意图编程）模式下利用 Claude Code 等工具进行全代码生成的竞技。

技术工具与成本

开发者在项目开发过程中采用了多种 AI 工具，并记录了相关的技术参数：

  • 核心代码生成：使用 Claude Code（将 5x 套餐升级至 Max 20x 套餐）。
  • 美术资源处理：利用 GPT images 2 和 Grok 模型制作游戏纹理、插画和 3D 模型。
  • 投入成本：开发者仅花费 100 美元用于订阅升级。
  • 代码规模：AI 生成了约 2.7 万行代码，共计完成 188 次提交。

开发过程与技术细节

在实际操作中，该开发者全程未手写任何一行代码，其核心工作包括提示词编写、项目规划、功能测试以及修补 AI 处理不到位的缺口。针对 AI 生成 3D 地图困难的挑战，开发者选择使用编辑器手动搭建欧洲风格城市环境。此外，多人模式通过 Cloudflare 上的实时 WebSocket 技术来传递玩家位置与物品堆信息。

总结

一名 iOS 开发者利用 Claude Code 等 AI 工具在 15 天内完成了一款 Capybara 外卖游戏并斩获 2.5 万美元奖金。该案例展示了“Vibe Coding”模式下，人类通过高效的提示词规划与 AI 模型协作，能够快速实现从代码到美术资源的全自动化生产。

開発プロセス

ユーザーu/Ieocooutは7月10日にRedditコミュニティへ投稿を行い、自ら一行もコードを書くことなく、すべてをAIに委ねることでわずか15日間で「Capybara Delivery」の制作に成功し、25,000ドルの賞金を獲得したことを明らかにしました。

大会情報

Vibe Jam 2026は、独立開発者のPieter Levelsが主催する年次「Vibe Coding（雰囲気プログラミング／意図ベースのプログラミング）」ゲーム開発コンテストです。この大会はClaude CodeなどのAIツールを活用して全コードを生成するプロジェクトを世界中の開発者が競う場となっており、多くの参加者を集めました。

コストおよびツール

開発者は約27,000行のコードを生成するために、以下の内容でリソースを投入しました。

  • Claude Code 5xプランからMax 20xプランへアップグレード（費用：100ドル）
  • テクスチャおよびイラスト処理：GPT images 2モデル、Grokモデル（無料トライアル版を使用）

AIとの相互作用およびアセット

開発者は全工程において自らコードを記述することはなく、以下のプロセスで進めました。

  • Claudeへの呼び出しによるコミット数：188回
  • 生成された総コード量：約27,000行
  • AIで制作した要素：ロゴ、イラスト、テクスチャ、3Dモデルのすべて

開発者自身はプロンプトの作成、企画、テスト、およびAIが処理できなかった部分の補完を担当しました。

技術的な課題とマルチプレイヤー

開発者は、AIによる3Dマップ生成の難しさを指摘しています。これに対し、以下の手法で解決を図りました。

  • 都市構築：エディタを使用し、ヨーロッパスタイルの都市を手動で数時間かけて構築
  • マルチプレイヤーモード：単一のグローバル都市とロビーを採用
  • 通信技術：CloudflareのリアルタイムWebSocketを通じて、プレイヤーの位置やアイテム情報を転送

Overview

According to reports from IT_Home and Wccftech, an iOS developer with nine years of experience recently unveiled "Capybara Delivery," a game developed in just two weeks using 100% AI-generated code. The developer won a $25,000 prize (approximately 170,000 RMB) at the Cursor Vibe Jam 2026 event.

Development Process

On July 10, user u/Ieocoout shared a post on Reddit stating that they successfully produced "Capybara Delivery" in 15 days without writing a single line of code manually. By delegating the entire coding process to AI, the developer was able to secure the $25,000 prize.

Competition Details

Vibe Jam 2026 is an annual game development competition hosted by independent developer Pieter Levels, focusing on "Vibe Coding" (intent-based programming). The event serves as a global platform where developers compete to create projects using AI tools like Claude Code to generate the entire codebase.

Costs and Tools

To produce approximately 27,000 lines of code, the developer invested in specific AI tiers and models:

  • Spent $100 to upgrade a Claude Code plan from 5x to Max 20x.
  • Utilized GPT images 2 (free trial) for textures and illustrations.
  • Used Grok models for additional asset processing.

AI Interaction and Assets

The developer did not write any manual code, instead making 188 calls to Claude to generate the bulk of the project's script. The scope of AI integration included:

  • Generation of approximately 27,000 lines of code.
  • AI-generated logos, illustrations, textures, and 3D models.
  • Human oversight for prompt engineering, planning, testing, and refining elements that the AI could not handle automatically.

Technical Challenges and Multiplayer

The developer noted that generating a 3D map through AI proved difficult. To overcome this, they manually constructed a European-style city using an editor over several hours to create a playable environment. The multiplayer mode features a single global city and lobby, utilizing Cloudflare's real-time WebSocket to transmit player positions and item information.

Summary

An experienced iOS developer successfully created the game "Capybara Delivery" in just two weeks using 100% AI-generated code and assets, winning a $25,000 prize. The project demonstrated how "Vibe Coding" and tools like Claude Code can streamline development while still requiring human intervention for complex tasks like manual environment building.
