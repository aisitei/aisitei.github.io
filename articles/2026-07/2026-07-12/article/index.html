Apple iPhone 18 Pro용 A20 Pro 칩, LPDDR5X 아키텍처 유지 및 6채널 96비트 대역폭 업그레이드

2026-07-12

메모리 사양

기술 매체 Wccftech에 따르면 Apple iPhone 18 Pro 및 iPhone 18 Pro Max에 탑재될 A20 Pro 칩은 LPDDR6로 업그레이드되지 않고 LPDDR5X 메모리를 계속 채택할 예정입니다. 다만, 메모리 성능은 향상된 것으로 알려졌습니다.

A20 Pro 칩은 6채널 LPDDR5X 메모리 구조를 채택하며, 각 채널의 비트 폭은 16-bit로 유지되어 총 메모리 비트 폭이 96-bit에 달하게 됩니다.

기존 모델 비교

공개된 자료에 따르면 A19 Pro 칩은 4채널 LPDDR5X 메모리 구조를 채택하여 각 채널의 비트 폭이 16-bit이며, 4개의 채널이 결합되어 총 64-bit의 메모리 비트 폭을 형성합니다. 해당 모델은 로컬 AI 실행 시나리오에 최적화되어 있으며 12GB 메모리를 탑재하고 있습니다.

기술 분석

로컬 AI 처리 시나리오에서는 연산 능력뿐만 아니라 메모리 대역폭의 제한도 중요한 요소입니다. 더 넓은 비트 폭을 확보하면 데이터 처리를 위해 기다리는 시간을 줄일 수 있습니다.

메모리 표준 정보

LPDDR5X: 모바일 기기를 위한 저전력 메모리 표준으로, 대역폭, 소비 전력 및 패키징 공간의 균형을 중시하며 스마트폰과 태블릿 등에서 주로 사용됩니다. LPDDR5의 강화 버전인 이 규격은 고성능 모바일 SoC와 결합하여 멀티태스킹, 이미지 연산, 로컬 AI 추론 등의 시나리오에 적합합니다.

LPDDR6: 차세대 저전력 모바일 메모리 표준으로 LPDDR5X의 후속 진화 방향으로 간주됩니다. 데이터 전송 효율과 에너지 효율을 더욱 높이는 것을 목표로 하며, 복잡한 생성형 AI 모델, 로컬 대형 모델 추론 및 고사양 이미지 처리와 같이 더 높은 대역폭이 필요한 모바일 컴퓨팅 시나리오에 적합합니다.

총평

Apple의 A20 Pro 칩은 LPDDR6 대신 성능이 강화된 6채널 LPDDR5X 구조를 채택하여 로컬 AI 처리를 위한 메모리 비트 폭을 96-bit로 확장할 예정입니다. 이는 전작인 A19 Pro(64-bit)보다 넓은 대역폭을 제공함으로써 데이터 처리 효율을 높이는 데 중점을 두고 있습니다.

A20 Pro 芯片内存架构

根据 Wccftech 的报道，搭载于 iPhone 18 Pro 和 iPhone 18 Pro Max 的 A20 Pro 芯片将继续采用 LPDDR5X 内存而非升级至 LPDDR6。虽然硬件标准未变，但通过增加通道数量来提升性能。

A19 Pro 与 A20 Pro 规格对比

为了优化本地 AI 处理场景，A20 Pro 通过增加内存位宽来减少数据处理等待时间：

  • A19 Pro：采用 4 通道 LPDDR5X 架构，每个通道位宽为 16-bit，总位宽为 64-bit，配备 12GB 内存。
  • A20 Pro：预计采用 6 通道 LPDDR5X 架构，每个通道位宽仍为 16-bit，但总位宽将提升至 96-bit。

LPDDR 技术标准说明

文章介绍了两种主要的移动端低功耗内存标准：

  • LPDDR5X：兼顾带宽、功耗和封装空间，适用于多任务处理、影像计算及本地 AI 推理。
  • LPDDR6：下一代标准，旨在提供更高的传输效率与能效，支持更复杂的生成式 AI 模型及大模型推理。

总结

iPhone 18 Pro 系列的 A20 Pro 芯片将继续采用 LPDDR5X 内存架构，但通过从 4 通道升级至 6 通道，将总位宽从 64-bit 提升至 96-bit。这一设计旨在通过增加带宽来优化本地 AI 处理性能。

メモリ仕様

技術メディアWccftechの報道によると、Apple iPhone 18 ProおよびiPhone 18 Pro Maxに搭載されるA20 Proチップは、LPDDR6へのアップグレードは見送られ、引き続きLPDDR5Xメモリを採用する見込みです。しかし、そのメモリ性能自体は向上していると報じられています。

A20 Proチップの仕様は以下の通りです。

  • 構造：6チャネル LPDDR5X
  • 各チャネルのビット幅：16-bit
  • 総メモリビット幅：96-bit

従来モデルとの比較

公開されたデータによると、A19 Proチップは4チャネルのLPDDR5Xメモリ構造を採用しており、各チャネルが16-bitで構成され、合計64-bitのメモリビット幅となっていました。このモデルはローカルAI実行シナリオに最適化されており、12GBのメモリを搭載しています。

技術分析

ローカルAI処理のシナリオにおいては、演算能力だけでなくメモリ帯域幅の制限も重要な要素となります。より広いビット幅を確保することで、データ処理に伴う待機時間を短縮することが可能になります。

メモリ規格の情報

LPDDR5X：モバイル機器向けの低電力メモリ規格であり、帯域幅、消費電力、パッケージサイズのバランスを重視しており、スマートフォンやタブレットなどで主に使用されます。LPDDR5の強化版であるこの規格は、高性能なモバイルSoCと組み合わせることで、マルチタスク、画像処理、ローカルAI推論などのシナリオに適しています。

LPDDR6：次世代の低電力モバイルメモリ規格であり、LPDDR5Xの次なる進化形と見なされます。データ転送効率とエネルギー効率のさらなる向上を目的としており、複雑な生成AIモデル、ローカルでの大規模モデル推論、高負荷な画像処理など、より高い帯域幅を必要とするモバイルコンピューティングシナリオに適しています。

総評

AppleのA20 Proチップは、LPDDR6の採用に代わり、性能を強化した6チャネルLPDDR5X構造を採用することで、ローカルAI処理のためのメモリビット幅を96-bitに拡張する方針です。これにより、前モデルのA19 Pro（64-bit）よりも広い帯域幅を提供し、データ処理効率の向上に重点を置いています。

まとめ

Appleの次世代チップA20 Proは、LPDDR6ではなく強化された6チャネルLPDDR5Xを採用することで、メモリビット幅を96-bitへと拡大します。これにより前モデルよりも広い帯域幅を確保し、ローカルAI処理におけるデータ転送効率の大幅な向上を目指しています。

Memory Specifications

According to tech outlet Wccftech, the A20 Pro chip intended for the Apple iPhone 18 Pro and iPhone 18 Pro Max will continue to utilize LPDDR5X memory rather than upgrading to LPDDR6. However, it is reported that the overall memory performance has been enhanced.

The A20 Pro chip features a 6-channel LPDDR5X memory structure. While each channel maintains a 16-bit width, the total memory bit width reaches 96-bit.

  • Structure: 6-channel LPDDR5X
  • Bit width per channel: 16-bit
  • Total memory bit width: 96-bit

Comparison with Previous Models

Available data indicates that the A19 Pro chip utilizes a 4-channel LPDDR5X memory structure. In that configuration, four channels of 16-bit each combine to form a total memory bit width of 64-bit. That model is optimized for local AI execution scenarios and is equipped with 12GB of memory.

Technical Analysis

In local AI processing scenarios, memory bandwidth is a critical factor alongside computational power. Securing a wider bit width can reduce the time spent waiting during data processing tasks.

Memory Standard Information

LPDDR5X: A low-power memory standard for mobile devices that balances bandwidth, power consumption, and packaging space. It is primarily used in smartphones and tablets. As an enhanced version of LPDDR5, this standard is suitable for multitasking, image processing, and local AI inference when paired with high-performance mobile SoCs.

LPDDR6: The next-generation low-power mobile memory standard considered the successor to LPDDR5X. It aims to further improve data transmission efficiency and energy efficiency. This standard is designed for mobile computing scenarios requiring higher bandwidth, such as complex generative AI models, local large model inference, and high-end image processing.

Overall Review

The Apple A20 Pro chip will adopt an enhanced 6-channel LPDDR5X structure instead of LPDDR6 to expand the memory bit width to 96-bit for local AI processing. This approach focuses on increasing data processing efficiency by providing a wider bandwidth than its predecessor, the A19 Pro (64-bit).

Summary

The Apple A20 Pro chip will utilize a 6-channel LPDDR5X architecture to provide a 96-bit memory width for improved data processing. While it does not adopt the newer LPDDR6 standard, this configuration offers significantly higher bandwidth than the previous generation's 64-bit setup. This strategy aims to optimize performance specifically for local AI inference and efficient data handling.
