iOS 27 버전 마이크로소프트 Outlook 연락처, 발신자 정보 및 Siri 등 포함한 iPhone 시스템 레벨 표시 지원

2026-07-05

업데이트 계획

IT소식에 따르면, 기술 매체 NeoWin은 7월 3일 게시한 보도에서 Microsoft가 2027년 1월 iOS 27 버전용 Outlook 앱을 업데이트하여 시스템 전체에서 Outlook 연락처를 표시할 계획이라고 밝혔습니다.

기술적 구현

IT소식이 번역한 Microsoft 로드맵의 내용은 다음과 같습니다.

사용자가 주소록에 완전히 접근하거나 연락처를 기기에 복사할 필요 없이, Apple의 Contact Provider 프레임워크를 통해 시스템 수준(발신자 표시, 전화, 메시지, Siri)에서 Outlook 연락처를 구현합니다.

기존 방식과의 차이

현재 Outlook 연락처는 Outlook 앱 내부에만 제한되어 있어, 사용자가 iPhone 기본 주소록에서 해당 연락처를 호출하려면 전체 주소록 접근 권한을 부여하고 연락처를 Contacts(연락처) 앱으로 수동 복사해야 합니다. 새로운 솔루션이 도입되면 시스템이 연락처 데이터를 직접 호출할 수 있어 수동 복사 단계가 생략됩니다.

기능 확장

해당 기능이 출시되면 Outlook에 저장된 연락처는 발신 번호 매칭, 전화 앱 검색, 메시지 앱 통합 및 Siri 호출을 지원하게 되며, 이는 연락처가 여러 iOS 기본 인터페이스에서 표시될 수 있음을 의미합니다.

총평

Microsoft는 2027년 1월부터 Apple의 Contact Provider 프레임워크를 활용해 Outlook 연락처를 시스템과 통합할 계획입니다. 이를 통해 사용자는 별도의 수동 복사 과정 없이도 전화, 메시지, Siri 등 다양한 iOS 기본 기능에서 Outlook 연락처를 직접 활용할 수 있게 됩니다.

Outlook iOS 应用更新计划

微软计划于 2027 年 1 月升级 Outlook iOS 应用，旨在通过 Apple 的 Contact Provider 框架实现系统级显示 Outlook 联系人。

技术方案与改进

目前，用户若要让 iPhone 原生通讯录调用 Outlook 联系人，必须授予完整地址簿访问权限并手动将联系人复制到本地 Contacts 应用。新方案的优势包括：

  • 无需用户完全访问通讯录
  • 无需将联系人复制到设备上
  • 通过 Contact Provider 框架实现系统级集成

功能集成范围

在功能上线后，存储在 Outlook 中的联系人将支持以下原生入口：

  • 来电号码匹配
  • 电话应用检索
  • 信息（Messages）应用集成
  • Siri 调用

总结

微软计划于 2027 年 1 月通过 Apple 的 Contact Provider 框架升级 Outlook iOS 应用。此举旨在让用户无需手动复制数据即可在 iPhone 系统级功能中调用 Outlook 联系人，从而提升与系统原生功能的集成体验。

アップデート計画

ITニュースの報道によると、技術メディアNeoWinが7月3日に公開した記事において、Microsoftは2027年1月のiOS 27向けOutlookアプリのアップデートにより、システム全体でOutlookの連絡先を表示する計画であることを明らかにしました。

技術的な実装

ITニュースが翻訳したMicrosoftのロードマップの内容は以下の通りです。

ユーザーがアドレス帳への完全なアクセス権を付与したり、連絡先をデバイスにコピーしたりする必要なく、AppleのContact Providerフレームワークを通じてシステムレベル（発信者表示、電話、メッセージ、Siri）でOutlookの連絡先を実装します。

従来の手法との違い

現在、Outlookの連絡先はOutlookアプリ内に限定されています。そのため、iPhoneの標準連絡先から該当する連絡先を呼び出すには、全アドレス帳へのアクセス権を許可し、手動で「連絡先」アプリにコピーする必要があります。新しいソリューションが導入されることで、システムが連絡先データを直接呼び出せるようになり、この手動コピーの手順が省略されます。

機能の拡張

この機能がリリースされると、Outlookに保存されている連絡先は以下の機能をサポートするようになります。これにより、連絡先が複数のiOS標準インターフェースで表示可能となります。

  • 発信番号のマッチング
  • 電話アプリでの検索
  • メッセージアプリとの統合
  • Siriによる呼び出し

まとめ

Microsoftは2027年1月より、AppleのContact Providerフレームワークを活用してOutlookの連絡先をシステムに統合する計画です。これにより、ユーザーは手動でデータをコピーする手間なく、電話やメッセージ、SiriといったiOSの標準機能でOutlookの連絡先を直接活用できるようになります。

Update Plans

According to IT News, a report published by tech outlet NeoWin on July 3 revealed that Microsoft plans to update the Outlook app for iOS 27 in January 2027 to display Outlook contacts across the entire system.

Technical Implementation

The content of the Microsoft roadmap translated by IT News is as follows:

Outlook contacts will be implemented at the system level (caller ID, phone, messages, and Siri) through Apple's Contact Provider framework. This allows users to access their contact information without needing full address book permissions or manually copying contacts to the device.

Difference from Current Method

Currently, Outlook contacts are restricted within the Outlook app itself. To view these contacts in the iPhone's default address book, users must grant full permission and manually copy them to the Contacts app. With the new solution, the system will be able to call contact data directly, eliminating the need for manual copying.

Feature Expansion

Once this feature is launched, contacts stored in Outlook will support several native iOS functions:

  • Caller ID matching
  • Phone app search
  • Messages app integration
  • Siri commands

This means that contact information can be displayed across various default iOS interfaces.

Summary

Starting in January 2027, Microsoft plans to utilize Apple's Contact Provider framework to integrate Outlook contacts into the broader iOS system. This update will allow users to access their Outlook data through standard features like Phone, Messages, and Siri without the need for manual copying.
