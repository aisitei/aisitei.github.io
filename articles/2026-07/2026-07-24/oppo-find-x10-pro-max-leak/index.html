한 제조사의 PM 공정 기기에서 OV52A 2억 화소 망원 카메라 테스트 중, OPPO Find X10 Pro Max로 예상

2026-07-24

망원 카메라

IT홈의 7월 23일 보도에 따르면, 블로거 @数码闲聊站이 공개한 내용에 따르면 특정 제조사의 PM 공정 기기에서 테스트 중인 초대형 센서 망원 카메라는 전 세대 U 모델과 동일한 OmniVision OV52A 200Mp 1/1.28"입니다. 이 사양은 근거리 망원 매크로를 지원하며, 성공적으로 탑재될 경우 동급 내에서 독보적인 성능을 보여줄 것으로 예상됩니다.

모델 및 상세 사양

IT홈은 전 세대 모델인 OPPO Find X10 Pro Max의 가능성에 주목했습니다. 이전 세대인 OPPO Find X9 Ultra에 탑재된 OmniVision OV52A 이미지 센서의 상세 스펙은 다음과 같습니다.

  • 센서: OV52A 200Mp 1/1.28"
  • 조리개: f/2.2
  • 초점거리: 70mm (환산)
  • 손떨림 보정: 듀얼 OIS

또한, 해당 블로거는 이전에 특정 제조사의 Pro Max 모델에 대해 다음과 같은 양산 사양을 예고한 바 있습니다.

  • 메인 카메라: 200Mp 1/1.3"± 초대형 센서
  • 망원 카메라: 200Mp 1/1.28"± 초대형 센서 페리스코프 망원
  • 멀티 스펙트럼 렌즈: 3Mp±
  • 프로세서: 2nm Dimensity 칩셋

해당 기기는 두 가지 디스플레이 옵션과 초광각 카메라 사양을 검토 중인 것으로 알려졌습니다.

  • 디스플레이 옵션: 6.89" 2K LTPO 바 타입 (또는 6.78" 1.5K LTPO 선택 가능)
  • 초광각 카메라 옵션: 200Mp 1/1.56" 대형 센서 (또는 50Mp 1/2.75" 선택 가능)

총평

OPPO Find X10 Pro Max로 추정되는 신제품은 전 세대와 동일한 OmniVision OV52A 센서를 탑재하여 강력한 망원 및 매크로 성능을 제공할 것으로 보입니다. 또한 2nm Dimensity 칩셋과 다양한 디스플레이 옵션을 포함하는 고사양 플래그십 모델이 될 가능성이 높습니다.

长焦镜头爆料

博主 @数码闲聊站 透露，某厂工程机正在测试超大尺寸传感器长焦镜头。该镜头预计采用与前代同款的 OV52A 传感器，若顺利落地，将具备极强的近距离长焦微距能力。

  • 传感器型号：OV52A
  • 像素规格：200Mp
  • 传感器尺寸：1/1.28 英寸
  • 光圈：f/2.2
  • 等效焦距：70mm
  • 防抖技术：两轴 OIS

潜在机型与已知参数

根据爆料习惯，该工程机预计为 OPPO Find X10 Pro Max。此前已有相关机型的初步规格信息流出：

  • 主摄：200Mp, 1/1.3" 超大尺寸传感器
  • 潜望长焦：200Mp, 1/1.28" 超大尺寸传感器
  • 多光谱镜头：3Mp
  • 核心芯片：2nm Dimensity
  • 屏幕选项：6.89" 2K LTPO 或 6.78" 1.5K LTPO
  • 超广角选择：200Mp, 1/1.56" 或 50Mp, 1/2.75"

总结

博主爆料称 OPPO Find X10 Pro Max 可能继续沿用 OV52A 200Mp 长焦传感器。该配置若最终采用，将为用户提供强大的长焦微距拍摄体验。目前关于新机的具体发布时间及完整参数仍需持续关注。

望遠カメラ

ITホームの7月23日の報道およびブロガー@数码闲聊站の公開情報によると、特定のメーカーのPM工程デバイスでテスト中の超大型センサー搭載望遠カメラは、前世代のUモデルと同じOmniVision OV52A 200Mp 1/1.28"であることが判明しました。この仕様は近接マクロ撮影をサポートしており、採用が成功すれば同クラスにおいて圧倒的な性能を発揮すると予想されています。

モデルおよび詳細仕様

ITホームは、次世代モデルの可能性としてOPPO Find X10 Pro Maxに注目しています。前世代のOPPO Find X9 Ultraに搭載されたOmniVision OV52Aイメージセンサーの詳細は以下の通りです。

  • センサー: OV52A 200Mp 1/1.28"
  • 絞り値: f/2.2
  • 焦点距離: 70mm（換算）
  • 手ブレ補正: デュアルOIS

また、同ブロガーは以前、特定のメーカーのPro Maxモデルについて以下の量産仕様を予測しています。

  • メインカメラ: 200Mp 1/1.3"± 超大型センサー
  • 望遠カメラ: 200Mp 1/1.28"± 超大型センサー ペリスコープ望遠
  • マルチスペクトラムレンズ: 3Mp±
  • プロセッサ: 2nm Dimensityチップセット

このデバイスは、2種類のディスプレイオプションと超広角カメラの仕様を検討していると報じられています。

  • ディスプレイオプション: 6.89" 2K LTPO バータイプ（または6.78" 1.5K LTPOを選択可能）
  • 超広角カメラオプション: 200Mp 1/1.56" 大型センサー（または50Mp 1/2.75"を選択可能）

まとめ

OPPO Find X10 Pro Maxと推測される新モデルは、前世代と同じOmniVision OV52Aセンサーを搭載することで、強力な望遠およびマクロ性能を提供する見込みです。さらに、2nm Dimensityチップセットの採用や多彩なディスプレイオプションを備えた、極めて高性能なフラッグシップモデルになる可能性が高いです。

Telephoto Camera

According to a report by IT Home on July 23, based on information released by blogger @数码闲聊站, a massive sensor telephoto camera is being tested in the PM process of a specific manufacturer's device. The unit features the OmniVision OV52A 200Mp 1/1.28" sensor, which is identical to the one used in the previous generation's U model. This specification supports close-range telephoto macro and is expected to deliver industry-leading performance in its class if successfully integrated.

Model and Detailed Specifications

IT Home has highlighted the possibility of the OPPO Find X10 Pro Max. The following are the detailed specifications for the OmniVision OV52A image sensor used in the previous generation's OPPO Find X9 Ultra:

  • Sensor: OV52A 200Mp 1/1.28"
  • Aperture: f/2.2
  • Focal Length: 70mm (equivalent)
  • Stabilization: Dual OIS

Additionally, the blogger previously shared the following production specifications for a specific manufacturer's Pro Max model:

  • Main Camera: 200Mp 1/1.3"± ultra-large sensor
  • Telephoto Camera: 200Mp 1/1.28"± ultra-large sensor periscope telephoto
  • Multi-spectrum Lens: 3Mp±
  • Processor: 2nm Dimensity chipset

The device is reportedly being reviewed with two display options and various ultra-wide camera specifications:

  • Display Options: 6.89" 2K LTPO bar type (or 6.78" 1.5K LTPO)
  • Ultra-wide Camera Options: 200Mp 1/1.56" large sensor (or 50Mp 1/2.75")

Summary

The rumored OPPO Find X10 Pro Max is expected to feature the OmniVision OV52A sensor, providing superior telephoto and macro capabilities. With a 2nm Dimensity chipset and multiple display configurations, it is positioned as a high-end flagship device.
