Huawei 📱 스마트폰

Huawei HiCar 7.0 정식 버전 업데이트, 스마트폰에서 직접 주행 모드 실행 가능

2026-07-29

업데이트 소식

IT홈에 따르면, Huawei HiCar가 어제 Huawei 앱 갤러리(App Gallery)를 통해 7.0.0.300 (70000300) 정식 버전 업데이트를 출시했습니다. 해당 애플리케이션을 사용하려면 휴대폰 시스템이 HarmonyOS 6.0 이상 버전이어야 하며, HUAWEI HiCar를 지원하는 차량에서 사용해야 합니다.

주요 업데이트 내용

  • 휴대폰 내 드라이빙 모드 지원 (설정 - 멀티 디바이스 협업 - HUAWEI HiCar - 드라이빙 모드 경로로 활성화 가능)
  • 스마트 데스크탑에 새로운 데스크톱 레이아웃 추가 (일부 차량 인포테인먼트 시스템만 지원)
  • 더 많은 앱에서 '흔들기' 기능을 통한 내비게이션 전환 지원
  • 일부 시나리오에서의 연결 안정성 최적화

드라이빙 모드 개선

IT홈의 테스트 결과, 최신 버전의 HiCar로 업데이트한 후 사용자는 휴대폰에서 직접 드라이빙 모드를 실행할 수 있습니다. 이 모드는 'HiCar 모바일 버전'으로 이해할 수 있으며, 레이아웃 또한 차량용 HiCar와 유사합니다. 해당 모드는 이전 HarmonyOS 4.X 버전 시스템에서도 출시된 적이 있으나, 당시에는 세로 화면만 지원했습니다. 최신 버전의 드라이빙 모드는 가로 화면을 지원하게 되어 더욱 편리한 사용자 경험을 제공합니다.

서비스 개요

HiCar는 Huawei가 출시한 휴대폰과 자동차 연결 제품으로, 간단한 연결을 통해 운전 중 차량 시스템에서 휴대폰의 내비게이션, 음악, 전화, 음성 상호작용 등의 기능을 사용할 수 있습니다. 올해 5월, Huawei HiCar는 공식적으로 70개 이상의 자동차 브랜드와 협력 관계를 구축했으며, 누적 탑재량은 4,000만 대 이상, 협력 모델은 600종이 넘는 것으로 발표되었습니다.

총평

Huawei HiCar가 업데이트를 통해 드라이빙 모드에서 가로 화면을 지원하고 연결 안정성을 최적화했습니다. 또한 스마트 데스크탑 레이아웃과 내비게이션 전환 기능을 강화했으며, 현재 70개 이상의 자동차 브랜드와 협력하며 광범위한 차량 환경을 지원하고 있습니다.

版本更新信息

Huawei HiCar 已在 App Gallery 推出了 7.0.0.300 (70000300) 正式版本。该版本要求手机系统为 HarmonyOS 6.0 及以上版本，并需在支持 HUAWEI HiCar 的汽车上使用。

主要功能更新

  • 新增驾驶模式：用户可通过“设置 - 多设备协同 - HUAWEI HiCar - 驾驶模式”进行开启。
  • 智慧桌面优化：新增桌面布局（仅部分车机支持）。
  • 导航流转增强：更多应用支持“摇一摇导航流转”。
  • 稳定性提升：优化了部分场景下的连接稳定性。

实测体验与市场规模

在最新版本中，手机端的驾驶模式已正式支持横屏使用，相比此前仅支持竖屏的模式，提供了更友好的交互体验。该模式的布局设计与车机端高度相似。

作为 Huawei 推出的手机与汽车互联产品，Huawei HiCar 已与 70 多个汽车品牌建立合作关系，累计装车量超过 4000 万，涵盖车型超过 600 款。该产品支持用户在驾驶时通过车机操作导航、音乐、电话及语音交互等功能。

总结

Huawei HiCar 发布 7.0.0.300 版本，核心更新包括新增支持横屏的驾驶模式、优化连接稳定性以及增强导航流转。目前该产品已广泛应用于超过 600 款车型中，旨在提供更便捷的手机与车机互联体验。

アップデート情報

ITホームの報道によると、Huawei HiCarが昨日、Huawei App Galleryを通じて正式バージョン7.0.0.300（70000300）をリリースしました。このアプリケーションを使用するには、スマートフォンのシステムがHarmonyOS 6.0以上である必要があり、かつHUAWEI HiCarをサポートする車両で利用する必要があります。

主なアップデート内容

  • スマートフォン内でのドライビングモード対応（設定 - マルチデバイス連携 - HUAWEI HiCar - ドライビングモードのパスから有効化可能）
  • スマートデスクトップに新しいデスクトップレイアウトを追加（一部の車両インフォテインメントシステムのみ対応）
  • より多くのアプリにおいて、「振る」動作によるナビゲーションへの切り替えをサポート
  • 特定のシナリオにおける接続安定性の最適化

ドライビングモードの改善

ITホームのテスト結果によると、最新バージョンのHiCarにアップデートすることで、ユーザーはスマートフォンから直接ドライビングモードを実行できるようになりました。このモードは「HiCarモバイル版」と捉えることができ、レイアウトも車両用HiCarと類似しています。以前のHarmonyOS 4.X系システムでもリリースされたことはありますが、当時は縦画面のみの対応でした。最新バージョンのドライビングモードでは横画面（ランドスケープ）をサポートするようになり、より快適なユーザー体験を提供します。

サービスの概要

HiCarはHuaweiが提供するスマートフォンと車両の接続製品であり、簡単な接続を通じて運転中に車両システムからスマートフォンのナビゲーション、音楽、通話、音声対話などの機能を利用できます。今年5月、Huawei HiCarは公式に70以上の自動車ブランドと提携関係を構築しており、累計搭載台数は4,000万台以上、協力モデルは600種を超えることが発表されています。

総評

Huawei HiCarは今回のアップデートにより、ドライビングモードでの横画面対応や接続安定性の最適化を実現しました。また、スマートデスクトップのレイアウトとナビゲーション切り替え機能を強化しており、現在70以上の自動車ブランドと提携することで、幅広い車両環境をサポートしています。

まとめ

Huawei HiCarがバージョン7.0.0.300にアップデートされ、スマートフォンでの横画面対応や接続安定性の向上が行われました。この更新により、よりスムーズなナビゲーション切り替えやスマートデスクトップのレイアウト強化が実現します。現在、多くの自動車ブランドと提携しており、幅広い車両環境で高度な連携体験を提供しています。

Update News

According to IT Home, Huawei HiCar has released version 7.0.0.300 (70000300) through the Huawei App Gallery. To use this application, the mobile device must run HarmonyOS 6.0 or higher and be used in a vehicle that supports HUAWEI HiCar.

Key Update Highlights

  • Support for driving mode on the phone (can be activated via Settings - Multi-device Collaboration - HUAWEI HiCar - Driving Mode).
  • Added new desktop layouts to the smart desktop (supported only on specific vehicle infotainment systems).
  • Support for switching to navigation using a "shake" gesture in more applications.
  • Optimized connection stability across various scenarios.

Driving Mode Enhancements

Based on tests by IT Home, users can now launch driving mode directly from their phones after updating to the latest version of HiCar. This mode functions as a "HiCar mobile version" and features a layout similar to the in-vehicle HiCar system. While this mode was previously available on HarmonyOS 4.X systems, it only supported portrait orientation at that time. The latest version now supports landscape orientation, providing a more convenient user experience.

Service Overview

HiCar is a Huawei solution for connecting mobile phones to vehicles, allowing users to access navigation, music, calls, and voice interactions via the vehicle's system through a simple connection. As of May this year, Huawei HiCar has officially established partnerships with over 70 automotive brands, with cumulative installations exceeding 40 million units across more than 600 models.

Summary

The latest update for Huawei HiCar introduces landscape orientation support for its driving mode and optimizes connection stability. It also enhances the user experience through new smart desktop layouts and gesture-based navigation switching while maintaining a broad reach across over 70 automotive brands.
