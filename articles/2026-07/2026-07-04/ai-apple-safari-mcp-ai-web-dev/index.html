Apple Safari 기술 프리뷰 247, MCP 서비스 도입으로 AI 에이전트를 통한 웹 개발 및 디버깅 가속화

2026-07-04

개요

Apple WebKit 블로그는 Safari Technology Preview 247에서 MCP 서버 지원을 도입했다고 발표했습니다. 이 기능은 개발 및 디버깅 프로세스를 가속화하기 위해 도입되었습니다.

MCP(Model Context Protocol)는 AI 에이전트가 외부 도구, 서비스 및 데이터 소스에 연결할 수 있도록 하는 개방형 표준입니다. 이를 통해 코드 저장소, 팀 협업 플랫폼, 데이터베이스, 로컬 파일 및 브라우저 개발 도구와 같은 다양한 환경과 연결하여 정보를 읽거나 권한이 부여된 작업을 수행할 수 있습니다.

기능

Safari Technology Preview 247에서 MCP 서버를 구성하면 프로그래밍 에이전트가 Safari 브라우저 창에 연결되어 코드의 실제 렌더링 상태를 더욱 충분히 파악할 수 있게 됩니다.

  • 웹페이지 확인
  • 콘솔 로그 및 네트워크 요청 접근
  • 스크린샷 캡처
  • 페이지 요소와 상호작용

활용 사례

Apple이 명시한 주요 활용 분야는 다음과 같습니다.

  • 웹사이트 디버깅
  • Safari 호환성 문제 식별
  • 성능 분석
  • 접근성 검사
  • 페이지 및 사용자 인터페이스(UI) 상태 확인

총평

Apple은 Safari Technology Preview 247에 MCP 서버 지원을 추가하여 AI 에이전트가 브라우저 환경과 직접 상호작용할 수 있는 기반을 마련했습니다. 이를 통해 개발자는 웹사이트 디버깅, 성능 분석 및 호환성 확인 등 다양한 개발 프로세스를 더욱 효율적으로 수행할 수 있게 됩니다.

Safari 技术预览版新增 MCP 支持

Apple WebKit 博客宣布，在 Safari Technology Preview 247 中引入了对 MCP 服务器的支持。此项功能旨在通过连接 Safari 浏览器窗口，让 AI 智能体能够更充分地了解代码在浏览器中的实际呈现，从而加速开发和调试流程。

什么是 MCP？

MCP（Model Context Protocol）是一种开放标准，旨在让兼容的 AI 智能体能够连接到外部工具、服务和数据源。其典型应用场景包括：

  • 连接代码仓库
  • 团队协作平台
  • 数据库
  • 本地文件
  • 浏览器开发工具（用于读取信息或执行授权操作）

功能与应用场景

在配置完成后，编程智能体可以通过 Safari MCP 服务器执行多种操作：

  • 检查网页内容
  • 访问控制台日志和网络请求
  • 抓取页面截图
  • 与页面元素进行交互

上述功能可应用于以下具体场景：

  • 调试网站
  • 识别 Safari 兼容性问题
  • 性能分析
  • 可访问性检查
  • 验证页面和用户界面状态

总结

Apple 在 Safari Technology Preview 247 中引入 MCP 服务器支持，旨在让 AI 智能体能够更深度地接入浏览器数据。这一举措将显著提升开发者在调试、性能分析及兼容性检查等方面的效率。

概要

AppleのWebKitブログは、Safari Technology Preview 247においてMCPサーバーのサポートを導入したと発表しました。この機能は、開発およびデバッグプロセスの加速を目的として導入されています。

MCP（Model Context Protocol）は、AIエージェントが外部ツール、サービス、およびデータソースに接続できるようにするためのオープン標準です。これにより、コードリポジトリ、チームコラボレーションプラットフォーム、データベース、ローカルファイル、ブラウザ開発ツールなど、多様な環境と連携して情報を読み取ったり、権限を与えられた操作を実行したりすることが可能になります。

機能

Safari Technology Preview 247でMCPサーバーを構成することで、プログラミングエージェントがSafariブラウザのウィンドウに接続し、コードの実際のレンダリング状態をより詳細に把握できるようになります。

  • ウェブページの確認
  • コンソールログおよびネットワークリクエストへのアクセス
  • スクリーンショットのキャプチャ
  • ページ要素とのインタラクション

活用事例

Appleが指定する主な活用分野は以下の通りです。

  • ウェブサイトのデバッグ
  • Safariの互換性問題の特定
  • パフォーマンス分析
  • アクセシビリティの検査
  • ページおよびユーザーインターフェース（UI）の状態確認

まとめ

AppleはSafari Technology Preview 247にMCPサーバーのサポートを追加することで、AIエージェントがブラウザ環境と直接相互作用できる基盤を構築しました。これにより、開発者はデバッグやパフォーマンス分析、互換性の確認といったさまざまな開発プロセスをより効率的に遂行できるようになります。

Overview

The Apple WebKit blog announced the introduction of MCP server support in Safari Technology Preview 247. This feature was implemented to accelerate development and debugging processes.

MCP (Model Context Protocol) is an open standard that allows AI agents to connect to external tools, services, and data sources. Through this protocol, agents can connect to various environments—such as code repositories, team collaboration platforms, databases, local files, and browser development tools—to read information or perform authorized actions.

Features

By configuring an MCP server in Safari Technology Preview 247, programming agents can connect to Safari browser windows to gain a more comprehensive understanding of the actual rendering state of code.

  • Viewing web pages
  • Accessing console logs and network requests
  • Capturing screenshots
  • Interacting with page elements

Use Cases

The primary use cases specified by Apple include:

  • Website debugging
  • Identifying Safari compatibility issues
  • Performance analysis
  • Accessibility testing
  • Verifying page and user interface (UI) status

Summary

Apple has introduced MCP server support in Safari Technology Preview 247 to enable AI agents to interact directly with the browser environment. This integration provides developers with a more efficient way to perform essential tasks such as debugging, performance analysis, and compatibility checks.
