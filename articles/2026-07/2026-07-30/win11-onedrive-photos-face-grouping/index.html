마이크로소프트 Win11, OneDrive Photos 앱 조용히 출시... 권한 허용 시 얼굴 기반 사진 그룹화 지원

2026-07-30

신규 애플리케이션 도입

7월 29일 IT 뉴스에 따르면, 기술 매체 Windows Latest가 마이크로소프트(Microsoft)가 Windows Update 또는 Windows용 OneDrive 애플리케이션을 통해 'OneDrive Photos'라는 사진 애플리케이션을 조용히 배포하고 있다고 보도했습니다.

해당 매체는 Microsoft Photos 키워드를 검색하던 중, 수동으로 설치한 적이 없는 새로운 'OneDrive Photos' 애플리케이션을 발견했습니다.

기술 사양 및 구조

이 앱의 경로는 "C:\Program Files\Microsoft OneDrive\OneDrive.App.exe"이며, 기존 OneDrive 애플리케이션에 속해 있습니다. 이 앱은 WebView2를 기반으로 제작되었으며 네이티브 Windows 애플리케이션이 아닙니다.

기능 및 인터페이스

로그인하지 않은 상태에서도 이 애플리케이션은 로컬 파일을 스캔할 수 있습니다. 사용자가 'Gallery(갤러리)'를 열면 앱이 장치 내의 로컬 이미지를 자동으로 표시합니다.

인터페이스 요소로, 왼쪽 탐색 모음에는 다음과 같은 6개의 섹션이 포함되어 있습니다:

  • Moments(순간)
  • Gallery(갤러리)
  • People(인물)
  • Albums(앨범)
  • Favorites(즐겨찾기)
  • This PC(내 PC)

보기 옵션의 경우, 사용자는 River(평면)와 Square(격자) 2가지 레이아웃을 전환할 수 있으며, Roomy(여유) 또는 Compact(조밀) 표시 밀도를 선택하고 썸네일 크기를 조정할 수 있습니다.

로그인 후 기능 및 AI 서비스

Microsoft 계정으로 로그인하면 OneDrive Photos는 전체 OneDrive 갤러리로 전환되며, 인공지능(AI) 기반의 클라우드 검색 기능을 제공합니다. 사용자가 다소 모호한 설명을 입력하더라도 시스템이 일치하는 이미지나 파일을 찾으려고 시도하며, OCR(광학 문자 인식)을 통해 이미지 내의 텍스트를 읽어 콘텐츠 위치 파악을 도울 수 있습니다.

또한 이 애플리케이션은 'People' 영역을 제공하여 사진 속 유사한 얼굴을 그룹화합니다. Microsoft는 이 기능을 활성화하기 전에 사용자의 동의를 구하며, 일부 지역에서 얼굴 데이터가 생체 인식 데이터로 간주될 수 있음을 명확히 안내합니다.

Microsoft는 그룹화된 얼굴 정보는 사용자 본인만 볼 수 있으며 관련 데이터를 제3자와 공유하지 않는다고 밝혔습니다. 사용자는 기능을 끄고 해당 데이터를 삭제할 수도 있습니다.

총평

마이크로소프트는 WebView2 기반의 'OneDrive Photos'를 통해 로컬 및 클라우드 이미지 관리 기능을 강화하고 있습니다. 특히 AI 검색과 OCR 기술을 결합하여 사용자 편의성을 높였으며, 개인정보 보호를 고려한 인물 인식 기능을 포함하고 있습니다.

新应用推广

微软正通过 Windows Update 或 OneDrive 应用程序静默推广名为 OneDrive Photos 的新照片应用程序。该应用被发现并非由用户手动安装，而是作为系统或相关组件的一部分在推送。

技术架构与路径

OneDrive Photos 并不是原生 Windows 应用，而是基于 WebView2 技术构建的 Web 视图应用。其具体文件路径为：

  • C:\Program Files\Microsoft OneDrive\OneDrive.App.exe

基础功能与界面设计

在未登录微软账户的情况下，该应用仍可扫描并展示设备中的本地图像。用户可以在左侧导航栏中切换以下 6 个核心板块：

  • Moments（瞬间）
  • Gallery（图库）
  • People（人物）
  • Albums（相册）
  • Favorites（收藏夹）
  • This PC（此电脑）

在视图展示方面，用户可以自定义以下选项：

  • 布局模式：River（平铺）或 Square（方块）
  • 显示密度：Roomy（宽松）或 Compact（紧凑）

高级功能与 AI 增强

当用户登录微软账户后，OneDrive Photos 将解锁完整的云端功能支持：

  • 人工智能云端搜索：支持通过模糊描述来定位匹配的图片或文件。
  • OCR（光学字符识别）：自动读取图像中的文字以辅助内容定位。
  • People 区域：利用 AI 技术将相似人脸归为一组，并在获得用户许可的前提下处理相关生物识别数据。

总结

微软推出了基于 WebView2 构建的 OneDrive Photos 应用，旨在提供更丰富的本地与云端照片管理体验。该应用集成了多样化的视图自定义选项，并为登录用户提供 AI 搜索、OCR 文字识别及人脸自动分组等高级功能。

新機能アプリケーションの導入

7月29日のITニュースによると、技術メディアのWindows Latestが、MicrosoftはWindows UpdateまたはWindows用OneDriveアプリを通じて「OneDrive Photos」という写真アプリケーションを密かに展開していると報じました。

同メディアは、「Microsoft Photos」というキーワードを検索していた際に、手動でインストールした覚えのない新しい「OneDrive Photos」アプリケーションを発見しました。

技術仕様と構造

このアプリのパスは「C:\Program Files\Microsoft OneDrive\OneDrive.App.exe」であり、既存のOneDriveアプリケーションの一部として含まれています。このアプリはWebView2をベースに構築されており、ネイティブなWindowsアプリケーションではありません。

機能とインターフェース

このアプリケーションは、ログインしていない状態でもローカルファイルをスキャンすることが可能です。ユーザーが「Gallery（ギャラリー）」を開くと、デバイス内のローカル画像が自動的に表示されます。

インターフェース要素として、左側のナビゲーションバーには以下の6つのセクションが含まれています：

  • Moments（瞬間）
  • Gallery（ギャラリー）
  • People（人物）
  • Albums（アルバム）
  • Favorites（お気に入り）
  • This PC（PC内）

表示オプションについては、ユーザーはRiver（平坦）とSquare（格子）の2種類のレイアウトを切り替えることができ、Roomy（ゆったり）またはCompact（密集）の表示密度を選択してサムネイルのサイズを調整することが可能です。

ログイン後の機能とAIサービス

Microsoftアカウントでログインすると、OneDrive Photosは全OneDriveギャラリーに切り替わり、人工知能（AI）に基づいたクラウド検索機能が提供されます。ユーザーが多少曖昧な説明を入力しても、システムは一致する画像やファイルを見つけようと試みます。また、OCR（光学文字認識）を通じて画像内のテキストを読み取り、コンテンツの場所特定を支援します。

さらに、このアプリケーションは「People」エリアを提供し、写真内の類似した顔をグループ化します。Microsoftはこの機能を有効にする前にユーザーの同意を求め、一部の地域では顔データが生体認識データとみなされる可能性があることを明確に通知しています。

Microsoftは、グループ化された顔情報はユーザー本人しか閲覧できず、関連データを第三者と共有しないことを明かしています。また、ユーザーは機能をオフにし、該当のデータを削除することも可能です。

総評

MicrosoftはWebView2ベースの「OneDrive Photos」を通じて、ローカルおよびクラウドの画像管理機能を強化しています。特にAI検索とOCR技術を組み合わせることで利便性を高めつつ、プライバシーに配慮した人物認識機能を統合しています。

まとめ

MicrosoftはWindows向けにWebView2ベースの「OneDrive Photos」を導入し、ローカルとクラウドの両方で高度な画像管理を提供します。AIによる検索やOCR機能、顔認識による自動整理といった便利な機能を備えつつ、ユーザーのプライバシー保護にも配慮した設計となっています。

New Application Introduction

On July 29, tech outlet Windows Latest reported that Microsoft is quietly deploying a photo application called "OneDrive Photos" via Windows Update or the OneDrive app for Windows.

The publication discovered the new "OneDrive Photos" application while searching for the "Microsoft Photos" keyword, noting that it appeared without any manual installation by the user.

Technical Specifications and Structure

The application is located at "C:\Program Files\Microsoft OneDrive\OneDrive.App.exe" and is part of the existing OneDrive application suite. This app is built on WebView2 and is not a native Windows application.

Features and Interface

Even without being logged in, this application can scan local files. When a user opens the "Gallery," the app automatically displays local images stored on the device.

The interface includes a navigation bar on the left with the following six sections:

  • Moments
  • Gallery
  • People
  • Albums
  • Favorites
  • This PC

Regarding view options, users can switch between two layouts—River and Square—and choose between Roomy or Compact display densities while adjusting thumbnail sizes.

Post-Login Features and AI Services

Upon logging in with a Microsoft account, OneDrive Photos transitions to the full OneDrive gallery and provides AI-powered cloud search capabilities. The system attempts to find matching images or files even when users enter somewhat vague descriptions. It also utilizes OCR (Optical Character Recognition) to read text within images to help identify content locations.

Additionally, the application features a "People" section that groups similar faces in photos. Microsoft requests user consent before enabling this feature and clearly informs users that facial data may be considered biometric data in certain regions.

Microsoft stated that grouped facial information is only visible to the user and is not shared with third parties. Users also have the option to turn off the feature and delete the corresponding data.

Overall Review

Through the WebView2-based "OneDrive Photos," Microsoft is enhancing both local and cloud image management capabilities. By combining AI search and OCR technology, it improves user convenience while incorporating privacy-conscious facial recognition features.

Summary

Microsoft is introducing "OneDrive Photos," a WebView2-based application designed to streamline the management of local and cloud images. The app integrates advanced features such as AI-powered search, OCR, and face grouping while maintaining clear privacy protocols for biometric data. This update aims to enhance user convenience by providing more robust tools for organizing visual content across both local devices and the OneDrive cloud.
