스마트폰용 AI 게임 제작 도구, Roblox 모바일 버전에 'Build' 기능 업데이트 예정

2026-07-18

기능 소개

Roblox가 공식 발표를 통해 모바일 클라이언트용 'Build' 기능을 출시한다고 밝혔습니다. 이 기능은 사용자가 모바일 기기에서 AI 생성 도구를 활용하여 자신만의 게임을 제작할 수 있게 해줍니다.

사용 편의성 및 기술적 특징

공식 발표에 따르면, 'Build' 기능은 프로그래밍 지식이 없는 사용자도 간단한 프롬프트 입력만으로 기초적인 게임을 생성할 수 있도록 지원합니다. 예를 들어 사용자가 "울창한 숲을 배경으로 한 따뜻한 모험 게임을 만들어줘"라고 입력하면 시스템이 자동으로 초기 버전을 생성하며, 사용자는 이를 언제든지 수정하고 친구들과 공유할 수 있습니다.

Build 기능은 오픈 소스 모델과 Roblox 자체 개발 모델 등 다양한 AI 모델로 구동되며, 다음과 같은 요소들을 지원합니다.

  • 게임 플레이 메커니즘
  • 환경
  • 캐릭터
  • 비주얼 스타일
  • 사운드 효과

출시 일정 및 서비스 계획

해당 기능은 7월 28일부터 Alpha 테스트를 시작하며, 뉴질랜드 거주 인증을 마친 9세 이상 사용자에게 우선 제공됩니다. 16세 이상의 사용자는 생성한 게임을 전 세계 플레이어들에게 공개할 수 있습니다. 향후 공식적으로 무료 기본 버전과 유료 프리미엄 버전을 출시할 예정입니다.

총평

Roblox는 모바일에서 AI를 활용해 코딩 없이 게임을 제작할 수 있는 'Build' 기능을 도입합니다. 이 기능은 다양한 AI 모델을 기반으로 환경, 캐릭터, 사운드 등 여러 요소를 생성하며, 향후 무료 및 유료 버전으로 제공될 예정입니다.

移动端AI创作功能

Roblox 官方宣布其移动版客户端将推出“Build”功能。该功能允许用户通过简单的提示词（Prompt）在手机上利用 AI 生成工具创建游戏，旨在让没有任何编程技能的用户也能快速构建出包含基础内容的初始版本。

核心技术与内容支持

“Build”功能由多种 AI 模型驱动，涵盖了开源模型和 Roblox 自研模型。该系统能够协助用户生成以下维度的内容：

  • 游戏玩法机制
  • 环境场景
  • 角色设计
  • 视觉风格
  • 音效

发布计划与分级

该功能将于 7 月 28 日开启 Alpha 测试，具体的推广安排如下：

  • 首批测试范围：新西兰地区、已完成验证的 9 岁以上用户。
  • 全球发布权限：16 岁以上的用户可将生成的游戏发布给全球玩家。
  • 商业模式：官方计划推出免费的基础版本，并同步提供付费的高级版本。

总结

Roblox 将在移动端推出“Build”功能，利用多种 AI 模型让用户无需编程即可通过提示词创作包含玩法、视觉和音效的完整游戏。该功能将于 7 月 28 日开启 Alpha 测试，并采取基础版免费、高级版付费的商业模式。

機能紹介

Robloxは公式発表を通じて、モバイルクライアント向けに「Build」機能をリリースすることを明らかにしました。この機能により、ユーザーはモバイルデバイス上でAI生成ツールを活用して独自のゲームを制作できるようになります。

利便性と技術的特徴

公式発表によると、「Build」機能はプログラミングの知識がないユーザーでも、簡単なプロンプトを入力するだけで基礎的なゲームを作成できるようにサポートします。例えば、ユーザーが「うっそうとした森を舞台にした温かい冒険ゲームを作って」と入力すると、システムが自動的に初期バージョンを生成し、ユーザーはそれをいつでも修正して友人と共有できます。

Build機能はオープンソースモデルやRoblox独自の開発モデルなど、多様なAIモデルによって駆動し、以下の要素をサポートします。

  • ゲームプレイメカニズム
  • 環境
  • キャラクター
  • ビジュアルスタイル
  • サウンドエフェクト

リリーススケジュールおよびサービス計画

この機能は7月28日からAlphaテストを開始し、ニュージーランド居住の認証を済ませた9歳以上のユーザーに優先的に提供されます。16歳以上のユーザーは、作成したゲームを世界中のプレイヤーに公開することができます。今後、公式に無料の基本版と有料のプレミアム版をリリースする予定です。

総評

RobloxはモバイルでAIを活用し、コーディングなしでゲーム制作ができる「Build」機能を導入します。この機能は多様なAIモデルに基づき、環境、キャラクター、サウンドなど様々な要素を生成し、将来的に無料版と有料版の両方で提供される予定です。

まとめ

Robloxはモバイル端末からAIを活用してノーコードでゲーム制作ができる「Build」機能を導入します。この機能は多様なAIモデルを用いて環境やキャラクターなどを自動生成し、将来的には無料版と有料のプレミアム版を展開する計画です。

Feature Introduction

Roblox has officially announced the launch of the 'Build' feature for its mobile client. This feature allows users to create their own games on mobile devices by utilizing AI-powered generation tools.

Ease of Use and Technical Features

According to the official announcement, the 'Build' feature enables users without any programming knowledge to generate basic games simply by entering prompts. For example, if a user inputs "Create a warm adventure game set in a dense forest," the system will automatically generate an initial version that the user can modify and share with friends at any time.

The Build feature is powered by various AI models, including open-source models and those developed internally by Roblox. It supports the following elements:

  • Gameplay mechanics
  • Environment
  • Characters
  • Visual style
  • Sound effects

Release Schedule and Service Plans

The feature will begin Alpha testing on July 28, initially available to users aged 9 and older in New Zealand who have completed residency verification. Users aged 16 and older will be able to share their created games with players worldwide. In the future, Roblox plans to officially release both a free basic version and a paid premium version.

Summary

Roblox is introducing the 'Build' feature on mobile to enable users to create games without coding by leveraging various AI models. The tool supports multiple elements including environment, characters, and sound effects, with plans to offer both free and premium versions in the future.
