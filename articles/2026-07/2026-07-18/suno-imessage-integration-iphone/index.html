Apple 📱 스마트폰

Suno, iMessage 연동: Apple iPhone 17 등 스마트폰 사용자가 채팅 내에서 AI로 노래 생성 가능

2026-07-18

iMessage 연동 기능

IT홈(IT之家)의 보도에 따르면, 기술 매체 9to5Mac은 어제(7월 15일) 게시물을 통해 Suno 앱이 설치된 iPhone 사용자가 대화 화면을 벗어나지 않고 iMessage 내에서 텍스트 프롬프트나 음성 메모를 통해 직접 노래를 생성할 수 있게 되었다고 보도했습니다.

Suno 서비스 정보

Suno는 주요 AI 음악 생성 플랫폼 중 하나로, 현재 전 세계적으로 200만 명 이상의 유료 사용자를 보유하고 있으며 매일 700만 곡 이상의 노래를 생성하고 있습니다.

업데이트 상세

7월 7일에 업데이트된 Suno 앱 버전에서는 iMessage 앱 드로어에 새로운 기능 진입점이 추가되었습니다. 사용자는 대화 화면 내에서 해당 확장을 호출하여 텍스트 프롬프트로 노래를 생성하거나 음성 메모를 통해 생성을 트리거할 수 있습니다.

사용 편의성

새롭게 도입된 iMessage 환경에서 사용자는 먼저 음악 장르를 선택한 후 노래 생성을 실행할 수 있습니다. 첫 번째 결과가 만족스럽지 않을 경우, 생성 결과를 새로고침하여 다양한 버전을 확인한 후 채팅방으로 전송할 수 있습니다.

총평

Suno 앱이 iMessage와 연동되어 iPhone 사용자가 대화창을 벗어나지 않고 텍스트나 음성 메모로 노래를 생성할 수 있게 되었습니다. 사용자는 음악 장르 선택 및 결과물 새로고침 기능을 통해 원하는 스타일의 곡을 생성하여 채팅에 공유할 수 있습니다.

Suno 与 iMessage 集成功能

iPhone 用户现在无需离开对话界面，即可在 iMessage 中通过文本提示或语音备忘录直接生成歌曲。该功能已在 7 月 7 日更新的 Suno 应用版本中加入，并在 iMessage 应用抽屉中提供了新的功能入口。

Suno 平台概况

  • 付费用户：全球拥有超过 200 万付费用户。
  • 生成量：每天生成超过 700 万首歌曲。

交互流程与操作细节

在 iMessage 的新功能场景中，用户可以进行以下操作：

  • 选择特定的音乐流派。
  • 通过文本提示或语音备忘录触发生成。
  • 若对初次输出结果不满意，支持刷新并查看不同版本后再发送到聊天中。

总结

Suno 已在 iMessage 中推出新功能，允许 iPhone 用户直接在对话界面内通过文字或语音创作音乐。这一集成简化了操作流程，让用户能够更便捷地在社交场景中分享 AI 生成的歌曲。

iMessage連携機能

ITホームの報道によると、テックメディアの9to5Macは昨日（7月15日）の投稿において、SunoアプリをインストールしたiPhoneユーザーが、チャット画面を離れることなくiMessage内でテキストプロンプトやボイスメモを通じて直接楽曲を生成できるようになったと報じました。

Sunoサービス情報

Sunoは主要なAI音楽生成プラットフォームの1つであり、現在世界中で以下の規模を誇っています。

  • 有料ユーザー数：200万人以上
  • 1日の楽曲生成数：700万曲以上

アップデートの詳細

7月7日に更新されたSunoアプリでは、iMessageのアプリドロワーに新しい機能への入り口が追加されました。ユーザーは会話画面内でこの拡張機能を呼び出すことで、テキストプロンプトによる楽曲生成や、ボイスメモによる生成のトリガーを実行することが可能です。

利便性

新しく導入されたiMessage環境において、ユーザーはまず音楽ジャンルを選択してから楽曲生成を実行できます。最初の結果が満足のいくものでない場合、生成結果をリフレッシュしてさまざまなバージョンを確認した上で、チャットルームへ送信することができます。

総評

SunoアプリとiMessageの連携により、iPhoneユーザーは会話のコンテキストを維持したまま、テキストやボイスメモで楽曲を作成し共有できるようになりました。音楽ジャンルの選択や結果の再生成機能により、ユーザーは好みのスタイルの曲をスムーズに作成・共有することが可能です。

まとめ

SunoアプリがiMessageと連携し、iPhoneユーザーがチャット画面から離れることなくテキストやボイスメモでAI楽曲を生成できる機能が追加されました。このアップデートにより、特定のジャンル選択や結果の再生成が可能になり、よりシームレスな音楽制作と共有体験が提供されます。

iMessage Integration

According to a report by IT Home, the tech media outlet 9to5Mac published a post on July 15 stating that iPhone users with the Suno app installed can now generate music directly within iMessage. Users can create songs using text prompts or voice memos without ever leaving the conversation screen.

Suno Service Information

Suno is one of the leading AI music generation platforms, currently boasting a significant global presence:

  • Over 2 million paid users worldwide
  • More than 7 million songs generated daily

Update Details

In the version updated on July 7, a new entry point was added to the iMessage app drawer. This allows users to invoke the extension within the chat window to generate music via text prompts or trigger creation through voice memos.

User Convenience

Within the newly integrated iMessage environment, users can select a specific music genre before initiating the generation process. If the first result is not satisfactory, they can refresh the output to view different versions before sending the final track to the chat room.

Summary

Suno has integrated with iMessage, allowing iPhone users to create songs using text or voice memos directly within their conversation threads. The feature includes options for genre selection and result refreshing, providing a seamless way to generate and share AI-powered music in real-time.
