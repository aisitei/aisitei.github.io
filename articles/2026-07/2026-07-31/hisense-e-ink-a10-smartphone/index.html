4년의 공을 들인 하이센스 E-Ink 스크린 스마트폰 A10 시리즈 8월 28일 출시: 자석 부착형 LCD 컬러 보조 스크린 선택 가능

2026-07-31

제품 출시 정보

Hisense의 E-Ink 스크린 스마트폰 A10 시리즈가 JD.com에 상륙했습니다. Pro 버전과 Ultra 버전으로 구성된 이번 신제품은 8월 28일 정식 판매를 시작할 예정이며, 현재 가격 정보는 공개되지 않았습니다.

제공되는 SKU 사양은 다음과 같습니다:

  • 8GB RAM + 128GB 저장 공간
  • 8GB RAM + 256GB 저장 공간
  • 12GB RAM + 512GB 저장 공간

주요 사양

해당 시리즈는 전면에 6.13인치 E-Ink 스크린을 탑재했으며, Qualcomm QCM6690 프로세서를 탑재하고 Android 16 시스템과 호환됩니다. 또한 NFC, 적외선 리모컨, 앱 분할, 통화 녹음, 마그네틱 무선충전 등의 기능을 지원합니다.

모델별 특징

Hisense A10 Ultra 모델은 마그네틱 탈부착이 가능한 컬러 LCD 보조 스크린을 기본으로 제공하며, A10 Pro 모델은 본체 후면에 마그네틱 링과 금속 접점을 탑재하여 별도의 컬러 보조 스크린을 장착할 수 있는 구조입니다.

이전 모델 정보

Hisense가 이전에 출시한 E-Ink 스크린 스마트폰은 2022년 출시된 A9 모델로, 약 4년 만에 신제품가 출시됩니다. 당시 A9는 6.1인치 300ppi E-Ink 스크린을 탑재했으며 가격은 1799위안부터 시작했습니다.

총평

Hisense는 약 4년 만에 새로운 E-Ink 스크린 스마트폰 A10 시리즈를 출시하며 Pro와 Ultra 두 가지 버전을 선보입니다. 각 모델은 마그네틱 방식의 컬러 보조 스크린 지원 여부에 차이가 있으며, 최신 Android 시스템과 다양한 편의 기능을 탑재한 것이 특징입니다.

产品发布与上市信息

海信旗下 A10 系列 E-Ink 屏幕手机已在京东上架。该系列包含 Pro 版本和 Ultra 版本，计划于 8 月 28 日正式开售，目前尚未公布具体价格。

存储配置选项

  • 8GB RAM + 128GB 存储空间
  • 8GB RAM + 256GB 存储空间
  • 12GB RAM + 512GB 存储空间

核心硬件与功能规格

A10 系列手机搭载了以下关键技术参数：

  • 屏幕：6.13 英寸 E-Ink 屏幕
  • 处理器：Qualcomm QCM6690
  • 系统：Android 16
  • 附加功能：支持 NFC、红外遥控、应用分身、通话录音及磁吸无线充电。

型号差异说明

A10 Ultra 版本标配一块磁吸可拆卸彩色 LCD 副屏。而 A10 Pro 机身背部配备磁吸环和金属触点，预计需要额外购买配套的彩色副屏。

总结

海信即将于 8 月 28 日推出搭载 E-Ink 屏幕的 A10 系列手机。该系列提供 Pro 和 Ultra 两个版本，搭载 Qualcomm QCM6690 处理器及 Android 16 系统，并具备独特的磁吸副屏功能。

製品発売情報

HisenseのE-Inkスクリーン搭載スマートフォン「A10シリーズ」がJD.comに登場しました。ProとUltraの2つのモデルで構成されるこの新製品は、8月28日より正式に販売を開始する予定ですが、現時点で価格情報は公開されていません。

提供されるSKU構成は以下の通りです：

  • 8GB RAM + 128GB ストレージ
  • 8GB RAM + 256GB ストレージ
  • 12GB RAM + 512GB ストレージ

主な仕様

本シリーズは前面に6.13インチのE-Inkスクリーンを搭載しており、Qualcomm QCM6690プロセッサを搭載し、Android 16システムと互換性があります。また、NFC、赤外線リモコン、アプリ分割、通話録音、マグネット式ワイヤレス充電などの機能をサポートしています。

モデル別の特徴

Hisense A10 Ultraモデルは、磁石で着脱可能なカラーLCDサブスクリーンを標準で提供します。一方、A10 Proモデルは本体背面にマグネットリングと金属接点を搭載しており、別売りのカラーサブスクリーンを取り付けることができる構造となっています。

前モデルの情報

Hisenseが以前に発売したE-Inkスクリーン搭載スマートフォンは、2022年にリリースされたA9モデルであり、約4年ぶりの新製品となります。当時のA9は6.1インチ300ppiのE-Inkスクリーンを搭載し、価格は1799元からとなっていました。

まとめ

Hisenseは約4年ぶりにE-Inkスクリーン搭載スマートフォン「A10シリーズ」を発表し、ProとUltraの2つのバリエーションを展開します。各モデルは磁石によるカラーサブスクリーンのサポート有無に違いがあり、最新のAndroidシステムや多彩な便利機能を備えているのが特徴です。

Product Launch Information

The Hisense A10 series, featuring E-Ink screens, has arrived on JD.com. The new lineup consists of Pro and Ultra versions, which are scheduled to go on sale officially starting August 28. Pricing information for the devices has not yet been disclosed.

The available SKU specifications are as follows:

  • 8GB RAM + 128GB storage
  • 8GB RAM + 256GB storage
  • 12GB RAM + 512GB storage

Key Specifications

The series features a 6.13-inch E-Ink screen on the front and is powered by the Qualcomm QCM6690 processor, making it compatible with the Android 16 system. Additionally, the devices support various features including NFC, infrared remote control, split-screen mode, call recording, and magnetic wireless charging.

Model Variations

The Hisense A10 Ultra model comes standard with a detachable magnetic color LCD secondary screen. The A10 Pro model is designed with magnetic rings and metal contacts on the rear of the body, allowing for the attachment of an optional external color secondary screen.

Previous Model Information

The last E-Ink smartphone released by Hisense was the A9 model in 2022, making this new series a release after approximately four years. At that time, the A9 featured a 6.1-inch 300ppi E-Ink screen and started at a price of 1,799 RMB.

Summary

Hisense is launching the A10 series with Pro and Ultra versions featuring E-Ink displays and support for magnetic color secondary screens. The new lineup integrates modern features like Android 16 compatibility and various convenience functions after a four-year gap since the previous model.
