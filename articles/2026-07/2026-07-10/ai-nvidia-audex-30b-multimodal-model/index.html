NVIDIA, 멀티모달 확장 시 텍스트 능력 저하를 방지하는 30B 파라미터 규모의 Audex 통합 모델 발표

2026-07-10

모델 개요

NVIDIA는 올해 6월 논문을 발표하며 Audex(Nemotron-Labs-Audex-30B-A3B)를 공개했습니다. 이 모델은 총 파라미터 수 30B, 활성 파라미터 3B 규모의 통합 오디오-텍스트 대규모 언어 모델로, 핵심적인 텍스트 지능을 유지하면서도 오디오(audio)와 음성(speech)을 이해하고 생성할 수 있습니다.

모델 구조 및 설계

이 모델의 백본은 Nemotron-Cascade-2-30B-A3B라는 텍스트 모델로, 다음과 같은 구조를 가집니다.

  • 52개 층의 하이브리드 Mamba-Transformer 구조
  • 128개의 라우터블 전문가(routable experts) 포함
  • 매회 6개의 전문가 활성화

Audex의 설계 목표는 멀티모디컬 확장 시 발생할 수 있는 텍스트 능력 저하 문제를 방지하는 것입니다. 논문에 따르면 Audex는 오디오 입력을 인코딩하여 텍스트 임베딩 공간으로 매핑하며, 양자화된 오디오 출력 토큰과 텍스트 토큰을 통합적으로 처리합니다.

오디오 및 음성 기술

Audex는 오디오 구성 요소와 음성 출력을 위해 다음과 같은 기술을 적용했습니다.

  • 오디오 인코더: AF-Whisper를 사용하여 16kHz 입력을 처리하며, 두 개의 MLP 어댑터를 통해 특징을 매핑합니다.
  • 단어집 확장: 출력 단어집이 기존 131,072개에서 205,312개의 토큰으로 확장되었습니다.
  • 음성 출력: X-Codec2(음성 코덱)를 사용하여 초당 50개 토큰을 처리하며, 단일 레이어의 finite scalar quantization을 적용하고 코드북 크기는 65,536입니다.
  • 비음성 오디오: X-Codec(오디오 코덱)을 사용하며 초당 200개 토큰을 처리하고, 4개 레이어의 flattened residual vector quantization을 활용합니다.

텍스트 성능 평가

텍스트 평가 결과, Audex는 MMLU-Redux에서 86.4를 기록하여 백본 모델(86.3)보다 높은 성적을 거두었으며, IMO AnswerBench에서는 81.1을 기록해 백본의 79.3을 상회했습니다. 다만 MMLU-Pro와 GPQA-Diamond에서는 소폭 하락하는 수치를 보였습니다.

총평

NVIDIA가 공개한 Audex는 멀티모디컬 확장 시에도 텍스트 지능의 저하를 방지하도록 설계된 통합 오디오-텍스트 대규모 언어 모델입니다. Mamba-Transformer 기반의 구조와 고도화된 코덱 기술을 결합하여 오디오 및 음성 처리 능력을 확보했으며, 주요 텍스트 평가에서 우수한 성능을 입증했습니다.

模型概述

NVIDIA 推出了 Audex（Nemotron-Labs-Audex-30B-A3B）统一音频-文本大语言模型。该模型旨在在保留核心文本智能的同时，具备理解和生成音频（audio）以及语音（speech）的能力。

技术架构与参数

Audex 基于 Nemotron-Cascade-2-30B-A3B 骨干模型构建，采用混合 Mamba-Transformer 结构。其设计核心是防止多模态扩展后导致的文本能力下滑。

  • 总参数量：30B
  • 激活参数：3B
  • 架构细节：52 层混合 Mamba-Transformer 结构，包含 128 个可路由专家，每次激活 6 个。

音频与语音处理组件

Audex 通过将音频输入编码并映射到文本嵌入空间，实现对量化后的音频输出标记和文本标记的统一处理。

  • 音频编码：使用 AF-Whisper 处理 16kHz 输入，配合两层 MLP 适配器。
  • 词表扩展：从原始的 131,072 个 Token 扩展至 205,312 个 Tokens。
  • 语音输出（X-Codec2）：速率为每秒 50 个标记，码本大小为 65,536。
  • 非语音音频（X-Codec）：速率为每秒 200 个标记。

性能评测

在相关基准测试中，Audex 在保持文本能力的同时展现了优异的跨模态表现：

  • MMLU-Redux：得分 86.4（高于骨干模型的 86.3）。
  • IMO AnswerBench：得分 81.1（高于骨干模型的 79.3）。
  • 在 MLLU-Pro 与 GPQA-Diamond 上出现小幅下降。

总结

NVIDIA 推出的 Audex 是一个集成了音频与文本处理能力的统一大模型，采用混合 Mamba-Transformer 架构并支持大规模词表扩展。该模型成功实现了在增强多模态能力的同时，保持甚至提升核心文本推理性能。

モデル概要

NVIDIAは今年6月に論文を発表し、Audex（Nemotron-Labs-Audex-30B-A3B）を公開しました。このモデルは総パラメータ数30B、アクティブパラメータ3Bの統合オーディオ・テキスト大規模言語モデル（LLM）であり、核となるテキスト知能を維持しながら、オーディオおよび音声の理解と生成を行うことができます。

モデル構造と設計

このモデルのバックボーンはNemotron-Cascade-2-30B-A3Bというテキストモデルで、以下の構造を備えています。

  • 52層のハイブリッドMamba-Transformer構造
  • 128個のルータブルエキスパート（routable experts）を含む
  • 毎回の推論で6つのエキスパートをアクティブ化

Audexの設計目標は、マルチモーダル拡張時に発生しうるテキスト能力の低下を防ぐことです。論文によると、Audexはオーディオ入力をエンコードしてテキスト埋め込み空間にマッピングし、量子化されたオーディオ出力トークンとテキストトークンを統合的に処理します。

オーディオおよび音声技術

Audexはオーディオコンポーネントと音声出力を実現するために、以下の技術を採用しています。

  • オーディオエンコーダー：AF-Whisperを使用して16kHzの入力を処理し、2つのMLPアダプターを通じて特徴をマッピングします。
  • 語彙（Vocabulary）の拡張：出力トークン数が従来の131,072から205,312へと拡大されました。
  • 音声出力：X-Codec2（音声コーデック）を使用し、毎秒50トークンを処理します。単一レイヤーの有限スカラー量子化（finite scalar quantization）を適用し、コードブックサイズは65,536です。
  • 非音声オーディオ：X-Codec（オーディオコーデック）を使用し、毎秒200トークンを処理します。4層のフラットな残差ベクトル量子化（flattened residual vector quantization）を活用しています。

テキスト性能評価

テキスト評価の結果、AudexはMMLU-Reduxで86.4を記録し、バックボーンモデル（86.3）を上回る成績を収めました。また、IMO AnswerBenchでは81.1を記録し、バックボーンの79.3を上回りました。一方で、MMLU-ProとGPQA-Diamondではわずかに低下する数値が見られました。

総評

NVIDIAが公開したAudexは、マルチモーダルの拡張時にもテキスト知能の低下を防ぐよう設計された統合オーディオ・テキスト大規模言語モデルです。Mamba-Transformerベースの構造と高度なコーデック技術を組み合わせることで、優れたオーディオおよび音声処理能力を獲得し、主要なテキスト評価においても高い性能を実証しました。

まとめ

NVIDIAが発表したAudexは、Mamba-Transformer構造と高度なコーデック技術を融合させた統合オーディオ・テキストLLMです。マルチモーダル化によるテキスト能力の低下を防ぐ設計により、高品質な音声処理と優れたテキスト性能の両立を実現しています。

Model Overview

NVIDIA released Audex (Nemotron-Labs-Audex-30B-A3B) in June of this year. This integrated audio-text Large Language Model features a total of 30B parameters with 3B active parameters, enabling it to understand and generate audio and speech while maintaining core text intelligence.

Model Structure and Design

The backbone of this model is the Nemotron-Cascade-2-30B-A3B text model, which incorporates the following architecture:

  • 52-layer hybrid Mamba-Transformer structure
  • 128 routable experts
  • 6 active experts per inference

The design goal of Audex is to prevent the degradation of text capabilities that can occur during multimodal expansion. According to the research paper, Audex maps audio inputs into a text embedding space and processes quantized audio output tokens and text tokens together.

Audio and Speech Technology

Audex implements the following technologies for its audio components and speech output:

  • Audio Encoder: Uses AF-Whisper to process 16kHz input, mapping features through two MLP adapters.
  • Vocabulary Expansion: The output vocabulary was expanded from 131,072 to 205,312 tokens.
  • Speech Output: Utilizes X-Codec2 (speech codec) to process 50 tokens per second, applying finite scalar quantization on a single layer with a codebook size of 65,536.
  • Non-speech Audio: Uses X-Codec (audio codec) to process 200 tokens per second, utilizing flattened residual vector quantization across four layers.

Text Performance Evaluation

In text evaluation tests, Audex scored 86.4 on MMLU-Redux, outperforming its backbone model's score of 86.3. It also achieved 81.1 on IMO AnswerBench, surpassing the backbone's 79.3. However, it showed slight decreases in scores for MLLU-Pro and GPQA-Diamond.

Overall Review

NVIDIA's Audex is an integrated audio-text LLM designed to prevent the loss of text intelligence during multimodal expansion. By combining a Mamba-Transformer based architecture with advanced codec technologies, it achieves robust audio and speech processing capabilities while demonstrating superior performance in key text evaluations.

Summary

NVIDIA's Audex is an integrated audio-text LLM that maintains high-level text intelligence while providing advanced audio and speech generation capabilities. By utilizing a hybrid Mamba-Transformer architecture and specialized codecs, it successfully balances multimodal expansion with core linguistic performance.
