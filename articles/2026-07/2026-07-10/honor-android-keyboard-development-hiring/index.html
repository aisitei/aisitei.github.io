Honor 📱 스마트폰

Honor, 안드로이드 스마트폰용 자체 개발 입력기 구축 및 '개발 전문가' 모집 중

2026-07-10

채용 소식

IT홈의 7월 7일 보도에 따르면, Honor 공식 홈페이지에 업데이트된 채용 정보에 따르면 Honor 단말기 관련 부문에서 '입력 방식 Android 개발 전문가'를 모집하고 있습니다.

해당 직무의 설명에 따르면, Honor는 기초부터 구축하는 완전히 자체 개발한 입력 방식 시스템을 계획하고 있으며, 여기에는 단말기 측 UX 상호작용 프레임워크, 입력 엔진(음성, 키보드, 필기 포함), 개인화된 단어 사전의 온디바이스 및 클라우드 동기화, 지연 시간 및 전력 소모 최적화 등 여러 핵심 모듈이 포함됩니다.

자격 요건 측면에서 Honor는 지원자가 0에서 1로 복잡한 클라이언트 UI/UX 상호작용 프레임워크를 구축해 본 숙련된 경험을 갖추고 있어야 하며, Android 입력 방식 프레임워크에 대한 깊은 이해와 입력 엔진, 단어 사전 관리 등 관련 모듈의 전체 개발 경험이 있는 사람을 요구합니다.

또한, 해당 직무는 다음과 같은 기술 및 경험을 요구합니다:

  • Systrace, PerfDog 등의 도구를 활용한 전 경로 성능 최적화 능력
  • Cursor, Claude Code 등 AI 프로그래밍 도구를 활용한 연구 개발 효율화 실무 경험
  • Sogou, Baidu, iFlytek, Huawei, Xiaomi 등 주요 입력 방식 제품 개발 경험

배경 및 동기

현재 Honor 스마트폰 시스템에는 Baidu 입력 방식 Honor 버전이 사전 설치되어 있습니다. 그러나 Honor 공식 커뮤니티에서는 자사 개발 입력 방식에 대한 사용자의 요구가 오랫동안 지속되어 왔습니다. 일부 사용자는 서드파티 입력 방식을 사용할 경우 '데이터 루프 단절'이 발생한다고 판단합니다. 즉, 사용자의 입력 데이터와 개인화된 단어 사전 등 핵심 자산이 서드퍼티 플랫폼에 쌓여 Honor가 자체 개발한 YOYO 스마트 엔진과 엔드 투 엔드 서비스 루프를 형성하기 어렵다는 것입니다. 또한 제품 혁신의 속도가 타인에게 제약받아 '소프트웨어 및 하드웨어 코어'의 통합적인 빠른 업데이트를 구현할 수 없다는 의견입니다.

업계 동향 및 특허

산업 트렌드로 볼 때, 주요 스마트폰 제조사들의 입력 방식 자체 개발은 일반적인 현상이 되었습니다. Apple은 2007년부터 iOS 네이티브 입력 방식을 탑재해 왔으며, vivo는 2016년에 Jovi 입력 방식을 출시했고, Huawei는 2021년에 Xiaoyi(小艺) 입력 방식을 발표했습니다. 올해 3월, Xiaomi도 Xiaomi HyperOS(Xiaomi 澎湃 OS) 3 베타 버전에서 자체 개발한 입력 방식을 선보이며 시스템 하단에 직접 통합하고 대규모 언어 모델 AI 기능을 결합했습니다.

또한 국가지식재산권국 정보에 따르면, Honor는 2024년 7월 '입력 방식 전환 방법 및 관련 장치'라는 명칭의 특허(공개 번호: CN121387112A)를 신청했습니다. 해당 특허는 후보 단어 정확도와 개인정보 보호 사이의 균형을 맞추기 위해 사용자 공간에 따라 입력 방식 모드를 자동으로 전환하는 기술 솔루션을 포함합니다.

총평

Honor는 데이터 루프 형성 및 소프트웨어와 하드웨어 코어의 통합적 업데이트를 위해 자사 개발 입력 시스템 구축을 목표로 전문 인력을 채용하고 있습니다. 이는 Apple, vivo, Huawei, Xiaomi 등 주요 제조사들이 이미 추진해 온 기술 트렌드와 궤를 같이하며, 관련 특허 출정을 통해 기술적 기반을 강화하고 있는 것으로 보입니다.

招聘信息披露

Honor 官网更新显示，公司正在招募“输入法Android开发专家”。该岗位的核心目标是构建一套从底层开始的完全自研输入法系统。

  • 涵盖模块：端侧 UX 交互框架、包含语音、键盘、手写的输入引擎。
  • 核心功能：个人化词库的端云同步、时延与功耗优化等。

任职要求与技术栈

Honor 要求候选人具备从 0 到 1 搭建复杂客户端 UI/UX 交互框架的经验，并深入理解 Android 输入法框架及相关模块开发。

  • 性能工具：Systrace、PerfDog。
  • AI 工具：Cursor、Claude Code。
  • 优先背景：具有搜狗、百度、讯飞、Huawei、Xiaomi 等主流产品开发经验者优先。

战略动机与行业趋势

目前 Honor 手机预装的是百度输入法，但用户呼声要求自研。自研旨在解决“数据闭环断裂”问题，让用户词库等核心资产能与 YOYO 智慧引擎形成端到端的服务闭环。

行业内 Apple、vivo、Huawei 以及近期在 HyperOS 中推出自研输入法的 Xiaomi 等厂商均已采取类似策略，旨在实现“软硬芯”一体化迭代。

专利布局

Honor 已于 2024 年 7 月申请相关专利（公开号：CN121387112A），涉及根据用户空间自动切换输入法模式的技术方案，旨在平衡候选词准确率与隐私安全。

总结

Honor 正通过招聘专业人才构建全自研的输入法系统，以解决目前依赖第三方平台导致的“数据闭环断裂”问题。此举旨在提升用户体验并实现与 YOYO 智慧引擎的深度融合，符合当前主流手机厂商强化底层技术自主权的趋势。

採用情報

ITホームの7月7日の報道によると、Honorの公式サイトに更新された採用情報において、Honor端末関連部門で「入力方式Android開発エキスパート」を募集していることが明らかになりました。

職務内容によると、Honorは基礎から構築する完全な自社開発の入力システムを計画しており、これにはデバイス側のUXインタラクションフレームワーク、入力エンジン（音声、キーボード、手書きを含む）、パーソナライズされた単語辞書のオンデバイスおよびクラウド同期、遅延および消費電力の最適化など、複数の主要モジュールが含まれます。

応募要件として、Honorは候補者が0から1へ複雑なクライアントUI/UXインタラクションフレームワークを構築した熟練した経験を持ち、Android入力方式フレームワークに対する深い理解と、単語辞書管理などの関連モジュールの全開発経験を有することを求めています。

また、この職務では以下の技術および経験が求められます：

  • Systrace、PerfDogなどのツールを活用した全経路のパフォーマンス最適化能力
  • Cursor、Claude CodeなどAIプログラミングツールを活用した研究開発効率化の実務経験
  • Sogou、Baidu、iFlytek、Huawei、Xiaomiなど主要な入力方式製品の開発経験

背景と動機

現在、HonorのスマートフォンシステムにはBaiduの入力方式（Honor版）がプリインストールされています。しかし、Honor公式コミュニティでは、自社開発の入力方式に対するユーザーの要望が長らく続いています。一部のユーザーは、サードパーティの入力方式を使用する場合、「データのループ断絶」が発生すると判断しています。つまり、ユーザーの入力データやパーソナライズされた単語辞書などの重要な資産がサードパーティのプラットフォームに蓄積され、Honorが独自開発したYOYOスマートエンジンやエンド・トゥ・エンドのサービスループを構築することが困難になるという懸念です。また、製品革新のスピードが他社に制限され、「ソフトウェアとハードウェアのコア」の統合的な迅速なアップデートを実現できないという意見もあります。

業界動向と特許

産業トレンドとして、主要なスマートフォンメーカーによる入力方式の自社開発は一般的な現象となっています。Appleは2007年からiOSネイティブの入力方式を搭載しており、vivoは2016年にJovi入力方式をリリースし、Huaweiは2021年にXiaoyi（小意）入力方式を発表しました。今年3月、XiaomiもXiaomi HyperOS 3のベータ版で自社開発の入力方式を披露し、システム下層に直接統合し、大規模言語モデルAI機能を統合しました。

また、国家知識財産権局の情報によると、Honorは2024年7月「入力方法の切り替え方法および関連装置」という名称の特許（公開番号：CN121387112A）を申請しました。この特許は、候補単語の正確性とプライバシー保護のバランスをとるため、ユーザー空間に応じて入力モードを自動的に切り替える技術ソリューションを含んでいます。

まとめ

Honorは、データループの構築とハードウェア・ソフトウェアの統合的なアップデートを実現するため、自社開発の入力システム構築に向けた専門人材を採用しています。これはAppleやHuawei、Xiaomiといった主要メーカーが取り進めてきた技術トレンドに合致しており、特許取得を通じて技術基盤を強化する動きを見せています。

Recruitment News

According to a report by IT Home on July 7, Honor's official website has updated its recruitment information, seeking an "Android Input Method Development Specialist" for its device-related division.

The job description states that Honor plans to build a completely self-developed input system from the ground up. This includes several core modules: a device-side UX interaction framework, an input engine (covering voice, keyboard, and handwriting), on-device and cloud-synchronized personalized dictionaries, and optimization for latency and power consumption.

Regarding qualifications, Honor requires candidates with extensive experience in building complex client UI/UX interaction frameworks from the ground up. Candidates must possess a deep understanding of the Android input method framework and have comprehensive development experience in related modules such as input engines and dictionary management.

Additionally, the role requires the following skills and experience:

  • Ability to perform full-path performance optimization using tools like Systrace and PerfDog.
  • Practical experience in improving R&D efficiency using AI programming tools such as Cursor and Claude Code.
  • Experience in developing input method products for major providers including Sogou, Baidu, iFlytek, Huawei, and Xiaomi.

Context and Motivation

Currently, Honor smartphones come pre-installed with the Baidu version of the input method. However, there has been a long-standing demand from the Honor official community for an in-house developed input method. Some users argue that using third-party input methods results in a "data loop disconnection." Specifically, they point out that because core assets—such as user input data and personalized dictionaries—are stored on third-party platforms, it is difficult for Honor to establish its own YOYO smart engine and an end-to-end service loop. Furthermore, some argue that relying on others limits the pace of innovation, making it impossible to achieve rapid, integrated updates for "software and hardware cores."

Industry Trends and Patents

From an industry trend perspective, the independent development of input methods by major smartphone manufacturers has become common. Apple has featured a native iOS input method since 2007, vivo launched the Jovi input method in 2016, and Huawei introduced the Xiaoyi (小艺) input method in 2021. In March of this year, Xiaomi also showcased its self-developed input method in the beta version of Xiaomi HyperOS, integrating it directly into the system layer while combining it with Large Language Model (LLM) AI features.

Furthermore, according to information from the National Intellectual Property Administration, Honor applied for a patent titled "Method for Switching Input Methods and Related Device" (Publication Number: CN121387112A) in July 2024. This patent includes a technical solution that automatically switches input method modes based on the user's space to balance candidate word accuracy with privacy protection.

Overall Review

Honor is actively recruiting specialists to build an in-house input system to establish data loops and achieve integrated updates between software and hardware cores. This move aligns with the technical trends pursued by major manufacturers such as Apple, vivo, Huawei, and Xiaomi, and appears to be bolstered by their recent patent filings to strengthen their technical foundation.

Summary

Honor is hiring experts to develop a proprietary Android input method system to replace current third-party solutions and improve the integration of its hardware and software ecosystem. This move follows industry trends set by competitors like Apple, Huawei, and Xiaomi, who have all moved toward in-house input systems. The initiative is supported by recent patent filings aimed at balancing user privacy with high-accuracy input features.
