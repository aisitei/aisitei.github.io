Meta, AI 에이전트의 작업 능력을 강화하는 멀티모달 추론 모델 Muse Spark 1.1 발표

2026-07-13

모델 개요

Meta는 7월 9일 AI 에이전트를 위한 멀티모달 추론 모델 Muse Spark 1.1을 공식 발표했습니다. 이 모델은 에이전트 작업에서의 계획, 협업 및 실행 능력을 중점적으로 강화했으며, 도구 호출, 코드 개발, 애플리케이션 조작 능력을 향상시켰습니다.

협업 및 컨텍스트

Meta에 따르면 Muse Spark 1.1은 멀티 에이전트 협력 메커니즘을 강화했습니다. 메인 에이전트가 정보를 수집하고 계획을 세우면, 이를 분할하여 여러 서브 에이전트에게 할당해 병렬로 실행함으로써 복잡한 프로젝트의 처리 시간을 단축합니다. 또한 최대 100만 토큰의 컨텍스트 길이를 지원하여 긴 작업 흐름 속에서도 핵심 정보를 유지하고 초기 단계의 내용을 호출할 수 있습니다.

애플리케이션 및 코드 개발

애플리케이션 조작 측면에서 Muse Spark 1.1은 여러 애플리케이션 간에 지속적인 장기 프로세스 작업을 수행할 수 있으며, 상황에 따라 인터페이스를 직접 클릭하거나 자동화를 위한 스크립트를 작성하는 등의 판단을 스스로 내립니다. 코드 개발 분야에서는 복잡한 프로그램 오류 진단 및 수정, 신규 기능 개발, 대규모 코드 마이그레이션 등을 지원하며, 개발 단계를 미리 계획하고 하위 작업을 분할하여 긴 개발 과정 중에도 중요한 컨텍스트를 유지합니다.

안전성 및 성능 비교

Meta는 Muse Spark 1.1의 안전성을 강조하며 내부 보안 프레임워크인 'Advanced AI Scaling Framework'에 따른 사전 평가를 완료했다고 밝혔습니다. 이 모델은 화학 및 생물학적 안전, 사이버 보안, 통제 상실 위험 등에서 안전 범위를 유지하며, 프롬프트 주입이나 탈옥 공격에 대한 저항력을 높이고 환각 현상과 사용자 동조 경력(Sycophancy)을 줄였습니다.

내부 평가 결과에 따르면 Muse Spark 1.1은 에이전트 능력, 코드 개발 및 일반 추론 측면에서 전 세대 대비 눈에 띄는 향상을 보였으며, 신뢰도 교정 및 위험 식별 등에서도 개선되었습니다. 다만 일부 PC 조작, 긴 컨텍스트 및 코드 개발 테스트에서는 GPT-5.5와 Claude Opus 4.8보다 낮은 성능을 기록했습니다.

서비스 제공

현재 Muse Spark 1.1은 Meta AI 앱과 meta.ai의 Thinking 모드에 탑재되었습니다. 또한 공식적으로 일반 개발자를 위한 Meta Model API 프리뷰 버전을 공개하여, 개발자들이 이 모델을 호출하고 자신의 애플리케이션에 통합할 수 있도록 지원합니다.

총평

Meta는 에이전트 협력과 코드 개발 및 앱 조작 능력이 강화된 Muse Spark 1.1을 출시했습니다. 이 모델은 긴 컨텍스트와 향상된 보안성을 제공하지만, 특정 영역에서는 GPT-5.5나 Claude Opus 4.8에 비해 성능이 뒤처지는 것으로 나타났습니다.

模型核心能力

Meta 正式发布 Muse Spark 1.1 多模态推理模型，专门为 AI 智能体设计。该版本显著提升了模型在任务规划、协同执行、工具调用、代码开发以及跨应用操作方面的综合能力。

技术规格与协作机制

Muse Spark 1.1 通过强化多智能体协作机制来优化复杂项目的处理效率，并提供强大的上下文支持：

  • 支持最高 100 万 token 的上下文长度，确保长流程中的信息连续性。
  • 采用“主智能体规划、子智能体并行执行”的架构，缩短任务处理时间。
  • 具备跨应用操作能力，可根据场景自动选择点击界面、编写脚本或批量执行步骤。

代码开发与安全防护

在软件工程领域，Muse Spark 1.1 支持复杂错误诊断、新功能开发及大规模代码迁移。同时，Meta 对模型安全性进行了严格把控：

  • 通过 Advanced AI Scaling Framework 评估，确保在生物、化学、网络安全等领域的合规性。
  • 增强了对提示词注入和越狱攻击的抵抗力。
  • 降低了模型的幻觉现象及迎合用户倾向。

性能对比与发布渠道

尽管 Muse Spark 1.1 在智能体能力和通用推理上优于前代，但在部分特定测试（如长上下文、代码开发）中仍落后于 GPT-5.5 和 Claude Opus 4.8。目前该模型已上线 Meta AI App 及 meta.ai 的 Thinking 模式，并面向开发者开放 Meta Model API 预览版。

总结

Meta 推出的 Muse Spark 1.1 是一个强化了多智能体协作和长上下文处理能力的多模态推理模型。它在代码开发、自动化操作及安全性方面有显著提升，目前已通过多种渠道面向用户和开发者开放使用。

モデル概要

Metaは7月9日、AIエージェント向けのマルチモーダル推論モデル「Muse Spark 1.1」を正式に発表しました。このモデルは、エージェントによるタスク遂行における計画、協力、および実行能力の強化に重点を置いており、ツール呼び出し、コード開発、アプリケーション操作能力の向上を実現しています。

連携とコンテキスト

Metaによると、Muse Spark 1.1はマルチエージェントの協力メカニズムを強化しています。メインエージェントが情報を収集し計画を立てると、それを分割して複数のサブエージェントに割り当てて並列で実行することで、複雑なプロジェクトの処理時間を短縮します。また、最大100万トークンのコンテキスト長をサポートしており、長い作業フローの中でも重要な情報を維持し、初期段階の内容を参照することが可能です。

アプリケーションおよびコード開発

アプリケーション操作の面において、Muse Spark 1.1は複数のアプリケーション間での継続的な長期プロセスを実行でき、状況に応じてインターフェースを直接クリックするか、自動化のためのスクリプトを作成するかといった判断を自ら下します。コード開発分野では、複雑なプログラムのデバッグや修正、新機能の開発、大規模なコード移行などをサポートし、開発工程を事前に計画してサブタスクを分割することで、長期的な開発プロセスにおいても重要なコンテキストを維持します。

安全性と性能比較

MetaはMuse Spark 1.1の安全性を強調しており、内部セキュリティフレームワークである「Advanced AI Scaling Framework」に基づく事前評価を完了したことを明らかにしました。このモデルは化学・生物学的安全性、サイバーセキュリティ、制御喪失のリスクなどの範囲内で安全性を維持し、プロンプトインジェクションや脱獄（Jailbreak）攻撃への耐性を高め、ハルシネーションやユーザーへの迎合（Sycophancy）を低減しています。

内部評価の結果、Muse Spark 1.1はエージェント能力、コード開発、および一般的な推論において前世代と比較して顕著な向上を見せ、信頼性の校正やリスクの特定においても改善されました。一方で、一部のPC操作、長いコンテキスト、およびコード開発のテストにおいては、GPT-5.5やClaude Opus 4.8よりも低い性能を記録しました。

サービスの提供

現在、Muse Spark 1.1はMeta AIアプリおよびmeta.aiのThinkingモードに搭載されています。また、一般の開発者向けに「Meta Model API」のプレビュー版を公式に公開しており、開発者がこのモデルを呼び出し、自身のアプリケーションに統合できるようにサポートしています。

総評

Metaは、エージェントの連携、コード開発、およびアプリ操作能力が強化されたMuse Spark 1.1をリリースしました。このモデルは長大なコンテキストと向上した安全性を備えていますが、特定の領域ではGPT-5.5やClaude Opus 4.8に劣る性能を示すことも確認されています。

まとめ

MetaはAIエージェント向けのマルチモーダル推論モデル「Muse Spark 1.1」を発表し、高度なマルチエージェント連携と最大100万トークンのコンテキスト長による強力な処理能力を提供します。コード開発やアプリ操作において大幅な進化を見せつつ、強固なセキュリティフレームワークの導入により安全性を向上させています。一方で、特定のタスクにおいては競合モデルであるGPT-5.5やClaude Opus 4.8に及ばない場面もあると報告されています。

Model Overview

Meta officially unveiled Muse Spark 1.1, a multimodal reasoning model designed for AI agents, on July 9. The model focuses on enhancing planning, collaboration, and execution capabilities in agent tasks, while improving tool calling, code development, and application manipulation.

Collaboration and Context

According to Meta, Muse Spark 1.1 features an enhanced multi-agent cooperation mechanism. While a main agent gathers information and develops plans, these are divided among multiple sub-agents for parallel execution, thereby reducing the processing time for complex projects. Additionally, it supports a context length of up to 1 million tokens, allowing it to maintain core information and recall early details even during long workflows.

Application and Code Development

Regarding application manipulation, Muse Spark 1.1 can perform continuous, long-term tasks across multiple applications, making autonomous decisions such as interacting with interfaces directly or writing scripts for automation depending on the situation. In the field of code development, it supports complex program error diagnosis and correction, new feature development, and large-scale code migrations by pre-planning development stages and dividing sub-tasks to maintain critical context during long development cycles.

Safety and Performance

Meta emphasized the safety of Muse Spark 1.1, stating that it completed preliminary evaluations under its internal "Advanced AI Scaling Framework." The model maintains safety boundaries regarding chemical and biological risks, cybersecurity, and loss-of-control risks, while increasing resistance to prompt injection and jailbreak attacks and reducing hallucinations and sycophancy.

Internal evaluation results indicate that Muse Spark 1.1 showed significant improvements over the previous generation in agent capabilities, code development, and general reasoning, as well as improvements in reliability calibration and risk identification. However, it recorded lower performance than GPT-5.5 and Claude Opus 4.8 in certain areas, including PC manipulation, long context tasks, and code development tests.

Availability

Muse Spark 1.1 is currently integrated into the Meta AI app and the "Thinking" mode on meta.ai. Furthermore, Meta has officially released a preview version of the Meta Model API for general developers, enabling them to call the model and integrate it into their own applications.

Summary

Meta has launched Muse Spark 1.1, a multimodal reasoning model that enhances agent collaboration, code development, and application manipulation through multi-agent systems and a large context window. While the model shows significant improvements in safety and general reasoning over previous versions, it currently trails behind GPT-5.5 and Claude Opus 4.8 in specific areas like long-context coding and PC interaction.
