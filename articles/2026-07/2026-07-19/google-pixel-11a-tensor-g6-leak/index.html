Google Pixel 11a 스마트폰 유출: Tensor G6 자체 개발 칩, MediaTek M90 모뎀 탑재

2026-07-19

개요

IT홈은 7월 18일, 기술 매체 NotebookCheck가 Google Pixel 11a의 관련 사양 정보를 공개했다고 보도했습니다. 해당 기기의 내부 코드네임은 Formosan으로 확인되었습니다.

성능

Pixel 11a는 Google이 자체 개발한 Tensor G6 칩(코드네임 Malibu)과 Titan M3 보안 칩을 탑재할 예정입니다. 또한 PowerVR C 시리즈 GPU 칩(CXTP-48-1536) 및 MediaTek M90 모뎀을 채택합니다.

디스플레이

Pixel 11a는 다음과 같은 디스플레이 사양을 갖췄습니다.

  • 6.3인치 디스플레이
  • 1080 x 2424 해상도
  • 60~120Hz 주사율
  • HDR 모드 최대 밝기 2,250니트
  • 피크 밝기 최대 3,350니트

스펙

해당 기기는 8GB RAM을 탑재하며, 배터리 용량은 4,870mAh입니다. 이는 Pixel 10a의 5,100mAh보다 낮은 수치입니다.

색상

유출된 정보에 따르면 총 4가지 색상이 제공됩니다.

  • Obsidian (블랙)
  • Olive (그린)
  • Frost (퍼플)
  • Fog (실버)

카메라

전면 카메라는 'dokkaebi'라는 코드네임의 새로운 센서를 탑재할 예정이나, 현재 다른 카메라에 대한 추가 정보는 공개되지 않았습니다.

총평

Google Pixel 11a는 Tensor G6와 Titan M3 보안 칩을 탑재하고 고휘도 디스플레이를 갖춘 것이 특징입니다. 전작 대비 배터리 용량은 소폭 감소했으나, 새로운 전면 카메라 센서와 다양한 색상 옵션을 제공할 예정입니다.

产品基础信息与核心芯片

根据 NotebookCheck 的爆料，Google Pixel 11a 的内部代号为 Formosan。该机型搭载了多项关键硬件组件：

  • 处理器：Tensor G6（代号 Malibu）
  • 安全芯片：Titan M3
  • GPU：PowerVR C 系列 GPU（CXTP-48-1536）
  • 调制解调器：MediaTek M90

屏幕参数

Pixel 11a 配备了高规格的显示屏，具体参数如下：

  • 尺寸：6.3 英寸
  • 分辨率：1080 × 2424
  • 刷新率：60-120 Hz
  • 亮度表现：HDR 模式下最高可达 2250 尼特，峰值亮度可达 3350 尼特

硬件规格与外观设计

在其他核心配置和视觉设计方面，Pixel 11a 的相关信息如下：

  • 内存：8GB
  • 电池容量：4870 mAh（低于 Pixel 10a 的 5100 mAh）
  • 配色选项：Obsidian（黑色）、Olive（绿色）、Frost（紫色）、Fog（银色）
  • 前置摄像头：采用代号为 dokkaebi 的新传感器

总结

Google Pixel 11a 已有相关规格流出，确认搭载 Tensor G6 芯片及高亮度显示屏。尽管电池容量略低于上一代产品，但该机提供了丰富的配色选择并配备了全新的前置摄像头传感器。

Pixel 11aは以下のディスプレイ仕様を備えています。

  • 6.3インチ ディスプレイ

カメラ

Google Pixel 11aは、Tensor G6とTitan M3セキュリティチップの搭載、および高輝度ディスプレイの採用が大きな特徴です。前モデルと比較してバッテリー容量はわずかに減少していますが、新しいフロントカメラセンサーや多彩なカラーバリエーションの提供が期待されます。

Overview

On July 18, IT Home reported that the tech outlet NotebookCheck revealed several specification details for the Google Pixel 11a. The device's internal codename has been identified as "Formosan."

Performance

The Pixel 11a is expected to be equipped with Google's in-house developed Tensor G6 chip (codenamed Malibu) and the Titan M3 security chip. Furthermore, it will feature a PowerVR C series GPU (CXTP-48-1536) and a MediaTek M90 modem.

Display

The Pixel 11a features the following display specifications:

  • 6.3-inch display
  • 1080 x 2424 resolution
  • 60-120Hz refresh rate
  • Maximum brightness of 2,250 nits in HDR mode
  • Peak brightness up to 3,350 nits

Specifications

The device will come with 8GB of RAM and a battery capacity of 4,870mAh. This is lower than the 5,100mAh capacity found in the Pixel 10a.

Color Options

According to leaked information, the device will be available in four different colors:

  • Obsidian (Black)
  • Olive (Green)
  • Frost (Purple)
  • Fog (Silver)

Camera

The front camera is expected to feature a new sensor with the codename "dokkaebi," though no additional information regarding other cameras has been disclosed yet.

Summary

The Google Pixel 11a will feature the Tensor G6 chip, Titan M3 security chip, and a high-brightness display. While it features a slightly smaller battery capacity than its predecessor, it introduces a new front camera sensor and various color options.
