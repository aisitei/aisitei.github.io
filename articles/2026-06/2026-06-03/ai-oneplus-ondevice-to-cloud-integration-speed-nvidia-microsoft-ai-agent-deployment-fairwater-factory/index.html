NVIDIA, Microsoft, AI 에이전트의 엔드-투-클라우드 통합 배포 스택 공개, Fairwater 공장 조기 가동

2026-06-03

서론

IT之家 6월 3일 소식에 따르면, 오늘 개막한 Build 2026 개발자 컨퍼런스에서 타이베이에 있는 NVIDIA CEO 젠슨 황이 온라인으로 참석하여 Microsoft CEO 사티아 나델라의 기조연설에 참여했습니다.

양사는 RTX Spark, DGX Station for Windows, Foundry 플랫폼의 NVIDIA 오픈 모델, GitHub Copilot의 OpenShell 보안 런타임, 차세대 AI 공장 등 여러 협력에 대해 논의했습니다.

Microsoft와 NVIDIA는 또한 일련의 심층적인 협력을 발표하고 Build 컨퍼런스에서 Windows 장치, Azure 클라우드 및 온프레미스 배포를 아우르는 통합 고성능 컴퓨팅 스택을 선보였습니다. 이는 개발자가 AI 에이전트 및 물리적 AI를 구축, 실행 및 확장할 수 있도록 엔드투엔드 지원을 제공합니다.

Windows 장치 협력

Windows 장치 측면에서 NVIDIA와 Microsoft는 AI 에이전트 시대를 위한 PC를 재정의할 것입니다. RTX Spark는 개인 에이전트를 위해 특별히 제작된 최초의 Windows PC 플랫폼으로, 1페타플롭의 AI 컴퓨팅 성능, 최대 128GB의 통합 메모리, 하루 종일 지속되는 배터리 수명, 그리고 전원 공급 없이도 성능 저하 없는 AI 및 그래픽 성능을 제공합니다.

이 플랫폼은 CUDA, RTX, DLSS, TensorRT 등 NVIDIA의 30년 이상 축적된 기술을 통합하며, RTX Spark를 탑재한 노트북과 소형 데스크톱 PC는 올 가을 Microsoft Surface, ASUS, Dell, HP, Lenovo, MSI 등의 제조사에서 출시될 예정입니다.

DGX Station for Windows는 현재 가장 강력한 데스크톱 AI 슈퍼컴퓨터로, NVIDIA GB300 Grace Blackwell Ultra 데스크톱 슈퍼칩을 탑재하고 최대 748GB의 통합 메모리와 20페타플롭의 FP4 성능을 갖추고 있어 로컬에서 최대 1조 개의 매개변수를 가진 고급 모델을 실행할 수 있습니다. 이 시스템은 4분기에 ASUS, Dell, GIGABYTE, HP, MSI, Supermicro 등의 제조사에서 출시될 예정입니다. 두 제품 모두 자율 에이전트를 위한 보안 설계 런타임인 NVIDIA OpenShell을 실행합니다.

모델 및 플랫폼 협력

모델 및 플랫폼 측면에서 NVIDIA의 오픈 모델 포트폴리오가 Microsoft Foundry에 공식적으로 출시되었습니다. 코딩, 과학 연구 및 엔터프라이즈 워크플로우에서 장기 실행 에이전트를 위한 새로운 오픈 프런티어 추론 모델인 Nemotron 3 Ultra는 이번 달 Foundry 호스팅 컴퓨팅에서 사용할 수 있으며, 음성 인식을 위한 Nemotron 3.5 ASR 및 Nemotron 3.5 콘텐츠 보안 모델도 함께 출시됩니다.

또한 Anthropic의 Claude 모델은 이제 Azure의 NVIDIA GB300 Blackwell Ultra 시스템에서 기본적으로 실행되며, 향후 몇 주 내에 고객에게 공개될 예정입니다.

NVIDIA Agent Toolkit과 NVIDIA NemoClaw 청사진은 개발자가 Foundry에서 프로덕션급 에이전트를 구축할 수 있는 오픈소스 플랫폼을 제공하며, cuDF, cuOpt, AI-Q, NeMo를 포함한 CUDA-X 라이브러리는 이제 에이전트가 사용할 수 있는 도메인별 스킬로 제공됩니다.

데이터 계층 협력

데이터 계층 측면에서 NVIDIA 가속 컴퓨팅은 이제 Microsoft Fabric Data Warehouse에 내장되었습니다. Microsoft의 내부 벤치마크에 따르면 SQL 실행 속도는 CPU 기준선 대비 최대 6배에 달하며, 높은 동시성 부하에서는 다른 세 가지 주요 클라우드 데이터 웨어하우스 제공업체보다 최대 7배 빠릅니다. 양사는 이는 연구에서 생산에 이르는 수년간의 심층적인 엔지니어링 협력의 결과이며, 기업 데이터 계층이 AI 에이전트의 지속적인 쿼리 및 추론 속도를 따라잡을 수 있도록 한다고 밝혔습니다.

물리적 AI 협력

물리적 AI 분야에서 Microsoft는 NVIDIA의 오픈소스 물리적 AI 스킬 및 도구를 Azure 및 물리적 AI 툴체인과 통합하여 개발자에게 Cosmos 3 하이브리드 트랜스포머 아키텍처 기반의 통합 플랫폼을 제공합니다. 이 플랫폼은 로봇, 자율 주행 차량 및 산업 시스템과 같은 자율 시스템의 시뮬레이션, 훈련 및 배포에 사용됩니다. Cosmos 3는 시각적 추론, 세계 생성 및 동작 생성과 같은 주요 벤치마크에서 오픈 모델 중 1위를 차지했습니다. 온프레미스 배포 시나리오의 경우 Microsoft는 Azure Local의 Foundry Local을 NVIDIA RTX PRO 6000 Blackwell Server Edition 플랫폼에 도입하고 Nemotron 오픈 모델 제품군과 결합하여 기업이 온프레미스, 하이브리드 또는 주권 환경에서 고성능 AI 워크로드를 실행할 수 있도록 합니다. Foundry Local on Azure Local은 이제 다중 노드 배포 및 vLLM 런타임을 지원합니다.

보안 개발 협력

보안 개발 측면에서 NVIDIA OpenShell은 GitHub Copilot에 통합되었습니다. 각 에이전트는 독립적인 샌드박스 컨테이너에서 실행되며, 모든 외부 호출은 파일, 네트워크 또는 자격 증명에 도달하기 전에 정책에 따라 평가됩니다. 정책은 코드로 작성되고 리포지토리에서 버전 관리되며 즉시 업데이트할 수 있습니다. OpenShell은 Apache 2.0 오픈소스 라이선스를 기반으로 하며, 모델에 구애받지 않고 로컬, 하이브리드 및 클라우드 환경을 포괄합니다.

AI 인프라 협력

AI 인프라 측면에서 Microsoft의 위스콘신주 페어워터에 위치한 AI 공장은 예정보다 일찍 가동되어 수십만 대의 NVIDIA Grace Blackwell 시스템을 운영하고 있으며, 조지아주의 유사한 AI 공장과 상호 연결되어 확장 가능한 분산 AI 시스템을 구성합니다. 젠슨 황은 Microsoft가 가장 많은 Blackwell 칩을 배포했다고 직접 인정했습니다.

Microsoft는 NVIDIA Vera Rubin 플랫폼에 대한 검증을 완료했으며, 이 플랫폼은 현재 완전 생산 단계에 있으며 Azure 데이터 센터에 배포될 예정입니다. Vera Rubin은 개조 없이 Blackwell과 병렬로 배포할 수 있으며, 메가와트당 추론 처리량을 최대 10배 향상시키고, 에이전트 토큰당 비용을 한 자릿수 낮추며, 모델 및 데이터 보안을 보호하기 위한 NVIDIA 기밀 컴퓨팅이 내장되어 있습니다.

총평

NVIDIA와 Microsoft는 Build 2026 컨퍼런스에서 AI 에이전트 시대를 위한 광범위한 협력을 발표했습니다. 이 협력은 Windows PC, Azure 클라우드, 온프레미스 배포를 아우르는 통합 고성능 컴퓨팅 스택을 제공하며, RTX Spark PC 플랫폼과 DGX Station for Windows를 통해 강력한 AI 컴퓨팅 성능을 제공합니다. 또한 NVIDIA의 오픈 모델과 물리적 AI 도구가 Microsoft 플랫폼에 통합되어 개발자가 AI 에이전트 및 자율 시스템을 구축하고 확장할 수 있도록 지원합니다.

战略合作与核心平台

Microsoft 与 NVIDIA 在 Build 2026 大会上宣布达成深度合作，共同构建涵盖 Windows 设备、Azure 云端及本地部署的统一计算栈。双方重点合作领域包括 RTX Spark、DGX Station for Windows、Foundry 平台上的 NVIDIA 开放模型、GitHub Copilot 中的 OpenShell 安全运行时以及下一代 AI 工厂。

移动与桌面硬件设备

双方旨在重新定义面向 AI 智能体时代的 PC，推出了两款核心产品：

  • RTX Spark：首批专为个人智能体打造的 Windows PC 平台。
    • 性能指标：提供 1 petaflop 的 AI 算力、最高 128GB 统一内存。
    • 续航与图形：支持一整天续航，具备无衰减的离电 AI 与图形性能。
    • 合作厂商：将于今秋由 Microsoft Surface、ASUS、Dell、HP、Lenovo 和 MSI 等厂商推出。
  • DGX Station for Windows：目前性能最强的桌面级 AI 超级计算机。
    • 核心硬件：搭载 NVIDIA GB300 Grace Blackwell Ultra 桌面超级芯片。
    • 性能指标：配备最高 748GB 统一内存和 20 petaflops FP4 性能，支持运行高达 1 万亿参数的先进模型。
    • 合作厂商：预计于第四季度由 ASUS、Dell、Gigabyte、HP、MSI 和 Supermicro 等厂商推出。

模型生态与开发工具

NVIDIA 的开放模型组合已正式登陆 Microsoft Foundry，并提供丰富的开发者工具：

  • 核心模型：Nemotron 3 Ultra（面向编码、科研和企业工作流）、Nemotron 3.5 ASR（语音识别）及 Nemotron 3.5 内容安全模型。
  • 第三方集成：Anthropic 的 Claude 模型已在 Azure 上的 NVIDIA GB300 Blackwell Ultra 系统中原生运行。
  • 开发者工具包：提供 NVIDIA Agent Toolkit、NVIDIA NemoClaw 蓝图，以及包含 cuDF、cuOpt、AI-Q 和 NeMo 的 CUDA-X 库作为领域专用技能。

数据基础设施与 AI 工厂

双方在底层架构和大规模计算设施上进行了深度融合：

  • 数据层加速：NVIDIA 加速计算已集成至 Microsoft Fabric Data Warehouse，SQL 执行速度最高可达 CPU 基线的 6 倍。
  • AI 工厂建设：Microsoft 在威斯康星州和佐治亚州建立的 AI 工厂运行数十万套 NVIDIA Grace Blackwell 系统，构成分布式 AI 系统。
  • 下一代架构：Microsoft 已完成对 NVIDIA Vera Rubin 平台的验证并投入生产。该平台每兆瓦推理吞吐量提升最高 10 倍，且能显著降低智能体 token 成本。

安全开发与物理 AI

在安全性与特定领域应用方面，双方提供了专门的解决方案：

  • OpenShell 安全运行时：集成至 GitHub Copilot，为每个智能体提供独立的沙箱容器，并支持以代码形式编写和版本化管理的安全策略。
  • 物理 AI 领域：基于 Cosmos 3 混合 Transformer 架构的统一平台，用于仿真、训练和部署机器人、自动驾驶车辆及工业系统等自主系统。

总结

Microsoft 与 NVIDIA 在 Build 2026 大会上展示了深度合作成果，涵盖从高性能硬件（RTX Spark、DGX Station）到模型层（Nemotron 系列）、数据基础设施以及物理 AI 等全方位领域。双方通过整合 Azure 云端能力与 NVIDIA 的先进芯片技术，旨在为开发者提供构建、运行和扩展 AI 智能体的完整生态系统。

はじめに

IT之家の6月3日の報道によると、本日開幕したBuild 2026開発者カンファレンスにおいて、NVIDIAのCEOであるJensen Huang氏がタイベからオンラインで参加し、MicrosoftのCEO Satya Nadella氏の基調講演に加わりました。

両社は、RTX Spark、DGX Station for Windows、FoundryプラットフォームにおけるNVIDIAオープンモデル、GitHub CopilotのOpenShellセキュリティランタイム、次世代AIファクトリーなど、多岐にわたる協力関係について議論しました。

MicrosoftとNVIDIAはさらに、一連の深い協力関係を発表し、BuildカンファレンスにおいてWindowsデバイス、Azureクラウド、およびオンプレミス展開を網羅する統合高性能コンピューティングスタックを披露しました。これは開発者がAIエージェントや物理的AI（Physical AI）を構築、実行、拡張するためのエンドツーエンドのサポートを提供することを目的としています。

Windowsデバイスの協力

Windowsデバイスの側面において、NVIDIAとMicrosoftはAIエージェント時代のためのPCを再定義します。RTX Sparkは、パーソナルエージェント向けに特別に設計された初のWindows PCプラットフォームであり、以下の性能を提供します。

  • 1ペタフロップのAI計算性能
  • 最大128GBの統合メモリ
  • 一日中持続するバッテリー寿命
  • 電源供給なしでもパフォーマンス低下のないAIおよびグラフィックス性能

このプラットフォームは、CUDA、RTX、DLSS、TensorRTなど、NVIDIAが30年以上にわたり蓄積してきた技術を統合しています。RTX Sparkを搭載したノートPCおよび小型デスクトップPCは、今秋にMicrosoft Surface、ASUS、Dell、HP、Lenovo、MSIなどのメーカーから発売される予定です。

DGX Station for Windowsは、現在最も強力なデスクトップAIスーパーコンピューターであり、NVIDIA GB300 Grace Blackwell Ultraデスクトップスーパーチップを搭載しています。最大748GBの統合メモリと20ペタフロップのFP4性能を備えており、ローカルで最大1兆個のパラメータを持つ高度なモデルを実行可能です。このシステムは第4四半期にASUS、Dell、GIGABYTE、HP、MSI、Supermicroなどのメーカーから発売される予定です。両製品とも、自律型エージェント向けのセキュリティ設計ランタイムであるNVIDIA OpenShellを実行します。

モデルおよびプラットフォームの協力

モデルとプラットフォームの側面では、NVIDIAのオープンモデルポートフォリオがMicrosoft Foundryに正式にリリースされました。コーディング、科学研究、エンタープライズワークフローにおける長期実行エージェント向けの新しいオープンフロンティア推論モデル「Nemotron 3 Ultra」は、今月よりFoundryホスティングコンピューティングで利用可能となり、音声認識用のNemotron 3.5 ASRおよびコンテンツセキュリティモデルも同時にリリースされます。

また、AnthropicのClaudeモデルは、今後数週間以内に顧客向けに公開される予定で、現在はAzureのNVIDIA GB300 Blackwell Ultraシステム上で標準的に実行されます。

NVIDIA Agent ToolkitとNVIDIA NemoClawブループリントは、開発者がFoundryでプロダクションレベルのエージェントを構築できるオープンソースプラットフォームを提供します。cuDF、cuOpt、AI-Q、NeMoを含むCUDA-Xライブラリは、エージェントが利用可能なドメイン固有のスキルとして提供されます。

データレイヤーの協力

データレイヤーにおいて、NVIDIA加速コンピューティングはMicrosoft Fabric Data Warehouseに組み込まれました。Microsoftの内部ベンチマークによると、SQL実行速度はCPUベースラインと比較して最大6倍に達し、高い同時実行負荷においては他の主要なクラウドデータウェアハウスプロバイダーよりも最大7倍高速です。両社は、これが研究から生産に至る数年間の深いエンジニアリング協力の結果であり、企業データレイヤーがAIエージェントの継続的なクエリおよび推論速度に追いつけるようにすることを目的としていると述べています。

物理的AI（Physical AI）の協力

物理的AI分野において、MicrosoftはNVIDIAのオープンソース物理的AIスキルおよびツールをAzureおよび物理的AIツールチェーンと統合し、開発者にCosmos 3ハイブリッドトランスフォーマーアーキテクチャに基づく統合プラットフォームを提供します。このプラットフォームは、ロボット、自動運転車、産業システムなどの自律システムのシミュレーション、トレーニング、展開に使用されます。Cosmos 3は、視覚的推論、世界生成、動作生成などの主要なベンチマークにおいてオープンモデルの中で1位を獲得しました。

オンプレミス展開シナリオでは、MicrosoftはAzure LocalのFoundry LocalをNVIDIA RTX PRO 6000 Blackwell Server Editionプラットフォームに導入し、Nemotronオープンモデル製品群と組み合わせることで、企業がオンプレミス、ハイブリッド、またはソブリン環境で高性能なAIワークロードを実行できるようにします。Foundry Local on Azure Localは、マルチノード展開およびvLLMランタイムをサポートします。

セキュア開発の協力

セキュア開発の側面では、NVIDIA OpenShellがGitHub Copilotに統合されました。各エージェントは独立したサンドボックスコンテナ内で実行され、すべての外部呼び出しはファイル、ネットワーク、または資格情報に到達する前にポリシーに従って評価されます。ポリシーはコードで記述され、リポジトリでバージョン管理され、即座に更新可能です。OpenShellはApache 2.0オープンソースライセンスに基づいており、モデルに依存せず、ローカル、ハイブリッド、クラウド環境を網羅します。

AIインフラの協力

AIインフラの側面では、Wisconsin州PaywortonにあるMicrosoftのAIファクトリーが予定より早く稼働し、数十万台のNVIDIA Grace Blackwellシステムを運用しており、Georgia州の同様のAIファクトリーと相互接続され、拡張可能な分散型AIシステムを構成しています。Jensen Huang氏は、Microsoftが最も多くのBlackwellチップを導入していることを直接認めました。

MicrosoftはNVIDIA Vera Rubinプラットフォームの検証を完了しており、このプラットフォームは現在完全な生産段階にあり、Azureデータセンターに展開される予定です。Vera Rubinは、改造なしでBlackwellと並行して展開でき、メガワットあたりの推論スループットを最大10倍向上させ、エージェントトークンあたりのコストを一桁削減し、モデルおよびデータのセキュリティを保護するためのNVIDIA機密コンピューティング（Confidential Computing）を内蔵しています。

まとめ

MicrosoftとNVIDIAはBuild 2026において、Windows PC、Azureクラウド、オンプレミス環境を含む広範な協力体制を発表しました。RTX SparkやDGX Station for Windowsといった強力なハードウェア基盤に加え、Nemotronシリーズや物理的AIツールを統合することで、開発者が高度なAIエージェントや自律システムを構築・展開できる包括的なエコシステムを提供します。

Introduction

According to a report from IT Home on June 3, NVIDIA CEO Jensen Huang joined Microsoft CEO Satya Nadella's keynote at the Build 2026 developer conference via an online appearance from Taipei.

The two companies discussed several collaborative initiatives, including RTX Spark, DGX Station for Windows, NVIDIA open models on the Foundry platform, GitHub Copilot's OpenShell security runtime, and next-generation AI factories.

Microsoft and NVIDIA also announced a series of deep collaborations, showcasing an integrated high-performance computing stack across Windows devices, Azure cloud, and on-premises deployments at the Build conference. This initiative provides end-to-end support for developers to build, deploy, and scale AI agents and physical AI.

Windows Device Collaboration

Regarding Windows devices, NVIDIA and Microsoft aim to redefine PCs for the era of AI agents. RTX Spark is the first Windows PC platform specifically designed for personal agents, offering high performance and efficiency:

  • 1 petaflop of AI computing performance
  • Up to 128GB of unified memory
  • All-day battery life
  • Uncompromised AI and graphics performance even without a power supply

This platform integrates over 30 years of NVIDIA technology, including CUDA, RTX, DLSS, and TensorRT. Laptops and small form factor desktops equipped with RTX Spark are scheduled to launch this fall from manufacturers including Microsoft Surface, ASUS, Dell, HP, Lenovo, and MSI.

DGX Station for Windows is currently the most powerful desktop AI supercomputer. It features the NVIDIA GB300 Grace Blackwell Ultra desktop superchip and provides high-end capabilities:

  • Up to 748GB of unified memory
  • 20 petaflops of FP4 performance
  • Ability to run advanced models with up to 1 trillion parameters locally

This system is scheduled for release in the fourth quarter by manufacturers such as ASUS, Dell, GIGABYTE, HP, MSI, and Supermicro. Both products run NVIDIA OpenShell, a secure design runtime for autonomous agents.

Model and Platform Collaboration

In terms of models and platforms, NVIDIA's open model portfolio has been officially released on Microsoft Foundry. The Nemotron 3 Ultra—a new open frontier inference model for long-running agents in coding, scientific research, and enterprise workflows—will be available on Foundry-hosted computing this month. Additionally, the Nemotron 3.5 ASR and Nemotron 3.5 content security models will also be released.

Furthermore, Anthropic's Claude models are now running natively on Azure's NVIDIA GB300 Blackwell Ultra systems and will be available to customers within the coming weeks.

The NVIDIA Agent Toolkit and NVIDIA NemoClaw blueprints provide open-source platforms for developers to build production-grade agents on Foundry. CUDA-X libraries, including cuDF, cuOpt, AI-Q, and NeMo, are now provided as domain-specific skills that agents can utilize.

Data Layer Collaboration

Regarding the data layer, NVIDIA accelerated computing is now integrated into Microsoft Fabric Data Warehouse. According to internal benchmarks from Microsoft, SQL execution speeds reach up to 6x faster than CPU baselines. Under high concurrency loads, it is up to 7x faster than three other major cloud data warehouse providers.

The companies stated that this is the result of years of deep engineering collaboration ranging from research to production, ensuring that enterprise data layers can keep pace with the continuous query and inference speeds of AI agents.

Physical AI Collaboration

In the field of physical AI, Microsoft has integrated NVIDIA's open-source physical AI skills and tools with Azure and the physical AI toolchain to provide developers with an integrated platform based on the Cosmos 3 hybrid transformer architecture. This platform is used for the simulation, training, and deployment of autonomous systems such as robots, autonomous vehicles, and industrial systems. Cosmos 3 ranked first among open models in key benchmarks including visual reasoning, world generation, and action generation.

For on-premises deployment scenarios, Microsoft is introducing Foundry Local on Azure Local on the NVIDIA RTX PRO 6000 Blackwell Server Edition platform combined with the Nemotron open model suite. This allows enterprises to run high-performance AI workloads in on-premise, hybrid, or sovereign environments. Foundry Local on Azure Local now supports multi-node deployment and vLLM runtimes.

Secure Development Collaboration

Regarding secure development, NVIDIA OpenShell has been integrated into GitHub Copilot. Each agent runs in an independent sandbox container, where all external calls are evaluated against policies before reaching files, networks, or credentials. These policies are written in code, version-controlled in repositories, and can be updated instantly. OpenShell is based on the Apache 2.0 open-source license and supports local, hybrid, and cloud environments regardless of the model used.

AI Infrastructure Collaboration

Regarding AI infrastructure, Microsoft's AI factory in Pewauke, Wisconsin, began operations ahead of schedule, operating hundreds of thousands of NVIDIA Grace Blackwell systems. It is interconnected with a similar AI factory in Georgia to form an expandable distributed AI system. Jensen Huang personally acknowledged that Microsoft has deployed the largest number of Blackwell chips.

Microsoft has completed verification for the NVIDIA Vera Rubin platform, which is currently in full production and will be deployed across Azure data centers. Vera Rubin can be deployed in parallel with Blackwell without modifications, increasing inference throughput per megawatt by up to 10x, reducing the cost per agent token by a single digit, and featuring built-in NVIDIA confidential computing to protect model and data security.

Summary

Microsoft and NVIDIA announced extensive collaborations at Build 2026 focused on the era of AI agents across Windows, Azure, and on-premise environments. Key hardware highlights include the RTX Spark for personal devices and DGX Station for high-performance local inference, while software integrations include Nemotron models, Claude on Azure, and the OpenShell security runtime. The partnership also emphasizes infrastructure growth with massive Blackwell deployments and the upcoming Vera Rubin platform to enhance efficiency and security.
