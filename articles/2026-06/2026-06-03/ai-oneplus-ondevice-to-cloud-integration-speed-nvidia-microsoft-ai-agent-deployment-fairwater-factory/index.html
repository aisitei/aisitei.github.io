OnePlus 🤖 AI

원플러스(OnePlus)를 중심으로 한 온디바이스부터 클라우드까지의 통합 속도: NVIDIA와 마이크로소프트가 AI 에이전트 전체 배포 스택을 선보이고, Fairwater 공장이 선제적으로 가동됩니다.

2026-06-03

Build 2026 개발자 컨퍼런스 주요 내용 요약

IT之家에 따르면, 6월 3일에 개최된 Build 2026 개발자 컨퍼런스에서 NVIDIA의 CEO인 Jensen Huang은 온라인으로 참석했으며, Microsoft의 Satya Nadella CEO가 진행한 기조연설에 참여했습니다.

양사는 RTX Spark, DGX Station for Windows, Foundry 플랫폼 기반의 NVIDIA 개방 모델, GitHub Copilot 내 OpenShell 보안 런타임, 차세대 AI 공장 등 다방면의 협력 방안을 논의했습니다. Microsoft와 NVIDIA는 이번 Build 컨퍼런스에서 Windows 장치, Azure 클라우드, 온프레미스 배포를 아우르는 통합 OnePlus 컴퓨팅 스택을 선보이며, 개발자들이 AI 에이전트 및 물리적 AI를 구축, 실행, 확장할 수 있도록 엔드투엔드 지원 체계를 마련했습니다.

AI 에이전트 시대의 PC 플랫폼 재정의

NVIDIA와 Microsoft는 Windows 장치용으로 AI 에이전트 시대를 겨냥한 PC를 새롭게 정의합니다. RTX Spark는 개인 에이전트를 위해 처음 설계된 Windows PC 플랫폼입니다.

  • AI 성능: 1 petaflop의 AI 컴퓨팅 파워 제공
  • 메모리: 최대 128GB 통합 메모리 탑재
  • 배터리 및 성능: 하루 종일 지속되는 배터리 수명과 전력 공급 없이도 저하 없는 AI 및 그래픽 성능 유지

이 플랫폼에는 CUDA, RTX, DLSS, TensorRT 등 NVIDIA의 30년 이상의 기술 축적이 통합되어 있습니다. RTX Spark가 탑재된 노트북과 소형 데스크톱은 올 가을 Microsoft Surface, Asus, Dell, HP, Lenovo, MSI 등 여러 제조사를 통해 출시될 예정입니다.

데스크톱 AI 슈퍼컴퓨터 및 데이터 처리 능력 강화

DGX Station for Windows는 현재 성능상 가장 강력한 데스크톱급 AI 슈퍼컴퓨터로 소개되었습니다. 이 시스템은 NVIDIA GB300 Grace Blackwell Ultra 데스크톱 슈퍼 칩을 탑재했으며, 최대 748GB 통합 메모리와 20 petaflops FP4 성능을 제공하여 로컬 환경에서 최대 1조 개 매개변수(parameter)의 첨단 모델을 구동할 수 있습니다.

DGX Station for Windows는 다가오는 4분기에 Asus, Dell, Gigabyte, HP, MSI, Supermicro 등 제조사를 통해 출시될 예정입니다. 두 제품 모두 자율 에이전트를 목표로 설계된 안전한 런타임인 NVIDIA OpenShell을 구동합니다.

개방형 모델 및 플랫폼 생태계 구축

모델 및 플랫폼 측면에서, NVIDIA의 개방형 모델 조합은 Microsoft Foundry에 공식적으로 상륙했습니다. 코딩, 연구, 기업 워크플로우 등 장기간 구동되는 에이전트를 위한 새로운 개방형 최첨단 추론 모델인 Nemotron 3 Ultra가 이달 중 Foundry 호스팅 컴퓨팅을 통해 사용 가능해집니다.

또한 음성 인식용 Nemotron 3.5 ASR과 Nemotron 3.5 콘텐츠 안전 모델도 함께 출시되었습니다. 더불어 Anthropic의 Claude 모델은 이미 Azure상의 NVIDIA GB300 Blackwell Ultra 시스템에서 네이티브로 구동되고 있으며, 수주 내에 고객들에게 공개될 예정입니다.

개발자들을 위해 NVIDIA Agent Toolkit과 NVIDIA NemoClaw 블루프린트가 Foundry 상에서 프로덕션급 에이전트를 구축할 수 있는 오픈 소스 플랫폼을 제공합니다. CUDA-X 라이브러리(cuDF, cuOpt, AI-Q, NeMo 포함)는 이미 도메인 특화 스킬로 에이전트에 활용 가능합니다.

데이터 및 물리적 AI 영역의 혁신

데이터 계층에서는 NVIDIA 가속 컴퓨팅 기능이 Microsoft Fabric Data Warehouse에 내장되었습니다. Microsoft 내부 벤치마크 테스트 결과, SQL 실행 속도는 CPU 기준선의 최대 6배에 달했으며, 높은 동시 접속 부하 상황에서는 다른 주요 클라우드 데이터 웨어하우스 제공업체 대비 최대 7배의 성능을 보였습니다.

물리적 AI 분야에서는 Microsoft가 NVIDIA의 개방형 물리 AI 스킬과 도구를 Azure 및 물리 AI 툴체인과 통합하고 있습니다. 이를 통해 개발자들은 Cosmos 3 하이브리드 트랜스포머 아키텍처 기반의 통합 플랫폼을 얻게 되어, 로봇, 자율주행 차량, 산업 시스템 등 자율 시스템의 시뮬레이션, 학습, 배포가 가능해집니다. Cosmos 3는 비전 추론, 월드 생성, 액션 생성 등 핵심 벤치마크에서 개방형 모델 중 최고 성능을 기록했습니다.

로컬 배포 환경에 대응하여 Microsoft는 Azure Local상의 Foundry Local을 NVIDIA RTX PRO 6000 Blackwell Server Edition 플랫폼에 도입합니다. Nemotron 개방 모델 패밀리와 결합하여, 기업들은 로컬, 하이브리드 또는 주권(Sovereign) 환경에서 고성능 AI 워크로드를 구동할 수 있습니다. Foundry Local on Azure Local은 현재 다중 노드 배포와 vLLM 런타임을 지원합니다.

보안 및 인프라 구축 현황

안전 개발 측면에서, NVIDIA OpenShell이 GitHub Copilot에 통합되었습니다. 모든 에이전트는 독립적인 격리 컨테이너(sandbox container) 내에서 실행되며, 외부 호출 시 파일 접근, 네트워크 또는 자격 증명 사용 전에 정책 평가를 거치게 됩니다. 이 정책은 코드로 작성되어 저장소에 버전 관리되고 즉시 업데이트가 가능합니다.

AI 인프라 측면에서는 Microsoft가 Washington 주 Ferwrote에 위치한 AI 공장을 미리 가동하여 수십만 개의 NVIDIA Grace Blackwell 시스템을 운영하고 있으며, 이는 Georgia주의 유사 시설과 연결되어 확장 가능한 분산형 AI 시스템을 구성했습니다. Jensen Huang은 또한 "Microsoft가 가장 많은 Blackwell 칩을 배치했다"고 직접 언급했습니다.

Microsoft는 NVIDIA Vera Rubin 플랫폼에 대한 검증을 완료했으며, 이 플랫폼은 현재 전면 양산을 거쳐 Azure 데이터 센터에 배포될 예정입니다. Vera Rubin은 개조 없이 Blackwell과 병렬로 배포 가능하며, 메가와트당 추론 처리량(inference throughput)이 최대 10배 향상되고, 에이전트 토큰 비용이 한 자릿수만큼 낮아지며, 모델과 데이터 보안을 보호하는 NVIDIA 기밀 컴퓨팅 기능을 내장하고 있습니다.

총평

이번 Build 2026 컨퍼런스는 AI 에이전트 시대를 겨냥한 하드웨어와 소프트웨어의 전방위적인 통합 로드맵을 제시했습니다. NVIDIA는 RTX Spark를 통해 개인용 PC의 컴퓨팅 역량을 재정의하고, DGX Station for Windows 및 Foundry 플랫폼을 통해 데이터센터급 성능을 제공합니다. 특히 OpenShell과 같은 보안 기능 강화 및 Nemotron, Claude 등 개방형 모델 생태계 구축은 기업들이 AI 에이전트를 안전하게 현장에 적용할 수 있는 기반을 마련했음을 보여줍니다.

设备端与平台合作

微软与 NVIDIA 在 Build 大会上展示了跨越 Windows 设备、Azure 云及本地部署的统一计算栈，旨在为开发者构建、运行和扩展 AI 智能体与物理 AI 提供端到端支持。

  • RTX Spark：专为个人智能体打造的 Windows PC 平台。
  • 核心规格：提供 1 petaflop 的 AI 算力、最高 128GB 统一内存，并具备无衰减的离电 AI 与图形性能。
  • 合作厂商：相关产品将于今秋由 Microsoft Surface、ASUS、Dell、HP、Lenovo 和 MSI 等厂商推出。
  • DGX Station for Windows：高性能桌面级 AI 超级计算机。
  • 核心规格：搭载 NVIDIA GB300 Grace Blackwell Ultra 芯片，配备最高 748GB 统一内存和 20 petaflops FP4 性能，支持运行高达 1 万亿参数的模型。

模型与数据层优化

NVIDIA 的一系列开放模型已进入 Microsoft Foundry 平台，并显著提升了企业级的数据处理能力。

  • Nemotron 系列：包括面向编码和科研的 Nemotron 3 Ultra，以及用于语音识别的 Nemotron 3.5 ASR 和内容安全模型。
  • Anthropic Claude 模型：已在 Azure 上的 NVIDIA GB300 Blackwell Ultra 系统中原生运行。
  • Microsoft Fabric Data Warehouse：集成 NVIDIA 加速计算后，SQL 执行速度最高可达 CPU 基线的 6 倍，在高并发负载下优于其他主流云数据仓库。

物理 AI 与安全开发

双方在机器人、自动驾驶等物理 AI 领域以及开发者工具的安全性方面进行了深度整合。

  • 物理 AI：基于 Cosmos 3 混合 Transformer 架构，提供用于仿真、训练和部署机器人及自动驾驶车辆的统一平台。
  • GitHub Copilot 集成：NVIDIA OpenShell 已集成至 GitHub Copilot，为智能体提供独立的沙箱容器并支持以代码形式编写的策略管理。

基础设施与下一代架构

微软大规模部署 NVIDIA 的先进芯片，并已完成对新一代平台的验证。

  • AI 工厂：微软在威斯康星州和佐治亚州的 AI 工厂运行数十万套 NVIDIA Grace Blackwell 系统。
  • Vera Rubin 平台：该平台已全面投产并部署至 Azure 数据中心，每兆瓦推理吞吐量最高提升 10 倍，且能显著降低智能体 token 成本。

总结

微软与 NVIDIA 在 Build 大会上宣布了涵盖 PC 端、桌面端、云端模型及物理 AI 等全方位领域的深度合作。双方通过 RTX Spark、DGX Station 以及一系列高性能芯片（如 Blackwell 和 Vera Rubin）构建强大的硬件基础，并结合 OpenShell 与 Fabric 数据层优化提升智能体的安全性与处理效率。

Build 2026 デベロッパーカンファレンスの主要内容

IT之家の報道によると、6月3日に開催されたBuild 2026デベロッパーカンファレンスにおいて、NVIDIAのCEOであるJensen Huang氏がオンラインで参加し、MicrosoftのSatya Nadella CEOによる基調講演に加わりました。

両社はRTX Spark、DGX Station for Windows、FoundryプラットフォームベースのNVIDIAオープンモデル、GitHub Copilot内でのOpenShellセキュアランタイム、次世代AIファクトリーなど、多岐にわたる協力体制について議論しました。MicrosoftとNVIDIAは、今回のBuildカンファレンスにおいて、Windowsデバイス、Azureクラウド、オンプレミス展開を網羅する統合されたOnePlusコンピューティングスタックを発表し、開発者がAIエージェントや物理的AI（Physical AI）を構築、実行、拡張するためのエンドツーエンドの支援体制を整えました。

AIエージェント時代に向けたPCプラットフォームの再定義

NVIDIAとMicrosoftは、Windowsデバイス向けにAIエージェント時代を見据えたPCを新たに定義します。RTX Sparkは、パーソナルエージェントのために初めて設計されたWindows PCプラットフォームです。

  • AI性能: 1ペタフロップスのAI計算能力を提供
  • メモリ: 最大128GBの統合メモリを搭載
  • バッテリーとパフォーマンス: 一日中持続するバッテリー寿命と、電源供給なしでも低下しないAIおよびグラフィックス性能を維持

このプラットフォームには、CUDA、RTX、DLSS、TensorRTなど、NVIDIAが30年以上にわたり蓄積してきた技術が統合されています。RTX Sparkを搭載したノートPCおよび小型デスクトップは、今秋、Microsoft Surface、Asus、Dell、HP、Lenovo、MSIなど複数のメーカーを通じて発売される予定です。

デスクトップAIスーパーコンピューターとデータ処理能力の強化

DGX Station for Windowsは、現在最も強力なデスクトップ級AIスーパーコンピューターとして紹介されました。このシステムはNVIDIA GB300 Grace Blackwell Ultraデスクトップスーパーチップを搭載し、最大748GBの統合メモリと20ペタフロップスのFP4性能を提供するため、ローカル環境で最大1兆個のパラメータを持つ最先端モデルを実行可能です。

DGX Station for Windowsは、来る第4四ターンにAsus、Dell、Gigabyte、HP、MSI、Supermicroなどのメーカーを通じて発売される予定です。両製品とも、自律型エージェントをターゲットに設計されたセキュアなランタイムであるNVIDIA OpenShellを実行します。

オープンモデルおよびプラットフォームエコシステムの構築

モデルとプラットフォームの側面では、NVIDIAのオープンモデルの組み合わせがMicrosoft Foundryに正式に導入されました。コーディング、研究、企業ワークフローなど、長期間動作するエージェント向けの新しいオープンな最先端推論モデルであるNemotron 3 Ultraは、今月中にFoundryホスティングコンピューティングを通じて利用可能になります。

また、音声認識用のNemotron 3.5 ASRとNemotron 3.5コンテンツ安全モデルも同時にリリースされました。さらに、AnthropicのClaudeモデルはすでにAzure上のNVIDIA GB300 Blackwell Ultraシステムでネイティブに動作しており、数週間以内に顧客へ公開される予定です。

開発者のために、NVIDIA Agent ToolkitとNVIDIA NemoClawブループリントがFoundry上でプロダクション級のエージェントを構築できるオープンソースプラットフォームを提供します。CUDA-Xライブラリ（cuDF、cuOpt、AI-Q、NeMoを含む）は、すでにドメイン特化型スキルとしてエージェントに活用可能です。

データおよび物理的AI領域の革新

データレイヤーでは、NVIDIAのアクセラレーションコンピューティング機能がMicrosoft Fabric Data Warehouseに組み込まれました。Microsoftの内部ベンチマークテストの結果、SQL実行速度はCPU基準の最大6倍に達し、高い同時接続負荷の状況下では他の主要なクラウドデータウェアハウスプロバイダーと比較して最大7倍の性能を示しました。

物理的AI（Physical AI）分野において、MicrosoftはNVIDIAのオープンな物理AIスキルとツールをAzureおよび物理AIツールチェーンに統合しています。これにより、開発者はCosmos 3ハイブリッドトランスフォーマーアーキテクチャに基づく統合プラットフォームを得ることで、ロボット、自動運転車、産業システムなどの自律システムのシミュレーション、学習、展開が可能になります。Cosmos 3は、ビジョン推論、ワールド生成、アクション生成などの主要なベンチマークにおいて、オープンモデルの中で最高性能を記録しました。

ローカル展開環境に対応するため、MicrosoftはAzure Local上のFoundry LocalをNVIDIA RTX PRO 6000 Blackwell Server Editionプラットフォームに導入します。Nemotronオープンモデルファミリーと組み合わせることで、企業はローカル、ハイブリッド、またはソブリン（Sovereign）環境で高性能なAIワークロードを実行できます。Foundry Local on Azure Localは現在、マルチノード展開とvLLMランタイムをサポートしています。

セキュリティとインフラ構築の現状

安全な開発の側面では、NVIDIA OpenShellがGitHub Copilotに統合されました。すべてのエージェントは独立した隔離コンテナ（サンドボックスコンテナ）内で実行され、外部呼び出しの際にファイルアクセス、ネットワーク、または資格情報の使用前にポリシー評価が行われます。このポリシーはコードで記述され、リポジトリでバージョン管理され、即座に更新が可能です。

AIインフラの側面では、Microsoftがワシントン州FerwroteにあるAIファクトリーを先行稼働させ、数十万のNVIDIA Grace Blackwellシステムを運用しており、これはジョージア州の同様の施設と接続され、拡張可能な分散型AIシステムを構成しています。Jensen Huangはまた、「Microsoftが最も多くのBlackwellチップを配置している」と直接言及しました。

MicrosoftはNVIDIA Vera Rubinプラットフォームの検証を完了しており、このプラットフォームは現在フル生産を経てAzureデータセンターに展開される予定です。Vera Rubinは変更なしでBlackwellと並行して展開可能であり、メガワットあたりの推論スループットが最大10倍向上し、エージェントのトークンコストを1桁分削減し、モデルとデータのセキュリティを保護するNVIDIA機密コンピューティング機能を内蔵しています。

まとめ

Build 2026では、MicrosoftとNVIDIAによるAIエージェント時代を見据えた包括的なハードウェア・ソフトウェア統合ロードマップが提示されました。RTX SparkやDGX Station for Windowsといった強力な計算基盤の提供に加え、NemotronやClaudeなどのオープンモデルエコシステムの構築、そして高度なセキュリティ機能（OpenShell）の統合により、企業や開発者が安全かつ高性能なAIエージェントを実用的な環境へ展開するための強固な基盤が整いました。

According to IT House, during the Build 2026 developer conference held on June 3, NVIDIA CEO Jensen Huang joined Microsoft CEO Satya Nadella for a keynote presentation. The two companies discussed extensive collaboration across various fields, including RTX Spark, DGX Station for Windows, NVIDIA open models based on the Foundry platform, OpenShell secure runtime within GitHub Copilot, and next-generation AI factories.

Microsoft and NVIDIA introduced an integrated "OnePlus" computing stack covering Windows devices, Azure cloud, and on-premise deployments. This framework is designed to provide end-to-end support for developers to build, deploy, and scale AI agents and physical AI.

Redefining PC Platforms for the Age of AI Agents

NVIDIA and Microsoft are redefining PC platforms for the era of AI agents. RTX Spark is a Windows PC platform specifically designed for personal agents.

  • AI Performance: Provides 1 petaflop of AI computing power.
  • Memory: Equipped with up to 128GB of unified memory.
  • Battery and Performance: Offers all-day battery life while maintaining high AI and graphics performance without a power source.

This platform integrates over 30 years of NVIDIA technology, including CUDA, RTX, DLSS, and TensorRT. Laptops and small desktops featuring RTX Spark are scheduled to launch this fall through various manufacturers, including Microsoft Surface, Asus, Dell, HP, Lenovo, and MSI.

Enhanced Desktop AI Supercomputing and Data Processing

DGX Station for Windows was introduced as the most powerful desktop-class AI supercomputer currently available. This system features the NVIDIA GB300 Grace Blackwell Ultra desktop super chip, providing up to 748GB of unified memory and 20 petaflops of FP4 performance, enabling it to run advanced models with up to 1 trillion parameters in local environments.

DGX Station for Windows is expected to launch in the fourth quarter through manufacturers such as Asus, Dell, Gigabyte, HP, MSI, and Supermicro. Both products utilize NVIDIA OpenShell, a secure runtime designed for autonomous agents.

Building an Open Model and Platform Ecosystem

Regarding models and platforms, a suite of NVIDIA open models has officially landed on Microsoft Foundry. Nemotron 3 Ultra, a new open state-of-the-art inference model for long-running agents in coding, research, and enterprise workflows, will be available through Foundry hosted computing starting this month.

Additionally, the Nemotron 3.5 ASR and Nemotron 3.5 content safety models were released. Furthermore, Anthropic's Claude models are already running natively on NVIDIA GB300 Blackwell Ultra systems on Azure and are expected to be available to customers within weeks.

For developers, the NVIDIA Agent Toolkit and NVIDIA NemoClaw blueprints provide open-source platforms for building production-grade agents on Foundry. CUDA-X libraries (including cuDF, cuOpt, AI-Q, and NeMo) are already available as domain-specific skills for use in agents.

Innovations in Data and Physical AI

On the data layer, NVIDIA accelerated computing features have been integrated into Microsoft Fabric Data Warehouse. Internal benchmark tests by Microsoft showed that SQL execution speeds reached up to 6 times faster than CPU baselines, and performed up to 7 times better than other major cloud data warehouse providers under high concurrent load conditions.

In the field of physical AI, Microsoft is integrating NVIDIA's open physical AI skills and tools with Azure and physical AI toolchains. This provides developers with an integrated platform based on the Cosmos 3 hybrid transformer architecture, enabling the simulation, training, and deployment of autonomous systems such as robots, autonomous vehicles, and industrial systems. Cosmos 3 achieved top performance among open models in key benchmarks including vision reasoning, world generation, and action generation.

To support local deployment environments, Microsoft is introducing Foundry Local on Azure Local on the NVIDIA RTX PRO 6000 Blackwell Server Edition platform. Combined with the Nemotron open model family, this allows enterprises to run high-performance AI workloads in local, hybrid, or sovereign environments. Foundry Local on Azure Local currently supports multi-node deployment and vLLM runtimes.

Security and Infrastructure Status

Regarding secure development, NVIDIA OpenShell has been integrated into GitHub Copilot. All agents run within independent isolated sandbox containers, where policy evaluations are conducted before external calls access files, networks, or credentials. These policies are written in code, version-controlled in repositories, and can be updated instantly.

In terms of AI infrastructure, Microsoft has pre-activated "AI factories" in Ferwrote, Washington, operating hundreds of thousands of NVIDIA Grace Blackwell systems. These are connected to similar facilities in Georgia to form an expandable distributed AI system. Jensen Huang explicitly noted that "Microsoft has deployed the most Blackwell chips."

Microsoft has completed verification for the NVIDIA Vera Rubin platform, which is currently moving toward full production and deployment in Azure data centers. Vera Rubin can be deployed in parallel with Blackwell without modifications, offering up to 10 times higher inference throughput per megawatt, reducing agent token costs by a single digit, and featuring NVIDIA confidential computing capabilities to protect model and data security.

Build 2026 Developer Conference Highlights

According to IT Home, NVIDIA CEO Jensen Huang attended the Build 2026 developer conference on June 3rd online, participating in a keynote delivered by Microsoft CEO Satya Nadella.

The two companies discussed extensive cooperation across various areas, including RTX Spark, DGX Station for Windows, NVIDIA open models based on the Foundry platform, OpenShell secure runtime within GitHub Copilot, and next-generation AI factories. During the Build conference, Microsoft and NVIDIA unveiled an integrated OnePlus computing stack spanning Windows devices, Azure cloud, and on-premises deployment to provide developers with an end-to-end support system for building, running, and scaling AI agents and physical AI.

Redefining PC Platforms for the Age of AI Agents

NVIDIA and Microsoft are redefining PCs for the era of AI agents on Windows devices. RTX Spark is a Windows PC platform specifically designed for personal agents.

  • AI Performance: Provides 1 petaflop of AI computing power
  • Memory: Equipped with up to 128GB of unified memory
  • Battery and Performance: Features all-day battery life while maintaining consistent AI and graphics performance even without a power supply

This platform integrates over 30 years of NVIDIA technology, including CUDA, RTX, DLSS, and TensorRT. Laptops and small desktops equipped with RTX Spark are scheduled to launch this fall through various manufacturers, including Microsoft Surface, Asus, Dell, HP, Lenovo, and MSI.

Desktop AI Supercomputers and Enhanced Data Processing

DGX Station for Windows was introduced as currently the most powerful desktop-class AI supercomputer. This system features the NVIDIA GB300 Grace Blackwell Ultra desktop super chip, providing up to 748GB of unified memory and 20 petaflops of FP4 performance, enabling the execution of advanced models with up to 1 trillion parameters in local environments.

DGX Station for Windows is scheduled for release in the upcoming fourth quarter through manufacturers such as Asus, Dell, Gigabyte, HP, MSI, and Supermicro. Both products run NVIDIA OpenShell, a secure runtime designed for autonomous agents.

Building an Open Model and Platform Ecosystem

Regarding models and platforms, a suite of NVIDIA open models has officially landed on the Microsoft Foundry platform. Nemotron 3 Ultra, a new state-of-the-art inference model for long-running agents in coding, research, and enterprise workflows, will be available via Foundry hosted computing later this month.

Additionally, Nemotron 3.5 ASR for voice recognition and the Nemotron 3.5 content safety model were also released. Furthermore, Anthropic's Claude models are already running natively on NVIDIA GB300 Blackwell Ultra systems on Azure and are expected to be available to customers within weeks.

For developers, the NVIDIA Agent Toolkit and NVIDIA NemoClaw blueprints provide open-source platforms on Foundry for building production-grade agents. CUDA-X libraries (including cuDF, cuOpt, AI-Q, and NeMo) are already available for use as domain-specific skills in agents.

Innovation in Data and Physical AI

On the data layer, NVIDIA accelerated computing features have been integrated into Microsoft Fabric Data Warehouse. Internal benchmark tests by Microsoft showed that SQL execution speeds reached up to 6 times the CPU baseline, and under high concurrent load conditions, it outperformed other major cloud data warehouse providers by up to 7 times.

In the field of physical AI, Microsoft is integrating NVIDIA's open physical AI skills and tools with Azure and the physical AI toolchain. This provides developers with an integrated platform based on the Cosmos 3 hybrid transformer architecture, enabling the simulation, training, and deployment of autonomous systems such as robots, autonomous vehicles, and industrial systems. Cosmos 3 achieved top performance among open models in key benchmarks including vision reasoning, world generation, and action generation.

To support local deployment environments, Microsoft is introducing Foundry Local on Azure Local onto the NVIDIA RTX PRO 6000 Blackwell Server Edition platform. Combined with the Nemotron open model family, this allows enterprises to run high-performance AI workloads in local, hybrid, or sovereign environments. Foundry Local on Azure Local currently supports multi-node deployment and vLLM runtimes.

Security and Infrastructure Status

Regarding secure development, NVIDIA OpenShell has been integrated into GitHub Copilot. All agents run within independent isolated sandbox containers, and policy evaluations are conducted before external calls access files, networks, or credentials. These policies are written in code, version-controlled in repositories, and can be updated instantly.

In terms of AI infrastructure, Microsoft has pre-activated AI factories in Ferwrote, Washington, operating hundreds of thousands of NVIDIA Grace Blackwell systems. These are connected to similar facilities in Georgia to form a scalable distributed AI system. Jensen Huang explicitly mentioned that "Microsoft has deployed the most Blackwell chips."

Microsoft has completed validation for the NVIDIA Vera Rubin platform, which is currently moving into full production and deployment across Azure data centers. Vera Rubin can be deployed in parallel with Blackwell without modification, offering up to 10 times higher inference throughput per megawatt, reducing agent token costs by a single digit, and featuring NVIDIA confidential computing capabilities to protect model and data security.

Summary

The Build 2026 conference showcased a comprehensive roadmap for the integration of hardware and software aimed at the era of AI agents. Through products like RTX Spark and DGX Station for Windows, along with the expansion of open models on Microsoft Foundry and enhanced security via OpenShell, the partnership provides a robust foundation for developers to deploy high-performance, secure AI solutions across PC, desktop, and cloud environments.
