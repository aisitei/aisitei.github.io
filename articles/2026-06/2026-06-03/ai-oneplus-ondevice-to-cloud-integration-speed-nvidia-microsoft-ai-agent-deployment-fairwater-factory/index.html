OnePlus 🤖 AI

원플러스(OnePlus)를 중심으로 한 온디바이스부터 클라우드까지의 통합 속도: NVIDIA와 마이크로소프트가 AI 에이전트 전체 배포 스택을 선보이고, Fairwater 공장이 선제적으로 가동됩니다.

2026-06-03

Build 2026 개발자 컨퍼런스 주요 내용 요약

IT之家에 따르면, 6월 3일에 개최된 Build 2026 개발자 컨퍼런스에서 NVIDIA의 CEO인 Jensen Huang은 온라인으로 참석했으며, Microsoft의 Satya Nadella CEO가 진행한 기조연설에 참여했습니다.

양사는 RTX Spark, DGX Station for Windows, Foundry 플랫폼 기반의 NVIDIA 개방 모델, GitHub Copilot 내 OpenShell 보안 런타임, 차세대 AI 공장 등 다방면의 협력 방안을 논의했습니다. Microsoft와 NVIDIA는 이번 Build 컨퍼런스에서 Windows 장치, Azure 클라우드, 온프레미스 배포를 아우르는 통합 OnePlus 컴퓨팅 스택을 선보이며, 개발자들이 AI 에이전트 및 물리적 AI를 구축, 실행, 확장할 수 있도록 엔드투엔드 지원 체계를 마련했습니다.

AI 에이전트 시대의 PC 플랫폼 재정의

NVIDIA와 Microsoft는 Windows 장치용으로 AI 에이전트 시대를 겨냥한 PC를 새롭게 정의합니다. RTX Spark는 개인 에이전트를 위해 처음 설계된 Windows PC 플랫폼입니다.

  • AI 성능: 1 petaflop의 AI 컴퓨팅 파워 제공
  • 메모리: 최대 128GB 통합 메모리 탑재
  • 배터리 및 성능: 하루 종일 지속되는 배터리 수명과 전력 공급 없이도 저하 없는 AI 및 그래픽 성능 유지

이 플랫폼에는 CUDA, RTX, DLSS, TensorRT 등 NVIDIA의 30년 이상의 기술 축적이 통합되어 있습니다. RTX Spark가 탑재된 노트북과 소형 데스크톱은 올 가을 Microsoft Surface, Asus, Dell, HP, Lenovo, MSI 등 여러 제조사를 통해 출시될 예정입니다.

데스크톱 AI 슈퍼컴퓨터 및 데이터 처리 능력 강화

DGX Station for Windows는 현재 성능상 가장 강력한 데스크톱급 AI 슈퍼컴퓨터로 소개되었습니다. 이 시스템은 NVIDIA GB300 Grace Blackwell Ultra 데스크톱 슈퍼 칩을 탑재했으며, 최대 748GB 통합 메모리와 20 petaflops FP4 성능을 제공하여 로컬 환경에서 최대 1조 개 매개변수(parameter)의 첨단 모델을 구동할 수 있습니다.

DGX Station for Windows는 다가오는 4분기에 Asus, Dell, Gigabyte, HP, MSI, Supermicro 등 제조사를 통해 출시될 예정입니다. 두 제품 모두 자율 에이전트를 목표로 설계된 안전한 런타임인 NVIDIA OpenShell을 구동합니다.

개방형 모델 및 플랫폼 생태계 구축

모델 및 플랫폼 측면에서, NVIDIA의 개방형 모델 조합은 Microsoft Foundry에 공식적으로 상륙했습니다. 코딩, 연구, 기업 워크플로우 등 장기간 구동되는 에이전트를 위한 새로운 개방형 최첨단 추론 모델인 Nemotron 3 Ultra가 이달 중 Foundry 호스팅 컴퓨팅을 통해 사용 가능해집니다.

또한 음성 인식용 Nemotron 3.5 ASR과 Nemotron 3.5 콘텐츠 안전 모델도 함께 출시되었습니다. 더불어 Anthropic의 Claude 모델은 이미 Azure상의 NVIDIA GB300 Blackwell Ultra 시스템에서 네이티브로 구동되고 있으며, 수주 내에 고객들에게 공개될 예정입니다.

개발자들을 위해 NVIDIA Agent Toolkit과 NVIDIA NemoClaw 블루프린트가 Foundry 상에서 프로덕션급 에이전트를 구축할 수 있는 오픈 소스 플랫폼을 제공합니다. CUDA-X 라이브러리(cuDF, cuOpt, AI-Q, NeMo 포함)는 이미 도메인 특화 스킬로 에이전트에 활용 가능합니다.

데이터 및 물리적 AI 영역의 혁신

데이터 계층에서는 NVIDIA 가속 컴퓨팅 기능이 Microsoft Fabric Data Warehouse에 내장되었습니다. Microsoft 내부 벤치마크 테스트 결과, SQL 실행 속도는 CPU 기준선의 최대 6배에 달했으며, 높은 동시 접속 부하 상황에서는 다른 주요 클라우드 데이터 웨어하우스 제공업체 대비 최대 7배의 성능을 보였습니다.

물리적 AI 분야에서는 Microsoft가 NVIDIA의 개방형 물리 AI 스킬과 도구를 Azure 및 물리 AI 툴체인과 통합하고 있습니다. 이를 통해 개발자들은 Cosmos 3 하이브리드 트랜스포머 아키텍처 기반의 통합 플랫폼을 얻게 되어, 로봇, 자율주행 차량, 산업 시스템 등 자율 시스템의 시뮬레이션, 학습, 배포가 가능해집니다. Cosmos 3는 비전 추론, 월드 생성, 액션 생성 등 핵심 벤치마크에서 개방형 모델 중 최고 성능을 기록했습니다.

로컬 배포 환경에 대응하여 Microsoft는 Azure Local상의 Foundry Local을 NVIDIA RTX PRO 6000 Blackwell Server Edition 플랫폼에 도입합니다. Nemotron 개방 모델 패밀리와 결합하여, 기업들은 로컬, 하이브리드 또는 주권(Sovereign) 환경에서 고성능 AI 워크로드를 구동할 수 있습니다. Foundry Local on Azure Local은 현재 다중 노드 배포와 vLLM 런타임을 지원합니다.

보안 및 인프라 구축 현황

안전 개발 측면에서, NVIDIA OpenShell이 GitHub Copilot에 통합되었습니다. 모든 에이전트는 독립적인 격리 컨테이너(sandbox container) 내에서 실행되며, 외부 호출 시 파일 접근, 네트워크 또는 자격 증명 사용 전에 정책 평가를 거치게 됩니다. 이 정책은 코드로 작성되어 저장소에 버전 관리되고 즉시 업데이트가 가능합니다.

AI 인프라 측면에서는 Microsoft가 Washington 주 Ferwrote에 위치한 AI 공장을 미리 가동하여 수십만 개의 NVIDIA Grace Blackwell 시스템을 운영하고 있으며, 이는 Georgia주의 유사 시설과 연결되어 확장 가능한 분산형 AI 시스템을 구성했습니다. Jensen Huang은 또한 "Microsoft가 가장 많은 Blackwell 칩을 배치했다"고 직접 언급했습니다.

Microsoft는 NVIDIA Vera Rubin 플랫폼에 대한 검증을 완료했으며, 이 플랫폼은 현재 전면 양산을 거쳐 Azure 데이터 센터에 배포될 예정입니다. Vera Rubin은 개조 없이 Blackwell과 병렬로 배포 가능하며, 메가와트당 추론 처리량(inference throughput)이 최대 10배 향상되고, 에이전트 토큰 비용이 한 자릿수만큼 낮아지며, 모델과 데이터 보안을 보호하는 NVIDIA 기밀 컴퓨팅 기능을 내장하고 있습니다.

총평

이번 Build 2026 컨퍼런스는 AI 에이전트 시대를 겨냥한 하드웨어와 소프트웨어의 전방위적인 통합 로드맵을 제시했습니다. NVIDIA는 RTX Spark를 통해 개인용 PC의 컴퓨팅 역량을 재정의하고, DGX Station for Windows 및 Foundry 플랫폼을 통해 데이터센터급 성능을 제공합니다. 특히 OpenShell과 같은 보안 기능 강화 및 Nemotron, Claude 등 개방형 모델 생태계 구축은 기업들이 AI 에이전트를 안전하게 현장에 적용할 수 있는 기반을 마련했음을 보여줍니다.
