Huawei nova 16 시리즈 스마트폰, '스타 플래시' 기능 공개... Pro/Ultra 모델은 스타일러스 펜 연결 가능

2026-06-03

출시 정보

IT之家에 따르면, Huawei nova 16 시리즈 신제품이 어제 공식 출시되었습니다. 이번 시리즈는 총 네 가지 모델로 구성되었으며, 전 모델이 StarFlash E2.0을 지원합니다. 가격은 2,699위안부터 시작합니다.

StarFlash 기능 상세 지원 현황

Huawei의 공식 웹사이트에서는 nova 16 시리즈가 지원하는 StarFlash 기능을 구체적으로 공개했습니다.

  • StarFlash 정밀 찾기
  • StarFlash 기능을 지원하는 스타일러스 펜 / 키보드 / 마우스 연결
  • StarFlash 기능을 지원하는 스마트워치 (휴대폰 네트워크 공유)
  • 키보드 및 마우스 연결

기술 설명: StarFlash

StarFlash 기술(NearLink)은 국제 스타플래시 무선 단거리 통신 연합에서 발표한 새로운 유형의 무선 단거리 통신 표준 기술입니다. 현재 Huawei의 일부 휴대폰 모델이 StarFlash를 지원합니다.

다만, StarFlash 기능은 기기의 구체적인 하드웨어 지원 능력에 따라 달라지므로 시스템 업그레이드를 통해서는 지원할 수 없습니다.

총평

Huawei nova 16 시리즈는 전 모델에서 최신 무선 통신 표준인 StarFlash E2.0을 탑재하여 연결성을 강화한 것이 특징입니다. 이 기능은 단순한 소프트웨어 업데이트가 아닌, 하드웨어 차원의 지원이 필수적이며, 다양한 주변 기기와의 연동을 통해 사용자 경험을 확장할 것으로 기대됩니다.

产品发布与定价

Huawei nova 16 系列新机已于 6 月 1 日正式发布，全系共包含四款机型。该系列产品的起售价为 2699 元。

核心技术支持

Huawei nova 16 系列全系支持星闪 E2.0 技术。根据官方信息，其具体的星闪功能包括：

  • 星闪精确查找
  • 连接支持星闪功能的手写笔、键盘及鼠标
  • 连接支持星闪功能的手表（可共享手机网络）

技术定义与说明

星闪 (NearLink) 是由国际星闪无线短距通信联盟发布的全新无线短距通信标准。该技术的支持取决于具体的硬件配置，无法通过系统升级获得。

总结

Huawei nova 16 系列共四款机型上市，起售价为 2699 元。全系产品均搭载星闪 E2.0 技术，旨在提供更强的外设连接与定位能力。需注意该功能属于硬件层面的支持，无法通过软件更新获取。

発売情報

IT之家の報道によると、Huawei nova 16シリーズが昨日正式に発表されました。本シリーズは計4モデルで構成されており、全モデルがStarFlash E2.0をサポートしています。価格は2,699元からとなっています。

StarFlash機能の詳細なサポート状況

Huaweiの公式サイトでは、nova 16シリーズがサポートするStarFlash機能の具体的な内容が公開されました。

  • StarFlash 精密探索
  • StarFlashをサポートするスタイラスペン、キーボード、マウスの接続
  • StarFlashをサポートするスマートウォッチ（携帯電話ネットワーク共有）
  • キーボードおよびマウスの接続

技術解説：StarFlash

StarFlash技術（NearLink）は、国際スターフラッシュ無線短距離通信連合によって発表された新しいタイプの無線短距離通信標準技術です。現在、Huaweiの一部スマートフォンモデルがStarFlashをサポートしています。

ただし、StarFlash機能はデバイス固有のハードウェアによるサポート能力に依存するため、システムアップデートのみで機能を有効にすることはできません。

総評

Huawei nova 16シリーズは、全モデルに最新の無線通信規格であるStarFlash E2.0を搭載し、接続性を強化しているのが特徴です。この機能は単なるソフトウェアの更新ではなく、ハードウェアレベルでのサポートが必要な技術であり、多様な周辺機器との連携を通じてユーザー体験を拡張することが期待されます。

まとめ

Huawei nova 16シリーズは全モデルでStarFlash E2.0を採用し、デバイスと周辺機器間の接続性を大幅に向上させています。この機能はハードウェアに依存する技術であり、スタイラスペンやスマートウォッチなどとの高度な連携を実現します。

Release Information

Detailed StarFlash Feature Support

Huawei's official website has disclosed specific details regarding the StarFlash features supported by the nova 16 series:

  • StarFlash Precise Finding
  • Connection with stylus pens, keyboards, and mice supporting StarFlash
  • Smartwatches supporting StarFlash (with mobile network sharing)
  • Keyboard and mouse connection

Technology Overview: StarFlash

StarFlash technology (NearLink) is a new type of wireless short-range communication standard released by the International Starflash Wireless Short-Range Communication Alliance. Currently, several Huawei mobile phone models support this technology.

Note that because StarFlash functionality depends on specific hardware capabilities, it cannot be enabled through system updates alone.

Overall Review

The Huawei nova 16 series is characterized by the integration of the latest wireless communication standard, StarFlash E2.0, across all models to enhance connectivity. Since this feature requires hardware-level support rather than just a software update, it is expected to significantly expand the user experience through seamless interaction with various peripheral devices.

Summary

The Huawei nova 16 series features four models equipped with StarFlash E2.0 to provide enhanced connectivity with peripherals like styluses and smartwatches. This hardware-dependent technology aims to create a more integrated ecosystem for users, moving beyond simple software-based improvements.
