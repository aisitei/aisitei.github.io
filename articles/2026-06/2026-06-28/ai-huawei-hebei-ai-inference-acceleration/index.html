Huawei 🤖 AI

Huawei와 허베이 모바일, 전국 이동통신사 최초의 AI 추론 가속 솔루션 실전망 테스트 완료로 긴 시퀀스 토큰 처리량 372% 향상

2026-06-28

협력 및 테스트 개요

6월 24일, MWC 상하이 2026 기간 중 Huawei와 중국 이동통신그룹 후베이 유한공사(Hubei Mobile)는 양측이 전국 통신 사업자 최초의 AI 추론 가속 솔루션 현장 테스트를 성공적으로 완료했다고 발표했습니다.

이번 테스트는 Huawei OceanStor A800 스토리지 및 Ascend A3 슈퍼 노드 아키텍처를 기반으로 하며, UCM(Unified Cache Manager, 추론 메모리 데이터 관리)을 탑재했습니다. 이를 통해 긴 시퀀스 AI 추런 시나리오에서 토큰 처리량(Token throughput)이 최대 372%까지 향상되는 획기적인 성과를 거두었습니다.

기술적 특징

AI 애플리케이션이 에이전트(Agent) 형태로 진화함에 따라 코드 생성, 다회차 대화와 같은 긴 컨텍스트 시퀀스가 주요 시나리오로 부상하고 있습니다. 그러나 기존 연산 카드의 고대역폭 메모리 용량은 제한적이며, 이는 KV Cache의 적중률을 저해하는 요인이 됩니다.

Huawei는 2025년 말 UCM 추론 메모리 데이터 관리 기술을 출시하여 고대역폭 메모리와 DRAM의 용량 한계를 극복하고 외장 스토리지를 통해 PB급의 KV Cache를 제공하며, KV Cache에 대한 전체 생명주기 계층화 관리 및 스케줄링을 수행합니다. 이를 통해 단일 대화 시 컨텍스트 윈도우를 크게 확장할 뿐만 아니라 다회차 대화에서 과거 KV Cache를 재사용하여 중복 계산을 방지합니다.

테스트 결과

이번 테스트는 Hubei Mobile의 실제 네트워크 환경에 vLLM-Ascend 프레임워크를 구축하여 MiniMax M2.5, GLM-5.1 등 주요 대형 모델을 대상으로 8K에서 190K 사이의 긴 시퀀스 입력 시나리오를 시뮬레이션했습니다.

MiniMax M2.5 모델 시나리오:

  • UCM 활성화 후 첫 토큰 지연(TTFT)이 26%~62% 개선
  • 단일 NPU 카드의 토큰 출력 효율(TPS) 대폭 향상
  • 시퀀스 길이 64K에서 TPS 58% 향상
  • 시퀀스 길이 128K에서 TPS 78% 향상

GLM-5.1 모델 시나리오:

  • TTFT 개선 폭이 51%~93%에 달함
  • TPS가 56%~372% 향상
  • 시퀀스 길이 64K에서 TPS 313% 향상
  • 시퀀스 길이 128K에서 TPS 372% 향상

Huawei는 테스트를 통해 컨텍스트 길이가 길어질수록 AI 추론 가속 솔루션의 장점이 더욱 확대되며, 긴 시퀀스 추론 과정에서의 KV Cache 용량 병목 현상을 효과적으로 해결했음을 확인했다고 밝혔습니다.

총평

Huawei와 Hubei Mobile은 협력을 통해 통신 사업자용 AI 추론 가속 솔루션의 성공적인 현장 테스트를 완료했습니다. 특히 UCM 기술을 도입하여 긴 시퀀스 처리 시 발생하는 KV Cache 용량 문제를 해결하고, 대형 모델에서 토큰 처리 효율을 획기적으로 개선하는 성과를 거두었습니다.

合作与技术架构

Huawei 与中国移动通信集团湖北有限公司宣布，双方已成功完成全国运营商首个 AI 推理加速解决方案的现网测试。该方案基于 Huawei OceanStor A800 存储与昇腾 A3 超节点架构，并搭载 UCM（Unified Cache Manager）推理记忆数据管理技术。

UCM 技术核心优势

针对 Agent 等长上下文序列场景（如代码生成、多轮对话），传统算力卡的高带宽内存容量有限。UCM 技术通过以下方式解决 KV Cache 的瓶颈：

  • 突破高带宽内存和 DRAM 的容量限制，提供 PB 级的 KV Cache。
  • 对 KV Cache 进行全生命周期的分层管理与调度。
  • 在多轮对话中复用历史 KV Cache，避免重复计算并大幅扩展上下文窗口。

实测性能数据

在湖北移动现网环境中部署 vLLM-Ascend 框架，针对 MiniMax M2.5 和 GLM-5.1 等主流大模型进行测试（模拟 8K 至 190K 长序列输入）：

MiniMax M2.5 模型表现：

  • 首 Token 延迟（TTFT）优化：26% - 62%。
  • 64K 序列长度下，TPS 提升 58%。
  • 128K 序列长度下，TPS 提升 78%。

GLM-5.1 模型表现：

  • 首 Token 延迟（TTFT）优化：51% - 93%。
  • 64K 序列长度下，TPS 提升 313%。
  • 128K 序列长度下，TPS 提升 372%。

总结

Huawei 与湖北移动合作推出的基于 UCM 技术的 AI 推理加速方案，有效解决了长上下文推理中的 KV Cache 容量瓶颈。实测证明，该技术能显著提升 MiniMax M2.5 和 GLM-5.1 等模型在长序列场景下的 Token 吞吐率并优化首 Token 延迟。

提携およびテストの概要

6月24日、MWC Shanghai 2026の期間中、Huaweiと中国の通信事業者Hubei Mobileは、双方が国内通信事業者の初となるAI推論加速ソリューションのフィールドテストを成功裏に完了したと発表しました。

今回のテストは、Huawei OceanStor A800ストレージおよびAscend A3スーパーノードアーキテクチャをベースとし、UCM（Unified Cache Manager、推論メモリデータ管理）を搭載しています。これにより、長いシーケンスのAI推論シナリオにおいて、トークン処理量（Token throughput）が最大372%向上するという画期的な成果を達成しました。

技術的特徴

AIアプリケーションがエージェント（Agent）へと進化するにつれ、コード生成や複数回の対話といった長いコンテキストのシーケンスが主要なシナリオとして浮上しています。しかし、従来の演算カードの高帯域幅メモリ（HBM）容量には限りがあり、これがKV Cacheのヒット率を低下させる要因となっています。

Huaweiは2025年末にUCM推論メモリデータ管理技術をリリースし、高帯域幅メモリとDRAMの容量制限を克服します。外部ストレージを通じてPB級のKV Cacheを提供し、KV Cacheに対する全ライフサイクルにわたる階層化管理およびスケジューリングを実行します。これにより、単一の対話におけるコンテキストウィンドウを大幅に拡張するだけでなく、複数回の対話において過去のKV Cacheを再利用することで重複計算を防ぎます。

テスト結果

今回のテストでは、Hubei Mobileの実ネットワーク環境にvLLM-Ascendフレームワークを構築し、MiniMax M2.5やGLM-5.1などの主要な大規模モデルを対象に、8Kから190Kまでの長いシーケンス入力シナリオをシミュレーションしました。

MiniMax M2.5 モデルのシナリオ：

  • UCM有効化後、最初のトークン遅延（TTFT）が26%〜62%改善
  • 単一NPUカードのトークン出力効率（TPS）が大幅に向上
  • シーケンス長64KでTPSが58%向上
  • シーケンス長128KでTPSが78%向上

GLM-5.1 モデルのシナリオ：

  • TTFTの改善幅が51%〜93%に達する
  • TPSが56%〜372%向上
  • シーケンス長64KでTPSが313%向上
  • シーケンス長128KでTPSが372%向上

Huaweiはテストを通じて、コンテキストが長くなるほどAI推論加速ソリューションの利点が拡大し、長いシーケンスの推論過程におけるKV Cache容量のボトルネックを効果的に解決したことを確認したと述べています。

まとめ

HuaweiとHubei Mobileは、通信事業者向けのAI推論加速ソリューションのフィールドテストに成功しました。UCM技術の導入により、長大なコンテキスト処理におけるKV Cacheの容量問題を解決し、大規模モデルにおけるトークン処理効率を劇的に向上させることが実証されました。

Collaboration and Test Overview

On June 24, during MWC Shanghai 2026, Huawei and Hubei Mobile announced the successful completion of field tests for the first AI inference acceleration solution for national telecommunications carriers. The test was based on the Huawei OceanStor A800 storage and Ascend A3 super node architecture, featuring UCM (Unified Cache Manager) for inference memory data management. This configuration achieved a breakthrough by improving token throughput by up to 372% in long-sequence AI inference scenarios.

Technical Features

As AI applications evolve into "Agents," long context sequences—such as code generation and multi-turn dialogues—are becoming primary use cases. However, the limited high-bandwidth memory (HBM) capacity of existing computing cards often hinders KV Cache hit rates.

Huawei's UCM technology, scheduled for release in late 2025, overcomes the capacity limits of HBM and DRAM by providing PB-scale KV Cache through external storage while performing full lifecycle management and scheduling. This not only significantly expands the context window for single conversations but also prevents redundant calculations in multi-turn dialogues by reusing previous KV Caches.

Test Results

The test was conducted within Hubei Mobile's actual network environment using the vLLM-Ascend framework. It simulated long sequence input scenarios ranging from 8K to 190K for major large models, including MiniMax M2.5 and GLM-5.1.

MiniMax M2.5 model scenario:

  • TTFT (Time to First Token) improved by 26% to 62% after UCM activation
  • Significant improvement in TPS (Tokens Per Second) on a single NPU card
  • TPS increased by 58% at a sequence length of 64K
  • TPS increased by 78% at a sequence length of 128K

GLM-5.1 model scenario:

  • TTFT improvement reached between 51% and 93%
  • TPS improved by 56% to 372%
  • TPS increased by 313% at a sequence length of 64K
  • TPS increased by 372% at a sequence length of 128K

Huawei stated that the test confirmed that the advantages of its AI inference acceleration solution become more pronounced as context lengths increase, effectively resolving KV Cache capacity bottlenecks during long-sequence inference processes.

Conclusion

Through this collaboration, Huawei and Hubei Mobile successfully completed field tests for an AI inference acceleration solution tailored for telecommunications carriers. By implementing UCM technology, the partnership addressed KV Cache capacity issues in long sequence processing and achieved significant improvements in token processing efficiency for large-scale models.

Summary

Huawei and Hubei Mobile successfully tested a new AI inference acceleration solution utilizing OceanStor A800 storage and Ascend A3 architecture. By implementing UCM technology, the system overcomes memory limitations to significantly boost token throughput and efficiency for large models handling long context sequences.
