Anthropic, 스마트폰용 Claude Cowork 테스트하며 긴 AI 작업의 원격 관리 기능 지원

2026-06-28

모바일용 Claude Cowork 테스트

기술 매체 bleepingcomputer는 6월 26일, Anthropic이 모바일용 Claude Cowork를 테스트 중이라고 보도했습니다. 이를 통해 사용자는 스마트폰에서 직접 작업을 시작하고 조정할 수 있습니다.

기능 및 활용 사례

Claude Cowork는 Anthropic이 Claude를 위해 설계한 데스크톱 중심의 에이전트 작업 모드로, 시간이 오래 걸리는 일반적인 지식 기반 업무를 처리하는 데 적합합니다. 이 기능은 사용자가 권한을 부여한 파일을 활용하여 문서 생성, 표 제작, 보고서 작성 등을 지원하며, 자료 정리, 문서 처리 및 다단계 작업 추적 등이 주요 활용 사례입니다.

현재 Cowork는 주로 macOS와 Windows용 Claude Desktop에 기반하고 있으나, 새로운 스크린샷에 따르면 Anthropic은 더욱 완전한 모바일 경험을 준비 중인 것으로 보입니다. 다만 모바일 버전이 데스크톱과 완전히 동일한 기능을 제공하지는 않을 수 있습니다.

해당 매체는 유출된 스크린샷을 바탕으로, Anthropic이 모바일용 Claude Cowork를 작업 시작, 방향 조정 및 진행 상황 확인을 위한 '원격 컨트롤러' 역할로 정의한 것으로 추측하고 있습니다.

개발 배경 및 원격 제어

Claude Cowork는 2026년 1월 13일 출시되었으며, 비개발자를 포함한 모든 사용자를 대상으로 하는 Claude Code 도우미의 파생 버전으로 포지셔닝되었습니다. 사용자는 컴퓨터 내 특정 폴더에 대한 접근 권한을 부여하여 파일을 읽고, 편집하고, 생성할 수 있습니다.

2026년 1월 14일 보도에 따르면 Cowork 코드의 "거의 전부"가 Anthropic의 AI인 Claude에 의해 작성되었으며, 개발 기간은 단 일주일 반이 소요되었습니다. 당시에는 Mac용 Claude Max 구독자에게만 제공되었습니다.

2026년 3월 24일, Anthropic은 Claude가 사용자의 Mac을 직접 제어할 수 있는 '컴퓨터 사용(Computer Use)' 기능을 테스트하기 시작했으며, 이와 연동되는 Dispatch 기능을 출시했습니다. 이를 통해 사용자는 스마트폰에서 데스크톱용 Claude에 음성 또는 텍스트 명령을 보내 기기 간 원격 제어를 수행할 수 있습니다.

총평

Anthropic은 모바일 환경에서도 업무를 관리하고 진행 상황을 확인할 수 있는 Claude Cowork의 모바일 지원을 준비 중입니다. 특히 '컴퓨터 사용' 기능과 Dispatch 기능을 결합하여 스마트폰으로 데스크톱 기반 작업을 원격 제어할 수 있는 통합적인 경험을 제공하고자 합니다.

移动端功能测试

Anthropic 正在测试将 Claude Cowork 推送到移动端。根据最新披露的截图，手机端的 Claude Cowork 被定位为“远程控制器”，允许用户在移动设备上发起任务、调整方向并查看进度。

Claude Cowork 产品定义

Claude Cowork 是 Anthropic 为 Claude 设计的桌面导向智能体工作模式，专门用于处理耗时较长的常规知识工作。其核心功能包括：

  • 调用用户授权的文件
  • 创建文档、生成表格及撰写报告
  • 执行资料整理、文档处理和多步骤任务跟进

研发背景与相关技术

Claude Cowork 于 2026 年 1 月 13 日发布，是面向非开发者群体的 Claude Code 助手衍生版本。该功能的代码几乎全部由 AI 完成，开发周期仅为一周半。

此外，Anthropic 还推出了相关的跨设备协作功能：

  • Computer Use（2026 年 3 月 24 日开始测试）：允许 Claude 直接控制用户的 Mac 电脑。
  • Dispatch 功能：支持用户通过手机向电脑端的 Claude 发送语音或文本指令，实现远程遥控。

总结

Anthropic 正推动 Claude Cowork 进入移动端，旨在为用户提供跨设备的智能体协作体验。该功能结合了强大的自动化任务处理能力与便捷的移动端远程控制功能。

モバイル向けClaude Coworkのテスト

技術メディアのbleepingcomputerは6月26日、Anthropicがモバイル向けのClaude Coworkをテスト中であると報じました。これにより、ユーザーはスマートフォンから直接タスクを開始し、調整を行うことが可能になります。

機能と活用事例

Claude Coworkは、AnthropicがClaude向けに設計したデスクトップ中心のエージェント作業モードであり、時間がかかる一般的な知識ベースの業務を処理するのに適しています。この機能は、ユーザーに権限を与えたファイルを利用して文書作成、表の作成、レポート作成などをサポートし、データの整理、ドキュメント処理、多段階のタスク追跡などが主な活用事例となります。

現在、Coworkは主にmacOSおよびWindows向けのClaude Desktopに基づいていますが、新たなスクリーンショットによると、Anthropicはより完全なモバイル体験を準備している模様です。ただし、モバイル版がデスクトップ版と完全に同一の機能を提供しない可能性もあります。

同メディアは流出したスクリーンショットに基づき、Anthropicがモバイル向けのClaude Coworkを、タスクの開始、方向の調整、および進捗状況の確認のための「リモートコントローラー」としての役割として定義していると推測しています。

開発背景とリモート制御

Claude Coworkは2026年1月13日にリリースされ、非開発者を含むすべてのユーザーを対象としたClaude Codeアシスタントの派生版として位置付けられました。ユーザーはコンピュータ内の特定のフォルダに対するアクセス権限を与えることで、ファイルを読み取り、編集し、作成することができます。

2026年1月14日の報道によると、Coworkコードの「ほぼすべて」がAnthropicのAIであるClaudeによって執筆され、開発期間はわずか1週間半を要したとのことです。当時、この機能はMac用のClaude Maxサブスクライバーにのみ提供されていました。

2026年3月24日、AnthropicはClaudeがユーザーのMacを直接操作できる「Computer Use」機能をテストし始め、これと連携するDispatch機能をリリースしました。これにより、ユーザーはスマートフォンからデスクトップ版のClaudeに音声またはテキストで指示を送り、デバイス間でのリモート制御を実行できるようになります。

まとめ

Anthropicは、モバイル環境でも業務管理や進捗確認ができるClaude Coworkのモバイル対応を進めています。「Computer Use」機能とDispatch機能を組み合わせることで、スマートフォンからデスクトップベースのタスクを遠隔操作できる統合的な体験の提供を目指しています。

Testing Claude Cowork for Mobile

Technology outlet bleepingcomputer reported on June 26 that Anthropic is testing Claude Cowork for mobile devices. This update will allow users to initiate and adjust tasks directly from their smartphones.

Features and Use Cases

Claude Cowork is a desktop-centric agent mode designed by Anthropic for Claude, specifically tailored to handle time-consuming, knowledge-based tasks. It supports various functions using files that the user has granted permission to access:

  • Document creation
  • Table generation
  • Report writing

Key use cases include data organization, document processing, and tracking multi-step workflows. While Cowork is currently based on Claude Desktop for macOS and Windows, leaked screenshots suggest that Anthropic is preparing a more comprehensive mobile experience. However, the mobile version may not offer identical functionality compared to the desktop version.

Based on leaked screenshots, bleepingcomputer suggests that Anthropic defines the mobile version of Claude Cowork as a "remote controller" intended for starting tasks, adjusting directions, and monitoring progress.

Development Background and Remote Control

Released on January 13, 2026, Claude Cowork is positioned as a derivative of the Claude Code assistant aimed at all users, including non-developers. Users can grant access to specific folders on their computers, allowing the AI to read, edit, and create files.

Reports from January 14, 2026, indicated that "nearly all" of the Cowork code was written by Anthropic's AI, Claude, in just a week and a half. At that time, it was only available to Mac Claude Max subscribers.

On March 24, 2026, Anthropic began testing the "Computer Use" feature, which allows Claude to directly control a user's Mac, alongside the launch of the Dispatch feature. This integration enables users to send voice or text commands from their smartphones to the desktop version of Claude, facilitating cross-device remote control.

Summary

Anthropic is developing mobile support for Claude Cowork to enable users to manage and monitor progress on tasks via smartphone. By combining "Computer Use" with the Dispatch feature, Anthropic aims to provide an integrated experience where mobile devices can remotely control desktop-based workflows.
