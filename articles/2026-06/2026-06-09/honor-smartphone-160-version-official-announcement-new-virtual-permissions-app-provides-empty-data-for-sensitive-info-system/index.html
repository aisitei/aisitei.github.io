Honor MagicOS 1.60 업데이트: 가상 권한 기능 추가

IT之家에 따르면, Honor 제품 유지보수 및 업그레이드 계정(@Honor小芳哥)이 오늘 영상을 통해 Honor 스마트폰의 1.60 버전에서 새롭게 추가된 '가상 권한(Virtual Permissions)' 기능을 소개했습니다.

주요 기능: 개인 정보 보호 강화

사용자들이 흔히 겪는 불편함 중 하나는 특정 앱을 사용하기 위해 민감한 데이터에 대한 접근 권한을 요구받는 경우입니다. 이 문제를 해결하기 위해 '가상 권한'이 도입되었습니다.

작동 원리 및 효과

이제 가상 권한 기능을 활성화하면, 앱이 '통화 기록'과 같은 민감 정보를 읽으려고 시도할 때 시스템은 실제 데이터 대신 빈 데이터를 제공합니다. 이를 통해 사용자의 개인 정보가 효과적으로 보호됩니다.

설정 방법

사용자가 이 기능을 쉽게 찾고 활성화할 수 있도록 설정 경로는 다음과 같습니다:

  • 설정 > 개인정보 및 보안 > 가상 권한

총평이번 Honor MagicOS 1.60 업데이트의 핵심은 '가상 권한' 기능 도입을 통한 사용자 프라이버시 강화입니다. 이 기능을 통해 민감 정보에 대한 앱 접근 시도에도 시스템이 빈 데이터를 제공함으로써, 사용자가 자신의 개인 정보를 더욱 안전하게 보호할 수 있게 되었습니다.

新增功能：虚拟权限

Honor 在手机 160 版本中推出了“虚拟权限”功能。该功能旨在解决用户在授予应用权限时面临的隐私困扰，当应用程序尝试获取如“通话记录”等敏感信息时，系统会自动提供空白数据给应用，从而有效保护用户的个人隐私安全。

操作路径与细节

用户可以通过以下路径进入并配置该功能：

  • 设置 > 隐私与安全 > 虚拟权限

系统更新背景

此项新功能包含在 Honor MagicOS 的六月系统升级内容中。

总结

Honor 在 160 版本中新增了“虚拟权限”功能，通过提供虚假数据来保护用户通话记录等敏感信息不被应用获取。该功能已整合至 Honor MagicOS 六月更新中，旨在提升移动端的隐私保护水平。

Honor MagicOS 1.60 アップデート：仮想権限機能の追加

IT之家の報道によると、Honor製品のメンテナンスおよびアップグレード担当アカウント（@Honor小芳哥）が公開した動画にて、HonorスマートフォンのMagicOS 1.60バージョンで新しく追加された「仮想権限（Virtual Permissions）」機能が紹介されました。

主要な機能：プライバシー保護の強化

ユーザーが日常的に直面する不便さの一つに、特定のアプリを使用するために機密データへのアクセス権限を要求されるケースがあります。この問題を解決するために「仮想権限」機能が導入されました。

動作原理と効果

「仮想権限」機能を有効にすると、アプリが「通話履歴」などの機密情報を読み取ろうとした際に、システムが実際のデータではなく空のデータを提供します。これにより、ユーザーの個人情報が効果的に保護される仕組みとなっています。

設定方法

ユーザーがこの機能を見つけやすく、かつ簡単に有効化できるように、以下のパスで設定が行えます：

  • 設定 > プライバシーとセキュリティ > 仮想権限

まとめ

Honor MagicOS 1.60のアップデートでは、プライバシー保護を強化する「仮想権限（Virtual Permissions）」機能が導入されました。この機能により、アプリが機密情報にアクセスしようとした際にシステム側で空のデータを返すため、ユーザーはより安全に個人情報を守ることができます。

Honor MagicOS 1.60 Update: Virtual Permissions Feature Added

According to IT House, an official Honor maintenance and update account (@Honor小芳哥) released a video today introducing the new 'Virtual Permissions' feature included in version 1.60 of MagicOS for Honor smartphones.

Key Feature: Enhanced Privacy Protection

One common inconvenience users face is being prompted to grant access to sensitive data just to use specific applications. The 'Virtual Permissions' feature was introduced to address this issue and provide a layer of security between the user and third-party apps.

Mechanism and Effects

Once the Virtual Permissions feature is activated, the system provides empty data instead of actual information when an application attempts to access sensitive content such as 'Call Logs.' This ensures that personal information remains protected even if an app requests access to private records.

How to Configure

To help users easily find and enable this feature, the navigation path is provided below:

  • Settings > Privacy & Security > Virtual Permissions

Summary

The Honor MagicOS 1.60 update introduces 'Virtual Permissions' to significantly enhance user privacy by providing dummy data when apps request access to sensitive information. This feature ensures that personal details, such as call logs, are not exposed to applications, providing a safer browsing and app-usage experience.

新增“虚拟权限”功能

Honor 在手机 160 版本中推出了“虚拟权限”功能。该功能旨在保护用户隐私，当应用程序尝试获取通话记录等敏感信息时，系统将向应用提供空白数据，从而防止真实信息的泄露。

操作路径

用户可以通过以下路径进入并开启相关设置：

  • 设置 > 隐私与安全 > 虚拟权限

总结

Honor 在 MagicOS 系统更新中引入了“虚拟权限”功能。该功能通过在应用请求敏感信息时提供虚假数据，有效增强了用户个人信息的安全性。
