Xcode 27 베타 출시: Apple은 이를 AI 지능형 앱 구축의 “최적 장소”라고 말합니다.

2026-06-09

WWDC 2026 주요 발표: Xcode 및 Core AI 프레임워크 대폭 업그레이드

IT之家에 따르면, 지난 6월 9일에 개최된 2026 WWDC(세계 개발자 컨퍼런스)에서 Apple은 개발자를 대상으로 새로운 Xcode와 Core AI 프레임워크를 업데이트하여 공개했습니다.

Core AI 프레임워크: 멀티모달 기능 강화

Apple은 개발자들이 인공지능 기능을 더욱 유연하게 활용할 수 있도록 신규 Foundation Models 프레임워크를 발표했습니다. 이 새로운 프레임워크는 이미지 입력을 지원하여, 개발자가 사진과 텍스트를 동시에 장치 측 모델에 전달할 수 있게 했습니다.

이를 통해 앱은 훨씬 풍부한 멀티모달 작업을 직접 처리할 수 있는 기반을 마련하게 됩니다.

Xcode: 에이전트(Agent) 기반 코딩 워크플로우로 진화

이번 Xcode 업데이트에서는 코딩 어시스턴트를 더욱 지능적인 에이전트식 코딩 워크플로우로 발전시키는 데 초점을 맞췄습니다. 주요 개선 사항은 다음과 같습니다.

  • 다국어 지원 및 현지화: 앱 로컬라이제이션 기능을 강화하여, 개발자가 다양한 언어에 맞는 적응 작업을 처리하는 것을 돕습니다.
  • 시뮬레이터 연동: 코딩 어시스턴트가 시뮬레이터와 상호작용할 수 있게 되어, 코드 작성 단계부터 테스트 및 디버깅 과정까지 통합적으로 관리할 수 있습니다.

또한, 개발자는 앱 미리보기(Preview) 크기를 더 쉽게 조정하고 미리보기 인터페이스와 직접 상호 작용하는 것이 가능해집니다.

개발자 경험 개선 및 향후 계획

Apple 소프트웨어 엔지니어링 수석 부사장인 Craig Federighi는 Xcode가 에이전트 AI 애플리케이션을 구축하기 위한 "최적의 장소(best place)"가 되었다고 강조했습니다.

더 많은 세부 사항은 추후 특집 세션과 State of the Union 연설에서 공개될 예정입니다.

총평

이번 WWDC 발표는 Apple이 개발자 도구와 AI 기능을 통합하여 앱 개발의 패러다임을 변화시키고 있음을 보여줍니다. 특히 Core AI 프레임워크를 통해 이미지와 텍스트가 결합된 멀티모달 기능이 강화되었으며, Xcode는 단순한 코딩 환경을 넘어 테스트, 로컬라이제이션까지 아우르는 에이전트 기반의 통합 개발 플랫폼으로 진화했습니다.

Core AI 框架更新

Apple 推出了全新的 Foundation Models 框架，旨在让开发者更灵活地调用 AI 能力。该新框架已支持图像输入，允许开发者将图片与文本一并传输给设备端模型，从而支持应用处理更丰富的多模态任务。

Xcode 功能升级

新版 Xcode 推向智能体式编码工作流，旨在提升开发效率。具体更新包括：

  • 提供应用本地化功能，帮助开发者处理多语言适配。
  • 编码助手支持与模拟设备交互，涵盖从编写代码到测试、调试的完整环节。
  • 优化了预览尺寸调整以及与预览界面的交互体验。

官方表态

Apple 软件工程高级副总裁 Craig Federighi 表示，Xcode 已成为构建智能体 AI 应用的“最佳场所”。

总结

Apple 在 WWDC 上推出了全新的 Xcode 和 Core AI 框架。核心更新包括支持多模态任务的 Foundation Models 以及具备更强交互能力和智能体工作流的 Xcode，旨在全面赋能开发者构建 AI 应用。

WWDC 2026の主要発表：XcodeおよびCore AIフレームワークの大幅なアップグレード

IT之家の報道によると、6月9日に開催されたWWDC（世界開発者会議）において、Appleは開発者向けにアップデートされた新しいXcodeとCore AIフレームワークを発表しました。

Core AIフレームワーク：マルチモーダル機能の強化

Appleは、開発者がAI機能をより柔軟に活用できるようにするための新しいFoundation Modelsフレームワークを発表しました。この新しいフレームワークは画像入力をサポートしており、開発者が写真とテキストを同時にデバイス上のモデルへ送信できるようになります。

これにより、アプリがより高度なマルチモーダル処理を直接実行するための基盤が整います。

Xcode：エージェント（Agent）ベースのコーディングワークフローへの進化

今回のXcodeアップデートでは、コーディングアシスタントをよりインテリジェントなエージェント型コーディングワークフローへと進化させることに重点を置いています。主な改善点は以下の通りです。

  • 多言語サポートとローカライゼーション： アプリのローカライゼーション機能を強化し、開発者が多様な言語に適応する作業を効率的に処理できるよう支援します。
  • シミュレータ連携： コーディングアシスタントがシミュレータと相互作用できるようになり、コード作成からテスト、デバッグに至るまでのプロセスを一貫して管理することが可能になります。

さらに、開発者はアプリプレビュー（Preview）のサイズをより簡単に調整し、プレビューインターフェースと直接対話できるようになります。

開発者体験の向上と今後の展望

Appleのソフトウェアエンジニアリング担当シニアバイスプレジデントであるCraig Federighiは、XcodeがエージェントAIアプリケーションを構築するための「最適な場所（best place）」になったことを強調しました。

詳細については、今後の特別セッションおよびState of the Union演説にて順次公開される予定です。

まとめ

今回のWWDCでは、Appleが開発者ツールとAI機能を統合することでアプリ開発のパラダイムシフトを推進していることが示されました。Core AIフレームワークによるマルチモーダルの強化に加え、Xcodeは単なるコーディング環境を超え、テストやローカライゼーションまで網羅するエージェントベースの統合開発プラットフォームへと進化しています。

WWDC 2026 Key Announcements: Major Upgrades to Xcode and Core AI Framework

According to IT House, during the WWDC held on June 9, Apple unveiled significant updates for developers, including a new version of Xcode and an enhanced Core AI framework.

Core AI Framework: Enhanced Multimodal Capabilities

Apple introduced a new Foundation Models framework designed to provide developers with greater flexibility when utilizing artificial intelligence features. This new framework supports image inputs, enabling developers to send both photos and text simultaneously to on-device models.

This advancement provides the foundation for applications to process much richer multimodal tasks directly on the device.

Xcode: Evolution Toward Agent-Based Coding Workflows

The latest Xcode update focuses on evolving coding assistants into more intelligent, agent-based coding workflows. Key improvements include:

  • Multilingual Support and Localization: Enhanced app localization features help developers manage adaptation tasks across various languages.
  • Simulator Integration: Coding assistants can now interact with simulators, allowing for a unified workflow that covers everything from initial code writing to testing and debugging.

Furthermore, developers can now more easily resize app previews and interact directly with preview interfaces.

Improved Developer Experience and Future Plans

Craig Federighi, Apple's Senior Vice President of Software Engineering, emphasized that Xcode has become the "best place" for building agent AI applications.

More details are expected to be revealed in upcoming special sessions and the State of the Union speech.

Summary

Apple is transforming the app development landscape by integrating advanced AI capabilities directly into its developer tools. The new Core AI framework enables sophisticated multimodal processing, while the updated Xcode provides an integrated, agent-based environment that streamlines coding, testing, and localization.
