Apple 🤖 AI

LM Studio, Apple과 협력하여 4대의 Mac Studio에서 수조 파라미터 규모의 Kimi K2.6 거대 모델 구동 성공

2026-06-21

개요

6월 20일 IT_Home에 따르면, Apple WWDC 2026 기간 중 LM Studio는 Apple과 협력하여 4대의 Mac Studio 클러스터에서 Moonshot AI의 1조 파라미터 대규모 모델인 Kimi K2.6을 성공적으로 구동했습니다. 또한 LM Link를 통해 MacBook Neo 및 iPhone에서 안전하게 원격 접속하는 기능을 선보였습니다.

모델 사양

Kimi K2.6 대형 모델은 다음과 같은 기술적 특징을 갖추고 있습니다.

  • 총 파라미터 규모: 1조 개
  • 아키텍처: MoE (Mixture of Experts)
  • 활성 파라미터: 320억 개
  • 지원 기능: 긴 컨텍스트, 멀티모달 입력 및 에이전트 태스크 처리

성능 및 하드웨어

LM Studio의 공식 설명에 따르면, 이번 시연에서 4대의 Mac Studio는 Apple의 메모리 공유 및 상호 연결 기술을 통해 클러스터를 형성했으며, 이를 통해 약 1.5TB의 통합 메모리 용량을 확보하여 대규모 모델의 추론 요구 사항을 충족할 수 있었습니다.

개발자 테스트 결과에 따르면, 유사한 Mac Studio 클러스터 구성에서 Kimi K2.6 모델은 특정 모드에서 약 28 tokens/s의 생성 속도를 기록했으며, 기존 GPU 클러스터 대비 낮은 전력 소모를 보여주었습니다. LM Studio는 로컬 AI 모델 실행 플랫폼으로서, 이번 Apple과의 협력을 통해 소비자용 하드웨어에서 대규모 오픈 소스 모델을 배포할 수 있는 가능성을 입증했습니다.

기술적 진보 및 연결성

이번 시연은 Thunderbolt 5 RDMA 지원과 다중 기기 메모리 공유 능력을 포함하여, AI 로컬 배포 측면에서 Apple 생태계의 기술적 진보를 강조했습니다. LM Studio의 원격 접속 기능인 LM Link는 2026년 6월 초 Mac 앱 및 Locally AI iOS 앱에 업데이트되었으며, 종단 간 암호화 연결을 지원합니다.

총평

LM Studio와 Apple의 협력은 고성능 Mac Studio 클러스터를 활용해 Kimi K2.6과 같은 초거대 모델을 로컬 환경에서 성공적으로 구동할 수 있음을 보여주었습니다. 특히 Thunderbolt 5 RDMA 기반의 메모리 공유 기술과 LM Link를 통한 안전한 원격 접속 기능은 소비자용 하드웨어 생태계 내에서 강력한 AI 활용 가능성을 제시했습니다.

Kimi K2.6 模型规格

Moonshot AI 推出的 Kimi K2.6 是一个基于 MoE 架构的大规模模型，具备强大的处理能力。

  • 总参数规模：1 万亿
  • 激活参数：320 亿
  • 核心功能：支持长上下文、多模态输入以及智能体任务处理

Mac Studio 集群与硬件性能

LM Studio 与 Apple 合作，在 WWDC 2026 期间展示了利用 Mac 系列硬件运行超大规模模型的可能性。

  • 集群配置：4 台 Mac Studio 通过 Apple 的内存共享和互联技术组成集群
  • 统一内存容量：约 1.5TB
  • 性能表现：在特定模式下生成速度可达约 28 tokens/s，且功耗低于传统 GPU 集群
  • 核心技术：支持 Thunderbolt 5 RDMA 等多设备内存共享能力

LM Link 与远程访问功能

通过 LM Link 功能，用户可以在移动端和轻便设备上安全地与集群中的模型进行交互。

  • 支持终端：MacBook Neo、iPhone
  • 安全性：采用端到端加密连接，确保数据和通信在本地化处理
  • 软件更新：LM Link 已于 2026 年 6 月初更新至 Mac 应用和 Locally AI iOS 应用中

总结

LM Studio 与 Apple 合作展示了在由四台 Mac Studio 组成的集群上运行万亿参数规模的 Kimi K2.6 模型。该方案利用高容量统一内存实现了高性能、低功耗的推理，并通过 LM Link 提供跨设备的安全远程访问能力。

概要

6月20日、IT_Homeの報道によると、Apple WWDC 2026期間中、LM StudioはAppleと協力し、4台のMac Studioクラスター上でMoonshot AIの1兆パラメータの大規模モデル「Kimi K2.6」を正常に動作させることに成功しました。また、LM Linkを通じてMacBook NeoおよびiPhoneから安全にリモートアクセスする機能も披露されました。

モデル仕様

Kimi K2.6大型モデルは、以下の技術的特徴を備えています。

  • 総パラメータ数：1兆
  • アーキテクチャ：MoE (Mixture of Experts)
  • アクティブパラメータ：320億
  • サポート機能：ロングコンテキスト、マルチモーダル入力、エージェントタスク処理

性能とハードウェア

LM Studioの公式説明によると、今回のデモンストレーションでは、4台のMac StudioがAppleのメモリ共有および相互接続技術を通じてクラスターを形成しました。これにより約1.5TBの統合メモリ容量を確保し、大規模モデルの推論要件を満たすことが可能となりました。

開発者テストの結果によると、同様のMac Studioクラスター構成において、Kimi K2.6モデルは特定のモードで約28 tokens/sの生成速度を記録し、従来のGPUクラスターと比較して低い消費電力を示しました。LM StudioはローカルAIモデル実行プラットフォームとして、今回のAppleとの協力により、コンシューマー向けハードウェアで大規模なオープンソースモデルを展開できる可能性を証明しました。

技術的進歩と接続性

今回のデモンストレーションは、Thunderbolt 5 RDMAのサポートやマルチデバイス間でのメモリ共有能力を含め、AIのローカル展開におけるAppleエコシステムの技術的進歩を強調しました。LM Studioのリモートアクセス機能であるLM Linkは、2026年6月初旬にMacアプリおよびLocally AI iOSアプリにアップデートされ、エンドツーエンドの暗号化接続をサポートしています。

まとめ

LM StudioとAppleの協力により、高性能なMac Studioクラスターを活用してKimi K2.6のような超巨大モデルをローカル環境で動作させることが可能になったことが示されました。特にThunderbolt 5 RDMAによるメモリ共有技術とLM Linkによる安全なリモートアクセス機能は、コンシューマー向けハードウェアにおける強力なAI活用の可能性を提示しています。

Overview

On June 20, according to IT_Home, LM Studio collaborated with Apple during WWDC 2026 to successfully run Moonshot AI's Kimi K2.6—a large-scale model featuring 1 trillion parameters—on a cluster of four Mac Studios. Additionally, the collaboration showcased "LM Link," which provides secure remote access capabilities for MacBook Neo and iPhone devices.

Model Specifications

The Kimi K2.6 large model features the following technical specifications:

  • Total Parameters: 1 Trillion
  • Architecture: MoE (Mixture of Experts)
  • Active Parameters: 32 Billion
  • Supported Features: Long context, multimodal input, and agent task processing

Performance and Hardware

According to LM Studio's official description, the four Mac Studios formed a cluster utilizing Apple's memory sharing and interconnect technologies. This configuration provided approximately 1.5TB of unified memory capacity, meeting the inference requirements for large-scale models.

Developer testing revealed that in specific modes, the Kimi K2.6 model achieved generation speeds of approximately 28 tokens/s on a similar Mac Studio cluster setup while exhibiting lower power consumption compared to traditional GPU clusters. As a platform for executing local AI models, LM Studio's collaboration with Apple demonstrated the feasibility of deploying large open-source models on consumer hardware.

Technical Advancements and Connectivity

The demonstration highlighted significant technical progress within the Apple ecosystem regarding local AI deployment, specifically including Thunderbolt 5 RDMA support and multi-device memory sharing capabilities. LM Link, a remote access feature from LM Studio, was updated in early June 2026 for Mac applications and Locally AI iOS apps, supporting end-to-end encrypted connections.

Summary

The collaboration between LM Studio and Apple demonstrates that massive models like Kimi K2.6 can be successfully operated in local environments using high-performance Mac Studio clusters. By leveraging Thunderbolt 5 RDMA for memory sharing and providing secure remote access through LM Link, the partnership highlights the significant potential for advanced AI capabilities within the consumer hardware ecosystem.
