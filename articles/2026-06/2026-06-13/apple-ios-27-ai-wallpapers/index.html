당신이 생각하는 최고의 배경화면 제작: Apple iOS 27 업데이트, AI 맞춤형으로 iPhone 17 등 기종별 배경화면 지원

2026-06-13

새로운 배경화면 기능

IT홈은 6월 12일 보도에 따르면, 기술 매체 9to5Mac이 어제(6월 11일) 게시한 글을 통해 Apple이 iOS 27 시스템에서 새로운 맞춤형 배경화면 기능을 추가했다고 밝혔습니다. 이 기능은 사용자가 Image Playground AI를 활용하여 iPhone 17 등 다양한 화면 크기에 최적화된 배경화면을 생성할 수 있도록 지원합니다.

접근 방식

사용자는 별도의 Image Playground 앱을 실행할 필요 없이 다음 경로를 통해 접근할 수 있습니다.

  • 설정 > 배경화면 > 새 배경화면 추가
  • 잠금 화면에서 길게 누른 후 "+" 버튼 클릭

배경화면 갤러리의 상단 바에 새로 추가된 Image Playground 입구를 통해 즉시 제작을 시작할 수 있습니다.

AI 기반 자동 추천 및 맞춤형 제작

iOS 27의 배경화면 갤러리에는 AI 자동 추천 기능이 도입되었습니다. 시스템은 사용자의 사진첩에 있는 사진를 바탕으로 스타일이 가미된 버전의 배경화면을 자동으로 제안합니다.

테스트 버전에서는 사용자의 별도 조작 없이도 일부 사진을 세련된 스타일의 배경화면으로 자동 변환하며, 생성된 모든 AI 기반 배경화면 옆에는 Image Playground 아이콘이 표시됩니다.

맞춤형 제작 기능의 경우, 사용자는 텍스트 설명을 통해 원하는 이미지 내용을 입력하거나 특정 스타일을 선택할 수 있으며, 기존 사진이나 인물을 바탕으로도 생성이 가능합니다. 생성된 이미지는 iPhone 배경화면에 최적화된 크기로 자동 조정되어 수동으로 자르는 번거로움을 없애줍니다.

총평

iOS 27은 Image Playground AI를 통합하여 사용자가 텍스트나 기존 이미지를 기반으로 고품질의 맞춤형 배경화면을 손쉽게 제작할 수 있는 기능을 제공합니다. 특히 자동 추천 및 크기 최적화 기능이 포함되어 사용자 경험이 한층 강화될 것으로 보입니다.

新增基于 Image Playground 的壁纸功能

在 iOS 27 系统中，Apple 推出了全新的自定义壁纸功能。该功能利用 Image Playground AI 技术，支持用户生成适配 iPhone 17 等多种屏幕尺寸的定制化壁纸。

操作入口与交互方式

用户可以通过以下两种路径进入并使用相关功能：

  • 系统设置：前往“设置 → 壁纸 → 添加新壁纸”。
  • 锁屏界面：长按锁屏界面后点击 “+” 按钮。

在画廊顶栏中，新增了 Image Playground 入口，用户点击即可进入创作模式。

AI 推荐与定制化生成

iOS 27 的壁纸系统引入了多项 AI 驱动的功能：

  • 自动推荐机制：系统会基于用户相册中的照片，自动生成风格化的壁纸建议。
  • 自动化转换：在测试版中，部分照片会自动转化为精美的风格化壁纸，并显示 Image Playground 图标。
  • 多样化创作方式：支持通过文字描述、选择特定风格，或以现有照片及人物为基础进行生成。
  • 自动尺寸适配：生成的图像将自动匹配 iPhone 壁纸的最佳尺寸，无需用户手动裁剪。

总结

iOS 27 通过集成 Image Playground AI 技术，极大地丰富了壁纸定制功能。系统支持从文字描述或现有照片中生成高度个性化的内容，并提供自动化推荐与尺寸适配，简化了用户的创作流程。

新しい壁紙機能

ITホームの6月12日の報道によると、テックメディアの9to5Macが昨日（6月11日）公開した記事において、AppleがiOS 27システムに新しいカスタマイズ可能な壁紙機能を追加したことが明らかになりました。この機能により、ユーザーはImage Playground AIを活用して、iPhone 17など様々な画面サイズに最適化された壁紙を生成できるようになります。

アクセス方法

ユーザーは専用のImage Playgroundアプリを起動することなく、以下のパスからこの機能にアクセスできます。

  • 設定 > 壁紙 > 新しい壁紙を追加
  • ロック画面を長押しし、「+」ボタンをクリック

壁紙ギャラリーの上部バーに追加されたImage Playgroundの入り口から、すぐに制作を開始することが可能です。

AIによる自動推奨とカスタム作成

iOS 27の壁紙ギャラリーには、AIによる自動推奨機能が導入されました。システムはユーザーのフォトアルバム内にある写真を基に、スタイルを適用したバージョンの壁紙を自動的に提案します。

テスト版では、ユーザーの操作なしでも一部の写真を洗練されたスタイルの壁紙に自動変換し、生成されたすべてのAIベースの壁紙の横にはImage Playgroundアイコンが表示されます。

カスタム作成機能については、ユーザーがテキストの説明を入力して希望する画像内容を指定したり、特定のスタイルを選択したりできるほか、既存の写真や人物を基に生成することも可能です。生成された画像はiPhoneの壁紙に最適化されたサイズに自動調整されるため、手動でトリミングする手間がかかりません。

総評

iOS 27はImage Playground AIを統合することで、ユーザーがテキストや既存の画像に基づいて高品質なカスタム壁紙を簡単に作成できる機能を提供します。特に自動推奨およびサイズ最適化機能が含まれていることで、ユーザー体験が一層向上すると見込まれます。

まとめ

iOS 27ではImage Playground AIの統合により、テキストや既存の画像からデバイスに最適化された壁紙を簡単に生成できるようになります。AIによる自動提案や自動サイズ調整機能の追加により、ユーザーはより手軽で高度なカスタマイズ体験を得られるようになります。

New Wallpaper Features

According to a report by IT Home on June 12, tech outlet 9to5Mac revealed that Apple has added new customized wallpaper features in iOS 27. This feature allows users to generate wallpapers optimized for various screen sizes, such as the iPhone 17, utilizing Image Playground AI.

Access Methods

Users can access this feature without needing to launch a separate Image Playground app through the following paths:

  • Settings > Wallpaper > Add New Wallpaper
  • Long press on the Lock Screen and tap the "+" button

Creation can also begin immediately via the newly added Image Playground entry located in the top bar of the wallpaper gallery.

AI-Powered Recommendations and Custom Creation

The iOS 27 wallpaper gallery introduces an AI auto-recommendation feature. The system automatically suggests stylized versions of wallpapers based on photos within the user's photo library.

In the beta version, some photos are automatically converted into stylish wallpapers without any manual input from the user, and an Image Playground icon is displayed next to all AI-generated wallpapers.

For custom creation, users can enter desired image content via text descriptions or select specific styles; they can also generate images based on existing photos or people. The generated images are automatically resized for iPhone screens, removing the hassle of manual cropping.

Overall Review

By integrating Image Playground AI, iOS 27 provides users with a way to easily create high-quality customized wallpapers based on text or existing images. In particular, features such as auto-recommendations and size optimization are expected to significantly enhance the user experience.

Summary

iOS 27 integrates Image Playground AI to provide users with convenient tools for creating high-quality, customized wallpapers through text prompts or existing photos. The update also includes automated styling suggestions based on the user's library and automatic size optimization for various device screens.
