Huawei, 공간 효과 및 AI 업그레이드를 포함한 HarmonyOS 7 출시

2026-06-13

새로운 시각적 스타일과 심화된 AI 통합

HarmonyOS 7의 가장 큰 변화 중 하나는 사용자 인터페이스(UI)에 더욱 깊은 입체감을 부여하는 새로운 공간 디자인 언어입니다. Huawei는 소프트웨어 기반 렌더링 기술을 활용하여 잠금 화면이 배경화면과 자연스럽게 어우러지는 효과를 포함한 시스템 전반에 3차원 효과를 구현했습니다. 또한 버튼, 슬라이더 및 기타 화면 요소에 움직임과 깊이를 더하는 새로운 조명 효과가 추가되었습니다.

HarmonyOS 7에서 인공지능은 훨씬 더 큰 역할을 수행합니다. Huawei는 이번 버전이 단순히 기존 기능 위에 AI 기능을 덧붙인 것이 아니라, 포괄적인 AI 기반 아키텍처를 바탕으로 구축된 첫 번째 운영체제라고 설명했습니다. 업그레이드된 Celia 어시스턴트는 이제 사용자 의도를 파악하고, 다단계 작업을 수행하며, 앱 및 서비스와 더욱 깊게 상호작용할 수 있는 시스템 수준의 지능형 허브로 자리매김했습니다.

또한 HarmonyOS Intelligent Agent Framework 2.0을 도입하여 복잡한 요청에 대한 작업 완료율을 90% 이상으로 높였다고 합니다. 이와 더불어 더욱 스마트해진 사진 편집 도구, 콘텐츠 생성 기능 및 개선된 시스템 수준의 지원이 포함됩니다. 이제 어시스턴트는 더 넓은 범위의 앱 내 명령을 지원하며 자연어 요청에 더욱 효과적으로 대응합니다.

보안 강화 및 성능 최적화

AI 기능과 더불어 HarmonyOS 7은 일반적인 사기 수법으로부터 사용자를 보호하기 위한 새로운 방지 플랫폼을 도입했습니다. 시스템은 의심스러운 QR 코드 식별, 잠재적인 사기 웹 페이지 탐지, 앱 사칭 시도 경고 및 해외 스팸 전화 번호 인식 기능을 제공합니다.

또한 AI 기반 음성 사기 탐지 및 통신 안전에 중점을 둔 여러 도구가 추가되었습니다. 성능 개선 또한 이번 업데이트의 핵심 요소입니다. Huawei에 따르면 HarmonyOS 7은 이전 세대보다 최대 15% 향상된 성능을 제공하면서도 장기적인 시스템 부하 성장을 효과적으로 제어합니다.

HarmonyOS 7 개발자 베타 출시

Huawei는 HarmonyOS 7 Developer Beta 프로그램에 참여 가능한 첫 번째 기기 목록을 확정했습니다. 오늘부터 다음 기기에서 개발자 베타를 사용할 수 있습니다.

  • Huawei Mate 80 Pro
  • Mate X7
  • Mate XT Master
  • Pura 90 Pro Max
  • Pura X
  • Pura X Collector’s Edition
  • nova 15 Pro

해당 기기를 보유한 개발자는 즉시 새로운 소프트웨어를 테스트할 수 있으며, 안정적인 버전은 올해 말 출시될 예정입니다. 오는 9월 중국에서 출시될 Mate 90 시리즈는 HarmonyOS 7이 기본 탑재되는 첫 번째 Huawei 스마트폰이 될 전망입니다.

총평

HarmonyOS 7은 단순한 기능 업데이트를 넘어 AI 기반 아키텍처를 핵심으로 설계된 차세대 운영체제로서의 면모를 보여줍니다. 시각적 디자인의 혁신과 강력한 보안 플랫폼, 그리고 향상된 성능을 통해 기기 간 연결성을 강화하고 사용자 경험을 한 단계 끌어올렸습니다.

New Visual Style and Enhanced AI Integration

One of the most significant changes in HarmonyOS 7 is its new spatial design language, which provides a deeper sense of depth to the user interface (UI). Huawei utilized software-based rendering technology to implement 3D effects across the system, including an effect where the lock screen blends naturally with the wallpaper. Additionally, new lighting effects have been added to buttons, sliders, and other on-screen elements to provide movement and depth.

AI plays a much larger role in HarmonyOS 7. Huawei explained that this version is not simply an addition of AI features onto existing functions, but rather the first operating system built upon a comprehensive AI-based architecture. The upgraded Celia assistant has established itself as a system-level intelligent hub capable of understanding user intent, performing multi-step tasks, and interacting more deeply with apps and services.

Furthermore, the introduction of the HarmonyOS Intelligent Agent Framework 2.0 has reportedly increased the completion rate for complex requests to over 90%. This is accompanied by smarter photo editing tools, content generation capabilities, and improved system-level support. The assistant now supports a wider range of in-app commands and responds more effectively to natural language requests.

Security Enhancements and Performance Optimization

Alongside AI features, HarmonyOS 7 introduces a new prevention platform to protect users from common fraud tactics. The system provides functions such as identifying suspicious QR codes, detecting potentially fraudulent web pages, warning against app impersonation attempts, and recognizing overseas spam phone numbers.

Additionally, several tools focused on AI-based voice scam detection and communication safety have been added. Performance improvements are also a key element of this update. According to Huawei, HarmonyOS 7 delivers up to a 15% performance increase over the previous generation while effectively managing long-term system load growth.

HarmonyOS 7 Developer Beta Release

Huawei has finalized the list of first devices eligible for the HarmonyOS 7 Developer Beta program. Starting today, the developer beta can be used on the following devices:

  • Huawei Mate 80 Pro
  • Mate X7
  • Mate XT Master
  • Pura 90 Pro Max
  • Pura X
  • Pura X Collector’s Edition
  • nova 15 Pro

Developers owning these devices can test the new software immediately, with a stable version scheduled for release at the end of this year. The Mate 90 series, set to launch in China this September, is expected to be the first Huawei smartphone to ship with HarmonyOS 7 pre-installed.

Summary

HarmonyOS 7 marks a transition to an AI-centric architecture, featuring enhanced spatial UI designs and a more capable Celia assistant for complex tasks. The update also introduces robust anti-fraud security measures and provides up to a 15% performance boost over the previous generation. The first wave of devices for the developer beta has been announced, with the Mate 90 series set to be the primary debut for the new OS.

新しい視覚的スタイルと深化したAI統合

HarmonyOS 7における最大の変化の一つは、ユーザーインターフェース（UI）により深い立体感を与える新しい空間デザイン言語の採用です。Huaweiはソフトウェアベースのレンダリング技術を活用し、ロック画面が壁紙と自然に調和する効果を含むシステム全体に3次元的なエフェクトを実装しました。また、ボタンやスライダー、その他の画面要素には、動きと奥行きを加える新しいライティング効果が追加されています。

HarmonyOS 7において、人工知能（AI）はより大きな役割を果たします。Huaweiは、今回のバージョンが単に既存の機能にAIを追加したものではなく、包括的なAIベースのアーキテクチャに基づいて構築された初のオペレーティングシステムであると説明しています。アップグレードされたCeliaアシスタントは、ユーザーの意図を把握し、多段階のタスクを実行し、アプリやサービスとより深く相互作用できるシステムレベルのインテリジェントなハブとして位置づけられました。

さらに、HarmonyOS Intelligent Agent Framework 2.0を導入することで、複雑な要求に対するタスク完了率を90%以上に向上させたと報告されています。これに加え、よりスマートになった写真編集ツール、コンテンツ生成機能、および強化されたシステムレベルのサポートが含まれます。現在、アシスタントはより広範なアプリ内コマンドをサポートし、自然言語によるリクエストにより効果的に対応します。

セキュリティ強化とパフォーマンスの最適化

AI機能に加え、HarmonyOS 7は一般的な詐欺の手口からユーザーを保護するための新しい防御プラットフォームを導入しました。システムは、不審なQRコードの識別、潜在的な詐欺ウェブページの検知、アプリのなりすまし試行への警告、および海外からのスパム電話番号の認識機能を提供します。

また、AIベースの音声詐欺検知や通信の安全に焦点を当てた複数のツールも追加されました。パフォーマンスの向上も今回のアップデートの核心要素です。Huaweiによると、HarmonyOS 7は前世代よりも最大15%向上したパフォーマンスを提供しながら、長期的なシステム負荷の増大を効果的に抑制します。
