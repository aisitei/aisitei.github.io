OpenHarmony 7.0 Beta1 출시: 더욱 세밀해진 앱 제어, 강화된 카메라 전문 기능 및 Ark Web 커널의 Chromium 144 업그레이드

2026-06-12

OpenHarmony 7.0 Beta1 공개

오픈소스 기반의 OpenHarmony 7.0 첫 번째 테스트 버전(Beta1)이 Gitcode 플랫폼에 제출되었습니다.

공식 설명 문서에 따르면, 이번 버전은 애플리케이션 프레임워크, 인터페이스 상호작용, 창 관리, 웹 엔진, 오디오 및 비디오 처리 등 다양한 분야에서 기능 강화가 이루어졌습니다.

애플리케이션 개발 및 UI 개선

  • Ability 관련 기능 강화: Ability 종료 사유 파악, AbilityStage 시작 로딩 정보 확인, 알림 커스텀 벨소리 및 잠금 화면 알림 제어 등 더욱 세밀한 제어 기능을 지원합니다.
  • 인터페이스 상호작용 향상: 동적 레이아웃 컨테이너, Tabs 내 중첩 스크롤, 커스텀 컴포넌트의 전역 재사용 기능 등이 추가되었습니다.
  • 창 관리 능력 강화: 표준 플로팅 윈도우가 추가되어 유연한 창 관리 기능을 제공하며, 필요에 따라 창 페이지 콘텐츠를 파기할 수 있습니다.
  • 콘텐츠 임베딩 서비스(Content Embed): 앱 간 문서 상호 임베딩 및 협업 편집을 위한 프레임워크를 제공하며, 개발자가 클라이언트와 서버 측 인터페이스를 쉽게 구현할 수 있도록 지원합니다.

ArkWeb 엔진 강화

  • Chromium 커널 업그레이드: ArkWeb의 기반이 되는 Chromium 커널이 132 버전에서 144 버전으로 업데이트되었습니다.
  • 웹 페이지 제어 및 보안: User-Agent Client Hints 기능 지원, URL 화이트리스트 설정(허용된 URL만 로드/이동), 기본 우클릭 메뉴 활성화 여부 제어 등이 포함됩니다.
  • 다운로드 및 데이터 처리: 다운로드 완료 시 원본 URL 정보 제공, 참조 페이지 URL 확인 기능이 추가되었으며 웹 페이지 보안 구성 속성 설정을 위한 클래스가 도입되었습니다.

멀티미디어 및 카메라 성능

  • 오디오/비디오 처리 강화: HDR 효과 지원, 멀티 스크린 녹화, Cinepak 코덱 지원 등이 포함됩니다. 또한 H265 하드웨어 인코더에 CBRHQ(고품질 고정 비트레이드 모드)가 추가되었습니다.
  • MIDI 장치 지원: USB 또는 Bluetooth BLE를 통해 외부 MIDI 키보드, 전자 피아노, MIDI 컨트롤러 등과 연결하여 메시지 송수신 및 장치 열거, 핫플러그 감지 기능을 제공합니다.
  • 카메라 전문 기능 강화: 플래시, 광학 손떨림 보정(OIS), 노출, 수동 초점, ISO 감도, 리코(Ricoh) 렌즈 호출 및 설정 등 다양한 카메라 전문 기능이 추가되었습니다.
  • 비디오 품질 향상: 비디오를 위한 AIHDR 포맷 지원과 특정 MIME 유형의 보안 디코더 선택 기능을 통해 DRM 보호 콘텐츠 처리가 강화되었습니다.

시스템 성능 및 개발 도구

  • 가상 머체(VM) 관리: 모든 VM 스레드의 힙 메모리 정보 확인, 임계치 초과 시 콜백 알림 등 가상화 환경에서의 메모리 관리 기능이 강화되었습니다.
  • 파일 시스템 및 보안: 파일 mmap 기능을 통한 효율적인 읽음/쓰기 접근을 지원하며, 앱 샌드박스 내 파일을 알림용 커스텀 벨소리로 설정할 수 있습니다.
  • 디버깅 도구 개선: HiProfiler에 파일 캐시 모드가 도입되어 메모리 할당 정보 수집 성능이 향상되었으며, HiDebug를 통해 리소스 누수 추적 및 물리 메모리 사용량 확인 등이 가능해졌습니다.

총평

OpenHarmony 7.0 Beta1은 웹 엔진의 대규모 업데이트와 더불어 멀티미디어 처리, 카메라 전문 기능 등 전반적인 성능을 크게 강화했습니다. 특히 개발자들을 위한 디버깅 도구 및 시스템 관리 기능을 고도화하여 더욱 안정적이고 강력한 생태계를 구축하는 데 중점을 둔 것이 특징입니다.

版本发布概况

OpenHarmony 7.0 首个测试版（Beta1）已提交至 Gitcode 平台。该版本在应用程序框架、界面交互、窗口管理、网页引擎、音视频处理等多个核心维度进行了功能增强，旨在提供更精细的控制能力和更好的用户体验。

应用开发与交互优化

针对开发者提供的工具链和 UI 组件进行了大量改进：

  • Ability 与 AbilityStage： 支持获取应用退出原因、启动加载信息，并提供更多 C API 用于管理组件。
  • 界面交互： 引入动态布局容器（支持运行时切换算法）、Tabs 嵌套滚动能力以及自定义组件的全局复用。
  • 窗口管理： 新增标准悬浮窗功能，支持更灵活的窗口控制；支持按需销毁窗口页面内容。
  • 用户体验： 支持拖拽异步通知、软键盘状态保持、多行文本缩略模式优化等。

ArkWeb 引擎升级

ArkWeb 引擎在内核和安全性上有了显著提升：

  • 核心升级： 内核从 Chromium 132 版本升级至 144 版本。
  • 安全与控制： 支持 URL 白名单控制、默认右键菜单开关，并提供专门的 Web 安全配置选项。
  • 功能增强： 支持 User-Agent Client Hints 功能，并在下载任务中支持获取原始 URL 和引用页 URL。

多媒体与硬件能力

该版本大幅强化了音视频处理和底层硬件交互能力：

  • 视觉效果： 支持 HDR 效果、AIHDR 格式以及多种图像元数据（WebP, GIF, TIFF 等）的处理。
  • 编解码与录制： 支持 Cinepak 编解码、H265 高质量恒定码率（CBRHQ）模式，并支持多屏幕录制。
  • 音频与外设： 新增 OH_MIDI C API 支持通过 USB 或蓝牙连接 MIDI 设备；提供独立的音频会话策略。
  • 相机能力： 增加一系列专业能力，包括闪光灯、光学防抖、手动对焦及 ISO 感光度等。

系统底层与工具链

在文件系统、网络和开发者调试方面提供了更多支持：

  • 内容共享： 新增 Content Embed 服务，支持跨应用文档嵌入与协同编辑。
  • 文件处理： 支持文件 mmap 能力实现高效读写，并提供沙箱目录共享功能。
  • 网络与安全： 增强 TLS 证书链验证（支持至 1000 个）；新增企业重签名证书管理能力。
  • 调试工具： HiProfiler 提供文件缓存模式以提升性能；HiDebug 支持更全面的资源采集和物理内存信息获取。

总结

OpenHarmony 7.0 Beta1 版本在底层架构、ArkWeb 内核升级以及多媒体处理能力上进行了全面强化。它通过引入动态布局、增强的 C API 和更强大的硬件支持，为开发者提供了更丰富的工具链和更高的定制自由度。该版本是为后续正式版铺平道路的重要里程碑。

OpenHarmony 7.0 Beta1公開

オープンソースベースのOpenHarmony 7.0初のテストバージョン（Beta1）がGitcodeプラットフォームに公開されました。

公式説明文書によると、今回のバージョンではアプリケーションフレームワーク、インターフェース操作、ウィンドウ管理、Webエンジン、オーディオおよびビデオ処理など、多岐にわたる分野で機能強化が行われています。

アプリケーション開発およびUIの改善

  • Ability関連機能の強化：Abilityの終了理由の把握、AbilityStageの開始ロード情報の確認、通知のカスタム着音、ロック画面での通知制御など、より詳細な制御機能をサポートします。
  • インターフェース操作の向上：動的レイアウトコンテナ、Tabs内でのネストされたスクロール、カスタムコンポーネントのグローバル再利用機能などが追加されました。
  • ウィンドウ管理能力の強化：標準的なフローティングウィンドウが追加され、柔軟なウィンドウ管理が可能になり、必要に応じてウィンドウページのコンテンツを破棄できるようになります。
  • コンテンツ埋め込みサービス（Content Embed）：アプリ間でのドキュメント相互埋め込みおよび共同編集のためのフレームワークを提供し、開発者がクライアントとサーバー側のインターフェースを容易に実装できるようにサポートします。

ArkWebエンジンの強化

  • Chromiumカーネルのアップグレード：ArkWebの基盤となるChromiumカーネルがバージョン132から144へアップデートされました。
  • ウェブページの制御とセキュリティ：User-Agent Client Hints機能のサポート、URLホワイトリストの設定（許可されたURLのみをロード/移動）、デフォルトの右クリックメニューの有効化制御などが含まれます。
  • ダウンロードおよびデータ処理：ダウンロード完了時のオリジナルURL情報の提供、参照ページURLの確認機能が追加され、ウェブページのセキュリティ構成属性を設定するためのクラスが導入されました。

マルチメディアおよびカメラ性能

  • オー処理/ビデオ処理の強化：HDR効果のサポート、マルチスクリーン録画、Cinepakコーデックのサポートなどが含まれます。また、H265ハードウェアエンコーダーにCBRHQ（高品質固定ビットレートモード）が追加されました。
  • MIDIデバイスのサポート：USBまたはBluetooth BLEを介して外部MIDIキーボード、電子ピアノ、MIDIコントローラーなどと接続し、メッセージの送受信、デバイス列挙、ホットプラグ検出機能を提供します。
  • カメラ専門機能の強化：フラッシュ、光学式手ブレ補正（OIS）、露出、マニュアルフォーカス、ISO感度、Ricohレンズの呼び出しおよび設定など、多様なカメラ専門機能が追加されました。
  • ビデオ品質の向上：ビデオ向けのAIHDRフォーマットのサポートと、特定のMIMEタイプのセキュリティデコーダー選択機能により、DRM保護コンテンツの処理が強化されました。

システム性能および開発ツール

  • 仮想マシン（VM）管理：すべてのVMスレッドのヒープメモリ情報の確認、閾値超過時のコールバック通知など、仮想化環境におけるメモリ管理機能が強化されました。
  • ファイルシステムとセキュリティ：ファイルmmap機能による効率的な読み取り/書き込みアクセスをサポートし、アプリサンドボックス内のファイルを通知用カスタム着信音として設定できるようになります。
  • デバッグツールの改善：HiProfilerにファイルキャッシュモードが導入され、メモリ割り当て情報の収集性能が向上しました。また、HiDebugを通じてリソース漏れ（リーク）の追跡や物理メモリ使用量の確認などが可能になりました。

まとめ

OpenHarmony 7.0 Beta1は、Webエンジンの大規模なアップデートに加え、マルチメディア処理やカメラ機能など、総合的なパフォーマンスを大幅に強化しています。特に開発者向けのデバッグツールやシステム管理機能の高度化により、より安定した強力なエコシステムの構築を目指しているのが特徴です。

OpenHarmony 7.0 Beta1 Released

The first test version (Beta1) of the open-source OpenHarmony 7.0 has been submitted to the Gitcode platform.

According to official documentation, this version introduces significant improvements across various fields, including application frameworks, interface interactions, window management, web engines, and audio/video processing.

Application Development and UI Improvements

  • Enhanced Ability features: Supports more granular controls such as identifying reasons for Ability termination, checking loading information for AbilityStage, and controlling custom ringtones and lock screen notifications.
  • Improved interface interaction: Added dynamic layout containers, nested scrolling within Tabs, and the ability to globally reuse custom components.
  • Strengthened window management: Introduced standard floating windows to provide flexible management, including the ability to discard window page content as needed.
  • Content Embed service: Provides a framework for cross-app document embedding and collaborative editing, allowing developers to easily implement client-side and server-side interfaces.

ArkWeb Engine Enhancements

  • Chromium kernel upgrade: The ArkWeb underlying Chromium kernel has been updated from version 132 to version 144.
  • Web page control and security: Includes support for User-Agent Client Hints, URL whitelist settings (loading/navigating only allowed URLs), and controls for enabling or disabling default right-click menus.
  • Download and data processing: Added features such as providing original URL information upon download completion, verifying referrer page URLs, and introducing classes for configuring web page security properties.

Multimedia and Camera Performance

  • Enhanced audio/video processing: Includes HDR effect support, multi-screen recording, Cinepak codec support, and the addition of CBRHQ (Constant Bit Rate High Quality) mode to H265 hardware encoders.
  • MIDI device support: Provides message transmission/reception, device enumeration, and hotplug detection for external MIDI keyboards, electronic pianos, and MIDI controllers via USB or Bluetooth BLE.
  • Advanced camera features: Added professional camera functions such as flash, Optical Image Stabilization (OIS), exposure, manual focus, ISO sensitivity, and Ricoh lens calling and configuration.
  • Improved video quality: Enhanced DRM-protected content processing through support for AIHDR formats for video and the ability to select specific MIME type security decoders.

System Performance and Development Tools

  • Virtual Machine (VM) management: Improved memory management in virtualized environments, including checking heap memory information for all VM threads and receiving callback notifications when thresholds are exceeded.
  • File system and security: Supports efficient read/write access through the file mmap function and allows files within an app sandbox to be set as custom ringtones.
  • Improved debugging tools: Introduced a file cache mode in HiProfiler to improve memory allocation information collection performance, and enabled resource leak tracking and physical memory usage monitoring via HiDebug.

Summary

OpenHarmony 7.0 Beta1 introduces significant upgrades to the ArkWeb engine, multimedia processing, and professional camera features. The update focuses on enhancing system stability and developer experience by refining debugging tools and core system management capabilities.
