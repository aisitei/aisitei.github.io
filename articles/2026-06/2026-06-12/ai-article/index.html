Xiaomi, MiMo Code V0.1.0 오픈소스 공개

Xiaomi가 새로운 터미널 기반 AI 코딩 어시스턴트인 MiMo Code V0.1.0을 오픈소스로 공개했습니다. 이 도구는 AI 기반 프로그래밍 도구의 가장 큰 문제점 중 하나인, 작업 시간이 길어질수록 이전 내용을 잊어버리는 문제를 해결하고자 합니다.

Xiaomi는 MiMo-7B를 2025년에 발표한 최초의 오픈소스 추론 및 코딩 모델로 선보였습니다. MiMo Code는 이 기반 위에 구축되었지만, 단순한 모델이 아니라 터미널에서 장기 소프트웨어 프로젝트를 직접 지원하도록 설계된 완전한 코딩 에이전트입니다.

이 도구는 오픈소스 OpenCode 프로젝트를 기반으로 하며 MIT 라이선스 하에 배포되어 개발자들이 자유롭게 사용, 수정 및 구축할 수 있습니다. 기본적으로 Xiaomi의 최신 멀티모달 AI 모델인 MiMo-V2.5에 무료로 액세스할 수 있으며, 사용자는 DeepSeek, Kimi, GLM과 같은 타사 서비스에 연결하여 다른 백엔드를 사용할 수도 있습니다.

AI의 기억력 문제 해결

MiMo Code의 주요 기능 중 하나는 영구적인 메모리 시스템입니다. 대부분의 AI 코딩 어시스턴트는 모델의 컨텍스트 창에 전적으로 의존하며, 이 창이 가득 차면 이전 결정이나 대화를 잊어버리기 시작합니다.

반면 MiMo Code는 작업하는 동안 컨텍스트를 지속적으로 관리하고 저장하는 전용 백그라운드 서브 에이전트를 가지고 있습니다. 활성 대화가 한계에 가까워지면 서브 에이전트가 자동으로 모든 것을 구조화된 요약으로 압축하여 메인 에이전트가 중단 없이 계속 진행할 수 있도록 합니다.

Xiaomi는 또한 7일마다 자동으로 실행되는 /dream 기능을 포함했습니다. 이 기능은 별도의 유지보수 에이전트를 실행하여 오래된 세션과 메모리 파일을 검토하고, 중복을 제거하고, 파일 경로를 확인하며, 모든 것을 업데이트된 장기 메모리 저장소로 압축합니다.

Compose 모드와 MiMo Harness

MiMo Code는 MiMo 모델을 위해 특별히 구축된 전용 Harness 시스템도 도입합니다. 이 프레임워크는 AI를 일반적인 API 엔드포인트로 취급하기보다는 모델의 기본 기능을 보다 직접적으로 활용하도록 설계되었습니다.

이것은 Tab 키를 눌러 활성화되는 Compose 모드 기능과 함께 작동합니다. AI에게 한 번에 한 단계씩 완료하도록 요청하는 대신, 대략적인 아이디어나 목표를 제공하면 에이전트가 계획 및 설계부터 코딩, 테스트, 검토까지 전체 워크플로우를 처리하려고 시도합니다.

Xiaomi는 이러한 접근 방식이 "산업 등급의 완성품"을 생산할 수 있다고 말합니다. 이는 대담한 주장일 수 있지만, 회사는 이를 뒷받침하는 벤치마크 결과를 제시합니다. Xiaomi에 따르면, MiMo Code는 SWE-Bench Pro에서 62%, Terminal Bench 2에서 73%의 점수를 달성했으며, 동일한 기본 모델을 사용하면서 Claude Code보다 약 5%포인트 높은 성능을 보였습니다.

이 어시스턴트는 MiMo-V2.5-ASR로 구동되는 내장 음성 입력 기능도 제공합니다. 사용자는 키보드를 만지지 않고도 명령을 받아쓰거나, 오타를 수정하거나, "보내기" 및 "실행"과 같은 작업을 트리거할 수 있습니다.

시작하기

MiMo Code는 매우 간단하게 설정할 수 있습니다. macOS 및 Linux에서는 단일 터미널 명령으로 설치할 수 있으며, Windows 사용자는 npm을 통해 설치할 수 있습니다. 설치 후에는 터미널에 mimo를 입력하는 것만으로 도구를 실행할 수 있습니다.

초기 설정은 사용자에게 모델 구성을 자동으로 안내하며, Xiaomi는 무료 MiMo-V2.5 채널을 계정 생성이나 등록 절차 없이 사용할 수 있다고 말합니다.

총평

Xiaomi의 MiMo Code는 AI 코딩 어시스턴트의 고질적인 '기억력 상실' 문제를 해결하기 위해 영구 메모리 시스템과 /dream 기능을 도입했습니다. 또한, MiMo Harness와 Compose 모드를 통해 AI가 전체 개발 워크플로우를 효율적으로 처리하도록 지원하며, 벤치마크 결과로 그 성능을 입증했습니다. 터미널 기반의 오픈소스 도구로 개발자들에게 새로운 가능성을 제시할 것으로 기대됩니다.

Xiaomi의 MiMo Code는 AI 코딩 어시스턴트의 고질적인 '기억력 상실' 문제를 해결하기 위해 영구 메모리 시스템과 /dream 기능을 도입했습니다. 또한, MiMo Harness와 Compose 모드를 통해 AI가 전체 개발 워크플로우를 효율적으로 처리하도록 지원하며, 벤치마크 결과로 그 성능을 입증했습니다. 터미널 기반의 오픈소스 도구로 개발자들에게 새로운 가능성을 제시할 것으로 기대됩니다.

Xiaomi, MiMo Code V0.1.0 오픈소스 공개

Xiaomi가 새로운 터미널 기반 AI 코딩 어시스턴트인 MiMo Code V0.1.0을 오픈소스로 공개했습니다. 이 도구는 AI 기반 프로그래밍 도구의 가장 큰 문제점 중 하나인, 작업 시간이 길어질수록 이전 내용을 잊어버리는 문제를 해결하고자 합니다.

Xiaomi는 MiMo-7B를 2025년에 발표한 최초의 오픈소스 추론 및 코딩 모델로 선보였습니다. MiMo Code는 이 기반 위에 구축되었지만, 단순한 모델이 아니라 터미널에서 장기 소프트웨어 프로젝트를 직접 지원하도록 설계된 완전한 코딩 에이전트입니다.

이 도구는 오픈소스 OpenCode 프로젝트를 기반으로 하며 MIT 라이선스 하에 배포되어 개발자들이 자유롭게 사용, 수정 및 구축할 수 있습니다. 기본적으로 Xiaomi의 최신 멀티모달 AI 모델인 MiMo-V2.5에 무료로 액세스할 수 있으며, 사용자는 DeepSeek, Kimi, GLM과 같은 타사 서비스에 연결하여 다른 백엔드를 사용할 수도 있습니다.

AI의 기억력 문제 해결

MiMo Code의 주요 기능 중 하나는 영구적인 메모리 시스템입니다. 대부분의 AI 코딩 어시스턴트는 모델의 컨텍스트 창에 전적으로 의존하며, 이 창이 가득 차면 이전 결정이나 대화를 잊어버리기 시작합니다.

반면 MiMo Code는 작업하는 동안 컨텍스트를 지속적으로 관리하고 저장하는 전용 백그라운드 서브 에이전트를 가지고 있습니다. 활성 대화가 한계에 가까워지면 서브 에이전트가 자동으로 모든 것을 구조화된 요약으로 압축하여 메인 에이전트가 중단 없이 계속 진행할 수 있도록 합니다.

Xiaomi는 또한 7일마다 자동으로 실행되는 /dream 기능을 포함했습니다. 이 기능은 별도의 유지보수 에이전트를 실행하여 오래된 세션과 메모리 파일을 검토하고, 중복을 제거하고, 파일 경로를 확인하며, 모든 것을 업데이트된 장기 메모리 저장소로 압축합니다.

Compose 모드와 MiMo Harness

MiMo Code는 MiMo 모델을 위해 특별히 구축된 전용 Harness 시스템도 도입합니다. 이 프레임워크는 AI를 일반적인 API 엔드포인트로 취급하기보다는 모델의 기본 기능을 보다 직접적으로 활용하도록 설계되었습니다.

이것은 Tab 키를 눌러 활성화되는 Compose 모드 기능과 함께 작동합니다. AI에게 한 번에 한 단계씩 완료하도록 요청하는 대신, 대략적인 아이디어나 목표를 제공하면 에이전트가 계획 및 설계부터 코딩, 테스트, 검토까지 전체 워크플로우를 처리하려고 시도합니다.

Xiaomi는 이러한 접근 방식이 "산업 등급의 완성품"을 생산할 수 있다고 말합니다. 이는 대담한 주장일 수 있지만, 회사는 이를 뒷받침하는 벤치마크 결과를 제시합니다. Xiaomi에 따르면, MiMo Code는 SWE-Bench Pro에서 62%, Terminal Bench 2에서 73%의 점수를 달성했으며, 동일한 기본 모델을 사용하면서 Claude Code보다 약 5%포인트 높은 성능을 보였습니다.

이 어시스턴트는 MiMo-V2.5-ASR로 구동되는 내장 음성 입력 기능도 제공합니다. 사용자는 키보드를 만지지 않고도 명령을 받아쓰거나, 오타를 수정하거나, "보내기" 및 "실행"과 같은 작업을 트리거할 수 있습니다.

시작하기

MiMo Code는 매우 간단하게 설정할 수 있습니다. macOS 및 Linux에서는 단일 터미널 명령으로 설치할 수 있으며, Windows 사용자는 npm을 통해 설치할 수 있습니다. 설치 후에는 터미널에 mimo를 입력하는 것만으로 도구를 실행할 수 있습니다.

초기 설정은 사용자에게 모델 구성을 자동으로 안내하며, Xiaomi는 무료 MiMo-V2.5 채널을 계정 생성이나 등록 절차 없이 사용할 수 있다고 말합니다.
