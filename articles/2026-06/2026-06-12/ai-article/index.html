MiMo Code 공개 및 배경

Xiaomi가 새로운 터미널 기반 AI 코딩 어시스턴트인 MiMo Code V0.1.0을 오픈 소스로 공개했습니다. 이 도구는 AI 기반 프로그래밍 도구가 긴 작업 과정에서 문맥을 잃어버리는 고질적인 문제를 해결하기 위해 설계되었습니다.

MiMo Code는 2025년에 발표된 Xiaomi의 첫 오픈 소스 추론 및 코딩 모델인 MiMo-7B를 기반으로 구축되었습니다. 단순히 하나의 모델에 그치는 것이 아니라, 터미널에서 직접 장기 소프트웨어 프로젝트를 지원하도록 설계된 완전한 코딩 에이전트입니다.

오픈 소스 및 유연성

MiMo Code는 오픈 소스 OpenCode 프로젝트를 기반으로 하며 MIT 라이선스로 출시되어 개발자들이 자유롭게 사용, 수정 및 확장할 수 있습니다. 기본적으로 Xiaomi의 최신 멀티모달 AI 모델인 MiMo-V2.5에 대한 무료 접근을 제공하며, 사용자의 필요에 따라 다음과 같은 타사 서비스와 연결할 수 있습니다.

  • DeepSeek
  • Kimi
  • GLM

지속적인 메모리 시스템

MiMo Code의 핵심 기능 중 하나는 지속적인 메모리 시스템입니다. 대부분의 AI 코딩 어시스턴트는 모델의 컨텍스트 윈도우에 전적으로 의존하기 때문에, 한계치에 도달하면 이전 결정이나 대화 내용을 잊어버리기 시작합니다.

반면, MiMo Code는 백그라운드 서브 에이전트를 통해 작업 중인 문맥을 지속적으로 관리하고 저장합니다. 활성 대화가 제한에 가까워지면 서브 에이전트가 모든 내용을 구조화된 요약본으로 자동 압축하여 메인 에이전트가 흐름을 놓치지 않고 계속 진행할 수 있도록 돕습니다.

또한, 7일마다 자동으로 실행되는 /dream 기능이 포함되어 있습니다. 이 기능은 별도의 유지 관리 에이전트를 가동하여 오래된 세션과 메모리 파일을 검토하고, 중복 제거, 파일 경로 확인 및 장기 메모리 저장소 업데이트를 수행합니다.

Compose 모드와 MiMo Harness

MiMo Code는 MiMo 모델에 최적화된 전용 Harness 시스템을 도입했습니다. 이는 AI를 일반적인 API 엔드포인트로 취급하는 대신, 모델의 기반 능력을 보다 직접적으로 활용할 수 있도록 설계된 프레임워크입니다.

Tab 키로 활성화되는 Compose 모드는 한 번에 한 단계씩 진행하는 방식이 아니라, 사용자가 대략적인 아이디어나 목표를 제시하면 에이전트가 계획부터 디자인, 코딩, 테스트, 검토까지 전체 워크플로우를 처리하도록 합니다.

Xiaomi는 이러한 접근 방식을 통해 "산업 수준의 완성도"를 구현할 수 있다고 강조합니다. 실제 벤치마크 결과는 다음과 같습니다.

  • SWE-Bench Pro: 62% 달성
  • Terminal Bench 2: 73% 달성 (동일 기반 모델을 사용하는 Claude Code보다 약 5%포인트 우수)

음성 지원 및 시작하기

이 어시스턴트는 MiMo-V2.5-ASR를 활용한 내장 음성 입력 기능을 제공합니다. 사용자는 키보드 조작 없이도 명령을 입력하거나 오타를 수정하고, "전송" 또는 "실행"과 같은 동작을 트리거할 수 있습니다.

MiMo Code는 매우 간단하게 설정할 수 있으며, 환경에 따른 설치 방법은 다음과 같습니다.

  • macOS 및 Linux: 단일 터미널 명령어로 설치
  • Windows: npm을 통해 설치
  • 실행: 터미널에 mimoin 입력
  • 특이사항: MiMo-V2.5 채널은 별도의 계정 생성이나 등록 없이 무료로 사용 가능

총평

Release of MiMo Code and Background

Xiaomi has released MiMo Code V0.1.0, an open-source terminal-based AI coding assistant. This tool is specifically designed to address the common issue where AI-powered programming tools lose context during long, complex tasks.

MiMo Code is built upon MiMo-7B, Xiaomi's first open-source reasoning and coding model released in 2025. Rather than being just a standalone model, it functions as a complete coding agent designed to support long-term software projects directly within the terminal.

Open Source and Flexibility

Based on the open-source OpenCode project, MiMo Code is released under the MIT license, allowing developers to freely use, modify, and expand it. It provides default free access to Xiaomi's latest multimodal AI model, MiMo-V2.5, while also offering integration with various third-party services:

  • DeepSeek
  • Kimi
  • GLM

Persistent Memory System

One of the core features of MiMo Code is its persistent memory system. Most AI coding assistants rely entirely on the model's context window; once that limit is reached, they begin to forget previous decisions or conversation history.

In contrast, MiMo Code utilizes background sub-agents to continuously manage and store the ongoing context. When an active conversation approaches its limit, a sub-agent automatically compresses the content into structured summaries, allowing the main agent to maintain continuity without losing track of the workflow.

Additionally, it includes a "/dream" function that runs automatically every seven days. This feature activates a dedicated maintenance agent to review old sessions and memory files, performing tasks such as deduplication, verifying file paths, and updating the long-term memory repository.

Compose Mode and MiMo Harness

MiMo Code introduces a dedicated "Harness" system optimized for MiMo models. This framework is designed to leverage the model's underlying capabilities more directly rather than treating the AI as a standard API endpoint.

The Compose mode, activated by the Tab key, moves away from step-by-step execution. Instead, when a user provides a general idea or goal, the agent handles the entire workflow—from planning and design to coding, testing, and review.

Xiaomi emphasizes that this approach enables "industrial-grade" completion. The following benchmark results demonstrate its performance:

  • SWE-Bench Pro: 62%
  • Terminal Bench 2: 73% (outperforming Claude Code, which uses the same base model, by approximately 5 percentage points)

Voice Support and Getting Started

The assistant includes a built-in voice input feature powered by MiMo-V2.5-ASR. Users can enter commands, correct typos, or trigger actions like "send" or "execute" without using a keyboard.

MiMo Code is easy to set up, with installation methods varying by environment:

  • macOS and Linux: Install via a single terminal command
  • Windows: Install via npm
  • Execution: Type "mimoin" in the terminal
  • Note: The MiMo-V2.5 channel is available for free without the need for separate account creation or registration

Summary

Xiaomi has launched MiMo Code, an open-source terminal assistant that utilizes a persistent memory system and sub-agents to maintain context during long coding projects. It features a "Compose" mode for automated end-to-end workflows and outperforms competitors like Claude Code in specific benchmarks. The tool also supports voice input via MiMo-V2.5-ASR and offers flexible integration with various third-party models.

持久记忆系统

Compose 模式与 MiMo Harness

MiMo Code 引入了针对 MiMo 模型优化的专用 Harness 系统。该框架旨在更直接地利用模型的底层能力，而非仅仅将其视为通用的 API 端点。

通过 Tab 键激活的 Compose 模式并非采取逐步进行的模式，而是允许用户提供大致的创意或目标后，由代理处理从规划、设计、编码到测试、审查的整个工作流。

Xiaomi 强调这种方法可以实现“工业级完成度”。实际基准测试结果如下：

  • SWE-Bench Pro: 达到 62%
  • Terminal Bench 2: 达到 73%（比使用相同基础模型的 Claude Code 高出约 5 个百分点）

语音支持与入门指南

该助手提供利用 MiMo-V2.5-ASR 的内置语音输入功能。用户无需键盘操作即可输入命令、修正拼写错误或触发“发送”及“执行”等动作。

MiMo Code 的配置非常简单，不同环境的安装方法如下：

まとめ

Xiaomiは、コンテキストの維持能力を大幅に強化したオープンソースのコーディングエージェント「MiMo Code」を公開しました。独自のHarnessシステムと持続的なメモリシステムにより、長期プロジェクトでも一貫した支援を提供し、さらに音声入力やマルチモデル連携など、開発者の利便性を高める機能を備えています。

Release of MiMo Code and Background

Xiaomi has released MiMo Code V0.1.0, an open-source terminal-based AI coding assistant. This tool is specifically designed to address the common issue where AI-powered programming tools lose context during long development processes.

MiMo Code is built upon MiMo-7B, Xiaomi's first open-source reasoning and coding model released in 2025. Rather than serving as just a standalone model, it functions as a complete coding agent designed to support large-scale software projects directly within the terminal.

Open Source and Flexibility

Based on the OpenCode project, MiMo Code is released under the MIT license, allowing developers to freely use, modify, and expand the tool. It provides free access to Xiaomi's latest multimodal AI model, MiMo-V2.5, and can be integrated with various third-party services:

  • DeepSeek
  • Kimi
  • GLM

Persistent Memory System

One of the core features of MiMo Code is its persistent memory system. While most AI coding assistants rely entirely on the model's context window—causing them to forget previous decisions or conversation details once the limit is reached—MiMo Code utilizes background sub-agents to continuously manage and store the working context.

When an active conversation approaches the limit, a sub-agent automatically compresses all content into structured summaries, allowing the main agent to maintain continuity. Additionally, it includes a /dream feature that runs automatically every seven days. This function activates a dedicated maintenance agent to review old sessions and memory files, perform deduplication, verify file paths, and update long-term memory storage.

Compose Mode and MiMo Harness

MiMo Code introduces a dedicated "MiMo Harness" system optimized for the MiMo model. This framework is designed to leverage the model's underlying capabilities more directly rather than treating the AI as a standard API endpoint.

The Compose mode, activated by the Tab key, moves away from step-by-step execution. Instead, when a user provides a general idea or goal, the agent handles the entire workflow, including planning, design, coding, testing, and review. Xiaomi emphasizes that this approach achieves "industrial-grade" quality, as evidenced by the following benchmark results:

  • SWE-Bench Pro: 62%
  • Terminal Bench 2: 73% (outperforming Claude Code, which uses the same base model, by approximately 5 percentage points)

Voice Support and Getting Started

The assistant features built-in voice input capabilities utilizing MiMo-V2.5-ASR. This allows users to enter commands, correct typos, and trigger actions such as "send" or "execute" without manual keyboard input.

MiMo Code is easy to set up across different environments:

  • macOS and Linux: Install via a single terminal command
  • Windows: Install via npm
  • Execution: Enter mimoin in the terminal
  • Note: The MiMo-V2.5 channel is available for free without requiring separate account creation or registration

Summary

Xiaomi has launched MiMo Code, an open-source terminal assistant that utilizes a persistent memory system and sub-agents to maintain context during long coding tasks. It features a "Compose" mode for automated workflow handling and offers integrated voice support via MiMo-V2.5-ASR. The tool is released under the MIT license and provides high performance on industry benchmarks like SWE-Bench Pro.
