Xiaomi, MiMo Code V0.1.0 오픈소스 공개

Xiaomi가 새로운 터미널 기반 AI 코딩 어시스턴트인 MiMo Code V0.1.0을 오픈소스로 공개했습니다. 이 도구는 AI 기반 프로그래밍 도구의 가장 큰 문제점 중 하나인, 작업 시간이 길어질수록 이전 내용을 잊어버리는 문제를 해결하고자 합니다.

Xiaomi는 MiMo-7B를 2025년에 발표한 최초의 오픈소스 추론 및 코딩 모델로 선보였습니다. MiMo Code는 이 기반 위에 구축되었지만, 단순한 모델이 아니라 터미널에서 장기 소프트웨어 프로젝트를 직접 지원하도록 설계된 완전한 코딩 에이전트입니다.

이 도구는 오픈소스 OpenCode 프로젝트를 기반으로 하며 MIT 라이선스 하에 배포되어 개발자들이 자유롭게 사용, 수정 및 구축할 수 있습니다. 기본적으로 Xiaomi의 최신 멀티모달 AI 모델인 MiMo-V2.5에 무료로 액세스할 수 있으며, 사용자는 DeepSeek, Kimi, GLM과 같은 타사 서비스에 연결하여 다른 백엔드를 사용할 수도 있습니다.

AI의 기억력 문제 해결

MiMo Code의 주요 기능 중 하나는 영구적인 메모리 시스템입니다. 대부분의 AI 코딩 어시스턴트는 모델의 컨텍스트 창에 전적으로 의존하며, 이 창이 가득 차면 이전 결정이나 대화를 잊어버리기 시작합니다.

반면 MiMo Code는 작업하는 동안 컨텍스트를 지속적으로 관리하고 저장하는 전용 백그라운드 서브 에이전트를 가지고 있습니다. 활성 대화가 한계에 가까워지면 서브 에이전트가 자동으로 모든 것을 구조화된 요약으로 압축하여 메인 에이전트가 중단 없이 계속 진행할 수 있도록 합니다.

Xiaomi는 또한 7일마다 자동으로 실행되는 /dream 기능을 포함했습니다. 이 기능은 별도의 유지보수 에이전트를 실행하여 오래된 세션과 메모리 파일을 검토하고, 중복을 제거하고, 파일 경로를 확인하며, 모든 것을 업데이트된 장기 메모리 저장소로 압축합니다.

Compose 모드와 MiMo Harness

MiMo Code는 MiMo 모델을 위해 특별히 구축된 전용 Harness 시스템도 도입합니다. 이 프레임워크는 AI를 일반적인 API 엔드포인트로 취급하기보다는 모델의 기본 기능을 보다 직접적으로 활용하도록 설계되었습니다.

이것은 Tab 키를 눌러 활성화되는 Compose 모드 기능과 함께 작동합니다. AI에게 한 번에 한 단계씩 완료하도록 요청하는 대신, 대략적인 아이디어나 목표를 제공하면 에이전트가 계획 및 설계부터 코딩, 테스트, 검토까지 전체 워크플로우를 처리하려고 시도합니다.

Xiaomi는 이러한 접근 방식이 "산업 등급의 완성품"을 생산할 수 있다고 말합니다. 이는 대담한 주장일 수 있지만, 회사는 이를 뒷받침하는 벤치마크 결과를 제시합니다. Xiaomi에 따르면, MiMo Code는 SWE-Bench Pro에서 62%, Terminal Bench 2에서 73%의 점수를 달성했으며, 동일한 기본 모델을 사용하면서 Claude Code보다 약 5%포인트 높은 성능을 보였습니다.

이 어시스턴트는 MiMo-V2.5-ASR로 구동되는 내장 음성 입력 기능도 제공합니다. 사용자는 키보드를 만지지 않고도 명령을 받아쓰거나, 오타를 수정하거나, "보내기" 및 "실행"과 같은 작업을 트리거할 수 있습니다.

시작하기

MiMo Code는 매우 간단하게 설정할 수 있습니다. macOS 및 Linux에서는 단일 터미널 명령으로 설치할 수 있으며, Windows 사용자는 npm을 통해 설치할 수 있습니다. 설치 후에는 터미널에 mimo를 입력하는 것만으로 도구를 실행할 수 있습니다.

초기 설정은 사용자에게 모델 구성을 자동으로 안내하며, Xiaomi는 무료 MiMo-V2.5 채널을 계정 생성이나 등록 절차 없이 사용할 수 있다고 말합니다.

총평

Xiaomi의 MiMo Code는 AI 코딩 어시스턴트의 고질적인 '기억력 상실' 문제를 해결하기 위해 영구 메모리 시스템과 /dream 기능을 도입했습니다. 또한, MiMo Harness와 Compose 모드를 통해 AI가 전체 개발 워크플로우를 효율적으로 처리하도록 지원하며, 벤치마크 결과로 그 성능을 입증했습니다. 터미널 기반의 오픈소스 도구로 개발자들에게 새로운 가능성을 제시할 것으로 기대됩니다.

Xiaomi 发布 MiMo Code V0.1.0 开源项目

Xiaomi 推出了基于终端的 AI 编程助手 MiMo Code V0.1.0 并将其作为开源项目发布。该工具旨在解决 AI 编程工具中常见的一个核心问题：随着工作时间变长，模型往往会遗忘之前的上下文内容。

MiMo Code 构建在 Xiaomi 于 2025 年推出的首个开源推理及编程模型 MiMo-7B 之上。它并非一个简单的模型，而是一个旨在直接支持长期软件项目的完整编码代理（Agent）。

该工具基于开源项目 OpenCode 开发，并采用 MIT 许可证发布，允许开发者自由地使用、修改和构建。默认情况下，用户可以免费访问 Xiaomi 最新的多模态 AI 模型 MiMo-V2.5，同时也支持连接到 DeepSeek、Kimi 和 GLM 等第三方服务作为后端。

解决 AI 的记忆力问题

MiMo Code 的核心功能之一是持久记忆系统。大多数 AI 编程助手完全依赖模型的上下文窗口，一旦该窗口填满，就会开始遗忘之前的决策或对话内容。

相比之下，MiMo Code 拥有专门的后台子代理（Sub-agent）来持续管理并存储工作过程中的上下文。当活跃对话接近极限时，该子代理会自动将所有内容压缩为结构化的摘要，确保主代理能够无缝地继续后续任务。

此外，Xiaomi 还引入了每 7 天自动执行一次的 /dream 功能。此功能会启动一个独立的维护代理来检查过时的会话和记忆文件，剔除重复项、验证文件路径，并将所有内容压缩到更新后的长期记忆库中。

Compose 模式与 MiMo Harness

MiMo Code 还引入了专门为 MiMo 模型构建的专用 Harness 系统。该框架旨在更直接地利用模型的原生能力，而非仅仅将其视为通用的 API 端点。

这一系统与通过按下 Tab 键激活的 Compose 模式协同工作。用户无需要求 AI 一次只执行一个步骤，只需提供大致的想法或目标，代理就会尝试处理从规划、设计到编码、测试和审查的整个工作流。

Xiaomi 声称这种方法能够产出“工业级成品”。为了支持这一声明，公司提供了相关的基准测试结果：

  • SWE-Bench Pro: 62%
  • Terminal Bench 2: 73%（在采用相同基础模型的情况下，比 Claude Code 高约 5 个百分点）

该助手还提供由 MiMo-V2.5-ASR 驱动的内置语音输入功能。用户无需操作键盘即可进行语音指令录入、纠正拼写错误或触发“发送”和“执行”等操作。

快速上手

MiMo Code 的配置过程非常简单。安装方式如下：

  • macOS 及 Linux: 通过单条终端命令即可安装
  • Windows: 可通过 npm 进行安装

安装完成后，用户只需在终端输入 mimo 即可启动工具。初始设置过程中，系统会自动引导用户进行模型配置。Xiaomi 表示，用户无需创建账户或进行注册程序即可直接使用免费的 MiMo-V2.5 通道。

总结

Xiaomi 推出的 MiMo Code 通过持久记忆系统和 /dream 功能有效解决了 AI 编程中的“遗忘”问题。结合 MiMo Harness 和 Compose 模式，它能够高效处理完整的开发工作流并获得优异的基准测试成绩。作为一款基于终端的开源工具，MiMo Code 为开发者提供了一个强大且具备高度自动化能力的 AI 协作新选择。

Xiaomi、MiMo Code V0.1.0をオープンソースで公開

Xiaomiは、新しいターミナルベースのAIコーディングアシスタント「MiMo Code V0.1.0」をオープンソースとして公開しました。このツールは、AIを活用したプログラミングツールにおける大きな課題の一つである、作業時間が長くなるにつれて以前の文脈を忘れてしまうという問題を解決することを目的としています。

Xiaomiは、2025年に発表された初のオープンソース推論およびコーディングモデル「MiMo-7B」をベースに、MiMo Codeを構築しました。MiMo Codeは単なるモデルではなく、ターミナル上で長期的なソフトウェアプロジェクトを直接サポートするように設計された完全なコーディングエージェントです。

このツールはオープンソースのOpenCodeプロジェクトに基づいており、MITライセンスの下で配布されるため、開発者は自由に使用、修正、構築が可能です。デフォルトではXiaomiの最新マルチモーダルAIモデルであるMiMo-V2.5に無料でアクセスでき、ユーザーはDeepSeek、Kimi、GLMなどのサードパーティ製サービスに接続して他のバックエンドを使用することも可能です。

AIの記憶に関する問題の解決

MiMo Codeの主要な機能の一つは、永続的なメモリシステムです。ほとんどのAIコーディングアシスタントはモデルのコンテキストウィンドウに完全に依存しており、このウィンドウがいっぱいになると、以前の決定や会話を忘れ始めます。

一方、MiMo Codeは作業中にコンテキストを継続的に管理・保存する専用のバックグラウンドサブエージェントを備えています。アクティブな対話が制限に近づくと、サブエージェントが自動的にすべてを構造化された要約に圧縮し、メインエージェントが中断することなく継続できるようにします。

また、Xiaomiは7日ごとに自動実行される「/dream」機能も搭載しました。この機能は独立したメンテナンスエージェントを実行し、古いセッションやメモリファイルをレビューして重複を削除し、ファイルパスを確認し、すべてを更新された長期メモリストレージに圧縮します。

ComposeモードとMiMo Harness

MiMo Codeは、MiMoモデル向けに特別に構築された専用のHarnessシステムも導入しています。このフレームワークは、AIを一般的なAPIエンドポイントとして扱うのではなく、モデル本来の機能をより直接的に活用するように設計されています。

これは、Tabキーを押すことで有効になる「Composeモード」と連動します。ユーザーがAIに一歩ずつ指示を与える代わりに、大まかなアイデアや目標を提供すると、エージェントが計画と設計からコーディング、テスト、レビューに至るまでのワークフロー全体を処理しようと試みます。

Xiaomiはこのアプローチにより「産業レベルの完成品」を生成できると主張しており、それを裏付けるベンチマーク結果も提示しています。Xiaomiの発表によると、MiMo CodeはSWE-Bench Proで62%、Terminal Bench 2で73%を記録し、同じベースモデルを使用しているClaude Codeよりも約5ポイント高い性能を示しました。

さらに、このアシスタントはMiMo-V2.5-ASRによる内蔵音声入力機能も提供します。ユーザーはキーボードを操作することなく、コマンドの聞き取り、誤字の修正、「送信」や「実行」といったアクションのトリガーを行うことができます。

導入方法

MiMo Codeは非常に簡単にセットアップできます。macOSおよびLinuxでは単一のターミナルコマンドでインストールでき、Windowsユーザーはnpmを通じてインストールすることが可能です。インストール後は、ターミナルに「mimo」と入力するだけでツールを実行できます。

初期設定では、システムがユーザーにモデル構成を自動的に案内します。Xiaomiは、アカウント作成や登録手続きなしで無料のMiMo-V2.5チャネルを利用できると述べています。

まとめ

XiaomiのMiMo Codeは、永続的なメモリシステムと「/dream」機能を導入することで、AIコーディングアシスタント特有の記憶喪失問題を解決しようとしています。また、MiMo HarnessとComposeモードにより、AIが開発ワークフロー全体を効率的に処理することを支援し、ベンチマークでも高い性能を実証しています。ターミナルベースのオープンソースツールとして、開発者に新たな可能性を提供するものと期待されます。

Xiaomi Releases MiMo Code V0.1.0 Open Source

Xiaomi has released MiMo Code V0.1.0 as an open-source terminal-based AI coding assistant. This tool is designed to address one of the primary limitations of AI programming tools: the tendency for models to forget previous context as task duration increases.

MiMo Code is built upon MiMo-7B, which Xiaomi introduced in 2025 as its first open-source inference and coding model. Rather than being a simple standalone model, MiMo Code functions as a complete coding agent designed to support long-term software projects directly within the terminal.

Based on the open-source OpenCode project, it is distributed under the MIT license, allowing developers to freely use, modify, and build upon it. It provides free access to Xiaomi's latest multimodal AI model, MiMo-V2.5, while also supporting connections to third-party services such as DeepSeek, Kimi, and GLM.

Solving AI Memory Issues

A key feature of MiMo Code is its permanent memory system. Most AI coding assistants rely entirely on the model's context window; once this window reaches capacity, they begin to forget previous decisions or conversations.

In contrast, MiMo Code utilizes a dedicated background sub-agent that continuously manages and stores context during operation. When an active conversation nears its limit, the sub-agent automatically compresses the information into structured summaries, allowing the main agent to continue without interruption.

Xiaomi also included the /dream function, which runs automatically every seven days. This feature activates a maintenance agent that reviews old sessions and memory files, removes redundancies, verifies file paths, and compiles everything into an updated long-term memory repository.

Compose Mode and MiMo Harness

MiMo Code introduces a dedicated "Harness" system specifically built for MiMo models. This framework is designed to leverage the model's native capabilities more directly rather than treating the AI as a standard API endpoint.

This works in tandem with the Compose mode, which is activated by pressing the Tab key. Instead of requiring users to prompt the AI step-by-step, users can provide a general idea or goal, and the agent attempts to handle the entire workflow—from planning and design to coding, testing, and review.

Xiaomi claims this approach can produce "industrial-grade" results. To support this claim, the company provided several benchmark results:

  • SWE-Bench Pro: 62%
  • Terminal Bench 2: 73%
  • Outperformed Claude Code by approximately 5 percentage points while using the same base model.

The assistant also features a built-in voice input capability powered by MiMo-V2.5-ASR. Users can dictate commands, correct typos, or trigger actions such as "send" and "execute" without touching their keyboards.

Getting Started

MiMo Code is designed for easy setup. It can be installed via a single terminal command on macOS and Linux, while Windows users can install it through npm. Once installed, the tool can be launched by simply typing "mimo" in the terminal.

The initial configuration automatically guides the user through model configurations. Xiaomi notes that the free MiMo-V2.5 channel is available without requiring account creation or registration.

Summary

Xiaomi's MiMo Code addresses the "memory loss" issue in AI coding assistants by implementing a permanent memory system and an automated /dream maintenance feature. By utilizing the MiMo Harness and Compose mode, it enables agents to handle complex development workflows autonomously while achieving high performance on industry benchmarks.
