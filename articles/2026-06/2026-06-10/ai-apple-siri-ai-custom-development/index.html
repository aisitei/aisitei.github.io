Apple, 'Gemini 기반'이라는 추측에 응답: iOS 27 버전 Siri AI, AFM 자체 개발로 구축

2026-06-10

애플의 독자적인 모델 강조

IT홈에 따르면, 기술 매체 Appleinsider는 오늘(6월 9일) 게시물을 통해 2026년 글로벌 개발자 회의(WWDC) 기조연설 종료 후 진행된 인터뷰 내용을 보도했습니다. 해당 인터뷰에서 애플 경영진은 'Apple Foundation Models'가 단순히 "Gemini를 씌운 버전"이 아니며, 완전히 독자적으로 제어되는 모델임을 강조했습니다.

애플 측은 Apple Foundation Models가 Google Gemini 기술을 활용해 증류(Distillation) 및 학습 과정을 거치기는 하지만, 최종 제공되는 모델은 애플의 코드, 기술 및 데이터 체계로 구성된 완전한 자체 모델이며 Gemini의 "껍데기" 버전이 아니라고 밝혔습니다.

모델 라인업

Appleinsider의 보도에 따르면, 현재 Apple Foundation Models 체계는 다음과 같이 5가지 주요 모델로 구성됩니다.

  • AFM Core: 온디바이스(On-device) 기반의 기본 AI 로컬 작업 수행
  • AFM Core Advanced: 네이티브 멀티모달 기능 지원 및 희소 구조(Sparse Architecture) 채택으로 로컬에서 더욱 복잡한 AI 기능 구현
  • AFM Cloud: 기기 내에서 처리하기 어려운 고부하 요청 담당
  • AFM Cloud Image: 이미지 생성 및 편집에 특화
  • AFM Cloud Pro: 에이전트 도구 및 가장 무거운 부하의 작업에 최적화

기술 사양 및 인프라

애플은 모든 모델이 Apple Silicon에 최적화되어 있으며, 학습 과정에서 독점 데이터를 사용하고 Gemini 모델의 증류 기술을 활용해 성능을 최적화했다고 설명했습니다.

또한 애플은 사용자가 Apple Foundation Models를 호출할 때 Google 코드나 Gemini 에이전트에 노출되지 않으며, Google 검색에 직접 연결되지도 않는다는 점을 강조했습니다.

클라우드 모델의 경우, 특히 AFM Cloud Pro는 에이전트 도구 및 고부하 작업을 위해 도입되었으며, 인프라 측면에서는 Google 클라우드 서버와 NVIDIA GPU 자원을 활용하면서도 Private Cloud Compute 인증을 유지합니다.

총평

애플은 Gemini 기술의 도움을 받되, 최종 결과물은 애플만의 독자적인 데이터와 기술로 구축된 모델임을 명확히 했습니다. 특히 온디바이스와 클라우드 환경에 최적화된 5가지 모델 체계를 통해 사용자 경험과 보안(Private Cloud Compute)을 동시에 확보하려는 전략을 보여주고 있습니다.

Apple Foundation Models 的技术定位

在 2026 年全球开发者大会（WWDC）期间，Apple 高管明确表示 Apple Foundation Models 模型并非“Gemini 套壳”。虽然这些模型在训练过程中利用了 Google Gemini 技术进行蒸馏优化，但最终交付的产品是由 Apple 自有的代码、技术和数据体系构成的独立模型。用户在调用相关功能时，不会直接接触到 Google 代码或 Google Search。

核心产品线与规格

Apple Foundation Models 体系目前包含以下 5 个主要模型：

  • AFM Core：用于端侧基础 AI 操作的本地模型。
  • AFM Core Advanced：支持原生多模态能力，采用稀疏架构，可在本地承载更复杂的 AI 功能。
  • AFM Cloud：负责处理设备本地难以完成的高负载请求。
  • AFM Cloud Image：专门针对图像生成和编辑设计的云端模型。
  • AFM Cloud Pro：面向智能体工具和最重负载任务的云端模型。

硬件优化与基础设施

所有模型均针对 Apple Silicon 芯片进行了定制，并使用专有数据进行训练。在处理高强度任务时，AFM Cloud Pro 虽然采用了 Google 云服务器和 NVIDIA 图形处理器资源，但仍保持 Private Cloud Compute 认证，以确保数据的安全性。

总结

Apple 强调其 Foundation Models 是基于自有技术构建的独立体系而非简单的 Gemini 套壳。该系列涵盖了从端侧到云端的 5 个核心模型，并在利用外部硬件资源的同时，通过定制化开发和认证机制保障用户隐私与体验。

Appleの独自モデルを強調

ITホームの報道によると、技術メディアのAppleinsiderが本日（6月9日）公開した記事において、2026年の世界開発者会議（WWDC）の基調講演終了後に行われたインタビュー内容が報じられました。このインタビューの中で、Appleの経営陣は「Apple Foundation Models」が単に「Geminiをラップしたバージョン」ではなく、完全に独自の制御下にあるモデルであることを強調しました。

Apple側は、Apple Foundation ModelsがGoogle Geminiの技術を活用して蒸留（Distillation）および学習プロセスを経てはいるものの、最終的に提供されるモデルはAppleのコード、技術、およびデータ体系で構成された完全な自社モデルであり、Geminiの「外装」だけを借りたものではないと明かしました。

モデルラインナップ

Appleinsiderの報道によると、現在のApple Foundation Models体系は以下の5つの主要モデルで構成されています。

  • AFM Core: オンデバイス（On-device）ベースの基本的なAIローカルタスクを実行
  • AFM Core Advanced: ネイティブマルチモーダル機能をサポートし、希薄構造（Sparse Architecture）を採用することで、より複雑なAI機能をローカルで実現
  • AFM Cloud: デバイス内での処理が困難な高負荷のリクエストを担当
  • AFM Cloud Image: 画像生成および編集に特化
  • AFM Cloud Pro: エージェントツールおよび最も負荷の高いタスクに最適化

技術仕様とインフラ

Appleは、すべてのモデルがApple Siliconに最適化されており、学習過程において独自のデータを使用し、Geminiモデルの蒸留技術を活用することで性能を最適化したと説明しています。

さらにAppleは、ユーザーがApple Foundation Modelsを呼び出す際にGoogleのコードやGeminiのエージェントに露出することはなく、Google検索に直接接続されることもない点を強調しました。

クラウドモデルに関しては、特にAFM Cloud Proがエージェントツールや高負荷なタスクのために導入されており、インフラ面ではGoogleのクラウドサーバーやNVIDIAのGPUリソースを活用しながらも、Private Cloud Computeの認証を維持しています。

まとめ

AppleはGeminiの技術を学習プロセスに取り入れつつも、最終的な成果物は独自のデータと技術で構築されたモデルであることを明確にしました。オンデバイスとクラウドの両方に最適化された5つのモデル体系を通じて、ユーザー体験とセキュリティ（Private Cloud Compute）の両立を目指す戦略を示しています。

Apple Emphasizes Proprietary Models

According to IT Home, Appleinsider published a report on June 9th following an interview conducted after the 2026 Worldwide Developers Conference (WWDC). During the interview, Apple executives emphasized that "Apple Foundation Models" are not simply a "Gemini-wrapped version," but are fully independently controlled models.

Apple clarified that while the Apple Foundation Models undergo distillation and training processes utilizing Google Gemini technology, the final models provided to users consist of Apple's own code, technology, and data infrastructure. They are not merely a "shell" of Gemini.

Model Lineup

According to reports from Appleinsider, the current Apple Foundation Models framework consists of five primary models:

  • AFM Core: Performs basic AI tasks on-device.
  • AFM Core Advanced: Supports native multimodal capabilities and adopts a Sparse Architecture to implement more complex AI functions locally.
  • AFM Cloud: Handles high-load requests that are difficult to process within the device.
  • AFM Cloud Image: Specialized for image generation and editing.
  • AFM Cloud Pro: Optimized for agent tools and the most demanding workloads.

Technical Specifications and Infrastructure

Apple stated that all models are optimized for Apple Silicon and utilize proprietary data during training, employing Gemini distillation techniques to optimize performance.

Furthermore, Apple emphasized that when users call Apple Foundation Models, they are not exposed to Google code or Gemini agents, nor is there a direct connection to Google Search. For cloud-based models—specifically AFM Cloud Pro, which were introduced for agent tools and high-load tasks—the system utilizes Google Cloud servers and NVIDIA GPU resources while maintaining Private Cloud Compute certification.

Summary

Apple is developing its own proprietary Foundation Models that utilize Google's distillation techniques while remaining independent of Gemini's core infrastructure. The five-model lineup provides a balance between on-device performance and high-load cloud capabilities, all while maintaining strict privacy standards through Private Cloud Compute certification.
