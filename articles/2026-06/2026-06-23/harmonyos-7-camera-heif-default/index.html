Huawei HarmonyOS 7.0 개발자 Beta 1, 카메라 촬영 기본 포맷을 JPG에서 HEIF로 전환

2026-06-23

시스템 업데이트

HarmonyOS 7.0 (API26) Developer Beta 1 버전에서 HarmonyOS 기기의 카메라 촬영 기본 형식이 JPG에서 HEIF로 변경되었습니다.

HEIF 도입 배경

Huawei는 고화질 사진의 보급으로 파일 크기가 커짐에 따라, 사용자의 앨범과 클라우드 백업을 위한 효율적인 저장이 더욱 중요해졌다고 밝혔습니다. HEIF는 고효율 이미지 포맷으로, 주로 HEVC(H.265) 코딩을 활용하여 뛰어난 화질을 유지하면서도 파일 크기를 줄일 수 있습니다.

사용자 편의성

카메라 기본 형식이 HEIF로 전환됨에 따라, 동일한 양의 사진 기록 시 저장 공간이 빠르게 소모되는 것을 방지하며 장기적인 촬영, 백업 및 공유가 더욱 용이해집니다. 이는 기존 방식에서 고효율의 사진 저장 방식으로 업그레이드된 것으로 볼 수 있습니다.

개발자 가이드

HEIF 이미지는 앨범 선택, 콘텐츠 게시, 고객 서비스용 이미지 전송, 클라우드 백업, 이미지 편집 등 다양한 시나리오에서 활용됩니다. 원활한 사용자 경험을 위해 개발자는 앱 내 이미지 업로드 시 파일 확장자 검증 규칙을 조정해야 하며, Image Kit가 제공하는 인코딩 및 디코딩 기능을 통해 HEIF를 JPEG 또는 PNG로 변환하여 처리할 수도 있습니다.

총평

HarmonyOS 7.0 Developer Beta 1 버전부터 카메라 기본 형식이 고효율 포맷인 HEIF로 변경됩니다. 이를 통해 사용자는 화질을 유지하면서도 저장 공간을 절약할 수 있으며, 개발자는 서비스 연동 시 HEIF를 올바르게 처리하기 위한 기술적 대응이 필요합니다.

HarmonyOS 默认拍照格式更新

在 HarmonyOS 7.0 (API26) Developer Beta 1 版本中，Huawei 将设备的相机拍照默认格式从 JPG 切换为 HEIF。

HEIF 格式的技术优势

由于现代照片分辨率高、文件体积大，采用 HEIF 旨在提供更高效的存储方案：

  • 基于 HEVC (H.265) 编码。
  • 在保持良好画质的同时显著降低文件体积。
  • 优化相册空间占用，使云端备份和分享更加便捷。

对开发者与服务的建议

随着 HEIF 图片进入更多应用场景（如内容发布、客服传图等），开发者需注意以下技术适配：

  • 调整 App 在图片上传时的文件扩展名校验规则。
  • 可利用 Image Kit 提供的编解码能力，将 HEIF 转码为 JPEG 或 PNG 以确保兼容性。

总结

HarmonyOS 7.0 (API26) Developer Beta 1 将默认拍照格式改为 HEIF，旨在通过高效编码平衡画质与存储空间。开发者需相应调整 App 的文件校验规则，并可利用 Image Kit 进行必要的转码处理以确保服务链路的连续性。

システムアップデート

HarmonyOS 7.0 (API26) Developer Beta 1から、Huaweiデバイスのカメラ撮影におけるデフォルト形式がJPGからHEIFに変更されました。

HEIF導入の背景

Huaweiは、高画質化に伴うファイルサイズの増大により、ユーザーのアルバムやクラウドバックアップのための効率的なストレージ管理がより重要になっていると述べています。HEIFは高効率な画像フォーマットであり、主にHEVC（H.265）コーディングを活用することで、優れた画質を維持しながらファイルサイズを削減することが可能です。

ユーザーの利便性

カメラのデフォルト形式がHEIFに移行したことで、大量の写真を記録する際のストレージ消費を抑え、長期的な撮影、バックアップ、および共有がより容易になります。これは、従来の方式から高効率な写真保存方法へのアップグレードと捉えることができます。

開発者向けガイド

HEIF画像は、以下のような多様なシナリオで活用されます。

  • アルバムの選択
  • コンテンツの投稿
  • カスタマーサービス用画像の送信
  • クラウドバックアップ
  • 画像の編集

スムーズなユーザー体験を提供するため、開発者はアプリ内での画像アップロード時にファイル拡張子の検証ルールを調整する必要があります。また、Image Kitが提供するエンコードおよびデコード機能を通じて、HEIFをJPEGまたはPNGに変換して処理することも可能です。

まとめ

HarmonyOS 7.0 Developer Beta 1より、カメラの標準フォーマットが高効率なHEIFに変更されます。これによりユーザーは画質を維持したままストレージ容量を節約でき、開発者はサービス連携においてHEIFを適切に処理するための技術的な対応が必要となります。

System Update

With the release of HarmonyOS 7.0 (API26) Developer Beta 1, the default camera capture format for HarmonyOS devices has been changed from JPG to HEIF.

Introduction of HEIF

Huawei stated that as high-quality photography becomes more common, file sizes have increased, making efficient storage for user albums and cloud backups increasingly important. HEIF is a high-efficiency image format that utilizes HEVC (H.265) coding to reduce file sizes while maintaining superior image quality.

Enhanced User Experience

By switching the default camera format to HEIF, users can prevent rapid storage depletion when capturing large volumes of photos, making long-term shooting, backing up, and sharing more convenient. This transition is considered an upgrade to a high-efficiency photo storage method compared to traditional formats.

Developer Guidelines

HEIF images are utilized in various scenarios, including album selection, content publishing, transmitting images for customer service, cloud backups, and image editing. To ensure a seamless user experience, developers should adjust file extension validation rules when uploading images within apps. Additionally, they can utilize the encoding and decoding functions provided by Image Kit to convert HEIF files into JPEG or PNG formats as needed.

Summary

Starting with HarmonyOS 7.0 Developer Beta 1, Huawei has adopted HEIF as the default camera format to balance high image quality with storage efficiency for users. While this provides a better experience for managing and sharing photos, it requires developers to implement technical adjustments or use Image Kit tools to ensure proper handling of HEIF files in their applications.
