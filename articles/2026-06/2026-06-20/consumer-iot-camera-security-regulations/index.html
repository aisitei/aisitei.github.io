네트워크 보안 인증 마크 사양

네트워크 보안 인증 마크는 파란색 배경의 컬러 마크로, 가로 46.9mm, 세로 50mm 크기입니다. 마크는 비율에 따라 확대 또는 축소할 수 있으나, 문구와 QR 코드 등 정보가 명확하게 식별되어야 합니다.

소비자용 인터넷 연결 카메라의 네트워크 보안 인증 마크에는 다음 내용이 포함됩니다:

  • 제품 제조사명
  • 제품 사양 및 모델명
  • 네트워크 보안 능력 등급
  • 네트워크 보안 인증 유효기간

政策发布与产品定义

国家互联网信息办公室、工业和信息化部、公安部于6月19日发布了《实施网络安全标识的产品目录（第一批）》及《消费类网联摄像头网络安全标识实施规则》。

“消费类网联摄像头”定义为具备互联网联网功能、提供音视频信息采集和处理服务的独立摄像头，且不适用于公共安全领域。

网络安全标识规格

该标识采用蓝色背景，标准尺寸为46.9mm（长）× 50mm（宽），支持按比例缩放。标识包含以下核心内容：

  • 产品生产者名称
  • 产品规格型号
  • 网络安全能力等级
  • 网络安全标识有效期
  • 检测实验室名称
  • 依据的国家标准或技术文件编号
  • 扫码可获取报告、关键指标及符合性声明的备案信息码

能力等级与测试标准

消费类网联摄像头的网络安全能力分为三个级别，对应的标识如下：

  • 基础级：一星
  • 增强级：二星
  • 领先级：Samsung

产品需依据 TC260-PG-20265A 标准进行检测，涵盖物理与硬件安全、系统与软件安全、网络与通信安全、数据安全与个人信息保护等多个维度的单项要求。

展示位置要求

网络安全标识可标注在产品的明显部位、包装物、使用说明书，或在设备的开机启动画面、应用管理界面中。对于通过网络交易的产品，需在产品信息展示主页面醒目位置进行展示。

总结

相关部门发布了针对消费类网联摄像头的网络安全标识实施规则，明确了产品的定义、技术标准及三级能力划分（一星、二星、Samsung）。此举旨在通过规范化的标识和检测要求，提升家用智能摄像头在数据保护与系统安全方面的合规性。

New Network Security Certification Regulations Announced

On June 19, according to IT Home, China's Cyberspace Administration of China (CAC), the Ministry of Industry and Information Technology (MIIT), and the Ministry of Public Safety released the "Network Security Certification Product List (First Batch)" along with the accompanying "Implementation Rules for Network Security Certification of Consumer Internet-Connected Cameras."

Definition of Target Products

The document defines consumer internet-connected cameras as standalone cameras purchased and used by individuals or organizations that provide voice and video information collection and processing services and feature internet connectivity. These regulations do not apply to cameras used in the public safety sector.

Network Security Certification Mark Specifications

The network security certification mark is a color mark on a blue background, measuring 46.9mm in width and 50mm in height. While the mark can be scaled proportionally, information such as text and QR codes must remain clearly identifiable.

The following details are included in the network security certification mark for consumer internet-connected cameras:

  • Manufacturer name
  • Product specifications and model name
  • Network security capability level
  • Validity period of the network security certification
  • Name of the testing agency
  • Relevant national standard or technical document number
  • Registration information code (A QR code allows users to verify inspection reports, key indicators, manufacturer compliance declarations, etc.)

Security Levels and Testing Criteria

The network security capability of consumer internet-connected cameras is divided into three levels—Basic, Enhanced, and Leading—represented by one star, two stars, and three stars, respectively.

Consumer internet-connected cameras are tested according to TC260-PG-20265A "Network Security Standard Practice Guide — Network Security Certification Requirements for Consumer Internet-Connected Cameras." The assessment determines the network security capability level based on individual categories including physical and hardware security, system and software security, network and communication security, data security and privacy protection, and security assurance. All specific requirements within a given level must be met to obtain that corresponding certification.

Display Locations for Certification Marks

The network security certification mark can be displayed on prominent parts of the product, packaging, instruction manuals, or on device boot screens and app management interfaces. For online transactions, the mark must be displayed in a prominent location on the product information page.

Summary

Chinese authorities have introduced a mandatory network security certification system for consumer internet-connected cameras to enhance data protection and device security. The regulations establish three distinct levels of security (Basic, Enhanced, and Leading) and require specific information to be displayed on a standardized mark across physical products and online platforms. This initiative aims to ensure safety throughout the entire lifecycle of these devices, from manufacturing and distribution to end-user use.

  • Validity period of the network security certification
  • Name of the testing laboratory
  • Reference national standard or technical document numbers
  • Registration information code (A QR code allowing users to check inspection reports, key indicators, and manufacturer compliance declarations)

Capability Levels and Testing Standards

The network security capabilities of consumer internet-connected cameras are categorized into three levels: Basic (1 star), Enhanced (2 stars), and Leading (3 stars).

Devices are tested according to the "Network Security Standard Practice Guide — Network Security Certification Requirements for Consumer Internet-Connected Cameras" (TC260-PG-20265A). This process determines the security level based on several categories, including physical and hardware security, system and software security, network and communication security, data security and privacy protection, and security assurance. A device must satisfy all individual requirements within its respective category to obtain the corresponding certification level.

Display Locations for Certification Marks

The network security certification mark may be displayed on visible parts of the product, on packaging materials, in user manuals, or on the device's boot screen and management app interface. For online transactions, the mark must be prominently displayed on the product information page.

Summary

Chinese authorities have introduced a rigorous certification system for consumer internet-connected cameras to enhance data protection and hardware security. By mandating these certification marks across manufacturing, distribution, and end-user environments, the move aims to ensure higher safety standards within the market.
