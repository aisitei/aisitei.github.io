2026-06-20

새로운 네트워크 보안 인증 규정 발표

6월 19일, IT Home(IT_Home)에 따르면 중국 국가인터넷정보국, 공업정보화부, 공안부는 '네트워크 보안 인증 제품 목록(제1차)' 및 관련 시행 규칙인 '소비자용 인터넷 연결 카메라 네트워크 보안 인증 시행 규칙'을 발표했습니다.

대상 제품 정의

본 문서에서 정의하는 소비자용 인터넷 연결 카메라는 개인 또는 조직이 구매 및 사용하며, 음성 및 영상 정보 수집과 처리 서비스를 제공하고 인터넷 연결 기능이 있는 독립형 카메라를 의미합니다. 해당 규정은 공공 안전 분야의 카메라에는 적용되지 않습니다.

네트워크 보안 인증 마크 사양

네트워크 보안 인증 마크는 파란색 배경의 컬러 마크로, 가로 46.9mm, 세로 50mm 크기입니다. 마크는 비율에 따라 확대 또는 축소할 수 있으나, 문구와 QR 코드 등 정보가 명확하게 식별되어야 합니다.

소비자용 인터넷 연결 카메라의 네트워크 보안 인증 마크에는 다음 내용이 포함됩니다:

  • 제품 제조사명
  • 제품 사양 및 모델명
  • 네트워크 보안 능력 등급
  • 네트워크 보안 인증 유효기간
  • 검사 기관 명칭
  • 근거가 되는 국가 표준 또는 기술 문서 번호
  • 등록 정보 코드(QR 코드를 통해 검사 보고서, 핵심 지표, 제품 제조사 준수 선언 등의 정보를 확인할 수 있음)

보안 등급 및 테스트 기준

소비자용 인터넷 연결 카메리의 네트워크 보안 능력은 낮은 단계부터 높은 단계까지 기초(Basic), 강화(Enhanced), 선도(Leading)의 세 가지 수준으로 나뉘며, 각각 별 1개, 별 2개, Samsung으로 표시됩니다.

소비자용 인터넷 연결 카메라는 TC260-PG-20265A '네트워크 보안 표준 실무 가이드 — 네트워크 보안 인증 소비자용 인터넷 연결 카메라 보안 요구사항'에 따라 테스트를 거쳐 물리 및 하드웨어 보안, 시스템 및 소프트웨어 보안, 네트워크 및 통신 보안, 데이터 보안 및 개인정보 보호, 보안 보장 등 개별 항목의 네트워크 보안 능력 등급을 결정합니다. 동일 등급의 모든 단일 요구 사항을 충족해야 해당 네트워크 보안 능력 등급을 획득할 수 있습니다.

인증 마크 표시 위치

네트워크 보안 인증 마크는 제품의 눈에 띄는 부분, 포장재, 사용 설명서 또는 기기의 부팅 화면, 앱 관리 인터페이스 등에 표시될 수 있습니다. 온라인 거래 시에는 제품 정보 페이지의 주요 위치에 해당 네트워크 보안 인증 마크를 노출해야 합니다.

총평

중국 당국은 소비자용 인터넷 연결 카메라에 대한 엄격한 네트워크 보안 인증 체계를 도입하여 사용자 데이터 보호와 기기 보안을 강화하고자 합니다. 이번 조치는 제품의 제조부터 유통, 실제 사용 환경까지 전 과정에서 보안 인증 마크를 의무화함으로써 시장 내 안전성을 확보하는 데 목적이 있습니다.
