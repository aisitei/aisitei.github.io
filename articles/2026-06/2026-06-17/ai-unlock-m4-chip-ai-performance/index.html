Apple M4 칩의 AI 훈련 잠재력 해제

IT之家 6월 16일 소식에 따르면, Apple M4 등 칩에 탑재된 뉴럴 엔진은 원래 추론 용도로만 개방되어 개발자들이 사전 훈련된 AI 모델을 실행할 수는 있었지만, 새로운 모델을 직접 훈련하는 데는 사용할 수 없었습니다. 그러나 X 사용자 @0x0SojalSec는 M4의 소프트웨어 제한을 우회하고 M4 SoC를 리버스 엔지니어링했다고 주장했습니다.

전체 과정은 모든 데이터를 RAM에 저장하여 실행하므로 속도가 매우 빠르고 경험도 상당히 원활합니다.

@0x0SojalSec는 오늘 새벽 X에 GitHub 코드 저장소를 공유하여 "M4의 완전한 잠재력을 해제하는 방법"을 시연했습니다. Apple은 이러한 칩과 직접 통신할 수 있는 권한을 개방하지 않았기 때문에, 그는 Core ML, Metal 등 Apple 도구를 사용하지 않았고 GPU도 호출하지 않았습니다. 대신, M4와 통신하기 위해 "맞춤형 MIL(모델 중간 언어)"을 처음부터 개발했습니다.

M4의 관련 하드웨어 기능이 "잠겨" 있었기 때문에 전체 과정에서 몇 가지 우회적인 방법이 필요했습니다. 예를 들어, 훈련 프로세스가 멈춰서 재설정해야 계속할 수 있을 때, 맞춤형 MIL은 "exec()" 명령을 호출하여 프로세스를 다시 시작하고 훈련을 계속합니다. 이렇게 하면 프로그램이 현재 상태를 새로 고쳐 직접적인 충돌을 피하면서 학습을 계속할 수 있습니다.

@0x0SojalSec는 속도를 높이기 위해 M4 잠금 해제 과정에서 NAND 플래시 메모리에 "전혀 쓰지 않았다"고 밝혔습니다. NAND 플래시 메모리는 쓰기 속도가 느린 반면 RAM은 더 빠르기 때문에 전체 프로세스를 고속으로 유지할 수 있습니다. 소프트웨어 제한을 돌파한 후, iPad 또는 Mac의 M4는 15.8TFLOPS의 AI 처리 성능을 달성할 수 있으며, 이는 AI 모델 훈련 작업을 수행하기에 충분합니다.

주의할 점은, 현재 동일한 맞춤형 MIL이 최신 Apple Silicon에 사용될 수 있는지, 또는 exec()가 새로운 플랫폼에서 예상대로 작동할 수 있는지 확인할 수 없다는 것입니다.

총평

한 개발자가 Apple M4 칩의 소프트웨어 제한을 우회하여 AI 모델 훈련에 활용하는 데 성공했습니다. 그는 Apple의 공식 도구를 사용하지 않고 맞춤형 모델 중간 언어(MIL)를 개발하여 M4와 직접 통신했습니다. 이 방법을 통해 M4는 15.8TFLOPS의 AI 처리 성능을 발휘하며, 이는 AI 모델 훈련에 충분한 수준입니다.

核心硬件能力突破

  • Apple M4 芯片中的神经网络引擎（Neural Engine）被成功破解，打破了原有的仅限推理使用的软件限制。
  • 在绕过限制后，M4 在 iPad 或 Mac 上可达到 15.8 TFLOPS 的 AI 处理性能，足以支持复杂的 AI 模型训练任务。

逆向工程与技术突破

  • X 用户 @0x0SojalSec 对 M4 SoC 完成了逆向工程，并在 GitHub 分享了相关代码库。
  • 该方案成功绕过了 Apple 未开放的直接通信权限，实现了对芯片完整潜力的释放。

定制开发工具链

  • 开发者并未使用 Core ML、Metal 等官方提供的工具或调用 GPU。
  • 而是从零开发了一套自定义 MIL（模型中间语言）来与 M4 进行直接通信。

性能优化策略

  • 为了追求极致速度，整个流程在处理数据时完全放在 RAM 中运行。
  • 通过避免写入较慢的 NAND 闪存，确保了训练过程的高速且流畅的体验。

系统稳定性保障

  • 针对训练进程可能出现的卡顿或崩溃问题，该方案采用了 "exec ()" 命令。
  • 当进程卡住时，调用该命令可让程序自动重置并继续学习，从而避免直接崩溃。

未来兼容性预警

目前尚无法确认这套自定义 MIL 是否能适配更新的 Apple Silicon 芯片，也无法确定 "exec ()" 命令在不同新平台上的运行效果。

总结

研究者通过逆向工程成功突破了 Apple M4 芯片神经网络引擎的限制，使其能够执行原本仅支持推理的 AI 模型训练任务。该方案利用自定义 MIL 和内存优化技术实现了高达 15.8 TFLOPS 的性能表现，但其在后续型号上的兼容性仍有待验证。

Apple M4チップのAI学習能力を解放

IT之家（IT Home）の6月16日の報道によると、Apple M4などのチップに搭載されているニューラルエンジンは、本来推論用として公開されており、開発者が事前学習済みのAIモデルを実行することは可能でしたが、新しいモデルを直接トレーニングする用途には使用できませんでした。しかし、Xユーザーの@0x0SojalSec氏は、M4のソフトウェア制限を回避し、M4 SoCをリバースエンジニアリングしたと主張しています。

このプロセスはすべてのデータをRAMに保存して実行するため、非常に高速でスムーズな動作を実現します。

@0x0SojalSec氏は本日未明のXにてGitHubのリポジトリを公開し、「M4の完全なポテンシャルを引き出す方法」を実証しました。Appleがチップとの直接通信権限を開放していないため、彼は以下のツールを使用せず、代わりに「カスタムMIL（モデル中間言語）」をゼロから開発しました。

  • Core ML
  • Metal
  • GPUの呼び出し

M4の関連ハードウェア機能が「ロック」されていたため、プロセス全体でいくつかの回避策が必要でした。例えば、トレーニングプロセスが停止し再設定が必要な際、カスタムMILは「exec()」コマンドを呼び出してプロセスを再起動し、学習を継続します。これにより、プログラムは現在の状態を更新しながら直接的な衝突（クラッシュ）を避けて学習を続行できます。

@0x0SojalSec氏は速度向上のため、M4のロック解除プロセスにおいてNANDフラッシュメモリを使用せず、より高速なRAMを活用することでプロセス全体を高速度で維持しています。ソフトウェア制限を突破した後の性能は以下の通りです。

  • AI処理性能：15.8 TFLOPS（iPadまたはMacのM4）

注意点として、現在このカスタムMILが他の最新Apple Siliconで動作するか、あるいはexec()が新しいプラットフォームで期待通りに機能するかは確認されていません。

まとめ

開発者が独自のカスタムMILを構築することで、Apple M4チップのソフトウェア制限を回避し、AIモデルのトレーニングに活用することに成功しました。この手法によりM4は15.8 TFLOPSの性能を発揮し、AIモデルの学習において十分な能力を備えることが確認されました。

Unlocking AI Training Potential on Apple M4 Chips

According to reports from IT Home on June 16, the Neural Engine integrated into chips like the Apple M4 was originally designed only for inference purposes. While this allowed developers to run pre-trained AI models, it did not permit the direct training of new models. However, X user @0x0SojalSec claims to have bypassed these software limitations through reverse engineering of the M4 SoC.

The process is reported to be very fast and smooth because all data is stored in RAM during execution.

Early this morning, @0x0SojalSec shared a GitHub repository on X demonstrating "how to unlock the full potential of the M4." Since Apple did not provide permissions for direct communication with these chips, the developer did not use standard tools such as Core ML or Metal, nor did they call the GPU. Instead, they developed a custom Model Intermediate Language (MIL) from scratch to communicate directly with the M4.

Because certain hardware features of the M4 were "locked," several workarounds were required during the process. For example, when a training process stalled and needed a reset to continue, the custom MIL invoked an "exec()" command to restart the process. This allows the program to refresh its current state and continue learning while avoiding direct crashes.

To maximize speed, @0x0SojalSec stated that they "did not use" NAND flash memory at all during the M4 unlocking process. Since RAM is significantly faster than NAND flash, this approach keeps the entire process running at high speeds. Once software limitations are bypassed, the M4 in iPads or Macs can achieve 15.8 TFLOPS of AI processing performance, which is sufficient for performing AI model training tasks.

It should be noted that it remains unconfirmed whether this specific custom MIL can be used on other modern Apple Silicon chips or if the "exec()" command will function as expected on different platforms.

Summary

A developer successfully bypassed software restrictions on the Apple M4 chip to enable its use for AI model training. By creating a custom Model Intermediate Language (MIL) and bypassing standard tools, the M4 can reach 15.8 TFLOPS of performance. This method allows the hardware to perform tasks that were previously restricted by Apple's default software limitations.
