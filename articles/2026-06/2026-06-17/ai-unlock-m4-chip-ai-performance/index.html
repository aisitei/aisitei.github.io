Apple 🤖 AI

개발자, Apple 소프트웨어 제한 우회하여 M4 칩의 15.8TFLOPS AI 연산 능력 성공적으로 해제

2026-06-17

기술적 돌파구

Apple M4 등 칩셋에 탑재된 뉴럴 엔진은 본래 추론(Inference) 용도로만 개방되어 있어, 개발자가 사전 학습된 AI 모델을 실행할 수는 있지만 새로운 모델을 직접 학습시키는 데는 제한이 있었습니다. 그러나 X 사용자 @0x0SojalSec가 M4의 소프트웨어 제한을 우회하고 M4 SoC에 대한 역공학(Reverse Engineering)을 성공했다고 밝혔습니다.

해당 과정에서 모든 데이터를 RAM 내에서 처리함으로써 매우 빠른 속도와 매끄러운 성능을 구현한 것으로 알려졌습니다.

구현 방식

@0x0SojalSec는 오늘 새벽 X를 통해 M4의 잠재력을 완전히 끌어낼 수 있는 방법을 담은 GitHub 저장소를 공유했습니다. Apple이 해당 칩과 직접 통신하는 권한을 제한했기 때문에, 그는 Core ML이나 Metal 같은 Apple 표준 도구를 사용하거나 GPU를 호출하는 대신, 처음부터 자체 제작한 MIL(모델 중간 언어)을 개발하여 M4와 통신하는 방식을 채택했습니다.

M4의 관련 하드웨어 기능이 '잠금' 상태였기 때문에 몇 가지 우회 기술이 동원되었습니다. 예를 들어 학습 프로세스가 멈춰 재시작이 필요한 경우, 커스텀 MIL이 "exec()" 명령을 호출하여 프로세스를 재시작하고 학습을 이어가도록 설계되었습니다. 이를 통해 프로그램은 현재 상태를 새로고침하며 충돌을 방지하고 지속적으로 학습을 진행할 수 있습니다.

성능 및 사양

@0x0SojalSec에 따르면 속도를 높이기 위해 M4 잠금 해제 과정에서 NAND 플래시 메모리에 데이터를 쓰는 작업을 완전히 배제했습니다. 쓰기 속도가 느린 NAND 대신 빠른 RAM을 활용함으로써 전체 프로세스를 고속으로 유지할 수 있었습니다.

소프트웨어 제한을 돌파한 후, iPad 또는 Mac에 탑재된 M4는 최대 15.8 TFLOPS의 AI 처리 성능을 발휘하며 AI 모델 학습 작업을 수행하기에 충분한 성능을 보여줍니다.

다만, 현재로서는 동일한 커스텀 MIL이 최신 Apple Silicon에서 작동할지, 혹은 "exec()" 명령이 다른 플랫폼에서 의도대로 작동할지는 확인되지 않았습니다.

총평

X 사용자가 M4 SoC의 역공학을 통해 소프트웨어 제한을 우회하고 뉴럴 엔진의 성능을 극대화하는 방법을 공개했습니다. 커스텀 MIL과 RAM 기반 처리 방식을 통해 M4가 AI 모델 학습에서도 강력한 성능(15.8 TFLOPS)을 발휘할 수 있음을 입증했으나, 다른 기기와의 호환성은 추가적인 검증이 필요합니다.

突破 M4 硬件限制

X 用户 @0x0SojalSec 通过逆向工程绕过了 Apple M4 芯片的软件限制。原本 M4 的神经网络引擎仅开放给推理使用，导致开发者无法直接用于训练新模型。通过该技术，开发者成功让 M4 SoC 支持了 AI 模型训练任务。

由于 Apple 未提供直接与芯片通信的权限，该方案并未采用 Core ML 或 Metal 等官方工具，而是从零开发了一套自定义 MIL（模型中间语言）来与 M4 进行通信。

性能优化与技术细节

为了确保训练过程的高效与流畅，该项目采用了以下技术手段：

  • 内存加速： 整个流程在 RAM 中运行而非写入 NAND 闪存，利用高速内存显著提升处理速度。
  • 高性能指标： 解锁限制后，M4 在 iPad 或 Mac 中可达到 15.8 TFLOPS 的 AI 处理性能。
  • 容错机制： 当训练进程卡住时，系统通过调用 "exec ()" 命令让进程重新启动并继续学习，从而避免程序崩溃。

总结

研究者通过自定义 MIL 绕过了 Apple M4 的软件限制，使其能够支持 AI 模型训练而非仅限于推理。该方案利用 RAM 加速和特定指令处理，使 M4 在 iPad 和 Mac 上达到 15.8 TFLOPS 的高性能表现。

技術的な突破口

Apple M4などのチップに搭載されているニューラルエンジンは、本来「推論（Inference）」の用途のみに開放されており、開発者が事前学習済みのAIモデルを実行することは可能ですが、新しいモデルを直接学習させることには制限がありました。しかし、Xユーザーの@0x0SojalSec氏がM4のソフトウェア制限を回避し、M4 SoCのリバースエンジニアリングに成功したことを明らかにしました。

この過程において、すべてのデータをRAM内で処理することで、非常に高速でスムーズなパフォーマンスを実現したと報じられています。

実装方法

@0x0SojalSec氏は本日未明、M4の潜在能力を完全に引き出すための手法を含むGitHubリポジトリをXで公開しました。Appleが当該チップとの直接通信権限を制限しているため、彼はCore MLやMetalといったApple標準ツールを使用したりGPUを呼び出したりする代わりに、独自に開発したMIL（モデル中間言語）を用いてM4と通信する手法を採用しました。

M4の関連ハードウェア機能が「ロック」状態であったため、いくつかの回避技術が動員されました。例えば、学習プロセスが停止して再起動が必要な場合、カスタムMILが「exec()」コマンドを呼び出してプロセスを再起動し、学習を継続できるように設計されています。これにより、プログラムは現在の状態をリフレッシュしてクラッシュを防ぎ、継続的に学習を進めることが可能になります。

性能および仕様

@0x0SojalSec氏によると、速度を向上させるためにM4のロック解除プロセスにおいて、NANDフラッシュメモリへのデータ書き込み作業を完全に排除しました。書き込み速度の遅いNANDの代わりに高速なRAMを活用することで、プロセス全体を高速度で維持することが可能となりました。

ソフトウェア制限を突破した後、iPadまたはMacに搭載されたM4は以下の性能を発揮し、AIモデルの学習作業を実行するのに十分な能力を示しています。

  • AI処理性能：最大15.8 TFLOPS

ただし、現時点では同じカスタムMILが最新のApple Siliconで動作するか、あるいは「exec()」コマンドが他のプラットフォームで意図通りに動作するかは確認されていません。

まとめ

XユーザーがM4 SoCのリバースエンジニアリングを通じてソフトウェア制限を回避し、ニューラルエンジンの性能を最大化する方法を公開しました。カスタムMILとRAMベースの処理を採用することで、M4がAIモデルの学習においても強力なパフォーマンス（15.8 TFLOPS）を発揮できることを実証しましたが、他のデバイスとの互換性についてはさらなる検証が必要です。

Technical Breakthrough

The Neural Engine in chipsets such as the Apple M4 was originally designed exclusively for inference, meaning that while developers could run pre-trained AI models, they faced significant limitations when attempting to train new models directly. However, X user @0x0SojalSec has announced the successful reverse engineering of the M4 SoC, effectively bypassing these software restrictions.

It is reported that this method achieves high speeds and smooth performance by processing all data within the RAM.

Implementation Method

Early this morning, @0x0SojalSec shared a GitHub repository containing methods to fully unlock the potential of the M4. Because Apple restricted direct communication with the chip, the developer opted not to use standard tools like Core ML or Metal, nor did they call the GPU; instead, they developed a custom MIL (Model Intermediate Language) to communicate directly with the M4.

Since certain hardware features of the M4 were in a "locked" state, several bypass techniques were employed. For example, if a training process stops and requires a restart, the custom MIL is designed to call an "exec()" command to restart the process and continue training. This allows the program to refresh its current state, preventing crashes and ensuring continuous learning.

Performance and Specifications

According to @0x0SojalSec, the process of unlocking the M4 completely excluded writing data to NAND flash memory to maximize speed. By utilizing fast RAM instead of slower NAND, the entire process is maintained at high speeds.

  • AI processing performance: Up to 15.8 TFLOPS on M4-powered iPads or Macs after bypassing software limits.

At this time, it has not been confirmed whether this specific custom MIL will function on other recent Apple Silicon chips or if the "exec()" command will behave as intended on different platforms.

Summary

An X user revealed a method to bypass software limitations and maximize the Neural Engine's performance on the M4 SoC through reverse engineering. By utilizing a custom MIL and RAM-based processing, the system can achieve up to 15.8 TFLOPS for AI model training, though its compatibility with other Apple Silicon devices remains unverified.
