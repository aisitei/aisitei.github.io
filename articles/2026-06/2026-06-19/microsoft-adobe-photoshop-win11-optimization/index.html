마이크로소프트와 Adobe 협력으로 Win11 버전 포토샵 최적화, x64 플랫폼에서 성능 20% 향상

2026-06-19

협력 및 성능 개선

Microsoft는 6월 16일 발표를 통해 Adobe와 협력하여 MSVC 및 SPGO 기술 조합을 통해 Windows 11 시스템에서 Photoshop의 성능과 응답 속도를 향상시켰다고 발표했습니다. 이를 통해 x64 플랫폼에서는 성능이 20%, ARM64 플랫폼에서는 13% 향상되었습니다.

기술적 배경

MSVC(Microsoft Visual C++)는 Microsoft가 개발한 C++ 컴파일러 제품군으로, Windows 플랫폼에서 네이티브 애플리케이션을 구축하는 데 사용되는 주요 도구입니다.

SPGO(Sample-based Profile-Guided Optimization)는 프로그램 실행 중에 수집된 샘플 데이터를 분석하여 코드 최적화를 안내하는 컴파일러 최적화 기술입니다.

최적화 방식

양사 팀은 Photoshop과 같은 이미지 처리 프로세스가 주로 GPU에 의존하지만, 브러시 드로잉이나 파일 열기 등 사용자가 가장 민감하게 느끼는 상호작용 작업은 여전히 CPU 성능에 의존한다고 밝혔습니다.

양사 팀은 MSVC 피크 성능 컴파일 모델을 사용하여 /GL 플래그를 활성화함으로써 컴파일러의 전역 최적화와 LTCG를 활성화했습니다. LTCG는 컴파일러가 서로 다른 소스 파일(번역 단위)을 가로질러 전역 최적화를 수행할 수 있게 하는 기술로, 더 깊은 수준의 코드 인라이닝 및 데드 코드 제거 등의 최적화를 실현하며 이는 결과적으로 더욱 정교한 성능 향상을 가져옵니다.

사용자 경험 개선

Adobe의 시니어 소프트웨어 개발자 John Fitzgerald는 다음과 같이 언급했습니다.

  • 사용자의 드로잉 및 스트로크 작업이 더욱 매끄러워짐
  • 파일 열기 시간 단축
  • 관련 필터 처리 속도 향상

이러한 개선 사항은 전문적인 크리에이티브 작업에서 가장 빈번하게 발생하며 지연 시간에 민감한 핵심 기능들입니다.

총평

Microsoft와 Adobe의 기술적 협력을 통해 Windows 11 환경에서 Photoshop 성능이 유의미하게 향상되었습니다. 특히 CPU 의존도가 높은 인터랙션 작업에서의 최적화를 통해 전문 크리에이터들에게 더욱 쾌적한 작업 환경을 제공할 것으로 기대됩니다.

合作背景与技术应用

Microsoft 与 Adobe 合作，通过 MSVC 和 SPGO 技术组合提升了 Windows 11 系统上 Photoshop 的性能和响应速度。MSVC 是用于构建原生应用的 C++ 编译器套件，而 SPGO 则是一种通过分析程序运行时样本数据来指导代码优化的技术。

核心优化技术

双方团队利用 MSVC 峰值性能编译模型并结合以下关键技术进行优化：

  • 启用 /GL 标志以实现全局优化。
  • 采用 LTCG（Link-Time Code Generation）技术，允许编译器跨越不同源文件进行更深层次的代码内联和死代码消除。

性能提升数据

通过上述技术的结合，Photoshop 在不同架构平台上的表现显著提升：

  • x64 平台：性能提升 20%
  • ARM64 平台：性能提升 13%

用户体验优化

Adobe 表示，这些改进针对专业创意工作中最敏感的延迟操作。具体优化包括：

  • 绘制和描边操作更加流畅。
  • 文件打开时间缩短。
  • 相关滤镜处理速度更快。

总结

Microsoft 与 Adobe 合作利用 MSVC 和 SPGO 技术显著提升了 Windows 11 上 Photoshop 的性能，其中 x64 平台提升 20%，ARM64 平台提升 13%。此次优化旨在通过更高效的编译技术，为专业用户提供更流畅的绘图、文件打开及滤镜处理体验。

提携とパフォーマンスの向上

Microsoftは6月16日の発表において、Adobeと協力し、MSVCおよびSPGO技術を組み合わせることでWindows 11システム上でのPhotoshopの性能と応答速度を向上させたと発表しました。これにより、x64プラットフォームで20%、ARM64プラットフォームで13%のパフォーマンス向上が実現されました。

技術的背景

MSVC（Microsoft Visual C++）は、Microsoftが開発したC++コンパイラ製品群であり、Windowsプラットフォームでネイティブアプリケーションを構築するための主要なツールです。

SPGO（Sample-based Profile-Guided Optimization）は、プログラムの実行中に収集されたサンプルデータを分析してコードの最適化を導くコンパイラ最適化技術です。

最適化の手法

両社のチームは、Photoshopのような画像処理プロセスは主にGPUに依存するものの、ブラシ描画やファイルの展開など、ユーザーが最も敏感に感じるインタラクティブな操作は依然としてCPU性能に依存していると述べています。

両社チームはMSVCのピークパフォーマンスコンパイルモデルを使用し、/GLフラグを有効化することで、コンパイラーのグローバル最適化とLTCGを有効化しました。LTCGは、コンパイラーが異なるソースファイル（翻訳単位）を横断してグローバル最適化を実行できるようにする技術であり、より高度なインライン展開やデッドコードの削除などの最適化を実現し、結果としてより精緻なパフォーマンス向上をもたらします。

ユーザー体験の改善

Adobeのシニアソフトウェア開発者であるJohn Fitzgeraldは、次のように述べています。

  • 描画およびストローク作業のさらなるスムーズ化
  • ファイルを開く時間の短縮
  • 関連するフィルター処理速度の向上

これらの改善点はプロフェッショナルなクリエイティブ制作において頻繁に発生し、遅延に対して敏感なコア機能です。

総評

MicrosoftとAdobeの技術的な協力により、Windows 11環境におけるPhotoshopのパフォーマンスが有意に向上しました。特にCPUへの依存度が高いインタラクティブな作業において最適化が行われたことで、プロのクリエイターにとってより快適な作業環境が提供されることが期待されます。

まとめ

MicrosoftとAdobeの協力により、Windows 11上でのPhotoshopのパフォーマンスが大幅に向上しました。特にMSVCやSPGO技術を活用することで、描画やファイル操作といったCPU依存のインタラクティブな動作が最適化され、プロのクリエイター向けによりスムーズな作業環境が提供されます。

Collaboration and Performance Improvements

On June 16, Microsoft announced a collaboration with Adobe to enhance the performance and responsiveness of Photoshop on Windows 11 systems through a combination of MSVC and SPGO technologies. This optimization resulted in a 20% performance increase on x64 platforms and a 13% improvement on ARM64 platforms.

Technical Background

MSVC (Microsoft Visual C++) is Microsoft's suite of C++ compilers, serving as a primary tool for building native applications on Windows platforms.

SPGO (Sample-based Profile-Guided Optimization) is a compiler optimization technique that analyzes sample data collected during program execution to guide code optimization.

Optimization Methodology

The joint teams noted that while image processing tasks primarily rely on the GPU, user-sensitive interactions—such as brush drawing and opening files—still depend heavily on CPU performance.

By utilizing MSVC's peak performance compilation model and enabling the /GL flag, the team activated global optimization and LTCG (Link Time Code Generation). LTCG allows the compiler to perform global optimizations across different source files (translation units), enabling advanced optimizations such as deeper code inlining and dead code removal, which results in more sophisticated performance gains.

Enhanced User Experience

John Fitzgerald, a Senior Software Developer at Adobe, highlighted the following improvements:

  • Smoother drawing and stroke actions
  • Reduced file opening times
  • Faster processing of related filters

These improvements target core features that occur frequently in professional creative workflows where latency sensitivity is critical.

Overall Review

The technical collaboration between Microsoft and Adobe has significantly improved Photoshop performance within the Windows 11 environment. By optimizing CPU-dependent interaction tasks, the update provides a more seamless experience for professional creators who require high responsiveness during their workflow.

Summary

Microsoft and Adobe collaborated to optimize Photoshop on Windows 11 using MSVC and SPGO technologies, achieving significant performance gains on both x64 and ARM64 platforms. The updates specifically target CPU-dependent tasks like brush drawing and file opening to reduce latency for professional creators.
