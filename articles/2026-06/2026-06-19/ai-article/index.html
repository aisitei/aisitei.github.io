Xiaomi, 기억·인식·실행이 가능한 스마트홈 AI 오픈 소스 솔루션 'Xiaomi Miloco 2.0' 발표

2026-06-19

개요

IT소식에 따르면, Xiaomi는 오늘 미래를 겨냥한 '홈 스마트 AI 오픈소스 솔루션'인 Xiaomi Miloco 2.0을 공식 발표하고 공개했습니다.

이 솔루션은 자체 개발한 MiMo 대규모 언어 모델(LLM)을 기반으로 구축되었으며, Agent 형태의 OpenClaw를 통해 상호작용 방식, 제품 기능, 기억 시스템 등 다양한 측면에서 전면적인 업그레이드를 이루었습니다. Miloco 1.0과 비교해 Miloco 2.0은 스마트 홈의 미래 형태를 한 단계 더 깊이 탐색하며, '기억하고, 사람을 식별하며, 실행할 줄 아는' 능동형 지능(Proactive Intelligence)으로 나아가기 시작했습니다.

주요 기능 및 시나리오

Xiaomi가 공개한 소개 영상에 따르면, 남성 사용자가 평균적인 귀가 시간보다 늦게 도착할 경우 시스템이 '야근 중일 가능성'을 추론하고, XiaoAi 스피커가 자동으로 "오늘 고생 많으셨어요, 일찍 쉬세요"라는 음성을 출력하며 능동적인 배려를 제공합니다. 또한 새로운 MiHome 기기를 감지하면 자동으로 연결된 신규 시나리오를 추천하기도 합니다.

핵심 기능

공통 상식: 사전 설정된 규칙 없이 시스템 내장된 공통 상식을 기반으로 위험 요소를 자동 인식하고 단계별 경고를 제공합니다 (예: 아이가 날카로운 도구를 만지거나 노인이 넘어지는 경우).

신원 식별: 얼굴, 체형 등 신원 정보를 통합하여 대규모 언어 모델을 통해 가족 구성원의 신원을 식별하며, 새로운 구성원의 자동 등록 및 신원에 기반한 개인화된 동작을 지원합니다.

홈 기억: 인식과 상호작용 과정에서 가족 구성원의 장기적인 습관과 선호도를 축적하여 Agent의 능동적 의사결정 시 참고 자료로 활용하며, 안정적인 습관은 자동 알림이나 자동 실행되는 홈 작업으로 업그레이드됩니다.

홈 작업: 단순한 '조건 트리거 규칙'에서 장기간 운영 가능한 복잡한 홈 작업으로 업그레이드되었습니다. 조건 자동화(입장 시 조음 켜짐), 정기 알림(매일 약 복용 알림), 습관 통계(매일 30분 운동) 등이 포함되며, 실행 시 Agent가 의도를 파악하고 자율적으로 수행합니다.

능동형 지능: 공통 상식, 신원 식별, 홈 기억, 홈 작업의 네 가지 능력을 기반으로 시스템이 마치 상식을 갖추고 가족을 잘 알며 계획할 줄 아는 집사처럼 상황을 관찰하고 판단하며 적시에 개입하여 사용자가 말하기 전에 필요한 일을 처리합니다.

시스템 및 하드웨어 사양

  • 홈 패널: 사용자용 Web 패널을 통해 실시간 홈 개요, MiHome 기기, 가족 구성원 및 기록, 과거 이벤트 로그를 확인할 수 있습니다.
  • 하드웨어: 권장 메모리 ≥ 4GB, 저장 공간 ≥ 256GB, 7x24 상시 가동 지원 (Mac mini 권장).
  • 운영체제: macOS / Linux (Windows는 WSL 환경에서 실행 가능).
  • 계정 및 기기: Xiaomi 계정 및 MiHome 연결 기기 필요.
  • 멀티모달 대규모 언어 모델 API Key: 인식용은 MiMo-v2.5, Agent용은 OpenClaw 내 설정 시 MiMo-v2.5-pro 사용 권장.

총평

Xiaomi Miloco 2.0은 단순한 자동화 시스템을 넘어 대규모 언어 모델과 Agent 기술을 결합하여 진정한 '능동형 스마트 홈'을 구현하려는 시도입니다. 특히 사용자의 습관을 학습하고 기억하는 기능을 통해 더욱 개인화되고 지능적인 홈 환경을 제공할 것으로 기대됩니다.

产品发布与核心理念

Xiaomi 正式发布并开源面向未来的“全屋智能 AI 开源方案” Xiaomi Miloco 2.0。该方案基于自研 MiMo 大模型构建，通过 Agent 形式接入 OpenClaw，旨在实现交互方式、产品功能及记忆系统的全面升级。相比于 1.0 版本，Miloco 2.0 更强调“能记忆、会识人、懂执行”的家庭主动智能能力。

核心功能特性

Miloco 2.0 通过以下五个维度构建智能化体验：

  • 通用常识：无需预设规则，基于系统内建常识自动识别并分级预警危险隐患（如孩童玩耍或老人跌倒）。
  • 身份识别：融合人脸、体态等信息，由大模型实现家庭成员的身份识别及个性化操作。
  • 家庭记忆：从交互中沉淀长期习惯与偏好，作为 Agent 主动决策时的参考依据。
  • 家庭任务：将单一的“条件触发规则”升级为可长期运转的复杂任务（如定时提醒、习惯统计等）。
  • 主动智能：整合上述能力，使系统具备类似管家般的观察、判断并适时干预的能力。

硬件与运行要求

用户部署该方案时需满足以下技术规格：

  • 硬件配置：建议内存 ≥ 4GB，存储 ≥ 256GB，支持 7×24 常驻运行（推荐使用 Mac mini）。
  • 操作系统：支持 macOS、Linux（Windows 用户请在 WSL 中运行）。
  • 必要组件：需具备 Xiaomi 账号及已接入米家的设备；需配备多模态大模型 API Key（推荐使用 MiMo-v2.5 或 MiMo-v2.5-pro）。

总结

Xiaomi 推出的 Miloco 2.0 是一个基于 MiMo 大模型的全屋智能 AI 开源方案。它通过强化记忆、身份识别和主动决策能力，旨在将传统的“条件触发”式智能家居升级为具备高度感知力与执行力的“管家式”主动智能系统。

共通の常識：事前設定されたルールなしに、システム内蔵の常識に基づいてリスク要因を自動認識し、段階的な警告を提供します（例：子供が鋭利な道具に触れたり、高齢者が転倒した場合など）。

身元識別：顔や体型などの身元情報を統合し、大規模言語モデルを通じて家族構成員の身元を識別。新しいメンバーの自動登録や、個人の属性に基づいたパーソナライズされた動作をサポートします。

ホームメモリ：認識やインタラクションの過程で、家族の長期的な習慣や好みを蓄積し、Agentの能動的な意思決定の判断材料として活用します。安定した習慣は、自動通知や自動実行されるホームタスクへとアップグレードされます。

ホームタスク：単純な「条件トリガールール」から、長期間運用可能な複雑なホームタスクへと進化しました。条件の自動化（入室時に照明を点灯）、定期的な通知（毎日の服薬リマインド）、習慣の統計（毎日30分の運動など）が含まれ、実行時にAgentが意図を把握し自律的に遂行します。

プロアクティブ・インテリジェンス：常識、身元識別、ホームメモリ、ホームタスクの4つの能力に基づき、システムがまるで常識を備え家族を熟知した執事のように状況を観察・判断し、ユーザーが話す前に必要なことを処理します。

Overview

According to IT news, Xiaomi has officially announced and released "Xiaomi Miloco 2.0," an open-source solution for future-oriented smart home AI.

Built upon the self-developed MiMo Large Language Model (LLM), this solution features a comprehensive upgrade in interaction methods, product functions, and memory systems through the Agent-based OpenClaw. Compared to Miloco 1.0, Miloco 2.0 explores the future of smart homes more deeply, moving toward "Proactive Intelligence" that can remember, identify individuals, and execute tasks independently.

Key Features and Scenarios

According to the introductory video released by Xiaomi, if a male user arrives home later than their average time, the system infers they may be working late. The XiaoAi speaker then automatically outputs a message: "You worked hard today; get some rest early," providing proactive care. Additionally, the system automatically recommends new scenarios when it detects newly connected MiHome devices.

Core Capabilities

Common Sense: Based on built-in common sense rather than pre-set rules, the system automatically identifies hazards and provides step-by-step warnings (e.g., a child touching sharp tools or an elderly person falling).

Identity Recognition: By integrating facial features and body shapes, the system identifies family members through the LLM. It also supports the automatic registration of new members and provides personalized actions based on individual identities.

Home Memory: The system accumulates long-term habits and preferences during interactions to serve as a reference for the Agent's proactive decision-making. Stable habits are automatically upgraded into notifications or self-executing home tasks.

Home Tasks: These have been upgraded from simple "condition-trigger rules" to complex, long-running home operations. This includes automated conditions (e.g., turning on lights upon entry), periodic reminders (e.g., daily medication alerts), and habit statistics (e.g., 30 minutes of daily exercise). The Agent identifies the user's intent and performs these tasks autonomously.

Proactive Intelligence: By combining common sense, identity recognition, home memory, and home tasks, the system acts like a butler who observes, judges, and intervenes at the right time—handling necessary tasks before the user even speaks.

System and Hardware Specifications

  • Home Panel: A web panel for users to view real-time home overviews, MiHome devices, family member records, and past event logs.
  • Hardware: Recommended memory ≥ 4GB, storage ≥ 256GB; supports 24/7 operation (Mac mini recommended).
  • Operating System: macOS / Linux (Windows is supported via a WSL environment).
  • Account and Devices: Requires a Xiaomi account and connected MiHome devices.
  • Multimodal LLM API Keys: MiMo-v2.5 for recognition; MiMo-v2.5-pro is recommended for Agent settings within OpenClaw.

Summary

Xiaomi Miloco 2.0 moves beyond simple automation by combining LLM and Agent technology to create a truly proactive smart home environment. By learning and remembering user habits, the system aims to provide a highly personalized experience where the home anticipates and fulfills needs automatically.
