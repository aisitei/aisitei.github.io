Huawei 🤖 AI

Huawei, 코드 작성·컴파일 및 빌드·기기 실행 등을 지원하는 DevEco Code Harmony 개발용 AI 에이전트 도구 출시

2026-06-14

신규 도구 발표

Huawei는 HDC 2026 기간 동안 HarmonyOS 개발 시나리오를 위한 AI Agent 도구인 DevEco Code를 공개했습니다. 이 도구는 코드 작성, 컴파일 및 빌드, 기기 실행, 문서 조회, 런타임 디버깅 및 ArkTS 문제 해결 등의 기능을 지원합니다.

기술적 특징

DevEco Code는 오픈 소스 프로젝트인 OpenCode를 기반으로 확장 개발되었으며, OpenCode의 터미널 상호작용, 구성 체계, Provider / MCP / Skill / Plugin 등의 기능을 유지합니다. 또한 HarmonyOS 프로젝트에 최적화된 DevEco Studio, Hvigor, HDC, Skill, HarmonyOS 지식베이스, ArkTS 체크 및 기기 디버깅 관련 통합 기능을 추가했습니다.

개발 시나리오

DevEco Code는 다음과 같은 주요 HarmonyOS 개발 도구 기능들을 통합하여 제공하며, 이를 통해 다양한 개발 환경을 지원합니다.

  • 신규 프로젝트 생성 (Zero to One)
  • 페이지 증분 개발
  • 빌드 오류 수정
  • 실제 기기 디버깅

총평

Huawei는 HarmonyOS 개발 생태계의 효율성을 높이기 위해 AI Agent 기반의 DevEco Code를 도입했습니다. 이 도구는 기존 오픈 소스 기술을 바탕으로 강력한 통합 기능을 제공하며, 개발자들이 코드 작성부터 디버깅까지의 전 과정을 더욱 원활하게 수행할 수 있도록 지원합니다.

产品发布与核心定位

Huawei 在 HDC 2026 期间推出了 DevEco Code。这是一款面向 HarmonyOS 开发场景的 AI Agent 工具，旨在为开发者提供全方位的辅助能力。

DevEco Code 支持的核心功能包括：

  • 代码编写
  • 编译构建
  • 设备运行
  • 文档查阅
  • 运行时调试
  • ArkTS 问题修复

技术架构与集成能力

DevEco Code 基于开源项目 OpenCode 进行扩展开发，保留了原有的终端交互、配置体系以及 Provider / MCP / Skill / Plugin 等核心能力。

针对 HarmonyOS 工程，该工具集成了以下相关组件：

  • DevEco Studio
  • Hvigor
  • HDC
  • Skill
  • HarmonyOS 知识库
  • ArkTS 检查
  • 设备调试

核心应用场景

该工具集成了常用的 HarmonyOS 开发能力，能够支持开发者处理以下常见任务：

  • 从零到一创建 HarmonyOS 工程
  • 增量开发页面
  • 修复编译报错
  • 真机调试

总结

Huawei 推出的 DevEco Code 是一个基于 OpenCode 扩展的 AI Agent 工具，旨在为 HarmonyOS 开发提供全流程支持。它通过集成多种核心工具和知识库，涵盖了从代码编写到真机调试的多个关键环节。

開発シナリオ

DevEco Codeは以下の主要なHarmonyOS開発ツール機能を統合して提供し、多様な開発環境をサポートします。

  • 新規プロジェクトの作成（Zero to One）
  • ページのインクリメンタル開発
  • ビルドエラーの修正
  • 実機デバッグ

まとめ

HuaweiはHarmonyOS開発エコシステムの効率化を目指し、AI AgentベースのDevEco Codeを導入しました。このツールはオープンソース技術を基盤としながら強力な統合機能を備えており、コード作成からデバッグに至るまでの全工程をより円滑に進めることを支援します。
