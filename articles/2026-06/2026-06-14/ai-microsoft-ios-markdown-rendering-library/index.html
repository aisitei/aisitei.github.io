마이크로소프트, AI 대규모 언어 모델(LLM) 채팅 시나리오에 최적화된 iOS 스트리밍 마크다운 렌더링 라이브러리 오픈소스 공개

2026-06-14

개요

Microsoft는 이번 주 수요일 GitHub를 통해 iOS 플랫폼용 SwiftStreamingMarkdown 렌더링 라이브러리를 오픈 소스로 공개했습니다. 이 라이브러리는 대규모 언어 모델(LLM) 채팅 인터페이스 등에서 마크다운(Markdown) 텍스트를 스트리밍 방식으로 렌더링할 때 발생하는 성능 병목 현상을 해결하기 위해 개발되었습니다.

해당 프로젝트는 MIT 라이선스를 채택하고 있으며, 개발자는 Swift Package Manager를 통해 애플리케이션에 직접 통합할 수 있습니다. 예상되는 추가 다운로드 용량은 약 3MB입니다. 이 라이브러리는 부드러운 스크롤과 글자 단위 애니메이션을 유지하면서도 메인 스레드의 과도한 부하를 방지하도록 설계되었습니다.

기술적 특징

기존의 마크다운 렌더링 방식과 달리, SwiftStreamingMarkdown은 스트리밍 텍스트 생성에 최적화되어 있습니다. AI가 답변을 생성하거나 대화 내용이 실시간으로 나타날 때, 기존 파서들은 문법 트리를 반복적으로 재구성해야 하므로 화면 끊김 현상이 발생하기 쉽습니다. 반면, 이 라이브러리는 텍스트가 도착하는 즉시 분석과 렌더링을 동시에 수행하며 내장된 전환 애니메이션과 부드러운 스크롤을 제공하여 채팅 인터페이스의 상호작용을 원활하게 유지합니다.

개발자는 StreamedMarkdownView 컴포넌트를 사용하여 점진적으로 데이터가 추가되는 비동기 데이터 소스를 연결함으로써 매끄러운 렌더링 경험을 얻을 수 있습니다. 정적 텍스트의 경우 MarkdownView 컴포넌트를 통해 일반적인 렌더링이 가능합니다.

지원 문법 및 기능

SwiftStreamingMarkdown은 CommonMark와 GitHub 스타일 마크다운(GFM)의 핵심 서브셋을 지원하며, 구체적으로 다음과 같은 요소들을 포함합니다:

  • 제목, 단락
  • 굵게, 기울임, 취소선
  • 인라인 코드, 링크
  • 울타리형 코드 블록, 인용 블록
  • 순서 및 무순위 목록
  • 구분선, 표
  • 인라인 및 블록 수준의 LaTeX 수식
  • LLM 출처 추적을 위한 인라인 참조 마크

지원되지 않는 일부 문법(예: 이미지는 대체 텍스트만 표시, 작업 목록 미구현 등)에 대해서는 원본 텍스트를 읽기 가능한 텍스트로 처리하여 콘텐츠 손실이나 렌더링 중단을 방지합니다.

또한 수학 공식 렌더링(LaTeX), 설정 가능한 타이포그래피 및 테마 시스템, iOS 컨텍스트 메뉴 등을 기본으로 지원하며, 분석 및 상호작용 추적을 위한 내장 훅(Hook)을 제공합니다. 개발자는 MarkdownRenderConfig 객체를 통해 전역 스타일을 통합 설정하고, MarkdownListener 프로토콜을 구현하여 렌더링 생명주기 이벤트와 사용자 상호작용을 수신할 수 있습니다.

성능 및 통합

Microsoft에 따르면 iPhone XS에서 진행한 성능 테스트 결과, 높은 부하의 스트리밍 콘텐츠가 지속적으로 전송되는 상황에서도 메인 스레드의 작업 부하가 다른 일반적인 라이브러리보다 효과적으로 제어되었으며 눈에 띄는 UI 끊김이 발생하지 않았습니다.

개발자는 Xcode에서 "File — Add Package Dependencies"를 통해 GitHub 저장소 주소를 입력하고 버전을 선택하여 통합하거나, Package.swift 파일에 의존성 항목을 추가할 수 있습니다. 또한 공식 GitHub 페이지에서는 SwiftUI 샘플 프로젝트를 제공하며, 이를 통해 스트리밍 데모, 설정 인터페이스 및 로그 리스너 구현 사례를 확인할 수 있습니다.

총평

Microsoft가 공개한 SwiftStreamingMarkdown은 특히 LLM 기반의 실시간 채팅 서비스에서 필수적인 스트리밍 마크다운 렌더링 성능을 최적화한 라이브러리입니다. 낮은 메인 스레드 부하와 풍부한 기능 지원을 통해 개발자가 사용자에게 끊김 없는 인터페이스를 제공하는 데 큰 도움을 줄 것으로 기대됩니다.
