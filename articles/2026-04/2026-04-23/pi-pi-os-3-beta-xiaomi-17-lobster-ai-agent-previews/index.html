Xiaomi miclaw: AI 에이전트 '미클로' 공개 및 주요 기능 분석

IT之家에 따르면, Xiaomi는 최신 운영체제인 Xiaomi澎湃 OS 3 Beta 버전을 통해 새로운 인공지능(AI) 에이전트 'Xiaomi miclaw'를 Xiaomi 17 시리즈와 Redmi K90 Pro Max 등 여러 기종으로 배포하고 있습니다.

Xiaomi의 공식 설명에 따르면, Xiaomi miclaw는 스마트폰을 AI 도구로 변모시키는 역할을 합니다. 사용자의 의도를 이해하고 권한을 부여받으면, 특정 앱이나 생태계 기능을 호출할 수 있을 뿐만 아니라 시스템 레벨의 도구를 자율적으로 선택하여 명령을 수행합니다.

이 에이전트는 사용자 개개인을 인식하고 기억하며, 모호하게 전달된 작업 요청도 스스로 판단하여 작업을 완료하는 능력을 갖추고 있습니다. 또한 지속적인 학습과 성장을 통해 행동 방식을 조정하고 기능을 확장하며, 경험을 메모리 시스템에 축적함으로써 사용할수록 사용자를 더 깊이 이해하게 됩니다.

주요 특징 및 기술 개요

Xiaomi miclaw는 Xiaomi MiMo 대형 모델(LLM)을 기반으로 구축된 AI 상호작용 테스트 제품입니다. 이 에이전트는 사용자 경험 향상에 초점을 맞춘 다양한 기능을 제공합니다.

  • 개인화 및 학습 능력 강화: 새로운 페르소나 시스템을 도입하여 뚜렷한 성격, 말투, 그리고 기억 능력을 갖추었으며, 사용자와의 상호작용을 통해 점진적으로 사용자에게 최적화됩니다.
  • 동적 기능 추가: 사용자가 에이전트와 대화하는 내용에 기반하여 자동으로 '스토리'나 '피드' 형태의 동적 콘텐츠를 생성해 제공합니다.
  • 지능형 스킬 시스템: 자기 개선, 사진 검색, 차량 호출 내비게이션 등 일상생활에서 자주 사용되는 고빈도 시나리오를 포괄하는 새로운 스킬 체계를 구축했으며, 이를 통합 관리할 수 있습니다.

시스템 연동 및 사용자 편의 기능

Xiaomi miclaw는 광범위한 시스템 도구와 외부 서비스를 연결하여 스마트폰 사용성을 극대화합니다.

  • 자동화된 일정 관리: 자연어 처리만으로 타이머를 설정할 수 있으며, 지정된 시간에 맞춰 실행하고 결과를 능동적으로 사용자에게 푸시합니다.
  • 광범위한 시스템 도구 지원: 캘린더, 메모, 사진첩, 시스템 설정 등 80가지 이상의 앱 기능을 통합하여 사용할 수 있습니다.
  • 외부 서비스 확장성: 제3자 MCP(Market Connector Platform)를 추가할 수 있어 더 많은 외부 서비스를 연결하고 활용 범위를 넓힐 수 있습니다.

전문 비서 및 크로스 디바이스 경험

사용자의 일상생활 전반을 지원하는 전문 어시스턴트 모듈과 기기 간의 끊김 없는 연동 기능이 핵심적으로 추가되었습니다.

  • 다양한 전문 비서:
    • 일정 비서: 한 문장으로 일정 관리, 경로 계획, 차량 비교 견적, 고속철도 및 항공편 정보 조회가 가능합니다.
    • 커뮤니케이션 비서: 사람 찾기, 전화 걸기, 메시지 전송, 연락처 정리, 문자 내용 요약 등 커뮤니케이션 작업을 지원합니다.
    • 오피스 비서: 메모 생성, 음성 녹음 텍스트 변환 및 회의록 정리, 파일 정리 등 업무 효율성을 높이는 기능을 제공합니다.
    • 이미지 비서: 의도 기반으로 사진을 검색하고 정리하며 관리할 수 있으며, 자연어를 통해 이미지 보정 작업까지 수행합니다.
    • Mi Home 비서: '생명감 있는 집'을 구현하도록 지원하며, 기기 제어, 고장 진단, 소모품 조회 및 자동화 시나리오 생성 기능을 포함합니다.
    • 전문 어시스턴트 스토어: 다양한 전문 비서를 추가하고 관리할 수 있으며, 제3자 'Wind 투자 비서'가 정식으로 출시되었습니다.
    • 맞춤형 에이전트 생성: 사용자가 직접 자연어를 이용해 피트니스 코치나 영어 회화 튜터 등 원하는 전용 어시스턴트를 만들 수 있습니다.
    • 크로스 디바이스 동기화: 사용자 선호도와 약속 사항을 휴대폰, 태블릿, 노트북 등 모든 기기에서 기억하며, 기기를 전환해도 반복 입력할 필요가 없습니다.
    • 파일 검색 및 전송: 동일 계정의 여러 기기 간에 한 문장으로 파일을 검색하고 전송할 수 있으며, 파일 열기, 저장, 위치 확인까지 지원합니다.

    총평

    Xiaomi miclaw는 단순한 음성 비서를 넘어 사용자의 의도를 파악하고 능동적으로 학습하며 다양한 시스템 도구와 외부 서비스를 통합하는 고도화된 AI 에이전트입니다. 특히 전문 어시스턴트 모듈과 크로스 디바이스 동기화 기능은 사용자에게 매우 높은 수준의 편의성을 제공합니다. 다만, 아직 초기 탐색 단계의 제품인 만큼 안정성 및 복잡한 시나리오에서의 실행 효율성은 지속적인 최적화가 필요해 보입니다.

产品发布与推送

Xiaomi HyperOS 3 Beta 版已向 Xiaomi 17 系列、REDMI K90 Pro Max 等机型推送“龙虾”智能体 Xiaomi miclaw。该产品基于 Xiaomi MiMo 大模型构建，旨在让手机成为能够理解用户意图、具备记忆能力并能调用系统级工具及第三方能力的 AI 工具。

核心功能与技术特性

作为前沿探索型产品，Xiaomi miclaw 在稳定性、功耗表现及复杂场景执行成功率方面仍在持续优化中。其主要更新内容包括：

  • 个性化体系： 具备鲜明的性格、语气与记忆能力，能够根据交互记录不断进化。
  • 动态功能： 根据用户对话内容自动发布动态。
  • 技能体系： 涵盖自我改进、照片搜索、打车导航等高频场景，并支持在技能中心统一管理。
  • 自然语言指令： 支持通过自然语言创建定时任务，并由系统按时执行并推送结果。
  • 广泛的工具集成： 支持调用 80+ 项系统工具（涵盖日历、笔记、相册、系统设置等）以及第三方 MCP 服务。

预设助手与跨设备协同

Xiaomi miclaw 提供多种针对特定场景的预设助手，并支持通过“助手商店”创建如健身教练、英语陪练等自定义角色：

  • 日程助手： 一句话完成行程管理、路线规划、打车比价及交通信息查询。
  • 沟通助手： 支持找人、拨号、发消息、整理联系人及总结短信内容。
  • 办公助手： 提供笔记生成、录音转写与纪要整理、文件整理等能力。
  • 影像助手： 支持按意图搜索、管理照片视频，并支持自然语言修图。
  • 米家助手： 提供设备控制、故障诊断、耗材查询及自动化创建。
  • 跨设备协同： 支持在手机、平板和笔记本电脑之间同步记忆；支持一句话完成跨设备的跨文件搜索与传输。

总结

Xiaomi 推出的“龙虾”智能体 Xiaomi miclaw 是基于 MiMo 大模型构建的 AI 交互工具，旨在通过更强的记忆能力、丰富的预设助手（如日程、办公、米家等）以及跨设备协同功能提升用户体验。该产品目前已在部分高端机型推送，是 Xiaomi 在智能化系统领域的一项前沿探索。

Xiaomi miclaw: AI Agent 'miclaw' Revealed and Key Features Analyzed

According to IT Home, Xiaomi is rolling out a new artificial intelligence (AI) agent called "Xiaomi miclaw" through its latest operating system, HyperOS 3 Beta. The feature is being deployed across various models, including the Xiaomi 17 series and Redmi K90 Pro Max.

According to Xiaomi's official description, Xiaomi miclaw transforms a smartphone into an AI tool. Once granted permission, it can understand user intent, call specific apps or ecosystem functions, and autonomously select system-level tools to execute commands.

This agent recognizes and remembers individual users and possesses the ability to interpret and complete even vaguely phrased requests. Through continuous learning and growth, it adjusts its behavior, expands its capabilities, and builds a memory system that allows it to understand the user more deeply over time.

Key Features and Technical Overview

Xiaomi miclaw is an AI interaction test product built on the Xiaomi MiMo large language model (LLM). It offers various features focused on enhancing the user experience.

  • Enhanced Personalization and Learning: It introduces a new persona system with distinct personality, tone of voice, and memory capabilities, optimizing itself for the user through ongoing interaction.
  • Dynamic Feature Addition: Based on conversations with the agent, it can automatically generate dynamic content in "story" or "feed" formats.
  • Intelligent Skill System: It features a new skill system covering high-frequency daily scenarios such as self-improvement, photo searching, and vehicle hailing navigation, which can be managed collectively.

System Integration and User Convenience

Xiaomi miclaw maximizes smartphone usability by connecting a wide range of system tools and external services.

  • Automated Schedule Management: Users can set timers using natural language processing, with the agent actively pushing notifications to the user at the designated time.
  • Broad System Tool Support: It integrates over 80 app functions, including calendar, notes, photo albums, and system settings.
  • External Service Scalability: It supports the addition of third-party MCP (Market Connector Platform) to connect and utilize a wider range of external services.

Specialized Assistants and Cross-Device Experience

The core updates include specialized assistant modules designed to support daily life and seamless cross-device synchronization.

  • Various Specialized Assistants:
    • Schedule Assistant: Manages schedules, plans routes, provides vehicle quotes, and retrieves information for high-speed rail and flights with a single sentence.
    • Communication Assistant: Supports finding people, making calls, sending messages, organizing contacts, and summarizing text content.
    • Office Assistant: Provides features to create notes, convert voice recordings to text, organize meeting minutes, and manage files.
    • Image Assistant: Searches, organizes, and manages photos based on intent, including image editing via natural language.
    • Mi Home Assistant: Supports the creation of a "lively home" through device control, fault diagnosis, consumable checks, and automated scenario generation.
  • Assistant Store: Users can add and manage various specialized assistants; for example, the third-party "Wind Investment Assistant" has been officially released.
  • Custom Agent Creation: Users can create dedicated assistants, such as a fitness coach or an English conversation tutor, using natural language.
  • Cross-Device Synchronization: The agent remembers user preferences and commitments across phones, tablets, and laptops, eliminating the need for repeated input when switching devices.
  • File Search and Transfer: Users can search for and transfer files across multiple devices under the same account with a single sentence, including support for opening, saving, and locating files.

Summary

Xiaomi miclaw is an advanced AI agent that goes beyond a simple voice assistant by understanding user intent, learning from interactions, and integrating various system tools and external services. Its specialized assistant modules and cross-device synchronization offer high levels of convenience, though it may require further optimization for complex scenarios as it is still in its early stages.
