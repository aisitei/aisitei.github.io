Huawei Pura X Max, 새로운 AI 비서 탑재로 '지능형 동반자' 역할 수행

IT之家에 따르면, Huawei 터미널 공식 채널은 오늘 업계 최초의 가로형 폴더블 스마트폰인 Huawei Pura X Max를 공개하며, 새로운 'XiaoYi Companion AI'를 탑재한다고 발표했습니다. 이 AI는 "당신이 생각하는 것을 이해하고, 당신이 필요로 하는 것을 충족시키며, 자연스럽게 함께하는 동반자" 역할을 목표로 합니다.

IT之家에 따르면, Huawei가 이전에 출시한 모델에는 해당 AI 서비스가 탑재되지 않았기 때문에, 새로운 XiaoYi Companion AI는 Huawei Pura X Max를 통해 최초로 선보여질 예정입니다. 공식 예고 영상에 따르면, 이 새로운 AI는 다음과 같은 기능을 지원합니다.

주요 기능

  • 스마트 할 일 관리 (Smart To-Do): 현재 앱 화면의 정보를 지능적으로 인식하여 할 일 목록이나 캘린더에 추가할 수 있으며, 화면을 능동적으로 인식하는 기능도 제공합니다.
  • 여행 비서 (Trip Assistant): 현재 앱 화면의 정보를 지능적으로 인식하여 경로 계획, 예상 소요 시간 확인, 항공편 정보 조회, 원터치 택시 호출 등의 기능을 제공합니다.
  • 전역 할 일 관리 (Global To-Do): 할 일 목록을 지능적으로 자동 기록하고 정리하며, 원클릭으로 구체적인 이벤트 내용, 시간, 장소 등의 정보를 확인할 수 있습니다.
  • 지능형 독서 지원 (Smart Reading): 사용자가 읽는 내용을 지능적으로 인식하여 즐겨찾기, 긴 글 요약, 핵심 정리, 마인드맵 생성 등의 기능을 제공합니다. 사용자가 선택한 텍스트 내용을 XiaoYi가 지능적으로 검색하고 관련 정보를 종합하여 보여줍니다.
  • 주제 추천 (Topic Recommendation): 사용자가 읽는 내용을 지능적으로 인식하여 관련 주제에 대한 토론 및 정보를 추천합니다.
  • 전역 XiaoYi 호출: 위에 언급된 모든 시나리오의 능동적인 AI 동반 기능 구역에는 XiaoYi 음성 버튼이 마련되어 있어, 사용자가 클릭하거나 길게 눌러 음성 명령을 내릴 수 있습니다.

기술 사양 및 사용 방법

새로운 XiaoYi Companion AI는 HarmonyOS 6.1 버전의 기능으로 예상됩니다. 공식 예고 영상의 주석에 따르면, 현재 이 기능은 일부 앱에만 적용되어 있으며, 사용하기 위해서는 추후 HOTA(Over-The-Air) 업데이트를 통해 지원받고, 반드시 네트워크에 연결된 상태여야 합니다. 또한, 사용 전 설정에서 기능을 활성화해야 하며, 이후에는 내비게이션 바(화면 하단의 작은 막대)를 두 번 탭하여 호출할 수 있습니다.

총평

Huawei Pura X Max에 탑재된 새로운 XiaoYi Companion AI는 단순한 음성 비서를 넘어, 사용자의 현재 상황과 맥락을 이해하는 '지능형 동반자'의 역할을 수행합니다. 스마트 할 일 관리, 여행 비서, 지능형 독서 지원 등 일상생활의 다양한 영역에 걸쳐 AI 기능을 통합함으로써, 폴더블 플래그십 스마트폰의 사용자 경험을 한 단계 끌어올린 것이 특징입니다.

产品发布与核心功能

Huawei 官方宣布，首款横向阔折叠手机 Huawei Pura X Max 将搭载全新的“小艺伴随式 AI”。该功能旨在提供“懂你所想，应你所需，默契相伴”的智能交互体验。作为新机首发功能，它涵盖了多个高频使用场景。

核心功能亮点

  • 智能待办： 能够识别当前 App 显示信息，支持一键加入待办或日历，并具备主动识别屏幕的功能。
  • 行程助手： 提供路线规划、预计耗时查询、航班信息获取及一键打车等服务。
  • 全局待办： 支持自动记录与整理待办事项，用户可一键查看具体的事件内容、时间及地点。
  • 智慧伴读： 包含长文导读、总结、生成脑图以及基于选中内容的智能查询汇总功能。
  • 话题推荐： 根据用户当前阅读的内容提供相关的热门话题讨论。

技术规格与交互要求

该“小艺伴随式 AI”预计属于 HarmonyOS 6.1 版本的功能。使用该功能需要满足以下条件：

  • 系统支持： 目前已适配部分应用，但仍需后续 HOTA 支持。
  • 网络与设置： 使用时需保持联网状态，并需在系统设置中手动开启。
  • 交互方式： 各功能区设有小艺语音按钮（支持点击或按住说话），用户也可通过双击导航条唤起相关功能。

总结

Huawei Pura X Max 将首发搭载“小艺伴随式 AI”，提供涵盖待办、行程、阅读等全场景的智能化辅助服务。该功能预计基于 HarmonyOS 6.1 构建，旨在通过更深度的系统融合与主动交互提升用户体验。

Huawei Pura X Max、新AIアシスタント搭載で「インテリジェントな相棒」へと進化

IT之家の報道によると、Huaweiの公式チャンネルは本日、業界初の横型折りたたみスマートフォンであるHuawei Pura X Maxを発表し、新たに「XiaoYi Companion AI」を搭載することを明らかにしました。このAIは、「ユーザーの思考を理解し、必要なものを満たし、自然に寄り添うパートナー」としての役割を目指しています。

IT之家によると、以前のモデルにはこのAIサービスが搭載されていなかったため、新しいXiaoYi Companion AIはHuawei Pura X Maxで初めて公開される予定です。公式の予告動画によると、この新しいAIは以下の機能をサポートしています。

主な機能

  • スマートToDo（Smart To-Do）： 現在のアプリ画面の情報をインテリジェントに認識し、ToDoリストやカレンダーに追加することが可能です。また、画面を能動的に認識する機能も提供されます。
  • 旅行アシスタント（Trip Assistant）： 現在のアプリ画面の情報をインテリジェントに認識し、ルート計画、予想所要時間の確認、フライト情報の照会、ワンタップでのタクシー配車などの機能を提供します。
  • グローバルToDo（Global To-Do）： ToDoリストをインテリジェントに自動記録・整理し、ワンクリックで具体的なイベント内容、時間、場所などの情報を確認できます。
  • スマート読書支援（Smart Reading）： ユーザーが読んでいる内容をインテリジェントに認識し、お気に入り登録、長文の要約、重要事項のまとめ、マインドマップの生成などの機能を提供します。ユーザーが選択したテキスト内容をXiaoYiがインテリジェントに検索し、関連情報をまとめて表示します。
  • トピック推奨（Topic Recommendation）： ユーザーが読んでいる内容をインテリジェントに認識し、関連するトピックに関する議論や情報を提案します。
  • グローバルXiaoYi呼び出し： 上記のすべてのシナリオにおける能動的なAIコンパニオン機能エリアには、XiaoYi音声ボタンが用意されており、ユーザーはクリックまたは長押しで音声コマンドを出すことができます。

技術仕様および使用方法

新しいXiaoYi Companion AIは、HarmonyOS 6.1の機能として提供される見込みです。公式予告動画の注釈によると、現在この機能は一部のアプリにのみ適用されており、使用するには今後HOTA（Over-The-Air）アップデートを通じてサポートを受ける必要があり、必ずネットワークに接続された状態である必要があります。また、使用前に設定で機能を有効にする必要があり、その後はナビゲーションバー（画面下部の小さなバー）をダブルタップすることで呼び出すことができます。

総評

Huawei Pura X Maxに搭載される新しい XiaoYi Companion AIは、単なる音声アシスタントの枠を超え、ユーザーの現在の状況や文脈を理解する「インテリジェントな相棒」としての役割を果たします。スマートToDo管理、旅行アシスタント、スマート読書支援など、日常生活のさまざまな領域にAI機能を統合することで、折りたたみフラッグシップスマートフォンのユーザー体験を一段上のレベルへと引き上げているのが特徴です。

まとめ

Huawei Pura X Maxに搭載される「XiaoYi Companion AI」は、文脈を理解する高度なパートナーとして機能し、ToDo管理や旅行支援、読書サポートなど多岐にわたる機能を統合しています。このAIの導入により、折りたたみフラッグシップ機におけるユーザー体験が大幅に向上することが期待されます。

Huawei Pura X Max Features New AI Assistant as an 'Intelligent Companion'

According to IT Home, Huawei's official channel has unveiled the Huawei Pura X Max—the industry's first horizontal foldable smartphone—featuring the new "XiaoYi Companion AI." This AI is designed to function as a companion that understands what you are thinking, fulfills your needs, and integrates naturally into your daily life.

As reported by IT Home, since this specific AI service was not included in previously released models, it will make its debut on the Huawei Pura X Max. According to the official teaser video, this new AI supports the following features:

Key Features

  • Smart To-Do: Intelligently recognizes information on the current app screen to add items to a to-do list or calendar, while providing active screen recognition capabilities.
  • Trip Assistant: Recognizes information on the current screen to provide route planning, estimated travel times, flight information lookups, and one-touch taxi hailing.
  • Global To-Do: Automatically records and organizes to-do lists, allowing users to view specific event details such as time and location with a single click.
  • Smart Reading: Recognizes the content being read to provide features like favorites, long-form summaries, key point highlights, and mind map generation. XiaoYi also searches for and compiles related information based on selected text.
  • Topic Recommendation: Identifies what the user is reading to recommend discussions and information regarding related topics.
  • Global XiaoYi Call: A dedicated XiaoYi voice button is provided in all active AI companion scenarios, allowing users to issue commands via a tap or long press.

Technical Specifications and Usage

The new XiaoYi Companion AI is expected to be a feature of HarmonyOS 6.1. According to notes in the official teaser video, this feature is currently available only on certain apps. To use it, users must receive an HOTA update, maintain a network connection, and enable the function in settings. Once enabled, it can be summoned by double-tapping the navigation bar at the bottom of the screen.

Summary

The XiaoYi Companion AI on the Huawei Pura X Max moves beyond a simple voice assistant to become an "intelligent companion" that understands context and user intent. By integrating advanced features like smart task management, travel assistance, and intelligent reading support, it significantly enhances the user experience for flagship foldable smartphones.
