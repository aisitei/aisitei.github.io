Huawei 리샤오룽, Pura X Max 사용 3개월 경과 "역대급 최고의 폴더블 디스플레이"라 극찬

Huawei Pura X Max 공개 및 출시 일정

IT之家에 따르면, 업계 최초의 가로형 폴더블 스마트폰인 Huawei Pura X Max가 오늘 아침 공식적으로 공개되고 예약 판매를 시작했습니다. 신제품은 4월 20일에 정식 출시될 예정입니다.

주요 특징 및 사용자 평가

Huawei 기기 BG CTO인 리샤오롱은 오늘 글을 통해 자신이 Pura X Max를 약 3개월 동안 사용했다고 공개했습니다. 그는 이 제품을 자신이 사용해 본 폴더블 기기 중 가장 뛰어나다고 평가했습니다.

Pura X Max는 폴더블 디스플레이의 장점을 극대화했습니다. 기기를 접었을 때는 더욱 작고 휴대하기 편리하며, 펼쳤을 때는 더 넓은 디스플레이 면적을 활용할 수 있습니다.

디자인 및 기능적 기대 효과

Huawei 공식 예열 이미지를 분석한 결과, Pura X Max는 펼친 상태의 크기와 비율이 작은 태블릿과 유사한 형태를 띱니다. 이는 신제품이 기존 P X 모델의 아쉬움을 보완할 것으로 기대됩니다.

특히, Pura X Max는 다음과 같은 기능을 제공할 것으로 예상됩니다:

  • 위챗 태블릿 버전 지원 (듀얼 기기 로그인 가능)
  • PC급 애플리케이션 구동 가능

총평

Huawei Pura X Max는 가로형 폴더블 폼팩터를 도입하며 폴더블 시장의 새로운 기준을 제시할 것으로 보입니다. 작은 크기와 넓은 활용성을 동시에 갖춘 이 모델은 태블릿과 스마트폰의 경계를 허물며 사용자 경험을 혁신할 잠재력을 지니고 있습니다.

产品发布信息

Huawei Pura X Max 作为行业首款横向阔折叠手机，已于4月13日正式亮相并开启预订。该产品的官方发布日期定于4月20日。

高管评价与核心体验

Huawei终端BG CTO李小龙透露其已使用Pura X Max约3个月，并称其为目前用过最好用的双折叠设备。该机型在设计上兼顾了便携性与大屏体验：

  • 折叠状态：尺寸更显小巧。
  • 展开状态：提供更大的显示面积。

硬件规格与功能预期

根据官方预热图，Huawei Pura X Max 在展开形态下的尺寸和比例接近一台小型平板电脑。这预示着该设备有望支持以下高级功能：

  • 微信平板版（可实现双终端设备登录）。
  • PC级应用支持。

总结

Huawei Pura X Max 作为首款横向阔折叠手机，将于4月20日正式发布。该机型凭借接近平板的展开尺寸和优化的显示比例，旨在提供更强的多任务处理能力及PC级应用体验。

Huawei Pura X Maxの公開と発売スケジュール

IT之家の報道によると、業界初の横型フォルダブルスマートフォン「Huawei Pura X Max」が今朝正式に発表され、予約販売が開始されました。新製品は4月20日に正式に発売される予定です。

主な特徴とユーザーの評価

HuaweiデバイスBGのCTOであるリ・シャオロン（Li Xiaong）氏は本日、自身の投稿を通じてPura X Maxを約3ヶ月間使用したことを明かしました。同氏は、この製品をこれまでに使用したフォルダブル端末の中で最も優れたものと高く評価しています。

Pura X Maxはフォルダブルディスプレイの利点を最大限に引き出しています。デバイスを折りたたんだ状態ではよりコンパクトで持ち運びに適しており、展開した際にはより広いディスプレイ面積を活用することが可能です。

デザインと機能的な期待効果

Huaweiの公式ティザー画像を分析した結果、Pura X Maxは展開時のサイズと比率が小型タブレットに近い形状となっていることが判明しました。これにより、新製品は従来のXモデルにおける課題を補うものと期待されています。

特に、Pura X Maxでは以下の機能の提供が予想されています：

  • WeChatタブレット版のサポート（デュアルデバイスログインが可能）
  • PC級アプリケーションの動作が可能

まとめ

Huawei Pura X Maxは横型フォルダブルフォームファクターを採用することで、折りたたみスマホ市場に新たな基準を提示します。コンパクトなサイズと高い汎用性を両立しており、スマートフォンとタブレットの境界を曖昧にし、ユーザー体験を革新する可能性を秘めています。

Huawei Pura X Max Unveiling and Release Schedule

According to IT之家, the industry's first horizontal foldable smartphone, the Huawei Pura X Max, was officially unveiled this morning with pre-orders now open. The new device is scheduled for an official release on April 20th.

Key Features and User Feedback

Li Xiaolong, CTO of Huawei's Device Business Group (BG), shared a post today stating that he had been using the Pura X Max for approximately three months. He described it as the most outstanding foldable device he has ever used.

The Pura X Max maximizes the advantages of a foldable display; it is more compact and portable when folded, while providing a larger screen area when unfolded.

Design and Functional Expectations

Analysis of official teaser images indicates that the Pura X Max features dimensions and proportions similar to a small tablet in its unfolded state. This design is expected to address some of the shortcomings found in previous P X models.

Specifically, the Pura X Max is expected to offer the following capabilities:

  • Support for WeChat's tablet version (enabling dual-device login)
  • Ability to run PC-level applications

Overall Impression

By introducing a horizontal foldable form factor, the Huawei Pura X Max is set to establish new standards in the foldable market. Combining a compact size with high versatility, this model has the potential to innovate the user experience by blurring the boundaries between tablets and smartphones.

Summary

The Huawei Pura X Max is a groundbreaking horizontal foldable smartphone launching on April 20th that aims to redefine the foldable market. It offers a versatile form factor capable of running PC-level applications while functioning as both a portable phone and a tablet-like device. By bridging the gap between these two categories, it promises a significantly enhanced user experience.
