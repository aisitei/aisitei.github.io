화웨이 Pura 90/Pro/Max 전 모델, USB 3.1 Gen 1 사양 설명 삭제한 Type-C 포트 스펙 페이지 공개

2026-04-22

Pura 90 시리즈 출시 및 스펙 변화

IT之家에 따르면, Huawei가 최근 Pura 시리즈 전 제품군 신제품 발표회에서 Pura 90, Pura 90 Pro, Pura 90 Max 세 모델을 공개했습니다.

데이터 포트 사양 비교 분석

Pura 시리즈의 데이터 케이블 인터페이스(Data Cable Interface) 사양이 모델 및 세대별로 변화를 보이고 있어 구매 시 유의해야 할 중요한 기술적 변경 사항이 확인되었습니다.

  • 신규 Pura 90 시리즈 (Pura 90 / Pro / Max)
  • 데이터 케이블 인터페이스 사양은 'USB Type-C'로 명시되어 있습니다.

반면, 이전 세대 모델 및 기존 Mate 라인업의 사양은 다음과 같습니다.

  • Pura 80 Pro 시리즈 (Pro / Pro+ / Ultra)
    데이터 케이블 인터페이스는 'USB Type-C, USB 3.1 Gen 1, DP 1.2'를 지원합니다.
  • Pura 80 표준 모델
    데이터 케이블 인터페이스는 'USB Type-C, USB 2.0'으로 명시되어 있습니다.
  • 기존 Huawei Mate 80 전 라인업
    여전히 'USB Type-C, USB 3.1 Gen 1'을 지원합니다.

총평

이번 Pura 90 시리즈는 플래그십 모델임에도 불구하고 데이터 케이블 인터페이스 사양이 단순히 'USB Type-C'로만 표기되어 있어, 고속 전송 규격(예: USB 3.1 Gen 1)에 대한 구체적인 정보가 부족합니다. 따라서 사용자는 이전 세대 Pro 모델들이 지원했던 높은 대역폭의 데이터 전송 속도를 기대하기 어려울 수 있으므로, 구매 전에 반드시 공식 스펙을 재확인할 필요가 있습니다.

新机发布与接口描述

Huawei 在 Pura 系列及全场景新品发布会中推出了 Pura 90、Pura 90 Pro 及 Pura 90 Max 三款手机。根据 Huawei 官网信息，这三款新机型的“数据线接口”目前仅标注为 “USB Type-C”。

与前代及同系列参数对比

相比于上一代产品，当前在售的型号在官方页面上的端口描述更为具体：

  • Pura 90 / Pro / Max：USB Type-C
  • Pura 80 Pro / Pro+ / Ultra：USB Type-C, USB 3.1 Gen 1，支持 DP 1.2
  • Pura 80 标准版：USB Type-C, USB 2.0
  • Mate 80 标准版：USB Type-C, USB 3.1 Gen 1

总结

Huawei 新推出的 Pura 90 系列在官网参数页面中仅标注为“USB Type-C”，相比上一代 Pura 80 系列更为简略。这种描述上的差异可能意味着新机型具体的传输协议细节尚未完全披露或进行了简化处理。

Pura 90シリーズの発売とスペックの変化

IT之家の報道によると、Huaweiは先日開催されたPuraシリーズの全製品発表会において、Pura 90、Pura 90 Pro、Pura 90 Maxの3モデルを発表しました。

データポート仕様の比較分析

Puraシリーズのデータケーブルインターフェース（Data Cable Interface）の仕様は、モデルや世代によって変化が見られており、購入時に注意すべき重要な技術的変更点として確認されています。

  • 新型 Pura 90 シリーズ (Pura 90 / Pro / Max)
  • データケーブルインターフェースの仕様は「USB Type-C」と明記されています。

一方、前世代モデルおよび既存のMateラインナップの仕様は以下の通りです。

  • Pura 80 Pro シリーズ (Pro / Pro+ / Ultra)
    データケーブルインターフェースは「USB Type-C, USB 3.1 Gen 1, DP 1.2」をサポートしています。
  • Pura 80 標準モデル
    データケーブルインターフェースは「USB Type-C, USB 2.0」と明記されています。
  • 既存の Huawei Mate 80 全ラインナップ
    引き続き「USB Type-C, USB 3.1 Gen 1」をサポートしています。

総評

今回のPura 90シリーズは、フラッグシップモデルであるにもかかわらず、データケーブルインターフェースの仕様が単に「USB Type-C」としか記載されておらず、高速転送規格（例：USB 3.1 Gen 1）に関する具体的な情報が不足しています。そのため、ユーザーは前世代のProモデルがサポートしていた高帯域のデータ転送速度を期待できない可能性があるため、購入前に必ず公式スペックを再確認する必要があります。

まとめ

Huaweiの新型Pura 90シリーズは、フラッグシップ機でありながらデータインターフェースの具体的な転送規格（USB 3.1等）が明記されていません。前モデルと比較して通信速度に差がある可能性があるため、購入前に詳細な仕様を確認することが推奨されます。

Pura 90 Series Launch and Specification Changes

According to IT之家, Huawei recently unveiled three new models—the Pura 90, Pura 90 Pro, and Pura 90 Max—during a product launch event for the Pura series.

Data Port Specification Comparison

The data cable interface specifications for the Pura series vary across different models and generations, marking an important technical change that consumers should note before purchasing.

  • New Pura 90 Series (Pura 90 / Pro / Max)
    • The data cable interface is specified simply as "USB Type-C."

    In contrast, the specifications for previous generation models and the existing Mate lineup are as follows:

    • Pura 80 Pro Series (Pro / Pro+ / Ultra)
      • The data cable interface supports "USB Type-C, USB 3.1 Gen 1, DP 1.2."
      • The data cable interface is specified as "USB Type-C, USB 2.0."
      • These models still support "USB Type-C, USB 3.1 Gen 1."

      Overall Assessment

      Despite being flagship models, the Pura 90 series lists its data cable interface simply as "USB Type-C," lacking specific high-speed standards such as USB 3.1 Gen 1. Consequently, users may not experience the high bandwidth data transfer speeds offered by previous Pro models. It is recommended that potential buyers verify the official specifications before making a purchase.

      Summary

      The new Pura 90 series features a simplified "USB Type-C" specification compared to the more detailed "USB 3.1 Gen 1" and "DP 1.2" specs found in previous flagship models like the Pura 80 Pro. This lack of specific high-speed protocols may result in lower data transfer speeds for the new lineup. Potential buyers should check official documentation to confirm the exact capabilities of their chosen model.

  • Pura 80 标准版：标注为“USB Type-C，USB 2.0”。
  • Mate 80 标准版：目前在售页面标注为“USB Type-C，USB 3.1 Gen 1”。

总结

Huawei 新推出的 Pura 90 系列产品在官方页面上的数据线接口描述较为简略，仅标注为“USB Type-C”。相比之下，上一代 Pura 80 系列及 Mate 80 系列在官网页面上提供了更详细的 USB 版本和 DP 支持信息。
