화웨이 Pura 90 Pro Max, '빛 감각의 경계를 허물다' 테마 공개: 잠금 화면 실시간 촬영으로 주변 환경을 벽지로 변신시키는 기능

Pura 90 시리즈 공식 발표

IT之家에 따르면, 지난 4월 22일 Huawei Pura 시리즈 및 전장면 신제품 발표회에서 Huawei의 임원인 위청둥(余承东)이 Pura 90 시리즈 스마트폰을 공식 출시했습니다. 새로운 모델은 세 가지 버전으로 구성되며, 가격은 4699위안부터 시작합니다.

주요 기능: 광감 무한 테마

특히 Huawei Pura 90 Pro Max 모델에서는 '광감 무한(光感无界)' 테마가 최초로 공개되었습니다. 이 기능을 사용하면 잠금 화면에서 실시간으로 주변 환경을 촬영할 수 있으며, 손가락 터치 한 번만으로도 주변 배경을 위젯이나 벽지로 설정할 수 있습니다.

이 테마를 성공적으로 적용한 후, 잠금 화면에서 화면을 켜면 사용자는 다음과 같은 기능을 이용할 수 있습니다:

  • 실시간 필터 효과 확인: 휴대폰을 돌리면 투명 필터가 실시간으로 다양한 동적 효과를 보여줍니다.
  • 현장 모드 진입: 화면을 길게 누르면 주변의 실제 풍경이 투명한 효과로 화면에 나타나는 '현장 모드'에 진입할 수 있습니다. 다시 한번 길게 누르면 현장 모드를 종료할 수 있습니다.

공식 설명에 따르면, 광감 무한 테마를 사용하면 주변 환경을 실시간으로 감지하여 실제 풍경 화면을 투명 효과로 휴대폰 잠금 화면에 구현할 수 있습니다. 다만, 만약 이미 얼굴 인식으로 잠금을 해제하도록 설정된 경우, 이 테마를 적용할 때 자동으로 얼굴 슬라이드 방식으로 전환된다는 점에 유의해야 합니다.

Huawei Pura 90 系列发布

在 Huawei Pura 系列及全场景新品发布会上，Huawei 正式发布了 Pura 90 系列手机。该系列提供三种机型选择，并提供相应的定价信息。

  • 产品型号：标准版、Pro、Pro Max
  • 起售价：4699 元

光感无界主题功能

Huawei Pura 90 Pro Max 首发搭载了“光感无界”主题。该功能允许用户在锁屏时实时取景，并将周围环境转化为动态壁纸。具体交互功能包括：

  • 查看滤镜效果：通过转动手机，透明滤镜可呈现不同的动态效果。
  • 进入实景模式：长按屏幕即可将周边实景以通透效果呈现在锁屏界面上，再次长按可退出该模式。

系统适配说明

在应用“光感无界”主题时，若用户原本设置了人脸直接解锁，系统会自动切换为“人脸滑动解锁”模式。

总结

Huawei 正式发布 Pura 90 系列手机，包含标准版、Pro 及 Pro Max 三款机型，起售价为 4699 元。其中 Pura 90 Pro Max 特色搭载了支持实时取景与动态滤镜的“光感无界”锁屏主题。

Pura 90シリーズの公式発表

IT之家の報道によると、4月22日に開催されたHuawei Puraシリーズおよび新製品発表会において、Huaweiの幹部である余承東（Yu Chengdong）氏がPura 90シリーズスマートフォンを正式に発表しました。新モデルは3つのバリエーションで構成され、価格は4,699元からとなっています。

主要機能：「光感無界」テーマ

特にHuawei Pura 90 Pro Maxモデルでは、「光感無界（Light Sense Boundless）」というテーマが初公開されました。この機能を使用すると、ロック画面で周囲の環境をリアルタイムに撮影でき、ワンタッチで周囲の風景をウィジェットや壁紙として設定することが可能になります。

このテーマを適用した状態でロック画面を表示すると、ユーザーは以下の機能を利用できます：

  • リアルタイムフィルター効果：スマートフォンを回転させると、透明なフィルターがリアルタイムでさまざまな動的エフェクトを表示します。
  • 現場モードへの移行：画面を長押しすることで、周囲の実際の風景が透明なエフェクトとして画面に現れる「現場モード」に入ることができます。もう一度長押しすると、このモードを終了できます。

公式の説明によると、「光感無界」テーマを使用することで、周囲の環境をリアルタイムに検知し、実際の風景を透明なエフェクトとしてロック画面に再現します。ただし、すでに顔認証によるロック解除を設定している場合、このテーマを適用すると自動的に「顔スライド」方式へと切り替わる点に注意が必要です。

まとめ

HuaweiはPura 90シリーズを発表し、特にPro Maxモデルでは周囲の風景をリアルタイムで反映する「光感無界」という革新的なテーマを導入しました。この機能により、ロック画面で動的なエフェクトや現場モードを楽しむことができ、設定に応じて顔スライドによるスムーズな操作にも対応します。

Official Launch of the Pura 90 Series

According to IT Home, Huawei executive Yu Chengdong officially launched the Pura 90 series smartphones during the launch event for the Pura series and new automotive products on April 22. The new lineup consists of three versions, with prices starting from 4,699 RMB.

Key Feature: "Infinite Light Sensing" Theme

The Huawei Pura 90 Pro Max model specifically introduces the "Infinite Light Sensing" (光感无界) theme. This feature allows users to capture their surroundings in real-time on the lock screen and set the surrounding environment as a widget or wallpaper with a single touch.

Interactive Features and Modes

Once the "Infinite Light Sensing" theme is successfully applied, users can access the following features when turning on the lock screen:

  • Real-time Filter Effects: Rotating the phone displays various dynamic effects through a transparent filter.
  • Scene Mode: Long-pressing the screen enters "Scene Mode," where the actual surrounding scenery appears on the screen with a transparent effect. A second long press will exit this mode.

According to the official description, the "Infinite Light Sensing" theme detects the environment in real-time to project the actual landscape onto the lock screen using a transparent effect. However, users should note that if face unlock is already enabled, applying this theme will automatically switch the unlocking method to a facial slide mode.

Summary

Huawei has officially launched the Pura 90 series with prices starting at 4,699 RMB. The Pro Max model features a unique "Infinite Light Sensing" theme that integrates real-time environmental capture and dynamic filter effects into the lock screen experience. This feature includes a specialized Scene Mode and automatic adjustment of face unlock settings when activated.
