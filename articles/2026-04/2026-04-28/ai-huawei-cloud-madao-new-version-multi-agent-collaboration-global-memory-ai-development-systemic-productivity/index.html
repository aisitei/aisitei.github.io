화웨이 클라우드 마다오 신규 버전 출시: 다중 에이전트 협업과 전역 메모리로 AI 개발을 '시스템적 생산성'으로 이끌다

2026-04-28

개요

Huawei의 Cloud CodeArts(클라우드 코드아츠) AI 코딩 에이전트가 새로운 버전을 공식 출시했습니다. 이번 업데이트는 '시스템화된 생산성'을 핵심 가치로 삼아 개발 효율성, 협업 방식, 코드 품질 개선부터 Skill 축적에 이르기까지 다방면에서 전면적인 최적화를 이루었으며, 기업 수준의 복잡한 개발 요구사항을 충족시키도록 설계되었습니다.

개발 효율성 강화

새로운 버전에서는 여러 세션 병렬 처리와 AI 에이전트 자동 분배 기능이 추가되어 복잡한 작업을 수행하는 능력이 크게 향상되었습니다.

  • 다중 세션 병렬 처리: 개발자는 하나의 IDE 내에서 여러 작업 스레드를 동시에 열어 독립적으로 다양한 개발 업무를 진행할 수 있어, 다중 작업 처리 효율성이 높아집니다.
  • 에이전트 자동 분배: 주 에이전트가 복잡한 작업을 필요에 따라 세분화하고, 동적으로 하위 에이전트를 생성하여 협업을 수행합니다. 각 하위 에이전트는 컨텍스트(문맥)를 독립적으로 격리하여 특정 하위 작업에 집중할 수 있게 함으로써, AI가 더욱 길고 복잡한 개발 프로세스를 지원하며 정확도가 크게 향상되었습니다.

프로젝트 협업 및 지식 관리

이번 버전은 '선호도 기억(Preference Memory)' 기능과 프로젝트 단위의 지식 축적 시스템을 강화했습니다.

  • 개인 선호도 기억: 사용자는 대화를 통해 언어, 개발 프로세스, 코딩 표준 등 개인적인 선호 규칙을 지속적으로 설정하고 업데이트할 수 있으며, 이 설정이 프로젝트 전반에 걸쳐 글로벌하게 적용됩니다. 이를 통해 개발 습관을 한 번 설정하면 장기간 재사용할 수 있어 반복적인 커뮤니케이션 비용을 획기적으로 줄여줍니다.
  • 프로젝트 스마트 명함 기능: 기존 프로젝트를 위한 구조화된 설명 문서를 원클릭으로 생성합니다. 이 기능은 코드 저장소를 자동으로 깊이 분석하여 프로젝트 아키텍처, 초기화 방식, 개발 표준 등 핵심 정보를 축적하고, 이를 AI 실행 과정의 지속적인 참고 자료로 활용합니다. 결과적으로 전체 코드 컨텍스트에 대한 의존도를 줄이고 토큰 소모를 효과적으로 낮추면서도, 코드 생성의 정확성과 일관성을 높여 프로젝트 기존 규범에 더욱 부합하게 만듭니다.

코드 품질 검증

새로운 버전에서는 AI 코드 리뷰 기능이 추가되어 개발된 코드를 다각도로 점검할 수 있습니다.

  • 다차원 검사: 보안 취약점, 컴파일 오류, 요구사항 충족도 등 여러 측면에서 검사를 수행합니다.
  • 완벽한 보고서 제공 및 수정 지원: 문제 위치, 영향 설명, 심각도 레벨이 포함된 종합적인 리뷰 보고서를 생성하며, 자동 수정 기능까지 지원하여 코드 품질과 엔지니어링 적용 가능성을 높입니다.

생태계 확장 및 Skill 구축

Huawei는 20년 이상의 연구 개발 경험과 수천억 줄의 코드를 기반으로, 요구사항 관리, 시스템 설계, 개발 테스트부터 배포까지 전 과정을 아우르는 고빈도 시나리오 Skill을 CodeArts에 내장하여 즉시 사용 가능하도록 했습니다.

또한, 새로운 버전에서는 '스킬 커스터마이징 작업실'이 도입되어 스킬 생성기 및 스킬 테스터가 포함되었습니다. 이를 통해 개발자는 자신만의 전용 스킬을 빠르고 쉽게 만들고 테스트하며 재사용할 수 있게 되어, 개인과 팀의 경험을 재활용 가능한 자산으로 축적할 수 있습니다.

開発効率の強化

  • エージェント自動分配: メインエージェントが複雑なタスクを必要に応じて細分化し、動的にサブエージェントを生成して協調を実行します。各サブエージェントはコンテキスト（文脈）を独立して隔離することで特定のサブタスクに集中でき、AIがより長く複雑な開発プロセスをサポートできるようになり、精度が大幅に向上しました。

プロジェクトのコラボレーションと知識管理

今回のバージョンでは、「Preference Memory」機能とプロジェクト単位の知識蓄積システムを強化しました。

  • 個人の Preference Memory: ユーザーは対話を通じて、言語、開発プロセス、コーディング標準などの個人的なルールを継続的に設定・更新でき、この設定はプロジェクト全体にグローバルに適用されます。これにより、一度設定すれば長期的に再利用可能となり、繰り返されるコミュニケーションコストを劇的に削減します。
  • プロジェクトスマートカード機能: 既存のプロジェクト向けに構造化された説明ドキュメントをワンクリックで生成します。この機能はコードリポジトリを自動的に深く分析し、プロジェクトアーキテクチャ、初期化方法、開発標準などの核心情報を蓄積し、AI実行過程の継続的な参照資料として活用します。結果として、全体のコードコンテキストへの依存度を下げてトークン消費を効果的に抑えつつ、コード生成の正確性と一貫性を高め、既存のプロジェクト規範により適合させます。

コード品質の検証

新バージョンではAIコードレビュー機能が追加され、開発されたコードを多角的に点検できます。

  • 多次元検査: セキュリティ脆弱性、コンパイルエラー、要件充足度など、複数の側面から検査を実行します。
  • 完全なレポート提供と修正支援: 問題箇所、影響の説明、深刻度レベルを含む包括的なレビューレポートを生成し、自動修正機能までサポートすることで、コードの品質とエンジニアリングへの適用可能性を高めます。

エコシステムの拡張とSkill構築

Huaweiは20年以上の研究開発経験と数千億行のコードに基づき、要件管理、システム設計、開発テストからデプロイに至るまで全工程を網羅する高頻度シナリオのSkillをCodeArtsに内蔵し、即座に使用可能にしました。

Overview

Huawei has officially released a new version of its Cloud CodeArts AI coding agent. This update focuses on "systematized productivity" as its core value, providing comprehensive optimizations in development efficiency, collaboration methods, code quality improvement, and skill accumulation. It is specifically designed to meet the complex development requirements of enterprise-level environments.

Enhanced Development Efficiency

The new version introduces multi-session parallel processing and automatic agent distribution, significantly improving the ability to handle complex tasks.

  • Multi-session Parallel Processing: Developers can open multiple task threads simultaneously within a single IDE to perform various development tasks independently, increasing multi-tasking efficiency.
  • Agent Auto-distribution: A primary agent breaks down complex tasks as needed and dynamically generates sub-agents to collaborate. Each sub-agent operates with an isolated context to focus on specific sub-tasks, allowing the AI to support longer, more complex development processes with significantly higher accuracy.

Project Collaboration and Knowledge Management

This version strengthens "Preference Memory" features and a project-level knowledge accumulation system.

  • Personal Preference Memory: Users can continuously set and update personal preference rules—such as programming languages, development processes, and coding standards—through conversation. These settings are applied globally across the project, allowing developers to reuse their established habits over long periods and drastically reduce repetitive communication costs.
  • Project Smart Card Feature: This feature generates structured documentation for existing projects with a single click. It automatically analyzes code repositories to gather core information such as project architecture, initialization methods, and development standards, using this data as a continuous reference during AI execution. Consequently, it reduces reliance on the entire code context and lowers token consumption while improving the accuracy and consistency of generated code in alignment with existing project norms.

Code Quality Verification

The new version includes an AI code review feature to inspect developed code from multiple angles.

  • Multi-dimensional Inspection: The system performs checks across various dimensions, including security vulnerabilities, compilation errors, and requirement fulfillment.
  • Comprehensive Reporting and Fix Support: It generates comprehensive review reports that include the location of issues, impact descriptions, and severity levels, while also providing automatic fix capabilities to enhance code quality and engineering feasibility.

Ecosystem Expansion and Skill Building

Based on over 20 years of R&D experience and hundreds of billions of lines of code, Huawei has integrated "high-frequency scenario Skills" into CodeArts. These cover the entire lifecycle—from requirement management and system design to development, testing, and deployment—making them immediately available for use.

Additionally, a "Skill Customization Workshop" has been introduced, featuring skill generators and skill testers. This allows developers to quickly create, test, and reuse their own dedicated skills, enabling individuals and teams to accumulate their experiences as reusable assets.

Conclusion

With this CodeArts update, Huawei is accelerating a new paradigm in AI development. By combining multi-agent collaboration, persistent memory features, and engineering standardization, the product enhances the understanding of AI programming and moves software development toward a more efficient and intelligent stage of "system productivity."

The update also provides a robust ecosystem of pre-built and customizable skills, aiming to transform software development into a highly efficient, system-driven process.

项目协作与知识管理

  • 项目智能名片： 支持一键生成结构化的项目说明文档。该功能会自动深度分析代码库，提取项目架构、初始化方式、开发标准等核心信息作为 AI 执行过程的参考。这在降低对全量代码上下文依赖和减少 Token 消耗的同时，确保了生成的代码符合既有的项目规范。

代码质量验证

新版本新增了 AI 代码评审功能，能够从多个维度对开发出的代码进行检查。

  • 多维度检测： 从安全漏洞、编译错误、需求满足度等多个维度进行扫描。
  • 报告提供与修复支持： 生成包含问题位置、影响说明及严重程度的综合评审报告，并提供自动修复功能，提升代码质量和工程可落地性。

生态扩展与技能构建

基于 Huawei 超过 20 年的研发经验和数千亿行代码积累，Cloud CodeArts 内置了涵盖需求管理、系统设计、开发测试到部署等全流程的高频场景 Skill，可供即时调用。

此外，新版本引入了“技能自定义工坊”，包含技能生成器和技能测试器。这使得开发者能够快速创建、测试并复用专属技能，将个人和团队的经验转化为可重用的资产。

Overview

Huawei has officially released a new version of its Cloud CodeArts AI coding agent. This update centers on the core value of "systematized productivity," providing comprehensive optimizations in development efficiency, collaboration methods, code quality improvement, and skill accumulation. It is specifically designed to meet the complex development requirements of enterprise-level environments.

Enhanced Development Efficiency

The new version introduces multi-session parallel processing and automatic agent distribution, significantly improving the ability to handle complex tasks.

  • Multi-session Parallel Processing: Developers can open multiple task threads simultaneously within a single IDE to perform various development tasks independently, increasing multi-tasking efficiency.
  • Agent Auto-distribution: A primary agent breaks down complex tasks as needed and dynamically generates sub-agents to collaborate. Each sub-agent operates with an isolated context to focus on specific sub-tasks, which significantly improves accuracy during long and complex development processes.

Project Collaboration and Knowledge Management

This version strengthens "Preference Memory" and project-level knowledge accumulation systems, aiming to reduce repetitive communication costs and improve the precision of code generation.

  • Personal Preference Memory: Users can continuously set and update personal rules—such as preferred languages, development processes, and coding standards—which are applied globally across projects. This allows for long-term reuse of settings and drastically reduces recurring communication overhead.
  • Project Smart Cards: This feature generates structured project description documents with a single click. It automatically analyzes the code repository to gather key information such as architecture, initialization methods, and development standards. By reducing reliance on full code context and lowering token consumption, it ensures generated code aligns more closely with existing project norms.

Code Quality Verification

The new version includes an AI code review feature that allows for the multi-dimensional inspection of developed code.

  • Multi-dimensional Inspection: The system performs checks across various dimensions, including security vulnerabilities, compilation errors, and requirement fulfillment.
  • Comprehensive Reporting and Fix Support: It generates comprehensive review reports containing the location of issues, impact descriptions, and severity levels, while also providing automated fix capabilities to improve code quality and engineering feasibility.

Ecosystem Expansion and Skill Building

Leveraging over 20 years of R&D experience and hundreds of billions of lines of code, Huawei has integrated high-frequency scenario skills—covering the entire lifecycle from requirement management and system design to testing and deployment—directly into CodeArts for immediate use.

Furthermore, a "Skill Customization Workshop" featuring skill generators and testers has been introduced. This allows developers to quickly create, test, and reuse custom skills, enabling individuals and teams to transform their experiences into reusable assets.

Summary

The latest update to Huawei's Cloud CodeArts introduces multi-agent collaboration, "Preference Memory," and automated code reviews to streamline complex enterprise development. By integrating extensive industry knowledge into a customizable skill system, the platform enhances both the efficiency and quality of software production. This move marks a shift toward more intelligent, systematic productivity in AI-assisted programming.
