마이크로소프트, M365 서비스 저하로 일부 아이폰 사용자 아웃룩 접속 오류 확인

2026-04-29

Microsoft 365 서비스 장애 발생 보고

IT之家에 따르면, Microsoft의 공식 계정(@MSFT365Status)은 지난 4월 28일 X 플랫폼을 통해 Microsoft 365 일부 서비스에 장애가 발생했음을 확인했습니다. 이 문제는 특히 iOS 메일 앱을 사용하여 Outlook에 접속하는 사용자들에게 영향을 미쳤으며, 사용자는 간헐적인 로그인 실패, "요청 과다(too many requests)" 오류 메시지, 또는 예기치 않은 로그아웃 등의 문제를 겪을 수 있습니다.

사건 개요 및 기간

IT之家가 인용한 Microsoft 공식 상태 페이지에 따르면, 이번 장애는 다음과 같은 시간대에 발생했습니다:

  • 발생 시점: 세계 협정시(UTC) 4월 27일 월요일 오전 8시 45분 (베이징 시간 기준 27일 오후 4시 45분)
  • 종료 시점: 세계 협정시(UTC) 4월 27일 월요일 저녁 7시 16분 (베이징 시간 기준 28일 새벽 3시 16분)
  • 총 지속 시간: 약 11시간 동안 지속되었습니다.

기술적 상태 및 영향

Microsoft 365 서비스 상태 웹사이트는 이번 사건을 "서비스 저하(service degradation)"로 분류했습니다. 이는 서비스가 완전히 중단된 것은 아니지만, 안정성이 떨어져 사용자가 Outlook.com에 로그인할 때 반복적으로 실패하거나 "요청 과다" 오류 메시지를 접하게 될 수 있음을 의미합니다.

공식 발표에 따르면, 장애가 발생한 기간 동안 iOS 사용자는 기본 메일 앱을 통해 Outlook과 Hotmail에 접근하는 데 어려움을 겪었습니다.

원인 분석 및 대응 방안

Microsoft는 이번 사태를 완화하기 위해 최근 도입된 변경 사항 중 일부를 되돌리는(rollback) 작업을 진행하고 있습니다. 회사는 이 복구 작업이 완료된 후 장애 영향도가 감소하는지 면밀히 관찰할 것이며, 고객 보고서를 지속적으로 분석하고 서비스 원격 측정 데이터를 주의 깊게 모니터링하여 다음 해결 방안을 결정할 것이라고 밝혔습니다.

사용자 입장에서 볼 때, 이러한 유형의 장애는 이메일 송수신 전 단계인 '본인 인증(Identity Authentication)'에 직접적인 영향을 미칩니다. 비록 메일 내용 자체가 유실되지는 않더라도, 사용자가 Outlook.com에 진입하지 못하거나 기업 사용자의 경우 중요한 회의 알림이나 외부 연락 정보 확인을 놓칠 수 있는 위험이 있습니다.

총평

이번 Microsoft 365 장애는 서비스가 완전히 마비된 것이 아닌 '서비스 저하' 형태로 나타나 사용자 경험에 큰 혼란을 주었습니다. 특히 iOS 사용자가 기본 메일 앱으로 Outlook에 접속할 때 인증 과정에서 반복적인 오류를 겪은 것이 핵심 문제였습니다. Microsoft 측은 최근 변경 사항의 롤백과 지속적인 모니터링을 통해 안정성을 회복하는 데 집중하고 있습니다.

服务故障概述

Microsoft 官方确认 Microsoft 365 部分服务出现“service degradation”（服务降级）。此次故障主要影响 iOS 用户通过系统默认邮件应用访问 Outlook 和 Hotmail，导致用户在登录时可能遇到间歇性失败、显示“too many requests”错误或应用程序意外退出。

故障时间与范围

本次故障持续约 11 小时。具体受影响的时间节点如下：

  • 开始时间（UTC）：4 月 27 日 08:45（北京时间 4 月 27 日 16:45）
  • 结束时间（UTC）：4 月 27 日 19:16（北京时间 4 月 28 日 03:16）

修复措施与后续

为缓解故障影响，Microsoft 已采取以下行动：

  • 正在回滚近期引入的变更。
  • 持续分析客户报告并监控服务遥测数据。
  • 根据监测结果决定进一步的修复方案。

总结

Microsoft 365 近期发生服务降级，导致 iOS 用户在通过默认邮件应用访问 Outlook 和 Hotmail 时出现登录失败或“请求过多”等问题。微软已采取回滚措施并持续监控系统状态以确保服务的稳定性。

Microsoft 365のサービス障害報告

IT之家の報道によると、Microsoftの公式アカウント（@MSFT365Status）がXを通じて、Microsoft 365の一部サービスにおいて障害が発生したことを確認しました。この問題は特にiOSのメールアプリを使用してOutlookにアクセスするユーザーに影響を及ぼしており、断続的なログイン失敗、「リクエスト過多（too many requests）」というエラーメッセージの表示、または予期しないログアウトなどの問題が発生していました。

事象の概要と期間

IT之家が引用したMicrosoftの公式ステータスページによると、今回の障害は以下の時間帯に発生しました。

  • 発生時： 世界標準時（UTC）4月27日（月）午前8時45分（北京時間：27日午後4時45分）
  • 終了時： 世界標準時（UTC）4月27日（月）午後7時16分（北京時間：28日午前3時16分）
  • 総継続時間： 約11時間

技術的状況と影響

Microsoft 365のサービスステータスウェブサイトでは、今回の事象を「サービス低下（service degradation）」として分類しています。これはサービスが完全に停止したわけではないものの、安定性が低下し、ユーザーがOutlook.comにログインする際に繰り返し失敗したり、「リクエスト過多」のエラーメッセージが表示されたりする状態を指します。

公式発表によると、障害が発生した期間中、iOSユーザーは標準のメールアプリを通じてOutlookやHotmailにアクセスする際に困難を抱えました。

原因分析と対応策

Microsoftは今回の事態を緩和するため、最近導入された変更の一部をロールバック（差し戻し）する作業を行っています。同社は、この復旧作業の完了後に影響が減少するかを綿密に監視するとともに、顧客からの報告を継続的に分析し、サービスのリモートメトリクスデータを注意深く監視しながら次の解決策を決定する方針です。

ユーザーの視点では、この種の障害はメールの送受信の前段階である「本人認証（Identity Authentication）」に直接影響を与えます。メールの内容自体が消失することはありませんが、Outlook.comへのアクセスができなくなることで、企業ユーザーなどが重要な会議通知や外部からの連絡情報を確認できなくなるリスクがあります。

まとめ

今回のMicrosoft 365の障害は、完全な停止ではなく「サービス低下」として発生し、特にiOSデバイスの標準メールアプリを使用するユーザーに認証エラーなどの混乱をもたらしました。Microsoftは原因の緩和のため、最近の変更をロールバックし、継続的なモニタリングを通じてシステムの安定性回復に注力しています。

Report of Microsoft 365 Service Outage

According to IT House, Microsoft's official account (@MSFT365Status) confirmed on the X platform that certain Microsoft 365 services experienced an outage on April 28. The issue specifically affected users accessing Outlook via the iOS Mail app, who encountered problems such as intermittent login failures, "too many requests" error messages, or unexpected logouts.

Incident Overview and Duration

According to the official Microsoft status page cited by IT House, the outage occurred during the following timeframe:

  • Start Time: Monday, April 27, at 8:45 AM UTC (16:45 on April 27, Beijing Time)
  • End Time: Monday, April 27, at 7:16 PM UTC (03:16 on April 28, Beijing Time)
  • Total Duration: Approximately 11 hours.

Technical Status and Impact

The Microsoft 365 service status website classified this incident as "service degradation." This means that while the service was not completely offline, its stability was compromised, causing users to encounter repeated login failures or "too many requests" errors when trying to access Outlook.com.

According to official reports, during the period of the outage, iOS users experienced difficulties accessing both Outlook and Hotmail through their default mail applications.

Cause Analysis and Response Measures

Microsoft is currently rolling back some recently implemented changes to mitigate the situation. The company stated that it will closely monitor whether the impact decreases following these rollbacks. They also plan to continue analyzing customer reports and monitoring remote telemetry data to determine further solutions.

From a user perspective, this type of failure directly impacts "Identity Authentication," which is a prerequisite for sending and receiving emails. While the actual content of the emails was not lost, users were unable to access Outlook.com; for corporate users, this posed a risk of missing critical meeting notifications or external contact information.

Overall Assessment

The Microsoft 365 outage manifested as "service degradation" rather than a total blackout, yet it caused significant disruption to the user experience. The core issue was the repeated authentication errors encountered by iOS users accessing Outlook via native mail apps. Microsoft is currently focused on restoring stability through rollbacks and continuous monitoring.

Summary

Microsoft experienced an 11-hour service degradation that primarily affected Outlook and Hotmail access for iOS users using default mail apps. The issue centered on "Identity Authentication" failures rather than data loss, leading to login errors and "too many requests" messages. Microsoft is currently rolling back recent changes and monitoring telemetry data to restore full stability.
