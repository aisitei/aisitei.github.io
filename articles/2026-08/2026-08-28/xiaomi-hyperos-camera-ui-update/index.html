카메라 UI 업데이트

IT之家 8월 27일 보도에 따르면, Xiaomi 카메라 부서의 제품 매니저 @Bao_小李가 오늘 게시물을 통해 Xiaomi HyperOS 4 카메라 UI의 새로운 특징을 소개했습니다. 그는 이번 카메라 UI 업데이트가 전형적으로 "변화는 크지 않아 보이지만, 엄청난 공수가 투입된" 재구축 작업이라고 밝혔습니다.

  • 모든 아이콘의 시각적 요소와 MENU 상단 슬라이드 메뉴의 재질이 Xiaomi HyperOS 4의 미학에 맞춰졌으며, 카메라는 고립된 UI에서 벗어났습니다.
  • 전체 기능 레이아웃이 위로 이동하여 미리보기 화면이 중앙에 배치되어 대화면 기기를 잡고 사용하기 더 편리하고, 구도 시각적 균형이 개선되었습니다.
  • 모든 모드의 스위치 로직이 통일되어 아이콘 안내가 더욱 명확해졌으며, 하나의 버튼이 여러 모드를 혼란스럽게 나타내는 문제가 해결되었습니다.
  • 사진 / 인물 / 동영상 / 프로 모드 간의 화면 비율 창이 통일되어, 모드 전환 시 화면이 "튀는" 현상이 사라졌습니다.
  • 뷰티 & 필터 진입점이 독립적인 아이콘으로 분리되어 숨겨진 폴더블 메뉴에서 벗어나 한 번에 접근할 수 있게 되었습니다.
  • 보조 툴바가 가장자리에 걸리거나 미리보기 화면이 가려지는 오래된 문제가 근본적으로 해결되었습니다.
  • 워터마크 업데이트 시 빨간 점 알림이 추가되었고, 설정 페이지에서 워터마크 소재를 수동으로 새로 고칠 수 있습니다.
  • 카메라 설정 메뉴가 사용 빈도에 따라 재정렬되었고, 보조 제목이 추가되어 기능 찾기 효율이 높아졌습니다.
  • EV 노출 조절은 일시적으로 MENU 메뉴로 이동되었습니다.

Xiaomi 카메라 부서의 제품 매니저 @Bao_小李의 웨이보 첨부 이미지에 따르면, 이번 카메라 UI 업데이트는 "기능 안내의 명확성 및 촬영 시각적 균형 개선"에 중점을 두었습니다.

IT之家의 어제 보도에 따르면, Xiaomi HyperOS 4 카메라는 전반적으로 미학적 업데이트를 거쳐 시스템 디자인 체계에 깊이 맞춰졌으며, 글꼴 통일 및 아이콘 재설계가 이루어졌습니다. 이번 변경 및 업그레이드는 '비 Xiaomi 17 Ultra 라이카 에디션' 모델에만 적용됩니다.

Xiaomi 카메라 부서의 제품 매니저 @Bao_小李는 Xiaomi 17 Ultra 라이카 에디션의 카메라 소프트웨어 전체 디자인은 Xiaomi와 라이카 팀 간의 전방위적이고 심도 깊은 협력 경험의 결과이므로 이번 업데이트의 영향을 받지 않는다고 설명했습니다.

총평

Xiaomi HyperOS 4의 카메라 UI는 전반적인 미학적 업데이트를 통해 시스템 디자인 체계와 일관성을 확보했습니다. 이번 업데이트는 기능 레이아웃 개선, 아이콘 통일, 모드 전환 시 시각적 안정성 확보 등 사용자 경험 향상에 중점을 두었으며, 비 Xiaomi 17 Ultra 라이카 에디션 모델에 적용됩니다.

系统美学与设计对齐

  • 全量图标视觉和 MENU 上滑菜单材质已对齐 Xiaomi HyperOS(Xiaomi澎湃 OS) 4 的整体美学，使相机界面告别“孤岛 UI”。
  • 相机的整体功能布局进行了上移优化，使预览取景画面居中显示，提升大屏握持的舒适度和构图观感。

核心拍摄流程与操作优化

  • 统一了全模式开关逻辑，图标提示更加清晰，解决了之前同一个按钮在多模式下的表意混乱问题。
  • 拍照、人像、视频和专业等跨模式画幅窗口已实现统一，消除了切换模式时画面“跳一下”的视觉割裂感。
  • 美颜与滤镜入口被拆分为独立图标，用户可一步直达，告别了折叠隐藏式的操作流程。

功能细节修复与效率提升

  • 彻底解决了二级工具栏出现卡边或遮挡取景画面的老问题。
  • 水印功能更新新增了红点提醒机制，并在设置页支持用户主动刷新水印素材。
  • 相机设置菜单已根据使用频率重新排序，并增加了二级标题，提高了查找功能的效率。
  • EV 曝光调节功能暂时移入了 MENU 菜单进行管理。

适用范围与版本说明

本次相机 UI 焕新是针对非 Xiaomi 17 Ultra 라이카版 机型生效的系统升级。

  • 该次改动旨在实现深度对齐系统设计体系，统一了字体和重绘了图标。
  • Xiaomi 17 Ultra 라이카版本的相机软件设计属于 Xiaomi 和 Leica 团队的专属合作体验，不受本次 HyperOS(Xiaomi澎湃 OS) 4 的通用升级影响。

总结

小米通过此次针对非旗舰机型的 HyperOS(Xiaomi澎湃 OS) 4 相机 UI 重构，实现了从美学到功能的全方位优化。主要的改动包括系统级设计对齐、操作流程的简化（如统一模式切换和独立滤镜入口），以及修复了多项老问题，旨在提升用户拍摄时的观感平衡度和使用效率。

カメラUIのアップデート

IT之家が8月27日に報じたところによると、Xiaomiのカメラ部門プロダクトマネージャーである@Bao_小李氏が投稿を通じて、Xiaomi HyperOS 4における新しいカメラUIの特徴を紹介しました。同氏は、今回のカメラUIの更新は「見た目には大きな変化がないように見えても、膨大な労力が投じられた」再構築作業であると述べています。

  • すべてのアイコンの視覚的要素とメニュー上部のスライドメニューのデザインが、Xiaomi HyperOS 4のエステティクスに合わせて刷新され、カメラUIは従来の孤立したインターフェースから脱却しました。
  • 全体の機能レイアウトが上に移動し、プレビュー画面が中央に配置されたことで、大型デバイスでの操作性が向上し、構図の視覚的なバランスが改善されました。
  • すべてのモードにおけるスイッチロジックが統一され、アイコンによる案内がより明確になりました。また、一つのボタンが複数のモードを混乱させるという問題も解決されています。
  • 写真／ポートレート／動画／プロモード間の画面アスペクト比ウィンドウが統一されたため、モード切り替え時に画面が「跳ねる」現象がなくなりました。
  • ビューティー＆フィルターへのアクセスポイントが独立したアイコンとして分離され、隠しフォルダのメニューからではなく、ワンタップで直接アクセスできるようになりました。
  • 補助ツールバーがエッジに重なったり、プレビュー画面を覆い隠すという長年の問題が根本的に解決されました。
  • ウォーターマークの更新時には赤い点通知が追加され、設定ページからウォーターマーク素材を手動でリフレッシュすることが可能になりました。
  • カメラ設定メニューは使用頻度に応じて再配置され、補助的なタイトルが追加されたことで、機能を探す効率が高まりました。
  • EV露出調整機能は一時的にメニュー内に移動されました。

Xiaomiカメラ部門のプロダクトマネージャー@Bao_小李氏のWeiboに添付された画像によると、今回のUIアップデートは「機能案内（ガイダンス）の明確化と撮影時の視覚的バランス改善」に重点を置いています。

IT之家が昨日報じたところによれば、Xiaomi HyperOS 4カメラは全体的に美的なアップデートを受け、システムデザイン体系に深く組み込まれました。フォントの統一やアイコンの再設計が行われています。なお、この変更およびアップグレードは、「非Xiaomi 17 Ultraライカエディション」モデルのみに適用されます。

@Bao_小李氏は、Xiaomi 17 Ultraライカエディションのカメラソフトウェア全体のデザインは、Xiaomiとライカチームとの広範かつ深い協力経験の結果であるため、今回のアップデートの影響を受けないものだと説明しています。

まとめ

Xiaomi HyperOS 4のカメラUIは、システム全体のデザイン体系との一貫性を確保するため、包括的な美的な更新が行われました。主な改善点には、機能レイアウトの最適化、アイコンやモード切り替え時の視覚的安定性の向上などが含まれます。このアップデートはユーザーエクスペリエンスの向上に焦点を当てており、「非Xiaomi 17 Ultraライカエディション」モデルでの利用が可能です。

Xiaomi Camera UI Update

According to reports from IT之家 on August 27th, Xiaomi's Product Manager for the camera department, @Bao_小李, introduced new features for the Xiaomi HyperOS 4 camera UI via a post today. He stated that this camera UI update is a comprehensive rebuild effort described as "not looking like a big change, but requiring immense effort."

  • The visual elements of all icons and the material of the top slide menu in MENU have been aligned with the aesthetics of Xiaomi HyperOS 4, moving the camera away from an isolated UI.
  • The overall function layout has shifted upwards, placing the preview screen centrally for easier use on large-screen devices, thereby improving compositional visual balance.
  • The switch logic for all modes has been unified, making icon guidance clearer and resolving the issue where a single button confusingly displayed multiple modes.
  • The aspect ratio window between Photo / Portrait / Video / Pro modes has been standardized, eliminating the "jumping" effect when switching modes.
  • Access to Beauty & Filter has been separated into an independent icon, moving it out of a hidden foldable menu for immediate access.
  • Fundamental issues such as auxiliary toolbars overlapping edges or obscuring the preview screen have been resolved.
  • A red dot notification has been added during watermark updates, and users can manually refresh the watermark material in the settings page.
  • The camera settings menu has been reorganized based on usage frequency, and additional sub-titles have been added to improve efficiency when finding functions.
  • EV exposure adjustment has been temporarily moved to the MENU menu.

According to an image attached by @Bao_小李, Xiaomi's Product Manager for the camera department, this UI update focused on "improving clarity of function guidance and visual balance during shooting."

IT之家 reported yesterday that the Xiaomi HyperOS 4 camera has undergone overall aesthetic updates, deeply integrating with the system design framework through font standardization and icon redesign. These changes and upgrades will only apply to models other than the 'Xiaomi 17 Ultra Leica Edition.'

However, @Bao_小李 clarified that the entire camera software design for the Xiaomi 17 Ultra Leica Edition is the result of comprehensive and in-depth collaborative experience between Xiaomi and Leica, and therefore will not be affected by this update.

Summary

The Xiaomi HyperOS 4 camera UI has received an aesthetic overhaul to ensure consistency with the overall system design framework. The updates focus on improving user experience through better function layout, icon standardization, and visual stability during mode transitions. These changes are applicable to models other than the Xiaomi 17 Ultra Leica Edition, which retains its specialized software design.
