Xiaomi 18 Fold 스마트폰, 세계 최초 CXMT LPDDR6 메모리 탑재, 9월 공개

2026-08-30

소개

Xiaomi는 오늘 Xiaomi 18 Fold가 ChangXin Memory(CXMT)의 LPDDR6 메모리를 세계 최초로 탑재하며, 9월에 공개될 것이라고 공식 발표했습니다.

Xiaomi CEO 레이쥔의 발언

Xiaomi의 창립자이자 회장 겸 CEO인 레이쥔은 다음과 같이 밝혔습니다.

  • ChangXin Memory의 LPDDR6 메모리 양산을 축하합니다. 정말 대단합니다!
  • XRING O3가 ChangXin Memory LPDDR6를 최초로 지원하며, Xiaomi 18 Fold가 이를 최초로 탑재합니다.
  • 저는 이것이 시작에 불과하며, 앞으로 더 많은 뛰어난 중국 기술 기업들이 강력하게 협력하여 정점에 도달할 것이라고 믿습니다!

ChangXin Memory LPDDR6 스펙

ChangXin Memory는 2026년 반기 보고서에서 자체 개발한 LPDDR6 칩의 성능이 이전 세대 LPDDR5X 대비 전면적으로 향상되었다고 밝혔습니다.

  • 아키텍처 혁신 및 데이터 전송 최적화 기술을 통해 데이터 전송 잠재력을 최대한 발휘했습니다.
  • 최고 속도: 12800Mbps
  • 최대 칩 용량: 16GB
  • 현재 주요 고객에게 샘플을 보내 검증 중이며, 양산을 가속화하고 있습니다.

XRING O3 및 ChangXin Memory 협력

8월 24일, Xiaomi의 첫 AI 플래그십 SoC인 XRING O3가 공식 발표되었으며, 업계 최초로 LPDDR6를 지원합니다. 8월 28일, ChangXin Memory Technology Co., Ltd.는 공식 웨이보 계정을 개설했으며, 이 계정이 가장 먼저 팔로우한 계정은 Xiaomi Mobile이었습니다.

총평

Xiaomi 18 Fold는 ChangXin Memory의 LPDDR6 메모리를 세계 최초로 탑재하며, 이는 Xiaomi의 첫 AI 플래그십 SoC인 XRING O3가 LPDDR6를 지원하는 것과 맞물려 있습니다. ChangXin Memory의 LPDDR6는 이전 세대 대비 향상된 성능과 12800Mbps의 최고 속도를 제공하며, Xiaomi와 ChangXin Memory 간의 긴밀한 협력을 보여줍니다.

新品发布与首发搭载

  • Xiaomi 官宣：Xiaomi 18 Fold 将全球首发搭载长鑫 LPDDR6 内存，预计于 9 月上市。
  • AI旗舰芯片发布：Xiaomi 首款 AI 旗舰 SoC XRING O3 于 8 月 24 日正式发布，并成为行业首发支持 LPDDR6 的产品。

核心组件技术突破

  • LPDDR6性能提升：长鑫科技在 2026 年半年度报告中披露，自主研发的 LPDDR6 芯片性能较上一代 LPDDR5X 实现全面跃升。
  • 关键规格参数：该 LPDDR6 芯片具备以下指标：
    • 峰值速率：达 12800Mbps。
    • 最高容量：16GB。
  • 产业进展：目前长鑫的 LPDDR6 产品已向关键客户送样验证，正加速推进量产进程。

行业合作与品牌动态

Xiaomi 创始人雷军对长鑫科技实现 LPDDR6 内存量产表示祝贺，并指出 XRING O3 是首家支持该技术的设备，而 Xiaomi 18 Fold 将是首发搭载平台。

  • 行业信心：雷军表达了对中国优秀科技企业强强联合、勇攀高峰的信心。
  • 官方联动：长鑫存储技术有限公司于 8 月 28 日开通官方微博，并首次关注了 Xiaomi 手机官方账号，标志着双方合作关系的进一步加强。

总结

本次消息的核心在于中国本土供应链的重大突破。Xiaomi 通过其旗舰产品线（如 Xiaomi 18 Fold 和 XRING O3）率先采用了长鑫 LPDDR6 内存，标志着国内存储芯片在高端移动设备领域的应用里程碑。LPDDR6 的高规格参数和量产推进，预示着未来国产科技硬件将具备更强的性能竞争力。

概要

Xiaomiは、ChangXin Memory（CXMT）のLPDDR6メモリを世界で初めて搭載した「Xiaomi 18 Fold」を9月に正式発表すると公式に発表しました。

レイ・ジュンCEOの発言

Xiaomiの創業者であり会長兼CEOであるレイ・ジュン氏は、以下の通りコメントを発表しています。

  • ChangXin MemoryによるLPDDR6メモリの実用化を祝福し、「本当に素晴らしい」と述べています。
  • XRING O3がChangXin Memory LPDDR6を初めてサポートし、Xiaomi 18 Foldがこれを世界で最初に搭載することに言及しました。
  • この出来事は始まりに過ぎず、今後さらに多くの優れた中国のテクノロジー企業が強力に協力し、頂点に到達すると確信していると語っています。

ChangXin Memory LPDDR6のスペック

ChangXin Memoryは、自社開発したLPDDR6チップの性能が、前世代のLPDDR5Xと比較して全面的に向上したことを発表しました。

  • アーキテクチャの革新とデータ転送最適化技術により、データの伝送潜在能力を最大限に引き出しています。
  • 最高速度：12800Mbps
  • 最大チップ容量：16GB
  • 現在、主要な顧客へサンプルを送付し検証を進めており、量産化の加速を図っています。

XRING O3とChangXin Memoryの連携

Xiaomi初のAIフラッグシップSoCである「XRING O3」が8月24日に公式発表され、業界で初めてLPDDR6をサポートすることが明らかになりました。これに続き、ChangXin Memory Technology Co., Ltd.は8月28日に公式Weiboアカウントを開設し、最初にフォローしたアカウントはXiaomi Mobileでした。

まとめ

「Xiaomi 18 Fold」は、ChangXin MemoryのLPDDR6メモリを世界で初めて搭載するという画期的な発表を行いました。これは、Xiaomi初のAIフラッグシップSoCであるXRING O3がLPDDR6をサポートすることと連動しています。ChangXin Memory LPDDR6は、前世代比で性能向上を実現し、12800Mbpsという最高速度を提供することで、XiaomiとChangXin Memory間の緊密な技術協力関係を示しています。

Introduction

Xiaomi officially announced today that the Xiaomi 18 Fold will be the first device globally to feature ChangXin Memory (CXMT)'s LPDDR6 memory, with a public release scheduled for September.

Comments from Xiaomi CEO Lei Jun

Lei Jun, Founder, Chairman, and CEO of Xiaomi, stated:

  • "Congratulations on the mass production of ChangXin Memory's LPDDR6 memory. This is truly amazing!"
  • "XRING O3 will be the first to support ChangXin Memory LPDDR6, and the Xiaomi 18 Fold will be the first device to incorporate it."
  • "I believe this is just the beginning, and that many more outstanding Chinese technology companies will collaborate strongly to reach new heights!"

ChangXin Memory LPDDR6 Specifications

In its semi-annual report for 2026, ChangXin Memory announced that the performance of its self-developed LPDDR6 chip has been comprehensively improved compared to previous generation LPDDR5X.

  • The technology maximizes data transfer potential through architectural innovation and optimized data transmission techniques.
  • Top Speed: 12800Mbps
  • Maximum Chip Capacity: 16GB
  • Samples are currently being sent to major customers for verification, accelerating mass production.

XRING O3 and ChangXin Memory Collaboration

On August 24th, Xiaomi officially announced XRING O3, its first AI flagship SoC, which supports LPDDR6—a first in the industry. Subsequently, on August 28th, ChangXin Memory Technology Co., Ltd. opened an official Weibo account, and Xiaomi Mobile was the very first account to follow it.

Summary

The Xiaomi 18 Fold is set to debut globally with ChangXin Memory's LPDDR6 memory, marking a significant milestone for the company. This launch coincides with the XRING O3, Xiaomi's inaugural AI flagship SoC, which also supports LPDDR6. The new LPDDR6 offers enhanced performance and a top speed of 12800Mbps compared to previous generations, highlighting the close technological collaboration between Xiaomi and ChangXin Memory.
