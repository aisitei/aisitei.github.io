Huawei HarmonyOS 7.0.0.102 버전의 새로운 기능 공개, 온디바이스 AI 모델의 로컬 모델 버전 확인 등 지원

2026-08-18

업데이트 개요

Huawei가 오늘 HarmonyOS 7.0.0.102 SP8 버전 배포를 시작했습니다. 첫 번째 대상 모델은 Mate 80, Mate 70 시리즈 등이며, 시스템 패키지 크기는 약 6.79GB입니다. 새로운 버전에는 3D 공간 배경화면, 친밀 서클, 아웃도어 탐색 모드 등의 기능이 추가되었습니다.

AI 기능

HarmonyOS 7.0.0.102 버전으로 업그레이드하면, 온디바이스 AI 기능을 지원하는 모델에서 로컬 모델 버전, 파라미터 크기 및 서비스 시나리오를 확인할 수 있습니다 (각 모델의 최종 기능은 실제 출시 버전에 따릅니다).

로컬 대규모 언어 모델은 텍스트, 음성, 이미지 로컬 처리 서비스를 지원하며, Xiaoyi Assistant, 통화 요약, 텍스트 다듬기, Xiaoyi 글쓰기 지원 및 갤러리 검색 등의 기능을 지원합니다.

총평

Huawei는 HarmonyOS 7.0.0.102 SP8 업데이트를 통해 Mate 80, Mate 70 시리즈 등에 3D 공간 배경화면, 친밀 서클, 아웃도어 탐색 모드 등 다양한 신규 기능을 추가했습니다. 특히 온디바이스 AI 기능을 강화하여 로컬 대규모 언어 모델을 통해 텍스트, 음성, 이미지 처리 서비스를 지원하며, 사용자 경험을 향상시키는 데 중점을 두었습니다.

总结

Huawei 推出了 HarmonyOS 7.0.0.102 SP8 系统更新，主要针对 Mate 系列机型推送约 6.79 GB 的系统包。新版本显著增强了端侧 AI 能力及相关服务支持，并加入了 3D 壁纸等丰富的新功能。

アップデート概要

Huaweiは本日、HarmonyOS 7.0.0.102 SP8の配信を開始しました。初期対象モデルはMate 80やMate 70シリーズなどで、システムパッケージのサイズは約6.79GBです。新バージョンでは、3D空間壁紙、親密なサークル、アウトドア探索モードなどの機能が追加されています。

AI機能

HarmonyOS 7.0.0.102にアップデートすることで、オンデバイスAI機能をサポートするモデルにおいて、ローカルモデルのバージョン、パラメータサイズ、およびサービスシナリオを確認できるようになります（各モデルの最終的な機能は実際のリリースバージョンに準じます）。

ローカル大規模言語モデル（LLM）は、テキスト、音声、画像のローカル処理サービスをサポートしており、以下の機能を備えています。

  • Xiaoyi Assistant
  • 通話要約
  • テキストのブラッシュアップ
  • Xiaoyiライティング支援
  • ギャラリー検索

総評

HuaweiはHarmonyOS 7.0.0.102 SP8のアップデートを通じて、Mate 80やMate 70シリーズに3D空間壁紙、親密なサークル、アウトドア探索モードなど多彩な新機能を追加しました。特にオンデバイスAI機能を強化し、ローカル大規模言語モデルを通じてテキスト、音声、画像の処理サービスを提供することで、ユーザー体験の向上に重点を置いています。

Update Overview

Huawei has begun rolling out the HarmonyOS 7.0.0.102 SP8 update today. The initial rollout targets models such as the Mate 80 and Mate 70 series, with a system package size of approximately 6.79GB. This version introduces several new features, including 3D spatial wallpapers, Intimate Circle, and Outdoor Exploration Mode.

AI Features

Upgrading to HarmonyOS 7.0.0.102 allows supported devices to display local model versions, parameter sizes, and service scenarios for on-device AI (final features depend on the specific release).

Local Large Language Models (LLMs) support localized processing for text, voice, and images. These models power a variety of integrated functions:

  • Xiaoyi Assistant
  • Call summary
  • Text polishing
  • Xiaoyi writing assistance
  • Gallery search

Summary

The HarmonyOS 7.0.0.102 SP8 update introduces new visual and exploration modes for the Mate 80 and Mate 70 series while significantly enhancing on-device AI capabilities. By utilizing local Large Language Models, the update provides improved processing for text, voice, and images to create a more seamless user experience.
