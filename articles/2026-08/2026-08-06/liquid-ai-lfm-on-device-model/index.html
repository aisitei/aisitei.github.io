Liquid AI, 스마트폰 로컬 구동을 지원하는 LFM2.5-2.6B 온디바이스 소형 모델 발표

2026-08-06

제품 소개

AI 스타트업 Liquid AI가 현지 시간으로 어제 오픈 소스 에이전트 모델인 LFM2.5-2.6B를 발표했습니다. 26억 개의 파라미터로 구성된 LFM2.5-2.6B는 스마트폰을 포함한 온디바이스(on-device) 환경에 매우 적합하며, 동시에 계획, 호출, 다단계 처리와 같은 에이전트 워크플로우를 지원하기에 충분한 성능을 갖췄습니다.

기술 사양 및 플랫폼

LFM2.5-2.6B는 34T 토큰 데이터셋으로 사전 학습되었으며, 기존 토크나이저 확장을 통해 비라틴 문자 언어에 대한 지원을 강화했습니다. Liquid AI는 Hugging Face 플랫폼에서 해당 모델의 기본 버전과 후학습(post-training) 버전을 동시에 제공합니다.

성능 비교

Liquid AI가 제공한 데이터에 따르면, LFM2.5-2.6B는 gemma-4-E2B-it, gemma-4-E4B-it, Qwen3.5-4B, Qwen3.5-9B 등 더 큰 규모의 모델과 벤치마크 테스트를 진행했을 때 모든 지시 실행 항목과 거의 모든 도구 사용 프로젝트에서 앞섰으며, BFCLv4 테스트에서만 Qwen3.5-9B에 뒤처졌습니다.

LFM2.5-2.6B는 에이전트 작업에서 두 종류의 Gemma 모델보다 뛰어난 성능을 보였으며, Qwen 모델과 유사한 수준을 기록했습니다. STEM 분야에서는 AA Omniscience 테스트에서 앞섰으나 수학 테스트에서는 Qwen3.5-9B에 뒤처졌습니다. 프로그래밍은 더 큰 규모의 모델이 여전히 우위를 점하는 유일한 영역입니다.

총평

LFM2.5-2.6B는 적은 파라미터로도 스마트폰 등 온디바이스 환경에서 강력한 에이전트 워크플로우를 수행할 수 있는 성능을 갖췄습니다. 특히 다양한 지시 실행 및 도구 사용 항목에서 더 큰 규모의 모델들을 능가하는 성과를 보여주었습니다.

模型发布与核心定位

Liquid AI 发布了 LFM2.5-2.6B 开源智能体模型。该模型仅拥有 26 亿参数，旨在满足端侧设备（如智能手机）的本地部署需求，同时具备支持复杂规划、工具调用及多步骤处理的智能体工作流能力。

技术规格与平台支持

  • 预训练数据：基于 34T Token 数据集。
  • 语言兼容性：通过扩展现有分词器增强了对非拉丁字母语言的支持。
  • 发布渠道：在 Hugging Face 平台上提供基础版本和后训练版本。

基准测试表现

LFM2.5-2.6B 在与更大尺寸模型对比时，展现出极高的性价比和性能：

  • 指令执行与工具使用：在几乎所有项目中领先于 gemma-4-E2B-it 和 gemma-4-E4B-it，并与 Qwen3.5-4B、Qwen3.5-9B 表现相近。
  • STEM 领域：在 AA Omniscience 测试中领先，仅在数学测试中落后于 Qwen3.5-9B。
  • 编程能力：这是唯一一个更大尺寸模型仍保持优势的领域。

总结

Liquid AI 推出的 LFM2.5-2.6B 是一个专为端侧部署设计的轻量级智能体模型，在极小的参数规模下实现了强大的工具调用和指令执行能力。该模型在大多数基准测试中表现优异，特别适合需要在移动设备上运行的复杂工作流场景。

製品紹介

AIスタートアップのLiquid AIは、現地時間で昨日、オープンソースのエージェントモデル「LFM2.5-2.6B」を発表しました。26億のパラメータで構成されるLFM2.5-2.6Bは、スマートフォンを含むオンデバイス（on-device）環境に非常に適しており、同時に計画、呼び出し、多段階処理といったエージェントワークフローをサポートするのに十分な性能を備えています。

技術仕様およびプラットフォーム

LFM2.5-2.6Bは34Tのトークンデータセットで事前学習されており、既存のトークナイザー拡張を通じて非ラテン文字言語への対応を強化しています。Liquid AIはHugging Faceプラットフォームにおいて、同モデルのベースバージョンとポストトレーニング（post-training）バージョンの両方を提供しています。

性能比較

Liquid AIが提供したデータによると、LFM2.5-2.6Bはgemma-4-E2B-it、gemma-4-E4B-it、Qwen3.5-4B、Qwen3.5-9Bといったより大規模なモデルとベンチマークテストを実施した際、ほぼすべての指示実行項目およびツール使用プロジェクトにおいてこれらを上回りました。BFCLv4テストにおいてのみ、Qwen3.5-9Bに劣る結果となりました。

LFM2.5-2.6Bはエージェントのタスクにおいて2種類のGemmaモデルよりも優れた性能を示し、Qwenモデルと同等のレベルを記録しました。STEM分野ではAA Omniscienceテストで上回りましたが、数学テストではQwen3.5-9Bに劣りました。プログラミングに関しては、より大規模なモデルが依然として優位に立つ唯一の領域となっています。

総評

LFM2.5-2.6Bは少ないパラメータ数でありながら、スマートフォンなどのオンデバイス環境で強力なエージェントワークフローを実行できる性能を備えています。特に、多様な指示実行やツール使用の項目において、より大規模なモデルを上回る成果を見せました。

まとめ

Liquid AIが発表したLFM2.5-2.6Bは、軽量ながらも高度なエージェント機能を備えたオンデバイス向けに最適化されたモデルです。ベンチマークでは多くの項目で大規模モデルを凌駕しており、特にスマートフォン等のリソース制限のある環境での活用において高いポテンシャルを示しています。

Product Introduction

AI startup Liquid AI released LFM2.5-2.6B, an open-source agent model, yesterday. With 2.6 billion parameters, LFM2.5-2.6B is highly suitable for on-device environments, including smartphones, while providing sufficient performance to support agent workflows such as planning, calling, and multi-step processing.

Technical Specifications & Platform

LFM2.5-2.6B was pre-trained on a massive dataset and features enhanced support for non-Latin languages through tokenizer expansion. Liquid AI provides both the base version and post-training versions of the model on the Hugging Face platform.

  • Pre-trained on 34T token dataset
  • Enhanced non-Latin language support via expanded tokenizer
  • Available in base and post-training versions on Hugging Face

Performance Comparison

According to data provided by Liquid AI, LFM2.5-2.6B outperformed several larger models—including gemma-4-E2B-it, gemma-4-E4B-it, Qwen3.5-4B, and Qwen3.5-9B—in nearly all instruction execution categories and tool usage projects. The model only fell behind Qwen3.5-9B in the BFCLv4 test.

In agent tasks, LFM2.5-2.6B demonstrated superior performance compared to both types of Gemma models and recorded levels similar to the Qwen models. In STEM fields, it outperformed others in the AA Omniscience test but fell behind Qwen3.5-9B in mathematics tests. Programming remains the only area where larger models still maintain an advantage.

Overall Evaluation

LFM2.5-2.6B demonstrates the capability to execute powerful agent workflows in on-device environments like smartphones despite its low parameter count. It notably outperformed larger models across various instruction execution and tool usage metrics.

Summary

Liquid AI has launched LFM2.5-2.6B, an efficient open-source model designed for high-performance agent workflows in on-device environments. Despite its compact size, it excels in instruction following and tool use, outperforming several larger models in key benchmarks.
