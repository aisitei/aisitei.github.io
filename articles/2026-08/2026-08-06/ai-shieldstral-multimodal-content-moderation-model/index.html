가장 강력한 멀티모달 콘텐츠 검토 오픈 소스 AI 모델: Mistral, 단일 16GB GPU에서 구동 가능한 Shieldstral 출시

2026-08-06

모델 출시

Mistral AI는 어제(8월 4일) 콘텐츠 모더레이션용 AI 모델인 Shieldstral을 발표했습니다. 이 모델은 총 3B(30억)의 파라미터를 보유하고 있으며, Apache 2.0 라이선스에 따라 오픈 웨이트로 제공됩니다.

성능 및 사양

해당 모델은 Hugging Face 플랫폼에 공개되었으며, 12개 언어를 지원합니다. 단일 16GB GPU에서 구동이 가능합니다.

Mistral은 이 모델이 콘텐츠 안전 측면에서 7배 더 큰 규모의 오픈 모델과 대등한 성능을 보여주며, 멀티모달 콘텐츠 모더레이션 분야에서 SOTA를 달성했다고 밝혔습니다.

기술적 특징

Mistral에 따르면, 대부분의 보호 모델은 모델 가중치 내에 고정된 위험 범주 체계를 포함합니다. 이 경우 개발자는 사용 시나리오가 변경될 때마다 모델을 재학습시켜야 합니다.

반면 Shieldstral은 모더레이션 정책을 입력 내용에 포함하는 방식을 채택했습니다. 운영자는 '예/아니오' 질문과 함께 평가 시나리오 및 엄격도 설명을 제공할 수 있으며, 모델은 단일 출력 토큰으로부터 조정된 안전 점수를 생성합니다.

입력 구조

모델은 각 모더레이션 작업을 이진 질의응답으로 변환하며, 입력에는 세 개의 태그가 포함된 필드가 포함됩니다.

  • : 평가 시나리오 및 엄격도 설명
  • : "이 콘텐츠가 신체적 폭력을 조장합니까?"와 같은 단일 '예/아니오' 질문
  • : 검토 대상 내용 (프롬프트, 답변, 프롬프트와 답변의 조합 또는 선택적 텍스트가 포함된 이미지)

추론 방식

추론 시 모델은 '예'와 '아니오' 두 토큰의 논리값만 읽어 들인 후, softmax를 통해 연속적인 점수로 정규화하며 0.5를 임계값으로 하여 이진 판단을 출력합니다.

이 메커니즘은 프롬프트 분류, 답변 모더레이션, 거부 응답 감지 및 독성 감지 등을 모두 지원할 수 있습니다.

총평

Mistral AI는 3B 파라미터 규모의 Shieldstral을 통해 효율적인 콘텐츠 모더레이션 기능을 제공하며 멀티모달 분야에서 우수한 성능을 입증했습니다. 특히 정책을 가중치에 고정하는 대신 입력 단계에서 처리함으로써 프롬프트 분류 및 독성 감지 등 다양한 모더레이션 시나리오에 유연하게 대응할 수 있는 구조를 갖추었습니다.

模型发布与核心规格

Mistral AI 发布了名为 Shieldstral 的内容审核 AI 模型。该模型采用开放权重，并基于 Apache 2.0 许可证发布。

  • 参数量：3B（30 亿）
  • 平台支持：已上线 Hugging Face
  • 语言支持：12 种语言
  • 硬件要求：可在单张 16GB GPU 上运行

性能表现

Shieldstral 在内容安全方面的性能媲美规模为 7 倍的开放模型，并在多模态内容审核领域达到 SOTA（最先进）水平。

技术架构与创新

不同于将审核政策固化在权重中的传统模型，Shieldstrral 将审核政策放入输入内容中。这种设计允许开发者在不重新训练模型的情况下，通过调整提示词来适应不同的使用场景。

该模型将每项审核任务转化为二元问答，其输入包含三个核心字段：

  • <Instruct>：说明评估场景和严格程度。
  • <Query>：提出单一的“是或否”问题（例如：“这段内容是否宣传身体暴力？”）。
  • <Document>：提供待审核的内容，包括提示词、回答或包含文本的图像。

在推理过程中，模型通过读取逻辑值并经过 softmax 归一化处理，以 0.5 为阈值输出二元判断。该机制可支持提示词分类、回答审核、拒答检测和毒性检测等多种任务。

总结

Mistral 推出的 Shieldstral 是一个高效的 3B 参数内容审核模型，具备多语言支持且能在较低配置的硬件上运行。其核心优势在于通过动态输入而非权重硬编码来处理审核政策，显著提升了模型的灵活性和在不同场景下的适用性。

モデルのリリース

Mistral AIは昨日（8月4日）、コンテンツモデレーション用のAIモデル「Shieldstral」を発表しました。このモデルは計3Bのパラメータを持ち、Apache 2.0ライセンスのもとでオープンウェイトとして提供されます。

パフォーマンスと仕様

本モデルはHugging Faceプラットフォームで公開されており、12の言語をサポートしています。また、単一の16GB GPUで動作可能です。

Mistral社は、このモデルがコンテンツ安全性の面において7倍大きな規模のオープンモデルに匹敵する性能を示しており、マルチモーダルのコンテンツモデレーション分野においてSOTA（最先端）を達成したと述べています。

技術的特徴

Mistral社によると、従来の多くの保護モデルは、モデルの重みの中に固定されたリスクカテゴリ体系を含んでいます。この場合、開発者は使用シナリオが変わるたびにモデルを再学習させる必要があります。

対照的にShieldstralは、モデレーションポリシーを入力内容に含める手法を採用しています。運用者は「はい/いいえ」の質問とともに、評価シナリオや厳格度の説明を提供することができ、モデルは単一の出力トークンから調整された安全スコアを生成します。

入力構造

モデルは各モデレーションタスクを二項の質疑応答に変換し、入力には以下の3つのタグを含むフィールドが含まれます。

  • ：評価シナリオおよび厳格度の説明
  • ：「このコンテンツは身体的な暴力を助長しますか？」といった単一の「はい/いいえ」の質問
  • ：検証対象の内容（プロンプト、回答、またはそれらの組み合わせや、選択的なテキストを含む画像）

推論方法

推論時、モデルは「はい」と「いいえ」の2つのトークンの論理値を読み取った後、softmaxを通じて連続的なスコアに正規化し、0.5を閾値として二項判断を出力します。

このメカニズムにより、プロンプト分類、回答モデレーション、拒否応答の検知、および毒性（Toxicity）の検知など、あらゆるモデレーションシナリオに対応することが可能です。

総評

Mistral AIは3Bパラメータ規模のShieldstralを通じて、効率的なコンテンツモデレーション機能を提供し、マルチモーダル分野で優れた性能を実証しました。特に、ポリシーを重みに固定するのではなく入力段階で処理することで、プロンプト分類や毒性検知など、多様なモデレーションシナリオに柔軟に対応できる構造を備えています。

まとめ

Mistral AIは、3Bパラメータの軽量ながら高性能なコンテンツモデレーションモデル「Shieldstral」を発表しました。入力段階でポリシーを処理する独自の仕組みにより、マルチモーダル分野でSOTAを達成し、高い柔軟性と効率性を両立しています。

Model Launch

Mistral AI released Shieldstral on August 4th, an AI model specifically designed for content moderation. The model features a total of 3B parameters and is provided as open weights under the Apache 2.0 license.

Performance and Specifications

The model is available on the Hugging Face platform and supports 12 languages. It can be operated on a single GPU with 16GB of VRAM.

Mistral stated that Shieldstral delivers performance comparable to open models seven times its size in terms of content safety, achieving State-of-the-Art (SOTA) results in the field of multimodal content moderation.

Technical Features

According to Mistral, most guardrail models include fixed risk category systems within their weights. In those cases, developers must retrain the model every time a usage scenario changes.

In contrast, Shieldstral adopts a method of including moderation policies directly in the input content. Operators can provide evaluation scenarios and severity descriptions along with "Yes/No" questions, allowing the model to generate a calibrated safety score from a single output token.

Input Structure

The model converts each moderation task into a binary Q&A format, where the input includes fields containing three specific tags:

  • : Evaluation scenario and severity description.
  • : A single "Yes/No" question, such as "Does this content promote physical violence?"
  • : The content to be reviewed (including prompts, responses, combinations of both, or images containing selected text).

Inference Method

During inference, the model reads only the logic values of two tokens—"Yes" and "No"—and then normalizes them into continuous scores via softmax. It outputs a binary judgment using a threshold of 0.5.

This mechanism supports various functions, including prompt classification, response moderation, refusal detection, and toxicity detection.

Overall Evaluation

With the 3B-parameter Shieldstral model, Mistral AI provides efficient content moderation capabilities and demonstrates superior performance in the multimodal field. By processing policies at the input stage rather than fixing them within the weights, the architecture allows for flexible responses to various scenarios such as prompt classification and toxicity detection.

Summary

Mistral AI has released Shieldstral, a 3B-parameter open-weight model designed for efficient multimodal content moderation. By integrating moderation policies into the input rather than hardcoding them into the weights, it provides high flexibility and SOTA performance while remaining runnable on a single 16GB GPU.
