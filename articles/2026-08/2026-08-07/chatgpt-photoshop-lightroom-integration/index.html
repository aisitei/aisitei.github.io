오늘부터 ChatGPT에서 Adobe Photoshop 및 Lightroom을 활용하여 이미지 편집 및 디자인이 가능해집니다.

2026-08-07

협력 범위 확대

IT 소식에 따르면 Adobe는 작년 말 OpenAI의 Apps SDK를 활용해 Photoshop, Acrobat 및 Adobe Express를 ChatGPT에 도입했습니다. 오늘(6일)을 기점으로 협력 범위가 더욱 확장되었으며, 새롭게 출시된 Adobe 플러그인은 자사의 거의 모든 크리에이티브 소프트웨어를 포함합니다.

지원 도구 및 기능

사용자는 플러그인을 설치한 후 ChatGPT 내에서 Photoshop, Premiere, Acrobat, Lightroom, Illustrator 및 InDesign 등 70종 이상의 Adobe 도구를 직접 호출할 수 있습니다.

사용 방법 및 계정 연동

IT 소식의 테스트 결과에 따르면, 사용자는 ChatGPT 설정 메뉴의 플러그인 페이지에서 Adobe 플러그인을 추가할 수 있습니다. 설정을 완료한 후 프롬프트 입력창에 "@Adobe"와 구체적인 작업을 입력하면 해당 도구를 호출할 수 있습니다.

Adobe는 해당 플러그인이 OpenAI의 Codex 프로그래밍 애플리케이션 및 최근 출시된 Work 제품군과 함께 사용할 때 최상의 효과를 낸다고 밝혔습니다. 사용자는 Creative Cloud 계정에 로그인하지 않고도 기본 기능을 사용할 수 있으며, 로그인 시에는 서로 다른 세션 간의 작업 진행 상황을 저장하고 클라우드 파일에 직접 접근할 수 있습니다. 또한, Creative Cloud 계정을 통해 Adobe Firefly가 제공하는 생성형 AI 모델을 호출할 수도 있습니다.

서비스 방향성

Adobe는 사용자가 새로운 플러그인을 통해 사진 편집, 마케팅 영상 제작, PDF 생성 등의 작업을 수행하기를 기대하고 있으며, ChatGPT로 기존의 전문 소프트웨어를 대체할 계획은 없다고 밝혔습니다.

Adobe Firefly 및 에이전트 AI 부사장인 Forrest Ki는 "우리는 사람들이 어디에서 일하든 Adobe의 전문가용 크리에이티브 및 생산성 도구를 사용할 수 있기를 바랍니다. ChatGPT 내의 Adobe 플러그인은 크리에이티브 전문가들이 매일 의존하는 플래그십 애플리케이션의 대체제가 아닙니다. 정밀한 조작과 창작 과정에 대한 완전한 제어가 필요한 경우, 플래그십 애플리케이션은 여전히 더 심도 있는 기능을 제공합니다"라고 설명했습니다.

총평

Adobe는 ChatGPT 내에서 70종 이상의 도구를 활용할 수 있는 플러그인을 출시하여 협력 범위를 대폭 확대했습니다. 이 기능은 사용자의 편의성과 생산성을 높이는 보조 도구로 설계되었으며, 정밀한 작업이 필요한 경우에도 기존의 플래그십 소프트웨어와 상호 보완적인 관계를 유지합니다.

合作范围扩大

Adobe 进一步扩展了与 OpenAI 的合作，通过 Apps SDK 将旗下几乎整套创意软件引入 ChatGPT。新推出的 Adobe 插件涵盖了大量工具，旨在让用户在对话界面中更便捷地调用创作功能。

支持的工具列表

用户安装插件后，可以直接在 ChatGPT 中调用以下核心工具：

  • Photoshop
  • Premiere
  • Acrobat
  • Lightroom
  • Illustrator
  • InDesign
  • 以及其他 70 多款 Adobe 工具

功能与使用细节

用户可以通过 ChatGPT 设置菜单添加插件，并在提示词中输入“@Adobe”配合具体任务来调用相关工具。该插件在与 OpenAI 的 Codex 编程应用及 Work 套件配合时效果最佳。

关于账户权限与功能：

  • 未登录 Creative Cloud 账户仍可使用基本功能。
  • 登录后可保存不同会话中的工作进度，并直接访问云端文件。
  • Creative Cloud 账户还可用于调用 Adobe Firefly 提供的生成式 AI 模型。

产品定位与目标

Adobe 希望用户通过新插件完成照片编辑、营销视频制作和 PDF 生成等任务。官方明确表示，ChatGPT 中的插件并非旨在取代现有的专业旗舰应用；对于需要精确操作和充分掌控创作过程的专业需求，仍需使用功能更深入的旗舰软件。

总结

Adobe 扩展了与 OpenAI 的合作，将包含 Photoshop、Premiere 等在内的 70 多款工具集成至 ChatGPT 中。此举旨在通过插件提供便捷的生产力工具，但官方强调这些功能并非要取代专业级的创意旗舰软件。

提携範囲の拡大

ITニュースによると、Adobeは昨年末にOpenAIのApps SDKを活用し、Photoshop、Acrobat、およびAdobe ExpressをChatGPTに導入しました。本日（6日）をもってその協力範囲がさらに拡大され、新たにリリースされたAdobeプラグインは同社のほぼすべてのクリエイティブソフトウェアを網羅するようになっています。

対応ツールと機能

ユーザーはプラグインをインストールした後、ChatGPT内で以下のツールを含む70以上のAdobe製品を直接呼び出すことができます。

  • Photoshop
  • Premiere
  • Acrobat
  • Lightroom
  • Illustrator
  • InDesign

使用方法とアカウント連携

ITニュースのテスト結果によると、ユーザーはChatGPTの設定メニュー内にあるプラグインページからAdobeプラグインを追加できます。設定完了後、プロンプト入力欄に「@Adobe」と具体的なタスクを入力することで、該当するツールを呼び出すことが可能です。

Adobeは、このプラグインがOpenAIのCodexプログラミングアプリケーションや最近リリースされたWork製品群と併用した際に最高の効果を発揮すると述べています。ユーザーはCreative Cloudアカウントにログインせずに基本機能を利用でき、ログインすることで異なるセッション間での作業進捗の保存やクラウドファイルへの直接アクセスが可能になります。また、Creative Cloudアカウントを通じてAdobe Fireflyが提供する生成AIモデルを呼び出すことも可能です。

サービスの方向性

Adobeは、ユーザーが新しいプラグインを通じて写真編集、マーケティング動画制作、PDF作成などの作業を行うことを期待していますが、ChatGPTで既存の専門ソフトウェアを置き換える計画はないと明かしています。

Adobe FireflyおよびエージェントAI担当副社長のForrest Ki氏は次のように説明しています。「私たちは、ユーザーがどこで働いていてもAdobeのプロフェッショナル向けクリエイティブおよび生産性ツールを利用できるようにしたいと考えています。ChatGPT内のAdobeプラグインは、クリエイティブな専門家が日々依存しているフラッグシップアプリケーションの代替品ではありません。精密な操作や制作過程に対する完全な制御が必要な場合には、依然としてフラッグシップアプリケーションがより高度な機能を提供します。」

まとめ

AdobeはChatGPT内で70以上のツールを活用できるプラグインをリリースし、提携範囲を大幅に拡大しました。この機能はユーザーの利便性と生産性を高めるための補助的なツールとして設計されており、精密な操作が必要な場合には既存のフラッグシップソフトウェアと補完的な関係を維持します。

Expanding Collaboration Scope

According to IT news, Adobe integrated Photoshop, Acrobat, and Adobe Express into ChatGPT using OpenAI's Apps SDK late last year. As of today (the 6th), the scope of this collaboration has expanded further, with a newly released Adobe plugin now encompassing nearly all of the company's creative software.

Supported Tools and Features

After installing the plugin, users can directly call over 70 Adobe tools within ChatGPT, including:

  • Photoshop
  • Premiere
  • Acrobat
  • Lightroom
  • Illustrator
  • InDesign

Usage and Account Integration

According to tests conducted by IT news, users can add the Adobe plugin through the "Plugins" page in the ChatGPT settings menu. Once configured, users can invoke specific tools by entering "@Adobe" followed by a description of the task in the prompt input field.

Adobe stated that the plugin performs best when used alongside OpenAI's Codex programming applications and the recently released Work suite. Users can access basic features without logging into a Creative Cloud account; however, logging in allows users to save progress across different sessions and gain direct access to cloud files. Additionally, users with a Creative Cloud account can call generative AI models provided by Adobe Firefly.

Service Direction

Adobe expects users to utilize the new plugin for tasks such as photo editing, marketing video production, and PDF creation, but clarified that it has no plans to replace existing professional software with ChatGPT.

Forrest Ki, Vice President of Adobe Firefly and Agent AI, explained: "We want people to be able to use Adobe's professional creative and productivity tools wherever they work. The Adobe plugin within ChatGPT is not a replacement for the flagship applications that creative professionals rely on every day. For cases requiring precise manipulation and full control over the creative process, flagship applications still offer more in-depth features."

Overall Review

Adobe has significantly expanded its cooperation by releasing a plugin that allows users to utilize over 70 tools within ChatGPT. This feature is designed as an auxiliary tool to enhance user convenience and productivity while maintaining a complementary relationship with existing flagship software for tasks requiring high precision.

Summary

Adobe has launched a new plugin integrating over 70 of its creative tools into ChatGPT to improve accessibility and workflow for users. While the integration provides convenient shortcuts for common tasks like photo editing and video production, Adobe emphasizes that it is intended as a complementary tool rather than a replacement for its flagship professional software.
