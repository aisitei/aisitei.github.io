Apple 📱 스마트폰

마이크로소프트의 요청에 따라 Apple이 유럽에서 iPhone과 Windows 간 기기 간 복사 및 붙여넣기 기능을 출시할 계획입니다.

2026-08-05

기능 개요

Apple은 향후 iPhone과 Windows PC 간의 크로스 디바이스 복사 및 붙여넣기 기능을 지원하는 새로운 기능을 개발 중입니다.

도입 배경

이 기능은 Microsoft가 Apple을 통해 제출한 유럽 상호운용성 신청 메커니즘에서 비롯되었습니다. Apple은 유럽의 디지털 시장법(DMA) 요건을 준수하기 위해 해당 요청을 수용했으며, 올해 3월부터 검토를 시작해 6월 26일 프로젝트 실행 방안을 제출했습니다.

기능 상세

Microsoft에 따르면 이 기능은 사용자가 iPhone에서 복사한 텍스트나 기타 지원되는 콘텐츠를 Windows PC에 직접 붙여넣을 수 있게 하며, 반대 방향의 작업도 지원합니다. Microsoft는 특정 앱으로 전환하거나 매번 수동으로 전송을 실행할 필요 없이, 클립보드 동기화가 지속적이고 가벼운 시스템 기능으로 작동하기를 희망하고 있습니다.

구현 방식

이 요구사항에 대해 Apple이 제시한 방안은 iPhone과 페어링된 외부 기기(예: Windows PC) 간의 클립보드 내용 공유 및 가져오기를 허용하는 것입니다. 이 방식은 iOS 26.5에서 유럽 시장을 위해 도입된 서드파티 웨어러블 기기용 "액세서리 알림(Accessory Notifications)" 기능과 유사합니다. 사용자는 페어링된 각 기기에 iPhone 클립보드 접근을 허용하는 일회성 권한을 부여해야 합니다.

Apple은 개발자가 AccessorySetupKit를 통합하여 사용자가 관련 권한 절차를 완료하고, 이를 통해 클립보드 내용이 페어링된 기기와 공유될 수 있도록 해야 한다고 밝혔습니다. 해당 기능을 지원하는 모든 기기에서 사용자는 일회성 권한 확인을 거쳐야 합니다.

현재 상황 및 한계

현재 서드파티 앱은 전면에 실행될 때만 iPhone 클립보드 내용에 접근할 수 있으며, 매번 복사 또는 붙여넣기 시마다 접근 권한을 부여받아야 합니다. 반면 Apple 기기 간에는 이미 "공통 클립보드(Universal Clipboard)" 기능이 지원되어 iPhone, iPad, Mac 사이에서 크로스 디바이스 복사 및 붙여넣기가 가능합니다.

Microsoft는 현재의 제한적인 클립보드 접근 방식이 앱이 백그라운드에서 지속적으로 iPhone과 PC 또는 기타 연결된 기기 간의 클립보드 내용을 동기화하는 것을 방해하여 사용자 경험에 부정적인 영향을 미친다고 판단하고 있습니다.

출시 일정 및 지역

Apple은 이 기능을 구현하기 위해 상당한 엔지니어링 작업이 필요하며, 2027년 가을에 개발 완료를 예상하고 있습니다. 이후 개발자 베타 버전을 통해 검증을 거친 후 일반 대중에게 공개될 예정입니다. 개발이 원활하게 진행될 경우, 일반 사용자는 2028년 초에 이 기능을 공식적으로 사용할 수 있을 것으로 보입니다.

해당 기능은 초기에는 유럽 지역의 iPhone 및 Windows 사용자에게만 제공될 예정이나, 향후 전 세계 시장으로 확장될 가능성도 있습니다.

추가 정보

최근 몇 년간 Apple은 디지털 시장법(DMA)에 따라 개발된 일부 기능을 전 세계로 확대해 왔습니다. 예를 들어 iPhone에서 Android 휴대폰으로의 eSIM 이전이나, Android와 iPhone 간의 편리한 데이터 이동 기능 등이 포함됩니다. 반면 서드파티 웨어러블 기기의 AirPods와 유사한 페어링 경험 및 알림 전달 기능 등은 현재 유럽 지역에만 제한적으로 제공되고 있습니다.

총평

Apple은 Microsoft의 요청과 EU 디지털 시장법(DMA) 준수를 위해 iPhone과 Windows PC 간의 크로스 디바이스 클립보드 동기화 기능을 개발 중입니다. 이 기능은 2027년 가을에 개발 완료를 목표로 하며, 초기에는 유럽 지역에서 우선 제공되나 향후 글로벌 확장 가능성이 있습니다.

跨设备剪贴板功能

Apple 正在开发一项新功能，旨在支持 iPhone 与 Windows PC 之间的内容复制与粘贴。该功能将允许用户在两个系统之间直接传输文本或其他受支持的内容，无需切换特定应用或手动发起复杂的传输操作。

合作背景与动机

此项功能的源头是 Microsoft 通过 Apple 为欧盟《数字市场法案》（DMA）建立的互操作性申请机制提出的请求。Microsoft 希望将剪贴板同步转变为一种持续运行、轻量化的系统能力，而非依赖于特定应用的手动功能。

技术实现与授权

Apple 计划通过 AccessorySetupKit 框架来实现此项功能。用户需要为每台已配对的设备授予一次性权限来访问 iPhone 的剪贴板内容，这一逻辑与 iOS 26.5 中针对欧盟市场的“配件通知”功能类似。

  • 技术架构：接入 AccessorySetupKit 以处理授权流程。
  • 当前限制：目前第三方应用仅在前台运行时可读取剪贴板，且每次操作需手动授权。
  • 对比优势：旨在提供类似于 Apple 自家设备“通用剪贴板”的流畅体验。

发布时间与范围

由于涉及大量的工程开发工作，该功能预计于 2027 年秋季完成开发并进入开发者测试阶段。如果进度顺利，普通用户最快可能在 2028 年初正式使用。

  • 首发区域：初期仅面向欧盟地区的 iPhone 和 Windows 用户。
  • 全球推广：Apple 未来可能会将该功能扩展至全球市场。

总结

Apple 受 Microsoft 的推动，正开发支持 iPhone 与 Windows PC 跨设备剪贴板同步的功能。该功能预计于 2027 年完成开发并于 2028 年初在欧盟率先推出，旨在通过 AccessorySetupKit 提供更便捷的系统级交互体验。

機能概要

Appleは、今後iPhoneとWindows PCの間でクロスデバイスなコピー＆ペースト機能をサポートする新機能を開発中です。

導入の背景

この機能は、MicrosoftがAppleを通じて提出した欧州の相互運用性申請メカニズムに端を発しています。Appleは欧州のデジタル市場法（DMA）の要件を遵守するためこの要求を受け入れ、今年3月から検討を開始し、6月26日にプロジェクトの実施計画を提出しました。

機能の詳細

Microsoftによると、この機能によりユーザーはiPhoneでコピーしたテキストやその他のサポートされるコンテンツをWindows PCに直接貼り付けることが可能になり、逆方向の操作もサポートされます。Microsoftは、特定のアプリに切り替えたり、毎回手動で転送を実行したりすることなく、クリップボード同期が継続的かつ軽量なシステム機能として動作することを求めています。

実装方法

この要求に対し、Appleが提示した案は、iPhoneとペアリングされた外部デバイス（例：Windows PC）間でクリップボードの内容を共有およびインポートすることを許可するものです。この手法は、iOS 26.5で欧州市場向けに導入されたサードパーティ製ウェアラブルデバイス向けの「アクセサリ通知（Accessory Notifications）」機能と類似しています。ユーザーはペアリングされた各デバイスに対して、iPhoneのクリップボードへのアクセスを許可する一回限りの権限を付与する必要があります。

Appleは、開発者がAccessorySetupKitを統合することで、ユーザーが関連する権限プロセスを完了し、それを通じてクリップボードの内容がペアリングされたデバイスと共有されるようにする必要があることを明らかにしました。この機能をサポートするすべてのデバイスにおいて、ユーザーは一回限りの権限確認を行う必要があります。

現在の状況と制限

現在、サードパーティ製アプリは前面で実行されている場合にのみiPhoneのクリップボード内容にアクセスでき、コピーまたは貼り付けのたびにアクセス権限を付与される必要があります。一方、Appleデバイス間ではすでに「ユニバーサルクリップボード（Universal Clipboard）」機能がサポートされており、iPhone、iPad、Macの間でクロスデバイスなコピー＆ペーストが可能です。

Microsoftは、現在の制限的なクリップボードアクセス方法が、アプリがバックグラウンドで継続的にiPhoneとPCまたはその他の接続されたデバイス間でクリップボード内容を同期することを妨げ、ユーザー体験に悪影響を与えていると判断しています。

リリーススケジュールと地域

Appleはこの機能を実装するために多大なエンジニアリング作業を必要としており、2027年秋に開発完了を見込んでいます。その後、開発者ベータ版を通じて検証を経てから一般公開される予定です。開発が順調に進めば、一般ユーザーは2028年初頭にこの機能を公式に使用できるようになると見込まれます。

この機能は初期段階では欧州地域のiPhoneおよびWindowsユーザー向けに提供される予定ですが、将来的に世界市場へ拡大される可能性があります。

追加情報

近年、Appleはデジタル市場法（DMA）に従って開発された一部の機能を世界に展開してきました。例えば、iPhoneからAndroidスマートフォンへのeSIM移行や、AndroidとiPhone間のスムーズなデータ移行機能などが含まれます。一方で、サードパーティ製ウェアラブルデバイスのAirPodsと同様のペアリング体験や通知転送機能などは、現在欧州地域に限定して提供されています。

総評

AppleはMicrosoftの要請とEUデジタル市場法（DMA）への準拠のため、iPhoneとWindows PC間のクロスデバイスなクリップボード同期機能を開発中です。この機能は2027年秋の開発完了を目指しており、当初は欧州地域で優先提供されますが、将来的なグローバル展開の可能性も備えています。

Feature Overview

Apple is currently developing a new feature that will support cross-device copy and paste functionality between iPhones and Windows PCs.

Background

This initiative originated from Microsoft’s request through the European interoperability mechanism. To comply with the requirements of the European Digital Markets Act (DMA), Apple accepted the request, began reviewing it in March, and submitted a project implementation plan on June 26.

Feature Details

According to Microsoft, this feature will allow users to copy text or other supported content on an iPhone and paste it directly onto a Windows PC, with support for the reverse operation as well. Microsoft aims for clipboard synchronization to function as a continuous, lightweight system feature, eliminating the need for users to switch to specific apps or manually trigger a transfer every time.

Implementation Method

Apple’s proposed solution involves allowing the sharing and importing of clipboard content between an iPhone and paired external devices (e.g., Windows PCs). This method is similar to the "Accessory Notifications" feature introduced in iOS 26.5 for third-party wearable devices in the European market. Users will need to grant a one-time permission to allow each paired device to access the iPhone's clipboard.

Apple stated that developers must integrate AccessorySetupKit so that users can complete the necessary authorization procedures, enabling clipboard content to be shared with paired devices. This one-time permission check will be required on all devices supporting the feature.

Current Status and Limitations

Currently, third-party apps can only access iPhone clipboard content when they are running in the foreground, and they must be granted permission every time a copy or paste action occurs. In contrast, Apple devices already support "Universal Clipboard," which enables seamless cross-device copy and paste between iPhones, iPads, and Macs.

Microsoft has determined that the current restricted method of clipboard access hinders the ability of apps to continuously sync clipboard content between an iPhone and a PC or other connected devices in the background, which negatively impacts the user experience.

Release Schedule and Region

Apple noted that significant engineering work is required to implement this feature, with development expected to be completed in the fall of 2027. Following completion, it will undergo verification through developer beta versions before being released to the general public. If development proceeds smoothly, the feature is expected to be officially available to general users in early 2028.

While the feature is initially slated for iPhone and Windows users in the European region, there is a possibility of expansion to global markets in the future.

Additional Information

In recent years, Apple has expanded several features developed under the Digital Markets Act (DMA) to the global market. These include eSIM transfers from iPhones to Android phones and convenient data migration tools between Android and iPhone. Conversely, certain features—such as pairing experiences and notification delivery for third-party wearables similar to AirPods—remain limited to the European region.

Summary

Apple is developing a cross-device clipboard synchronization feature between iPhones and Windows PCs to comply with EU Digital Markets Act (DMA) requirements. The project aims to provide seamless copy-paste functionality, with an expected public release in early 2028 starting in Europe. While the initial rollout is regional, there is potential for global expansion following successful development and testing.
