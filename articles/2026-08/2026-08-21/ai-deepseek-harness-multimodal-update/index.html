DeepSeek Harness, 멀티모달 지원 업데이트 및 V4 비주얼 버전 공개

2026-08-21

DeepSeek Harness 업데이트

DeepSeek Harness가 출시 7일 만에 버전 업데이트를 진행했습니다. 최신 버전은 멀티모달 지원을 강화하여 DeepSeek 모델 어댑터가 기본 이미지 요청을 활성화하도록 구성할 수 있습니다.

아직 DeepSeek v4 모델의 비전 지원 버전은 출시되지 않았습니다.

하지만 타사 비전 지원 모델로 교체한 경우, 설정에서 수동으로 활성화할 수 있습니다.

다른 관점에서 보면, 이는 DeepSeek 자체 비전 모델이 향후 출시될 것이라는 일종의 스포일러일까요?

관련 변경 사항으로, 기존에는 순수 텍스트만 처리할 수 있었던 /goal, /plan 등의 명령어가 이제 이미지를 첨부하여 전송할 수 있게 되었습니다.

@ 멘션의 참조 범위도 파일에서 이전 대화로 확장되었습니다.

즉, 한 번의 질문에 스크린샷, 로컬 파일, 이전 대화를 동시에 첨부할 수 있습니다.

멀티모달 지원을 위한 기반 작업은 지난 업데이트에서 이미 완료되었습니다.

이제 MCP와 ACP는 이미지 첨부 파일을 영구적으로 저장할 수 있으며, 첨부 파일은 단일 호출이 끝나도 사라지지 않습니다. 또한 PTC Mode는 중첩된 이미지를 전달할 수 있습니다.

이미지가 워크플로우에 추가될 때 가장 흔히 발생하는 두 가지 버그도 이번 업데이트에서 함께 수정되었습니다.

  • 이미지 크기가 너무 커서 모델 요청이 실패하는 문제
  • 다중 대화에서 이전 이미지 누적 페이로드가 너무 높아 요청이 실패하는 문제

Codex 및 기타 개선 사항

새 버전에서는 Claude Code와 Codex가 더 이상 본체와 함께 배포되지 않고, 필요에 따라 설치하는 Profile Bundle로 변경되었습니다.

Codex 지원에는 두 가지 새로운 기능이 추가되었습니다. 하나는 비대화형 권한 모드로, 무인 프로세스에서 실행될 수 있도록 합니다. 다른 하나는 다중 이름 인스턴스로, 여러 개의 다른 구성과 이름을 가진 Codex 서브 에이전트가 동시에 존재할 수 있도록 합니다.

서브 에이전트의 "리턴 경로"도 변경되었습니다. 이제 reportDelivery는 부모 작업에 즉시 피드백을 제공하고 깨울 수 있으므로, 부모 작업이 서브 작업 종료를 감지하기 위해 기다릴 필요가 없습니다.

동일한 최적화 배치에는 web_search의 동시 쿼리 지원도 포함됩니다.

Windows PTY 터미널에는 영구 PowerShell 세션 지원이 추가되었으며, 미니멀리스트 모드 프리셋에서 기본적으로 활성화됩니다. 미니멀리스트 모드 자체는 영구 bash와 파일 편집기 두 가지 도구만 유지합니다.

SQLite 백엔드의 읽기/쓰기 및 포크 성능이 향상되었고, 저장 공간도 줄어들었지만, 데이터 구조는 이전 버전과 호환되지 않습니다.

마지막으로, "DeepSeek Harness"는 이제 등록 상표이며, 자세한 내용은 브랜드 사용 가이드라인 문서를 참조하십시오.

총평

DeepSeek Harness는 최신 업데이트를 통해 멀티모달 지원을 대폭 강화하여 이미지 첨부 및 이전 대화 참조 기능을 개선했습니다. Codex 서브 에이전트의 기능 확장과 성능 최적화도 이루어졌으며, 이는 향후 DeepSeek의 비전 모델 출시 가능성을 시사합니다.

DeepSeek 模型与多模态功能

  • DeepSeek Harness 更新，增强多模态支持，适配器支持配置启用原生图片请求。
  • 虽然 DeepSeek v4 目前尚未发布视觉版本，但用户可手动在配置中开启第三方支持视觉的模型。
  • 功能扩展：`/goal`、`/plan` 等命令现可带图发送；引用范围从文件扩展到历史会话，支持单次提问同时包含截图、本地文件和过往对话。

基础设施与后端优化

  • MCP 与 ACP 支持持久化图片附件（不再随单次调用结束而消失），并支持 PTC Mode 转发嵌套图片。
  • 修复了因图片尺寸过大或多轮对话中历史图片累计载荷过高导致的请求失败问题。
  • `web_search` 功能现已支持并发查询。

Codex 与工具链更新

  • Claude Code 和 Codex 不再随主体分发，改为按需安装的 Profile Bundle。
  • Codex 新增非交互权限模式（支持无人值守流程）及多命名实例功能，允许同时存在多个配置不同的子智能体。
  • 优化了子智能体的“回报路径”，`reportDelivery` 可及时反馈并唤醒父任务。

系统性能与品牌信息

  • Windows PTY 终端增加持久 PowerShell 会话支持，并在极简模式预设中默认开启。
  • SQLite 后端优化：提升了读写和分叉性能，降低了存储体积（注意数据结构与旧版不兼容）。
  • “DeepSeek Harness”现已成为注册商标。

总结

DeepSeek Harness 本次更新重点强化了多模态交互能力，包括图片持久化、多维度内容合并提问以及相关 Bug 修复。同时对 Codex 工具链进行了模块化拆分与功能增强，并优化了底层数据库性能和终端兼容性。

DeepSeek Harnessのアップデート

DeepSeek Harnessがリリースからわずか7日でバージョンアップを実施しました。最新バージョンではマルチモーール対応が強化され、DeepSeekモデルのアダプターでデフォルトの画像リクエストを有効にできるようになります。

現時点でDeepSeek v4のビジョン対応版はまだ公開されていません。

しかし、サードパーティ製のビジョン対応モデルに置き換えた場合は、設定から手動で有効にすることが可能です。

別の視点で見れば、これは将来的にDeepSeek独自のビジョンモデルがリリースされることを示唆する一種の「ネタバレ」とも捉えられます。

その他の変更点として、従来はテキストのみを処理可能だった /goal や /plan などのコマンドにおいて、画像を添付して送信できるようになりました。

@メンションの参照範囲も、ファイルから過去の会話へと拡張されました。

つまり、一度の質問でスクリーンショット、ローカルファイル、そして過去の会話を同時に添付することが可能になります。

マルチモーダル対応のための基盤作業は前回のアップデートですでに完了していました。

現在、MCPとACPは画像添付ファイルを永続的に保存でき、単一の呼び出しが終わっても消去されません。また、PTCモードではネストされた画像を転送できます。

ワークフローに画像が追加される際によく発生していた2つのバグも今回のアップデートで修正されました。

  • 画像サイズが大きすぎてモデルへのリクエストに失敗する問題
  • マルチターン対話において、過去の画像の累積ペイロードが高くなりリクエストに失敗する問題

Codexおよびその他の改善事項

新バージョンでは、Claude CodeとCodexが本体に同梱されず、必要に応じてインストールする「Profile Bundle」に変更されました。

Codexのサポートには2つの新機能が追加されています。一つは非対話型権限モードで、無人プロセスでの実行を可能にします。もう一つはマルチネームインスタンスで、異なる構成と名前を持つ複数のCodexサブエージェントを同時に存在させることができます。

サブエージェントの「リターンパス」も変更されました。reportDeliveryが親タスクに即座にフィードバックを提供し起動するため、親タスクはサブタスクの終了を待つ必要がありません。

同じ最適化セットには、web_searchの同時クエリ対応も含まれています。

Windows PTYターミナルには永続的なPowerShellセッションのサポートが追加され、ミニマリストモードのプリセットでデフォルトで有効になります。ミニマリストモード自体は、永続的なbashとファイルエディタの2つのツールのみを保持します。

SQLiteバックエンドの読み書きおよびフォーク性能が向上し、ストレージ容量も削減されましたが、データ構造は以前のバージョンとは互換性がありません。

最後に、「DeepSeek Harness」は登録商標となり、詳細はブランド使用ガイドラインを参照してください。

まとめ

DeepSeek Harnessの最新アップデートでは、マルチモーダル対応の強化により画像添付や過去の会話参照機能が大幅に改善されました。Codexサブエージェントの機能拡張とシステム全体のパフォーマンス最適化も行われており、今後のDeepSeek独自のビジョンモデルのリリースを予感させる内容となっています。

DeepSeek Harness Update

The DeepSeek Harness received a version update just seven days after its initial release. The latest version enhances multimodal support, allowing DeepSeek model adapters to be configured to enable default image requests.

While the vision-supported version of the DeepSeek v4 model has not been released yet, users can manually enable it in the settings if they switch to a third-party vision-supported model. From another perspective, this could be seen as a hint that an official DeepSeek vision model will be released in the future.

Regarding functional changes, commands such as /goal and /plan, which were previously limited to plain text, can now be sent with image attachments. Additionally, the scope of @ mentions has been expanded from files to include previous conversations. This allows users to attach screenshots, local files, and past dialogue simultaneously in a single query.

The foundational work for multimodal support was completed in the previous update. Now, MCP and ACP can permanently store attached images, which will no longer disappear after a single call ends. Furthermore, PTC Mode now supports nested images.

Two common bugs that occur when adding images to workflows were also addressed in this update:

  • Issues where model requests failed due to excessively large image sizes.
  • Request failures caused by high payload from accumulated previous images in multi-turn conversations.

Codex and Other Improvements

In the new version, Claude Code and Codex are no longer bundled with the main body; they have been moved to Profile Bundles that can be installed as needed.

Two new features were added for Codex support: a non-interactive permission mode, which allows execution in unmanned processes, and multi-name instances, allowing multiple sub-agents with different configurations and names to exist simultaneously.

The "return path" for sub-agents has also been modified. Since reportDelivery now provides immediate feedback and can wake the parent task, the parent task no longer needs to wait to detect the completion of a sub-task.

This optimization batch also includes support for concurrent queries in web_search.

The Windows PTY terminal now supports permanent PowerShell sessions, which are enabled by default in the minimalist mode preset. The minimalist mode itself maintains only two tools: persistent bash and a file editor.

Read/write and fork performance for the SQLite backend have been improved, and storage requirements have been reduced; however, the data structure is not backward compatible with previous versions.

Finally, "DeepSeek Harness" is now a registered trademark; please refer to the brand usage guidelines document for more details.

Summary

The latest DeepSeek Harness update significantly enhances multimodal capabilities by enabling image attachments and expanding context for mentions. It also introduces significant optimizations for Codex sub-agents and infrastructure, potentially signaling the upcoming launch of a native vision model.
