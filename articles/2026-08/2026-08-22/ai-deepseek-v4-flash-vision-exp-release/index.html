DeepSeek V4-Flash-Vision-Exp 출시: 멀티모달 API 서비스 시작, 에이전트 기능 Opus-4.8에 근접

2026-08-22

DeepSeek-V4-Flash-Vision-Exp 모델 출시

DeepSeek은 새로운 멀티모달 시각 이해 모델인 DeepSeek-V4-Flash-Vision-Exp를 DeepSeek API 플랫폼에 출시했다고 발표했습니다.

이 모델은 텍스트 외에 이미지 입력을 지원하며, 모델이 이미지를 설명하고, 스크린샷의 텍스트를 인식하고, 차트를 분석하는 등의 작업을 수행할 수 있도록 합니다. 지원되는 이미지 형식에는 JPEG, PNG, GIF, WebP가 포함됩니다.

DeepSeek은 V4-Flash-Vision-Exp가 다양한 Agent 프레임워크 내에서 우수한 멀티모달 적응 능력을 보여주었으며, 다양한 Agent 도구를 활용하여 더 많은 실용적인 작업 시나리오를 구현하는 데 효과적으로 기여할 수 있다고 밝혔습니다.

이 모델은 실험적인 모델이며, 사용자는 model='deepseek-v4-flash-vision-exp'를 설정하여 이 모델에 접근할 수 있습니다.

성능

DeepSeek-V4-Flash-Vision-Exp는 순수 텍스트 능력(Agent, 추론, 세계 지식 등) 면에서 DeepSeek-V4-Flash 정식 버전과 동등합니다. 시각 이해가 필요한 Agent 벤치마크에서는 DeepSeek-V4-Flash 대비 크게 향상되었으며, 멀티모달 Agent 능력은 Opus-4.8에 근접합니다.

API 접근 및 요금

사용자는 model='deepseek-v4-flash-vision-exp'를 설정하여 V4-Flash-Vision-Exp 모델의 API에 접근할 수 있습니다. API 서비스에서 이미지는 토큰으로 변환된 후 토큰 단위로 요금이 부과됩니다. 이미지 한 장은 최대 384 토큰을 차지하며, 요금은 V4-Flash 모델과 동일합니다.

멀티모달 API는 Chat Completions, Messages, Responses 세 가지 형식의 호출을 지원하여 다양한 Agent 도구에 쉽게 통합될 수 있습니다. 이미지와 텍스트 혼합 입력을 지원하며, base64 인라인, 외부 URL, Files API 세 가지 이미지 전송 방식을 지원합니다.

Files API는 현재 개방되어 있으며, 이 API는 무료입니다. 사용자는 먼저 이미지를 플랫폼에 업로드한 후 요청에서 file_id를 통해 참조하여 요청 대역폭을 절약할 수 있습니다(동일한 이미지를 여러 요청에서 반복적으로 업로드할 필요 없음).

총평

DeepSeek의 새로운 DeepSeek-V4-Flash-Vision-Exp 모델은 텍스트와 이미지 입력을 모두 처리하는 멀티모달 시각 이해 기능을 제공합니다. 이 실험적인 모델은 기존 DeepSeek-V4-Flash의 텍스트 처리 능력과 동등하며, 시각 이해 기반 Agent 작업에서 크게 향상된 성능을 보여줍니다. API를 통해 접근 가능하며, 다양한 이미지 형식과 전송 방식을 지원하여 여러 Agent 프레임워크에 쉽게 통합될 수 있습니다.

模型发布信息

  • DeepSeek 官方宣布推出全新的多模态视觉理解模型 DeepSeek-V4-Flash-Vision-Exp，并已上线 DeepSeek API 平台。
  • 该模型目前处于实验性质，用户可通过设置 model='deepseek-v4-flash-vision-exp' 进行访问。

多模态功能支持

  • DeepSeek-V4-Flash-Vision-Exp 支持在文本之外输入图片，具备描述图片、识别截图文字及分析图表等能力。
  • 支持的图片格式包括 JPEG、PNG、GIF 和 WebP。

性能表现对比

  • 在纯文本能力（Agent、推理、世界知识等）方面，DeepSeek-V4-Flash-Vision-Exp 与 DeepSeek-V4-Flash 正式版持平。
  • 在需要视觉理解的 Agent Benchmark 上，该模型较 DeepSeek-V4-Flash 有大幅跃升，多模态 Agent 能力已接近 Opus-4.8。

API 调用与计费规则

  • 在 API 服务中，图片将转换为 token 后按量计费，每张图片最多占用 384 tokens。
  • 该模型的计费价格与 V4-Flash 模型保持一致。

开发工具集成支持

  • 多模态 API 支持 Chat Completions、Messages、Responses 三种格式调用，便于接入各类 Agent 工具。
  • 支持三种图片传入方式：base64 内联、外部 URL 以及 Files API。
  • Files API 已开放且不收费，允许用户预先上传图片并使用 file_id 引用，从而在多个请求中节省带宽。

总结

DeepSeek 推出的 DeepSeek-V4-Flash-Vision-Exp 是一个兼具强劲文本能力与卓越视觉理解能力的实验性多模态模型。该模型通过丰富的 API 支持和 Files API 功能，旨在为各类 Agent 框架提供更高效的工具适配和工作场景支持。

DeepSeek-V4-Flash-Vision-Exp モデルのリリース

DeepSeekは、新しいマルチモーダル視覚理解モデル「DeepSeek-V4-Flash-Vision-Exp」をDeepSeek APIプラットフォームで公開したと発表しました。

このモデルはテキストに加えて画像入力をサポートしており、画像の描写、スクリーンショット内のテキスト認識、チャートの分析などのタスクを実行することが可能です。対応している画像形式には、JPEG、PNG、GIF、WebPが含まれます。

DeepSeekは、V4-Flash-Vision-Expが多様なAgentフレームワークにおいて優れたマルチモーダル適応能力を示しており、様々なAgentツールを活用することで、より実用的なタスクシナリオを構築する際に効果的に貢献できると述べています。

このモデルは実験的なものであり、ユーザーは model='deepseek-v4-flash-vision-exp' を設定することでアクセスすることが可能です。

パフォーマンス

DeepSeek-V4-Flash-Vision-Expは、純粋なテキスト能力（Agent、推論、世界知識など）において、DeepSeek-V4-Flashの正式版と同等の性能を備えています。視覚理解を必要とするAgentベンチマークではDeepSeek-V4-Flashを大幅に上回り、マルチモーダルAgent能力はOpus-4.8に匹敵します。

APIアクセスと料金

ユーザーは model='deepseek-v4-flash-vision-exp' を設定することで、V4-Flash-Vision-ExpモデルのAPIを利用できます。APIサービスにおいて画像はトークンに変換され、トークン単位で課金されます。1枚の画像につき最大384トークンを消費し、料金体系はV4-Flashモデルと同一です。

マルチモーダルAPIはChat Completions、Messages、Responsesの3つの呼び出し形式をサポートしており、さまざまなAgentツールへの統合が容易です。また、画像とテキストの混合入力をサポートし、base64インライン、外部URL、Files APIの3種類の画像転送方法に対応しています。

Files APIは現在公開されており、このAPI自体は無料です。ユーザーはあらかじめ画像をプラットフォームにアップロードし、リクエスト内でfile_idを参照することで帯域幅を節約できます（同じ画像を複数のリクエストで繰り返しアップロードする必要がありません）。

まとめ

DeepSeek-V4-Flash-Vision-Expは、テキストと画像の双方を処理するマルチモーダル視覚理解機能を備えた実験的なモデルです。DeepSeek-V4-Flashと同等のテキスト能力を持ちながら、視覚情報の活用において大幅な性能向上を実現しています。多様な画像形式や送信方法に対応しており、Agentフレームワークへのスムーズな統合が可能です。

Release of DeepSeek-V4-Flash-Vision-Exp Model

DeepSeek has announced the release of its new multimodal vision understanding model, DeepSeek-V4-Flash-Vision-Exp, on the DeepSeek API platform.

This model supports image inputs in addition to text, enabling it to perform tasks such as describing images, recognizing text within screenshots, and analyzing charts. Supported formats include JPEG, PNG, GIF, and WebP.

DeepSeek stated that V4-Flash-Vision-Exp demonstrates excellent multimodal adaptability across various Agent frameworks and can effectively contribute to implementing practical task scenarios by utilizing a wide range of Agent tools.

This is an experimental model; users can access it by setting `model='deepseek-v4-flash-vision-exp'`.

Performance

In terms of pure text capabilities—including Agent performance, reasoning, and world knowledge—DeepSeek-V4-Flash-Vision-Exp is equivalent to the standard DeepSeek-V4-Flash model. However, it shows significant improvements over DeepSeek-V4-Flash in Agent benchmarks requiring visual understanding, with multimodal Agent capabilities approaching Opus-4.8.

API Access and Pricing

Users can access the V4-Flash-Vision-Exp API by setting `model='deepseek-v4-flash-vision-exp'`. In the API service, images are converted into tokens for billing purposes. Each image consumes a maximum of 384 tokens, and pricing is identical to the V4-Flash model.

The multimodal API supports three call formats—Chat Completions, Messages, and Responses—enabling easy integration into various Agent tools. It supports mixed text and image inputs via three transmission methods: base64 inline, external URL, and Files API.

The Files API is currently open and free of charge. Users can upload images to the platform first and reference them using a `file_id` in their requests to save bandwidth, avoiding the need to re-upload the same image for multiple requests.

Summary

DeepSeek has launched DeepSeek-V4-Flash-Vision-Exp, an experimental multimodal model that combines robust text reasoning with advanced vision capabilities. It offers significant improvements in visual understanding over the standard V4-Flash while maintaining consistent pricing and easy integration via multiple API formats. The inclusion of a free Files API further facilitates efficient deployment within various Agent frameworks.
