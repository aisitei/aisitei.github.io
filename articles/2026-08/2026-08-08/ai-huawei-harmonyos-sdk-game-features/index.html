HarmonyOS 게임 신기능 및 업데이트

IT소식에 따르면, ChinaJoy 2026이 성공적으로 막을 내렸으며 Huawei HarmonyOS 개발자 공식 웨이보를 통해 HarmonyOS SDK의 새로운 게임 기능인 AI 슈퍼 해상도, 제어 및 디스플레이 분리, 하드웨어 레이 트레이싱 등이 공개되었습니다.

지난 6월, Huawei는 HarmonyOS SDK 26을 정식 출시하며 사용 편의성, 공간화, 지능화 측면에서 전면적인 업그레이드를 진행했으며, 여기에는 게임 즉시 실행 기능이 포함되었습니다.

여러 사용자의 공유에 따르면, HarmonyOS 7 개발자 및 화분(花粉) Beta 버전 시스템을 탑재한 태블릿과 스마트폰에서 게임 즉시 실행 기능이 구현되었으며, <원신>, <로크 왕국> 등의 게임이 빠르게 시작되는 것을 지원합니다.

AI 슈퍼 해상도

AI 슈퍼 해상도 기술은 Huawei 모바일 NPU의 하드웨어와 소프트웨어 협업 능력을 기반으로 구현됩니다. HDC 2026에서 공개된 <이링(异环)> 게임은 AI 슈퍼 해상도 기술을 통해 렌더링 해상도를 1080P로 높여 화질을 1.5배 향상시켰으며, 수중 터널의 빛이나 헤엄치는 물고기 떼와 같은 세밀한 장면을 온전히 구현해냈습니다.

제어 및 디스플레이 분리

제어 및 디스플레이 분리 기능은 폴더블 디스플레이 기기를 주요 대상으로 하며, 화면을 두 개의 대칭적인 독립 영역으로 나눕니다. 상단 화면은 핵심 렌더링 화면을 담당하고 하단 화면은 인터랙션 터치에 집중하여 고전 휴대용 게임기의 조작 로직을 깊이 있게 재현합니다. 이 기능은 API 버전 26.0.0부터 추가되었으며, 현재 일부 폴더블 디스플레이 기기에서만 지원되고 Vulkan API를 기반으로 개발되어야 합니다.

하드웨어 레이 트레이싱

하드웨어 레이 트레이싱 측면에서 Huawei Mate 80 Pro Max 풍치(风驰) 에디션은 <아레나 브레이크아웃> 게임에서 3,000만 개의 광선을 동시에 렌더링하는 하드웨어 레이 트레이싱을 선제적으로 지원하며, 고화질과 높은 프레임의 균형을 맞춘 90프레임 환경을 최초로 구현했습니다.

ChinaJoy 참여 성과

이번 ChinaJoy(7월 31일~8월 3일)에서 Huawei 게임 센터는 'HarmonyOS와 함께 즐기는 게임'을 주제로 50종 이상의 인기 게임과 함께 상하이 신국제박람중심 N3 홀 01번 부스에 참여하여 1,000제곱미터 규모의 사이버 놀이공원을 조성했습니다. 현재까지 HarmonyOS 플랫폼에는 3만 개 이상의 게임이 등록되었으며, 1,000여 개의 파트너사와 협력하고 있으며 20개 이상의 주요 게임 엔진을 지원합니다.

총평

Huawei는 HarmonyOS SDK를 통해 AI 슈퍼 해상도, 제어 및 디스플레이 분리, 하드웨어 레이 트레이싱 등 고도화된 게임 기능을 제공하며 기술적 진보를 보여주었습니다. 특히 폴더블 디스플레이에 최적화된 인터랙션과 강력한 그래픽 성능을 결합하여 사용자 경험을 강화하고 있습니다. 현재 HarmonyOS 플랫폼은 수많은 파트너사 및 다양한 게임 엔진과의 협력을 통해 방대한 게임 생태계를 구축하고 있습니다.

HarmonyOS SDK 与游戏秒启功能

随着 ChinaJoy 2026 的落幕，Huawei HarmonyOS 开发者官方披露了 HarmonyOS SDK 的一系列新特性。其中包含在 HarmonyOS SDK 26 中推出的“游戏秒启秒开”功能，该功能已在搭载 HarmonyOS 7 开发/花粉 Beta 版系统的手机及平板上实装，支持《原神》、《洛克王国》等热门游戏的快速启动。

核心技术特性展示

HarmonyOS 为移动端游戏提供了多项关键的技术优化：

  • AI 超分：依托 Huawei 移动端 NPU 的软硬协同能力，在《异环》游戏中将渲染分辨率提升至 1080P，画面清晰度提升 1.5 倍。
  • 控显分离：专门针对折叠屏设备设计，将屏幕划分为上部渲染、下部交互的两个独立区域，从 API 版本 26.0.0 开始支持，并基于 Vulkan API 开发。
  • 硬件光追：Huawei Mate 80 Pro Max 风驰版在《暗区突围》中支持 3000 万条光线同时渲染，并实现了 90 帧与均衡光追的同步开启。

生态规模与合作伙伴

HarmonyOS 平台目前已构建起庞大的游戏生态体系：

  • 上架游戏数量：超过 3 万款。
  • 合作厂商：达 1000 余家。
  • 引擎支持：全面支持 20 余个主流游戏引擎。

总结

Huawei 在 HarmonyOS SDK 中引入了 AI 超分、控显分离及硬件光追等核心技术，旨在显著提升移动端游戏的画质与交互体验。目前，HarmonyOS 已建立起包含数万款游戏和上千家合作伙伴的庞大生态体系。

HarmonyOS ゲームの新機能およびアップデート

ITニュースによると、ChinaJoy 2026が無事に閉幕し、Huawei HarmonyOSの開発者向け公式Weiboを通じて、HarmonyOS SDKの新しいゲーム機能である「AIスーパー解像度」、「操作とディスプレイの分離」、および「ハードウェアレイトレーシング」が公開されました。

昨年6月、HuaweiはHarmonyOS SDK 26を正式にリリースし、利便性、空間化、知能化の面で全面的なアップグレードを実施しました。これにはゲームの即時起動機能も含まれています。

複数のユーザーの報告によると、HarmonyOS 7の開発者版および「花粉」Beta版システムを搭載したタブレットやスマートフォンにおいて、ゲームの即時起動機能が実装されており、『原神』や『ロク王国』などのゲームが迅速に起動されることが確認されています。

AI スーパー解像度

AIスーパー解像度技術は、HuaweiモバイルNPUのハードウェアとソフトウェアの連携能力に基づいて実現されています。HDC 2026で公開されたゲーム『異環』では、このAIスーパー解像度技術を通じてレンダリング解像度を1080Pに引き上げ、画質を1.5倍向上させました。これにより、水中トンネルの光や泳ぐ魚の群れといった細かなシーンを忠実に再現することに成功しています。

操作とディスプレイの分離

「操作とディスプレイの分離」機能は、主に折りたたみ式ディスプレイデバイスを対象としており、画面を2つの対称的な独立領域に分割します。上部の画面が主要なレンダリングを担当し、下部の画面がインタラクティブなタッチ操作に集中することで、クラシックな携帯型ゲーム機の操作ロジックを深く再現します。この機能はAPIバージョン26.0.0から追加され、現在は一部の折りたたみ式デバイスでのみサポートされており、Vulkan APIに基づいて開発される必要があります。

ハードウェア・レイトレーシング

ハードウェアレイトレーシングの面では、Huawei Mate 80 Pro Max 風馳（Fengchi）エディションが『Arena Breakout』において3,000万本の光線を同時にレンダリングするハードウェアレイトレーシングを先行サポートし、高画質と高いフレームレートを両立させた90fpsの環境を初めて実現しました。

ChinaJoyへの参加成果

今回のChinaJoy（7月31日〜8月3日）において、Huaweiゲームセンターは「HarmonyOSと共に楽しむゲーム」をテーマに、50以上の人気ゲームとともに上海新国際博覧中心N3ホール01番ブースにて1,000平方メートルのサイバー遊園地を構築しました。現在までにHarmonyOSプラットフォームには3万以上のゲームが登録されており、1,000以上のパートナー企業と協力し、20以上の主要なゲームエンジンをサポートしています。

まとめ

HuaweiはHarmonyOS SDKを通じて、AIスーパー解像度やハードウェアレイトレーシングといった高度なゲーム機能を実装し、技術的な進歩を示しました。特に折りたたみデバイスに最適化された操作系と強力なグラフィック性能を組み合わせることで、ユーザー体験の向上を図っています。現在、HarmonyOSは広範なパートナーシップと多様なエンジンへの対応を通じて、巨大なゲームエコシステムを構築しています。

New Features and Updates for HarmonyOS Gaming

Following the conclusion of ChinaJoy 2026, Huawei's official Weibo account for HarmonyOS developers revealed several new game features within the HarmonyOS SDK: AI Super Resolution, Control and Display Separation, and Hardware Ray Tracing.

In June, Huawei officially released HarmonyOS SDK 26, which introduced comprehensive upgrades in usability, spatialization, and intelligence. These updates included a "game instant launch" feature designed to improve the user experience.

According to reports from various users, the game instant launch feature has been implemented on tablets and smartphones running HarmonyOS 7 developer or Flower Powder (花粉) Beta versions. This feature supports the rapid startup of popular titles such as and .

AI Super Resolution

The AI Super Resolution technology is powered by the collaborative capabilities of Huawei's mobile NPU hardware and software. In the game , this technology was used to increase rendering resolution to 1080P, enhancing image quality by 1.5x. This allows for the accurate depiction of intricate scenes, such as light filtering through underwater tunnels and schools of fish.

Control and Display Separation

The Control and Display Separation feature is primarily targeted at foldable devices, dividing the screen into two symmetrical independent zones. The top portion handles core rendering while the bottom portion focuses on interaction touch, effectively replicating the control logic of classic handheld game consoles. This feature was added starting from API version 26.0.0; it is currently supported on select foldable devices and must be developed using the Vulkan API.

Hardware Ray Tracing

Regarding hardware ray tracing, the Huawei Mate 80 Pro Max "Fengchi" Edition provides advanced support for the game . It can render 30 million rays simultaneously, achieving a high-performance environment of 90 frames per second (FPS) while maintaining high visual quality.

ChinaJoy Participation Results

During ChinaJoy (July 31 – August 3), the Huawei Game Center participated under the theme "Gaming with HarmonyOS." They hosted over 50 popular games in a 1,000-square-meter cyber park at Booth 01, Hall N3 of the Shanghai New International Expo Center. To date, the HarmonyOS platform features:

  • Over 30,000 registered games
  • Partnerships with over 1,000 companies
  • Support for more than 20 major game engines

Summary

Huawei has demonstrated significant technical progress by introducing advanced features like AI Super Resolution, Control and Display Separation, and Hardware Ray Tracing through the HarmonyOS SDK. These updates specifically enhance the experience for foldable devices and high-end gaming performance. Furthermore, the platform continues to build a massive ecosystem supported by thousands of games, partners, and various game engines.
