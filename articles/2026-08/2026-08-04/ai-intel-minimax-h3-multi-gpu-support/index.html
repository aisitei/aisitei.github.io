Intel, 오픈소스 멀티모달 비디오 모델 MiniMax H3에 Day 0 지원 및 멀티 GPU 기반 배포 솔루션 제공

2026-08-04

지원 소식

Intel은 오늘 차세대 오픈 소스 멀티모달 비디오 모델인 MiniMax H3에 대해 Day 0 출시 지원을 제공한다고 발표했습니다.

기술 아키텍처

Intel Arc Pro B70은 MiniMax H3에 대한 최적화를 가장 먼저 완료했으며, Intel 팀은 멀티 GPU 기반의 배포 솔루션을 구현했습니다.

이 솔루션은 Encoder 8 카드 텐서 병렬(8TP), DiT 8 카드 USP(Ulysses Sequence Parallel, Layer-wise Offloading 결합), 그리고 B70 GPU에 배치된 VAE의 전체 아키텍처를 채택하여 비디오 생성 전 과정에서 GPU 가속을 실현했습니다.

그중 Encoder는 8 카드 텐서 병렬을 사용하여 텍스트 인코딩을 수행합니다. 추론 과정에서 계산량이 가장 많은 모듈인 DiT는 8 카드 USP와 Layer-wise Offloading 기술을 결합하여 모델 파라미터를 레이어별로 GPU에 동적으로 로드하며, 이를 통해 단일 카드 메모리 제한을 극복하고 모델의 상주 메모리 요구량을 낮추는 동시에 더 큰 규모의 DiT 모델 배포를 지원합니다. VAE는 B70 GPU에 배치되어 최종 비디오 디코딩을 수행합니다. 이 솔루션은 모델 용량과 계산 효율성을 모두 고려하여 대규모 비디오 생성 모델에 더욱 확장성 있는 배포 방식을 제공합니다.

하이브리드 병렬 솔루션

이에 더해, 팀은 텐서 병렬(Tensor Parallel, TP)과 USP의 장점을 결합하여 2TP×4USP 하이브리드 병렬 솔루션을 개발했습니다. 순수 8 카드 USP와 비교할 때, 이 방식은 USP 병렬도를 8에서 4로 낮추고 2개의 텐서 병를 도입하여 계산을 협력적으로 가속합니다. 이를 통해 모델 확장성을 유지하면서도 USP로 인한 통신 오버헤드를 줄여 계산 부하와 통신 비용 사이의 최적의 균형을 맞추고 전체 추론 성능을 향상시켰습니다.

최적화 및 성능

또한, 팀은 llm-scaler-omni 프로젝트의 XPU Kernel 최적화를 결합하여 행렬 곱셈, 어텐션 등 핵심 연산자를 지속적으로 최적화했습니다. 이를 통해 GPU 계산 효율을 높이고 엔드투엔드 추론 지연 시간을 단축하며 우수한 최적화 효과를 거두었습니다.

총평

Intel은 MiniMax H3 모델에 대해 Arc Pro B70 기반의 멀티 GPU 배포 솔루션을 제공하며, 텐서 병렬 및 USP 기술을 결합해 효율적인 비디오 생성 환경을 구축했습니다. 특히 하이브리드 병렬 방식과 핵심 연산자 최적화를 통해 대규모 모델의 확장성과 추론 성능을 동시에 확보한 것이 특징입니다.

Intel 提供 MiniMax H3 首发支持

Intel 宣布为新一代开源多模态视频模型 MiniMax H3 提供 Day 0 首发支持。该方案基于 Intel 锐炫 Pro B70 GPU 实现，旨在通过多卡 GPU 部署架构提供全流程的视频生成加速。

核心部署架构

针对 MiniMax H3 的不同模块，Intel 团队设计了相应的优化路径：

  • Encoder：采用 8 卡张量并行（8TP）完成文本编码。
  • DiT：作为计算量最大的模块，采用 8 卡 USP（Ulysses Sequence Parallel）并结合 Layer-wise Offloading 技术，在突破单卡显存限制的同时降低模型常驻显存需求。
  • VAE：部署于 B70 GPU 上完成最终的视频解码。

混合并行与性能优化

为了进一步平衡计算负载与通信开销，团队引入了更高效的并行策略和算子优化：

  • 混合并行方案：开发出 2TP×4USP 的混合并行模式，将 USP 并行度由 8 降至 4，并引入 2 路张量并行协同加速。
  • XPU Kernel 优化：结合 llm-scaler-omni 项目，对矩阵乘法、注意力等关键算子进行优化，显著降低端到端推理时延。

总结

Intel 为开源视频模型 MiniMax H3 提供 Day 0 支持，通过在 Intel 锐炫 Pro B70 上采用多卡并行架构和 2TP×4USP 混合并行方案提升了处理效率。该方案结合 Layer-wise Offloading 与 XPU Kernel 优化，实现了高性能、高扩展性的视频生成推理。

サポート情報

Intelは本日、次世代のオープンソース・マルチモーダル動画モデル「MiniMax H3」に対し、Day 0リリースサポートを提供することを発表しました。

技術アーキテクチャ

Intel Arc Pro B70はMiniMax H3への最適化を最優先で完了しており、IntelチームはマルチGPUベースの展開ソリューションを実装しました。

このソリューションは、以下の構成を採用することで、動画生成の全工程においてGPU加速を実現しています。

  • Encoder：8カード・テンサー並列（8TP）を使用してテキストエンコーディングを実行。
  • DiT：計算量が最も多いモジュールであるDiTには、8カードUSP（Ulysses Sequence Parallel、Layer-wise Offloadingの統合）とLayer-wise Offloading技術を組み合わせることで、モデルパラメータをレイヤーごとにGPUへ動的にロードします。これにより、単一カードのメモリ制限を克服し、より大規模なDiTモデルの展開をサポートします。
  • VAE：B70 GPUに配置され、最終的なビデオデコーディングを実行。

このソリューションは、モデル容量と計算効率の両方を考慮しており、大規模な動画生成モデルに対してより拡張性の高い展開方法を提供します。

ハイブリッド並列ソリューション

さらに、チームはテンサー並列（Tensor Parallel, TP）とUSPの利点を組み合わせた「2TP×4USPハイブリッド並列ソリューション」を開発しました。純粋な8カードUSPと比較して、この手法はUSPの並列度を8から4に下げつつ、2つのテンサー並列を導入することで計算を協調的に加速させます。これにより、モデルの拡張性を維持しながらUSPによる通信オーバーヘッドを削減し、計算負荷と通信コストの最適なバランスを実現して、全体の推論性能を向上させています。

最適化とパフォーマンス

また、チームはllm-scaler-omniプロジェクトのXPU Kernel最適化を統合し、行列乗算やアテンションなどの主要演算子を継続的に最適化しました。これによりGPUの計算効率が向上し、エンドツーエンドの推論遅延時間が短縮されるなど、優れた最適化効果を実現しています。

総評

IntelはMiniMax H3モデルに対し、Arc Pro B70ベースのマルチGPU展開ソリューションを提供し、テンサー並列およびUSP技術を組み合わせることで効率的な動画生成環境を構築しました。特にハイブリッド並列方式と主要演算子の最適化を通じて、大規模モデルの拡張性と推論性能の両立を実現している点が特徴です。

まとめ

Intelは次世代マルチモーダル動画モデル「MiniMax H3」に対し、Arc Pro B70を活用した高度なマルチGPU展開ソリューションを提供します。テンサー並列とUSPを組み合わせたハイブリッド手法やXPU Kernelの最適化により、大規模モデルにおける拡張性と推論性能の両立を実現しました。

Support News

Intel has announced Day 0 launch support for MiniMax H3, a next-generation open-source multimodal video model.

Technical Architecture

The Intel Arc Pro B70 was the first to complete optimizations for MiniMax H3. The Intel team implemented a multi-GPU based deployment solution that utilizes several key technologies to achieve GPU acceleration throughout the entire video generation process:

  • Encoder: Utilizes 8 card Tensor Parallel (8TP) to perform text encoding.
  • DiT: As the most computationally intensive module, it combines 8 card USP (Ulysses Sequence Parallel) and Layer-wise Offloading. This allows model parameters to be loaded onto GPUs dynamically by layer, overcoming single-card memory limitations and reducing resident memory requirements while supporting larger DiT models.
  • VAE: Deployed on B70 GPUs to perform the final video decoding.

This architecture provides a highly scalable deployment method for large-scale video generation models by balancing model capacity with computational efficiency.

Hybrid Parallel Solution

In addition, the team developed a 2TP × 4USP hybrid parallel solution that combines the advantages of Tensor Parallel (TP) and USP. Compared to a pure 8-card USP configuration, this method reduces the USP parallelism from 8 to 4 while introducing 2 Tensor Parallels to accelerate calculations collaboratively.

This approach maintains model scalability while reducing the communication overhead caused by USP, creating an optimal balance between computational load and communication costs, thereby improving overall inference performance.

Optimization and Performance

The team also integrated XPU Kernel optimizations from the llm-scaler-omni project to continuously optimize core operators such as matrix multiplication and attention. These efforts have resulted in significant optimization effects, including increased GPU calculation efficiency and reduced end-to-end inference latency.

Summary

Intel has introduced a multi-GPU deployment solution for the MiniMax H3 model using Intel Arc Pro B70 GPUs. By combining Tensor Parallel and USP technologies with hybrid parallel methods and core operator optimizations, the solution provides high scalability and improved inference performance for large-scale video generation.
