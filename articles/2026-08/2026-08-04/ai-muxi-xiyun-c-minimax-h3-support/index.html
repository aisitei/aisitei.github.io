Muxi Xiyun C 시리즈 GPU, MiniMax H3 멀티모달 생성 모델 Day 0 지원 구현

2026-08-04

제품 발표

MetaX는 자사 Xiyun C 시리즈 GPU가 MiniMax H3 멀티모달 생성 모델에 대한 Day 0 적응을 완료했다고 발표했습니다. MetaX의 전방위적 자체 개발 MXMACA 소프트웨어 스택을 통해 사용자는 MiniMax H3를 신속하게 배포하고 해당 모델의 강력한 멀티모달 창작 능력을 활용할 수 있습니다.

성능 및 기술 사양

MetaX에 따르면, Xiyun C 시리즈 GPU는 자체 개발한 핵심 GPU IP를 기반으로 제작되어 높은 에너지 효율과 호환성을 갖추고 있으며, 대규모 모델의 초대형 파라미터 처리 및 긴 컨텍스트 추론 요구 사항을 정확하게 충족합니다. Xiyun C 시리즈는 고성능 하드웨어 아키텍처와 MXMACA 계산 플랫폼을 결합하여 MiniMax H3 모델에 대한 신속한 적응을 실현했습니다.

MXMACA 소프트웨어 스택

MXMACA 소프트웨어 스택은 MetaX GPU가 '사용 가능' 단계를 넘어 '사용하기 편리하고 쉬운' 단계로 도약하게 하는 핵심 기반입니다. 하드웨어 연산 능력과 상위 애플리케이션 생태계를 연결하는 핵심 허브로서, MXMACA 소프트웨어 스택은 다음과 같은 기능을 제공합니다.

  • 하부 드라이버, 사용자 모드 인터페이스, MXCC 컴파일러, 연산자 심층 적응 및 주요 학습/추론 프레임워크 연결을 포함한 전체 경로 지원
  • 국제 주요 생태계와 원활하게 호환되며 PyTorch, TensorFlow, vLLM, SGLang 등 40종 이상의 주요 AI 프레임워크 지원
  • 500개 이상의 AI 모델 안정적 실행 지원 및 기존 모델의 적응 기간 대폭 단축

총평

MetaX는 자체 개발한 Xiyun C 시리즈 GPU와 MXMACA 소프트웨어 스택을 통해 MiniMax H3 모델에 대한 신속한 최적화와 강력한 멀티모달 성능을 제공합니다. 특히 광범위한 AI 프레임워크 호환성을 바탕으로 대규모 모델의 처리 효율성을 높이고 배포 기간을 단축하는 데 중점을 두고 있습니다.

模型适配与部署

沐曦股份（MetaX）宣布其曦云 C 系列 GPU 已完成对稀宇 MiniMax H3 多模态生成模型的 Day 0 适配。通过依托自研的 MXMACA 软件栈，用户可以快速部署并调用 MiniMax H3 的多模态创作能力。

硬件架构优势

曦云 C 系列 GPU 基于 MetaX 自研核心 GPU IP 构建，旨在满足大模型处理的高要求：

  • 具备高能效比。
  • 精准匹配超大规模参数处理需求。
  • 支持长上下文推理需求。

MXMACA 软件栈能力

作为连接硬件算力与上层应用生态的核心枢纽，MXMACA 软件栈提供全链路技术支撑：

  • 覆盖范围：包括底层驱动、用户态接口、MXCC 编译器、算子深度适配等。
  • 兼容性：原生兼容 PyTorch、TensorFlow、vLLM 与 SGLang 等主流生态。
  • 规模支持：适配 40 余种主流 AI 框架，支持 500+ AI 模型稳定运行。

总结

MetaX 的曦云 C 系列 GPU 通过自研 MXMACA 软件栈实现了对 MiniMax H3 多模态模型的快速适配。该系列产品凭借高性能硬件架构和广泛的框架兼容性，能够显著缩短大模型从开发到部署的周期。

パフォーマンスおよび技術仕様

MetaXによると、Xiyun CシリーズGPUは独自開発のコアGPU IPを基に構築されており、高いエネルギー効率と互換性を備えています。また、大規模モデルの超巨大パラメータ処理や長いコンテキスト推論の要求にも正確に対応します。Xiyun Cシリーズは、高性能なハードウェアアーキテクチャとMXMACA計算プラットフォームを組み合わせることで、MiniMax H3モデルへの迅速な適応を実現しました。

MXMACAソフトウェアスタック

MXMACAソフトウェアスタックは、MetaX GPUが単に「利用可能」な状態から「使いやすく便利な」段階へと進化するための基盤となります。ハードウェアの演算能力と上位アプリケーションのエコシステムをつなぐ中核的なハブとして、MXMACAソフトウェアスタックは以下の機能を提供します。

  • 下位ドライバー、ユーザーモードインターフェース、MXCCコンパイラ、演算子の深化された適応、および主要な学習・推論フレームワークへの接続を含むフルパスのサポート
  • 国際的な主要エコシステムとの円滑な互換性を備え、PyTorch、TensorFlow、vLLM、SGLangなど40種以上の主要AIフレームワークをサポート
  • 500以上のAIモデルの安定した実行をサポートし、既存モデルの適応期間を大幅に短縮

Product Announcement

MetaX has announced that its Xiyun C series GPUs have completed Day 0 adaptation for the MiniMax H3 multimodal generative model. Through MetaX's comprehensive, self-developed MXMACA software stack, users can rapidly deploy MiniMax H3 and leverage the model's powerful multimodal creative capabilities.

Performance and Technical Specifications

According to MetaX, the Xiyun C series GPUs are manufactured based on proprietary core GPU IP, ensuring high energy efficiency and compatibility. They are designed to accurately meet the demands of large-scale models, including processing massive parameters and long-context inference requirements. The Xiyun C series achieves rapid adaptation for the MiniMax H3 model by combining a high-performance hardware architecture with the MXMACA computing platform.

MXMACA Software Stack

The MXMACA software stack is the core foundation that moves MetaX GPUs beyond the "usable" stage to become "easy to use." Serving as a critical hub connecting hardware computing power with upper-level application ecosystems, the MXMACA software stack provides the following features:

  • Full-path support including lower-level drivers, user-mode interfaces, the MXCC compiler, deep operator adaptation, and connections to major training/inference frameworks.
  • Seamless compatibility with major international ecosystems, supporting over 40 major AI frameworks such as PyTorch, TensorFlow, vLLM, and SGLang.
  • Stable execution support for over 500 AI models while significantly shortening the adaptation period for existing models.

Overall Assessment

MetaX provides rapid optimization and powerful multimodal performance for the MiniMax H3 model through its self-developed Xiyun C series GPUs and MXMACA software stack. The system specifically focuses on improving processing efficiency for large-scale models and shortening deployment times by leveraging extensive AI framework compatibility.

MetaX has announced that its Xiyun C series GPUs, supported by the MXMACA software stack, have achieved Day 0 adaptation for MiniMax H3 multimodal models.
