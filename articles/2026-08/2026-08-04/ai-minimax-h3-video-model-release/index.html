범용 비디오 모델 MiniMax H3 공식 오픈소스 공개, 멀티모달 컨텍스트 및 2K 해상도 지원

2026-08-04

개요

MiniMax가 차세대 범용 비디오 모델인 MiniMax H3를 공식적으로 오픈 소스로 공개했습니다.

MiniMax H3는 범용 멀티모달 생성 시스템으로, 텍스트, 이미지, 비디오, 오디오로 구성된 멀티모달 컨텍스트를 통합적으로 이해하며 최대 2K 해상도, 최장 15초 길이의 네이티브 스테레오 사운드가 포함된 비디오를 생성할 수 있습니다. 태스크 일반화 중심의 시스템 설계 덕분에 H3는 사전 학습 단계에서 광범위한 멀티모달 컨텍스트 이해 및 생성 능력을 갖추었으며, 복잡한 멀티모드 명령을 훌륭하게 수행합니다.

출력 사양

  • 출력 길이: 4~15초
  • 출력 화면비: 21:9, 16:9, 4:3, 1:1, 3:4, 9:16 등 다양한 비율 지원
  • 출력 해상도: 다양한 해상도 크기 지원 (기본값은 짧은 쪽을 768픽셀로 설정), H3-Regenerate-2K를 통해 2K 해어상도 생성 가능
  • 출력 프레임 레이트: 24 FPS
  • 출력 오디오: 32 kHz 스테레오
  • 지원 대화 언어: 아랍어, 중국어, 영어, 프랑스어, 독일어, 이탈리아어, 일본어, 한국어, 포르투갈어, 러시아어, 스페인어 등 11개 언어를 안정적으로 지원하며, 기타 언어에 대해서도 다양한 수준의 지원을 제공함

모델 버전 및 입력 사양

① H3-Base-FL2VA (첫 프레임 및 마지막 프레임 모드):

  • 이미지 입력 지원: 0장, 1장 또는 2장
  • 이미지 미입력 시: 텍스트-비디오(Text-to-Video) 모드
  • 첫 번째 프레임 이미지 입력 시: 첫 프레임 생성 비디오 모드
  • 마지막 프레임 이미지 입력 시: 마지막 프레임 생성 비디오 모드
  • 첫 번째 및 마지막 프레임 이미지 동시 입력 시: 첫 프레임 및 마지막 프레임 생성 비디오 모드

② H3-Base-Ref2VA (전체 모드 참조 모드):

  • 이미지: 최대 9장
  • 비디오: 최대 3개 (각 클립은 2~15초, 총합 15초 이내)
  • 오디오: 최대 3개 (반드시 이미지 또는 비디오와 함께 입력되어야 하며 단독으로만 입력될 수 없음, 각 클립은 2~15초, 총합 15초 이내)
  • 혼합 입력: 모든 유형의 입력 파일을 합쳐 최대 12개까지 지원

시스템 모듈

전체 H3 시스템은 다음 세 가지 모듈로 구성됩니다.

  • H3-Context-IR: 입력이 복잡해짐에 따라 멀티모드 명령을 심층적으로 이해하고 추출하여, H3가 더 쉽게 이해하고 생성에 직접 사용할 수 있는 형태인 Context Intermediate Representation(컨텍스트 중간 표현)으로 변환하는 전용 시스템입니다. 이는 최종 출력 품질에 매우 중요하므로 H3-Context-IR API를 생성 프로세스에 통합할 것을 강력히 권장합니다. 또는 프롬프트 가이드를 참고하여 자체 컨텍스트 처리 시스템을 구축할 수 있습니다.
  • H3-Base: H3-Context-IR의 출력을 바탕으로 오디오와 비디오를 생성하며, 768p 해상도의 결과를 출력합니다.
  • H3-Regenerate-2K: 768p 생성 결과와 원본 컨텍스트를 다시 H3에 전달하여 2K 해상도로 재생성합니다. 이는 H3의 강력한 생성 능력을 활용하는 동시에 원본 컨텍스트의 풍부한 정보를 활용하여 세부 사항이 더 정확하고 시각적 충실도가 높은 고해상도 결과를 생성합니다.

총평

MiniMax H3는 텍스트, 이미지, 비디오, 오디오를 통합적으로 이해하고 생성할 수 있는 범용 멀티모드 시스템으로, 복잡한 명령 수행과 고해상도(2K) 및 스테레오 사운드가 포함된 비디오 생성을 지원합니다. 세 가지 핵심 모듈을 통해 컨텍스트 이해도를 높이고 시각적 충실도가 높은 결과물을 제공하는 것이 특징입니다.

产品发布概况

MiniMax 正式开源新一代通用视频模型 MiniMax H3。该模型是一个通用型全模态生成系统，能够统一理解由文本、图像、视频和音频构成的多模态上下文。其核心优势在于以任务泛化为导向的系统设计，使其具备强大的多模态指令遵循能力，支持生成最高 2K 分辨率、最长 15 秒且带有原生立体声音频的视频。

输出规格参数

MiniMax H3 支持以下核心技术规格：

  • 输出时长：4–15 秒
  • 输出宽高比：支持多种比例，包括 21:9、16:9、4:3、1:1、3:4 和 9:16
  • 输出分辨率：默认短边为 768 像素；通过 H3-Regenerate-2K 可实现 2K 分辨率生成
  • 输出帧率：24 FPS
  • 输出音频：32 kHz 立体声
  • 支持语言：稳定支持阿拉伯语、中文、英语、法语、德语、意大利语、日语、韩语、葡萄牙语、俄语和西班牙语。

模型版本与输入模式

MiniMax H3 提供两种主要模型变体以满足不同创作需求：

  • H3-Base-FL2VA（首尾帧模式）：支持 0 到 2 张图像输入，可实现文生视频、首帧/尾帧生视频或双端帧生视频。
  • H3-Base-Ref2VA（全模态参考模式）：支持多模态混合输入，包括最多 9 张图像、3 段视频（每段 2–15 秒）以及 3 段音频。所有类型输入文件合计最多可达 12 个。

系统架构设计

完整的 H3 系统由三个核心模块组成：

  • H3-Context-IR：用于深度理解并提炼复杂的多模态指令，将其转换为 Context Intermediate Representation（上下文中间表示）。
  • H3-Base：基于转换后的内容生成 768p 分辨率的音频和视频。
  • H3-Regenerate-2K：将 768p 生成结果与原始上下文结合，重新生成细节更准确、视觉保真度更高的高分辨率 2K 视频。

总结

MiniMax 正式开源了全模态通用视频模型 MiniMax H3，该模型支持多模态输入（文/图/视/音）并能生成高质量的立体声视频。通过独特的三段式架构设计，H3 能够有效处理复杂指令并提供从 768p 到 2K 的高保真渲染能力。

概要

MiniMaxは、次世代の汎用ビデオモデルである「MiniMax H3」を公式にオープンソースとして公開しました。

MiniMax H3は、テキスト、画像、動画、オーディオで構成されるマルチモーダルコンテキストを一元的に理解するマルチモーダル生成システムです。最大2K解像度、最長15秒のネイティブステレオサウンドを含むビデオを生成することが可能です。タスクの汎用性を重視したシステム設計により、H3は事前学習段階で広範なマルチモーダルコンテキストの理解および生成能力を備えており、複雑なマルチモード命令を高度に遂行します。

出力仕様

  • 出力の長さ：4〜15秒
  • 出力アスペクト比：21:9、16:9、4:3、1:1、3:4、9:16など多様な比率をサポート
  • 出力解像度：様々なサイズに対応（デフォルトは短い方の辺を768ピクセルに設定）、H3-Regenerate-2Kを通じて2K解像度の生成が可能
  • フレームレート：24 FPS
  • オーディオ：32 kHz ステレオ
  • 対応言語：アラビア語、中国語、英語、フランス語、ドイツ語、イタリア語、日本語、韓国語、ポルトガル語、ロシア語、スペイン語など11言語を安定してサポート。その他の言語についても様々なレベルのサポートを提供

モデルバージョンおよび入力仕様

① H3-Base-FL2VA（最初のフレームおよび最後のフレームモード）:

  • 画像入力：0枚、1枚、または2枚
  • 画像なしの場合：テキストからビデオへの変換（Text-to-Video）モード
  • 最初のフレームの画像を入力：最初のフレーム生成ビデオモード
  • 最後のフレームの画像を入力：最後のフレーム生成ビデオモード
  • 最初と最後のフレームの両方の画像を同時入力：第一および最終フレーム生成ビデオモード

② H3-Base-Ref2VA（全体参照モード）:

  • 画像：最大9枚
  • 動画：最大3つ（各クリップは2〜15秒、合計15秒以内）
  • オーディオ：最大3つ（必ず画像または動画と組み合わせて入力する必要があり、単体での入力は不可。各クリップは2〜15秒、合計15秒以内）
  • 混合入力：すべての種類の入力を合わせて最大12個までサポート

システムモジュール

H3システム全体は、以下の3つのモジュールで構成されています。

  • H3-Context-IR：入力が複雑になるにつれ、マルチモード命令を深く理解・抽出し、H3がより容易に理解して生成に直接利用できる形式である「Context Intermediate Representation（コンテキスト中間表現）」へと変換する専用システムです。最終的な出力品質に非常に重要なため、生成プロセスにH3-Context-IR APIを統合することが強く推奨されます。または、プロンプトガイドを参照して独自のコンテキスト処理システムを構築することも可能です。
  • H3-Base：H3-Context-IRの出力を基にオーディオとビデオを生成し、768p解像度の結果を出力します。
  • H3-Regenerate-2K：768pの生成結果と元のコンテキストを再度H3に送り、2K解像度で再生成します。これにより、H3の強力な生成能力を活用しながら、元のコンテキストの豊富な情報を活用し、ディテールがより正確で視覚的な忠実度の高い高解像度結果を生成します。

まとめ

MiniMax H3は、テキスト、画像、動画、オーディオを統合的に理解・生成できる汎用マルチモーダルシステムです。独自の3つのモジュール構成により、複雑な指示への対応や、高解像度（2K）かつステレオサウンドを含む高品質なビデオ生成を実現します。

Overview

MiniMax has officially released its next-generation general-purpose video model, MiniMax H3, as an open-source project.

MiniMax H3 is a general-purpose multimodal generation system that comprehensively understands multimodal contexts including text, images, video, and audio. It can generate videos with resolutions up to 2K, durations of up to 15 seconds, and native stereo sound. Due to its task-generalization-focused design, H3 possesses extensive multimodal context understanding and generation capabilities during the pre-training stage, allowing it to execute complex multi-mode commands effectively.

Output Specifications

  • Output Length: 4–15 seconds
  • Output Aspect Ratio: Supports various ratios including 21:9, 16:9, 4:3, 1:1, 3:4, and 9:16
  • Output Resolution: Supports various sizes (default is set to 768 pixels for the shorter side); H3-Regenerate-2K can generate 2K resolution videos
  • Output Frame Rate: 24 FPS
  • Output Audio: 32 kHz stereo
  • Supported Languages: Stable support for 11 languages including Arabic, Chinese, English, French, German, Italian, Japanese, Korean, Portuguese, Russian, and Spanish; various levels of support are provided for other languages.

Model Versions and Input Specifications

① H3-Base-FL2VA (First Frame and Last Frame Mode):

  • Image Input Support: 0, 1, or 2 images
  • No image input: Text-to-Video mode
  • First frame image input: First frame generation video mode
  • Last frame image input: Last frame generation video mode
  • Both first and last frame image input: First and last frame generation video mode

② H3-Base-Ref2VA (Full Mode Reference Mode):

  • Images: Up to 9 images
  • Videos: Up to 3 videos (each clip between 2–15 seconds, total under 15 seconds)
  • Audio: Up to 3 clips (must be provided with an image or video; cannot be input alone; each clip between 2–15 seconds, total under 15 seconds)
  • Mixed Input: Supports up to 12 files in total across all types.

System Modules

The entire H3 system consists of the following three modules:

  • H3-Context-IR: A dedicated system that deeply understands and extracts multi-mode commands as inputs become complex, converting them into "Context Intermediate Representation" (a format easier for H3 to understand and use directly for generation). As this is critical for final output quality, it is highly recommended to integrate the H3-Context-IR API into the generation process or build a custom context processing system using provided prompt guides.
  • H3-Base: Generates audio and video based on the output from H3-Context-IR, producing results at 768p resolution.
  • H3-Regenerate-2K: Re-generates the 768p output along with the original context through H3 to produce a 2K resolution result. This utilizes H3's powerful generation capabilities while leveraging rich information from the original context to create high-resolution results with accurate details and higher visual fidelity.

Summary

MiniMax H3 is a versatile multimodal system capable of processing and generating content across text, image, video, and audio formats. It features a three-module architecture designed to enhance context understanding and provide high-fidelity 2K resolution videos with stereo sound.
