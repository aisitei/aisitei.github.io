강제 설치 논란 완화: Microsoft, 9월 OneDrive, 사진 앱 개별 제거 지원 예정

2026-08-14

OneDrive Photos 앱 독립적 제거 지원

IT之家 8월 13일 보도에 따르면, IT 매체 WinAero는 어제(8월 12일) 블로그 게시물을 통해 Microsoft가 9월부터 OneDrive Photos 앱의 독립적인 제거를 지원하여 사용자에게 Windows 경험에 대한 더 많은 제어 권한을 부여할 계획이라고 보도했습니다.

IT之家는 이전에 Microsoft가 일부 Windows 11 PC에 OneDrive Photos 앱을 강제로 설치했음을 인정했지만, Intune 관리 범위에 포함된 기업 장치에는 이 앱을 푸시하지 않았다고 명확히 밝혔다고 보도했습니다.

OneDrive Photos 앱이 강제로 설치된 PC의 경우, 현재 OneDrive 앱을 제거하지 않고는 OneDrive Photos 앱을 제거할 수 없으며, 관련 바로가기만 숨길 수 있습니다. 사용자가 OneDrive Photos 앱을 강제로 제거하더라도, OneDrive 앱이 설치된 장치에서는 Microsoft가 나중에 다시 다운로드하여 설치합니다.

이에 대해 Microsoft는 Microsoft 365 제품 로드맵에 두 가지 항목을 추가했습니다. 이 중 568931번 항목은 IT 관리자를 대상으로 하며, 8월에 배포될 예정입니다:

  • 조직은 OneDrive Photos의 접근 권한을 관리할 수 있습니다. 이 기능을 통해 시스템 관리자는 직원이 기업 장치에서 개인 Microsoft 계정을 사용하여 해당 앱에 로그인하는 것을 제한할 수 있습니다.

568934번 항목에서 Microsoft는 9월에 독립적인 제거 기능을 출시할 계획입니다:

  • OneDrive는 사용자가 OneDrive Photos 서비스를 독립적으로 제거할 수 있도록 지원하여, 사용자에게 Windows 사용 경험에 대한 더 많은 제어 권한을 부여합니다. Photos 서비스를 제거해도 OneDrive 앱이 제거되거나 파일 동기화가 중단되거나 사진 및 파일이 삭제되지 않습니다. 이는 다른 앱을 사용하여 사진을 관리하려는 사용자에게 명확한 제거 옵션을 제공합니다.

총평

Microsoft는 9월부터 Windows 11 사용자가 OneDrive Photos 앱을 OneDrive 앱과 독립적으로 제거할 수 있도록 지원할 예정입니다. 이는 사용자가 Windows 환경을 더 자유롭게 제어할 수 있도록 하기 위함이며, OneDrive Photos 제거 시에도 OneDrive 앱의 기능이나 파일 동기화에는 영향을 미치지 않습니다. 이로써 다른 사진 관리 앱을 선호하는 사용자들에게 명확한 선택지가 제공될 것입니다.

微软计划支持独立卸载 OneDrive Photos 应用

OneDrive Photos 强制安装问题

微软此前承认在部分 Windows 11 电脑上强制安装了 OneDrive Photos 应用，但未向 Intune 管理的企业设备推送。目前，用户无法在不卸载 OneDrive 应用的情况下卸载 OneDrive Photos，即使强制卸载也会被重新安装。

针对企业管理员的更新

微软在 Microsoft 365 产品路线图中新增了编号 568931 的条目，计划于 8 月部署，允许组织管理 OneDrive Photos 的访问权限。

  • 系统管理员可以限制员工在企业设备上使用个人 Microsoft 账户登录该应用。

独立卸载功能

微软计划在 9 月推出编号 568934 的条目，支持用户独立卸载 OneDrive Photos 服务。

  • 移除 Photos 服务不会卸载 OneDrive 应用。
  • 不会中断文件同步。
  • 不会删除照片和文件。
  • 为希望使用其他应用管理照片的用户提供清晰的移除选项。

总结

微软计划在 8 月和 9 月分阶段解决 OneDrive Photos 应用的强制安装问题。8 月将为企业管理员提供管理访问权限的功能，而 9 月将允许所有用户独立卸载 OneDrive Photos 服务，从而提升用户对 Windows 体验的掌控力，同时不影响 OneDrive 应用的核心功能。

OneDrive Photosアプリの独立したアンインストールに対応

IT之家8月13日の報道によると、ITメディアのWinAeroは昨日（8月12日）のブログ投稿で、Microsoftが9月からOneDrive Photosアプリの独立したアンインストールをサポートし、ユーザーにWindowsエクスペリエンスに対するより多くの制御権を与える計画であると報じました。

IT之家は以前、Microsoftが一部のWindows 11 PCにOneDrive Photosアプリを強制的にインストールしたことを認めたものの、Intune管理範囲に含まれる企業デバイスにはこのアプリをプッシュしていないことを明確にしていたと報じていました。

OneDrive Photosアプリが強制的にインストールされたPCの場合、現在、OneDriveアプリをアンインストールせずにOneDrive Photosアプリをアンインストールすることはできず、関連するショートカットを非表示にすることしかできません。ユーザーがOneDrive Photosアプリを強制的にアンインストールしても、OneDriveアプリがインストールされているデバイスでは、Microsoftが後で再度ダウンロードしてインストールします。

これに対し、MicrosoftはMicrosoft 365製品ロードマップに2つの項目を追加しました。このうち、項目番号568931はIT管理者を対象としており、8月に展開される予定です。

  • 組織はOneDrive Photosへのアクセス権を管理できます。この機能により、システム管理者は、従業員が企業デバイスで個人Microsoftアカウントを使用して当該アプリにログインすることを制限できます。

項目番号568934では、Microsoftは9月に独立したアンインストール機能をリリースする計画です。

  • OneDriveは、ユーザーがOneDrive Photosサービスを独立してアンインストールできるようにサポートし、ユーザーにWindowsの使用体験に対するより多くの制御権を与えます。Photosサービスをアンインストールしても、OneDriveアプリがアンインストールされたり、ファイル同期が停止したり、写真やファイルが削除されたりすることはありません。これは、他のアプリを使用して写真を管理したいユーザーに明確なアンインストールオプションを提供します。

「Microsoft、一部のWin11デバイスへのOneDrive Photos強制プッシュを認め、ユーザーの顔AI学習を否定」

「アンインストール後に再インストール：Microsoft Win11、OneDrive Photosを自動プッシュ、ショートカット非表示スクリプトを含む」

「情報筋によると、Microsoft Win11、OneDrive Photosアプリを静かにプッシュ、承認後に顔ごとの写真グループ化をサポート」

まとめ

Microsoftは9月から、Windows 11ユーザーがOneDrive PhotosアプリをOneDriveアプリとは独立してアンインストールできるようサポートする予定です。これにより、ユーザーはWindows環境をより自由に制御できるようになり、OneDrive PhotosをアンインストールしてもOneDriveアプリの機能やファイル同期には影響しません。これにより、他の写真管理アプリを好むユーザーに明確な選択肢が提供されることになります。

OneDrive Photos App to Support Independent Uninstallation

According to an IT Home report on August 13th, IT media outlet WinAero published a blog post yesterday (August 12th) stating that Microsoft plans to support the independent uninstallation of the OneDrive Photos app starting in September, giving users more control over their Windows experience.

IT Home previously reported that Microsoft admitted to forcibly installing the OneDrive Photos app on some Windows 11 PCs, but clarified that it did not push the app to enterprise devices covered by Intune management.

For PCs where the OneDrive Photos app was forcibly installed, it is currently impossible to remove the OneDrive Photos app without uninstalling the OneDrive app itself; only the related shortcuts can be hidden. Even if users forcibly remove the OneDrive Photos app, Microsoft will re-download and install it later on devices where the OneDrive app is present.

In response, Microsoft has added two items to its Microsoft 365 product roadmap. Item number 568931 is aimed at IT administrators and is scheduled for deployment in August:

  • Organizations will be able to manage access to OneDrive Photos. This feature allows system administrators to restrict employees from logging into the app using personal Microsoft accounts on corporate devices.

In item number 568934, Microsoft plans to release the independent uninstallation feature in September:

  • OneDrive will support users in independently uninstalling the OneDrive Photos service, giving users more control over their Windows experience. Removing the Photos service will not uninstall the OneDrive app, stop file synchronization, or delete photos and files. This provides a clear uninstallation option for users who wish to manage their photos using other apps.

Summary

Starting in September, Microsoft will allow Windows 11 users to independently uninstall the OneDrive Photos app from the OneDrive app. This initiative aims to give users greater control over their Windows environment. Removing OneDrive Photos will not affect the functionality of the OneDrive app or file synchronization, providing a clear option for users who prefer other photo management applications.
