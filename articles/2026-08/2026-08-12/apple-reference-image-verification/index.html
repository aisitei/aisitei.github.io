iOS 27 코드에서 Apple이 iPhone 촬영 사진의 진위 여부 검증을 위한 'Apple Reference Image' 인증 기능을 개발 중인 것으로 나타났습니다.

2026-08-12

새로운 기능 도입

IT홈의 보도에 따르면, 외신 9to5Mac이 Apple iOS 27 개발자 프리뷰 베타 5 코드에서 'Apple Reference Image'라는 새로운 기능을 발견했습니다. 이 기능은 iPhone으로 촬영한 사진의 출처가 실제인지 인증하는 데 사용됩니다.

배경 및 목적

생성형 AI 이미지 기술이 빠르게 발전함에 따라, AI로 생성되거나 깊게 수정된 이미지가 실제 사진으로 위장하기가 점점 쉬워지고 있습니다. 과거 전문가가 수 시간 동안 작업해야 했던 이미지 수정이 이제는 간단한 프롬프트 입력만으로 몇 초 만에 매우 사실적인 콘텐츠를 만들어낼 수 있게 되었습니다. 이에 따라 Apple은 사용자가 이미지가 실제로 iPhone으로 촬영된 것인지 직접 판단할 수 있도록 돕는 'Apple Reference Image' 인증 기능을 개발하게 되었습니다.

작동 원리

Apple Reference Image 기능은 Apple이 사용자의 원본 사진에 직접 접근하는 방식이 아닙니다. 시스템은 iPhone으로 촬영된 사진을 인증을 위해 클라우드 보안 환경으로 전송하며, 인증이 완료되면 해당 사진에 고유 ID를 부여합니다. 만약 특정 카메라 센서가 조작되거나 훼손된 것으로 감지될 경우, 시스템은 해당 센서와 관련된 이전 인증 기록을 취소할 수 있습니다.

개인정보 보호

이 기능에는 일련의 개인정보 보호 메커니즘이 포함되어 있습니다. 예를 들어, 인증된 사진은 다른 사용자와 공유할 수 있으며, 수신자의 Apple 기기에서 해당 사진이 여전히 인증 상태를 유지하고 있는지 로컬에서 확인할 수 있습니다. 이 과정에서 사용자가 어떤 이미지를 보고 있는지에 대한 정보는 Apple에 전달되지 않습니다.

공유 및 전송

공유 방식(AirDrop, 메시지 등)과 사진 유형(원본, 편집본 또는 인증 버전)에 따라 전송되는 데이터 내용이 달라질 수 있습니다. 사용자가 '모든 사진 데이터'를 선택하여 공유할 경우, 고유 하드웨어 식별자와 사진 관련 미편집 원본 비디오 클립이 포함될 수 있습니다.

또한 Apple은 USB 전송 시 'Transfer with Provenance(출처 정보 포함 전송)' 옵션을 추가할 계획입니다. 이 기능을 활성화하면 Mac이나 PC로 USB를 통해 전송된 인증 사진에 출처 데이터가 유지되어, 사용자가 기기에서 이미지의 원본 출처를 편리하게 확인할 수 있습니다.

총평

Apple은 생성형 AI 기술 확산에 따른 가짜 이미지 판별을 돕기 위해 'Apple Reference Image'라는 사진 인증 기능을 개발 중입니다. 이 기능은 클라우드 기반의 고유 ID 부여와 로컬 확인 시스템을 통해 개인정보를 보호하면서도 콘텐츠의 진위 여부를 확인할 수 있게 합니다. 또한 USB 전송 시에도 출처 정보를 유지하는 옵션을 제공하여 기기 간 데이터 이동 시 신뢰성을 확보하고자 합니다.

新功能：Apple Reference Image

在 iOS 27 开发者预览版中，Apple 正在开发名为 Apple Reference Image 的新功能。该功能旨在验证 iPhone 拍摄照片的真实性，以应对生成式 AI 技术导致虚假或深度修改图像日益泛滥的现状。

技术原理与安全机制

系统通过云端环境对用户拍摄的照片进行认证处理，并为每张符合要求的图片分配唯一标识符。若检测到硬件层面存在异常，系统将采取相应的保护措施。

  • 认证流程：照片被发送至云端安全环境进行验证。
  • 身份识别：认证通过后，系统会为该照片分配一个唯一的 ID。
  • 风险管控：如果发现摄像头传感器被篡改或破坏，系统将撤销相关认证记录。

隐私保护与多样化分享

为了保护用户隐私，接收方可以在本地设备上检查照片的认证状态，而无需向 Apple 传输任何关于查看行为的数据。此外，根据不同的共享场景和选择，提供的内容也会有所不同。

  • 动态内容：根据 AirDrop、信息等分享方式的不同，传输数据内容会有所区别。
  • 类型区分：系统会根据原始照片、编辑后照片或已认证版本提供相应的处理。
  • 全量数据选项：若用户选择“所有照片数据”，则包含唯一硬件标识符及未裁剪的原始视频片段。

USB 传输增强

Apple 还计划为 USB 连接引入 “Transfer with Provenance（携带来源信息传输）” 选项。当该功能启用时，通过 USB 线缆传输至 Mac 或 PC 的已认证照片将保留其原始来源数据，方便用户在跨设备操作时核实图片真实性。

总结

Apple 正开发 Apple Reference Image 功能以应对 AI 生成图像带来的挑战，旨在验证 iPhone 拍摄内容的真实性。该功能结合了云端认证、唯一 ID 分配及本地隐私保护机制，并支持在 USB 传输中保留来源数据。这体现了 Apple 在内容真实性与用户隐私平衡方面的技术布局。

新機能の導入

ITホームの報道によると、海外メディア9to5MacがApple iOS 27開発者プレビューベータ5コードにおいて「Apple Reference Image」という新機能を特定しました。この機能は、iPhoneで撮影された写真の出所が真正のものであるかを認証するために使用されます。

背景と目的

生成AI技術の急速な進歩に伴い、AIによって生成または高度に加工された画像が、実際の写真として偽装されることが容易になっています。かつては専門家が数時間かけて行っていた画像の修正が、現在では簡単なプロンプト入力だけでわずか数秒のうちに非常にリアルなコンテンツを作成できるようになりました。これを受け、Appleはユーザーが画像が実際にiPhoneで撮影されたものかどうかを判断するのを支援するため、「Apple Reference Image」認証機能を開発しました。

動作原理

Apple Reference Image機能は、Appleがユーザーの元の写真に直接アクセスする仕組みではありません。システムは、iPhoneで撮影された写真を認証のためにクラウドのセキュアな環境に転送し、認証が完了するとその写真に固有のIDを付与します。特定のカメラセンサーが改ざんまたは損傷していると検知された場合、システムはそのセンサーに関連する過去の認証記録を取り消す可能性があります。

プライバシー保護

この機能には一連のプライバシー保護メカニズムが含まれています。例えば、認証済みの写真は他のユーザーと共有でき、受信者のAppleデバイス上でその写真が依然として認証状態を維持しているかをローカルで確認できます。この過程において、ユーザーがどの画像を見ているかに関する情報はAppleに送信されません。

共有と転送

共有方法（AirDrop、メッセージなど）や写真のタイプ（オリジナル、編集済み、または認証済みバージョン）によって、転送されるデータの内容が異なる場合があります。ユーザーが「すべての写真データ」を選択して共有する場合、固有のハードウェア識別子や写真に関連する未編集のオリジナルビデオクリップが含まれる可能性があります。

また、AppleはUSB転送時に「Transfer with Provenance（出所情報を含む転送）」オプションを追加する計画です。この機能を有効にすると、MacやPCにUSB経由で転送された認証済み写真に出所データが保持され、ユーザーはデバイス上で画像のオリジナルの出所を簡単に確認できるようになります。

総評

Appleは生成AI技術の普及に伴う偽画像の判別を支援するため、「Apple Reference Image」という写真認証機能を開発中です。この機能は、クラウドベースの固有ID付与とローカル確認システムを通じて、プライバシーを保護しながらコンテンツの真偽を確認できるようにします。また、USB転送時にも出所情報を維持するオプションを提供することで、デバイス間でのデータ移動における信頼性を確保することを目指しています。

まとめ

Appleは生成AIによる偽画像の拡散に対抗するため、写真の真正性を証明する「Apple Reference Image」機能を開発しています。この機能はクラウド認証と固有IDの付与により、プライバシーを保護しながらコンテンツの信頼性を担保します。さらに、USB転送時にも出所情報を維持するオプションを提供し、デバイス間でのデータ移行における透明性と信頼性を向上させる計画です。

New Feature Introduction

According to a report by IT Home, the outlet 9to5Mac discovered a new feature called 'Apple Reference Image' in the Apple iOS 27 developer preview beta 5 code. This feature is designed to verify whether photos captured with an iPhone are authentic.

Background and Purpose

As generative AI technology advances rapidly, it is becoming increasingly easy for AI-generated or heavily modified images to masquerade as real photographs. Tasks that previously required hours of professional work can now produce highly realistic content in seconds using simple prompts. In response, Apple has developed the 'Apple Reference Image' authentication feature to help users determine whether an image was actually captured by an iPhone.

Mechanism and Operation

The Apple Reference Image feature does not involve Apple directly accessing a user's original photos. Instead, the system sends photos taken on an iPhone to a secure cloud environment for authentication; once verified, the photo is assigned a unique ID. If a specific camera sensor is detected as tampered with or damaged, the system may revoke previous authentication records associated with that specific sensor.

Privacy Protections

The feature includes several privacy mechanisms. For example, while verified photos can be shared with other users, the recipient's Apple device can verify the authentication status locally. During this process, no information regarding which specific images a user is viewing is transmitted to Apple.

Sharing and Data Transfer

The content of data sent may vary depending on the sharing method (such as AirDrop or Messages) and the type of photo (original, edited, or certified). If a user selects 'all photo data' when sharing, it may include unique hardware identifiers and unedited raw video clips related to the photo.

Additionally, Apple plans to introduce a 'Transfer with Provenance' option for USB transfers. When enabled, this ensures that authentication data is maintained when photos are transferred to a Mac or PC via USB, allowing users to easily verify the original source of an image on another device.

Summary

Apple is developing the 'Apple Reference Image' feature to help users distinguish between authentic photographs and AI-generated content. The system utilizes cloud-based unique IDs and local verification to maintain authenticity while ensuring user privacy. Furthermore, a 'Transfer with Provenance' option will be added for USB transfers to preserve source data when moving files between devices.
