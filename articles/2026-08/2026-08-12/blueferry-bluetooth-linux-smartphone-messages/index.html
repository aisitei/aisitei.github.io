BlueFerry 출시: 블루투스를 통해 Linux에서 iPhone 17 등 스마트폰의 메시지를 직접 송수신

2026-08-12

개요

IT소식에 따르면, 기술 매체 Linuxiac이 8월 10일 블로그를 통해 오픈 소스 프로젝트인 BlueFerry가 GitHub 플랫폼에 공개되었다고 보도했습니다. 이 프로젝트는 Bluetooth 방식을 통해 Linux 사용자가 iPhone 17 등과 같은 기종의 메시지를 직접 주고받을 수 있는 솔루션을 제공합니다.

사용자 경험

사용자는 BlueFerry 프로젝트를 통해 iPhone과 Linux PC를 페어링한 후, 데스크톱에서 iPhone으로 수신된 iMessage 및 SMS 내용을 확인할 수 있으며 대화창에서 직접 답장할 수도 있습니다. 새 메시지는 전화번호, iMessage가 등록된 Apple ID 이메일 또는 동기화된 연락처로 전송할 수 있습니다.

기술 구현

BlueFerry는 Mac 중개, 클라우드 서비스, Apple 로그인 또는 구독에 의존하지 않으며, 주로 다음 세 가지 Bluetooth 기술을 기반으로 합니다.

  • MAP over OBEX: 메시지 전송, 수신함 조회, 읽음 상태 및 메시지 전송 담당
  • PBAP over OBEX: vCard 형식으로 연락처 제공
  • Apple Notification Center Service: Bluetooth LE를 통해 추가적인 iPhone 알림을 제공하며, 일부 상황에서 참여자 파악이 어려운 그룹 채팅을 식별하는 데 도움을 줍니다.

제한 사항

BlueFerry는 페어링 후 확인 가능한 메시지만 인식할 수 있으며, iCloud Messages의 과거 내역을 검색하거나 기존 메시지 아카이브를 다운로드할 수 없습니다. 현재 버전에서는 첨부 파일, 메시지 반응(Reaction), 입력 상태, FaceTime, 통화 및 전체 전송 메시지 기록을 지원하지 않습니다.

개인정보 보호

기본적으로 이 애플리케이션은 무작위로 생성된 키를 사용하여 로컬에 저장된 메시지 내역과 동기화된 연락처를 암호화합니다. 키는 GNOME Keyring 또는 KDE Wallet에 저장됩니다. 사용자는 로컬 저장을 암호화하지 않거나, 로컬 데이터 보관을 완전히 비활성화하여 새 이벤트가 현재 세션에서만 잠시 머물도록 설정할 수도 있습니다.

총평

BlueFerry는 Linux 사용자가 별도의 클라우드나 Mac 중개 없이 Bluetooth를 통해 iPhone 17 등과 같은 기종의 메시지를 직접 주고받을 수 있게 하는 오픈 소스 프로젝트입니다. 로컬 데이터 암호화 기능을 제공하여 보안성을 확보하고 있으나, 현재 버전에서는 첨부 파일이나 FaceTime 등 일부 기능이 제한되어 있습니다.

项目概述

开源项目 BlueFerry 近期在 GitHub 平台上线，旨在为 Linux 用户提供一种通过蓝牙直接收发 iPhone（如 iPhone 17 等机型）iMessage 和短信的解决方案。用户在配对后可以在桌面端查看收到的消息内容，并支持直接回复至电话号码、已注册 iMessage 的 Apple ID 或同步的联系人。

技术实现

BlueFerry 的核心优势在于其独立性，不依赖 Mac 中继、云服务、Apple 登录或订阅。其主要采用以下三项蓝牙技术：

  • MAP over OBEX：负责消息传输、收件箱查询、已读状态和发送消息。
  • PBAP over OBEX：以 vCard 格式提供联系人信息。
  • Apple Notification Center Service：通过 Bluetooth LE 提供额外的 iPhone 通知，并协助识别群聊成员。

功能限制与隐私保护

目前该项目在功能上存在一定限制：

  • 仅能识别配对后收到的新消息，无法充当 iCloud Messages 历史浏览器或下载已有消息存档。
  • 当前版本不支持附件、消息反应、输入状态、FaceTime、通话以及完整的已发送消息历史。

在隐私保护方面，BlueFerry 默认使用随机生成的密钥加密本地存储的消息和联系人（支持 GNOME Keyring 或 KDE Wallet），并提供关闭加密或完全关闭本地数据保留的选项。

总结

BlueFerry 是一个为 Linux 用户提供的开源工具，通过蓝牙技术实现与 iPhone 端的 iMessage 和短信交互。该项目无需云端服务即可运行，但在附件支持和历史记录访问等方面仍有功能限制。

概要

ITニュースによると、技術メディアのLinuxiacは8月10日のブログにて、オープンソースプロジェクト「BlueFerry」がGitHubプラットフォームで公開されたことを報じました。このプロジェクトは、Bluetoothを通じてLinuxユーザーがiPhone 17などのデバイスと直接メッセージをやり取りできるソリューションを提供します。

ユーザー体験

ユーザーはBlueFerryプロジェクトを通じてiPhoneとLinux PCをペアリングすることで、デスクトップ上で受信したiMessageやSMSの内容を確認し、チャット画面から直接返信することができます。新しいメッセージは、電話番号、iMessageが登録されたApple IDのメールアドレス、または同期された連絡先に送信することが可能です。

技術的実装

BlueFerryはMacを介した中継、クラウドサービス、Appleへのログインやサブスクリプションに依存せず、主に以下の3つのBluetooth技術に基づいています。

  • MAP over OBEX: メッセージの送信、受信トレイの照会、既読状態、メッセージ送信を担当。
  • PBAP over OBEX: vCard形式で連絡先を提供。
  • Apple Notification Center Service: Bluetooth LEを通じて追加のiPhone通知を提供し、一部の状況において参加者の特定が困難なグループチャットを識別するのに役立ちます。

制限事項

BlueFerryはペアリング後に確認可能なメッセージのみを認識でき、iCloud Messagesの過去の履歴を検索したり、既存のメッセージアーカイブをダウンロードしたりすることはできません。現在のバージョンでは、添付ファイル、リアクション（Reaction）、入力中状態、FaceTime、通話、および全送信メッセージ履歴はサポートされていません。

プライバシー

このアプリケーションは、デフォルトでランダムに生成されたキーを使用して、ローカルに保存されたメッセージ履歴と同期された連絡先を暗号化します。キーはGNOME KeyringまたはKDE Walletに保存されます。ユーザーはローカル保存の暗号化を行わなかったり、ローカルデータの保存を完全に無効にして、新しいイベントを現在のセッションでのみ一時的に保持するように設定することも可能です。

総評

BlueFerryは、LinuxユーザーがクラウドやMacを介さず、Bluetoothを通じてiPhone 17などのデバイスと直接メッセージをやり取りできるようにするオープンソースプロジェクトです。ローカルデータの暗号化機能によりセキュリティを確保していますが、現バージョンでは添付ファイルやFaceTimeなど一部の機能に制限があります。

まとめ

BlueFerryは、Bluetoothを利用してLinux環境からiPhoneと直接メッセージのやり取りを可能にするオープンソースプロジェクトです。クラウドやMacを経由しない独自の仕組みでiMessageやSMSの送受信を実現し、ローカルでの暗号化によりプライバシーを保護します。現時点では添付ファイルやFaceTimeなどの一部機能には制限がありますが、Linuxユーザーにとって有用なソリューションを提供しています。

Overview

According to IT news, the technology outlet Linuxiac reported on August 10 that BlueFerry, an open-source project, has been released on the GitHub platform. This project provides a solution for Linux users to directly exchange messages with devices such as the iPhone 17 via Bluetooth.

User Experience

Through the BlueFerry project, users can pair an iPhone with a Linux PC to view iMessage and SMS content received on the phone directly on their desktop and reply within the chat window. New messages can be sent to phone numbers, Apple ID emails registered for iMessage, or synced contacts.

Technical Implementation

BlueFerry does not rely on Mac relays, cloud services, Apple logins, or subscriptions. It primarily utilizes the following three Bluetooth technologies:

  • MAP over OBEX: Handles message transmission, inbox browsing, read status, and delivery status.
  • PBAP over OBEX: Provides contacts in vCard format.
  • Apple Notification Center Service: Provides additional iPhone notifications via Bluetooth LE (BLE) and helps identify group chats where participants may be difficult to determine.

Limitations

BlueFerry can only recognize messages that are available after pairing; it cannot search past history or download existing archives from iCloud Messages. The current version does not support attachments, message reactions, typing indicators, FaceTime, calls, or full transmission logs.

Privacy

By default, the application encrypts locally stored message history and synced contacts using randomly generated keys. These keys are stored in GNOME Keyring or KDE Wallet. Users also have the option to not encrypt local storage or disable it entirely so that new events remain only for the current session.

Overall Review

BlueFerry is an open-source project that enables Linux users to exchange messages with devices like the iPhone 17 via Bluetooth without requiring cloud services or Mac intermediaries. While it ensures security through local data encryption, certain features such as attachments and FaceTime are currently limited in the current version.

Summary

BlueFerry is an open-source project that allows Linux users to communicate with iPhones via Bluetooth without relying on Apple's cloud services or Mac relay systems. While it provides a secure way to view and reply to iMessages and SMS, it currently lacks support for advanced features like attachments and FaceTime.
