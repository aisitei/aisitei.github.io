Google Pixel 11 스마트폰 표준 모델, 12GB RAM 기본 탑재 및 망원 카메라 포함이나 'HiLight' RGB 조명 기능은 제외

2026-08-12

기능 및 모델 차이

정보 소스 evowizz에 따르면, Google Pixel 11 표준 모델은 "HiLight" RGB 라이팅 기능을 제공하지 않으며, 해당 기능은 Pro 모델 전용으로 탑재될 예정입니다.

앞서 보도된 바와 같이, "HiLight" RGB 라이팅은 Google이 Pixel 11 시리즈를 위해 도입한 새로운 후면 원형 RGB 라이팅 기능입니다. 이 기능은 후면 카메라 모듈(Deco) 내부에 원형 컬러 LED 스트립을 통합한 것으로, 기기를 화면이 아래로 향하게 놓았을 때 시스템이 후면의 은은한 빛과 다양한 색상 및 동적 효과를 통해 사용자에게 알림을 제공합니다.

사양 정보

해당 소스에 따르면 Google Pixel 11 표준 모델은 다음과 같은 사양을 갖출 예정입니다.

  • 10.8MP 망원 렌즈
  • 12GB RAM 단일 버전

이는 이전에 제기된 "망원 렌즈 부재 및 8GB RAM 시작" 등의 루머가 사실이 아님을 시사합니다.

총평

Google Pixel 11 시리즈에서 "HiLight" RGB 라이팅 기능은 Pro 모델에만 독점적으로 탑재됩니다. 또한 표준 모델은 10.8MP 망원 렌즈와 12GB RAM을 탑재하여 기존의 사양 관련 루머를 반박하는 구성을 갖출 것으로 보입니다.

"HiLight" RGB 灯效功能

根据消息源 evowizz 的透露，Google Pixel 11 系列将推出全新的“HiLight”RGB 灯效。该功能在后置相机模组（Deco）内部集成了一圈环形彩色灯带，旨在当手机屏幕朝下放置时，通过背部的动态光影效果提醒用户。

相关信息指出，该项功能将作为 Pro 机型的专属配置，Pixel 11 标准版将不包含此项功能。

Pixel 11 标准版规格确认

针对 Pixel 11 标准版的硬件参数，消息源澄清了此前部分不实传闻：

  • 长焦镜头：配备 10.8Mp 长焦镜头。
  • 内存容量：仅提供 12GB RAM 版本（并非此前传闻的 8GB 起步）。

总结

Google Pixel 11 系列将引入“HiLight”环形 RGB 灯效，但该功能仅供 Pro 机型使用。此外，Pixel 11 标准版已确认配备 10.8Mp 长焦镜头并提供 12GB RAM 版本。

機能とモデルの差異

情報源evowizzによると、Google Pixel 11の標準モデルには「HiLight」RGBライティング機能は搭載されず、この機能はProモデル専用として搭載される予定です。

以前報じられた通り、「HiLight」RGBライティングは、GoogleがPixel 11シリーズ向けに導入する新しい背面の円形RGBライティング機能です。この機能は背面カメラモジュール（Deco）内に円形のカラーLEDストリップを統合したもので、デバイスを画面を下にした状態で置いた際に、システムが背面の淡い光やさまざまな色、動的なエフェクトを通じてユーザーに通知を知らせます。

スペック情報

同ソースによると、Google Pixel 11の標準モデルは以下の仕様を備える予定です。

  • 10.8MP 望遠レンズ
  • 12GB RAM 単一構成

これは、以前に浮上していた「望遠レンズの欠如」や「8GB RAMからスタート」といった噂が事実ではないことを示唆しています。

まとめ

Google Pixel 11シリーズにおいて、「HiLight」RGBライティング機能はProモデル限定の仕様となります。一方で標準モデルも、10.8MPの望遠レンズと12GB RAMを搭載する見込みであり、これまでのスペックに関する一部の噂を否定する構成となっています。

Features and Model Differences

According to information from evowizz, the Google Pixel 11 standard model will not feature the "HiLight" RGB lighting functionality; this feature is expected to be exclusive to the Pro models.

As previously reported, "HiLight" RGB lighting is a new rear circular RGB lighting feature introduced by Google for the Pixel 11 series. This feature integrates a circular color LED strip inside the rear camera module (Deco). When the device is placed face down, the system provides notifications to the user through subtle light, various colors, and dynamic effects from the back of the device.

Specification Information

According to the source, the Google Pixel 11 standard model is expected to feature the following specifications:

  • 10.8MP telephoto lens
  • 12GB RAM (single version)

This suggests that previous rumors regarding the "absence of a telephoto lens and an 8GB RAM starting point" are incorrect.

Summary

The Google Pixel 11 standard model will not include the "HiLight" RGB lighting feature, which remains exclusive to the Pro models. Furthermore, the standard model is expected to be equipped with a 10.8MP telephoto lens and 12GB of RAM, refuting earlier rumors regarding lower hardware specifications.
