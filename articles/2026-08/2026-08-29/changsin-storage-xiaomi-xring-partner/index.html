Xiaomi XRING O3, LPDDR6 메모리 핵심 파트너로 ChangXin Memory 지목

IT之家 8월 28일 소식에 따르면, ChangXin Memory Technologies Co., Ltd.가 공식 웨이보 계정을 개설했습니다. IT之家는 이 계정이 현재 세 개의 계정을 팔로우하고 있으며, 그중 첫 번째 팔로우 계정이 Xiaomi 휴대폰임을 확인했습니다.

IT之家의 이전 보도에 따르면, 이달 24일 Xiaomi의 첫 AI 플래그십 SoC XRING O3가 발표되었으며, 업계 최초로 LPDDR6를 지원합니다.

재롄서(财联社)가 공급망으로부터 입수한 정보에 따르면, 중국 스토리지 선두 기업인 ChangXin Memory가 Xiaomi XRING O3의 LPDDR6 메모리 핵심 파트너입니다. 이미 올해 3월부터 ChangXin Memory가 LPDDR6 제품 출시를 적극적으로 추진하고 있으며 핵심 고객에게 샘플을 보냈다는 시장 소식이 있었습니다. 올해 8월에는 여러 매체에서 ChangXin Memory의 LPDDR6가 검증 막바지에 이르렀다고 보도했습니다.

이번 XRING O3 칩 출시와 함께 국산 LPDDR6 칩 제품이 플래그십급 프로세서 칩에 처음으로 적용되었으며, 이는 국산 저전력 메모리가 공식적으로 글로벌 선두 그룹에 진입했음을 의미합니다.

  • Xiaomi XRING O3, 업계 최초 LPDDR6 메모리 지원, ChangXin Memory가 핵심 파트너라는 소식
  • ChangXin Memory의 LPDDR6가 연구 개발 검증 막바지에 이르렀으며, 올해 하반기 출시될 것이라는 소식

총평

ChangXin Memory가 공식 웨이보를 개설하며 Xiaomi 휴대폰을 첫 팔로우 계정으로 지정했습니다. 이는 Xiaomi의 첫 AI 플래그십 SoC인 XRING O3에 ChangXin Memory의 LPDDR6 메모리가 탑재될 것이라는 이전 보도를 뒷받침합니다. 이번 협력은 국산 LPDDR6 칩이 플래그십 프로세서에 처음 적용되는 사례로, 국산 저전력 메모리 기술이 글로벌 선두권에 진입했음을 보여줍니다.

新品发布与技术规格

  • Xiaomi于本月24日发布了首款AI旗舰SoC：XRING O3。
  • 该芯片的行业首发特性支持LPDDR6内存。

核心技术进展（LPDDR6）

长鑫存储在低功耗内存领域取得重要突破，其LPDDR6产品已接近验证尾声。

  • 本次应用标志着国产LPDDR6芯片首次在旗舰级处理器上实现落地。
  • 这使得国产低功耗内存正式跻身全球第一梯队。

产业链合作与合作伙伴

  • 长鑫存储技术有限公司已开通官方微博，并关注了Xiaomi手机等账号。
  • 根据供应链消息，国内存储龙头长鑫存储是Xiaomi XRING O3的LPDDR6内存核心合作伙伴。
  • 市场此前曾报道，长鑫存储自今年3月起便积极推进LPDDR6产品落地，并已向核心客户送样。

总结

本次消息的核心在于国产低功耗内存技术的重大突破。Xiaomi的XRING O3芯片首次搭载了由长鑫存储提供的LPDDR6内存，标志着国内存储芯片在旗舰级处理器领域的成功应用。这一进展不仅验证了长鑫存储的技术实力，也推动了中国本土低功耗内存迈入全球领先行列。

Xiaomi XRING O3、LPDDR6メモリの主要パートナーとしてChangXin Memoryが指名される

IT之家によると、ChangXin Memory Technologies Co., Ltd.が公式Weiboアカウントを開設したことが報じられました。同メディアが確認したところ、このアカウントは現在複数のアカウントをフォローしており、その中で最初のフォロー先がXiaomiのスマートフォンであることが判明しています。

これまでのIT知家の報道によれば、今月24日にXiaomi初のAIフラッグシップSoC「XRING O3」が発表されており、業界で初めてLPDDR6をサポートすることが注目されていました。

財聯社（Cailian She）がサプライチェーンから入手した情報によると、中国のストレージ大手であるChangXin Memoryは、「Xiaomi XRING O3」のLPDDR6メモリにおける主要パートナーであることが明らかになりました。市場の情報筋によれば、ChangXin Memoryは既に今年3月よりLPDDR6製品の投入を積極的に推進しており、主要顧客にサンプルを提供していました。そして今月8月には、複数のメディアからChangXin MemoryのLPDDR6が検証の最終段階に入ったと報じられています。

今回の「XRING O3」チップの発売に伴い、国産のLPDDR6チップ製品がフラッグシップ級プロセッサに初めて採用されることとなり、これは国内製の低消費電力メモリ技術が公式にグローバルな最先端グループに参入したことを意味します。

  • Xiaomi XRING O3は業界初のLPDDR6メモリをサポートし、ChangXin Memoryがその主要パートナーとなる見込みです。
  • ChangXin MemoryのLPDDR6は研究開発による検証が最終段階に達しており、今年下半期に市場投入されると報じられています。

まとめ

ChangXin Memoryが公式Weiboアカウントを開設し、Xiaomiスマートフォンを最初のフォロー先としたことは、同社のLPDDR6メモリが「XRING O3」に搭載されるというこれまでの報道を裏付けるものです。この提携は、国産のLPDDR6チップがフラッグシッププロセッサに初めて適用された事例であり、中国国内の低消費電力メモリ技術が国際的な最前線へと進出したことを示しています。

Xiaomi XRING O3 Names ChangXin Memory as Core Partner for LPDDR6 Memory

According to news reported by IT Home on August 28, ChangXin Memory Technologies Co., Ltd. has officially opened a Weibo account. IT Home noted that this newly created account is currently following three other accounts, the first of which is Xiaomi's official phone account.

Previous reports from IT Home stated that Xiaomi unveiled its first AI flagship SoC, XRING O3, on the 24th of this month, marking an industry first by supporting LPDDR6. Furthermore, information obtained by Cailian Source (财联社) from supply chain sources indicates that ChangXin Memory, a leading Chinese storage company, is the core partner for the LPDDR6 memory used in Xiaomi's XRING O3.

Market reports have previously indicated that ChangXin Memory has been actively promoting its LPDDR6 product since March of this year and has sent samples to key customers. By August, multiple media outlets reported that ChangXin Memory’s LPDDR6 was nearing the final stages of verification.

The launch of the XRING O3 chip marks the first time a domestically produced LPDDR6 chip product has been applied to a flagship processor, signifying that domestic low-power memory technology has officially entered the global leading group.

  • Xiaomi XRING O3 supports industry-first LPDDR6 memory, with ChangXin Memory identified as the core partner.
  • ChangXin Memory's LPDDR6 is reported to be nearing the end of R&D verification and expected to launch in the second half of this year.

Summary

The opening of a Weibo account by ChangXin Memory, with Xiaomi being its first followed account, corroborates previous reports that ChangXin Memory's LPDDR6 will be integrated into Xiaomi's XRING O3 AI flagship SoC. This collaboration is significant as it represents the first application of a domestic LPDDR6 chip in a flagship processor, demonstrating that China's low-power memory technology has successfully entered the global leadership tier.
