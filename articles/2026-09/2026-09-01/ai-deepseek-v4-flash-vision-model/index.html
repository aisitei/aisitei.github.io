DeepSeek-V4-Flash-Vision-Exp 모델 오픈소스 공개, 멀티모달 에이전트 기능 Opus-4.8에 근접

2026-09-01

DeepSeek V4 Flash Vision Exp 모델 출시

DeepSeek V4의 첫 번째 멀티모달 모델인 DeepSeek-V4-Flash-Vision-Exp가 MIT 라이선스로 Hugging Face에 오픈소스로 공개되었습니다.

공개된 내용에는 모델 파일, 토크나이저, 프롬프트 인코딩 참조 구현, 그리고 시각 인코더, Aligner, DFlash Attention, MoE, Hyper-Connections, DSpark 등 핵심 모듈을 포함하는 최소화된 PyTorch 추론 구현이 포함됩니다.

DeepSeek-V4-Flash-Vision-Exp는 DeepSeek V4 시리즈의 첫 번째 이미지 입력 지원 시각 모델이며, 공식적으로 "Exp" 실험 버전으로 명시되어 2026년 8월 21일 DeepSeek API 플랫폼에 출시되었습니다.

이 모델은 텍스트 외에 이미지를 입력할 수 있어, 이미지 설명, 스크린샷 내 텍스트 인식, 차트 분석 등의 기능을 수행할 수 있습니다. 지원되는 이미지 형식은 JPEG, PNG, GIF, WebP입니다.

DeepSeek은 V4-Flash-Vision-Exp가 다양한 Agent 프레임워크 내에서 우수한 멀티모달 적응 능력을 보여주며, 다양한 Agent 도구를 활용하여 더 많은 실용적인 작업 시나리오를 지원할 수 있다고 밝혔습니다. Agent, 추론, 세계 지식 등 순수 텍스트 작업에서는 V4-Flash 정식 버전과 동등한 성능을 유지하며 기존의 장점을 그대로 보존합니다. 시각적 이해가 필요한 Agent 벤치마크에서는 V4-Flash보다 크게 향상되었으며, 멀티모달 Agent 능력은 Opus-4.8에 근접합니다.

총평

DeepSeek-V4-Flash-Vision-Exp는 DeepSeek V4 시리즈의 첫 멀티모달 모델로, 이미지 입력 지원을 통해 텍스트와 이미지 정보를 동시에 처리할 수 있습니다. 이 모델은 Agent 프레임워크에서 뛰어난 멀티모달 적응 능력을 보여주며, 순수 텍스트 작업에서는 기존 V4-Flash 버전과 동등한 성능을 유지하고 시각적 이해가 필요한 Agent 작업에서는 크게 향상된 성능을 제공합니다.

新品发布与开源状态

  • DeepSeek V4 首个多模态模型 DeepSeek-V4-Flash-Vision-Exp 已在 Hugging Face 上线，并采用 MIT License 开源。
  • 该模型是 DeepSeek V4 系列首款原生支持图片输入的视觉模型，官方明确标注为“Exp”实验版本。

核心多模态能力

DeepSeek-V4-Flash-Vision-Exp 具备强大的视觉理解和分析能力，能够处理多种图像输入并执行复杂任务。

  • **支持功能：** 模型可实现图片描述、识别截图中的文字、以及分析图表等。
  • **支持格式：** 支持的图片格式包括 JPEG、PNG、GIF 和 WebP。

技术架构与开源内容

本次公开的内容为开发者提供了完整的模型组件和推理参考，便于社区进行研究和应用。

  • 公开资源包含： 模型文件、Tokenizer、Prompt Encoding 参考实现。
  • 核心模块覆盖： 最小化 PyTorch 推理实现涵盖了视觉编码器（Visual Encoder）、Aligner、DFlash Attention、MoE、Hyper-Connections 与 DSpark 等多个关键技术模块。

性能表现与应用前景

官方数据显示，该模型在多模态 Agent 应用场景中展现出极高的适配能力和优异的性能提升。

  • **纯文本任务保持：** 在 Agent、推理和世界知识等纯文本任务上，性能可与 V4-Flash 正式版持平，原有优势完整保留。
  • **视觉理解增强：** 在需要视觉理解的 Agent 基准测试中，表现较 V4-Flash 有大幅提升，多模态 Agent 能力已接近 Opus-4.8 的水平。

版本发布时间线

  • DeepSeek-V4-Flash-Vision-Exp 预计于 2026 年 8 月 21 日正式上线 DeepSeek API 平台。

总结

DeepSeek 发布了首个多模态实验版本 DeepSeek-V4-Flash-Vision-Exp，该模型已开源并在 Hugging Face 上线。它原生支持图片输入（如 JPEG、PNG 等），具备描述图像、识别文字和分析图表等功能。在保持纯文本任务性能的同时，其视觉理解能力大幅提升，使其成为多模态 Agent 框架的有力工具，预计将于 2026 年 8 月 21 日正式通过 API 提供服务。

DeepSeek V4 Flash Vision Exp モデルのリリース

DeepSeek V4初のマルチモーダルモデルである DeepSeek-V4-Flash-Vision-Exp が、MIT LicenseのもとHugging Faceでオープンソースとして公開されました。

今回公開された内容には、以下の要素が含まれています。

  • モデルファイル
  • トクナイザー（Tokenizer）
  • プロンプトエンコーディング参照実装
  • 視覚エンコーダー (Visual Encoder)、Aligner、DFlash Attention、MoE、Hyper-Connections、DSparkなどの中核モジュールを含む最小化されたPyTorch推論実装

DeepSeek-V4-Flash-Vision-Expは、DeepSeek V4シリーズにおける初の画像入力対応の視覚モデルであり、公式には「Exp」（実験版）として明記されています。なお、正式なリリースは2026年8月21日にDeepSeek APIプラットフォームで行われる予定です。

このモデルはテキストだけでなく画像をインプットとして受け付けるため、画像の説明生成、スクリーンショット内の文字認識（OCR）、チャート分析などの機能を実行できます。サポートされる画像形式は以下の通りです。

  • JPEG
  • PNG
  • GIF
  • WebP

DeepSeekによると、V4-Flash-Vision-Expは様々なAgentフレームワーク内で優れたマルチモーダル適応能力を発揮し、多様なAgentツールを活用することで、より多くの実用的なタスクシナリオをサポートできるとしています。純粋なテキスト作業（Agent、推論、世界知識など）においては、V4-Flashの正式バージョンと同等の性能を維持し、従来の利点をそのまま保持しています。一方、視覚的理解が必要なAgentベンチマークではV4-Flashよりも大幅に向上しており、マルチモーダルAgent能力はOpus-4.8に匹敵するとされています。

総評

DeepSeek-V4-Flash-Vision-Expは、DeepSeek V4シリーズ初のマルチモーダルモデルであり、画像入力に対応することでテキスト情報と画像情報を同時に処理できます。本モデルはAgentフレームワークにおいて優れたマルチモーダル適応能力を発揮しつつも、純粋なテキストタスクにおいては既存のV4-Flashバージョンと同等の性能を維持しています。特に視覚的理解が求められるAgent作業では大幅に性能が向上しており、実用的なAIアプリケーションへの応用が期待されます。

まとめ

DeepSeek V4シリーズ初のマルチモーダルモデル「DeepSeek-V4-Flash-Vision-Exp」がオープンソースとして公開されました。本モデルは画像入力に対応し、画像の説明やチャート分析など多岐にわたる視覚タスクを処理可能です。純粋なテキスト性能は既存のV4-Flashと同等レベルを維持しながらも、マルチモーダルAgent能力においては大幅な進化を遂げた点が最大の特徴です。

DeepSeek V4 Flash Vision Exp Model Release

The first multimodal model in the DeepSeek V4 series, DeepSeek-V4-Flash-Vision-Exp, has been open-sourced on Hugging Face under an MIT license.

The released content includes the model files, tokenizer, prompt encoding reference implementation, and a minimized PyTorch inference implementation featuring core modules such as the visual encoder, Aligner, DFlash Attention, MoE, Hyper-Connections, and DSpark.

DeepSeek-V4-Flash-Vision-Exp is the first vision model in the DeepSeek V4 series to support image input. It is officially designated as an "Exp" experimental version and was released on the DeepSeek API platform on August 21, 2026.

This model can accept images in addition to text inputs, allowing it to perform functions such as image description, text recognition within screenshots, and chart analysis. Supported image formats include JPEG, PNG, GIF, and WebP.

DeepSeek announced that V4-Flash-Vision-Exp demonstrates excellent multimodal adaptability across various Agent frameworks, enabling support for more practical task scenarios by utilizing diverse Agent tools. For pure text tasks—such as those involving Agents, inference, or world knowledge—it maintains performance equivalent to the standard V4-Flash version, preserving its existing strengths. However, in Agent benchmarks requiring visual understanding, it shows significant improvement over V4-Flash, bringing its multimodal Agent capability close to Opus-4.8.

Summary

DeepSeek-V4-Flash-Vision-Exp is the inaugural multimodal model of the DeepSeek V4 series, capable of processing both text and image information through image input support. The model demonstrates superior multimodal adaptability within Agent frameworks while maintaining performance parity with the standard V4-Flash version for pure text tasks. Crucially, it offers significantly enhanced performance in Agent tasks requiring visual understanding, achieving capabilities close to Opus-4.8.
