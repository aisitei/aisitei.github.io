Xiaomi, 산업용 화자 인식 대규모 모델 Xiaomi-CocktailASR-1 오픈소스 공개

2026-09-12

Xiaomi, 산업용 목표 화자 음성 인식 대규모 모델 오픈소스 공개

IT之家 9월 11일 소식에 따르면, Xiaomi 기술 부문은 오늘 Xiaomi-CocktailASR-1이라는 산업용 목표 화자 음성 인식 대규모 모델을 공식 발표하고 오픈소스로 공개했다고 밝혔습니다.

Xiaomi 측은 Xiaomi-CocktailASR-1이 "칵테일 파티 문제"를 해결하기 위해 개발되었다고 설명했습니다. (IT之家 주: 현재 음성 인식 기술은 한 사람이 말하는 내용을 높은 정확도로 인식할 수 있지만, 두 명 이상이 동시에 말할 경우 음성 인식률이 크게 떨어지는데, 이 문제를 칵테일 파티 문제라고 합니다.)

이 모델은 엔드투엔드 LLM 아키텍처를 채택했으며, 목표 화자의 참조 오디오를 음성 지문 프롬프트로 사용하여 여러 사람이 동시에 말하는 복잡한 환경에서도 목표 사용자의 음성만을 정확하게 추출하고 전사할 수 있습니다. 여러 주요 다중 화자 테스트 세트에서 SOTA(State-Of-The-Art) 성능을 달성하여 기존 솔루션을 크게 앞섰습니다.

또한, 이 모델은 단일 화자 인식 성능이 표준 ASR 모델에 필적하여 단일 화자 발화 시나리오를 원활하게 처리할 수 있습니다. 비목표 화자의 방해 음성을 거부하는 기능도 갖추고 있어 목표 화자가 없을 때는 빈 텍스트를 출력하여 오작동을 효과적으로 방지합니다. 이 외에도 사고의 사슬(Chain-of-Thought) 추론 모드를 지원하여 인식 결과에 대한 설명 가능한 추론 과정을 제공합니다.

총평

Xiaomi는 산업용 목표 화자 음성 인식 대규모 모델인 Xiaomi-CocktailASR-1을 오픈소스로 공개했습니다. 이 모델은 "칵테일 파티 문제" 해결을 목표로 하며, 엔드투엔드 LLM 아키텍처를 기반으로 다중 화자 환경에서 특정 화자의 음성만을 정확하게 인식합니다. SOTA 성능을 달성했으며, 단일 화자 인식 및 비목표 화자 음성 거부 기능도 갖추고 있습니다.

核心产品发布与定位

  • Xiaomi正式开源工业级目标说话人语音识别大模型：Xiaomi-CocktailASR-1。
  • 该模型旨在解决复杂的“鸡尾酒会”难题，即在多人同时交谈的复杂环境中进行精准语音识别。

技术架构与工作原理

  • 采用端到端 LLM 架构设计。
  • 通过目标说话人的一段参考音频作为声纹提示（Voiceprint）。
  • 核心功能是能在多说话人环境下，精准提取并仅转录指定目标用户的语音内容。

关键性能与识别能力

  • **多人环境识别：** 在多个主流多说话人测试集上达到 SOTA 级别，大幅领先现有方案。
  • **单人场景兼容性：** 单人识别性能可媲美标准 ASR 模型，实现无缝切换和兼顾。
  • **抗干扰与误报控制：** 具备拒识非目标说话人干扰语音的能力；当目标不在场时，系统能输出空文本，有效避免误触发。
  • **可解释性推理：** 支持思维链（Chain-of-Thought）推理模式，为识别结果提供清晰、可解释的推理过程。

模型获取与应用

  • 该模型已开源，用户可通过以下平台获取和使用：
  • GitHub 链接：https://github.com/xiaomi-research/xiaomi-cocktailasr-1
  • HuggingFace 链接：https://huggingface.co/Ease3/Xiaomi-CocktailASR-1

总结

小米发布了开源的 Xiaomi-CocktailASR-1 模型，解决了传统语音识别在多人交谈环境下的“鸡尾酒会”难题。该模型基于端到端 LLM 架构，利用声纹提示技术，能够在复杂背景下精准隔离并转录目标说话人的语音。其高性能和可解释的推理能力使其适用于需要高精度、抗干扰能力的工业级应用场景。

Xiaomi、産業用ターゲット話者音声認識大規模モデルをオープンソース公開

IT之家による9月11日の報道によると、Xiaomiの技術部門は本日、「Xiaomi-CocktailASR-1」という産業用ターゲット話者音声認識の大規模モデルを正式に発表し、オープンソースとして公開したと発表しました。

同社は、Xiaomi-CocktailASR-1が「カクテルパーティー問題」を解決するために開発されたと説明しています。（IT之家注：現在の音声認識技術では、一人の人物の発言を高精度で認識することは可能ですが、二名以上の人が同時に話す場合、認識率が大幅に低下する現象を「カクテルパーティー問題」と呼びます。）

このモデルはエンドツーエンドのLLMアーキテクチャを採用しており、ターゲットとなる話者の参照オーディオを音声フィンガープリントプロンプトとして使用することで、複数の人が同時に発言する複雑な環境下でも、ターゲットユーザーの声のみを正確に抽出・文字起こしすることが可能です。主要なマルチスピーカーテストセットにおいてSOTA（State-Of-The-Art）性能を達成し、既存のソリューションを大幅に凌駕しています。

さらに、このモデルは単一話者認識性能が標準的なASRモデルに匹敵するため、単一の話者が発言するシナリオも円滑に処理できます。また、ターゲットではない話者の妨害音声を拒否する機能も備えており、ターゲットとなる話者がいない場合は空のテキストを出力することで誤動作を効果的に防止します。その他、思考の連鎖（Chain-of-Thought）推論モードをサポートし、認識結果に対する説明可能な推論過程を提供します。

まとめ

Xiaomiは、産業用途に特化したターゲット話者音声認識の大規模モデル「Xiaomi-CocktailASR-1」をオープンソースとして公開しました。このモデルの最大の強みは、「カクテルパーティー問題」と呼ばれる複数人同時発言環境において、エンドツーエンドLLMアーキテクチャを用いて特定の人物の声のみを高精度で抽出できる点です。SOTA性能に加え、単一話者認識への対応や非ターゲット音声のノイズ除去機能も備え、実用的な応用が期待されます。

Xiaomi Releases Open-Source Large Model for Industrial Target Speaker Voice Recognition

According to news reported by IT之家 on September 11th, Xiaomi's technology division announced the official release and open-sourcing of a large model for industrial target speaker voice recognition called Xiaomi-CocktailASR-1.

Xiaomi explained that Xiaomi-CocktailASR-1 was developed to solve the "cocktail party problem." (Note: Current ASR technology can recognize speech from a single person with high accuracy, but when two or more people speak simultaneously, the recognition rate drops significantly; this issue is known as the cocktail party problem.)

The model adopts an end-to-end LLM architecture. By using reference audio of the target speaker as a voice fingerprint prompt, it can accurately extract and transcribe only the target user's voice even in complex environments where multiple people are speaking simultaneously. It achieved State-Of-The-Art (SOTA) performance across several major multi-speaker test sets, significantly surpassing existing solutions.

Furthermore, the model maintains single-speaker recognition performance comparable to standard ASR models, allowing it to smoothly handle single-speaker speech scenarios. It also features a function that rejects interfering noise from non-target speakers, effectively preventing malfunctions by outputting empty text when no target speaker is present. Additionally, it supports Chain-of-Thought (CoT) reasoning mode, providing an explainable inference process for the recognition results.

Summary

Xiaomi has open-sourced Xiaomi-CocktailASR-1, a large model designed for industrial target speaker voice recognition. The model specifically targets the "cocktail party problem," using an end-to-end LLM architecture to accurately isolate and transcribe only the intended speaker's voice in multi-speaker environments. It achieves SOTA performance while also maintaining strong single-speaker capabilities and incorporating features like noise rejection and Chain-of-Thought reasoning.
