Huawei 📱 스마트폰

Huawei Pura X View 바 타입 스마트폰, HarmonyOS 7.0.0.107 SP8 업데이트로 몰입형 광감도 균형 모드에 입자 애니메이션 효과 추가

2026-09-22

시스템 업데이트

Huawei Pura X View 바 타입 스마트폰이 HarmonyOS 7.0.0.107 SP8 버전으로 업데이트되었습니다. 시스템 패키지 크기는 약 4.88GB입니다. 새로운 버전에서는 몰입형 광감 균형 모드에 입자 애니메이션 효과가 추가되었으며, 카메라 야간 모드에는 화려한 별이 빛나는 밤하늘, 별이 빛나는 밤하늘 인물 촬영 장면 등이 추가되었습니다.

주요 업데이트 내용

  • 몰입형 광감 균형 모드에 입자 애니메이션 효과가 추가되었습니다. 알림 센터에서 알림을 제거하거나, 홈 화면에서 아이콘/카드를 제거하거나, 제어 센터에서 볼륨 바를 조절하는 등의 상황에서 입자 애니메이션 효과가 나타납니다 (설정 > 홈 화면 및 개인 설정 > 몰입형 광감 > 균형 모드).
  • 제어 센터 일부 아이콘의 표시 효과가 최적화되었습니다.
  • 알림 센터 미디어 제어 카드의 표시 효과가 최적화되었습니다.
  • 야간 모드에 화려한 별이 빛나는 밤하늘, 별이 빛나는 밤하늘 인물 촬영 장면이 추가되어 밤하늘과 별이 빛나는 밤하늘 아래 인물을 촬영할 때 새로운 경험을 제공하며, 더 많은 멋진 순간을 기록할 수 있도록 돕습니다.
  • 畅连 실시간 인터콤에 친구 찾기 기능이 추가되었습니다. 실시간 인터콤 위치 공유 중 친구가 근처에 있을 때, 친구 아바타의 찾기 아이콘을 클릭하면 안내에 따라 빠르게 친구를 찾을 수 있어 야외에서 만나거나 쇼핑몰에서 사람을 찾을 때 길을 잃지 않습니다.
  • 일부 시나리오에서 동반 AI 사용 경험이 최적화되었습니다.
  • 小艺 입력기의 시작 속도가 최적화되었습니다.
  • 오디오 외부 출력 효과가 최적화되었습니다.

성능

Huawei Pura X View는 Kirin 9030S 프로세서를 탑재했으며, 6400mm² VC 베이퍼 챔버를 갖추고 있습니다.

디스플레이

  • 전면에는 6.39인치 2232×1320 해상도의 OLED 바 타입 디스플레이가 적용되었으며, 화면 비율은 16:9.5입니다.
  • 화면 대 본체 비율은 96.1%에 달합니다.
  • 디스플레이는 120Hz 주사율, 2160Hz 고주파 PWM 디밍 및 6500nits 부분 피크 밝기를 지원하며, 쿤룬 글라스로 덮여 있습니다.

카메라

  • 후면에는 쿼드 카메라 시스템이 탑재되었습니다.
    • 2억 화소 RYYB 초집광 메인 카메라 (1/1.28인치 대형 센서, F1.8 조리개, OIS)
    • 5천만 화소 페리스코프 망원 카메라 (F2.6 조리개, OIS, 88mm 환산)
    • 8백만 화소 초광각 카메라
    • 2세대 홍펑 원색 카메라
  • 전면 카메라는 4천만 화소 렌즈 (1/2.55인치)입니다.

배터리 및 기타 기능

  • Huawei Pura X View는 7000mAh 실리콘 음극 배터리를 내장했으며, 66W 유선 충전과 50W 무선충전을 지원합니다.
  • 기기 두께는 약 6.68mm, 무게는 약 201g입니다.
  • 색상은 跃影红, 亚麻灰, 零度白, 幻夜黑 네 가지를 제공합니다.
  • IP68 및 IP69 방진 방수, 양방향 Beidou 위성 메시지 및 eSIM 기능을 지원합니다.

총평

Huawei Pura X View는 HarmonyOS 7.0.0.107 SP8 업데이트를 통해 카메라 야간 모드 기능과 시스템 애니메이션 효과가 개선되었습니다. Kirin 9030S 프로세서를 탑재하고 6.39인치 OLED 바 타입 디스플레이를 갖췄으며, 2억 화소 메인 카메라를 포함한 쿼드 카메라 시스템과 7000mAh 대용량 배터리를 제공합니다. 또한 IP68/IP69 방진 방수 및 양방향 Beidou 위성 메시지 기능을 지원하여 전반적으로 강력한 성능과 다양한 기능을 갖춘 스마트폰입니다.

系统软件升级与功能优化

  • HarmonyOS 7.0.0.107 SP8 版本更新： Huawei Pura X View 迎来了鸿蒙 HarmonyOS 7.0.0.107 SP8 版本升级，系统包大小约 4.88 GB。
  • 沉浸光感增强： “沉浸光感均衡档”新增粒子动效，适用于通知中心移除通知、桌面移除图标/卡片、控制中心调节音量条等多个场景。
  • 夜景拍摄升级： 夜景模式新增“绚丽星空”、“星空人像”等拍摄场景，提升用户在夜间记录精彩瞬间的能力。
  • AI与通讯优化： 优化部分场景伴随式 AI 的使用体验；增强畅连实时对讲功能，支持查找好友定位指引，方便户外寻找人员。

移动设备核心硬件配置

  • 处理器与散热： 搭载麒麟 9030S 处理器，配备 6400mm² VC 均热板。
  • 屏幕规格： 正面采用一块 6.39 英寸、2232×1320 分辨率的 OLED 바 타입屏，屏幕比例为 16:9.5，屏占比达 96.1%。
  • 显示技术指标： 支持 120Hz 刷新率、2160Hz 高频 PWM 调光及 6500nits 局部峰值亮度，并覆盖昆仑玻璃。

专业影像系统

  • 后置四摄系统： 配备包括 2 亿像素 RYYB 超聚光主摄（1/1.28 英寸大底传感器，F1.8 光圈，OIS）、5000 万像素潜望长焦（F2.6 光圈，OIS，等效 88mm）、800 万像素超广角及第二代红枫原色摄像头。
  • 前置镜头： 配备 4000 万像素自拍镜头（1/2.55 英寸）。

续航、耐用性与连接功能

  • 电池与充电： 内置 7000mAh 硅负极电池，支持 66W 有线快充和 50W 无线充电。
  • 机身设计与防护： 机身厚度约 6.68mm，重约 201g；支持 IP68 与 IP69 防尘防水等级。
  • 特殊功能： 支持双向北斗卫星消息和 eSIM 功能。

总结

本次更新主要围绕 HarmonyOS 7.0.0.107 SP8 版本，在系统体验、夜景拍摄和AI辅助功能上进行了全面升级。从硬件角度看，Huawei Pura X View 搭载麒麟 9030S处理器，拥有6.39英寸高规格OLED屏幕，并配备了2亿像素主摄和7000mAh大容量电池，同时具备IP68/IP69防护及卫星通信能力，是一款功能全面且配置顶级的旗舰机型。

システムアップデート

Huawei Pura X View バ（Bar）タイプのスマートフォンが、HarmonyOS 7.0.0.107 SP8バージョンにアップデートされました。システムパッケージのサイズは約4.88GBです。新バージョンでは、「没入型光感バランスモード」に粒子アニメーション効果が追加され、カメラの夜間モードには、華やかな星空や「星降る夜空（별이 빛나는 밤하늘）」をテーマにした人物撮影シーンなどが追加されています。

主なアップデート内容

  • 没入型光感バランスモードに粒子アニメーション効果が追加されました。通知センターでの通知削除時、ホーム画面でのアイコン/カードの削除時、コントロールセンターでの音量バー調整時など、様々な状況で粒子アニメーション効果が表示されます（設定 > ホーム画面とパーソナライゼーション > 没入型光感 > バランスモード）。
  • コントロールセンターの一部のアイコン表示効果が最適化されました。
  • 通知センターのメディアコントロールカードの表示効果が最適化されました。
  • 夜間モードに、華やかな星空や「星降る夜空」をテーマにした人物撮影シーンが追加され、夜空や星空の下で人物を撮影する際に新しい体験を提供し、より多くの素晴らしい瞬間を記録できるよう支援します。
  • 「暢連（チャングリエン）」のリアルタイムインターコム機能に「友達検索」機能が追加されました。リアルタイムインターコムでの位置情報共有中に友人が近くにいる場合、友達アバターの検索アイコンをクリックすると案内に従って素早く友人を見つけることができ、屋外やショッピングモールで迷子になることを防ぎます。
  • いくつかのシナリオにおいて、コンパニオンAIの使用体験が最適化されました。
  • 小艺（シャオイー）入力機の起動速度が最適化されました。
  • オーディオ外部出力効果が最適化されました。

カメラ

    • 5000万画素ペリスコープ望遠カメラ（F2.6絞り、OIS、88mm相当）

バッテリーとその他の機能

  • 本体の厚さは約6.68mm、重さは約201gです。

  • IP68およびIP69の防塵防水に対応し、双方向Beidou衛星メッセージ機能とeSIM機能をサポートします。

まとめ

Huawei Pura X Viewは、HarmonyOS 7.0.0.107 SP8へのアップデートにより、没入感のあるシステムアニメーションや夜間撮影モードが大幅に強化されました。Kirin 9030Sプロセッサを搭載し、6.39インチのOLEDバタイプディスプレイと2億画素メインカメラを含むクアッドカメラシステムを備えています。さらに、7000mAhの大容量バッテリーに加え、IP68/IP69対応や双方向Beidou衛星メッセージ機能など、高い性能と多様な実用性を兼ね備えた高性能スマートフォンです。

System Update

The Huawei Pura X View bar-type smartphone has been updated to HarmonyOS 7.0.0.107 SP8. The system package size is approximately 4.88GB. This new version introduces particle animation effects to the Immersive Sight Balance Mode, and enhances the camera night mode with features like starry sky scenes and portrait shots under a dazzling night sky.

Key Updates

  • Particle animation effects have been added to the Immersive Sight Balance Mode. These animations appear when removing notifications from the notification center, removing icons/cards from the home screen, or adjusting volume bars in the control center (Settings > Home Screen & Personalization > Immersive Sight > Balance Mode).
  • The display effect for some Control Center icons has been optimized.
  • The display effect for the Notification Center media control card has been optimized.
  • Night mode now includes starry sky and portrait shooting scenes under a dazzling night sky, offering new experiences when capturing photos of subjects against the night sky and helping users record more wonderful moments.
  • The Friend Finding feature has been added to the Live Intercom function. When sharing live intercom location, users can click the friend avatar's finding icon to quickly locate friends, ensuring you don't get lost when meeting people outdoors or shopping in a mall.
  • The user experience for Companion AI has been optimized in certain scenarios.
  • The startup speed of the Xiaoyi input method has been optimized.
  • Audio external output effects have been optimized.

Performance

The Huawei Pura X View is equipped with the Kirin 9030S processor and features a 6400mm² VC vapor chamber.

Display

  • It features a 6.39-inch OLED bar-type display with a resolution of 2232×1320, sporting a screen ratio of 16:9.5.
  • The device boasts a high screen-to-body ratio of 96.1%.
  • The display supports a 120Hz refresh rate, 2160Hz high-frequency PWM dimming, and a peak brightness of 6500nits, all protected by Kunlun Glass.

Camera

  • The rear camera features a quad-camera system:
    • 200MP RYYB main camera (1/1.28-inch large sensor, F1.8 aperture, OIS)
    • 50MP periscope telephoto camera (F2.6 aperture, OIS, 88mm equivalent)
    • 8MP ultra-wide-angle camera
    • Second-generation Hongfeng color camera
  • The front camera is a 40MP lens (1/2.55-inch).

Battery and Other Features

  • The Huawei Pura X View is built with a 7000mAh silicon anode battery, supporting 66W wired charging and 50W wireless charging.
  • The device has an approximate thickness of 6.68mm and weighs about 201g.
  • Available colors include Yueying Red, Linen Gray, Zero White, and Phantom Night Black.
  • It supports IP68 and IP69 dust/water resistance, bidirectional Beidou satellite messaging, and eSIM functionality.

Summary

The Huawei Pura X View received an update to HarmonyOS 7.0.0.107 SP8, improving features such as the camera night mode and system animations. Powered by the Kirin 9030S processor and featuring a 6.39-inch OLED display, it is equipped with a quad-camera system including a 200MP main lens and a massive 7000mAh battery. Furthermore, its support for IP68/IP69 dust/water resistance and bidirectional Beidou satellite messaging establishes it as a powerful smartphone with comprehensive functionality.
