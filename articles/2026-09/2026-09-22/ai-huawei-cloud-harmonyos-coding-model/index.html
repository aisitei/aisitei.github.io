Huawei Cloud CodeArts 업데이트

HarmonyOS 코딩 대규모 모델

Huawei Cloud의 독점적인 HarmonyOS 강화 훈련 시스템을 기반으로, HarmonyOS 코딩 대규모 모델은 100만 개 이상의 HarmonyOS 원본 자료를 통합하고 우수한 HarmonyOS 프로젝트 코드 라이브러리 및 컴포넌트 자산(오픈 소스 샘플, HarmonyOS API, 개발 사양 및 UI/UX 레이아웃 템플릿 포함)을 심층 학습하여 ArkTS 언어 및 HarmonyOS 개발 패러다임에 깊이 있게 적응합니다.

  • 훈련 데이터의 "더욱 완전성": 10만 개 이상의 HarmonyOS 고품질 데이터, 고빈도 HarmonyOS 개발 시나리오 컴포넌트 100% 커버리지, HarmonyOS API, 개발 사양, 코드 라이브러리 및 컴포넌트 자산 포함.
  • 코드 생성의 "더욱 정확성": 천 줄당 코드 오류율 80% 이상 감소, 개발자의 디버깅 부담 근본적으로 경감.
  • 컴파일 통과의 "더욱 안정성": 1회 컴파일 통과율 78% 이상 향상.
  • Token 소모의 "더욱 절약성": 단일 작업 Token 소모 20% 이상 감소.

HarmonyOS 인텔리전트 에이전트

HarmonyOS 코딩 인텔리전트 에이전트는 요구 사항 정리, 솔루션 설계, 코드 작성부터 컴파일 및 빌드까지 전 과정을 원스톱으로 처리하여 개발자의 반복적인 개입을 줄이고 HarmonyOS 애플리케이션의 엔드투엔드 개발을 실현합니다.

또한 인텔리전트 에이전트에는 DevEco CLI가 내장되어 있어 HarmonyOS 단말 시뮬레이터를 직접 호출할 수 있으며, 개발 결과를 즉시 확인하고 조정할 수 있습니다. 이는 업계 최초의 기능입니다. 이를 통해 HarmonyOS 애플리케이션이 다양한 휴대폰, 태블릿 등 단말 장치 크기에 자연스럽게 적응하고, 모든 HarmonyOS 단말 형태를 자유롭게 선택할 수 있습니다.

HarmonyOS 코딩 인텔리전트 에이전트에는 HarmonyOS 지식 베이스, 서드파티 라이브러리 변환, 미니 프로그램 메타 서비스 전환 등의 기능도 내장되어 있으며, 문서, API, 모범 사례가 실시간으로 업데이트되어 개발자가 즉시 사용할 수 있습니다.

HarmonyOS 개발자 실천 센터

  • 다중 시나리오 실천 사례: 내부 전문가와 생태계 개발자의 우수한 실천 사례를 모아 입문, 심화, 기업 수준의 실전 사례를 제공하며, 더 이해하기 쉬운 솔루션으로 개발자가 아이디어를 이해하고 방법을 배울 수 있도록 합니다.
  • 클라우드 실천 센터: 복잡한 환경 설정에서 벗어나 브라우저를 열어 개발, 컴파일, 패키징 및 테스트를 할 수 있습니다. 실천 센터는 사례, 코드 저장소 및 개발 환경을 연결하여 개발자가 관심 있는 사례를 발견하면 원클릭으로 클라우드 환경에 접속하여 실천 작업을 수행할 수 있도록 하여 진정한 "학습을 통한 활용"을 실현합니다.

Huawei Cloud CodeArtsのアップデート

Huawei Cloudは本日（9月21日）、HarmonyOS開発者向けにCodeArtsコードインテリジェントエージェントが全面的にアップグレードされたと発表しました。今回のアップグレードにより、「HarmonyOSコーディング大規模モデル」「CodeArts HarmonyOSインテリジェントエージェント」「HarmonyOS開発者実践センター」という3つの主要機能が追加されました。これは、HarmonyOSエコシステムのために特別に設計された、世界初かつ唯一のAIコーディングインテリジェントエージェントです。

HarmonyOSコーディング大規模モデル

Huawei Cloud独自のHarmonyOS強化トレーニングシステムに基づき、この大規模モデルは100万以上のHarmonyOSオリジナルデータを取り込みます。さらに、優れたHarmonyOSプロジェクトコードライブラリやコンポーネント資産（オープンソースサンプル、HarmonyOS API、開発仕様、UI/UXレイアウトテンプレートを含む）を深く学習することで、ArkTS言語およびHarmonyOSの開発パラダイムに高度に適応しています。

  • トレーニングデータの「完全性」向上： 10万以上の高品質なHarmonyOSデータに加え、高頻度のHarmonyOS開発シナリオコンポーネントを100%カバー。HarmonyOS API、開発仕様、コードライブラリ、コンポーネント資産を含みます。
  • コード生成の「正確性」向上： 1,000行あたりのコードエラー率が80%以上減少し、開発者のデバッグ負担を根本的に軽減します。
  • コンパイル合格の「安定性」向上： 1回のコンパイルでの合格率が78%以上向上しました。
  • トークン消費の「節約性」向上： 単一タスクあたりのトークン消費量を20%以上削減します。

HarmonyOSインテリジェントエージェント

HarmonyOSコーディングインテリジェントエージェントは、要件定義からソリューション設計、コード作成、コンパイル、ビルドに至る全プロセスをワンストップで処理し、開発者の手動介入を減らしながら、HarmonyOSアプリケーションのエンドツーエンドな開発を実現します。

また、このインテリジェントエージェントにはDevEco CLIが内蔵されており、HarmonyOS端末シミュレーターを直接呼び出すことができます。これは業界初の機能であり、開発結果を即座に確認し調整することが可能です。これにより、HarmonyOSアプリケーションが多様なスマートフォンやタブレットなどのデバイスサイズに自然に適応し、あらゆるHarmonyOS端末形態を自由に選択できます。

さらに、本エージェントにはHarmonyOSの知識ベース、サードパーティライブラリへの変換機能、ミニプログラムメタサービスへの切り替え機能なども内蔵されており、ドキュメント、API、ベストプラクティスがリアルタイムで更新され、開発者がすぐに利用できます。

HarmonyOS開発者実践センター

  • 多シナリオの実践事例： 社内専門家やエコシステム開発者の優れた実例を集約し、初心者向けから高度なレベル、企業レベルの実践的なケースを提供します。これにより、開発者はより理解しやすいソリューションを通じてアイデアを把握し、方法を学ぶことができます。

Huawei Cloud CodeArts Update

Today (September 21), Huawei Cloud announced that its CodeArts intelligent agent for coding has been fully upgraded for HarmonyOS developers. This upgrade introduces three core features: the "HarmonyOS Coding Large Model," the "CodeArts HarmonyOS Intelligent Agent," and the "HarmonyOS Developer Practice Center." These components together form the world's first and only AI coding intelligent agent specifically designed for the HarmonyOS ecosystem.

HarmonyOS Coding Large Model

Based on Huawei Cloud’s proprietary HarmonyOS reinforcement training system, the HarmonyOS Coding Large Model deeply adapts to the ArkTS language and the HarmonyOS development paradigm by integrating over one million pieces of original HarmonyOS data. It also learns from excellent HarmonyOS project code libraries and component assets (including open-source samples, HarmonyOS APIs, development specifications, and UI/UX layout templates).

  • "Greater Completeness" in Training Data: Includes over 100,000 pieces of high-quality HarmonyOS data, 100% coverage of high-frequency HarmonyOS development scenario components, HarmonyOS APIs, development specifications, and code/component assets.
  • "Greater Accuracy" in Code Generation: Reduces the code error rate per thousand lines by over 80%, fundamentally easing the debugging burden for developers.
  • "Greater Stability" in Compilation Passing: Improves the single-pass compilation success rate by over 78%.
  • "Greater Efficiency" in Token Consumption: Decreases single-task token consumption by more than 20%.

HarmonyOS Intelligent Agent

The HarmonyOS Coding Intelligent Agent handles the entire process—from requirement gathering and solution design to code writing, compilation, and building—in a one-stop manner. This significantly reduces the need for repetitive developer intervention and enables end-to-end development of HarmonyOS applications.

Furthermore, the intelligent agent integrates DevEco CLI, allowing it to directly call the HarmonyOS terminal simulator. Developers can instantly verify and adjust development results. This is an industry first feature that allows HarmonyOS applications to naturally adapt to various device sizes, such as phones and tablets, and freely select all forms of HarmonyOS terminals.

The agent also incorporates features like a HarmonyOS knowledge base, third-party library conversion, and mini-program meta service switching. Documentation, APIs, and best practices are updated in real time, making them immediately available for developers to use.

HarmonyOS Developer Practice Center

  • Multi-Scenario Practical Cases: Collects excellent practical examples from internal experts and ecosystem developers, providing case studies ranging from beginner to advanced and enterprise levels. This helps developers understand ideas and learn methods through more digestible solutions.
  • Cloud Practice Center: Allows development, compilation, packaging, and testing via a browser, eliminating the need for complex environment setup. The Practice Center connects cases, code repositories, and development environments, enabling developers to access the cloud environment with one click to perform practical work when they discover an interesting case, thereby realizing true "learning through application."

Summary

Huawei Cloud has significantly upgraded its CodeArts intelligent agent for HarmonyOS developers. This update introduces three key components—the HarmonyOS Coding Large Model, the HarmonyOS Intelligent Agent, and the HarmonyOS Developer Practice Center—providing an AI coding solution specialized for the HarmonyOS ecosystem. These features greatly enhance the efficiency and accuracy of HarmonyOS development, helping developers build applications more easily and quickly.
