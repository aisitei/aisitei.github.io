LongCat-2.5-Preview 모델 출시

Meituan의 LongCat API 오픈 플랫폼은 9월 25일 차세대 대규모 모델인 LongCat-2.5-Preview를 출시했습니다. 이 모델은 "장기 작업" 및 멀티모달 기능을 중심으로 하며, API 및 웹 페이지 체험 입구를 동시에 개방했습니다.

IT之家가 제공하는 공식 업데이트 로그 내용은 다음과 같습니다:

LongCat-2.5-Preview의 핵심 기능은 다음과 같습니다:

  • 멀티모달 이해: 이미지 이해 기능이 새로 추가되어 이미지 콘텐츠를 분석하고, 교차 모달 질의응답, 콘텐츠 요약 및 복잡한 시각적 추론을 지원합니다.
  • 탁월한 코딩 능력: 코드 생성, 코드 이해 및 자동화 프로그래밍 작업에서 뛰어난 성능을 보여줍니다.
  • Claude Code 등 주요 개발 환경에 대한 심층 적응: Claude Code, Hermes, OpenClaw, OpenCode, Kilo Code와 효율적으로 협업합니다.

공식 발표 정보에 따르면, LongCat-2.5-Preview 모델은 MoE(혼합 전문가) 방식을 계승하며, 총 파라미터 수는 약 1조 6천억 개이고, 추론 시 활성화되는 파라미터는 약 480억 개입니다. 이 모델은 기본적으로 100만 토큰의 컨텍스트 창을 지원하여 초장문서, 코드 라이브러리, 로그 및 다단계 복잡한 작업을 처리하는 데 적합합니다.

총평

Meituan의 LongCat API 플랫폼은 장기 작업과 멀티모달 기능을 강화한 LongCat-2.5-Preview 모델을 출시했습니다. 이 모델은 이미지 이해, 탁월한 코딩 능력, 그리고 주요 개발 환경과의 호환성을 특징으로 합니다. MoE 아키텍처를 기반으로 100만 토큰의 컨텍스트 창을 지원하여 복잡하고 방대한 데이터를 효율적으로 처리할 수 있습니다.

模型发布与平台入口

  • 美团旗下 LongCat API 开放平台于 9 月 25 日上线了新一代大模型 LongCat-2.5-Preview。
  • 该版本主打“长程任务”处理能力和多模态理解功能，并同步开放了 API 和网页端体验入口。

核心技术架构与参数

  • **模型路线：** 延续 MoE（混合专家）架构。
  • **总参数量：** 约达到 1.6 万亿。
  • **推理激活参数：** 每次推理激活参数约为 480 亿。
  • **上下文窗口：** 原生支持高达 100 万 token 的超长上下文窗口，适用于处理超长文档、代码库、日志和多轮复杂任务。

关键能力与应用场景

  • **多模态理解能力：** 新增图片解析功能，支持跨模态问答、内容摘要以及复杂的视觉推理任务。
  • **卓越的 Coding 能力：** 在代码生成、代码理解和自动化编程等开发任务上表现突出。

生态适配与协同

  • LongCat-2.5-Preview 模型具备深度适配能力，能够与主流开发环境高效协同，包括 Claude Code、Hermes、OpenClaw、OpenCode 和 Kilo Code 等。

总结

美团通过 LongCat API 开放平台发布了新一代大模型 LongCat-2.5-Preview。该模型基于 MoE 架构，拥有高达 100 万 token 的超长上下文窗口和 1.6 万亿的总参数量。其核心优势在于集成了多模态理解能力和强大的代码处理能力，旨在解决复杂、跨领域的“长程任务”需求。

LongCat-2.5-Preview モデルのリリース

美団（Meituan）が提供するLongCat APIオープンプラットフォームは、次世代の大規模モデル「LongCat-2.5-Preview」を9月25日にリリースしました。このモデルは、「長文処理タスク（Long Task）」とマルチモーダル機能を主軸としており、API経由およびウェブページでの体験アクセスポイントが同時に公開されています。

公式アップデートログによると、LongCat-2.5-Previewの主な機能は以下の通りです。

  • マルチモーダル理解: 画像理解機能が新たに搭載され、画像コンテンツの分析、クロスモーダルな質疑応答、コンテンツ要約、および複雑な視覚的推論をサポートします。
  • 卓越したコーディング能力: コード生成、コードの理解、自動化プログラミング作業において高い性能を発揮します。
  • 主要開発環境への深い適応性: Claude Code、Hermes、OpenClaw、OpenCode、Kilo Codeといった主要な開発環境と効率的に連携することが可能です。

公式発表の情報によれば、LongCat-2.5-PreviewモデルはMoE（Mixture of Experts：混合専門家）方式を継承しており、総パラメータ数は約1兆6,000億個、推論時にアクティブ化されるパラメータは約480億個に及びます。このモデルは基本的に100万トークンのコンテキストウィンドウをサポートしているため、超長文ドキュメント、コードライブラリ、ログファイル、および多段階の複雑なタスク処理に適しています。

LongCat-2.5-Preview Model Launch

Meituan's LongCat API open platform launched LongCat-2.5-Preview, its next-generation large model, on September 25th. This model focuses on "long-context tasks" and multimodal capabilities, opening access simultaneously through both the API and a web page experience.

According to the official update log provided by IT之家:

The core features of LongCat-2.5-Preview include:

  • Multimodal Understanding: Newly added image understanding capabilities allow it to analyze image content, supporting cross-modal Q&A, content summarization, and complex visual reasoning.
  • Exceptional Coding Ability: It demonstrates outstanding performance in code generation, code comprehension, and automated programming tasks.
  • Deep Adaptation to Major Development Environments: It efficiently collaborates with Claude Code, Hermes, OpenClaw, OpenCode, and Kilo Code.

According to the official announcement, the LongCat-2.5-Preview model inherits the MoE (Mixture of Experts) architecture, boasting a total parameter count of approximately 1.6 trillion parameters, with about 48 billion parameters activated during inference. Furthermore, this model natively supports a 1 million token context window, making it suitable for processing ultra-long documents, code libraries, logs, and multi-step complex tasks.

Overview

Meituan's LongCat API platform has released the LongCat-2.5-Preview model, enhancing its capabilities in long-context tasks and multimodal functions. Key features of this model include image understanding, exceptional coding ability, and compatibility with major development environments. Built on an MoE architecture and supporting a 1 million token context window, it can efficiently process complex and vast amounts of data.

Meituan launched LongCat-2.5-Preview via its LongCat API platform, focusing on advanced long-context tasks and multimodal capabilities. The model features image understanding, superior coding skills, and deep integration with major development tools like Claude Code. Leveraging an MoE architecture with a 1 million token context window, it is designed to handle complex data processing efficiently.
