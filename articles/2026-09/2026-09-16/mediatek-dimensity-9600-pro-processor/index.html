性能

MediaTekは、フラッグシップの新製品発表会において「Dimensity 9600 Pro」を発表しました。公式発表によると、このプロセッサはTSMCの最新2nmプロセス技術を採用する予定です。

Dimensity 9600 Proは330億個以上のトランジスタを搭載し、「業界最高水準」であるとされています。MediaTekはTSMCと共同で先端プロセス技術の研究を行い、設計・プロセス共最適化（DTCO）を実現しました。

また、本プロセッサは「AIネイティブアーキテクチャ」を採用することで、電力効率を大幅に改善しています。（Dimensity 9500と比較して）

  • ウルトラコアの消費電力を37%削減
  • マルチコアの消費電力を61%削減

アーキテクチャ面では、以下の構成となっています。

  • デュアルウルトラコア：C2-Ultra 4.55GHz
  • トリプルコア：C2-Pro 4.35GHz
  • トリプルコア：C2-Pro 3.1GHz

さらに、L2+L3+システムキャッシュとして34.5MBを搭載し、LPDDR6メモリおよびUFS 5.0フラッシュストレージのサポートを初めて実現しました。

Performance

MediaTek unveiled the Dimensity 9600 Pro during its latest flagship product launch event. According to the official announcement, this processor is set to adopt TSMC's cutting-edge 2nm process technology.

The Dimensity 9600 Pro features over 33 billion transistors, positioning it as "industry-leading." MediaTek achieved Design and Technology Co-Optimization (DTCO) by collaborating with TSMC on advanced manufacturing processes.

Furthermore, the processor incorporates an "AI Native Architecture," resulting in significant power efficiency improvements compared to the Dimensity 9500: a 37% reduction in Ultra Core power consumption and a 61% reduction in Multi Core power consumption.

In terms of architecture, the chip is composed of:

  • Dual Ultra Cores (C2-Ultra) clocked at 4.55GHz
  • Triple Cores (C2-Pro) clocked at 4.35GHz
  • Triple Cores (C2-Pro) clocked at 3.1GHz

It also features a substantial 34.5MB of L2+L3 system cache and is the first to support both LPDDR6 memory and UFS 5.0 flash storage.

Overview

The MediaTek Dimensity 9600 Pro boasts industry-leading performance, manufactured using TSMC's latest 2nm process and incorporating over 33 billion transistors. By utilizing an AI Native Architecture, it significantly improves power efficiency. Moreover, its support for LPDDR6 memory and UFS 5.0 storage provides a highly optimized solution for next-generation flagship devices.

Summary

MediaTek launched the Dimensity 9600 Pro, a processor built on TSMC's advanced 2nm process featuring over 33 billion transistors. The chip utilizes an AI Native Architecture to drastically improve power efficiency compared to previous models. Key highlights include its support for LPDDR6 memory and UFS 5.0 storage, positioning it as a top-tier solution for future flagship smartphones.
