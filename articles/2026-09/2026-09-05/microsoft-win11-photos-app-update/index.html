Microsoft, Win11 새 Photos 앱 전면 배포: 도구 모음 간소화, Ask Copilot 버튼 제거

2026-09-05

업데이트 개요

IT之家 9월 4일 보도에 따르면, IT 매체 Windows Latest는 오늘(9월 4일) Microsoft Photos 사진 뷰어 버전 2026.11080.24002.0이 모든 Windows 11 사용자에게 전면 배포되었다고 발표했습니다.

Microsoft는 2026년 7월부터 Windows Insider 프로그램 멤버들을 대상으로 테스트를 시작했으며, 주로 인터페이스 간소화, 응답 속도 향상, Ask Copilot 버튼 제거 등에 중점을 두었습니다. 현재는 모든 Windows 11 사용자에게 전면 배포되었습니다.

사용자 경험

이번 업데이트는 이미지 탐색과 관련 없는 인터페이스 요소를 줄여 사용자가 이미지와 자주 사용하는 작업을 우선적으로 볼 수 있도록 했습니다. Ask Copilot 버튼은 제거되었지만, AI 기반 배경 제거와 같은 선택적 기능은 유지됩니다.

도구 모음 조정

업데이트 전에는 사진 앱의 주 도구 모음에 최대 10개의 옵션이 표시되었지만, 새 버전에서는 Designer, OneDrive, Clipchamp 등의 옵션이 주 도구 모음에서 제거되어 새로운 "Open with"(연결 프로그램) 메뉴 또는 다른 위치로 통합되었습니다.

주 도구 모음에는 이제 편집, 회전, 삭제, 인쇄, 공유, "점 세 개" 메뉴 및 "연결 프로그램" 등 7가지 작업만 남았습니다. 슬라이드쇼 버튼은 앱 하단으로 이동했습니다. OneDrive 진입점은 왼쪽 사이드바 또는 설정 페이지로 변경되었으며, 사용자는 여전히 사이드바에서 클라우드 이미지를 액세스할 수 있습니다.

성능

Microsoft는 새 Microsoft Photos가 멀티 프로세스 아키텍처를 도입하여 사진 로딩 속도를 거의 2배 향상시켰다고 밝혔습니다.

해당 매체의 테스트 결과, 앱 시작 속도가 빨라지고 확대/축소 작업이 더 부드러워졌으며, 저사양 장치에서의 끊김 현상이 줄어들고 대용량 사진이 거의 즉시 열리는 것으로 나타났습니다.

오른쪽 클릭 메뉴

Microsoft는 오른쪽 클릭 메뉴도 간소화하여 일부 유사한 옵션을 중첩 메뉴로 통합하고, 시스템 수준의 오른쪽 클릭 메뉴와 유사한 명령 모음을 추가했습니다. IT之家는 관련 이미지를 아래에 첨부합니다.

이전 오른쪽 클릭 메뉴에 있던 "Visual search with Bing", "Edit with Designer", "Create a video with Microsoft Clipchamp" 등의 항목은 더 이상 직접 표시되지 않습니다.

지원 형식

새 사진 앱은 HEIC 이미지에 대한 지원을 강화하여 사용자가 다른 이미지 형식으로 변환할 필요 없이 HEIC 파일을 직접 편집할 수 있습니다.

총평

Microsoft Photos의 이번 업데이트는 인터페이스를 간소화하고 사용자 경험을 개선하는 데 중점을 두었습니다. 멀티 프로세스 아키텍처 도입으로 성능이 크게 향상되었으며, HEIC 파일 직접 편집 기능 추가로 편의성도 높아졌습니다. 전반적으로 더 빠르고 효율적인 사진 뷰어 환경을 제공합니다.

微软照片查看器全量更新：Windows 11新特性发布

科技媒体 Windows Latest报道，微软已面向所有Windows 11用户全量推送了Photos应用（版本号为2026.11080.24002.0）。本次更新旨在精简界面、提升性能和优化用户体验。

核心功能与用户体验改进

  • 界面简化： 整体减少了与图片浏览无关的界面元素，使常用操作和图片内容成为焦点。
  • 移除冗余按钮： 移除了“Ask Copilot”按钮等干扰性元素。
  • AI功能保留： 保留了如AI驱动的背景移除等可选高级功能供用户使用。

性能架构与加载速度提升

  • 多进程支持： 新版Photos应用引入了多进程架构（multi-process architecture）。
  • 加速效果显著： 微软官方表示，该架构使照片加载速度接近提升2倍，并改善了低配置设备上的卡顿问题。
  • 流畅度优化： 用户反馈指出，应用启动更快，缩放操作更平滑，大尺寸照片几乎可以立即打开。

工具栏与右键菜单的结构调整

  • 主工具栏精简： 主工具栏的操作选项从最多10个减少至7项核心操作（包括编辑、旋转、删除、打印、分享、“三点”菜单和“打开方式”）。
  • 功能模块重组： Designer、OneDrive 和 Clipchamp 等应用入口被移出主工具栏，统一转入新的“Open with”（打开方式）菜单或设置页面。
  • 侧边栏与底部调整： OneDrive的入口改至左侧边栏或设置页；幻灯片按钮则被移动到应用的底部区域。
  • 右键菜单优化： 微软精简了系统级右键菜单，将部分相近选项整合到嵌套菜单中，并移除了如“Visual search with Bing”等直接显示的过时命令。

格式支持与兼容性增强

  • HEIC原生支持： 新版照片应用加强了对HEIC图片的支持，用户现在无需预先转换格式，即可直接编辑这类文件。

总结

本次Photos应用的更新是一次全面的重构升级，核心目标是提升性能和简化操作流程。通过引入多进程架构实现加载速度的大幅提升，同时优化了界面布局、工具栏结构以及右键菜单，使Windows 11用户能获得更流畅、更专注的图片浏览体验。此外，新增的HEIC原生支持也增强了应用的兼容性。

アップデート概要

IT之家（IT Home）が9月4日に報じたところによると、ITメディアWindows Latestは、Microsoft Photosのビューアバージョン2026.11080.24002.0が本日（9月4日）、すべてのWindows 11ユーザー向けに全面展開されたと発表しました。

Microsoftは、2026年7月よりWindows Insiderプログラムのメンバーを対象にテストを開始し、主にインターフェースの簡素化、応答速度の向上、そして「Ask Copilot」ボタンの削除などに焦点を当ててきました。今回、すべてのWindows 11ユーザーへ正式に展開されました。

ユーザーエクスペリエンス（UX）の改善

今回のアップデートでは、画像閲覧と直接関係のないインターフェース要素が削減され、ユーザーが画像そのものや頻繁に使用する作業に集中できるようになりました。「Ask Copilot」ボタンは削除されましたが、AIによる背景除去などの選択的な機能は維持されています。

ツールバーの調整

アップデート前は、写真アプリのメインツールバーに最大10個のオプションが表示されていましたが、新バージョンではDesigner、OneDrive、Clipchampといったオプションがメインツールバーから削除され、新しい「開く」メニュー（Open with）や他の場所に統合されました。

メインツールバーには、以下の7つの主要な操作のみが残されています。

  • 編集
  • 回転
  • 削除
  • 印刷
  • 共有
  • 「…」（その他のオプション）メニュー
  • 「開く」メニュー（Open with）

また、スライドショーボタンはアプリの下部に移動しました。OneDriveへのアクセスポイントも左側のサイドバーまたは設定ページに変更されましたが、ユーザーは引き続きサイドバーからクラウド上の画像にアクセスできます。

パフォーマンスの向上

Microsoftによると、新しいMicrosoft Photosはマルチプロセスアーキテクチャを導入したことにより、写真の読み込み速度がほぼ2倍に向上しました。

当該メディアによるテストの結果からは、以下の点が確認されています。

  • アプリの起動速度が高速化された
  • 拡大・縮小操作がよりスムーズになった
  • 低スペックなデバイスでのカクつき（途切れ）現象が減少した
  • 大容量の写真がほぼ即座に開くようになった

右クリックメニューの簡素化

Microsoftは、コンテキストメニュー（右クリックメニュー）も簡素化しました。類似するオプションはネストされたメニューに統合され、システムレベルの右クリックメニューと同様のコマンドバーが追加されています。IT之家はこの関連画像を添付しています。

以前の右クリックメニューにあった「Visual search with Bing」「Edit with Designer」「Create a video with Microsoft Clipchamp」などの項目は、もはや直接表示されることはありません。

サポート形式

新しい写真アプリはHEIC画像への対応を強化しました。これにより、ユーザーは他の画像形式に変換する必要がなくなり、HEICファイルを直接編集できるようになりました。

まとめ

今回のMicrosoft Photosのアップデートは、インターフェースの簡素化とユーザー体験（UX）の改善に重点が置かれています。マルチプロセスアーキテクチャの導入によりパフォーマンスが大幅に向上し、さらにHEICファイルの直接編集機能追加によって利便性も高まっています。全体として、より高速で効率的な写真ビューア環境を提供することが期待されます。

Update Overview

According to a report by IT之家 on September 4th, the IT media outlet Windows Latest announced that version 2026.11080.24002.0 of the Microsoft Photos photo viewer has been fully rolled out to all Windows 11 users today (September 4th).

Microsoft began testing this update with members of the Windows Insider program starting in July 2026, focusing primarily on interface simplification, improved responsiveness, and the removal of the "Ask Copilot" button. It is now fully deployed to all Windows 11 users.

User Experience Changes

This update streamlines the interface by removing elements unrelated to image viewing and navigation, allowing users to focus on images and frequently used tasks. While the Ask Copilot button has been removed, optional features such as AI-based background removal have been retained.

Toolbar Adjustments

Previously, the main toolbar of the Photos app could display up to 10 options, but the new version removes options like Designer, OneDrive, and Clipchamp from the primary toolbar. These functions have been integrated into a new "Open with" menu or moved to different locations.

The main toolbar is now limited to seven core actions: Edit, Rotate, Delete, Print, Share, the "three dots" menu, and "Open with." The slideshow button has been moved to the bottom of the app. The OneDrive entry point has been changed to the left sidebar or settings page, though users can still access cloud images via the sidebar.

Performance Improvements

Microsoft stated that the new Microsoft Photos incorporates a multi-process architecture, nearly doubling the photo loading speed. Testing conducted by the media outlet showed faster app startup times and smoother zoom/pan operations. Furthermore, stuttering on low-spec devices has decreased, and large photos open almost instantly.

Right-Click Context Menu

Microsoft also simplified the right-click context menu by consolidating similar options into nested menus and adding a command bar similar to system-level right-click menus. IT之家 included related images below.

Items previously found in the right-click menu, such as "Visual search with Bing," "Edit with Designer," and "Create a video with Microsoft Clipchamp," are no longer displayed directly.

Supported Formats

The new Photos app has enhanced support for HEIC images, allowing users to edit HEIC files directly without needing to convert them to other formats.

Summary

This update focuses on simplifying the interface and improving the overall user experience of Microsoft Photos. Key improvements include a significant boost in performance due to the adoption of a multi-process architecture, and enhanced convenience through direct support for editing HEIC files. Overall, the app provides a faster and more efficient photo viewing environment.
