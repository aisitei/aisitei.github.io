카메라

Canon EOS R8 Mark II는 EOS R6 Mark II와 동일한 약 2,420만 유효 화소 풀프레임 CMOS 이미지 센서를 탑재하고 DIGIC X 이미지 프로세서와 결합되었습니다. 이번 업그레이드를 통해 바디 5축 시프트식 손떨림 보정 기능이 추가되었으며, IS 손떨림 보정 기능을 갖춘 RF 렌즈와 함께 사용할 경우 바디와 렌즈의 협력 손떨림 보정이 가능하여 중앙 보정 성능은 최대 7.5스톱에 달합니다.

동영상 촬영 시 EOS R8 Mark II는 협력 손떨림 보정 및 디지털 동영상 손떨림 보정 연동을 기반으로 이미지 안정화 "강화+" 모드가 추가되어 다중 손떨림 보정의 협력 작용으로 핸드헬드 촬영 시 흔들림으로 인한 화면 흐림을 크게 줄여줍니다.

연사 성능 면에서 EOS R8 Mark II는 전자 셔터 모드에서 최대 약 40매/초의 고속 연사를 지원하며, 전자 선막 셔터는 최대 약 6매/초를 지원합니다. EOS R8 Mark II는 또한 프리 연사 기능을 추가하여 셔터 버튼을 누르기 전 0.5초 동안의 화면을 기록할 수 있습니다.

2세대 듀얼 픽셀 AF를 기반으로 EOS R8 Mark II는 딥러닝 기술을 통해 AF 알고리즘을 개선하여 인식 정확도, 속도 및 복잡한 환경에서의 간섭 방지 능력을 강화했습니다. 최저 AF 밝기는 EV-7.5에 달하여 어두운 환경에서도 AF가 더욱 신뢰할 수 있습니다.

EOS R8 Mark II에는 16가지 색상 필터가 내장되어 있습니다. EOS R6 Mark III와 동일한 14가지 색상 필터 외에 네거티브 필름 톤 색상 필터와 포지티브 필름 톤 색상 필터의 2가지 필름 톤 필터가 추가되었습니다. 색상 필터 강도는 0%에서 100% 사이에서 11단계로 조절할 수 있습니다. JPG 형식 사진 촬영 또는 동영상 녹화 시 색상 필터를 직접 사용하여 후반 작업 없이 스타일리시한 이미지를 바로 출력할 수 있습니다.

기존 모델의 단일 핸드헬드 야경 모드와 비교하여 EOS R8 Mark II의 핸드헬드 야경 모드에는 파란색, 블랙 오렌지, 분홍색, 녹색의 4가지 색상 스타일 옵션이 추가되어 SF 야경, 네온 야경 등 다양한 테마를 표현하는 데 사용할 수 있습니다.

크리에이티브 자동 기능(크리에이티브 어시스트, 크리에이티브 브라케팅 및 고급 A+)도 EOS R8 Mark II에 이식되어 EOS 풀프레임 모델 중 최초로 크리에이티브 자동 기능을 탑재한 모델이 되었습니다. 이 기능은 파라미터 조절에 익숙하지 않은 초보 사진작가에게 완전 자동화된 조절 기능을 제공하며, 높은 명암비, 역광 인물, 하이라이트 과다 노출 등 촬영하기 어려운 조명 환경에 대해 자동으로 적합한 파라미터를 조절하여 촬영합니다.

동영상 촬영 시 EOS R8 Mark II는 크롭 없는 6K 오버샘플링 4K 60P 및 Full HD 180P 동영상 녹화를 지원하며, 슬로우 모션 및 퀵 모션 동영상 모드를 제공하고 고프레임률 동영상 촬영 시 사운드를 동시에 기록할 수 있습니다.

EOS R8 Mark II는 CINEMA EOS 시리즈와 공유하는 색상 프리셋인 사용자 정의 이미지(CP)를 탑재했습니다. 사용자는 Canon Log 3, BT.709 또는 PQ, HLG를 선택하여 CINEMA EOS와 호환되는 영상 제작을 실현할 수 있습니다. 또한 EOS R8 Mark II는 외부 Look File 파일 로드를 지원하여 고급 동영상 제작자의 색상 편집 요구를 충족합니다. 이 외에도 EOS R8 Mark II는 시네마 뷰 기능을 갖추고 있어 2.35:1 화면비의 시네마 프레임을 지원하여 동영상 촬영 시 영화 같은 와이드 프레임 구도를 직접 출력할 수 있습니다.

또한 EOS R8 Mark II는 풀프레임 및 APS-C 규격 VR 렌즈를 사용할 수 있으며, 새로 추가된 VR 클리어 모드는 VR 안경 시청에 최적화된 파라미터를 자동으로 적용할 수 있습니다.

총평

Canon EOS R8 Mark II는 EOS R6 Mark II와 동일한 2,420만 화소 풀프레임 센서와 DIGIC X 프로세서를 탑재하고, 바디 5축 손떨림 보정 기능을 추가하여 최대 7.5스톱의 보정 성능을 제공합니다. 동영상 촬영 시 6K 오버샘플링 4K 60P를 지원하며, 다양한 색상 필터와 크리에이티브 자동 기능을 통해 초보자부터 전문가까지 폭넓은 사용자에게 유연한 촬영 경험을 제공합니다. 특히, 핸드헬드 야경 모드와 시네마 뷰 기능은 창의적인 영상 제작에 새로운 가능성을 제시합니다.

图像传感器与核心性能

  • 成像系统： 采用与 EOS R6 Mark II 相同的约 2420 万有效像素全画幅 CMOS 图像传感器，搭配 DIGIC X 影像处理器。
  • 连拍速度： 电子快门模式最高支持约 40 张/秒高速连拍；电子前帘快门最高约 6 张/秒。

先进防抖与对焦系统

  • 机身防抖升级： 加入了机身五轴位移式手抖补偿机构，配合具备 IS 防抖功能的 RF 镜头，实现机身与镜头协同防抖，中心补偿性能最高可达 7.5 级。
  • 视频稳定增强： 短片拍摄新增影像稳定器“增强 +”模式，通过多重防抖协同作用，大幅降低手持拍摄的画面模糊度。
  • 对焦系统提升： 在第二代全像素双核对焦基础上，基于深度学习技术优化了对焦算法，识别精度和抗干扰能力加强；最低对焦亮度达到 EV-7.5，暗光场景对焦更可靠。

创意拍摄与色彩功能

  • 色彩滤镜： 内置 16 种色彩滤镜（包括新增的负片色调和正片色调两款胶片色调），强度可在 0%-100% 之间进行 11 级调整，可直接用于 JPG 照片或短片输出。

  • 创意自动功能： 首次搭载“创意辅助”、“创意包围”和“高级 A+”等创意自动功能，为摄影入门用户提供全自动化的拍摄参数调整支持。

专业视频创作与兼容性

  • 短片规格： 支持无裁切 6K 超采样 4K 60P 和全高清 180P 短片录制；具备慢动作和快动作模式，并支持高帧率拍摄时同步记录声音。
  • 专业色彩预设： 配备与 CINEMA EOS 系列共用的自定义图像（CP），用户可选择 Canon Log 3、BT.709 或 PQ、HLG 等多种色彩空间。
  • 电影级输出： 支持加载外部 Look File 文件，满足进阶短片创作者需求；具备电影视图功能，支持 2.35:1 宽高比电影画幅构图。
  • 镜头兼容性： 可使用全画幅及 APS-C 规格 VR 镜头，新增的 VR 清晰模式可自动适配 VR 眼镜观看所需的优化参数。

总结

Canon EOS R8 Mark II 作为一款升级的全画幅相机，在保持了高像素和专业色彩系统的基础上，重点强化了防抖、对焦和创意功能。其最大的亮点包括新增的五轴协同防抖机构（中心补偿最高 7.5 级）、增强的暗光 AF 能力以及首次集成的全套“创意自动”系统，使其在兼顾专业性和易用性的方面达到了新的高度。

デザイン

Canon EOS R8 Mark IIは、滑り止め加工を施したボディ外装を採用し、片手での撮影時の安定性を高めました。本体の総重量は約546gです。新しい多機能コントロールボタンと撮影インジケーターが追加され、多機能ホットシューインターフェースを通じて、様々な機能をサポートするマイクやフラッシュなどを直接接続できます。

カメラ性能

Canon EOS R8 Mark IIは、EOS R6 Mark IIと同じ約2,420万画素のフルサイズCMOSイメージセンサーを搭載し、DIGIC X画像プロセッサーと組み合わされています。今回のアップグレードにより、ボディ5軸シフト式手ブレ補正機能が追加されました。IS手ブレ補正機能を備えたRFレンズと組み合わせることで、ボディとレンズによる協調的な手ブレ補正が可能となり、中央部での補正性能は最大7.5段に達します。

動画撮影においては、「強化+」モードという画像安定化機能が追加されました。これは、協調的な手ブレ補正とデジタル動画手ブレ補正の連動に基づいたものであり、複数の手ブレ補正機構が連携することで、手持ち撮影時の揺れによる画面のブレを大幅に低減します。

連続撮影性能では、以下のスペックを実現しています。

  • 電子シャッターモード：最大約40コマ/秒の高速連写に対応
  • 電子カーテンシャッター：最大約6コマ/秒をサポート

また、EOS R8 Mark IIには「プレ連写」機能が追加され、シャッターボタンを押す前の0.5秒間の映像も記録することが可能です。

2世代のデュアルピクセルAFを基盤とし、EOS R8 Mark IIはディープラーニング技術によってAFアルゴリズムを改善しました。これにより、認識精度、速度、および複雑な環境下での干渉防止能力が強化されています。最低AF輝度はEV-7.5に達し、暗い環境下でもより信頼性の高いオートフォーカスを実現します。

EOS R8 Mark IIには16種類のカラーフィルターが内蔵されています。EOS R6 Mark IIIと同じ14色のカラーフィルターに加え、ネガフィルムトーンとポジフィルムトーンの2種類のフィルムトーンフィルターが追加されました。カラーフィルターの強度は0%から100%の間で11段階に調整可能です。JPG形式での写真撮影や動画録画時にカラーフィルターを直接使用することで、後処理なしでスタイリッシュな画像を即座に出力できます。

従来のモデルの単体手持ちナイトモードと比較して、EOS R8 Mark IIの手持ちナイトモードには、青色、ブラックオレンジ、ピンク、緑色の4種類のカラースタイルオプションが追加されました。これにより、SF的な夜景やネオンの夜景など、多様なテーマを表現することが可能です。

クリエイティブアシスト（Creative Assist）、クリエイティブブラケティング（Creative Bracketing）、およびアドバンストA+といった機能もEOS R8 Mark IIに搭載され、EOSフルサイズモデルとして初めてこれらの「クリエイティブ自動機能」を備えたモデルとなりました。この機能は、パラメーター調整に慣れていない初心者写真家に対し、完全自動化された調整機能を提供します。高い明暗差、逆光の人物撮影、ハイライトの過剰露出など、撮影が難しい照明環境において最適なパラメーターを自動で調整してくれます。

動画撮影時、EOS R8 Mark IIは以下の高解像度録画に対応しています。

  • クロップなし 6Kオーバーサンプリング 4K 60P
  • Full HD 180P

さらに、スローモーションおよびクイックモーション動画モードを提供し、高フレームレートでの動画撮影時に同時に音声を記録することも可能です。

EOS R8 Mark IIは、CINEMA EOSシリーズと共有するカラープリセット「カスタムイメージ（CP）」を搭載しています。ユーザーはCanon Log 3、BT.709、またはPQ/HLGを選択することで、CINEMA EOSと互換性のある映像制作が実現できます。また、外部Look Fileファイルのロードもサポートしており、高度な動画制作者のカラー編集要求に応えます。加えて、EOS R8 Mark IIにはシネマビュー機能が搭載されており、2.35:1のアスペクト比を持つシネマフレームをサポートし、動画撮影時に映画のようなワイドフレーム構図を直接出力できます。

さらに、フルサイズおよびAPS-C規格のVRレンズを使用でき、新しく追加された「VRクリアモード」は、VRメガネでの視聴に最適化されたパラメーターを自動で適用します。

まとめ

Canon EOS R8 Mark IIは、EOS R6 Mark IIと同等の2,420万画素フルサイズセンサーとDIGIC Xプロセッサーに加え、ボディ5軸手ブレ補正機能を追加し、最大7.5段の強力な補正性能を誇ります。動画撮影では6Kオーバーサンプリング 4K 60Pに対応し、16種類のカラーフィルターやクリエイティブ自動機能により、初心者からプロまで幅広いユーザーに柔軟な撮影体験を提供します。特に、手持ちナイトモードとシネマビュー機能は、創造的な映像制作の可能性を広げる画期的な機能です。

Design

The Canon EOS R8 Mark II features a non-slip coated body exterior to enhance stability when shooting with one hand. The total weight of the body is approximately 546g. It has been equipped with new multi-function control buttons and a shooting indicator light. Furthermore, it supports various external accessories like microphones and flashes via a versatile hot shoe interface.

Camera Specifications and Features

The Canon EOS R8 Mark II is powered by the same approximately 24.2MP full-frame CMOS image sensor found in the EOS R6 Mark II, paired with the DIGIC X image processor. This upgrade includes a built-in 5-axis in-body image stabilization (IBIS) system. When used with RF lenses that also feature IS stabilization, the combination allows for collaborative stabilization, achieving a maximum central stabilization performance of up to 7.5 stops.

For video recording, the EOS R8 Mark II introduces an enhanced Image Stabilization "Enhanced+" mode. This mode utilizes combined stabilization and digital video stabilization linkage, significantly reducing image blur caused by hand-held shake through collaborative action among multiple stabilization systems.

In terms of continuous shooting performance, the EOS R8 Mark II supports a high burst rate of approximately 40 frames per second (fps) in electronic shutter mode, and up to approximately 6 fps with the electronic curtain shutter. The camera also adds a pre-capture burst function, allowing users to record footage for 0.5 seconds before pressing the shutter button.

Based on the 2nd generation Dual Pixel AF system, the EOS R8 Mark II has improved its AF algorithm using deep learning technology. This enhances recognition accuracy, speed, and interference prevention in complex environments. The minimum AF brightness reaches EV-7.5, ensuring reliable autofocus even in low-light conditions.

The EOS R8 Mark II features 16 built-in color filters. In addition to the 14 color filters found on the EOS R6 Mark III, two film tone filters—a negative film tone filter and a positive film tone filter—have been added. The intensity of the color filter can be adjusted in 11 steps, ranging from 0% to 100%. Users can apply these color filters directly when shooting JPG format photos or recording videos, allowing them to produce stylish images immediately without post-processing.

Compared to the previous model's single hand-held night mode, the EOS R8 Mark II's hand-held night mode now includes four color style options: blue, black orange, pink, and green. These can be used to capture various themes, such as sci-fi nightscapes or neon city views.

Creative Auto functions (Creative Assist, Creative Bracketing, and Advanced A+) have been ported to the EOS R8 Mark II, making it the first full-frame model in the EOS lineup to feature this capability. This function provides fully automated adjustment for novice photographers unfamiliar with parameter adjustments. It automatically adjusts suitable parameters for challenging lighting conditions, such as high contrast, backlit portraits, or overexposed highlights.

For video recording, the EOS R8 Mark II supports 6K oversampled 4K 60P and Full HD 180P video recording without cropping. It also provides slow-motion and quick-motion video modes, allowing sound to be recorded simultaneously during high frame rate video capture.

The EOS R8 Mark II is equipped with Custom Image (CP) color profiles shared with the CINEMA EOS series. Users can select from Canon Log 3, BT.709, or PQ/HLG to achieve video production compatible with CINEMA EOS. Furthermore, the camera supports loading external Look File files, meeting the advanced color grading demands of professional videographers. Additionally, the EOS R8 Mark II features Cinema View, supporting a cinematic 2.35:1 aspect ratio frame that allows users to directly output a movie-like widescreen composition during video recording.

The camera can use both full-frame and APS-C format VR lenses. The newly added VR Clear mode automatically applies parameters optimized for viewing through Virtual Reality (VR) glasses.

Summary

The Canon EOS R8 Mark II maintains the 24.2MP full-frame sensor and DIGIC X processor of the EOS R6 Mark II while adding a 5-axis IBIS system, providing up to 7.5 stops of stabilization. It supports advanced video features including 6K oversampled 4K 60P, alongside diverse color filters and Creative Auto functions that cater to both beginners and professionals. Notably, the inclusion of enhanced hand-held night modes and Cinema View offers new creative possibilities for videography.
