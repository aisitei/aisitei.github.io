Canon Announces Dual Pixel 3D Converter

Canon has announced that it plans to release the Dual Pixel 3D Converter, an application for Windows systems, starting October 8, 2026. This software will allow users to generate high-definition 3D models from photographs.

The Dual Pixel 3D Converter application can convert:

  • Dual Pixel RAW (DPRAW) images taken with compatible EOS R system cameras and lenses.
  • JPEG image data containing depth information, captured with Canon EOS R8 Mark II (scheduled for release in October 2026) and compatible lenses.

Based on Dual Pixel CMOS AF Technology

Canon's proprietary Dual Pixel CMOS Phase Detection Autofocus technology enables the effective pixels to simultaneously perform image formation and phase detection functions. Each pixel is composed of two independent photodiode arrays, allowing it to acquire phase difference information.

Building upon this foundation, the Dual Pixel 3D Converter application estimates the three-dimensional shape of a subject using algorithms. It then uses high-definition images captured with Canon EOS cameras as surface textures to generate highly realistic 3D models. This entire process allows users to obtain a 3D model with high resolution texture and excellent color reproduction from a single image, without requiring special shooting equipment or additional captures.

Versatile 3D Modeling Capabilities

In practical use, users can import captured photos into the Dual Pixel 3D Converter application on their computer. They have the option to generate either a complete 3D model including the background or to extract and create a 3D model of only the main subject.

The application also supports adjusting the depth effect of the 3D model, allowing users to choose between enhancing the relief on screen for a more dramatic visual impact based on their needs and personal preference, or selecting a more natural depth representation. Beyond basic 3D model generation, users can add simple dynamic effects and custom backgrounds to the models and output preview videos to quickly check the finished effect. Furthermore, users can adjust the color and brightness of the 3D model by replacing its surface texture with an image edited using standard image processing software. The resulting 3D model can also be imported into general-purpose 3D editing software.

Expansion of Dual Pixel 3D Technology

Canon plans to further expand the application scope of Dual Pixel 3D technology by providing related solutions for enterprise clients within 2026. By integrating this technology into existing workflows or systems, it can be applied across various business scenarios, including photo authentication, e-commerce, and advertising.

Summary

Canon plans to introduce the Dual Pixel 3D Converter software in October 2026, enabling users to create high-quality 3D models from standard photographs. This technology leverages Canon's advanced Dual Pixel CMOS AF system, allowing for realistic 3D model generation from just a single image. The system offers versatile capabilities—from generating full scene models to customizing effects and textures—and is slated for expansion into enterprise solutions for various business applications.
