더우바오 대규모 모델 2.1 Pro 0915 버전 업데이트: 에이전트 제공 안정성 향상, 멀티모달 코딩 진화

2026-09-17

업데이트 개요

Volcano Engine는 오늘 Doubao 대형 모델 2.1 Pro를 0915 버전으로 업데이트했으며, API가 Volcano Ark에 전면 출시되었다고 발표했습니다.

IT之家는 공식 발표를 통해 Doubao 작업이 업그레이드되었으며, 사용자는 최신 버전을 다운로드하거나 업그레이드하여 "Doubao 2.1 Pro (0915 신버전)" 모델을 선택하면 경험할 수 있다고 밝혔습니다.

이번 업그레이드는 기업의 생산 수준 요구 사항에 맞춰 Agent 작업 전달, 멀티모달 코딩, 멀티모달 이해 및 Token 효율 최적화를 포함합니다.

Doubao 외에도 TRAE는 0915 버전에 동기화되어 연결되었습니다. 올해 6월 출시된 Doubao-Seed-Evolving도 동일한 버전으로 업데이트되어 기업은 API 연결 노드를 변경할 필요가 없습니다.

Agent 작업 전달

Agent 작업 전달 측면에서, 모델은 증거 추적, 권위 있는 정보원 검색, 시의성 판단 및 데이터 검증 능력을 강화하여 환각 현상이 현저히 줄어들고 도구 호출 사실에 더욱 충실해졌다고 공식적으로 밝혔습니다. 금융 투자 연구, 사무 자동화 등 장기 보고서 작업에서 결론은 근거를 확인할 수 있어 진행이 더욱 안정적입니다.

금융 투자 연구를 예로 들면, 모델은 분석가 수준의 분석 프레임워크를 갖추고 있어 연구 요구 사항을 자율적으로 분해하고, 고품질 데이터 소스를 조회하며, 모델링 분석을 통해 전문가 수준의 모델링 초안을 생성할 수 있다고 공식적으로 밝혔습니다.

멀티모달 코딩 능력

멀티모달 코딩 능력이 강화되어 모델이 복잡한 코드 저장소를 더 잘 이해하고, 파일 간, 장거리 문제에 직면했을 때 프로젝트 구조와 모듈 관계를 파악하고, 근본 원인을 찾아 수정하며, 요구 사항 이해부터 실행 검증까지의 엔드투엔드 프로세스를 커버합니다.

VLM 능력을 활용하여 모델은 디자인 초안, 도면 및 작업 녹화 화면을 직접 읽고 이해하여 시각 정보를 프런트엔드 코드 및 게임 로직으로 전환할 수 있으며, Web 3D 개발 및 게임 장면 구현 효과가 향상됩니다.

멀티모달 이해

멀티모달 이해 측면에서 비디오 추론 능력이 강화되어 비디오에서 증거를 찾아내고, 프레임 간 통합 후 답변하며, SOP를 참조하여 작업을 식별하고 원리를 설명할 수 있습니다. 물리 교육, 공학, 실험 작업, 의료 등 전문 콘텐츠 이해도가 향상되어 비디오 주석, 콘텐츠 품질 검사, 장편 비디오 편집 및 위치 요약 등의 시나리오에서 이점을 얻습니다.

이미지 이해는 3D 객체 및 밀집된 이미지-텍스트 방향으로 강화되었습니다. CAD 공작물, 게임 엔진 3D 요소 및 AR 공간을 식별할 수 있습니다. 공학 도면 치수 표기 및 공차 기호, PDF 도면 주석 및 각주와 표 헤더 계층, 재무 보고서 및 연구 보고서 표 추출 및 페이지 간 각주 참조 등의 처리 정확도가 향상되었습니다.

Token 효율 최적화

Token 효율도 동시에 최적화되어 추론 라운드 및 도구 호출 횟수가 감소했습니다. 이미지 추론 및 비디오 추론의 Token 소모는 이전 세대보다 30% 이상 감소하여 그림 보고 문제 풀이, 이미지 품질 검사, 비디오 검토 등 고빈도 시나리오의 비용이 더욱 저렴해졌습니다.

총평

Volcano Engine의 Doubao 대형 모델 2.1 Pro 0915 버전은 기업 생산 요구 사항에 맞춰 Agent 작업 전달, 멀티모달 코딩, 멀티모달 이해 및 Token 효율을 크게 개선했습니다. 특히 금융 투자 연구 및 복잡한 코드 분석에서 모델의 정확성과 효율성이 향상되었으며, 비디오 및 이미지 이해 능력 강화로 다양한 전문 분야에서의 활용도가 높아졌습니다. Token 소모 최적화로 고빈도 시나리오의 비용 효율성도 개선되었습니다.

模型核心升级与版本信息

  • 火山引擎宣布将“豆包大模型 2.1 Pro”更新至 0915 版本，并通过火山方舟全量上线 API。
  • 本次升级围绕企业生产级需求展开，覆盖 Agent 任务交付、多模态 Coding、多模态理解和 Token 效率优化等多个方面。
  • 除了豆包模型外，TRAE 和 Doubao-Seed-Evolving 也同步更新至同一 0915 版本，用户无需更换 API 接入节点。

企业级 Agent 任务交付与推理能力

  • **增强的可靠性：** 模型强化了证据溯源、权威信源检索、时效判断和数据核验能力，显著减少“幻觉”，结论更具可查证性。
  • **专业应用场景：** 在金融投研等长报告任务中，模型具备分析师级别框架，能自主拆解研究需求、查询高质量数据并产出专家级建模底稿。

多模态开发与代码生成能力

  • **复杂代码理解：** 模型提升了对复杂代码仓库的理解能力，能够处理跨文件、长程问题，定位根因并修复，覆盖从需求理解到运行验证的端到端流程。
  • **视觉信息转码：** 借助 VLM（视觉语言模型）能力，模型可直接读懂设计稿、图纸和操作录屏等视觉信息，将其转化为前端代码和游戏逻辑，提升 Web 3D 开发及游戏场景呈现效果。

多模态理解与专业应用增强

  • **视频推理：** 增强了跨帧整合能力，可在视频中定位证据并作答；适用于物理教学、工程、医疗等领域，可对照 SOP 辨认操作并解释原理，受益于内容质检和长视频摘要等场景。
  • **图像理解（3D与图文）：** 提升了对 3D 物体和密集图文的识别精度，能够识别 CAD 工件、游戏引擎 3D 元素及 AR 空间；处理能力增强包括工程图纸尺寸标注与公差符号、PDF 图注脚注层级提取以及财报研报表格提取。

效率优化与技术兼容性

  • **Token 消耗降低：** 模型同步优化了 Token 效率，图像推理和视频推理的 Token 消耗比上一代减少了 30% 以上，有效降低了高频场景（如看图解题、质检）的运行成本。

总结

火山引擎此次发布豆包大模型 2.1 Pro (0915) 版本，重点聚焦于提升模型的企业级生产力。核心升级体现在增强了 Agent 的可信赖性（证据溯源），并大幅拓展了多模态能力，使其能处理复杂的代码、设计图纸和视频信息。同时，通过优化 Token 效率，降低了高频业务场景的运行成本。

アップデート概要

Volcano Engineは、Doubao大規模モデル 2.1 Proをバージョン0915にアップデートし、そのAPIがVolcano Arkで全面リリースされたと発表しました。

IT之家による公式発表によると、Doubaoの機能がアップグレードされ、ユーザーは最新バージョンをダウンロードまたはアップグレードすることで、「Doubao 2.1 Pro (0915新バージョン)」モデルを選択して利用できるようになりました。

今回のアップグレードでは、企業の生産性要件に対応するため、エージェントタスク委任（Agent task delegation）、マルチモーダルコーディング、マルチモーダル理解、およびToken効率の最適化が含まれています。

Doubaoに加え、TRAEも0915バージョンに同期して接続されました。また、今年6月にリリースされたDoubao-Seed-Evolvingも同じバージョンにアップデートされているため、企業側はAPI接続ノードを変更する必要がありません。

エージェントタスク委任（Agent task delegation）

エージェントタスク委任の面では、モデルの能力が強化され、以下の点が改善されたと公式に発表されています。

  • 証拠追跡能力
  • 権威ある情報源の検索能力
  • 時宜判断能力
  • データ検証能力
これにより「幻覚（ハルシネーション）」現象が大幅に減少し、ツール呼び出しの結果により忠実になりました。金融投資研究や事務自動化など長期レポート作成タスクにおいて、結論に至った根拠を確認できるため、プロセスがより安定しています。

例えば、金融投資研究においては、モデルはアナリストレベルの分析フレームワークを備えていると公式に発表されています。これにより、研究要件を自律的に分解し、高品質なデータソースを参照し、モデリング分析を通じて専門家レベルのモデリング草案を生成することが可能です。

マルチモーダルコーディング能力

マルチモーダルコーディング能力が強化されたことで、モデルは複雑なコードリポジトリをより深く理解できるようになりました。特にファイル間や長距離にわたる問題に直面した場合でも、プロジェクト構造とモジュール間の関係性を把握し、根本原因を特定して修正することができ、要件の理解から実行検証に至るエンドツーエンドのプロセスをカバーします。

VLM（Vision-Language Model）能力を活用することで、モデルはデザイン草案、図面、作業録画画面などを直接読み取り理解し、視覚情報をフロントエンドコードやゲームロジックに変換できます。これにより、Web 3D開発やゲームシーンの実装効果が向上します。

マルチモーダル理解

マルチモーダル理解の面では、ビデオ推論能力が強化されました。具体的には、動画から証拠を抽出したり、フレーム間で情報を統合して回答を生成したり、SOP（標準作業手順書）を参照しながらタスクを特定し原理を説明することが可能になりました。物理教育、工学、実験作業、医療など専門的なコンテンツの理解度が向上し、ビデオのアノテーション、コンテンツ品質チェック、長尺ビデオ編集や位置要約などのシナリオで利点が得られます。

画像理解は、3Dオブジェクトおよび密度の高い画像-テキスト方向で強化されました。CAD製品、ゲームエンジンの3D要素、AR空間などを識別できます。また、工学図面の寸法表記や公差記号、PDF図面のアノテーション、脚注と表ヘッダーの階層構造、財務報告書や研究報告書の表抽出、ページを跨いだ脚注参照など、処理の精度が向上しています。

トークン効率の最適化

トークンの効率も同時に最適化され、推論ラウンド数およびツール呼び出し回数が減少しました。画像推論とビデオ推論におけるToken消費量は、前世代と比較して30%以上削減されたため、「図表レポート問題の解決」「画像品質チェック」「ビデオレビュー」といった高頻度のシナリオにおいてコストがより安価になりました。

まとめ

Volcano EngineのDoubao大規模モデル 2.1 Pro (0915バージョン)は、企業の生産性向上に対応するため、エージェントタスク委任、マルチモーダルコーディング、マルチモーダル理解、およびToken効率の面で大幅な改善を遂げました。特に金融投資研究や複雑なコード分析におけるモデルの正確性と効率性が高まり、ビデオ・画像理解能力の強化により多様な専門分野での活用が期待できます。トークン消費量の最適化も進み、高頻度タスクにおけるコスト効率性も向上しました。

Update Overview

Volcano Engine announced that it has updated its Doubao large model to version 2.1 Pro (0915) and fully launched the API on Volcano Ark.

IT之家 reported through an official announcement that the Doubao service has been upgraded, allowing users to experience the "Doubao 2.1 Pro (0915 New Version)" model by downloading or upgrading to the latest version.

This upgrade incorporates features tailored to enterprise productivity requirements, including Agent task delegation, multimodal coding, multimodal understanding, and Token efficiency optimization.

In addition to Doubao, TRAE has also been synchronized and connected with the 0915 version. The Doubao-Seed-Evolving, which was released in June of this year, has also been updated to the same version, meaning enterprises will not need to change their API connection nodes.

Agent Task Delegation

Regarding Agent task delegation, the model has officially enhanced its capabilities in evidence tracking, retrieving authoritative sources, determining timeliness, and data verification. This significantly reduces hallucination and increases adherence to tool calls. Consequently, long-form report tasks, such as financial investment research or office automation, are more stable because conclusions can be traced back to their supporting evidence.

For example, in financial investment research, the model is stated to possess an analyst-level analysis framework that can autonomously decompose research requirements, query high-quality data sources, and generate expert-level modeling drafts through analytical modeling.

Multimodal Coding Capability

The enhanced multimodal coding capability allows the model to better understand complex code repositories. It can grasp project structure and module relationships when faced with inter-file or long-range problems, identify root causes for correction, and cover the entire end-to-end process from requirement understanding to execution verification.

By utilizing VLM capabilities, the model can directly read and understand design drafts, blueprints, and recorded work screens, converting visual information into front-end code and game logic. This improves effectiveness in Web 3D development and game scene implementation.

Multimodal Understanding

In terms of multimodal understanding, video inference capabilities have been strengthened. The model can extract evidence from videos, answer questions after integrating frames, identify tasks, and explain principles by referencing Standard Operating Procedures (SOPs). This improves comprehension in specialized content such as physical education, engineering, experimental work, and medicine, offering advantages in scenarios like video annotation, content quality inspection, long-form video editing, and location summarization.

Image understanding has been enhanced for 3D objects and dense image-text pairings. It can identify CAD components, game engine 3D elements, and AR spaces. Processing accuracy has improved for:

  • Engineering drawing dimensioning and tolerance symbols
  • PDF drawing annotations and footnotes
  • Table header hierarchy in academic papers
  • Extracting tables from financial or research reports and cross-referencing page-level footnotes

Token Efficiency Optimization

Token efficiency has also been optimized, resulting in a reduction of inference rounds and tool call counts. The token consumption for image and video inference has decreased by over 30% compared to previous generations, making high-frequency scenarios—such as solving diagram problems, image quality inspection, and video review—more cost-effective.

Summary

Volcano Engine's Doubao large model 2.1 Pro (0915) significantly improves enterprise productivity by enhancing Agent task delegation, multimodal coding, multimodal understanding, and Token efficiency. Key improvements include enhanced accuracy and efficiency in financial research and complex code analysis, alongside improved utility across various specialized fields due to better video and image comprehension. Furthermore, token consumption optimization makes high-frequency scenarios more cost-effective.
