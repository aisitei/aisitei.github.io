Xiaomi-TabLDM 발표

Xiaomi는 오늘 범용 테이블 데이터 기반 대규모 모델인 Xiaomi-TabLDM을 공식 발표했습니다.

이 모델은 단일 사전 학습 모델과 통일된 기본 구성을 통해 다양한 테이블 데이터셋에 직접 적용되며, 각 작업에 대해 재학습, 매개변수 조정 또는 후처리 통합 없이 분류 및 회귀 예측을 수행할 수 있습니다.

오랫동안 금융, 의료, 제조, 물류 등 다양한 분야의 핵심 데이터가 테이블 형태로 존재해 왔습니다. 그러나 기존 테이블 머신러닝은 새로운 데이터셋마다 모델을 재학습하고, 매개변수를 조정하며, 심지어 모델을 통합해야 하는 경우가 많아 여러 번의 학습과 버전 관리 등 번거로운 배포 비용이 발생했습니다. Xiaomi-TabLDM은 "한 번의 사전 학습으로 여러 작업에 사용"하는 기반 모델 패러다임을 구조화된 데이터 영역에 도입하는 것을 목표로 합니다.

모델의 특징

이 모델은 세 가지 방향으로 테이블 기반 모델의 역량을 강화합니다. 사전 학습 측면에서 Xiaomi-TabLDM은 구조적 인과 모델(SCM)을 기반으로 생성된 대규모 합성 데이터를 완전히 활용하여 사전 학습을 진행하며, 다양한 데이터 규모, 변수 유형, 의존 관계 및 함수 관계를 포괄하여 사전 학습 작업 분포를 확장합니다. 모델 아키텍처 측면에서는 듀얼 스트림 특징 그룹화(dual-stream feature grouping), 경량 어텐션 잔차(lightweight Attention Residual) 및 희소 혼합 전문가(sparse Mixture-of-Experts)를 도입하여 다양한 세분성으로 특징 관계를 모델링하고, 희소 전문가를 통해 모델 용량을 확장합니다. 추론 측면에서는 Test-Time Scaling을 추가로 탐색하여 사전 학습 모델 매개변수를 변경하지 않고 추론 단계의 계산량을 늘려 예측 성능을 지속적으로 향상시킵니다.

성능

Xiaomi-TabLDM은 4대 공개 벤치마크 평가에서 모두 선두 그룹에 올랐습니다. 특히 회귀 능력에서 뛰어난 성능을 보였습니다.

  • OpenML-CTR23 회귀 순위 1위
  • TALENT, TabArena, BCCO의 회귀 작업에서 모두 2위
  • TALENT 이진 분류 작업에서 1위

성능과 효율성의 균형 측면에서 TabArena 회귀 작업을 예로 들면, Xiaomi-TabLDM은 두 번째로 높은 Elo 점수를 얻었으며, 1위를 차지한 TabFM보다 학습 시간은 82%, 예측 시간은 68% 단축했습니다 (Elo 점수는 원래 체스 등급 시스템으로, 여기서는 벤치마크 테스트에서 모델의 상대적 성능 순위를 측정하는 데 사용됩니다).

산업 현장 검증

실제 산업 현장 검증에서 Xiaomi-TabLDM은 기존 머신러닝보다 더 높은 예측 정확도와 다양한 작업 조건 적응 능력을 보여주었습니다.

  • 재료 성능 예측 시나리오에서 이 모델은 미세 조정 없이 예측 정확도를 130% 향상시키고, 약 90%의 비효율적인 시험 금형 및 장비 테스트를 줄였습니다.
  • 부품 무게 예측 시나리오에서는 XGBoost에 비해 오류 샘플 비율이 약 31% 감소했습니다.
  • 생산 구성 요소 예측 시나리오에서는 평균 오차가 XGBoost에 비해 약 54% 감소했습니다. 생산 작업 조건이 변경될 때, 약 30개의 새로운 작업 조건 샘플을 컨텍스트로 추가하는 것만으로 평균 오차를 약 62% 줄일 수 있었습니다.

현재 Xiaomi-TabLDM 관련 모델 가중치와 코드는 공식적으로 오픈소스화되었습니다. 관련 코드 및 모델 가중치는 다음과 같습니다.

  • 코드: https://github.com/xiaomi-research/xiaomi-tabldm
  • 가중치: https://huggingface.co/occams/Xiaomi-TabLDM
  • 기술 보고서: https://arxiv.org/abs/2609.03880

총평

Xiaomi가 발표한 Xiaomi-TabLDM은 단일 사전 학습 모델로 다양한 테이블 데이터셋에 적용 가능한 범용 대규모 모델입니다. 이 모델은 금융, 의료 등 다양한 산업 분야에서 테이블 데이터 처리의 효율성을 높이고, 기존 머신러닝 방식의 한계를 극복하는 것을 목표로 합니다. 특히 뛰어난 회귀 예측 성능과 실제 산업 현장에서의 높은 정확도 및 적응 능력을 입증했으며, 오픈소스화를 통해 개발자 커뮤니티에 기여할 것으로 기대됩니다.

模型核心概念与应用价值

  • Xiaomi今日发布通用表格数据基础大模型 Xiaomi-TabLDM，旨在解决传统机器学习在处理结构化数据时需要针对每个新数据集进行重新训练、调参和集成模型的繁重部署代价。
  • 该模型提出了“一次预训练、跨任务使用”的基础模型范式，适用于金融、医疗、制造、物流等领域的核心表格数据分析。

技术架构与能力提升

  • 预训练机制： Xiaomi-TabLDM 基于结构因果模型（SCM）生成的大规模合成数据进行预训练，覆盖了不同数据规模、变量类型、依赖关系和函数关系，扩大了预训练任务分布。
  • 模型架构创新： 引入了双流特征分组（dual-stream feature grouping）、轻量级注意力残差（lightweight Attention Residual）以及稀疏混合专家（sparse Mixture-of-Experts），以从不同粒度建模特征关系并扩大模型容量。
  • 推理优化： 模型探索了 Test-Time Scaling，能够在不改变预训练参数的前提下，通过增加推理阶段计算量持续提升预测性能。

公开基准测试表现

  • 在四大公开基准评测中，Xiaomi-TabLDM 均跻身第一梯队。
  • 回归能力： 在 OpenML-CTR23 回归榜排名第一；在 TALENT、TabArena 和 BCCO 的回归任务中均排名第二。
  • 分类能力： 在 TALENT 二分类任务中排名第一。
  • 效率优势（以 TabArena为例）： 取得了第二高 Elo 评分，同时训练时间比排名第一的 TabFM 减少了 82%，预测时间减少了 68%。

工业场景验证与性能提升

  • 在真实工业场景中，Xiaomi-TabLDM 的预测精度和跨工况适应能力优于传统机器学习方法。
  • 材料性能预测： 无需微调即可将预测精度提升 130%，减少了约 90% 的无效试模与装机测试。
  • 零件重量预测： 相比 XGBoost，失误样本比例降低约 31%。
  • 生产组分预测： 平均误差相比 XGBoost 降低约 54%；当工况变化时，仅补充约 30 条新工况样本作为上下文，即可将平均误差降低约 62%。

Xiaomi-TabLDMを発表

Xiaomiは本日、汎用的なテーブルデータに基づく大規模モデル「Xiaomi-TabLDM」を正式に発表しました。

このモデルは、単一の事前学習モデルと統一された基本構造により、様々なテーブルデータセットに直接適用可能です。特定のタスクごとに再学習やパラメータ調整、後処理の統合を行うことなく、分類および回帰予測を実行できます。

これまで、金融、医療、製造、物流など多岐にわたる分野の重要なデータはテーブル形式で存在してきました。しかし、従来のテーブル機械学習では、新しいデータセットごとにモデルを再学習したり、パラメータ調整を行ったり、さらにはモデルを統合する必要があり、何度も学習とバージョン管理が必要な煩雑なデプロイコストが発生していました。Xiaomi-TabLDMは、「一度の事前学習で複数のタスクに利用できる」基盤モデルパラダイムを構造化データ領域にもたらすことを目指しています。

モデルの特徴

本モデルは、以下の3つの側面からテーブルベースモデルの能力を強化しています。まず、事前学習の面では、Xiaomi-TabLDMは構造的因果モデル（SCM）に基づいて生成された大規模な合成データを完全に活用して事前学習を行います。これにより、多様なデータ規模、変数タイプ、依存関係、関数関係を網羅し、事前学習タスク分布を拡張します。

次に、モデルアーキテクチャの面では、「デュアルストリーム特徴グループ化（dual-stream feature grouping）」、「軽量アテンション残差（lightweight Attention Residual）」、および「スパースなMixture-of-Experts (MoE)」を導入し、多様な粒度で特徴間の関係性をモデル化するとともに、スパースエキスパートを通じてモデル容量を拡張します。

そして、推論の面では、「Test-Time Scaling」を追加的に探求することで、事前学習モデルのパラメータを変更することなく、推論段階での計算量を増やし、予測性能を持続的に向上させています。

性能

Xiaomi-TabLDMは、4つの公開ベンチマーク評価においてすべてトップグループにランクインしました。特に回帰能力において優れた性能を示しています。

  • OpenML-CTR23 回帰ランキングで1位
  • TALENT、TabArena、BCCOの回帰タスクすべてで2位
  • TALENT二値分類タスクで1位

性能と効率性のバランスという点では、TabArenaの回帰タスクを例にとると、Xiaomi-TabLDMは2番目に高いEloスコアを獲得しました。これは、1位のTabFMと比較して、学習時間を82%、予測時間を68%短縮したものです（Eloスコアは元のチェスのレーティングシステムであり、ここではベンチマークテストにおけるモデルの相対的な性能順位を測定するために使用されています）。

産業現場での検証

実際の産業現場での検証において、Xiaomi-TabLDMは従来の機械学習手法よりも高い予測精度と多様なタスク条件への適応能力を示しました。

  • 材料性能予測シナリオでは、ファインチューニングなしで予測精度を130%向上させ、約90%に及ぶ非効率的な試験金型および設備テストを削減しました。
  • 部品重量予測シナリオでは、XGBoostと比較してエラーサンプル比率が約31%減少しました。
  • 生産構成要素予測シナリオでは、平均誤差がXGBoostと比較して約54%減少しました。さらに、生産作業条件が変更された際でも、新しいタスク条件のサンプルをコンテキストとして追加するだけで、平均誤差を約62%削減することができました。

Xiaomi Announces Xiaomi-TabLDM: A General-Purpose Foundation Model for Tabular Data

Xiaomi officially announced Xiaomi-TabLDM today, a large-scale model designed for general-purpose table data processing. This model is unique because it can be directly applied to various tabular datasets using a single pre-trained model and unified base architecture. It performs classification and regression predictions without the need for task-specific retraining, parameter tuning, or post-processing integration.

Historically, critical data in fields such as finance, healthcare, manufacturing, and logistics has existed in table formats. However, traditional tabular machine learning often requires costly deployment cycles—including model retraining, parameter adjustment, and complex version management—every time a new dataset is introduced. Xiaomi-TabLDM aims to introduce the foundation model paradigm of "use once, apply many" into the domain of structured data.

Model Capabilities

The model enhances the capabilities of tabular models in three key areas:

  • Pre-training: Xiaomi-TabLDM conducts pre-training by fully utilizing large synthetic data generated from Structural Causal Models (SCM). This expands the pre-training task distribution to encompass diverse data scales, variable types, dependencies, and functional relationships.
  • Architecture: The architecture introduces dual-stream feature grouping, lightweight Attention Residual, and sparse Mixture-of-Experts (MoE). These components model feature relationships at various granularities and expand model capacity through sparse experts.
  • Inference: It incorporates Test-Time Scaling to continuously improve prediction performance by increasing the computational load during inference without modifying the pre-trained model's parameters.

Performance Benchmarks

Xiaomi-TabLDM achieved top rankings across all four public benchmark evaluations, demonstrating particularly outstanding regression capabilities.

  • Ranked 1st in OpenML-CTR23 Regression.
  • Achieved 2nd place in the regression tasks of TALENT, TabArena, and BCCO.
  • Secured 1st place in the binary classification task of TALENT.

In terms of balancing performance and efficiency, for instance, on the TabArena regression task, Xiaomi-TabLDM achieved the second-highest Elo score. Crucially, it reduced training time by 82% and prediction time by 68% compared to the top-ranked model (TabFM). (Note: The Elo score is a system originally used for chess ranking, here utilized to measure the relative performance standing of the model in benchmark tests.)

Industrial Validation

In real-world industrial validation scenarios, Xiaomi-TabLDM demonstrated higher prediction accuracy and superior adaptability across various task conditions compared to existing machine learning methods.

  • Material Performance Prediction: The model improved prediction accuracy by 130% without fine-tuning and reduced inefficient testing of molds and equipment by approximately 90%.
  • Part Weight Prediction: It decreased the error sample rate by about 31% compared to XGBoost.
  • Production Component Prediction: The average error was reduced by approximately 54% compared to XGBoost. Furthermore, when production conditions changed, simply adding about 30 new task condition samples as context reduced the average error by roughly 62%.

Both the model weights and code related to Xiaomi-TabLDM have been officially open-sourced. The relevant resources are available here:

Summary

Xiaomi-TabLDM is a general-purpose, large-scale foundation model capable of being applied to diverse tabular datasets using a single pre-trained architecture. It aims to boost efficiency in processing structured data across various industries, including finance and healthcare, while overcoming the limitations of traditional machine learning methods. The model has proven high accuracy and adaptability in real industrial settings, and its open-sourcing is expected to significantly contribute to the developer community.
