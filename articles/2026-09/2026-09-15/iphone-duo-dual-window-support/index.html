Apple 📱 스마트폰

최초로 '앱 듀얼 창'을 기본 지원하는 Apple 스마트폰, iPhone Duo 내부 화면에서 앱의 두 번째 독립 창을 열 수 있습니다

2026-09-15

UIWindowSceneActivation

UIWindowSceneActivation은 '동일 앱 다중 창/다중 인스턴스'에 더 가깝고, 전통적인 의미의 '앱 듀얼 오픈'과는 다릅니다.

개발자는 동일한 앱이 iPhone Duo의 내부 화면에서 두 번째 독립적인 창을 동시에 열도록 할 수 있습니다. 이는 일반적으로 파일 관리, 이메일, 채팅 또는 브라우저의 두 창과 같이 두 가지 콘텐츠를 나란히 처리하는 데 적합합니다.

전통적인 '앱 듀얼 오픈'은 두 개의 상호 독립적인 앱 컨테이너를 강조하는 반면, Apple의 방식은 동일한 앱이 개발자 지원을 통해 두 개의 인터페이스 창을 가지는 것으로, 일반적으로 동일한 앱 설치 패키지, 계정 세션 및 로컬 데이터를 공유합니다.

실제 사용 경험은 다음과 같을 수 있습니다.

  • 한 창에서 이메일 목록을 보고 다른 창에서 특정 이메일을 엽니다.
  • 한 창에서 폴더를 탐색하고 다른 창에서 파일을 미리 보거나 편집합니다.
  • 두 창에서 동일한 서비스의 다른 콘텐츠 또는 다른 세션을 엽니다.

두 번째 창을 열 수 있는지, 두 번째 창에 무엇이 표시되는지, 두 가지 작업을 동시에 수행할 수 있는지 여부는 해당 앱 개발자의 구현에 따라 결정됩니다.

iPhone Duo 전용 API

IT之家 9월 14일 소식에 따르면, IT 매체 macobserver는 어제(9월 13일) 블로그 게시물을 통해 iPhone Duo에 대한 기술 설명에서 Apple이 6가지 전용 애플리케이션 인터페이스를 공개했으며, 그중 가장 주목할 만한 것은 동일 앱의 다중 창/다중 인스턴스 지원이라고 보도했습니다.

기술 설명에서 Apple은 최소 6가지 iPhone Duo 전용 API 인터페이스를 소개했으며, 그중 UIWindowSceneActivation은 앱이 두 번째 창을 요청하도록 지원합니다.

Apple은 iPhone Duo가 기본 앱 듀얼 창을 지원하는 첫 번째 모델이지만, 새 창은 내부 화면에서만 열 수 있고 외부 화면에서는 열 수 없다고 밝혔습니다.

앱 듀얼 오픈 외에도 이번 기술 설명에서 Apple은 다양한 API 인터페이스 세부 정보를 공개했습니다.

총평

Apple은 iPhone Duo를 통해 'UIWindowSceneActivation'이라는 새로운 개념의 다중 창 기능을 선보입니다. 이는 기존의 '앱 듀얼 오픈'과는 달리, 동일한 앱 내에서 두 개의 독립적인 창을 열어 콘텐츠를 효율적으로 처리할 수 있게 합니다. 이 기능은 iPhone Duo의 내부 화면에서만 지원되며, 개발자의 구현에 따라 다양한 활용 가능성을 제공합니다.

核心功能：同一应用多窗口支持

科技媒体 macobserver 报道，Apple 在关于 iPhone Duo 的技术讲解中披露了其首款原生支持应用双窗口的机型特性。该功能的核心在于允许单个应用程序在内屏上打开第二个独立的窗口或实例。

关键API与技术细节

  • 核心接口： Apple 披露了至少 6 项 iPhone Duo 专属 API 接口，其中最受关注的是支持同一应用打开多窗口/多实例的 UIWindowSceneActivation。
  • 机型定位： iPhone Duo 是首款原生支持应用双窗口的设备。

与传统“应用双开”的区别

Apple 的多窗口机制与传统的“应用双开”存在本质区别，开发者需理解其工作原理：

  • 传统应用双开： 强调两个相互独立的应用容器。
  • Apple 多窗口模式： 是同一 App 由开发者支持的两个界面窗口，通常仍共享同一个 App 安装包、账号会话和本地数据。

实际使用场景与体验

该功能旨在实现并排处理两份内容，提升用户效率，可用于以下场景：

  • 在一个窗口查看邮件列表，另一个窗口打开某封特定邮件。
  • 一个窗口浏览文件文件夹，另一个窗口预览或编辑文件。
  • 在两个窗口同时打开同一服务的不同内容或不同会话。

功能实现与限制

该功能的具体实现细节和用户体验受制于开发者：

  • 控制权： 哪些 App 可以支持第二窗、第二个窗口显示什么内容，以及能否同时进行两个任务，均由该 App 的开发者决定。
  • 屏幕限制： Apple 表示，新窗口只能在内屏上打开，不能在外屏上打开。

总结

Apple 通过 UIWindowSceneActivation 等专属 API 为 iPhone Duo 带来了原生应用多窗口能力。这一功能并非传统意义上的独立“应用双开”，而是允许单个 App 在内屏上创建两个共享数据、并排处理不同内容的界面实例，极大地提升了用户在同一服务内的任务切换效率。

UIWindowSceneActivationとは

UIWindowSceneActivationは、「同一アプリ内での複数ウィンドウ/複数インスタンス」という概念に近く、従来の「アプリのデュアルオープン（二重起動）」とは異なります。

開発者は、同じアプリがiPhone Duoの内部画面内で、2つ目の独立したウィンドウを同時に開くように実装できます。これは、ファイル管理、メール、チャット、ブラウザなど、2種類のコンテンツを並行して処理するのに適しています。

従来の「アプリのデュアルオープン」が、互いに独立した2つのアプリコンテナであることを強調するのに対し、Appleのアプローチは、同じアプリが開発者のサポートを通じて2つのインターフェースウィンドウを持つというものであり、通常、単一のアプリインストールパッケージ、アカウントセッション、ローカルデータを共有します。

実際の利用体験としては、以下のようなものが考えられます。

  • あるウィンドウでメール一覧を表示し、別のウィンドウで特定のメールを開く。
  • 一方のウィンドウでフォルダを閲覧し、もう一方のウィンドウでファイルをプレビューまたは編集する。
  • 2つのウィンドウで同じサービスの異なるコンテンツやセッションを開く。

2つ目のウィンドウが開けるかどうか、何が表示されるか、そして2つのタスクを同時に実行できるかは、該当アプリの開発者がどのように実装したかによって決定されます。

iPhone Duo専用APIの公開

IT之家によると、ITメディアmacobserverは9月13日のブログ投稿で、AppleがiPhone Duoに関する技術説明会において6種類の専用アプリケーションインターフェースを公開したと報じました。特に注目されているのは、同一アプリ内での複数ウィンドウ/複数インスタンスのサポート機能です。

この技術説明会で、Appleは最低6つのiPhone Duo専用APIインターフェースを紹介し、そのうちUIWindowSceneActivationが、アプリに2つ目のウィンドウを要求することを可能にすると報じられました。

Appleは、iPhone Duoが基本的なアプリのデュアルウィンドウをサポートする最初のモデルであると述べましたが、新しいウィンドウは内部画面でのみ開け、外部画面では開けないという制限も明らかにしました。

今回の技術説明会では、アプリのデュアルオープン以外にも、様々なAPIインターフェースの詳細が公開されました。

まとめ

AppleはiPhone Duoを通じて、「UIWindowSceneActivation」という新しい概念の複数ウィンドウ機能を紹介しました。これは従来の「アプリのデュアルオープン」とは異なり、単一のアプリ内で複数の独立したウィンドウを開くことで、コンテンツを効率的に処理することを可能にします。ただし、この機能はiPhone Duoの内部画面でのみサポートされ、具体的な利用可能性は開発者の実装に依存します。

UIWindowSceneActivation

UIWindowSceneActivation is closer to "multi-window/multi-instance within the same app" and differs from the traditional concept of "App Dual Open."

Developers can enable a single application to open a second independent window simultaneously on the internal screen of an iPhone Duo. This setup is generally suitable for handling two pieces of content side-by-side, such as two windows for file management, email, chat, or browsing.

While traditional "App Dual Open" emphasizes two mutually independent app containers, Apple's approach involves the same application having two interface windows through developer support. These windows typically share the same app installation package, account session, and local data.

The actual user experience could look like this:

  • Viewing an email list in one window while opening a specific email in another.
  • Navigating folders in one window and previewing or editing files in another.
  • Opening different content or different sessions of the same service across two windows.

Whether a second window can be opened, what is displayed in that second window, and whether dual tasks can be performed simultaneously will depend on the implementation by the respective app developer.

Dedicated API for iPhone Duo

According to news from IT之家 on September 14th, the tech media outlet macobserver reported via a blog post yesterday (September 13th) that Apple unveiled six dedicated application interfaces for the iPhone Duo, with the most notable being multi-window/multi-instance support within a single app.

In its technical presentation, Apple introduced at least six dedicated API interfaces for iPhone Duo, including UIWindowSceneActivation, which supports an app requesting a second window.

Apple stated that while the iPhone Duo is the first model to support basic App Dual Window functionality, new windows can only open on the internal screen and not on external displays.

In addition to App Dual Open, Apple revealed details on various API interfaces during this technical presentation.

Summary

Apple introduced a new multi-window concept called 'UIWindowSceneActivation' via the iPhone Duo. Unlike existing 'App Dual Open,' this feature allows users to open two independent windows within the same application, enabling efficient content handling. This functionality is supported only on the internal screen of the iPhone Duo and offers diverse use cases based on developer implementation.
