더우바오 모바일 어시스턴트 소비자 버전 출시: GUI 협력 계약 동시 공개, 서드파티 앱 AI 자동화 작업 허용/거부 가능

2026-09-15

소개

IT之家 9월 14일, 더우바오(Doubao) 모바일 어시스턴트 소비자 버전이 오늘 정식 출시되었습니다. 이번 소비자 버전은 미리보기 버전에 비해 안정성, 일상적인 사용성, 그리고 인터랙티브 경험에 중점을 두었습니다.

주요 기능 및 특징

IT之家가 공식 보도자료를 통해 확인한 바에 따르면, 더우바오 모바일 어시스턴트는 음성, AI 버튼 등 다양한 방식으로 호출할 수 있어 여러 시나리오에 적합합니다. 특히 전용 AI 버튼은 지문 인증 기능을 갖추고 있어 본인 확인 후 추가 잠금 해제 없이 어시스턴트를 호출하여 관련 작업을 수행할 수 있습니다. 음성 호출의 경우, 더우바오 모바일 어시스턴트는 원거리, 내부 소음 및 시끄러운 환경 등 다양한 시나리오에 최적화되었습니다.

이번 더우바오 모바일 어시스턴트에는 화면 질문 답변 기능이 새로 추가되어 사용자가 별도로 스크린샷을 찍거나 앱을 전환할 필요 없이 현재 화면 내용을 기반으로 어시스턴트가 작업을 계속 처리할 수 있습니다. 예를 들어, 사용자가 카메라를 실내 환경에 비추고 "이 인테리어 스타일에 맞춰 1.2미터 이내, 가격 1,000위안 이하의 수납장을 찾아줘"라고 말하면, 더우바오는 화면과 요구사항을 결합하여 전자상거래 플랫폼에서 조건에 맞는 상품을 찾을 수 있습니다.

또한, 더우바오 모바일 어시스턴트는 로컬 데이터 검색 도구를 제공하여 사용자가 필요할 때 앨범, 문자 메시지, 메모 등의 정보를 검색할 수 있습니다. 예를 들어, 사용자가 홍콩 및 마카오 여행증의 만료일을 물으면 어시스턴트는 휴대폰의 관련 정보에서 답을 찾을 수 있습니다.

이 외에도 더우바오 모바일 어시스턴트는 녹음 경험을 업그레이드하고 Feishu Miaoji 기능을 통합했습니다. 로컬 검색 도구와 결합하여 사용자는 "어제 사용자 인터뷰에서 언급된 제품 제안"과 같이 구체적인 내용을 직접 질문할 수 있습니다. 사용자는 음성 입력, 세 손가락 위로 스와이프, 또는 AI 버튼과 볼륨 버튼을 동시에 누르는 등의 방식으로 현재 화면 내용을 수동으로 저장하여 로컬에서 검색 가능한 기억을 생성할 수 있습니다.

'휴대폰 조작' 기능 및 SAEP 프로토콜

또한, 더우바오 모바일 어시스턴트는 이번에 "휴대폰 조작" 기능을 베타 형태로 공개할 예정입니다. 공식적으로는 파트너들과 함께 개방적이고 규범적인 휴대폰 AI 애플리케이션 생태계를 구축하기를 희망합니다. 이를 위해 더우바오 모바일 어시스턴트는 화면 자동화 조작 선언 프로토콜(SAEP)을 발표하고, 30일간의 규칙 공시를 동시에 시작합니다.

이 프로토콜에 따라 타사 애플리케이션은 자체적으로 조작 경계를 선언하여 AI 어시스턴트가 해당 애플리케이션 내에서 화면 자동화 조작을 수행하는 것을 허용하거나 거부할 수 있습니다. 더우바오 모바일 어시스턴트는 개발자의 의사를 충분히 존중하며, 관련 조작을 명확히 거부하는 타사 애플리케이션에 대해서는 자동화 조작을 수행하지 않을 것입니다.

데이터 처리 및 보안

더우바오 모바일 어시스턴트는 데이터 수집 및 처리에서 "합리적 필요성"과 "사용자 자율 제어" 원칙을 따르며, Agent 보호 시스템을 구축하여 조작 가능한 범위를 계층적, 등급별로 관리합니다.

출시 기기

주목할 만한 점은 첫 번째 더우바오 모바일 어시스턴트 소비자 버전이 Nubia NaviX Ultra에 탑재될 예정이며, 이 기기는 현재 예약 판매 중이며 9월 16일에 정식 출시됩니다.

총평

더우바오 모바일 어시스턴트 소비자 버전은 안정성과 사용자 경험에 중점을 둔 AI 비서입니다. 음성 및 AI 버튼 호출, 화면 내용 기반 작업 처리, 로컬 데이터 검색 등 다양한 기능을 통해 일상적인 스마트폰 사용을 더욱 편리하게 만듭니다. 특히 SAEP 프로토콜을 통해 개발자의 자율성을 존중하며 개방적인 AI 생태계를 지향하고 있습니다.

产品发布与核心定位

  • 豆包手机助手消费者版本已正式发布，相比预览版更侧重于稳定性、日常可用性及交互体验。

智能唤醒与多场景适配

  • 多种唤醒方式：支持语音和AI键等多种模式，适应不同使用场景。
  • 专属 AI 键优化：该AI键具备指纹鉴权能力，用户完成本人验证后无需二次解锁即可调用助手执行任务。
  • 语音识别增强：针对远场、内噪及嘈杂环境等复杂场景进行了优化。

高级智能功能与本地数据整合

  • 屏幕问答能力（Contextual Q&A）：用户无需截图或切换应用，可让助手结合当前屏幕内容继续处理任务。例如，用户可通过相机对准室内环境，要求“根据这个装修风格，帮我选一个一米二以内、价格不超过一千元的柜子”，豆包可直接在电商平台找到符合条件的商品。
  • 本地数据检索：新增搜索工具，可从手机相册、短信、便签等本地信息中检索答案（如查找港澳通行证的到期时间）。
  • 录音与记忆功能升级：接入飞书妙记能力；用户可通过语音输入、三指上滑或同时按住AI键和音量键等方式手动保存屏幕内容，形成可本地检索的“记忆”。

生态开放与隐私保护机制

  • Beta “操作手机”功能：豆包手机助手推出此功能以构建开放、规范的AI应用生态。
  • SAEP协议建立：发布了屏幕自动化操作声明协议（SAEP），第三方应用可自主声明其操作边界，明确允许或拒绝AI助手进行自动化操作。
  • 数据处理原则：遵循“合理必要”与“用户自主控制”原则；建立了Agent防护体系，对可操作范围进行分层、分级管理。

硬件适配与发售信息

  • 首个豆包手机助手消费者版本将搭载于Nubia NaviX Ultra机型上。
  • 该设备目前已开启预约，并计划于9月16日正式发售。

总结

本次豆包手机助手消费者版本的发布，核心在于提升日常可用性和交互深度。它通过整合屏幕问答、本地数据搜索和飞书妙记等功能，极大地增强了AI助手的实用性。同时，通过推出SAEP协议并强调“合理必要”的数据处理原则，也为构建规范的手机AI生态奠定了基础。

概要

IT之家によると、Doubao（ドウバオ）モバイルアシスタントの一般消費者向けバージョンが本日正式にリリースされました。この消費者版は、従来のプレビュー版と比較して、安定性、日常的な使いやすさ、そしてインタラクティブな体験向上に重点を置いて開発されています。

主要機能と特徴

Doubaoモバイルアシスタントは、音声や専用AIボタンなど多様な方法で呼び出すことができ、様々な利用シーンに対応しています。特に注目されるのは、専用AIボタンが指紋認証機能を備えている点です。これにより、本人確認を済ませた後、追加のロック解除なしにアシスタントを起動し、関連タスクを実行できます。

音声での呼び出し機能は、遠距離や周囲の騒音など、多様な環境下で最適化されています。

今回のアップデートでは、「画面質問回答機能」が新しく追加されました。ユーザーがスクリーンショットを撮ったり、アプリを切り替えたりする必要がなくなり、アシスタントが現在の画面内容に基づいてタスク処理を継続できます。例えば、ユーザーがカメラで室内のインテリアを撮影し、「この内装スタイルに合わせた、1.2メートル以内、価格1,000元以下の収納棚を探して」と指示した場合、Doubaoは画面情報と要求事項を組み合わせて、電子商取引プラットフォームから条件に合った商品を見つけ出すことが可能です。

さらに、ローカルデータ検索ツールが提供され、ユーザーが必要な時にアルバム、メッセージ、メモなどの情報を検索できます。例えば、香港やマカオの旅行証の有効期限について尋ねると、アシスタントは携帯電話内の関連情報から回答を得ることができます。

その他、Doubaoモバイルアシスタントは録音体験がアップグレードされ、「Feishu Miaoji」機能も統合されました。ローカル検索ツールと組み合わせることで、「昨日行われたユーザーインタビューで言及された製品提案」といった具体的な内容を直接質問できます。また、音声入力、3本指でのスワイプ、AIボタンと音量ボタンの同時押しなどの方法で現在の画面内容を手動保存し、ローカルで検索可能な「記憶」を生成することも可能です。

「携帯電話操作」機能とSAEPプロトコル

Doubaoモバイルアシスタントは今回、「携帯電話操作（Phone Operation）」機能をベータ版として公開する予定です。同社は、パートナー企業と協力し、オープンで規範的な携帯電話AIアプリケーションエコシステムの構築を目指しています。

この目標を達成するため、Doubaoモバイルアシスタントは「画面自動化実行プロトコル（SAEP）」を発表するとともに、30日間のルール公表期間を開始します。このプロトコルに基づき、サードパーティのアプリケーションは自律的に操作の境界を宣言することができ、AIアシスタントがそのアプリ内で画面自動化操作を行うことを許可するかどうかを決定できます。Doubaoモバイルアシスタントは開発者の意図を尊重し、関連する操作を明確に拒否したサードパーティのアプリケーションに対しては、自動化操作を実行しません。

データ処理とセキュリティ

Doubaoモバイルアシスタントは、データの収集および処理において「合理的な必要性」と「ユーザーによる自己制御」の原則に従い、「エージェント保護システム」を構築しています。これにより、操作可能な範囲が階層的かつ段階的に管理されています。

発売デバイス

特筆すべき点として、最初のDoubaoモバイルアシスタント消費者バージョンはNubia NaviX Ultraに搭載される予定です。このデバイスは現在予約販売中で、9月16日に正式リリースされます。

まとめ

Doubaoモバイルアシスタントの消費者版は、安定性とユーザー体験向上に焦点を当てたAI秘書です。音声や専用ボタンによる呼び出しに加え、画面内容に基づいたタスク処理やローカルデータ検索といった多機能性を備え、日常的なスマートフォン利用を大幅に便利にします。特にSAEPプロトコルを通じて開発者の自律性を尊重しつつ、オープンなAIエコシステムの実現を目指している点が大きな特徴です。

Introduction

On September 14th, IT之家 reported the official launch of the consumer version of the Doubao mobile assistant. This consumer version focuses on stability, daily usability, and interactive experience compared to its preview version.

Key Features and Characteristics

According to an official press release from IT之家, the Doubao mobile assistant can be invoked through various methods, including voice commands and dedicated AI buttons, making it suitable for multiple scenarios. Notably, the dedicated AI button features fingerprint authentication, allowing users to call the assistant and perform related tasks without additional unlocking after verifying their identity.

For voice invocation, the Doubao mobile assistant is optimized for diverse scenarios, such as long distances, internal noise, and loud environments.

This new version of the Doubao mobile assistant introduces a screen question-answering function. This allows the assistant to continue processing tasks based on the current screen content without the user needing to take separate screenshots or switch apps. For instance, if a user points their camera at an indoor setting and says, "Find storage cabinets within 1.2 meters and under 1,000 yuan that match this interior style," Doubao can combine the screen context with the request to find suitable products on e-commerce platforms.

Furthermore, the Doubao mobile assistant provides a local data search tool, enabling users to retrieve information from albums, text messages, and notes when needed. For example, if a user asks about the expiration date of a Hong Kong or Macau travel pass, the assistant can find the answer within the phone's related information.

In addition, Doubao mobile assistant has upgraded its recording experience and integrated Feishu Miaoji functionality. Combined with the local search tool, users can ask specific questions such as "product suggestions mentioned in yesterday's user interview." Users can manually save the current screen content—through voice input, a three-finger swipe, or simultaneously pressing the AI button and volume button—to create locally searchable memories.

"Phone Control" Functionality and SAEP Protocol

Doubao mobile assistant will also beta-launch "phone control" functionality. The company aims to build an open and standardized mobile AI application ecosystem with partners. To achieve this, Doubao mobile assistant announced the Screen Automation Execution Protocol (SAEP) and simultaneously launched a 30-day rule disclosure period.

Under this protocol, third-party applications can declare their control boundaries themselves. This allows the AI assistant to either permit or deny screen automation actions within that specific application. Doubao mobile assistant respects developer autonomy and will not perform automated controls on any third-party application that explicitly refuses such related operations.

Data Processing and Security

In terms of data collection and processing, Doubao mobile assistant adheres to the principles of "reasonable necessity" and "user self-control," establishing an Agent protection system to manage the scope of control in a hierarchical and tiered manner.

Launch Device

A notable point is that the first consumer version of the Doubao mobile assistant will be equipped on the Nubia NaviX Ultra, which is currently available for pre-order and scheduled for official launch on September 16th.

Summary

The Doubao mobile assistant consumer version is an AI assistant focused heavily on stability and user experience. It enhances daily smartphone use through diverse features like voice/AI button invocation, screen content-based task processing, and local data searching. Critically, by implementing the SAEP protocol, it aims to build an open AI ecosystem while respecting developer autonomy.
