Adobe, Slack에 크리에이티브 도구 통합

Adobe는 오늘 자사의 크리에이티브 도구를 Slack 협업 플랫폼에 통합한다고 발표했습니다. 이제 사용자는 Slack 채팅창에 직접 프롬프트를 입력하여 다양한 콘텐츠를 만들 수 있습니다.

Adobe for Slack은 현재 Slack에 통합되어 있습니다. 사용자는 Slackbot 봇을 열고 "Manage Apps"를 선택한 다음 Adobe를 추가할 수 있습니다. 활성화되면 사용자는 채팅창에 "@Adobe 우리를 위한 계절 포스터 시리즈를 만들어 줘"와 같은 프롬프트를 직접 입력할 수 있습니다.

그러면 Slack은 Adobe의 Photoshop, Premiere, Illustrator 등 크리에이티브 도구를 호출하여 해당 결과물을 생성할 수 있습니다. 사용자는 텍스트 프롬프트뿐만 아니라 다른 사람과의 채팅 내용 및 공유 파일을 참조하여 필요한 콘텐츠를 생성할 수 있습니다.

또한 Adobe for Slack은 Slack 내부 데이터뿐만 아니라 Creative Cloud 리소스에서도 프로젝트 자료를 찾을 수 있습니다. 이 기능은 오늘부터 전 세계 시장에 출시되며, 사용자는 두 회사의 멤버십을 구독하면 사용할 수 있습니다.

총평

Adobe는 자사의 크리에이티브 도구를 Slack 플랫폼에 통합하여 사용자들이 채팅창에서 직접 콘텐츠를 생성할 수 있도록 했습니다. 이 통합을 통해 사용자는 텍스트 프롬프트, 채팅 내용, 공유 파일을 활용하여 Photoshop, Premiere, Illustrator 등의 도구를 통해 다양한 결과물을 만들 수 있습니다. Creative Cloud 리소스 연동도 지원하며, 이 기능은 양사 구독자에게 전 세계적으로 제공됩니다.

核心功能发布：Adobe工具接入Slack协作平台

  • Adobe宣布将旗下创意工具集（Creative Cloud）深度集成到Slack协作平台上，旨在提升工作流的效率和内容创作的便捷性。

使用方式与操作流程

  • 用户可通过在Slack聊天框内直接输入提示词来触发内容创建过程。
  • 具体操作步骤为：打开Slackbot机器人 -> 选择“Manage Apps” -> 添加Adobe应用。
  • 用户可以直接输入指令，例如：“@Adobe 为我们制作一系列季节海报”。

支持的创意工具与数据源

  • 调用工具：集成后可调用包括Photoshop、Premiere和Illustrator等核心创意工具，自动生成相应的设计方案。
  • 输入灵活性：用户不仅可以提供文字提示词（Prompt），还可以引用聊天记录中的其他内容或共享文件作为创作参考。
  • 数据来源广度：该功能可同时调用Slack内部的协作数据以及来自Creative Cloud的专业项目素材库，确保内容的丰富性和关联性。

产品推广与使用条件

Adobe for Slack功能即日起面向全球市场推出。用户需要订阅Adobe和Slack两家企业的会员服务后方可使用该集成功能。

总结

本次Adobe与Slack的深度整合，允许用户在日常协作聊天环境中直接调用Photoshop、Premiere等专业创意工具。通过输入文字提示词或引用现有文件，用户可以极大地简化内容创作流程，实现从沟通到设计的一体化工作流。

AdobeがSlackにクリエイティブツールを統合

Adobeは本日、自社のクリエイティブツール群をコラボレーションプラットフォーム「Slack」に統合すると発表しました。これにより、ユーザーはSlackのチャット画面から直接プロンプトを入力するだけで、様々なコンテンツを生成できるようになります。

この新機能は「Adobe for Slack」として提供され、現在すでにSlackに組み込まれています。利用するには、Slackbotを開き、「Manage Apps」からAdobeを追加して有効化します。アクティベートされると、ユーザーはチャット画面で「@Adobe、私たち向けの季節のポスターシリーズを作って」といったプロンプトを直接入力できます。

すると、SlackがAdobeのPhotoshop、Premiere、Illustratorなどのクリエイティブツールを呼び出し、必要な成果物を生成します。この際、ユーザーは単なるテキストプロンプトだけでなく、他のメンバーとのチャット履歴や共有ファイルを参照しながら、目的に応じたコンテンツを作成することが可能です。

さらに、「Adobe for Slack」はSlack内部のデータのみならず、Creative Cloudのリソースからもプロジェクト資料を検索し利用できます。この機能は本日より全世界市場でリリースされ、両社のメンバーシップを契約しているユーザーが利用可能となります。

まとめ

Adobeは自社のクリエイティブツール群をSlackプラットフォームに統合することで、チャット画面上でのコンテンツ生成体験を提供します。これにより、ユーザーはテキストプロンプトに加え、チャット履歴や共有ファイルを活用してPhotoshopやIllustratorなど多様なツールで成果物を制作できます。また、Creative Cloudリソースとの連携も可能となり、両社サブスクリプションの加入者に対してグローバルに提供される機能です。

Adobe Integrates Creative Tools into Slack Platform

Adobe announced today that it is integrating its creative tools into the Slack collaboration platform. Users can now generate various types of content by entering prompts directly within Slack chats.

The Adobe for Slack integration is currently available in Slack. To use it, users must open the Slackbot bot, select "Manage Apps," and then add Adobe. Once activated, users can enter prompts directly into the chat window, such as "@Adobe create a seasonal poster series for us."

This allows Slack to call upon Adobe's creative tools—including Photoshop, Premiere, and Illustrator—to generate the required results. Users can create necessary content by referencing not only text prompts but also existing chat history with colleagues and shared files.

Furthermore, Adobe for Slack can source project materials from both internal Slack data and external Creative Cloud resources. This feature is launching globally starting today, and access requires a subscription membership to both companies.

Summary

Adobe has integrated its suite of creative tools into the Slack platform, enabling users to generate content directly within their chat environment. This powerful integration allows users to leverage text prompts, existing chat history, and shared files across professional tools like Photoshop, Premiere, and Illustrator. The functionality is supported by connectivity to Creative Cloud resources and will be available globally to subscribers of both Adobe and Slack.
