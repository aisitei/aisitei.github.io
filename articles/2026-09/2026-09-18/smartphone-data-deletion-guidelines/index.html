반도체 저장 매체 블록 삭제 기술 지침

"반도체 저장 매체 블록 삭제 기술 지침"은 반도체 저장 매체 블록 삭제 기술의 구현 방법과 구체적인 작동 명령을 명확히 하며, 반도체 저장 매체 제조업체, 전자 제품 제조업체 등이 블록 삭제 명령을 적용, 호출 및 검증하는 데 적합합니다.

초안 작성 기관:

  • 중국전자기술표준화연구원
  • Yangtze Memory Technologies Co., Ltd.
  • Shenzhen Longsys Electronics Co., Ltd.
  • GigaDevice Semiconductor Inc.
  • Huawei Terminal Co., Ltd.
  • Honor Terminal Co., Ltd.
  • Beijing Xiaomi Mobile Software Co., Ltd.

이 실천 지침은 SSD(Solid State Drive), UFS(Universal Flash Storage), eMMC(Embedded MultiMediaCard) 및 RawFlash에 대해 블록 삭제의 적용 범위, 블록 삭제 방법, 삭제 범위, 구현 효과, 반환 상태 및 검증 및 감사 방법을 명확히 하고, 주류 반도체 저장 매체 블록 삭제 명령과 등가 메커니즘 비교표를 제공합니다.

초안 작성 기관:

  • 중국전자기술표준화연구원

  • SAISI (Shenzhen) Electronic Information Product Standardization Engineering Center Co., Ltd.

  • Zhongzaichengzi (Beijing) Environmental Protection Technology Development Co., Ltd.
  • Beijing SAISI Technology Development Co., Ltd.
  • Hangzhou Qili Software Technology Co., Ltd.
  • Anyunshudun Technology (Hangzhou) Co., Ltd.
  • Sichuan Changhong Greentech Environmental Protection Co., Ltd. 등

이 지침은 전자 제품 정보 삭제 로그 형식과 내용을 통일함으로써 전자 제품 재활용 정보 삭제의 과정 관리 및 조직 관리를 규범화하고, 정보 삭제 식별자를 기반으로 한 신뢰 메커니즘을 구축하여 정보 삭제 전 과정의 추적 및 검증 가능성을 실현하고, 재활용 작업 효율성을 높이는 동시에 사용자의 실질적인 권익을 충분히 보장하며, 전자 제품 재활용 및 중고 거래 산업의 건강하고 규범적인 발전을 촉진하는 것을 목표로 합니다.

승인 후, 재활용 사업자는 정보 삭제가 완료된 전자 제품 또는 대량 전자 제품의 외부 포장에 정보 삭제 물리적 식별자를 부착할 수 있습니다.

정보 삭제가 완료된 중고 전자 제품이 유통되거나 재판매될 때, 정보 삭제 로그 코드를 제공하는 경우 전자 식별자 또는 물리적 식별자를 정보 삭제 로그 코드 중앙에 배치하여 동시에 표시할 수 있습니다.

모바일 스마트 단말 정보 삭제 기술 지침

"모바일 스마트 단말 정보 삭제 기술 지침"은 휴대폰, 태블릿 PC 등 모바일 스마트 단말의 정보 삭제 구체적인 방법, 작동 과정 및 검증 요구사항을 명확히 하며, 모바일 스마트 단말 제품의 정보 삭제 기능 설계, 개발 테스트에 적합하고, 통신 장비 네트워크 접속 허가 감독 기관 등에 참고 자료를 제공할 수 있습니다.

초안 작성 기관:

  • 중국정보통신연구원
  • Boding Shihua (Beijing) Technology Co., Ltd.
  • Telecommunication Terminal Testing & Certification Co., Ltd.

  • Beijing Xiaomi Mobile Software Co., Ltd.
  • vivo Mobile Communication Co., Ltd.
  • Honor Terminal Co., Ltd.
  • Beijing Samsung Communication Technology Research Co., Ltd.
  • Huawei Terminal Co., Ltd.

스마트폰, 태블릿 PC 등 모바일 통신 네트워크에 접속할 수 있는 전자 제품의 정보 삭제 능력 요구사항을 이행하기 위해 전국 네트워크 보안 표준화 기술 위원회는 이 문서를 조직하여 제정했습니다. 정보 삭제 기본 요구사항, 삭제 범위, 삭제 방법, 삭제 작동 과정 등 4가지 측면에서 스마트폰과 태블릿 PC에 대한 관련 요구사항을 제시하고, 각 요구사항의 검증 방법을 명확히 했습니다. 이는 모바일 스마트 단말 제품의 정보 삭제 기능 설계, 개발, 테스트를 지도하는 데 적합하며, 감독 기관 및 제3자 평가 기관에도 참고 자료를 제공할 수 있습니다.

모바일 스마트 단말 정보 삭제는 데이터 덮어쓰기(overwrite)와 블록 삭제 두 가지 방법을 포함하며, 구체적인 요구사항은 다음과 같습니다.

  • a) 모바일 스마트 단말 저장 매체가 자기 매체인 경우, 데이터 덮어쓰기 방법을 사용하여 사용자 데이터 영역의 정보를 삭제합니다. 데이터 덮어쓰기 시, 사용자 데이터 영역, 다른 영역의 사용자 데이터 논리 주소와 물리 주소의 매핑 관계를 삭제하고, 사용자 데이터 영역의 남은 공간에 최소 3회 덮어쓰기를 수행하며, 최소 1회는 난수 덮어쓰기를 포함해야 합니다. 데이터 덮어쓰기 전체 과정 로그를 출력하거나 보존해야 하며, 여기에는 덮어쓰기 시작 시간, 종료 시간, 명령 정보, 실행 상태 등이 포함되지만 이에 국한되지 않습니다.
  • b) 모바일 스마트 단말 저장 매체가 반도체 매체인 경우, 데이터 덮어쓰기 또는 블록 삭제를 선택하여 사용자 데이터 영역의 정보를 삭제할 수 있습니다.
    1. 데이터 덮어쓰기를 선택하는 경우, 사용자 데이터 영역, 다른 영역의 사용자 데이터 논리 주소와 물리 주소의 매핑 관계를 삭제하고, 사용자 데이터 영역의 남은 공간에 최소 1회 덮어쓰기를 수행합니다.
    2. 블록 삭제를 선택하는 경우, 사용자 데이터 영역, 다른 영역의 사용자 데이터 논리 주소와 물리 주소의 매핑 관계를 삭제하고, 사용자 데이터 영역의 남은 공간에 블록 삭제 명령을 실행합니다. 블록 삭제 명령 실행 전체 과정 로그를 출력하거나 보존해야 하며, 여기에는 블록 삭제 시작 시간, 종료 시간, 명령 정보, 실행 상태 등이 포함되지만 이에 국한되지 않습니다.

  • b) 모바일 스마트 단말 저장 매체가 반도체 매체인 경우, 데이터 덮어쓰기 또는 블록 삭제를 선택하여 사용자 데이터 영역의 정보를 삭제할 수 있습니다.
    1. 데이터 덮어쓰기를 선택하는 경우, 사용자 데이터 영역, 다른 영역의 사용자 데이터 논리 주소와 물리 주소의 매핑 관계를 삭제하고, 사용자 데이터 영역의 남은 공간에 최소 1회 덮어쓰기를 수행합니다.
