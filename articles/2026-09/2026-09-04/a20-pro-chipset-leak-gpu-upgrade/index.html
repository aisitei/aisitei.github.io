A20 Pro 칩셋 유출: 7코어 GPU로 업그레이드, Apple iPhone 18 Pro/Max에 최초 탑재

2026-09-04

Apple A20 Pro 칩셋 분석

IT之家 9월 3일 소식에 따르면, 디지털 블로거 @白饭炒白米饭이 8월 30일 웨이보를 통해 솔더링 포인트(납땜 지점) 이미지를 바탕으로 Apple A20 Pro 칩의 규모와 내부 구조를 역추론했습니다. 이 내용은 현재 NotebookCheck 등 여러 매체와 @VadimYuryev 등 해외 블로거들에게 공유되고 있습니다.

IT之家는 관련 웨이보 내용을 다음과 같이 정리했습니다.

솔더링 포인트 이미지를 통해 A20 Pro 칩의 규모와 내부 구조를 역추론하고, 이 칩에 대해 이야기해 보겠습니다. 최종 완성된 이미지(그림 6)에 따르면, 2+4 CPU 구조와 7코어 GPU 구조를 가지고 있습니다. 최종 완성본을 통해 CPU 소형 코어의 L2 캐시가 다시 증가했음을 알 수 있으며, A19 Pro의 6MB L2에서 8MB L2로 업그레이드된 것으로 예상됩니다. CPU 대형 코어의 L2는 16MB로 변함이 없습니다. SLC 캐시는 아직 불분명하지만, 올해 새로운 ISP와 새로운 ANE가 추가되면서 캐시 수요가 상당히 높을 것이므로 줄어들지는 않을 것입니다.

칩 전체의 내부 구조 추론 과정은 다음과 같습니다. 칩 솔더링 포인트 이미지(그림 1)를 통해 LPDDR 인터페이스가 가장 오른쪽에 위치한다는 것을 알 수 있습니다. 다이 솔더링 포인트 배치도(그림 2)를 겹쳐보면 일부 솔더링 포인트가 비스듬하게 배열되어 있고, 일부는 정방향으로 배열되어 있음을 알 수 있으며, 이를 통해 칩 내부 부품의 배치 윤곽도(그림 3)를 그릴 수 있습니다.

윤곽도를 바탕으로 이전 칩 다이와 결합하면 상단이 GPU 부분이고, 중간 부분이 CPU 부분임을 알 수 있으며, 이를 통해 CPU의 내부 레이아웃(그림 4)을 그릴 수 있습니다.

CPU 부분을 그린 후에는 GPU 부분입니다. 역시 윤곽과 솔더링 포인트 배치를 바탕으로 GPU의 배치를 대략적으로 판단할 수 있습니다. 6코어, 7코어, 8코어 등 세 가지 코어 수에 대한 십여 가지 배치 방식을 시도한 결과, 7코어 GPU가 가장 합리적인 배치 방식이었습니다(그림 5).

위 웨이보 정보에 따르면, Apple A20 Pro의 GPU 코어 수는 A19 Pro의 6코어에서 7코어로 증가할 수 있습니다. 해외 블로거 @VadimYuryev는 그래픽 성능(GeekBench 7 Metal 그래픽 예상 점수 기준)이 28% 향상되어 iPad Pro의 M4 칩을 능가할 것으로 예상했습니다.

총평

솔더링 포인트 이미지를 통해 역추론된 Apple A20 Pro 칩은 2+4 CPU와 7코어 GPU 구조를 가질 것으로 예상됩니다. CPU 소형 코어의 L2 캐시는 8MB로 증가하고, GPU 코어 수는 7개로 늘어나 A19 Pro 대비 그래픽 성능이 최대 28% 향상될 가능성이 있습니다.

芯片结构反推与分析

数码博主 @白饭炒白米饭 通过对 Apple A20 Pro 芯片的焊点图进行逆向工程（Reverse Engineering），详细推理出该芯片的内部结构和关键参数，相关内容已被 NotebookCheck 等海外媒体关注。

A20 Pro 核心架构细节

  • CPU 结构： 推理为 2+4 的 CPU 配置。
  • L2 Cache 升级： 预计小核的 L2 Cache 将从 A19 Pro 的 6MB 提升至 8MB；大核的 L2 Cache 保持不变，仍为 16MB。
  • 缓存需求： 由于芯片将集成新的 ISP 和 ANE 等组件，推测 SLC 缓存不会被移除，且对缓存的需求较高。

GPU 与性能预测

  • GPU 核心数变化： 根据焊点图和排布轮廓分析，A20 Pro 的 GPU 部分最终确定为 7 核结构，相比 A19 Pro 的 6 核有所增加。
  • 图形性能提升预估： 海外博主 @VadimYuryev 基于 GeekBench 7 Metal 图形预估得分预测，A20 Pro 的图形性能预计将提升 28%。
  • 竞品对比： 该芯片的图形性能有望超过 iPad Pro 中搭载的 M4 芯片。

推理过程与技术依据

本次分析流程结合了焊点图、Die 焊点点位图和内部元器件排布轮廓图，通过逐步叠加信息，确定了 GPU 和 CPU 的大致布局，并最终锁定了 7 核 GPU 是最合理的配置方式。

总结

此次对 Apple A20 Pro 芯片的分析主要基于焊点图逆向工程，揭示了其在核心架构上的显著升级。A20 Pro 在 CPU L2 Cache、GPU 核心数和整体图形性能方面均有提升，预计将带来超过 M4 等竞品的强大计算能力。

Apple A20 Proチップの分析

IT之家によると、デジタルブロガーの@白饭炒白米饭が8月30日にWeibo（微博）を通じて公開した「はんだ付け点（soldering point）」の画像に基づき、Apple A20 Proチップの規模と内部構造を逆算しました。この情報は現在、NotebookCheckなどの複数のメディアや、海外ブロガーの@VadimYuryev氏などに共有されています。

IT之家がまとめた関連情報によると、はんだ付け点画像からA20 Proチップのサイズと内部構造を推定し、以下の点が明らかになりました。完成イメージ（図6）に基づくと、このチップは「2+4 CPU構造」と「7コアGPU構造」を持つとされています。

最終的な推測モデルからは、CPUのスモールコアのL2キャッシュが再び増加していることが確認でき、A19 Proの6MB L2から8MB L2へのアップグレードが見込まれます。一方、CPUの大規模コアのL2は16MBで変更はありませんでした。SLCキャッシュについてはまだ不明確ですが、今年導入される新しいISP（画像信号プロセッサ）とANE（Apple Neural Engine）によりキャッシュ需要が非常に高いため、減少する可能性はないとされています。

チップ内部構造の推測プロセス

チップ全体の内部構造は、以下の手順で推定されました。まず、チップのはんだ付け点画像（図1）からLPDDRインターフェースが最も右側に配置されていることが判明しました。次に、ダイのはんだ付け点の配置図（図2）を重ね合わせることで、一部の点が斜めに、一部が直角に配列していることがわかり、これに基づいてチップ内部部品の配置概略図（図3）を描きました。

この概略図を以前のチップダイと組み合わせると、上部がGPU部分、中央部がCPU部分であると特定でき、そこからCPUの内部レイアウト（図4）が描かれました。続いてGPU部分についても、概略図とはんだ付け点の配置に基づき配置が推定されました。6コア、7コア、8コアなど複数のコア数について試行錯誤が行われた結果、最も合理的な配置は「7コアGPU」であるという結論に至りました（図5）。

このWeiboの情報によれば、Apple A20 ProのGPUコア数はA19 Proの6コアから7コアに増加する可能性があります。海外ブロガーの@VadimYuryev氏は、グラフィック性能（GeekBench 7 Metalグラフィックス予想スコアに基づく）が28%向上し、iPad Pro搭載のM4チップを凌駕すると予測しています。

総評

はんだ付け点画像から逆算されたApple A20 Proチップは、「2+4 CPU」と「7コアGPU」という構造を持つと予想されます。CPUのスモールコアL2キャッシュが8MBに増加し、GPUコア数が7基に増えることで、A19 Proと比較してグラフィック性能が最大で28%向上する可能性があります。

まとめ

本記事は、デジタルブロガーによる「はんだ付け点」の画像解析に基づき、Apple A20 Proチップの内部構造を逆算したものです。主要な予測スペックとして、「2+4 CPU」「7コアGPU」が挙げられています。特にL2キャッシュの増加とGPUコア数の増強により、A19 Proから大幅にグラフィック性能が向上し、M4チップを超える可能性も指摘されています。

Analysis of Apple A20 Pro Chipset

According to an IT之家 report from September 3rd, digital blogger @白饭炒白米饭 reverse-engineered the size and internal structure of the Apple A20 Pro chip using images of its soldering points (solder joints) posted on Weibo on August 30th. This information has been shared with various outlets, including NotebookCheck, and international bloggers such as @VadimYuryev.

IT之家 summarized the relevant Weibo content as follows:

  • The analysis of the A20 Pro chip's size and internal structure based on soldering point images suggests that the chip features a 2+4 CPU configuration and a 7-core GPU structure.
  • The final reconstructed image indicates an increase in the L2 cache for the smaller CPU cores, expected to upgrade from the A19 Pro’s 6MB L2 to 8MB L2. The L2 cache for the larger CPU cores remains unchanged at 16MB.
  • While the SLC cache is still unclear, it is unlikely to decrease due to the high demand for cache resulting from the addition of a new ISP and ANE this year.

The process of deducing the chip's overall internal structure involved several steps:

  • By examining the chip soldering point image (Figure 1), it was determined that the LPDDR interface is located on the far right side.
  • Overlaying this with the die soldering point layout (Figure 2) revealed that some points were arranged diagonally while others were arranged orthogonally, allowing for the creation of an internal component placement outline (Figure 3).

Based on this outline, combining it with previous chip dies suggested that the top section is dedicated to the GPU and the middle section is dedicated to the CPU. This allowed for the drawing of the CPU's internal layout (Figure 4).

Following the CPU area was the GPU section. The placement of the GPU could also be roughly determined based on the outline and soldering point arrangement. After attempting dozens of layouts for three core counts—6 cores, 7 cores, or 8 cores—the 7-core GPU layout proved to be the most plausible (Figure 5).

According to the Weibo information, Apple A20 Pro's GPU core count may increase from the A19 Pro’s 6 cores to 7 cores. International blogger @VadimYuryev predicted that the graphics performance (based on estimated GeekBench 7 Metal scores) would improve by 28%, potentially surpassing the M4 chip found in the iPad Pro.

Overall Assessment

The Apple A20 Pro chip, reverse-engineered from soldering point images, is expected to feature a 2+4 CPU and a 7-core GPU structure. The L2 cache for the smaller CPU cores is anticipated to increase to 8MB, and the core count increases to 7, suggesting a potential graphics performance boost of up to 28% compared to the A19 Pro.

Summary

Digital bloggers have reverse-engineered the Apple A20 Pro chipset using images of its soldering points. The analysis suggests the chip will feature a 2+4 CPU and a 7-core GPU structure. Key expected upgrades include an increase in the smaller CPU core's L2 cache to 8MB and a jump to 7 GPU cores, which is predicted to boost graphics performance by up to 28% over the A19 Pro.
