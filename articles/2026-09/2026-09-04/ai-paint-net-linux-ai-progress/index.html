이미지 편집기 Paint.NET, 리눅스에 첫 출시: 개발자, AI 지원으로 3주 만에 12년 총합보다 큰 진전 이뤄

2026-09-04

Paint.NET, Linux 지원 시작

IT之家 9월 3일 소식, 개발자 릭 브루스터(Rick Brewster)가 9월 1일 X 플랫폼에 게시물을 올려 Paint.NET 5.2 Build 9739 버전을 출시하며 Wine을 통해 Linux 플랫폼을 처음으로 실험적으로 지원한다고 발표했습니다.

브루스터는 개발 과정에서 가장 큰 장애물은 Direct2D였다고 밝혔습니다. Direct2D는 Microsoft가 Windows 시스템을 위해 특별히 개발한 2D 그래픽 API이며, Paint.NET은 오랫동안 인터페이스 및 이미지 렌더링을 위해 Direct2D에 의존해 왔습니다.

Wine의 Direct2D 기본 지원이 완벽하지 않았기 때문에 브루스터는 기다리지 않고 자체적으로 내부 대체 솔루션을 개발하여 소프트웨어에 필요한 핵심 그래픽 API 기능을 구현했습니다.

브루스터는 AI 프로그래밍 도구인 Claude Code의 도움 덕분에 이번 Linux 이식 작업은 약 3주밖에 걸리지 않았으며, 이전 12년간의 모든 시도를 합친 것보다 더 큰 진전을 이루었다고 밝혔습니다.

단계적인 돌파구를 마련했음에도 불구하고 브루스터는 현재 구현이 여전히 느리고 버그가 많아 일반 사용자가 안정적으로 사용하기에는 아직 어렵다고 솔직하게 인정했습니다.

IT之家가 공개 자료를 확인한 결과, Paint.NET은 Windows용 무료 래스터 이미지 편집기로, 원래 워싱턴 주립대학교와 Microsoft의 지원을 받은 학생 프로젝트였습니다. Windows "그림판"의 향상된 대체품을 목표로 시작되었으며, 이후 시스템 그림판 도구와 Photoshop / GIMP 사이의 소프트웨어로 점차 발전했습니다.

총평

Paint.NET이 Wine을 통해 Linux 플랫폼을 실험적으로 지원하는 5.2 Build 9739 버전을 출시했습니다. 개발자 릭 브루스터는 Direct2D 의존성 문제를 자체 개발한 대체 솔루션으로 해결했으며, AI 프로그래밍 도구의 도움으로 3주 만에 이전 시도들을 뛰어넘는 성과를 거두었습니다. 현재는 속도 저하와 버그가 있지만, Windows 그림판과 Photoshop/GIMP 사이의 무료 래스터 이미지 편집기로서 Linux 사용자들에게 새로운 가능성을 제시합니다.

新品发布与兼容性进展

  • 开发者里克 · 布鲁斯特（Rick Brewster）于 9 月 1 日宣布，Paint.NET 发布了 5.2 Build 9739 版本。
  • 该版本通过 Wine 首次实现了对 Linux 平台的实验性支持。

核心技术挑战与移植方案

此次移植工作的最大障碍在于 Direct2D，这是微软专为 Windows 系统设计的 2D 图形 API，而 Paint.NET 的界面和图像渲染长期依赖此功能。

  • 由于 Wine 对 Direct2D 的原生支持不完善，布鲁斯特没有等待官方支持。
  • 他自行开发了内部替代方案，成功实现了软件所需的核心图形 API 功能，解决了兼容性问题。

开发效率与工具辅助

此次 Linux 移植工作展示了极高的开发效率和技术突破。

  • 得益于 AI 编程工具 Claude Code 的协助，整个 Linux 移植过程仅耗时约 3 周。
  • 该进展超过了 Paint.NET 此前在 Linux 平台上的历次尝试总和（此前累计时间达 12 年）。

产品定位与使用限制

尽管取得了阶段性突破，但布鲁斯特提醒用户，当前实现仍存在运行缓慢、bug 频发等问题，对于普通用户而言尚未达到稳定可用的状态。

  • Paint.NET 本身是一款面向 Windows 的免费栅格图像编辑器。
  • 它最初是学生项目，目标是作为系统“画图”工具的增强替代品，介于基础绘图工具和专业软件（如 Photoshop / GIMP）之间。

总结

Paint.NET 开发者成功为该 Windows 图像编辑器实现了首次实验性 Linux 支持，通过自行开发图形 API 替代方案解决了 Direct2D 的兼容难题。尽管此次移植工作借助 AI 工具Claude Code效率极高，但由于运行速度和Bug等问题，目前仍处于早期测试阶段，尚未达到稳定使用状态。

Paint.NET、Linuxサポートを開始

IT之家による9月3日の報道によると、開発者のリック・ブリュースター（Rick Brewster）は、9月1日にXプラットフォームで投稿し、Paint.NET 5.2 Build 9739バージョンをリリースしました。これにより、Wineを経由してLinuxプラットフォームが初めて実験的にサポートされることが発表されました。

ブリュースター氏は開発過程における最大の障壁はDirect2Dであったと述べています。Direct2DはMicrosoftがWindowsシステム向けに特別に開発した2DグラフィックAPIであり、Paint.NETはこのインターフェースおよび画像レンダリングの処理において長年Direct2Dに依存してきました。

WineによるDirect2Dのネイティブサポートが完璧ではなかったため、ブリュースター氏は待つことなく独自内部代替ソリューションを開発し、ソフトウェアに必要なコアグラフィックAPI機能を実装しました。

ブリュースター氏によると、AIプログラミングツールであるClaude Codeの助けを得たことで、今回のLinux移植作業はわずか約3週間で完了し、過去12年間にわたる全ての試みを合わせたものよりも大きな進歩を遂げたと述べています。

段階的なブレイクスルーを果たしたものの、ブリュースター氏は現在の実装は依然として遅く、バグも多いため、一般ユーザーが安定して使用するにはまだ難しいと率直に認めています。

IT之家が入手した資料によると、Paint.NETはWindows向けの無料ラスタ画像エディタであり、元々はワシントン州立大学とMicrosoftの支援を受けた学生プロジェクトとして始まりました。当初はWindows標準の「ペイント」の強化版を目指して開発され、その後、システム標準の描画ツールとPhotoshop/GIMPの間を埋めるソフトウェアへと徐々に進化してきました。

総評

Paint.NETがWineを通じてLinuxプラットフォームを実験的にサポートする5.2 Build 9739バージョンをリリースしました。開発者のリック・ブリュースター氏は、Direct2Dへの依存という問題を独自に開発した代替ソリューションによって解決し、AIプログラミングツールの支援により、過去の試みを凌駕する成果をわずか3週間で達成しました。

現時点では動作速度の低下やバグが残るものの、Windows標準の描画ツールとPhotoshop/GIMPの中間に位置する無料ラスタ画像エディタとして、Linuxユーザーに新たな可能性を提示しています。

Paint.NET Begins Experimental Linux Support

On September 3rd, IT之家 reported that developer Rick Brewster announced experimental support for the Linux platform via Wine, releasing Paint.NET version 5.2 Build 9739 on September 1st.

Overcoming Direct2D Dependencies

Brewster stated that the biggest hurdle during development was Direct2D. Direct2D is a specialized 2D graphics API developed by Microsoft for Windows systems, and Paint.NET has long relied on it for its interface and image rendering.

Because Wine's native support for Direct2D was not perfect, Brewster proactively developed an internal replacement solution to implement the core graphic API functionality required by the software.

Development Progress and Current Limitations

Brewster revealed that with the assistance of the AI programming tool Claude Code, this Linux port took only about three weeks—representing a greater advancement than all previous attempts combined over the past 12 years.

Despite achieving a significant breakthrough, Brewster was candid in admitting that the current implementation is still slow and buggy, making it difficult for general users to use stably.

Background on Paint.NET

According to materials reviewed by IT之家, Paint.NET is a free raster image editor for Windows. It originally started as a student project supported by Washington State University and Microsoft. Its goal was to be an enhanced alternative to the Windows "Paint" application, gradually evolving into software positioned between system painting tools and professional programs like Photoshop or GIMP.

Summary

Developer Rick Brewster has released Paint.NET version 5.2 Build 9739, providing experimental Linux support through Wine. To overcome the core dependency on Windows' Direct2D API, he developed an internal replacement solution. Utilizing AI programming tools like Claude Code, this port was completed in just three weeks, marking a major leap forward for the free raster image editor. While currently experiencing performance slowdowns and bugs, this release offers new possibilities for Linux users.
