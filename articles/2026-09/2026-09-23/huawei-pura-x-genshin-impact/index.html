Huawei Pura X View 바 타입 스마트폰 게임 어시스턴트, 원신 스마트 라이트 앤 섀도우 기능 추가로 하이라이트 반사 효과 향상

2026-09-23

소개

세계 최초의 와이드 바 타입 스마트폰인 Huawei Pura X View가 9월 7일 공식 출시되었습니다. 이 모델은 16:9.5 비율의 패널 디자인과 Kirin 9030S 프로세서를 탑재했으며, 5999위안부터 시작합니다.

게임 기능

Huawei Pura X View는 게임 어시스턴트를 통해 '원신' 플레이 시 광원 효과 설정을 지원합니다(다른 모델은 현재 지원하지 않음). 스마트 광원 효과를 켜면 하이라이트 반사 효과를 높일 수 있습니다.

그러나 이 모델은 '원신' 플레이 시 HDR 조정 기능이 없어 스마트 HDR을 통한 명암 디테일 대비 강화 기능을 사용할 수 없습니다. 현재 Huawei Mate 80 Pro Max는 스마트 HDR을 지원하지만, 스마트 광원 효과는 지원하지 않습니다.

Huawei HarmonyOS 7 시스템 게임 어시스턴트의 광원 효과 설정은 고성능 모드의 일부입니다. Huawei 공식 웹사이트 설명에 따르면, "일부 기능은 모델 또는 게임이 아직 지원되지 않아 표시되지 않을 수 있습니다."

고성능 모드를 켜면 게임 내 화면의 부드러움과 반응성을 향상시킬 수 있으며, 일부 게임에서는 해상도(화면 선명도 향상), HDR(명암 대비 강화), 광원 효과(하이라이트 반사 효과 추가) 등을 설정할 수 있습니다.

총평

Huawei Pura X View는 Kirin 9030S 프로세서를 탑재한 와이드 바 타입 스마트폰으로, '원신' 플레이 시 스마트 광원 효과를 지원하여 하이라이트 반사 효과를 강화할 수 있습니다. 그러나 HDR 조정 기능은 지원하지 않아 명암 대비 강화에는 한계가 있습니다. 고성능 모드를 통해 전반적인 게임 성능을 향상시킬 수 있습니다.

新品发布概览

  • 全球首款阔直板手机 Huawei Pura X View 已于 9 月 7 日正式上市。
  • 该机型的起售价为 5999 元。

核心硬件规格

  • 采用 16:9.5 的面板比例设计，属于阔直板屏幕形态。
  • 搭载麒麟 9030S 处理器。

游戏性能模式与功能特性

华为鸿蒙 HarmonyOS 7 系统集成了游戏助手，通过“高性能模式”来提升游戏的体验和流畅度。

  • **高性能模式功能：** 开启后可提升游戏内的画面流畅度和跟手性。
  • **可自定义设置项：** 部分游戏支持用户设置分辨率（用于增强清晰度）、HDR（增强明暗光亮对比）以及“光影感”（增加高光反射效果）。

Pura X View 的特色功能与局限性

  • **独有特性：** Pura X View 在游玩《原神》时支持游戏助手进行“光影感”设置，可增加高光反射效果（其他机型暂不支持此功能）。
  • **兼容性限制：** 当前该机型在游玩《原神》时缺失 HDR 调节功能，无法开启智能 HDR 来增强明暗细节对比。

设备间功能对比

  • **Huawei Mate 80 Pro Max 的优势：** 支持智能 HDR 功能。
  • **功能差异点：** Huawei Pura X View 虽然支持“光影感”，但与 Mate 80 Pro Max 不同，Pura X View 在游戏场景下缺乏智能 HDR 增强明暗细节对比的能力。

总结

华为发布了全球首款阔直板手机 Pura X View，其核心亮点在于搭载麒麟 9030S 处理器和独特的“光影感”游戏模式。虽然该机型提供了高性能的屏幕优化功能，但在与 Mate 80 Pro Max 等其他设备进行对比时，用户需注意在 HDR 增强明暗细节对比等高级功能上的差异和兼容性限制。

概要

世界初のワイドバータイプのスマートフォン「Huawei Pura X View」が9月7日に正式に発売されました。本モデルは、16:9.5のパネルデザインとKirin 9030Sプロセッサーを搭載し、価格は5,999元から提供されます。

ゲーム機能

Huawei Pura X Viewは、「原神」をプレイする際に「ゲームアシスタント」を通じて光源エフェクト設定をサポートしています（他のモデルでは現在対応していません）。スマート光源エフェクトをオンにすることで、ハイライトの反射効果を高めることができます。

ただし、本モデルには「原神」プレイ時のHDR調整機能がないため、スマートHDRによる明暗ディテールのコントラスト強化機能は利用できません。なお、現行のHuawei Mate 80 Pro MaxはスマートHDRをサポートしていますが、スマート光源エフェクトは対応していません。

HarmonyOS 7システムゲームアシスタントの光源エフェクト設定は、「高性能モード」の一部です。Huawei公式サイトの説明によると、「一部機能はモデルまたはゲームがまだ対応していないため表示されない場合があります。」

「高性能モード」をオンにすることで、ゲーム内の画面の滑らかさや反応性を向上させることが可能です。また、一部のゲームでは以下の設定を行うことができます。

  • 解像度（画面鮮明度の向上）
  • HDR（明暗コントラストの強化）
  • 光源エフェクト（ハイライト反射効果の追加）

Introduction

The Huawei Pura X View, described as the world's first wide bar type smartphone, was officially launched on September 7th. This model features a 16:9.5 panel design and is equipped with the Kirin 9030S processor, starting at 5999 yuan.

Gaming Features

The Huawei Pura X View utilizes its Game Assistant to support light source effects when playing 'Genshin Impact' (a feature not currently supported by other models).

  • Smart Light Source Effect: Turning on this effect can enhance highlight reflection during gameplay.

However, the model lacks an HDR adjustment function for 'Genshin Impact,' meaning users cannot utilize contrast enhancement through Smart HDR. While the Huawei Mate 80 Pro Max currently supports Smart HDR, it does not support smart light source effects.

The light source effect setting within the HarmonyOS 7 system Game Assistant is part of the High Performance Mode. According to official Huawei documentation, "Some features may not be displayed because they are not yet supported by the model or game."

Activating High Performance Mode can improve the smoothness and responsiveness of in-game screens. Furthermore, some games allow users to configure settings such as:

  • Resolution (to enhance screen clarity)
  • HDR (for enhanced contrast)
  • Light Source Effects (to add highlight reflection)

Overall Review

The Huawei Pura X View is a wide bar type smartphone powered by the Kirin 9030S processor. Its key gaming advantage is the support for smart light source effects when playing 'Genshin Impact,' which enhances highlight reflections. However, due to the lack of HDR adjustment functionality, its ability to enhance contrast is limited. Overall game performance can be significantly boosted through High Performance Mode.

Summary

The Huawei Pura X View is a new wide bar smartphone featuring the Kirin 9030S processor and a 16:9.5 panel. Its standout gaming feature is the smart light source effect for games like 'Genshin Impact,' which boosts highlight reflection. While High Performance Mode improves overall responsiveness, users should note that the device lacks HDR adjustment capabilities, limiting its contrast enhancement features.
