Snapseed 4.0 업데이트: 안드로이드 사용자에게 새로운 기능 제공

IT之家에 따르면, Google이 Play 스토어에 사진 편집 소프트웨어 Snapseed 4.0을 출시하며 안드로이드 사용자들을 위한 'Snapseed Camera' 기능을 추가했습니다. 이 기능을 통해 사용자는 필름 필터를 적용하여 사진을 촬영할 수 있게 되었습니다.

주요 업데이트 및 개선 사항

이번 Snapseed 4.0 업데이트는 여러 면에서 대대적인 개편과 기능 강화를 이루었습니다. 주요 내용은 다음과 같습니다:

  • 재설계된 사용자 인터페이스(UI): 편집 속도가 빨라지고, 새로운 '즐겨찾기' 바와 간소화된 도구 보기 기능을 제공합니다.
  • 핵심 업그레이드: 비파괴 편집(Non-destructive) 및 일괄 편집 기능이 도입되었습니다.
  • 전문 기능 강화: 스마트 마스킹(Smart Masking), Snapseed Camera, 인물 사진 및 필름 효과 관련 부분이 대폭 업데이트되었습니다.
  • 새로운 도구 추가: 색상 HSL 조정, 디헤이즈(De-haze), 글로우(Glow) 등 다양한 기능을 통해 색상과 빛을 정밀하게 제어할 수 있습니다.

사용자 경험 및 인터페이스 개편

9To5Google의 보도에 따르면, 이번 업데이트에서는 홈 화면 인터페이스가 전면 재설계되었습니다. 상단에는 편집된 사진이 표시되며, 하단의 '사진 추가' 버튼을 통해 시스템 파일 관리자에서 이미지를 선택하여 편집을 시작할 수 있습니다.

편집기 하단은 세 개의 탭으로 나뉘어 구성되어 있습니다: Looks(효과), Tools(도구), Export(내보내기). 이 중 'Tools' 탭은 다시 Refine(정교화), Fix(수정), Style(스타일), All(전체) 네 가지 하위 섹션으로 세분화되었습니다.

필름 카메라 기능 추가

가장 주목할 만한 변화 중 하나는 필름 필터의 도입입니다. 사용자들은 Snapseed Camera를 통해 코닥 포트라 400(Kodak Potra 400, KP1), 금 200(Gold 200, KG1), Fujifilm Superia 200(FS1), Pro 400h(FP1) 등 실제 필름의 느낌을 재현한 다양한 스타일의 필터를 선택할 수 있습니다.

총평

Snapseed 4.0 업데이트는 단순한 기능 추가를 넘어, 사용자 경험 전반에 걸친 대대적인 개편을 보여줍니다. 특히 비파괴 편집 및 일괄 처리 기능을 도입하고 전문 필름 카메라 모드를 추가함으로써, 사용자들이 더욱 정교하고 창의적인 사진 작업을 할 수 있도록 지원하는 플래그십 소프트웨어로 거듭났습니다.

版本更新与界面重构

Google 已在 Play 商店发布 Snapseed 4.0 修图软件。本次更新对用户界面进行了重新设计，旨在提供更快的编辑速度、全新的收藏夹栏以及简化的工具视图。

核心功能与新工具

  • 新增功能：支持无损编辑和批量编辑。
  • 专业功能：包含智能蒙版、Snapseed 相机以及人像和胶片的重大更新。
  • 新工具：引入 HSL 颜色控制、去雾（Dehaze）、光晕（Bloom）和泛光（Flare）等工具，帮助用户更好地掌控色彩与光线。

Snapseed Camera 与胶片滤镜

新增的 Snapseed Camera 支持多种模拟经典胶片的滤镜效果，具体包括：

  • Kodak Potra 400 (KP1)
  • Gold 200 (KG1)
  • Fujifilm Superia 200 (FS1)
  • Pro 400h (FP1)

界面布局细节

首页设计经过重构，顶部展示编辑过的照片，底部设有“添加照片”按钮。编辑器底部分为 Looks、Tools 和 Export 三个标签页；其中 Tools 标签进一步细分为 Refine、Fix、Style 和 All。

总结

Snapseed 4.0 在 Play 商店发布，带来了显著的 UI 优化和核心功能增强。本次更新重点引入了无损/批量编辑功能以及丰富的胶片滤镜效果，旨在提升 Android 用户在处理照片时的效率与创作多样性。

Snapseed 4.0 アップデート：Androidユーザー向けの新機能提供

IT之家の報道によると、GoogleはPlayストアにて写真編集ソフトウェア「Snapseed」のバージョン4.0をリリースし、Androidユーザー向けに「Snapseed Camera」機能を追加しました。この機能により、ユーザーはフィルムフィルターを適用しながら写真を撮影することが可能になります。

主要なアップデートと改善点

今回のSnapseed 4.0アップデートでは、多方面において大幅な刷新と機能強化が行われました。主な内容は以下の通りです。

  • 再設計されたユーザーインターフェース（UI）： 編集スピードの向上に加え、新しい「お気に入り」バーや簡略化されたツール表示機能が提供されます。
  • コア機能のアップグレード： 非破壊編集（Non-destructive）および一括編集機能が導入されました。
  • プロ向け機能の強化： スマートマスキング（Smart Masking）、Snapseed Camera、ポートレート、およびフィルム効果に関連する要素が大幅にアップデートされました。
  • 新ツールの追加： 色彩のHSL調整、デヘイズ（De-haze）、グロウ（Glow）など、多彩な機能を通じて色と光を精密にコントロールできるようになります。

ユーザー体験とインターフェースの刷新

9To5Googleの報道によると、今回のアップデートではホーム画面のインターフェースが全面的に再設計されました。上部には編集済みの写真が表示され、下部の「写真を追加」ボタンからシステムファイルマネージャー内の画像を選択して編集を開始できます。

エディタの下部は、Looks（効果）、Tools（ツール）、Export（書き出し）の3つのタブで構成されています。このうち「Tools」タブは、Refine（精緻化）、Fix（修正）、Style（スタイル）、All（すべて）の4つのサブセクションに細分化されました。

フィルムカメラ機能の追加

最も注目すべき変化の一つは、フィルムフィルターの導入です。ユーザーはSnapseed Cameraを通じて、Kodak Potra 400 (KP1)、Gold 200 (KG1)、Fujifilm Superia 200 (FS1)、Pro 400h (FP1)など、実際のフィルムの質感を再現した多様なスタイルのフィルターを選択できるようになります。

総評

Snapseed 4.0のアップデートは単なる機能追加にとどまらず、ユーザー体験全体における大幅な刷新を示しています。特に非破壊編集や一括処理機能の導入、そして専門的なフィルムカメラモードの追加により、ユーザーがより精緻でクリエイティブな写真制作を行えるフラッグシップソフトウェアへと進化しました。

まとめ

Snapseed 4.0は、UIの刷新や非破壊編集・一括処理といった強力な機能の導入により、ユーザー体験を大幅に向上させました。また、Snapseed Cameraによる多彩なフィルムフィルターの提供など、より高度でクリエイティブな写真制作をサポートするツールへと進化しています。

Snapseed 4.0 Update: New Features for Android Users

According to IT Home, Google has released Snapseed 4.0 on the Play Store, introducing the "Snapseed Camera" feature for Android users. This functionality allows users to apply various film filters directly while taking photos.

Key Updates and Improvements

The Snapseed 4.0 update brings significant overhauls and enhanced capabilities across several areas:

  • Redesigned User Interface (UI): Provides faster editing speeds, a new "Favorites" bar, and a simplified tool view.
  • Core Upgrades: Introduction of non-destructive editing and batch processing features.
  • Enhanced Professional Features: Major updates to Smart Masking, Snapseed Camera, Portrait photos, and film effects.
  • New Tools: Added functions such as HSL adjustment, De-haze, and Glow for precise control over color and light.

User Experience and Interface Overhaul

According to 9To5Google, the home screen interface has been completely redesigned in this update. The top section displays edited photos, while a "Add Photo" button at the bottom allows users to select images from the system file manager to begin editing.

The bottom of the editor is organized into three tabs: Looks, Tools, and Export. The "Tools" tab has been further categorized into four sub-sections: Refine, Fix, Style, and All.

Film Camera Feature Addition

One of the most notable changes is the introduction of film filters. Through Snapseed Camera, users can select various styles that replicate the aesthetic of real film stocks, such as Kodak Potra 400 (KP1), Gold 200 (KG1), Fujifilm Superia 200 (FS1), and Pro 400h (FP1).

Overall Review

The Snapseed 4.0 update goes beyond simple feature additions, representing a comprehensive overhaul of the overall user experience. By incorporating non-destructive editing, batch processing, and professional film camera modes, it has evolved into flagship software that supports more sophisticated and creative photo workflows.

Snapseed 4.0 introduces a major UI redesign for Android users, featuring organized tool tabs and faster navigation. Key technical upgrades include non-destructive editing, batch processing, and advanced tools like HSL adjustment and De-haze. The addition of the Snapseed Camera feature provides diverse film filters to enhance creative photography.
