Huawei HarmonyOS 6.1.1 (24) Beta1 버전 출시, 카메라 컨트롤러에 Camera Kit의 피사체 추적 기능 제공

2026-05-01

개요

Huawei 개발자 공식 웹사이트에 따르면 HarmonyOS 6.1.1 (24) Beta1 버전이 출시되었으며, 6.1.0 (23) 버전을 기반으로 개발 기능이 더욱 강화되었습니다.

주요 기능 강화

  • Ability Kit: AbilityStage 컨텍스트 기능이 강화되어 동적 리소스 로딩을 지원합니다.
  • ArkUI: 평행 시야 상태 획득, 사용자 정의 컴포넌트의 Ability 간 마이그레이션, 동적 레이아웃 컨테이너 등의 기능이 강화되었으며, 여러 컴포넌트의 C API가 추가되었습니다.
  • ArkTS: 가상 머신 측정 및 모니터링 기능이 강화되었고, taskpool 작업 시간 초과 설정을 지원합니다.
  • ArkWeb: 다운로드 작업 콜백 기능이 강화되었고, URL 화이트리스트 및 보안 제어 인터페이스가 추가되었습니다.
  • Camera Kit: 지연 미리보기 출력 및 자동 프레이밍(影随人动) 기능이 추가되었습니다.
  • Audio Kit: MIDI C API가 추가되어 외부 장치 연결을 지원합니다.
  • FAST Kit: 동시 해시 테이블, 벡터 연산 및 필터 기능이 추가되었습니다.
  • Performance Analysis Kit: 리소스 수집 및 크래시 로그 분석 기능이 강화되었습니다.
  • 새로운 Kit: Content Embed Kit(콘텐츠 임베딩 서비스) 및 Enterprise Threat Protection Kit(기업 위협 방지 서비스) 등이 추가되었습니다.

DevEco Studio 개선 사항

DevEco Studio의 기능도 더욱 강화되었습니다.

  • API 24 프로젝트 개발을 지원합니다.
  • Hot Reload 기능이 강화되어 C++ 코드 및 리소스 파일 수정이 가능합니다.
  • Binder 통신 정보, 메인 스레드 작업 큐, 샘플링 스택 데이터 등 더 많은 AppFreeze 로그를 분석하여 개발자의 문제 해결 효율성을 높입니다.
  • ComMemory 템플릿이 새로 추가되어 UI 인터페이스의 각 컴포넌트 메모리 할당 상황을 분석하고 UI 컴포넌트 메모리 누수 문제를 해결하는 데 도움을 줍니다.

HarmonyOS 6.1.1 (24) Beta1 신규 및 강화 기능

Ability

  • Ability의 마지막 종료 정보 필드에 종료 원인 획득 지원이 추가되었습니다.
  • AbilityStage 컨텍스트에 launchElement 필드가 추가되어 AbilityStage가 onCreate를 호출할 때 애플리케이션이 로드 중인 Ability를 알려 동적으로 리소스를 로드할 수 있습니다.
  • 애플리케이션 내 바로가기 조회 및 삭제 기능이 추가되어 사용자가 애플리케이션의 데스크톱 바로가기를 보고 관리할 수 있습니다.
  • 기존 관계형 데이터베이스를 생성하거나 여는 동기화 메서드가 추가되었습니다. 동기화 메서드는 RdbStore를 얻을 때까지 스레드를 블록할 수 있습니다.

미디어

  • 컴포넌트 콘텐츠에 HDR(고동적 범위 이미징) 밝기 효과를 추가하는 기능이 추가되었습니다.
  • 비디오의 AIHDR 형식이 추가되었습니다.

가상 머신

  • 가상 머신 측정 및 모니터링 기능이 강화되었습니다.
  • 모든 가상 머신 스레드의 힙 메모리 정보(스레드 ID, 스레드 이름, 힙 유형, 힙 객체 크기 포함)를 획득하는 기능이 추가되었습니다.
  • enableLocalHandleDetection 인터페이스가 추가되어 EventHandler 및 libuv 메커니즘의 작업이 범위 내에서 실행되도록 보장하여 메모리 누수를 방지합니다.
  • 힙 메모리가 경고 임계값을 초과할 경우의 콜백 함수가 추가되어, 가상 머신 메인 스레드에서 가비지 컬렉션 완료 후에도 힙 메모리가 경고 임계값을 초과하면 콜백이 실행됩니다.
  • taskpool의 execute 메서드가 강화되어, 작업 또는 작업 그룹 실행 시 작업 시간 초과 시간을 지정할 수 있습니다. 작업 또는 작업 그룹의 실행 시간이 설정된 시간 초과 시간을 초과하면 해당 오류 메시지가 발생합니다.

ArkUI

  • 애플리케이션이 평행 시야 기능을 능동적으로 통합할 때, 새로운 API 인터페이스를 통해 런타임에 현재 평행 시야의 분할 상태를 획득하여 비즈니스 로직 및 UX 애니메이션 등을 조정할 수 있습니다.
  • 사용자 정의 컴포넌트가 Ability 간 마이그레이션을 지원합니다.
  • 여러 컴포넌트의 C API가 추가되었습니다: OH_ArkUI_DecorationStyleOptions, OH_ArkUI_TextDataDetectorConfig, OH_ArkUI_TextEditorSelectionMenuOptions, OH_ArkUI_TextEditorPlaceholderOptions, OH_ArkUI_TextEditorStyledStringController, OH_ArkUI_TextEditorParagraphStyle, OH_ArkUI_ShadowOptions, OH_ArkUI_TextEditorTextStyle.
  • 일련의 속성 문자열 C API가 추가되었습니다.
  • 경쟁 전략을 포함하는 이벤트를 대상 UI 컴포넌트 노드로 전달하는 것을 지원합니다.
  • UIContext에 해당하는 페이지의 루트 노드를 획득하는 기능이 추가되었습니다.
  • Text 컴포넌트에 좌표에 따라 가장 가까운 문자 위치 정보를 획득하는 기능이 추가되었습니다.
  • Image 컴포넌트의 NODE_IMAGE_RESIZABLE 속성 메서드에 OH_Drawing_Lattice 타입 매개변수 생성을 지원하는 기능이 추가되었습니다.
  • 드래그 비동기 알림 인터페이스가 추가되어, 드래그 드롭 동작에서 잘라내기 또는 복사 처리 방식을 지정하고 드래그 드롭 동작의 애니메이션 실행 여부를 지정할 수 있습니다.
  • onNeedSoftkeyboard 콜백이 추가되어 개발자가 포커스 전환 후에도 소프트 키보드를 닫지 않도록 설정할 수 있습니다.
  • CanvasRenderingContext2D 및 OffscreenCanvasRenderingContext2D에 antialias 속성이 추가되어 텍스트 안티앨리어싱 기능을 끌 수 있습니다.
  • 분할 버튼에 enableStateAnimation 설정 항목이 추가되어, selectedIndexes가 바인딩된 상태 변수 변경 시 시스템 애니메이션을 실행할지 여부를 지정합니다.
  • Tabs 컴포넌트에 중첩 스크롤 기능이 추가되었습니다.
  • JS 컴포넌트에 회전 크라운 이벤트 리스닝 인터페이스가 추가되었습니다.
  • 여러 줄 텍스트의 축약 모드에 줄 시작 내용 생략(MULTILINE_START) 또는 줄 중간 내용 생략(MULTILINE_CENTER) 설정 지원이 추가되었습니다.
  • 동적 레이아웃 컨테이너 컴포넌트가 추가되어 런타임에 다른 레이아웃 알고리즘으로 동적으로 전환할 수 있으며, 자식 컴포넌트의 상태를 변경하지 않습니다.
  • 창 관리에 WindowStage의 페이지 콘텐츠(UIContent)를 필요에 따라 파괴하는 기능이 추가되었습니다.

ArkWeb

  • 다운로드 작업 완료 콜백에서 다운로드 항목의 원본 URL 주소를 획득하는 기능이 추가되었습니다. 참조 페이지의 URL 주소를 획득하는 기능이 추가되었습니다.
  • ArkWeb 웹 페이지 요청이 User-Agent Client Hints 기능을 지원합니다.
  • ArkWeb에 기본 오른쪽 클릭 메뉴 활성화 스위치가 추가되어, 이 인터페이스를 통해 기본 오른쪽 클릭 메뉴를 켤지 끌지 제어할 수 있습니다.
  • 웹 페이지의 URL 화이트리스트를 설정할 수 있으며, 화이트리스트 내의 URL만 로드/이동이 허용되고, 그렇지 않으면 차단되고 경고 페이지가 팝업됩니다.

오디오

  • 오디오 캡처 및 오디오 렌더링에 독립적인 오디오 세션 정책 및 동작 매개변수 설정 지원이 추가되었습니다.
  • OH_MIDI의 C API가 추가되어 애플리케이션이 USB 또는 Bluetooth BLE를 통해 외부 MIDI 장치(예: MIDI 키보드, 전자 피아노, MIDI 컨트롤러 등)를 연결하여 MIDI 메시지 송수신, 장치 열거 및 핫 플러그 리스닝을 구현할 수 있으며, 음악 창작, 악기 녹음 및 교육, MIDI 장치 제어 등의 시나리오에 사용할 수 있습니다.

비디오

  • Cinepak 미디어 형식의 코덱 기능이 추가되었습니다.
  • 특정 MIME 유형의 보안 디코더를 필터링하는 기능이 추가되어, 디지털 저작권 관리로 보호되는 DRM 미디어 리소스를 처리할 때 보안 링크를 지원하는 "보안 디코더"를 사용할 수 있습니다.
  • 백그라운드 재생 모드 설정 지원이 추가되어, 애플리케이션이 시스템에 백그라운드 재생 지원 여부를 알릴 수 있으며, 시스템은 기능에 따라 실시간 캡슐 표시를 결정합니다.

카메라

  • 지연 미리보기 출력 객체를 생성하는 기능이 추가되어, 스트림 구성 시 일반 미리보기 출력 객체 대신 데이터 스트림에 추가됩니다. 동시에 지연 미리보기의 Surface 설정도 지원합니다.
  • 카메라 컨트롤러에 자동 프레이밍(AUTO_FRAMING) 기능이 제공되어, 수동으로 화면을 조정할 필요 없이 하위 레이어에서 자동 자르기 및 확대/축소를 통해 인물 피사체가 항상 화면 중앙에 있도록 보장합니다.

Wi-Fi

  • C API를 통해 Wi-Fi 연결 정보를 획득하는 기능이 추가되었습니다.

Bluetooth

  • A2DP 재생 상태 브로드캐스트 및 SCO 브로드캐스트 이벤트가 추가되었습니다.

Content Embed Kit (새로운 Kit)

  • Content Embed Kit(콘텐츠 임베딩 서비스)는 애플리케이션 간 문서 상호 임베딩 및 공동 편집을 위한 프레임워크 기능을 제공하며, 개발자를 위해 클라이언트 및 서버 개발 인터페이스를 캡슐화하여 문서의 애플리케이션 간 임베딩 및 협업을 신속하게 구현할 수 있도록 합니다.

메뉴

  • 단일 1차 메뉴 항목 내용 업데이트 지원이 추가되었습니다.
  • 단일 2차 메뉴 항목 내용 업데이트 지원이 추가되었습니다.
  • 메뉴 항목의 기본 표시 아이콘 및 선택 시 표시되는 아이콘을 설정하는 기능이 추가되었습니다.

보안

  • 코드 서명 정보 조회 기능이 추가되어 개발자가 장치에 서명된 파일의 서명 정보를 획득할 수 있습니다.
  • 디지털 쉴드 서비스가 Tablet, PC/2in1 장치를 지원합니다.
  • 새로운 시스템 보안 관련 이벤트가 추가되었습니다: 프로세스 권한 상승 이벤트, 프로세스 비정상 디버깅 이벤트, 시스템 디렉토리 비정상 마운트 이벤트, 프로세스 비정상 크래시 이벤트, 애플리케이션 코드 미서명 이벤트, 애플리케이션 코드 서명 검증 비정상 이벤트, 드라이버 코드 서명 검증 비정상 이벤트, 드라이버 불법 커널 메모리 매핑 이벤트, 커널 메모리 비정상 사용 이벤트.
  • 애플리케이션 목록 관리 기능이 추가되어 개발자가 특정 애플리케이션이 KIA 정책의 통제를 받지 않도록 설정할 수 있습니다.

HDC

  • 상위 장치와 하위 장치 간의 HDC 인증 키를 설정하는 기능이 추가되었습니다.

프린트

  • 프린트 서비스 시작 이벤트를 구독하거나 구독 취소하는 기능이 추가되었습니다.

잠금 화면

  • 잠금 화면 비밀번호 재설정 복구 키를 획득하기 위해 팝업으로 잠금 화면 비밀번호를 확인하는 기능이 추가되었습니다.

Enterprise Threat Protection Kit (새로운 Kit)

  • Enterprise Threat Protection Kit(기업 위협 방지 서비스)는 파일 접근 및 처리에 중점을 둔 보안 방지 애플리케이션 구축을 위한 핵심 기능을 제공합니다. 애플리케이션은 파일을 스캔하여 잠재적 위협을 식별하고, 위협 파일에 대해 격리, 복구 또는 삭제 작업을 수행하여 기업 장치의 데이터 보안을 효과적으로 보호할 수 있습니다.

FAST Kit

  • 동시 해시 테이블이 추가되었습니다.
  • 일부 벡터 연산 및 복소수 처리 기능이 추가되었습니다.
  • 2차 IIR 필터 기능이 추가되었습니다.

카드

  • onUpdateForm 콜백에 카드 업데이트 원인 필드 지원이 추가되었습니다.

이미지

  • WebP 이미지 메타데이터 클래스가 추가되어 이미지의 메타데이터를 저장합니다.

입력 이벤트

  • C API 입력 이벤트가 강화되어 입력 이벤트의 압력, 창 좌측 상단에 대한 XY 상대 좌표 등의 이벤트를 제공합니다.

실시간 창

  • 실시간 창 카드 보조 영역 클릭을 통한 실시간 창 종료 지원이 추가되었습니다.
  • 실시간 창의 최대 수명 시간 매개변수 설정이 추가되어, 시스템이 미리 설정된 시간에 도달하면 자동으로 실시간 창을 종료합니다.

검색

  • 키워드 검색 시나리오에서 쿼리 결과에 관련성 점수 표시 지원이 추가되었습니다.

총평

HarmonyOS 6.1.1 (24) Beta1은 개발자 기능을 대폭 강화하여, Ability Kit, ArkUI, ArkTS, ArkWeb 등 핵심 프레임워크의 성능과 유연성을 향상시켰습니다. 특히 새로운 Content Embed Kit과 Enterprise Threat Protection Kit은 애플리케이션 간 협업 및 기업 보안 기능을 확장하며, DevEco Studio의 개선 사항은 개발 효율성을 크게 높일 것으로 기대됩니다. 전반적으로 이번 업데이트는 HarmonyOS 생태계의 개발자 경험과 플랫폼 역량을 한층 더 끌어올리는 데 중점을 두었습니다.

개요

Huawei 개발자 공식 웹사이트에 따르면 HarmonyOS 6.1.1 (24) Beta1 버전이 출시되었으며, 6.1.0 (23) 버전을 기반으로 개발 기능이 더욱 강화되었습니다.

주요 기능 강화

  • Ability Kit: AbilityStage 컨텍스트 기능이 강화되어 동적 리소스 로딩을 지원합니다.
  • ArkUI: 평행 시야 상태 획득, 사용자 정의 컴포넌트의 Ability 간 마이그레이션, 동적 레이아웃 컨테이너 등의 기능이 강화되었으며, 여러 컴포넌트의 C API가 추가되었습니다.
  • ArkTS: 가상 머신 측정 및 모니터링 기능이 강화되었고, taskpool 작업 시간 초과 설정을 지원합니다.
  • ArkWeb: 다운로드 작업 콜백 기능이 강화되었고, URL 화이트리스트 및 보안 제어 인터페이스가 추가되었습니다.
  • Camera Kit: 지연 미리보기 출력 및 자동 프레이밍(影随人动) 기능이 추가되었습니다.
  • Audio Kit: MIDI C API가 추가되어 외부 장치 연결을 지원합니다.
  • FAST Kit: 동시 해시 테이블, 벡터 연산 및 필터 기능이 추가되었습니다.
  • Performance Analysis Kit: 리소스 수집 및 크래시 로그 분석 기능이 강화되었습니다.
  • 새로운 Kit: Content Embed Kit(콘텐츠 임베딩 서비스) 및 Enterprise Threat Protection Kit(기업 위협 방지 서비스) 등이 추가되었습니다.

DevEco Studio의 기능도 더욱 강화되었습니다.

  • API 24 프로젝트 개발을 지원합니다.

총평

HarmonyOS 6.1.1 (24) Beta1은 개발자 기능을 대폭 강화하여, Ability Kit, ArkUI, ArkTS, ArkWeb 등 핵심 프레임워크의 성능과 유연성을 향상시켰습니다. 특히 새로운 Content Embed Kit과 Enterprise Threat Protection Kit은 애플리케이션 간 협업 및 기업 보안 기능을 확장하며, DevEco Studio의 개선 사항은 개발 효율성을 크게 높일 것으로 기대됩니다. 전반적으로 이번 업데이트는 HarmonyOS 생태계의 개발자 경험과 플랫폼 역량을 한층 더 끌어올리는 데 중점을 두었습니다.

개요

Huawei 개발자 공식 웹사이트에 따르면 HarmonyOS 6.1.1 (24) Beta1 버전이 출시되었으며, 6.1.0 (23) 버전을 기반으로 개발 기능이 더욱 강화되었습니다.

주요 기능 강화

  • Ability Kit: AbilityStage 컨텍스트 기능이 강화되어 동적 리소스 로딩을 지원합니다.
  • ArkUI: 평행 시야 상태 획득, 사용자 정의 컴포넌트의 Ability 간 마이그레이션, 동적 레이아웃 컨테이너 등의 기능이 강화되었으며, 여러 컴포넌트의 C API가 추가되었습니다.
  • ArkTS: 가상 머신 측정 및 모니터링 기능이 강화되었고, taskpool 작업 시간 초과 설정을 지원합니다.

총평

HarmonyOS 6.1.1 (24) Beta1은 개발자 기능을 대폭 강화하여, Ability Kit, ArkUI, ArkTS, ArkWeb 등 핵심 프레임워크의 성능과 유연성을 향상시켰습니다. 특히 새로운 Content Embed Kit과 Enterprise Threat Protection Kit은 애플리케이션 간 협업 및 기업 보안 기능을 확장하며, DevEco Studio의 개선 사항은 개발 효율성을 크게 높일 것으로 기대됩니다. 전반적으로 이번 업데이트는 HarmonyOS 생태계의 개발자 경험과 플랫폼 역량을 한층 더 끌어올리는 데 중점을 두었습니다.

개요

Huawei 개발자 공식 웹사이트에 따르면 HarmonyOS 6.1.1 (24) Beta1 버전이 출시되었으며, 6.1.0 (23) 버전을 기반으로 개발 기능이 더욱 강화되었습니다.

주요 기능 강화

  • Ability Kit: AbilityStage 컨텍스트 기능이 강화되어 동적 리소스 로딩을 지원합니다.
  • ArkUI: 평행 시야 상태 획득, 사용자 정의 컴포넌트의 Ability 간 마이그레이션, 동적 레이아웃 컨테이너 등의 기능이 강화되었으며, 여러 컴포넌트의 C API가 추가되었습니다.
  • ArkTS: 가상 머신 측정 및 모니터링 기능이 강화되었고, taskpool 작업 시간 초과 설정을 지원합니다.
  • ArkWeb: 다운로드 작업 콜백 기능이 강화되었고, URL 화이트리스트 및 보안 제어 인터페이스가 추가되었습니다.
  • Camera Kit: 지연 미리보기 출력 및 자동 프레이밍(影随人动) 기능이 추가되었습니다.
  • Audio Kit: MIDI C API가 추가되어 외부 장치 연결을 지원합니다.
  • FAST Kit: 동시 해시 테이블, 벡터 연산 및 필터 기능이 추가되었습니다.
  • Performance Analysis Kit: 리소스 수집 및 크래시 로그 분석 기능이 강화되었습니다.
  • 새로운 Kit: Content Embed Kit(콘텐츠 임베딩 서비스) 및 Enterprise Threat Protection Kit(기업 위협 방지 서비스) 등이 추가되었습니다.

DevEco Studio 개선 사항

DevEco Studio의 기능도 더욱 강화되었습니다.

  • API 24 프로젝트 개발을 지원합니다.
  • Hot Reload 기능이 강화되어 C++ 코드 및 리소스 파일 수정이 가능합니다.
  • Binder 통신 정보, 메인 스레드 작업 큐, 샘플링 스택 데이터 등 더 많은 AppFreeze 로그를 분석하여 개발자의 문제 해결 효율성을 높입니다.
  • ComMemory 템플릿이 새로 추가되어 UI 인터페이스의 각 컴포넌트 메모리 할당 상황을 분석하고 UI 컴포넌트 메모리 누수 문제를 해결하는 데 도움을 줍니다.

  • 백그라운드 재생 모드 설정 지원이 추가되어, 애플리케이션이 시스템에 백그라운드 재생 지원 여부를 알릴 수 있으며, 시스템은 기능에 따라 실시간 캡슐 표시를 결정합니다.

카메라

  • 지연 미리보기 출력 객체를 생성하는 기능이 추가되어, 스트림 구성 시 일반 미리보기 출력 객체 대신 데이터 스트림에 추가됩니다. 동시에 지연 미리보기의 Surface 설정도 지원합니다.
  • 카메라 컨트롤러에 자동 프레이밍(AUTO_FRAMING) 기능이 제공되어, 수동으로 화면을 조정할 필요 없이 하위 레이어에서 자동 자르기 및 확대/축소를 통해 인물 피사체가 항상 화면 중앙에 있도록 보장합니다.

Wi-Fi

Bluetooth

Content Embed Kit (새로운 Kit)

메뉴

  • 단일 2차 메뉴 항목 내용 업데이트 지원이 추가되었습니다.
  • 메뉴 항목의 기본 표시 아이콘 및 선택 시 표시되는 아이콘을 설정하는 기능이 추가되었습니다.

보안

  • 디지털 쉴드 서비스가 Tablet, PC/2in1 장치를 지원합니다.
  • 새로운 시스템 보안 관련 이벤트가 추가되었습니다: 프로세스 권한 상승 이벤트, 프로세스 비정상 디버깅 이벤트, 시스템 디렉토리 비정상 마운트 이벤트, 프로세스 비정상 크래시 이벤트, 애플리케이션 코드 미서명 이벤트, 애플리케이션 코드 서명 검증 비정상 이벤트, 드라이버 코드 서명 검증 비정상 이벤트, 드라이버 불법 커널 메모리 매핑 이벤트, 커널 메모리 비정상 사용 이벤트.

HDC

  • 상위 장치와 하위 장치 간의 HDC 인증 키를 설정하는 기능이 추가되었습니다.

프린트

잠금 화면

  • 잠금 화면 비밀번호 재설정 복구 키를 획득하기 위해 팝업으로 잠금 화면 비밀번호를 확인하는 기능이 추가되었습니다.

Enterprise Threat Protection Kit (새로운 Kit)
