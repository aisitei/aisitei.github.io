청신 반도체, 국내 최초 144채널 PCIe Gen5 스위치 교환 칩 공개

2026-05-01

발표 내용

IT之家에 따르면, Qingxin Semiconductor가 국내 최초의 144채널 PCIe Gen5 Switch 스위치 칩인 WL-G5144를 오늘 발표했습니다.

이 칩은 다음과 같은 주요 사양을 갖추고 있습니다:

  • 원시 대역폭: 9.2Tb/s
  • 종단 간 직통 지연 시간: 99ns

주요 스펙 및 유연성

IT之家에 따르면, 이 칩은 다양한 채널 사양으로 분할 구성이 가능하며, 다음과 같은 옵션을 지원합니다:

  • 분할 가능한 채널 사양: 104 / 96 / 80 / 72 / 48 / 32 채널

또한 유연한 포트 구성을 지원하여, 각 포트는 다음 폭으로 설정할 수 있습니다:

  • 포트 구성 폭: ×1 / ×2 / ×4 / ×8 / ×16 채널

총평

Qingxin Semiconductor가 발표한 WL-G5144는 국내 최초로 144채널 PCIe Gen5 Switch 스위치 칩이라는 점에서 주목받습니다. 이 칩은 9.2Tb/s의 높은 원시 대역폭과 낮은 지연 시간을 제공하며, 다양한 채널 및 포트 폭을 지원하는 뛰어난 유연성을 자랑합니다.

产品发布

青芯半导体正式发布了国内首款 144 通道 PCIe Gen5 Switch 交换芯片 WL-G5144。

核心技术参数

  • 原始带宽：支持 9.2Tb/s
  • 延迟表现：端到端直通延迟为 99ns
  • 通道切分：可向下切分为 104 / 96 / 80 / 72 / 48 / 32 通道规格
  • 端口配置：支持灵活的端口配置，每个端口可配置为 ×1 / ×2 / ×4 / ×8 / ×16 通道宽度

总结

青芯半导体推出的 WL-G5144 是国内首款 144 通道 PCIe Gen5 Switch 交换芯片。该产品具备高带宽、低延迟的性能优势，并支持高度灵活的通道切分与端口配置方案。

発表内容

IT之家の報道によると、Qingxin Semiconductorは本日、国内初の144チャネルPCIe Gen5 Switchスイッチチップ「WL-G5144」を発表しました。

このチップは以下の主要な仕様を備えています：

  • 生帯域幅（Raw Bandwidth）：9.2Tb/s
  • エンドツーエンド遅延：99ns

主なスペックと柔軟性

IT之家によると、このチップは多様なチャネル仕様での分割構成が可能で、以下のオプションをサポートしています：

  • 分割可能なチャネル数：104 / 96 / 80 / 72 / 48 / 32 チャネル

また、柔軟なポート構成をサポートしており、各ポートは以下の幅に設定可能です：

  • ポート構成の幅：x1 / x2 / x4 / x8 / x16 チャネル

総評

Qingxin Semiconductorが発表したWL-G5144は、国内初の144チャネルPCIe Gen5 Switchチップとして注目を集めています。このチップは9.2Tb/sの高い生帯域幅と低い遅延を実現するとともに、多様なチャネルおよびポート幅をサポートする優れた柔軟性を備えています。

まとめ

Qingxin Semiconductorは、国内初の144チャネルPCIe Gen5 Switchチップ「WL-G5144」を発表しました。このチップは9.2Tb/sの広帯域と低遅延を実現し、多様な構成オプションによって高い柔軟性を提供します。

Product Announcement

According to IT Home, Qingxin Semiconductor has announced the WL-G5144, the first domestically produced 144-channel PCIe Gen5 Switch chip.

The chip features the following key specifications:

  • Raw Bandwidth: 9.2Tb/s
  • End-to-end Latency: 99ns

Key Specifications and Flexibility

According to IT Home, the chip can be configured with various channel specifications, supporting the following options:

  • Divisible Channel Options: 104 / 96 / 80 / 72 / 48 / 32 channels

Furthermore, it supports flexible port configurations where each port can be set to the following widths:

  • Port Configuration Widths: x1 / x2 / x4 / x8 / x16 lanes

Summary

Qingxin Semiconductor's WL-G5144 is notable as the first domestic 144-channel PCIe Gen5 Switch chip. It provides high performance with a 9.2Tb/s raw bandwidth and low latency, while offering significant versatility through customizable channel and port configurations.
