Samsung, One UI 8.5 시스템 업데이트 배포 시작

IT Home에 따르면, 중국 내수용 Samsung Galaxy S24 시리즈 스마트폰을 대상으로 오늘부터 One UI 8.5 시스템 업데이트가 순차적으로 배포되기 시작했습니다.

업데이트 상세 정보

  • 버전 번호: S9280ZCU5DZDP / S9280CHC5DZDP / S9280ZCU5DZDP
  • 용량: 약 4GB
  • 보안 패치 레벨: 2026년 2월 5일

주요 업데이트 내용 및 특징

이번 One UI 8.5 시스템 업데이트는 새롭게 개선된 인터페이스 디자인과 더욱 깊이 통합된 Galaxy AI 등 다양한 신규 기능을 제공합니다. 구체적인 기능 내용은 이미 배포된 Galaxy S25 시리즈의 기능을 참고할 수 있습니다.

One UI 8.5 우선 적용 기기 목록

Samsung은 다음 장치들에 One UI 8.5 업데이트를 우선적으로 제공할 예정입니다:

  • Galaxy S25, S25+, S25 Ultra, S25 Edge, S25 FE
  • Galaxy Z Fold 7, Flip 7, Flip 7 FE
  • Galaxy Z TriFold
  • Galaxy S24, S24+, S24 Ultra, S24 FE
  • Galaxy Z Fold 6, Flip 6
  • Galaxy Tab S11, Tab S11 Ultra
  • Galaxy Tab S10+, Tab S10 Ultra

초기 업데이트를 받은 모든 기기는 시스템 성능 최적화, 시각적 개선은 물론 Galaxy S26 시리즈와 함께 출시되는 새로운 Galaxy AI 기능 세트를 포함한 완전한 One UI 8.5 경험을 누릴 수 있습니다. 다만 일부 구형 모델의 경우 특정 기능을 놓칠 수는 있으나, 핵심적인 사용자 경험에는 영향을 미치지 않을 것으로 예상됩니다.

총평

이번 One UI 8.5 업데이트는 Galaxy AI 기능의 심화 통합과 전반적인 시스템 최적화를 목표로 합니다. 특히 S25 시리즈와 폴더블 기기군을 중심으로 우선 배포되며, 사용자들은 새로운 인터페이스 디자인과 향상된 성능 개선점을 체감할 수 있을 것으로 보입니다.

系统更新概况

国行Samsung Galaxy S24系列手机已开始推送One UI 8.5系统更新。此次更新旨在提供全新的界面设计、更深层次的Galaxy AI整合以及性能优化，其核心功能参考了Galaxy S25系列的相关特性。

版本信息与规格

  • 版本号：S9280ZCU5DZDP / S9280CHC5DZDP / S9280ZCU5DZDP
  • 更新大小：约 4GB
  • 安全补丁级别：2026 年 2 月 5 日

支持设备列表

Samsung将优先为以下机型提供One UI 8.5更新：

  • Galaxy S25、S25+、S25 Ultra、S25 Edge、S25 FE
  • Galaxy Z Fold 7、Flip 7、Flip 7 FE
  • Galaxy Z TriFold
  • Galaxy S24、S24+、S24 Ultra、S24 FE
  • Galaxy Z Fold 6、Flip 6
  • Galaxy Tab S11、Tab S11 Ultra
  • Galaxy Tab S10+、Tab S10 Ultra

功能体验说明

首批更新的设备将获得完整的One UI 8.5体验，包含系统性能改进、视觉优化以及与Galaxy S26系列同步推出的全新Galaxy AI功能套件。虽然部分较旧的机型可能会错过某些特定功能，但核心用户体验不受影响。

总结

Samsung开始为S24等系列设备推送One UI 8.5系统更新，带来全新的视觉设计和深度集成的Galaxy AI功能。首批支持的机型将获得完整的性能优化与新功能套件，确保核心用户体验的一致性。
