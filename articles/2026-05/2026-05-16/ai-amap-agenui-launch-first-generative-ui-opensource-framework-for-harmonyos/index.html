Huawei HarmonyOS용 AGenUI 프레임워크 공개

Gaode가 "Huawei HarmonyOS 시스템 최초의 생성형 UI 오픈소스 프레임워크"인 AGenUI를 출시했다고 발표했습니다. 이 프레임워크는 AI 애플리케이션 개발 진입 장벽을 크게 낮추고, 다양한 기기에서의 인터페이스 적응 문제를 간소화하는 것을 목표로 합니다.

현재 이 프레임워크는 개발자 및 학계에 전면적으로 오픈소스 공개되었으며, 관련 GitHub 주소가 제공되었습니다.

기술 개요 및 작동 방식

AGenUI 프레임워크는 Google A2UI 프로토콜을 기반으로 하며 C++를 핵심 언어로 사용합니다. 이 기술은 AI 대규모 모델(LLM)이 생성한 인터페이스 의도를 HarmonyOS 네이티브 컴포넌트 렌더링으로 직접 변환할 수 있게 합니다.

이를 통해 단일 범용 인터페이스 프로토콜만으로 HarmonyOS 스마트폰, 태블릿, 차량용 디스플레이, 스마트 스크린, 웨어러블 기기 등 다양한 최종 장치에 끊김 없이 적응(Seamless Adaptation)하는 것이 가능합니다.

HarmonyOS 통합 및 성능 우위

Gaode는 AGenUI가 HarmonyOS 1+8+N 전 시나리오 분산 아키텍처에 깊이 맞춰져 있어, 개발자가 각기 다른 장치별로 개별적인 적응 및 디버깅 작업을 할 필요가 없다고 설명했습니다.

  • 시스템 통합성: 프레임워크는 HarmonyOS 시스템 레벨의 렌더링, 애니메이션, 분산 핵심 기능에 직접 연결되어 중간 계층 손실이 없습니다.
  • 생태계 협력: Xiaoyi 및 HarmonyOS 의도 프레임워크와 자연스럽게 협력하여 생성형 UI를 HarmonyOS 생태계의 시스템 레벨 표준 능력으로 끌어올립니다.

성능 측면에서, HarmonyOS 버전 AGenUI는 iOS나 Android 대응 버전에 비해 렌더링 성능이 20% 향상되었고 메모리 사용량은 18% 감소했습니다.

  • 사용자 경험: 다중 장치 인터페이스의 표현과 상호작용 경험이 매우 높은 수준으로 통일되어, HarmonyOS 분산 멀티 디바이스 협업의 핵심 강점을 최대한 발휘합니다.
  • 개발 효율성: 기존 UI 개발 방식은 확정적인 페이지 디자인에 초점을 맞추어 에이전트 구동형 동적 작업 상호작용 처리에 취약했습니다. AGenUI는 템플릿 대신 프로토콜을 사용하여 개발 효율성, AI 친화도, 개인화, 요구사항 커버리지 등 여러 면에서 우수한 성능을 보여줍니다.

총평

AGenUI는 HarmonyOS 생태계에 생성형 UI라는 새로운 표준 능력을 제시하며, AI 기반 애플리케이션 개발의 패러다임을 변화시킬 잠재력을 지니고 있습니다. 이 프레임워크는 단일 프로토콜로 다양한 장치 환경에서의 높은 호환성과 최적화된 성능을 동시에 구현하여, 개발자들에게 강력한 도구를 제공할 것으로 기대됩니다.

高德发布 AGenUI 开源框架

高德宣布推出“Huawei鸿蒙HarmonyOS系统首个生成式 UI 开源框架”AGenUI。该框架旨在降低 AI 应用的开发门槛，解决多设备界面适配繁琐的问题。目前，该项目已在 GitHub 上面向开发者和学术界全面开源。

技术架构与核心能力

AGenUI 基于谷歌 A2UI 协议，以 C++ 为核心，能够将 AI 大模型生成的界面意图直接转化为鸿蒙原生组件渲染。通过一套通用界面协议，可实现多终端的无缝适配：

  • 支持设备：涵盖鸿蒙手机、平板、车机、智慧屏、穿戴等多种终端。
  • 系统深度融合：适配鸿蒙 1+8+N 全场景分布式架构，直连系统级渲染、动效及分布式核心能力。
  • 生态协同：与小艺、鸿蒙意图框架天然协同，推动生成式 UI 成为系统的标准能力。

性能表现与技术优势

相较于 iOS 和 Android 端对应的版本，鸿蒙版 AGenUI 在性能和交互体验上具有显著优势：

  • 渲染性能提升 20%。
  • 内存占用降低 18%。
  • 技术路径采用“协议替代模板”，在处理 Agent 驱动的动态任务时，比传统 UI 开发更具 AI 友好度、开发效率更高且支持更多个性化需求。

总结

高德推出的 AGenUI 是首个面向 HarmonyOS 的生成式 UI 开源框架，旨在通过统一协议简化多设备适配并降低 AI 应用的开发门槛。该框架在性能上优于移动端竞品，并通过“协议替代模板”的技术路径显著提升了 Agent 驱动任务的交互体验。

Huawei HarmonyOS向けAGenUIフレームワーク公開

Gaodeが、HarmonyOSシステムにおける初の生成型UIオープンソースフレームワークである「AGenUI」をリリースしたと発表しました。このフレームワークは、AIアプリケーション開発の参入障壁を大幅に下げ、多様なデバイス間でのインターフェース適応の問題を簡素化することを目的としています。

現在、このフレームワークは開発者および学術機関向けに全面的にオープンソース公開されており、関連するGitHubリポジトリも提供されています。

技術概要および動作原理

AGenUIフレームワークはGoogleのA2UIプロトコルをベースとしており、C++をコア言語として採用しています。この技術により、大規模言語モデル（LLM）が生成したインターフェースの意図を、HarmonyOSネイティブコンポーネントのレンダリングへと直接変換することが可能になります。

これにより、単一の汎用インターフェースプロトコルのみで、HarmonyOSスマートフォン、タブレット、車載ディスプレイ、スマートスクリーン、ウェアラブルデバイスなど、多様な最終デバイスへのシームレスな適応（Seamless Adaptation）を実現します。

HarmonyOS統合と性能の優位性

Gaodeは、AGenUIがHarmonyOSの「1+8+N」全シナリオ分散アーキテクチャに深く適合しているため、開発者がデバイスごとに個別の適応やデバッグ作業を行う必要がないと説明しています。

  • システム統合性： フレームワークはHarmonyOSシステムのレンダリング、アニメーション、分散コア機能に直接接続されており、中間層での損失が発生しません。
  • エコシステム協力： XiaoyiおよびHarmonyOSの意図（Intent）フレームワークと自然に連携し、生成型UIをHarmonyOSエコシステムのシステムレベルの標準能力へと引き上げます。

パフォーマンス面において、HarmonyOS版AGenUIはiOSやAndroid対応バージョンと比較してレンダリング性能が20%向上し、メモリ使用量は18%削減されました。

  • ユーザー体験： マルチデバイスのインターフェース表現とインタラクション体験が一貫しており、HarmonyOSの分散マルチデバイス連携の強みを最大限に引き出します。
  • 開発効率： 従来のUI開発手法は固定されたページデザインに焦点を当てていたため、エージェント駆動型の動的な作業インタラクションへの対応が困難でした。AGenUIはテンプレートの代わりにプロトコルを使用することで、開発効率、AI親和性、パーソナライズ、要件カバー率など、複数の面で優れた性能を発揮します。

総評

AGenUIはHarmonyOSエコシステムに「生成型UI」という新たな標準能力を提示し、AIベースのアプリケーション開発のパラダイムを変革する可能性を秘めています。このフレームワークは、単一のプロトコルで多様なデバイス環境における高い互換性と最適化された性能を同時に実現し、開発者に対して強力なツールを提供することが期待されます。

まとめ

Gaodeが発表したAGenUIは、HarmonyOS向けに設計された初の生成型UIオープンソースフレームワークです。LLMの意図をネイティブコンポーネントへ直接変換するプロトコルを採用することで、多様なデバイスへのシームレスな適応と高いパフォーマンスを実現します。これにより、開発者は個別のデバイス調整を省きつつ、高度なAI体験を統合的に提供することが可能になります。

Release of AGenUI Framework for Huawei HarmonyOS

Gaode has announced the release of "AGenUI," the first open-source generative UI framework for the HarmonyOS system. This framework aims to significantly lower the barrier to entry for AI application development and simplify the challenges of adapting interfaces across a wide range of devices.

The framework is now fully open-sourced for developers and academia, with the corresponding GitHub repository provided for access.

Technical Overview and Operation

The AGenUI framework is based on the Google A2UI protocol and utilizes C++ as its core language. This technology allows interface intentions generated by Large Language Models (LLM) to be directly converted into HarmonyOS native component renderings.

By utilizing a single universal interface protocol, it enables "Seamless Adaptation" across various end-devices, including HarmonyOS smartphones, tablets, automotive displays, smart screens, and wearable devices.

HarmonyOS Integration and Performance Advantages

Gaode stated that AGenUI is deeply aligned with the HarmonyOS 1+8+N distributed architecture, meaning developers do not need to perform individual adaptation or debugging for different types of hardware.

  • System Integration: The framework connects directly to system-level rendering, animation, and distributed core functions without any loss in intermediate layers.
  • Ecosystem Collaboration: It integrates naturally with Xiaoyi and the HarmonyOS intent framework, elevating generative UI to a standard system-level capability within the HarmonyOS ecosystem.

In terms of performance, the HarmonyOS version of AGenUI shows a 20% improvement in rendering performance and an 18% reduction in memory usage compared to its iOS or Android counterparts.

  • User Experience: The presentation and interaction experience across multi-device interfaces are highly unified, maximizing the core strengths of HarmonyOS's distributed multi-device collaboration.
  • Development Efficiency: Traditional UI development focuses on fixed page designs, which often struggle to handle dynamic interactions driven by agents. AGenUI utilizes protocols instead of templates, demonstrating superior performance in terms of development efficiency, AI compatibility, personalization, and requirement coverage.

Conclusion

AGenUI introduces a new standard capability for generative UI within the HarmonyOS ecosystem and holds the potential to shift the paradigm of AI-based application development. By achieving high compatibility across various device environments while providing optimized performance through a single protocol, this framework provides developers with a powerful toolset.

Summary

Gaode has released AGenUI, an open-source generative UI framework for HarmonyOS that utilizes the Google A2UI protocol to simplify multi-device adaptation. The framework offers superior rendering and memory efficiency compared to other platforms while replacing traditional static templates with a protocol-based approach to enhance AI integration.
