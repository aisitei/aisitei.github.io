Adobe, 데스크톱 버전 Photoshop 27.7 출시: 제거 도구에 온디바이스 AI 지원, Apple Mac은 24GB 메모리 필요

2026-05-22

주요 업데이트: 제거 도구의 온디바이스 AI 지원

Adobe는 Photoshop 27.7 업데이트를 통해 제거 도구(Remove Tool)에 온디바이스 AI 모델 지원을 추가했습니다. 이는 네트워크 의존도를 줄이고 이미지 데이터 업로드로 인한 개인 정보 보호 문제를 완화하기 위함입니다.

  • 다운로드 후 로컬에서 편집 처리 가능
  • 모델을 언제든지 다운로드, 취소 또는 제거하여 클라우드 처리와 온디바이스 처리 간 전환 가능
  • 다운로드 전 하드웨어 호환성 자동 확인
  • 클라우드 처리와 온디바이스 처리 간 전환 가능

Adobe의 공식 답변에 따르면, Mac 플랫폼에서는 다음 사양을 충족해야 합니다.

  • macOS 13.0 이상
  • Apple M1/M2/M3 칩 또는 Intel 칩(AVX2 명령어 세트 지원)
  • 8GB RAM(16GB 권장)
  • 20GB의 여유 저장 공간

위 요구 사항을 충족하지 못하는 Mac 장치의 경우, Photoshop의 Device 모드는 비활성화되며 사용자는 클라우드 기반 제거 도구만 계속 사용할 수 있습니다.

Photoshop 데스크톱 버전과 Firefly 아이디어보드 통합

  • 공유 패널 및 내보내기 메뉴를 통해 모든 Photoshop 문서를 Firefly 아이디어보드로 직접 공유하여 새 아이디어보드를 만들거나 기존 아이디어보드에 추가할 수 있습니다.
  • Firefly 아이디어보드가 이제 변형 패널에 표시되어 무드보드를 만들고 AI 생성 변형을 비교하는 데 사용할 수 있습니다.
  • 미리 구성된 아이디어보드 레이아웃에서 Firefly 아이디어보드의 Ideate를 사용하여 생성된 이미지 변형을 열어 추가 탐색 및 반복 작업을 수행할 수 있습니다.
  • 새로운 안내식 워크플로우는 무드보드 및 시각적 개념, 브랜드 및 마케팅 자료, 소셜 미디어 콘텐츠를 만드는 데 도움이 됩니다.

고급 생성형 AI 기능 잠금 해제

더 많은 Creative Cloud 구독자에게 고급 생성형 AI 기능에 대한 액세스 권한이 제공됩니다. 자격을 갖춘 사용자는 이제 매월 100개의 생성형 크레딧(기존 25개)을 받아 크리에이티브 AI를 사용하는 구독자 커뮤니티의 역량을 크게 향상시킬 수 있습니다.

편집 작업 공간의 통합 계정 메뉴

새로운 통합 계정 메뉴를 통해 편집 작업 공간에서 Adobe 계정, 구독 세부 정보 및 생성형 크레딧을 직접 보고 관리할 수 있습니다.

최적화된 "웹용으로 저장" 대화 상자

"웹용으로 저장" 대화 상자가 현대적인 인터페이스로 업데이트되어 Photoshop의 다른 부분과 더욱 일관되고 새로워진 경험을 제공합니다.

파일 처리 및 환경 설정

  • 새로운 환경 설정을 통해 사용자는 JPEG 파일을 잠긴 배경 레이어가 아닌 일반 레이어로 열 수 있어 배경 잠금 해제를 자주 하는 사용자의 워크플로우를 간소화합니다.
  • 이제 사용자는 새 문서를 만들 때 기본 배경 레이어를 사용하지 않도록 선택하여 처음부터 투명한 캔버스를 가질 수 있습니다.

성능 및 인프라

  • 내부 측정 모듈이 재구성되어 사용량이 많은 측정값만 처리함으로써 텔레메트리 오버헤드를 줄이고 정상 작동 중 애플리케이션의 응답 속도를 향상시켰습니다.
  • 캔버스 HUD 진단 기능이 캔버스 컨텍스트 영역에서 보기 메뉴로 이동하여 사용자가 더 쉽게 찾고 캔버스 작업을 더욱 간결하고 원활하게 만들 수 있습니다.

고객 보고 수정 사항

  • 속성 패널에서 강조된 색상 사전 설정을 선택할 때 색조/채도 범위가 업데이트되지 않습니다.
  • Windows에서 너무 긴 파일 경로에서 WebP 파일을 열 때 "Photoshop이 이 유형의 파일을 인식할 수 없습니다"라는 오류 메시지가 나타납니다.

기타 주목할 만한 수정 사항

  • [Win] 버전 26.2와 25.12.1을 동시에 시작할 수 없습니다.
  • "JPEG 파일을 배경 레이어 없이 열기" 환경 설정은 이제 기존 사용자의 혼란을 피하기 위해 기본적으로 꺼져 있습니다.
  • 생성형 크레딧 할당량이 소진되었음을 알리는 알림에서 자세히 알아보기 URL이 업데이트되었습니다.

총평

이번 Photoshop 27.7 업데이트는 제거 도구에 온디바이스 AI 모델을 도입하여 개인 정보 보호와 효율성을 높인 것이 가장 큰 특징입니다. 또한 Firefly 아이디어보드와의 통합을 통해 크리에이티브 워크플로우를 개선하고, 더 많은 구독자에게 생성형 AI 크레딧을 확대 제공하여 AI 기반 창작 활동을 장려합니다. 전반적으로 사용자 경험 개선과 성능 최적화에 중점을 둔 업데이트입니다.

AI 功能升级

Photoshop 27.7 更新为移除工具（Remove Tool）引入了端侧 AI 模型支持，旨在减少网络依赖并降低数据上传带来的隐私顾虑。

  • 支持在本地处理编辑，用户可根据需求下载、取消或移除模型。
  • 提供云端与设备端处理的切换功能，并在下载前自动检查硬件兼容性（不符合要求的 Mac 设备将默认使用云端模式）。
  • Photoshop 桌面版与 Firefly 灵感板深度集成，支持通过共享面板和导出菜单快速同步内容。
  • Firefly 灵感板现已整合至变体面板中，并提供新的引导式工作流以辅助创建营销资源及社交媒体内容。

用户权益与账户管理

  • 扩大了高级版生成式 AI 功能的访问权限：符合条件的 Creative Cloud 订阅者每月可获得的生成式积分从 25 个大幅增加至 100 个。
  • 新增统一账户菜单，允许用户在编辑工作区直接查看并管理 Adobe 帐户、订阅详情及生成式积分。

界面与工作流优化

  • “存储为 Web 所用格式”对话框更新为现代化的 UI 设计，提供更一致的交互体验。
  • 在预先配置的灵感板布局中，支持通过 Firefly 灵感板中的 Ideate 功能进行图像变体的探索与迭代。

文件处理与首选项

  • 新增首选项允许用户将 JPEG 文件作为常规图层而非锁定背景打开。
  • 提供在创建新文档时选择不使用默认背景图层的选项，支持从透明画布开始创作。

性能优化与系统修复

本次更新对底层架构进行了重构以提升软件响应速度。

  • 重构内部度量模块，减少遥测开销并提高应用程序的运行响应。
  • 将画布 HUD 诊断功能移至视图菜单，使操作更加简洁流畅。
  • 修复了 Windows 系统下长路径 WebP 文件无法识别的问题。
  • 修复了属性面板颜色预设不更新、版本冲突等多个已知问题。

总结

Adobe 发布的 Photoshop 27.7 更新重点强化了 AI 能力，包括移除工具的端侧模型支持和 Firefly 的深度集成。此外，本次更新还大幅增加了订阅者的生成式积分，并对 UI、文件处理逻辑及系统底层性能进行了全面优化。

主要なアップデート：削除ツールへのオンデバイスAI対応

AdobeはPhotoshop 27.7のアップデートにより、削除ツール（Remove Tool）にオンデバイスAIモデルのサポートを追加しました。これによりネットワークへの依存を減らし、画像データのアップロードに伴うプライバシーの問題を緩和します。

  • ダウンロード後にローカルで編集処理が可能
  • モデルをいつでもダウンロード、キャンセル、または削除でき、クラウド処理とオンデバイス処理の間で切り替えが可能
  • ダウンロード前にハードウェアの互換性を自動確認
  • クラウド処理とオンデバイス処理のシームレスな切り替え

Adobeの公式回答によると、Macプラットフォームでは以下の仕様を満たす必要があります。

  • macOS 13.0 以上
  • Apple M1/M2/M3 チップ、またはIntelチップ（AVX2命令セットをサポート）
  • 8GB RAM（16GB推奨）
  • 20GBの空きストレージ

上記の要件を満たさないMacデバイスの場合、PhotoshopのDeviceモードが無効になり、ユーザーはクラウドベースの削除ツールのみを使用することになります。

Photoshopデスクトップ版とFireflyアイディアボードの統合

  • 共有パネルやエクスポートメニューを通じて、すべてのPhotoshopドキュメントをFireflyアイディアボードに直接共有し、新しいアイディアボードを作成したり既存のものに追加したりできます。
  • Fireflyアイディアボードがバリアントパネルに表示されるようになり、ムードボードの作成やAI生成されたバリアントの比較に使用できます。
  • あらかじめ構成されたアイディアボードレイアウトから、FireflyアイディアボードのIdeate機能を使用して生成された画像バリアントを開き、さらなる探索や反復作業を行うことができます。
  • 新しいガイド付きワークフローにより、ムードボードや視覚的概念、ブランド・マーケティング資料、ソーシャルメディアコンテンツの作成を支援します。

高度な生成AI機能の解放

より多くのCreative Cloudサブスクライバーに、高度な生成AI機能へのアクセス権が付与されます。対象となるユーザーは、毎月の生成クレジットが従来の25から100へと大幅に増加し、クリエイティブなAI活用能力を向上させることができます。

編集ワークスペース内の統合アカウントメニュー

新しい統合アカウントメニューにより、編集ワークスペースからAdobeアカウント、サブスクリプションの詳細、および生成クレジットを直接確認・管理できるようになります。

最適化された「Web用に保存」ダイアログ

「Web用に保存」ダイアログがモダンなインターフェースに更新され、Photoshopの他の部分と一貫性のある、より洗練された体験を提供します。

ファイル処理および環境設定

  • 新しい環境設定により、JPEGファイルをロックされた背景レイヤーではなく通常のレイヤーとして開くことができるようになり、バックグラウンドのロック解除を頻繁に行うユーザーのワークフローが簡略化されます。
  • 新しくドキュメントを作成する際にデフォルトの背景レイヤーを使用しないことを選択でき、最初から透明なキャンバスを用意することが可能です。

パフォーマンスとインフラ

  • 内部測定モジュールを再構成し、頻繁に使用されるメトリクスのみを処理することでテレメトリのオーバーヘッドを削減し、動作中のアプリケーションの応答速度を向上させました。
  • キャンバスHUD診断機能が「表示」メニューに移動し、ユーザーがより簡単に見つけられるようになり、キャンバス作業をよりスムーズにします。

顧客報告に基づく修正

  • プロパティパネルで強調されたカラープリセットを選択した際に色相/彩度の範囲が更新されない問題の修正。
  • Windowsにおいて非常に長いファイルパスにあるWebPファイルを開く際に「Photoshopはこのタイプのファイルを認識できません」というエラーメッセージが表示される問題の修正。

その他の注目すべき修正

  • [Win] バージョン26.2と25.12.1を同時に起動できない問題の解決。
  • 「JPEGファイルを背景レイヤーなしで開く」環境設定は、既存ユーザーの混乱を避けるためデフォルトでオフに。
  • 生成クリエイティブクレジットの割り当て不足を通知する際の詳細情報URLを更新。

まとめ

今回のPhotoshop 27.7アップデートでは、削除ツールへのオンデバイスAI導入によるプライバシー保護と効率性の向上が大きな特徴です。また、Fireflyアイディアボードとの統合や生成クリエイティブクレジットの増量により、ユーザーの創造的なワークフローが強化されます。全体として、パフォーマンスの最適化とユーザー体験の向上に重点を置いたアップデートとなっています。

On-Device AI Support for Remove Tool

Adobe has introduced on-device AI model support for the Remove Tool in the Photoshop 27.7 update. This initiative aims to reduce reliance on network connectivity and mitigate privacy concerns associated with uploading image data to the cloud.

  • Processing can be performed locally after downloading the model.
  • Users can download, cancel, or remove models at any time to switch between cloud and on-device processing.
  • The system automatically checks hardware compatibility before a download begins.
  • Seamless switching between cloud and on-device processing is supported.

According to Adobe's official documentation, the following specifications are required for Mac platforms:

  • macOS 13.0 or later
  • Apple M1/M2/M3 chips or Intel chips (supporting AVX2 instruction set)
  • 8GB RAM (16GB recommended)
  • 20GB of available storage space

For Mac devices that do not meet these requirements, the "Device" mode in Photoshop will be disabled, and users will continue to have access only to the cloud-based Remove Tool.

Photoshop Desktop Version and Firefly Idea Board Integration

  • Users can now share any Photoshop document directly to a Firefly Idea Board via the Share panel or Export menu to create new boards or add to existing ones.
  • Firefly Idea Boards are now displayed in the Variants panel, allowing users to create mood boards and compare AI-generated variations.
  • By using Ideate within pre-configured Idea Board layouts, users can open generated image variations for further exploration and iteration.
  • New guided workflows assist in creating mood boards, visual concepts, branding/marketing materials, and social media content.

Unlocking Advanced Generative AI Features

More Creative Cloud subscribers will now have access to advanced generative AI features. Eligible users will receive 100 generative credits per month (up from the previous 25), significantly expanding the capabilities of the community using creative AI.

Unified Account Menu in Edit Workspace

A new unified account menu allows users to view and manage their Adobe account, subscription details, and generative credits directly within the Edit workspace.

Optimized "Save for Web" Dialog

The "Save for Web" dialog has been updated with a modern interface, providing a more consistent and refreshed experience aligned with other parts of Photoshop.

File Handling and Preferences

  • New settings allow users to open JPEG files as standard layers rather than locked background layers, streamlining the workflow for those who frequently unlock backgrounds.
  • When creating new documents, users can now choose not to use a default background layer, allowing them to start with a transparent canvas from the beginning.

Performance and Infrastructure

  • Internal measurement modules have been restructured to process only high-usage metrics, reducing telemetry overhead and improving application responsiveness during normal operation.
  • The Canvas HUD diagnostic feature has been moved to the View menu within the Canvas Context area, making it easier to find while creating a cleaner and smoother canvas experience.

Customer Reported Fixes

  • Fixed an issue where Hue/Saturation ranges did not update when selecting highlighted color presets in the Properties panel.
  • Resolved an error on Windows where "Photoshop cannot recognize this type of file" appeared when opening WebP files with excessively long file paths.

Other Notable Fixes

  • [Win] Fixed an issue where versions 26.2 and 25.12.1 could not be launched simultaneously.
  • The "Open JPEG files without a background layer" setting is now off by default to avoid confusion for existing users.
  • The "Learn More" URL in notifications regarding exhausted generative credit allocations has been updated.

Summary

The Photoshop 27.7 update introduces on-device AI for the Remove Tool, enhancing both privacy and performance by reducing cloud dependency. It also features deeper integration with Firefly Idea Boards, an increase in monthly generative credits for subscribers, and various performance optimizations to improve the overall user experience.
