Photoshop 27.7 주요 업데이트: 온디바이스 AI 도입

Adobe는 지난 5월 20일 Photoshop 27.7 버전을 출시하며, '제거 도구(Remove Tool)'에 장치 기반 AI 모델을 지원하는 기능을 추가했습니다. 이 업데이트의 핵심은 클라우드 처리 의존도를 낮추고, 이미지 데이터 업로드로 인한 사용자 프라이버시 우려를 줄이는 데 있습니다.

장치 기반 제거 도구(On-Device Remove Tool) 기능

Photoshop은 이제 기기 자체의 AI 모델을 활용하여 클라우드 처리 없이도 객체를 제거할 수 있는 기능을 제공합니다. 사용자는 다음과 같은 이점을 누릴 수 있습니다.

  • 다운로드 후 로컬 환경에서 편집 및 처리가 가능합니다.
  • 필요에 따라 언제든지 모델 다운로드, 취소 또는 제거가 가능하여 클라우드 처리와 장치 기반 처리를 자유롭게 전환할 수 있습니다.
  • 모델을 다운로드하기 전에 하드웨어 호환성을 자동으로 확인해 줍니다.

[참고] Mac 플랫폼 요구 사항:

  • Adobe의 공식 권장 사양에 따르면, 특정 성능 기준을 충족하지 못하는 Mac 장치에서는 Photoshop 내 'Device 모드'가 비활성화되어 사용자가 클라우드 버전의 제거 도구만 사용할 수 있습니다.

크리에이티브 워크플로우 및 Firefly 통합 강화

이번 업데이트는 Adobe의 창작 생태계 전반에 걸쳐 Firefly 기능을 깊숙이 통합하여 사용자 경험을 향상시켰습니다.

  • Photoshop 데스크톱과 Firefly 영감 보드(Inspiration Board) 연동: 공유 패널 및 내보내기 메뉴를 통해 어떤 Photoshop 문서든 Firefly 영감 보드로 직접 공유하거나 기존 보드에 추가할 수 있습니다.
  • 영감 보드의 활용성 증대: Firefly 영감 보드가 변형 패널(Variations Panel)에 표시되어, 사용자가 무드보드를 만들거나 AI가 생성한 다양한 변이들을 비교하는 데 사용할 수 있게 되었습니다.
  • 아이디어 구상 워크플로우 제공: 미리 설정된 영감 보드 레이아웃에서 Firefly의 'Ideate' 기능을 사용하여 생성된 이미지 변이를 열고, 이를 바탕으로 추가적인 탐색과 반복 작업을 수행할 수 있습니다. 이 새로운 가이드형 워크플로는 무드보드, 비주얼 콘셉트, 브랜드/마케팅 자료 및 소셜 미디어 콘텐츠 제작에 도움을 줍니다.

생성형 AI 기능 접근성 및 계정 관리 개선

사용자들에게 더 많은 생성형 AI 기능을 제공하고 작업 환경의 편의성을 높였습니다.

  • 고급 생성형 AI 기능 잠금 해제: 더 많은 Creative Cloud 구독자가 고급 생성형 AI 기능에 접근할 수 있게 되었습니다. 자격이 되는 사용자는 이제 매월 100개의 생성형 크레딧(기존 25개)을 제공받게 되어, 구독자들이 창의적인 AI를 활용하는 능력이 대폭 향상되었습니다.
  • 통합 계정 메뉴: 새로운 통합 계정 메뉴를 통해 편집 작업 공간에서 Adobe 계정 정보, 구독 상세 내역, 생성형 크레딧 현황 등을 한 곳에서 확인하고 관리할 수 있습니다.

사용자 경험 및 성능 최적화

작업 효율성을 높이는 다양한 인터페이스 개선과 안정성 패치가 적용되었습니다.

  • '웹용으로 저장' 대화 상자 개편: 이 기능이 현대적인 UI로 업데이트되어 Photoshop의 다른 부분들과 더욱 일관되고 세련된 경험을 제공합니다.
  • 파일 처리 및 기본 설정 개선: 새로운 환경설정 덕분에 JPEG 파일을 잠긴 배경 레이어가 아닌 일반 레이어로 열 수 있게 되어, 배경 잠금 해제를 자주 하는 사용자들의 작업 흐름이 간소화되었습니다. 또한, 새 문서를 만들 때 기본 배경 레이어 사용 여부를 선택할 수 있어 처음부터 투명한 캔버스를 가질 수 있습니다.
  • 성능 및 아키텍처 최적화: 내부 측정 모듈을 재구성하여 높은 사용률의 측정 항목만 처리하도록 함으로써 원격 측정(Telemetry) 부하를 줄이고, 애플리케이션의 전반적인 응답 속도를 향상시켰습니다.
  • 사용자 보고 오류 수정: 속성 패널에서 강조 색상을 선택할 때 색조/채도 범위가 업데이트되지 않던 문제와, Windows 환경에서 긴 파일 경로로 WebP 파일을 열 때 발생하던 'Photoshop이 이 유형의 파일을 인식할 수 없습니다'라는 오류 메시지가 수정되었습니다.

총평

이번 Photoshop 27.7 업데이트는 클라우드 의존도를 낮춘 온디바이스 AI 기능을 전면에 내세우며 사용자 프라이버시와 접근성을 크게 개선했습니다. 또한, Firefly 영감 보드를 중심으로 크리에이티브 워크플로우를 통합하고 생성형 AI 크레딧을 대폭 늘려, 사용자가 보다 풍부한 기능과 효율적인 환경에서 창작 활동에 집중할 수 있도록 지원하는 것이 가장 큰 특징입니다.

移除工具支持端侧 AI 模型

Photoshop 27.7 更新为“移除工具”（Remove Tool）引入了端侧 AI 模型支持。此项功能旨在减少对网络连接的依赖，并降低因上传图像到云端而产生的隐私顾虑。

  • 用户可以在本地处理编辑，无需经过云端处理。
  • 支持在云处理与设备端处理之间切换，并可随时下载、取消或移除模型。
  • 系统会自动检测硬件兼容性；对于不符合要求的 Mac 设备，相关功能将置灰并默认使用云端版本。

Firefly 深度集成

本次更新加强了 Photoshop 与 Firefly 灵感板的协同能力：

  • 支持通过共享面板和导出菜单将文档直接分享到 Firefly 灵感板。
  • 在变体面板中显示 Firefly 灵感板，方便用户对比 AI 生成的不同变体。
  • 提供新的引导式工作流，协助用户创建情绪板、品牌营销资源及社交媒体内容。

生成式 AI 功能与账户管理

Adobe 提升了部分订阅者的创作权限并优化了管理界面：

  • 符合条件的 Creative Cloud 订阅者每月可获得的生成式积分从 25 个增加到 100 个。
  • 新增统一账户菜单，用户可在编辑工作区直接查看和管理 Adobe 账户、订阅详情及生成式积分。

界面优化与性能提升

更新还包含一系列针对易用性和系统性能的改进：

  • “存储为 Web 所用格式”对话框采用现代化界面，提供更一致的体验。
  • 支持将 JPEG 文件作为常规图层而非锁定背景打开，并允许在创建新文档时选择透明画布。
  • 重构内部度量模块以减少遥测开耗，提升应用响应速度。
  • 修复了包括 Windows 长路径 WebP 文件识别、色相/饱和度预设更新等多个已知问题。

总结

Adobe 发布的 Photoshop 27.7 更新重点在于引入端侧 AI 模型以增强“移除工具”的隐私性和离线能力，并显著增加了订阅者的生成式 AI 月份积分。此外，版本还深化了与 Firefly 的集成，并对界面交互、文件处理逻辑及系统底层性能进行了全面优化。

Photoshop 27.7 Major Update: On-Device AI Integration

Adobe released Photoshop version 27.7 on May 20, introducing support for device-based AI models within the "Remove Tool." The core objective of this update is to reduce reliance on cloud processing and mitigate user privacy concerns regarding the uploading of image data.

On-Device Remove Tool Features

Photoshop now utilizes local AI models to remove objects without requiring cloud processing. Users can benefit from the following features:

  • Editing and processing can be performed in a local environment after downloading the model.
  • Users can freely switch between cloud and device-based processing by downloading, canceling, or removing models as needed.
  • The system automatically checks hardware compatibility before a user downloads a model.

[Note] Mac Platform Requirements:

  • According to Adobe's official specifications, "Device Mode" within Photoshop will be disabled on Mac devices that do not meet specific performance standards, meaning those users can only use the cloud-based version of the Remove Tool.

Enhanced Creative Workflow and Firefly Integration

This update enhances the user experience by deeply integrating Firefly features across Adobe's creative ecosystem.

  • Photoshop Desktop and Firefly Inspiration Board Sync: Users can directly share any Photoshop document to a Firefly Inspiration Board or add it to an existing board via the Share Panel and Export menu.
  • Increased Utility of Inspiration Boards: Firefly Inspiration Boards are now displayed in the Variations Panel, allowing users to create mood boards or compare various AI-generated variations.
  • Ideation Workflow: Using the "Ideate" feature within predefined Inspiration Board layouts, users can open generated image variations and perform further exploration and iterations. This guided workflow assists in creating mood boards, visual concepts, marketing materials, and social media content.

Improved Generative AI Accessibility and Account Management

Adobe has expanded access to generative AI features while improving the convenience of the workspace.

  • Unlocking Advanced Generative AI Features: More Creative Cloud subscribers can now access advanced generative AI features. Eligible users will receive 100 generative credits per month (up from the previous 25), significantly expanding their ability to utilize creative AI tools.
  • Unified Account Menu: A new integrated account menu allows users to check and manage Adobe account information, subscription details, and generative credit status in one location within the workspace.

User Experience and Performance Optimization

Various interface improvements and stability patches have been implemented to increase work efficiency.

  • "Save for Web" Dialog Overhaul: This feature has been updated with a modern UI, providing a more consistent and polished experience aligned with other parts of Photoshop.
  • File Processing and Default Settings Improvements: New settings allow JPEG files to open as standard layers rather than locked background layers, streamlining the workflow for users who frequently unlock backgrounds. Additionally, when creating new documents, users can now choose whether to use a default background layer, allowing for transparent canvases from the start.
  • Performance and Architecture Optimization: The internal telemetry module was restructured to process only high-usage metrics, reducing telemetry overhead and improving overall application responsiveness.
  • Bug Fixes: Issues were resolved where hue/saturation ranges did not update when selecting highlight colors in the Properties panel, as well as a "Photoshop could not recognize this type of file" error message that occurred when opening WebP files with long paths on Windows.

Summary

The Photoshop 27.7 update focuses on enhancing privacy and accessibility by introducing on-device AI for the Remove Tool, reducing the need for cloud processing. It also strengthens the creative workflow through deeper Firefly integration and significantly increases monthly generative credits for subscribers. Additionally, the update includes various UI refinements and performance optimizations to improve overall user experience.

移除工具支持端侧 AI 模型

Photoshop 27.7 更新为“移除工具”（Remove Tool）新增了端侧 AI 模型支持。此项功能旨在减少对网络的依赖，并降低因上传图像到云端而产生的隐私顾虑。

  • 用户可以在本地处理编辑，或在云处理与设备端处理之间自由切换。
  • 系统会自动检查硬件兼容性，不符合要求的 Mac 设备将无法使用 Device 模式。
  • 支持随时下载、取消或移除本地模型。

Firefly 灵感板深度集成

Photoshop 桌面版与 Firefly 灵感板的整合更加紧密，旨在优化创意探索流程：

  • 通过共享面板和导出菜单，可将任何 Photoshop 文档直接分享到 Firefly 灵感板。
  • 在变体面板中显示灵感板，方便用户对比不同 AI 生成的变体。
  • 提供新的引导式工作流，用于创建情绪板、品牌营销资源及社交媒体内容。

生成式 AI 功能与账户管理

Adobe 提升了 Creative Cloud 订阅者的创作能力并优化了管理界面：

  • 符合条件的用户每月可获得 100 个生成式积分（原为 25 个）。
  • 新增统一账户菜单，允许用户在编辑工作区直接查看订阅详情和生成式积分。

性能优化与功能改进

本次更新还包含一系列针对用户体验、界面及系统底层架构的调整：

  • “存储为 Web 所用格式”对话框采用现代化界面，提升一致性。
  • 新增首选项允许将 JPEG 文件作为常规图层打开，并支持在创建新文档时提供透明画布。
  • 重构内部度量模块以减少遥测开销，提高应用响应速度。
  • 修复了 Windows 平台长路径 WebP 文件识别问题及其他已知 Bug。

总结

Adobe 发布的 Photoshop 27.7 更新核心亮点是为“移除工具”引入端侧 AI 模型，旨在提升隐私保护并减少网络依赖。同时，更新显著增加了 Creative Cloud 用户的生成式积分配额，并深化了与 Firefly 的集成以及一系列 UI 和性能优化。
