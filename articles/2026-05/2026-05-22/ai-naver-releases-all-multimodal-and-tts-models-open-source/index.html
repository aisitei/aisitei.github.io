넷이즈 유다오(NetEase Youdao)의 멀티모달 모델 '쯔위에 4(子曰 4)'와 음성 합성 모델 전면 오픈소스화

2026-05-22

오픈소스 발표

NetEase Youdao는 오늘 "자왈(子曰)" 대규모 언어 모델 4.0의 핵심 듀얼 엔진인 "멀티모달 모델"과 "음성 합성(TTS) 모델"을 전 세계에 전면 오픈소스로 공개한다고 발표했습니다. 개발자들은 무료로 다운로드, 배포 및 2차 개발을 할 수 있습니다.

멀티모달 모델

이번에 오픈소스화된 "자왈 4" 멀티모달 모델(27B 파라미터 규모)은 교육 시나리오에 특화되어 있으며, 시각 입력에 대한 수리 능력을 지원하여 업계 최고 수준(SOTA)을 달성했습니다.

  • 동일한 파라미터 규모의 모델 중 차트가 포함된 고난도 시각 수리 문제 처리
  • 순수 텍스트 중국어 수리 문제 정확도 81.4%

또한, 새로운 모델은 정교한 사고 과정 재구성 방식을 채택했습니다. 대규모의 고품질 추론 샘플을 모아 심층적으로 최적화하여 사고 과정 출력 길이를 43.2% 압축했습니다. 이는 동일한 질문에 대해 더 적은 토큰을 출력하고, 추론 경로가 더 짧으며, 답변이 더 빠르다는 것을 의미합니다.

실제 비즈니스를 수행하는 개발자와 기업에게는 추론 비용 절감이라는 직접적인 효과가 있습니다.

또한, NetEase Youdao 팀은 중국 학생들의 실제 숙제, 시험 및 질문 시나리오에 대해 심층적으로 최적화하여 실제 학습에서 발생하는 복잡한 문제점을 해결할 수 있도록 했습니다.

음성 합성(TTS) 모델

오픈소스 음성 합성(TTS) 모델은 다국어 음색 감정 전이 복제를 지원합니다. 중국어 오디오를 업로드하기만 하면 화자의 음색을 복제하여 영어, 한국어, 베트남어 등을 "중국식 억양 없이" 유창하게 말할 수 있습니다. 또한 감정 전이 복제도 정확하게 이루어집니다. 화자가 화난 목소리로 한 문장을 말하면 합성된 외국어도 화난 어조로 나옵니다.

  • 3초: 임의의 오디오 자료를 업로드하면 시스템이 3초 이내에 제로샷 원음 복제를 완료합니다.
  • 97%: 복제 작업에서 정확도가 97%를 초과하며, 복제된 음색과 원음의 유사도는 85% 이상입니다.
  • 14개 언어: 중국어, 영어, 일본어, 한국어, 독일어, 프랑스어, 스페인어, 인도네시아어, 이탈리아어, 태국어, 포르투갈어, 러시아어, 말레이어, 베트남어 등 14개 언어를 전면 지원합니다.

두 모델의 오픈소스 주소는 다음과 같습니다.

  • 멀티모달 모델: https://huggingface.co/netease-youdao/Confucius4
  • TTS 모델: https://github.com/netease-youdao/Confucius4-TTS

총평

NetEase Youdao는 "자왈 4.0" 대규모 언어 모델의 핵심 엔진인 멀티모달 모델과 음성 합성(TTS) 모델을 전 세계에 오픈소스로 공개했습니다. 교육 시나리오에 특화된 멀티모달 모델은 시각 수리 문제 해결에서 업계 최고 수준을 달성했으며, 음성 합성 모델은 다국어 음색 및 감정 전이 복제 기능을 제공하여 실제 학습 및 비즈니스 환경에서 활용될 수 있습니다.

核心开源动态

网易有道宣布将“子曰”大模型 4.0 的核心双引擎——“多模态模型”与“语音合成（TTS）模型”正式面向全球全量开源。开发者可免费下载、部署并进行二次开发。

多模态模型性能

“子曰 4”多模态模型专注于教育场景，在处理复杂视觉数理问题方面达到行业顶尖水平（SOTA）。

  • 参数规模：27B
  • 核心能力：支持视觉输入的数理能力。
  • 准确率：纯文本的中文数理难题准确率达 81.4%。

推理优化与成本

新模型采用了精细化思维链重构方案，通过汇总高质量、精简的推理样本进行深度优化。

  • 性能提升：将思维链输出长度压缩了 43.2%。
  • 实际效果：在提供相同答案的情况下，Token 输出更少、推理路径更短、响应速度更快。
  • 成本优势：显著降低开发者的推理成本。

TTS 音色克隆技术

开源的语音合成（TTS）模型支持跨语种音色情感迁移克隆，能够实现高度还原的原声效果。

  • 处理速度：上传音频素材后，系统可在 3 秒内完成零样本原声复制。
  • 准确度：克隆任务准确度超过 97%，克隆音色与原声相似度达 85% 以上。
  • 情感迁移：支持精准的情感克隆（如愤怒等语气可跨语种保留）。

全球化支持范围

TTS 模型具备强大的多语言能力，能够消除“中式口音”。

  • 支持数量：全面支持 14 种语言。
  • 覆盖语言：包括中、英、日、韩、德、法、西、印尼、意、泰、葡、俄、马来、越南语等。

资源获取渠道

相关模型已在以下平台提供：

  • 多模态模型：https://huggingface.co/netease-youdao/Confucius4
  • TTS 模型：https://github.com/netease-youdao/Confucius4-TTS

总结

网易有道正式开源“子曰”大模型 4.0 的多模态与 TTS 双核心引擎。其中，27B 参数的多模态模型在教育数理领域表现出色且推理成本更低；配套的 TTS 模型则实现了极速、高保真的跨语种情感克隆，支持 14 种主流语言。

オープンソースの公開

NetEase Youdaoは本日、大規模言語モデル「子曰（Zuo Yao）」4.0のコアとなる2つのエンジンである「マルチモーダルモデル」および「音声合成（TTS）モデル」を世界中で全面的にオープンソースとして公開すると発表しました。開発者はこれらのモデルを無料でダウンロード、配布、および二次開発を行うことができます。

マルチモーダルモデル

今回オープンソース化された「子曰4」マルチモーダルモデル（27Bパラメータ規模）は、教育シナリオに特化しており、視覚入力に対する数理能力をサポートすることで業界最高水準（SOTA）を達成しています。

  • 同等のパラメータ規模のモデルの中で、チャートを含む高度な視覚的数理問題の処理が可能
  • 純粋なテキストによる中国語の数理問題において81.4%の正確性を達成

また、新モデルは精緻な思考過程の再構成手法を採用しています。大量の高品質な推論サンプルを収集・最適化することで、思考過程の出力長を43.2%削減しました。これは、同一の質問に対してより少ないトークンを出力し、推論経路が短縮され、回答速度が向上することを意味します。

実際のビジネスを展開する開発者や企業にとっては、推論コストの削減という直接的なメリットがあります。

さらに、NetEase Youdaoチームは中国の学生による実際の宿題、試験、質問シナリオに対して深く最適化を行っており、実際の学習過程で発生する複雑な問題に対応できるように設計されています。

音声合成（TTS）モデル

オープンソースの音声合成（TTS）モデルは、多言語の音色および感情転送の複製をサポートします。中国語のオーディオをアップロードするだけで話者の音色を複製し、英語、韓国語、ベトナム語などを「中国語特有のアクセントなし」で流暢に話すことができます。また、感情の転送も正確に行われます。話者が怒った声で一文を話せば、合成された外国語も怒りのトーンで出力されます。

  • 3秒：任意のオーディオデータをアップロードすると、システムが3秒以内にゼロショットでの元音複製を完了します。
  • 97%：複製作業において正確性が97%を超え、複製された音色と元の音声の類似度は85%以上です。
  • 14言語：中国語、英語、日本語、韓国語、ドイツ語、フランス語、スペイン語、インドネシア語、イタリア語、タイ語、ポルトガル語、ロシア語、マレー語、ベトナム語など、計14の言語を全面的にサポートします。

両モデルのオープンソースURLは以下の通りです。

  • マルチモーダルモデル: https://huggingface.co/netease-youdao/Confiscus4
  • TTSモデル: https://github.com/netease-youdao/Confucius4-TTS

まとめ

NetEase Youdaoは、大規模言語モデル「子曰4.0」の核となるマルチモーダルモデルと音声合成（TTS）モデルをオープンソースとして公開しました。教育に特化したマルチモーダルモデルは高度な視覚的数理問題でSOTAを達成し、TTSモデルは多言語での感情豊かな音色複製を実現しており、教育およびビジネスの両面で高い実用性を備えています。

Open Source Release

NetEase Youdao has announced the global open-source release of its "Zuo Wa" (子曰) Large Language Model 4.0 core dual engines: a "Multimodal Model" and a "Text-to-Speech (TTS) Model." Developers are now free to download, deploy, and perform secondary development on these models.

Multimodal Model

The newly open-sourced "Zuo Wa 4" multimodal model features 27B parameters and is specifically optimized for educational scenarios. It achieves state-of-the-art (SOTA) performance in visual reasoning capabilities.

  • Handles complex visual math problems involving charts among models of the same parameter scale.
  • Achieves an accuracy rate of 81.4% on pure text Chinese mathematics problems.

The new model adopts a sophisticated thinking process reconstruction method. By gathering and deeply optimizing large-scale, high-quality reasoning samples, it has compressed the output length of the reasoning process by 43.2%. This means fewer tokens are used for the same question, resulting in shorter inference paths and faster response times.

For developers and enterprises, this translates directly into reduced inference costs. Furthermore, the NetEase Youdao team optimized the model based on actual homework, exams, and inquiry scenarios from Chinese students to address complex issues encountered in real-world learning environments.

Text-to-Speech (TTS) Model

The open-source TTS model supports multi-language timbre emotion transfer cloning. By uploading a piece of Chinese audio, the system can clone the speaker's voice and produce fluent speech in English, Korean, Vietnamese, and other languages without any "Chinese accent." It also accurately replicates emotional nuances; for example, if a speaker speaks with an angry tone, the synthesized foreign language will reflect that same anger.

  • 3 seconds: The system completes zero-shot original voice cloning within 3 seconds of uploading any audio data.
  • 97%: Cloning accuracy exceeds 97%, with over 85% similarity between the cloned voice and the original.
  • 14 languages: Fully supports 14 languages, including Chinese, English, Japanese, Korean, German, French, Spanish, Indonesian, Italian, Thai, Portuguese, Russian, Malay, and Vietnamese.

The open-source links for both models are as follows:

  • Multimodal Model: https://huggingface.co/netease-youdao/Confucius4
  • TTS Model: https://github.com/netease-youdao/Confucius4-TTS

Summary

NetEase Youdao has open-sourced the multimodal and TTS engines of its "Zuo Wa 4.0" model to support education and business applications. The multimodal model provides SOTA performance in visual reasoning with optimized inference costs, while the TTS model offers high-accuracy, multi-language voice cloning with emotional preservation.
