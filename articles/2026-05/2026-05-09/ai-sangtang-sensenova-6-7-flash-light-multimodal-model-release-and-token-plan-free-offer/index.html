새로운 모델 발표: SenseNova 6.7 Flash-Lite 출시

IT之家에 따르면, SenseNova는 차세대 경량화된 멀티모달 지능형 에이전트 모델인 SenseNova 6.7 Flash-Lite를 공개했습니다.

동시에 SenseNova Token Plan을 한시적으로 무료로 오픈하며, 전반적인 업무 기능인 SenseNova-Skills도 GitHub에서 오픈소스로 배포되었습니다.

핵심 기능 및 작동 원리

SenseNova 6.7 Flash-Lite는 '실제 세계의 작업 흐름(real-world workflow)'에 최적화되어 개발되었으며, 네이티브 멀티모달 아키텍처를 채택했습니다.

이는 인간처럼 복잡한 웹 페이지 레이아웃, 문서 구조, 재무 차트 등을 직접 '이해'할 수 있게 하여, '보는 것(看)', '생각하는 것(想)', '실행하는 것(做)'을 통합적으로 구현합니다. 이를 통해 데이터 분석, 심층 조사, PPT 생성 등 장기적이고 복잡한 작업의 성공률을 대폭 향상시킬 수 있습니다.

기술적 개선 및 효율성

이번 모델은 비전-텍스트 변환 중간 계층(visual-to-text intermediate layer)을 제거하여, 더 작은 파라미터 크기로도 에이전트 능력을 혁신적으로 끌어올렸습니다. 그 결과, 권위 있는 에이전트 벤치마크 테스트에서 동급 최고 수준(SOTA)의 여러 성과를 달성했습니다.

또한 추론 과정에서의 Token 소모량을 크게 줄였습니다. 정보 검색 같은 시나리오에서는 순수 텍스트 기반 에이전트에 비해 토큰 사용량이 무려 60% 감소했으며, 밀리초(ms) 단위의 피드백 속도를 구현하여 높은 빈도의 상호작용이 필요한 생산 환경 요구사항에 더욱 부합합니다.

개발자 접근성 및 서비스 제공

SenseNova는 SenseNova Token Plan을 공식 출시하고, 이를 한시적으로 무료로 사용할 수 있는 이벤트를 시작했습니다. 개발자는 첫 달 동안 5시간마다 1,500회의 호출 할당량을 별도의 진입 장벽 없이 이용할 수 있으며, 추후 Lite, Pro 등 더 다양한 요금제가 추가될 예정입니다.

더불어 SenseNova는 핵심 모델 능력을 SenseNova-Skills로 패키징하여 GitHub에 오픈소스로 공개했습니다. 개발자들은 다음과 같은 링크를 통해 접근할 수 있습니다.

  • SenseNova Skills 오픈소스 링크: https://github.com/OpenSenseNova/SenseNova-Skills/
  • SenseNova 6.7 Flash-Lite 기술 상세 정보: https://github.com/OpenSenseNova/SenseNova6.7

총평

새롭게 출시된 SenseNova 6.7 Flash-Lite는 멀티모달 아키텍처를 기반으로 복잡한 실제 업무 환경에 특화된 에이전트 모델입니다. 비전 처리와 추론 과정의 효율성을 극대화하여, 기존 대비 현저히 낮은 토큰 소모량과 빠른 응답 속도를 자랑합니다. 개발자들에게는 SenseNova-Skills 오픈소스를 제공하며 접근성을 높여, AI 기반 업무 자동화 시장에 큰 기여를 할 것으로 기대됩니다.

新模型发布

SenseTime 推出了新一代轻量化多模态智能体模型 SenseNova 6.7 Flash-Lite。该模型采用原生多模态架构，旨在处理“真实世界工作流”，能够直接识别复杂的网页布局、文档结构与财务图表，实现“看、想、做”一体化，提升数据分析、深度调研及 PPT 生成等长链路任务的成功率。

核心技术优势

  • 架构优化： 取消了视觉转文本中间层，在更小的参数量下实现了智能体能力的跨越式提升。
  • 性能领先： 在权威智能体基准测试中取得同级别多项 SOTA。
  • 成本降低： 在信息搜索等场景中，Token 消耗较纯文本智能体直降 60%。
  • 高频响应： 支持毫秒级反馈，符合生产环境的高频互动需求。

服务与开源计划

SenseTime 同步推出了 SenseNova Token Plan 并开启限时免费活动。开发者在首月可享受每 5 小时刷新 1500 次调用额度的无门槛配额，未来将推出 Lite、Pro 等更多档位。

此外，SenseNova 系列模型的核心能力已封装为 SenseNova-Skills 并在 GitHub 开源。

总结

SenseTime 推出的 SenseNova 6.7 Flash-Lite 通过原生多模态架构显著降低了 Token 消耗并提升了处理复杂任务的效率。同时，官方通过推出限时免费的 Token Plan 以及开源 SenseNova-Skills 系列工具，旨在为开发者提供更高效的智能体开发支持。

新モデルの発表：SenseNova 6.7 Flash-Lite をリリース

IT之家の報道によると、SenseNovaは次世代の軽量マルチモーダル・インテリジェント・エージェントモデル「SenseNova 6.7 Flash-Lite」を発表しました。

同時に、SenseNova Token Planを期間限定で無料公開するとともに、主要な業務機能であるSenseNova-SkillsもGitHubにてオープンソースとして配布されました。

コア機能と動作原理

SenseNova 6.7 Flash-Liteは「現実世界のワークフロー（real-world workflow）」に最適化して開発されており、ネイティブなマルチモーダル・アーキテクチャを採用しています。

これにより、人間のように複雑なウェブページのレイアウト、文書構造、財務チャートなどを直接「理解」することが可能になり、「見る」「考える」「実行する」を統合的に実現します。これによって、データ分析、詳細な調査、PPT作成など、長期的で複雑なタスクの成功率を大幅に向上させることができます。

技術的な改善と効率性

このモデルはビジョンからテキストへの変換中間層（visual-to-text intermediate layer）を排除することで、より小さなパラメータサイズでありながらエージェント能力を飛躍的に向上させました。その結果、権威あるエージェントのベンチマークテストにおいて、同クラス最高水準（SOTA）の成果を複数達成しています。

また、推論過程におけるトークン消費量も大幅に削減されました。情報検索などのシナリオでは、純粋なテキストベースのエージェントと比較してトークン使用量が60%減少し、ミリ秒（ms）単位のフィードバック速度を実現したことで、高頻度のインタラクションを必要とする生産環境の要求により適合しています。

開発者へのアクセシビリティとサービス提供

SenseNovaはSenseNova Token Planを正式にリリースし、期間限定で無料で使用できるイベントを開始しました。開発者は最初の1ヶ月間、特別な参入障壁なしで5時間ごとに1,500回のコール割り当てを利用でき、今後LiteやProなど、より多様な料金プランが追加される予定です。

さらに、SenseNovaは主要なモデル能力をSenseNova-Skillsとしてパッケージ化し、GitHubにオープンソースとして公開しました。開発者は以下のリンクからアクセス可能です。

  • SenseNova Skills オープンソースリンク: https://github.com/OpenSenseNova/SenseNova-Skills/
  • SenseNova 6.7 Flash-Lite 技術詳細情報: https://github.com/OpenSenseNova/SenseNova6.7

まとめ

SenseNova 6.7 Flash-Liteは、ネイティブなマルチモーダル・アーキテクチャにより複雑な実務ワークフローに最適化されたエージェントモデルです。ビジョン処理と推論の効率化によって低消費トークンと高速レスポンスを実現しており、オープンソースの提供を通じて開発者へのアクセシビリティを高めています。

New Model Release: SenseNova 6.7 Flash-Lite Launched

According to IT House, SenseNova has unveiled the SenseNova 6.7 Flash-Lite, a next-generation lightweight multimodal intelligent agent model.

Simultaneously, the SenseNova Token Plan is being offered for free for a limited time, and "SenseNova-Skills," which covers general work functions, has been released as open source on GitHub.

Core Features and Operation

SenseNova 6.7 Flash-Lite was developed to be optimized for "real-world workflows" and utilizes a native multimodal architecture.

This allows the model to directly "understand" complex web page layouts, document structures, and financial charts, integrating the processes of "seeing," "thinking," and "doing." This integration significantly improves success rates for long-term and complex tasks such as data analysis, in-depth research, and PPT generation.

Technical Improvements and Efficiency

By removing the vision-to-text intermediate layer, this model has drastically improved agent capabilities even with a smaller parameter size. As a result, it achieved several State-of-the-Art (SOTA) results in authoritative agent benchmark tests.

Furthermore, the model significantly reduces token consumption during the inference process. In scenarios such as information retrieval, token usage is reduced by 60% compared to pure text-based agents. It also achieves millisecond (ms) feedback speeds, meeting the requirements of production environments that demand high-frequency interaction.

Developer Accessibility and Services

SenseNova has officially launched the SenseNova Token Plan and initiated a limited-time free trial event. During the first month, developers can access an allocation of 1,500 calls every five hours without any entry barriers; various plans such as Lite and Pro will be added in the future.

Additionally, SenseNova packaged its core model capabilities into "SenseNova-Skills" and released them as open source on GitHub. Developers can access these via the following links:

  • SenseNova Skills Open Source Link: https://github.com/OpenSenseNova/SenseNova-Skills/
  • SenseNova 6.7 Flash-Lite Technical Details: https://github.com/OpenSenseNova/SenseNova6.7

Summary

SenseNova has launched the SenseNova 6.7 Flash-Lite, a multimodal agent model optimized for complex real-world workflows and high efficiency. By removing intermediate layers, it achieves SOTA performance with significantly lower token consumption and faster response times. The release includes open-source tools and a trial period to support developers in building AI-driven automation.
