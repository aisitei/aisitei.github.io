소비자용 웹캠 네트워크 보안 식별 기준 마련

IT之家에 따르면, 국가인터넷정보판공실(国家互联网信息办公室), 공업정보화부(工信部), 공안부 등이 공동으로 발표한 《네트워크 보안 식별 관리 방안》에 따라, 국가인터넷정보판공실이 《소비자용 연결 카메라 네트워크 보안 식별 시행 규칙》 및 관련 표준을 연구하여 초안을 작성했으며, 현재 사회에 의견 수렴을 위해 공개했습니다.

의견 제출 방법 및 기한

일반 대중은 다음 경로와 방식으로 피드백 의견을 제출할 수 있습니다:

  • 이메일: wajscy@cac.gov.cn
  • 우편: 의견서를 베이징시 하이뎬구 푸청로 15번지에 위치한 국가인터넷정보판공실 네트워크 보안 조정국으로 발송하며, 우표 봉투에 "시행 규칙 의견 수렴"이라고 명시해야 합니다. (우편번호 100048)

의견 제출 마감일은 2026년 5월 23일입니다.

규정 적용 범위 및 식별 표지 정보

IT之家가 입수한 '의견 수렴 초안'에 따르면, 이 문서는 소비자용 연결 카메라의 네트워크 보안 식별(표지) 등록 및 사용에 관한 내용을 다룹니다. 여기서 말하는 소비자용 연결 카메라는 소비자가 개인 또는 조직이 구매하여 사용하며, 개인이나 조직에게 음성/영상 정보 수집 및 처리 서비스를 제공하고 인터넷 연결 기능이 있는 독립적인 카메라를 의미합니다. 공공 안전 분야의 카메라는 이 규정의 적용 대상에서 제외됩니다.

네트워크 보안 식별 표지는 파란색 배경의 컬러 표지이며, 길이는 46.9mm, 너비는 50mm입니다. 이 표지는 비율에 맞춰 확대 또는 축소할 수 있으나, 패턴, 문자 및 등록 정보 코드가 명확하게 구별될 수 있도록 보장해야 합니다.

필수 포함 내용

소비자용 연결 카메라 네트워크 보안 식별에는 다음 내용이 반드시 포함되어야 합니다:

  • 제품 생산자 이름
  • 제품 사양 및 모델명
  • 네트워크 보안 능력 등급
  • 네트워크 보안 식별 유효 기간
  • 검사 실험실 이름
  • 근거가 된 국가 표준 또는 기술 문서 번호
  • 등록 정보 코드 (이 코드를 스캔하면 검사 보고서, 주요 지표, 제품 생산자 적합성 선언 등의 정보를 얻을 수 있습니다.)

총평

이번 규정은 소비자용 웹캠에 대한 네트워크 보안 기준을 명확히 하고 시장 투명성을 높이는 데 목적이 있습니다. 소비자들이 구매하는 연결 카메라 제품들이 필수적인 보안 식별 표지를 갖추도록 의무화함으로써, 사용자의 개인 정보 보호와 신뢰도를 강화할 것으로 기대됩니다.

国家互联网信息办公室、工业和信息化部、公安部联合印发《网络安全标识管理办法》，并针对《消费类网联摄像头网络安全标识实施规则》及相关标准公开征求社会意见。

公众可通过以下方式提交反馈：

  • 电子邮件：wajscy@cac.gov.cn
  • 信函地址：北京市海淀区阜成路 15 号国家互联网信息办公室网络安全协调局（邮编 100048），并在信封上注明“实施规则征求意见”。

反馈截止时间为 2026 年 5 月 23 日。

适用范围与定义

该文件适用于消费类网联摄像头的网络安全标识备案和使用。其中，消费类网联摄像头指消费者个人或组织购买、用于提供音视频信息采集和处理服务且具备互联网联网功能的独立摄像头。明确规定不适用于公共安全领域的摄像头。

网络安全标识规格

网络安全标识为蓝色背景的彩色标识，具体尺寸要求如下：

  • 长度：46.9mm
  • 宽度：50mm
  • 支持按比例放大或缩小，但必须保证图案、文字及备案信息码清晰可辨。

标识包含内容

消费类网联摄像头网络安全标识需包含以下核心要素：

  • 产品生产者名称
  • 产品规格型号
  • 网络安全能力等级
  • 网络安全标识有效期
  • 检测实验室名称
  • 依据的国家标准或技术文件编号
  • 备案信息码（扫码可获取检测报告、关键指标、产品生产者符合性声明等）

总结

相关部门正就消费类网联摄像头的网络安全标识实施规则征求意见，旨在规范个人及组织使用的联网摄像头。该标识包含详细的生产商信息、安全等级及扫码查验功能，反馈截止日期为 2026 年 5 月 23 日。

消費者向けウェブカメラのネットワークセキュリティ識別基準の策定

IT之家の報道によると、国家インターネット情報弁公室（CAC）、工業情報化部、公安部などが共同で発表した「ネットワークセキュリティ識別管理方策」に基づき、国家インターネット情報弁公室が「消費者用接続カメラのネットワークセキュリティ識別施行規則」および関連標準の草案を作成し、現在、社会的な意見を収集するために公開しています。

意見提出の方法および期限

一般の公衆は、以下の経路および方法でフィードバック意見を提出することができます。

  • メール：wajscy@cac.gov.cn
  • 郵送：意見書を北京市海淀区府清路15号の国家インターネット情報弁公室ネットワークセキュリティ調整局へ送付。封筒には「施行規則意見収集」と明記する必要があります。（郵便番号 100048）

意見提出の締め切りは2026年5月23日です。

規定の適用範囲および識別ラベルの情報

IT之家が入手した「意見収集草案」によると、この文書は消費者用接続カメラのネットワークセキュリティ識別（ラベル）の登録および使用に関する内容を扱っています。ここでいう「消費者用接続カメラ」とは、個人または組織が購入して使用し、個人や組織に対して音声・映像情報の収集および処理サービスを提供し、インターネット接続機能を持つ独立したカメラを指します。なお、公共安全分野のカメラはこの規定の適用対象から除外されます。

ネットワークセキュリティ識別ラベルは、青色の背景のカラーラベルで、サイズは長さ46.9mm、幅50mmです。このラベルは比率を維持したまま拡大または縮小が可能ですが、パターン、文字、および登録情報コードが明確に判別できることを保証しなければなりません。

必須項目

消費者用接続カメラのネットワークセキュリティ識別には、以下の内容が含まれている必要があります。

  • 製品製造者名
  • 製品仕様およびモデル名
  • ネットワークセキュリティ能力等級
  • ネットワークセキュリティ識別の有効期間
  • 検査試験機関の名称
  • 根拠となる国家標準または技術文書番号
  • 登録情報コード（このコードをスキャンすることで、検査報告書、主要指標、製品製造者の適合宣言などの情報を取得できます。）

まとめ

今回の規制は、消費者向けウェブカメラに関するネットワークセキュリティ基準を明確にし、市場の透明性を高めることを目的としています。接続カメラに必須のセキュリティ識別ラベルを義務付けることで、ユーザーの個人情報保護と製品への信頼性の向上が期待されます。

Establishment of Network Security Identification Standards for Consumer Webcams

According to IT Home, following the "Network Security Identification Management Measures" jointly released by the Cyberspace Administration of China (CAC), the Ministry of Industry and Information Technology (MIIT), and the Ministry of Public Security, the CAC has drafted the "Implementation Rules for Network Security Identification of Consumer Connected Cameras" along with related standards. These documents have been released to the public to gather feedback.

Feedback Methods and Deadlines

The general public can submit feedback through the following channels:

  • Email: wajscy@cac.gov.cn
  • Mail: Send the feedback letter to the Network Security Coordination Office of the Cyberspace Administration of China, located at No. 15 Fuqing Road, Haidian District, Beijing (Postcode: 100048). The envelope should be marked "Feedback on Implementation Rules."

The deadline for submitting comments is May 23, 2026.

Scope of Regulation and Identification Label Information

According to the draft obtained by IT Home, this document covers the registration and use of network security identification labels for consumer connected cameras. "Consumer connected cameras" refer to standalone cameras with internet connectivity purchased by individuals or organizations that provide voice/video information collection and processing services. Cameras used in public safety fields are excluded from these regulations.

The network security identification label is a color label with a blue background, measuring 46.9mm in length and 50mm in width. While the label can be scaled proportionally, it must ensure that patterns, characters, and registration information codes remain clearly distinguishable.

Required Information

The network security identification for consumer connected cameras must include the following details:

  • Manufacturer name
  • Product specifications and model name
  • Network security capability level
  • Validity period of the network security identification
  • Testing laboratory name
  • Reference national standard or technical document number
  • Registration information code (Scanning this code provides access to test reports, key indicators, and manufacturer declarations of conformity)

Summary

The Chinese government has introduced draft regulations establishing mandatory network security identification labels for consumer-grade webcams. These rules aim to increase market transparency and enhance user privacy by requiring clear information regarding manufacturing, safety levels, and testing reports. The initiative is designed to build greater consumer trust in connected camera devices.
