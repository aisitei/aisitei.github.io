📷 카메라

소비자용 네트워크 카메라의 네트워크 보안 식별에 관한 의견 수렴을 공개한 국가사이버정보판공실

2026-05-09

서문

IT之家 5월 8일 소식에 따르면, 국가인터넷정보판공실, 공업정보화부, 공안부가 공동으로 발표한 "네트워크 보안 식별 관리 방법"에 따라, 국가인터넷정보판공실은 "소비자용 네트워크 연결 카메라 네트워크 보안 식별 시행 규칙" 및 관련 표준을 연구하고 초안을 작성하여 현재 사회에 공개 의견을 수렴하고 있습니다. 대중은 다음 경로와 방식으로 의견을 제출할 수 있습니다.

  • 이메일: wajscy@cac.gov.cn
  • 우편: 베이징시 하이뎬구 푸청루 15호 국가인터넷정보판공실 네트워크 보안 조정국, 우편번호 100048. 봉투에 "시행 규칙 의견 수렴"이라고 명시해야 합니다.

의견 제출 마감일은 2026년 5월 23일입니다.

적용 범위

IT之家가 "의견 수렴 초안"에서 확인한 바에 따르면, 이 문서는 소비자용 네트워크 연결 카메라의 네트워크 보안 식별 등록 및 사용에 적용됩니다. 소비자용 네트워크 연결 카메라란 개인 또는 조직이 구매 및 사용하여 개인 또는 조직에 오디오/비디오 정보 수집 및 처리 서비스를 제공하고, 인터넷 연결 기능을 갖춘 독립형 카메라를 의미합니다. 공공 안전 분야의 카메라에는 적용되지 않습니다.

네트워크 보안 식별

네트워크 보안 식별은 파란색 배경의 컬러 식별이며, 길이는 46.9mm, 너비는 50mm입니다. 식별은 비율에 따라 확대 또는 축소할 수 있으며, 패턴, 텍스트 및 등록 정보 코드가 명확하게 식별 가능해야 합니다.

소비자용 네트워크 연결 카메라 네트워크 보안 식별에는 다음 내용이 포함됩니다.

  • 제품 생산자 명칭
  • 제품 사양 모델
  • 네트워크 보안 능력 등급
  • 네트워크 보안 식별 유효 기간
  • 테스트 실험실 명칭
  • 근거가 되는 국가 표준 또는 기술 문서 번호
  • 등록 정보 코드: 스캔을 통해 테스트 보고서, 주요 지표, 제품 생산자의 적합성 선언 등의 정보를 얻을 수 있습니다.

총평

국가인터넷정보판공실은 소비자용 네트워크 연결 카메라의 네트워크 보안 강화를 위해 "네트워크 보안 식별 시행 규칙" 초안을 공개하고 의견을 수렴하고 있습니다. 이 규칙은 카메라의 보안 식별 등록 및 사용에 대한 기준을 제시하며, 제품 생산자 정보, 보안 등급, 유효 기간 등 다양한 정보를 포함하여 소비자의 알 권리를 보장하고 보안 신뢰도를 높이는 데 목적이 있습니다.

政策发布与反馈渠道

国家互联网信息办公室、工业和信息化部、公安部联合印发《网络安全标识管理办法》，并公开征求《消费类网联摄像头网络安全标识实施规则》的意见。

  • 反馈方式：邮件（wajscy@cac.gov.cn）或信函至北京市海淀区阜成路15号。
  • 截止日期：2026年5月23日。

产品定义与适用范围

该规则适用于消费者个人或组织购买、使用，并提供音视频信息采集和处理服务的具有互联网联网功能的独立摄像头（消费类网联摄像头）。

明确规定：不适用于公共安全领域的摄像头。

标识物理规格

网络安全标识设计为蓝色背景的彩色标识。标准尺寸为长度46.9mm，宽度50mm。在按比例缩放时，必须确保图案、文字及备案信息码清晰可辨。

标识内容要求

消费类网联摄像头网络安全标识包含以下核心要素：

  • 产品生产者名称及规格型号
  • 网络安全能力等级及有效期
  • 检测实验室名称
  • 依据的国家标准或技术文件编号
  • 备案信息码（扫码可获取检测报告、关键指标、产品生产者符合性声明等）

总结

相关部门正征求消费类网联摄像头网络安全标识的实施规则，旨在规范此类产品的识别与合规。新规则明确了标识的具体物理尺寸、设计要求以及包含的各项核心信息。

IT之家の5月8日の報道によると、国家インターネット情報弁公室（CAC）、工業情報化部、公安部が共同で発表した「ネットワークセキュリティ識別管理方法」に基づき、国家インターネット情報弁公室は「消費者向けネットワーク接続カメラのネットワークセキュリティ識別実施規則」および関連標準の草案を作成し、現在社会からの意見を募集しています。一般のユーザーは以下の経路および方法で意見を提出することが可能です。

  • メール：wajscy@cac.gov.cn
  • 郵便：北京市海淀区阜成路15号 国家インターネット情報弁公室ネットワークセキュリティ調整局（郵便番号：100048）。封筒には「実施規則意見収集」と明記する必要があります。

意見の提出期限は2026年5月23日です。

適用範囲

IT之家が「意見収集草案」で確認したところ、この文書は消費者向けネットワーク接続カメラのネットワークセキュリティ識別登録および使用に適用されます。ここでいう「消費者向けネットワーク接続カメラ」とは、個人または組織が購入・使用し、オーディオ/ビデオ情報の収集および処理サービスを提供する、インターネット接続機能を備えたスタンドアロン型カメラを指します。なお、公共安全分野で使用されるカメラには適用されません。

ネットワークセキュリティ識別

ネットワークセキュリティ識別は青色の背景を持つカラーラベルであり、サイズは幅50mm、長さ46.9mmです。この識別ラベルは比率に応じて拡大または縮小が可能ですが、パターン、テキスト、および登録情報コードが明確に判別できる必要があります。

消費者向けネットワーク接続カメラのネットワークセキュリティ識別には、以下の内容が含まれます。

  • 製品製造者の名称
  • 製品の仕様モデル
  • ネットワークセキュリティ能力等級
  • ネットワークセキュリティ識別の有効期間
  • 試験機関の名称
  • 根拠となる国家標準または技術文書番号
  • 登録情報コード：スキャンすることで、テストレポート、主要指標、製品製造者の適合性宣言などの情報を取得できます。

総評

国家インターネット情報弁公室は、消費者向けネットワーク接続カメラのセキュリティ強化を目的として「ネットワークセキュリティ識別実施規則」の草案を公開し、意見を募っています。この規則は、カメラのセキュリティ識別の登録と使用に関する基準を提示するものであり、製造者情報、セキュリティ等級、有効期間などの多様な情報を記載することで、消費者の知る権利を保証し、製品の信頼性を高めることを目的としています。

まとめ

中国の国家インターネット情報弁公室（CAC）は、消費者向けネットワーク接続カメラのセキュリティ強化に向けた新たな識別ルールを策定中です。この規則により、製造者やセキュリティ等級などの情報がラベルに明記されるようになり、消費者の安心感と製品の信頼性の向上が図られます。

Introduction

According to a report by IT Home on May 8, following the "Network Security Identification Management Measures" jointly released by the Cyberspace Administration of China (CAC), the Ministry of Industry and Information Technology (MIIT), and the Ministry of Public Security, the CAC is currently researching and drafting the "Implementation Rules for Network Security Identification of Consumer Network-Connected Cameras." The draft is currently open for public comment. Members of the public can submit their feedback through the following channels:

  • Email: wajscy@cac.gov.cn
  • Mail: Network Security Coordination Department, Cyberspace Administration of China, No. 15 Fuqing Road, Haidian District, Beijing, Postcode 100048. The envelope must be marked "Feedback on Implementation Rules."

The deadline for submitting comments is May 23, 2026.

Scope of Application

According to the "Draft for Public Comment" reviewed by IT Home, this document applies to the registration and use of network security identification for consumer network-connected cameras. A consumer network-connected camera refers to a standalone camera with internet connectivity features that provides audio/video information collection and processing services to individuals or organizations. This regulation does not apply to cameras used in public safety fields.

Network Security Identification

The network security identification is a color label on a blue background, measuring 46.9mm in length and 50mm in width. The label may be scaled up or down proportionally as long as the patterns, text, and registration codes remain clearly legible.

The network security identification for consumer network-connected cameras includes the following information:

  • Manufacturer name
  • Product specification model
  • Network security capability rating
  • Validity period of the network security identification
  • Name of the testing laboratory
  • Reference national standard or technical document number
  • Information code: Scannable codes provide access to test reports, key indicators, and manufacturer declarations of conformity.

Summary

The Cyberspace Administration of China is gathering public feedback on draft rules for the network security identification of consumer-grade cameras. These regulations aim to enhance device security by mandating clear labels that include manufacturer details, safety ratings, and expiration dates to ensure transparency and build consumer trust.
