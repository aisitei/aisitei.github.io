상하이 텔레콤, 토큰 요금제 출시: 1위안당 25만 포인트, 휴대폰 요금 결제 지원

2026-05-17

Token 컴퓨팅 서비스 출시

Shanghai Telecom이 오늘 상하이에서 최초로 Token(토큰) 컴퓨팅 서비스를 출시하며, Token 요금제를 발표한 최초의 통신사가 되었습니다.

Token 요금제 세부 정보

  • Token 요금제는 사용량에 따라 구매할 수 있습니다.
  • 1위안으로 25만 포인트를 구매할 수 있으며, Kimi K2.5 대규모 언어 모델을 예로 들면 약 25만 입력 토큰을 호출할 수 있습니다.
  • 필요한 만큼만 구매할 수 있으며, 통신 요금으로 결제가 가능하고, 대량 구매 시 할인 혜택이 제공됩니다.

AI 가정 도우미 및 무료 체험

Shanghai Telecom은 "AI 가정 도우미"를 발표한 후, Shanghai Telecom 휴대폰 번호 사용자에게 2500만 포인트의 무료 체험 기회를 제공한다고 밝혔습니다. 이 무료 체험은 한 달간 유효합니다. 6월부터는 Telecom "Meihao Home" 사용자의 가정용 디지털 공간에 Token 회원 혜택이 추가되어, 통합 요금제에 모든 혜택이 포함될 예정입니다.

API를 통한 대규모 언어 모델 연동

또한, Shanghai Telecom 사용자는 포인트를 구매한 후 표준 API 인터페이스를 통해 30개 이상의 주요 대규모 언어 모델을 호출하여 AI 기능을 자신의 소프트웨어, 스크립트 또는 자동화 프로세스에 통합할 수 있습니다.

Token(토큰)이란?

IT之家의 설명에 따르면, Token(토큰)은 컴퓨터 과학 및 자연어 처리 분야의 기본적이고 중요한 개념으로, 일반적으로 텍스트 데이터가 분할 또는 토큰화 처리된 후의 최소 단위를 의미합니다. 이 단위는 단어, 구두점, 숫자 또는 기타 의미 있는 기호가 될 수 있습니다.

총평

Shanghai Telecom이 상하이 최초로 Token 컴퓨팅 서비스를 출시하며, 사용량 기반의 Token 요금제를 선보였습니다. 이 서비스는 사용자가 필요에 따라 AI 컴퓨팅 자원을 구매하고, 표준 API를 통해 다양한 대규모 언어 모델을 활용할 수 있도록 지원합니다. 또한, AI 가정 도우미와 연계된 무료 체험 및 회원 혜택을 제공하여 AI 서비스의 접근성을 높이고 있습니다.

运营商动向

上海电信正式推出 Token（词元）算力服务，成为上海首个发布此类资费套餐的运营商。

产品计费详情

  • 定价标准：1 元对应 25 万额度点。
  • 参考案例：以 Kimi K2.5 大模型为例，约可支持调用 25 万输入 Tokens。
  • 购买模式：支持按需订购、话费账单支付，并提供多量购买折扣。

用户优惠活动

  • “AI 家庭助手”推广：上海电信手机号用户可获得 2500 万额度点免费体验（有效期一个月）。

未来服务规划

从 6 月起，电信“美好家”用户的家庭数字空间将上线 Token 会员权益，提供融合套餐一价全包服务。

技术集成能力

用户购买额度后，可通过标准 API 接口调用 30 余款主流大模型，支持将 AI 能力集成到软件、脚本或自动化流程中。

总结

上海电信率先推出 Token 算力服务，提供多样化的计费模式和针对不同用户的优惠活动。该服务旨在通过标准 API 提供广泛的大模型调用能力，助力用户在多种应用场景中整合 AI 能力。

Tokenコンピューティングサービスの提供開始

Shanghai Telecomは本日、上海で初となるToken（トークン）コンピューティングサービスを開始し、Tokenプランを発表した最初の通信事業者となりました。

Tokenプランの詳細

  • Tokenプランは使用量に応じて購入することが可能です。
  • 1元で25万ポイントを購入でき、例えばKimi K2.5などの大規模言語モデルにおいて、約25万の入力トークンを呼び出すことができます。
  • 必要な分だけ購入可能で、通信料金として決済ができ、大量購入時には割引特典が提供されます。

AIホームアシスタントと無料体験

Shanghai Telecomは「AIホームアシスタント」を発表するとともに、Shanghai Telecomの携帯電話番号利用者に対して2,500万ポイントの無料体験を提供することを発表しました。この無料体験は1ヶ月間有効です。また、6月からはTelecomの「Meihao Home」ユーザーの家庭用デジタル空間にToken会員特典が追加され、統合プランにすべての特典が含まれる予定です。

APIを通じた大規模言語モデルとの連携

さらに、Shanghai Telecomの利用者はポイントを購入した後、標準的なAPIインターフェースを通じて30以上の主要な大規模言語モデルを呼び出し、AI機能を自身のソフトウェア、スクリプト、または自動化プロセスに統合することができます。

Token（トークン）とは？

IT之家の解説によると、Tokenはコンピュータ科学および自然言語処理における基本的かつ重要な概念であり、一般的にテキストデータが分割またはトークン化された後の最小単位を指します。この単位には、単語、句読点、数字、またはその他の意味のある記号が含まれます。

まとめ

Shanghai Telecomは、従量課金制のTokenプランを通じてユーザーがAIコンピューティング資源を柔軟に購入できる環境を構築しました。提供されるポイントを利用することで、標準API経由で30以上の大規模言語モデルを活用でき、開発や自動化への統合が容易になります。また、家庭用デバイスとの連携や無料キャンペーンを通じて、より身近なAI体験の提供を目指しています。

Launch of Token Computing Service

Shanghai Telecom has launched the first Token computing service in Shanghai, becoming the first telecommunications provider to offer a dedicated Token plan.

Token Plan Details

  • The Token plan can be purchased based on actual usage.
  • Users can purchase 250,000 points for 1 Yuan; for example, this allows for approximately 250,000 input tokens when calling the Kimi K2.5 large language model.
  • Users can purchase only what they need, pay via standard telecommunications billing, and receive discounts on bulk purchases.

AI Home Assistant and Free Trial

Following the launch of its "AI Home Assistant," Shanghai Telecom announced that users with Shanghai Telecom mobile numbers will receive a free trial of 25 million points. This trial is valid for one month. Starting in June, Token membership benefits will be added to the home digital space of "Meihao Home" users, incorporating all benefits into an integrated plan.

LLM Integration via API

Furthermore, after purchasing points, Shanghai Telecom users can call over 30 major large language models (LLMs) through standard API interfaces. This allows users to integrate AI capabilities into their own software, scripts, or automation processes.

What is a Token?

According to IT Home, a "Token" is a fundamental and essential concept in computer science and natural language processing (NLP). It refers to the minimum unit of text data after it has been segmented or processed through tokenization. These units can be words, punctuation marks, numbers, or other meaningful symbols.

Summary

Shanghai Telecom has introduced a usage-based Token plan as the first provider in Shanghai to offer such a service. This initiative allows users to purchase AI computing resources and access over 30 major LLMs via standard APIs for various applications. The service also includes trial offers and integrated benefits to improve accessibility to AI technologies.
