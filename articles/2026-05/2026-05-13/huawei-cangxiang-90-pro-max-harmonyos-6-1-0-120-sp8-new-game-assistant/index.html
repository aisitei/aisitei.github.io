Huawei Enjoy 90 Pro Max 스마트폰, HarmonyOS 6.1.0.120 SP8 버전으로 업데이트 시작, 새로운 게임 어시스턴트 탑재

2026-05-13

시스템 업데이트

Huawei는 오늘 Changxiang 90 Pro Max 스마트폰에 HarmonyOS 6.1.0.120 SP8 버전을 배포했습니다. 시스템 패키지 크기는 약 1.52GB이며, 갤러리 스마트 정리, 새로운 게임 어시스턴트 등의 기능을 제공합니다.

갤러리 기능

  • 새로운 스마트 정리 기능이 추가되어 중복되거나 유사한 사진을 쉽게 정리할 수 있어 추억을 더욱 깔끔하게 만들고, 저장 공간을 효율적으로 절약할 수 있습니다. (갤러리 앨범 페이지 > 오른쪽 상단 점 4개 아이콘 > 사진 정리)
  • 사진 편집에 스티커 기능이 추가되어 Emoji, 댄스 마스터 등 다양한 스티커를 즐길 수 있으며, 사용자 정의 스티커를 추가하여 사진 편집을 더욱 재미있게 만들 수 있습니다. (갤러리 > 사진 편집 > 스티커)
  • 낙서 기능이 최적화되어 화살표, 직선, 사각형, 원을 직접 추가할 수 있어 주석 작성이 더욱 편리해졌습니다. (갤러리 > 사진 편집 > 낙서)
  • 텍스트 기능이 최적화되어 다양한 꽃무늬 글자와 텍스트 상자 스타일이 추가되어 더욱 개성 있는 표현이 가능합니다. (갤러리 > 사진 편집 > 텍스트)

게임 어시스턴트

  • 게임 어시스턴트가 전면적으로 업그레이드되었습니다. 게임 시작 시 "게임 어시스턴트" 캡슐 알림을 클릭하거나 게임 화면에서 아래로 스크롤하여 어시스턴트 패널을 빠르게 열 수 있습니다.
  • 게임 어시스턴트 패널은 편리한 게임 도구를 제공합니다. "고성능 모드"를 클릭하여 게임 성능을 향상시키고, "너클 제스처 차단" 및 "방해 금지" 등을 활성화하여 몰입감 있는 경험을 보장합니다. 또한 "커뮤니티", "이벤트", "선물" 등 풍부한 게임 서비스를 확장하여 게임 공략, 이벤트 혜택, 최신 정보 등을 쉽게 얻고 게임 친구를 찾을 수 있어 게임을 즐기고 소통하며 더 나은 경험을 할 수 있습니다.

HarmonyOS CarLink

  • 새로운 HarmonyOS CarLink 카드가 추가되었습니다. 홈 화면에 추가하고 서비스 전환을 활성화하면 휴대폰 지도 앱의 주소, 내비게이션 작업 등이 Huawei 스마트 콕핏 중앙 제어 화면으로 자동으로 전환될 수 있습니다. (홈 화면 두 손가락으로 모으기 > 카드 > HarmonyOS CarLink)
  • 일부 시나리오에서 시스템 안정성이 최적화되었습니다.

통화 및 게임 성능

  • 일부 타사 앱의 통화 경험이 최적화되었습니다.
  • 일부 게임의 부드러움이 최적화되어 게임 경험이 향상되었습니다.

또한 Huawei 공식 웹사이트에서는 Changxiang 90 시리즈 휴대폰의 HarmonyOS 6.1 공개 베타 테스트 참여자 모집을 시작했습니다.

총평

Huawei Changxiang 90 Pro Max는 HarmonyOS 6.1.0.120 SP8 업데이트를 통해 갤러리 스마트 정리, 새로운 게임 어시스턴트, HarmonyOS CarLink 연동 등 다양한 기능을 추가했습니다. 특히 갤러리 기능은 사진 편집 및 정리를 더욱 편리하게 만들었으며, 게임 어시스턴트는 사용자에게 몰입감 있는 게임 경험과 풍부한 게임 서비스를 제공합니다. 또한 시스템 안정성 및 통화, 게임 성능 최적화를 통해 전반적인 사용자 경험을 향상시켰습니다.

系统更新信息

Huawei 推送了畅享 90 Pro Max 的 HarmonyOS 6.1.0.120 SP8 版本，该系统包大小约为 1.52 GB。

图库与多媒体功能

  • 新增智能清理功能：可自动识别并整理重复、相似照片，以节省设备存储空间。
  • 图片编辑增强：支持多种 Emoji 及自定义贴纸；优化涂鸦工具（支持箭头、直线、方形、圆形）；提供更多花字和文本框样式。

游戏体验优化

  • 游戏助手全面升级：支持通过胶囊提示或下拉操作快速打开面板，并提供高性能模式、屏蔽指关节及免打扰等功能。
  • 丰富服务集成：在游戏界面中提供圈子、活动、礼包等内容，方便获取攻略和福利。

车联生态联动

新增鸿蒙车联卡片，支持将手机地图上的地址、导航任务等自动流转至 Huawei 智能座舱中控屏。

系统稳定性与公测

  • 优化了部分场景的系统稳定性及三方应用通话体验。
  • 提升了部分游戏的流畅性。
  • Huawei 官网已开启畅享 90 系列手机的 HarmonyOS 6.1 公测版招募。

总结

华为为畅享 90 Pro Max 推送了 HarmonyOS 6.1.0.120 SP8 更新，重点涵盖图库智能清理、游戏助手升级以及鸿蒙车联功能的加入。此次更新旨在提升多媒体创作体验、增强游戏沉浸感并优化跨端联动能力。

システムアップデート

Huaweiは本日、Changxiang 90 Pro Max向けにHarmonyOS 6.1.0.120 SP8を配信しました。システムのパッケージサイズは約1.52GBで、ギャラリーのスマート整理や新しいゲームアシスタントなどの機能が含まれています。

ギャラリー機能

  • 「スマート整理」機能が追加され、重複または類似した写真を簡単に整理できるようになりました。これにより思い出をより整理しやすく、ストレージ容量も効率的に節約できます。（ギャラリーのアルバムページ ＞ 右上の4つのドットアイコン ＞ 写真の整理）
  • 写真編集にステッカー機能が追加され、Emojiやダンスマスターなど多彩なステッカーを楽しめるほか、カスタムステッカーを追加して編集をより楽しくすることができます。（ギャラリー ＞ 写真編集 ＞ ステッカー）
  • 落書き（ドローイング）機能が最適化され、矢印、直線、四角形、円を直接追加できるようになり、注釈の作成がより便利になりました。（ギャラリー ＞ 写真編集 ＞ 落書き）
  • テキスト機能が最適化され、さまざまな花柄の文字やテキストボックスのスタイルが追加され、より個性的な表現が可能になりました。（ギャラリー ＞ 写真編集 ＞ テキスト）

ゲームアシスタント

  • ゲームアシスタントが全面的にアップグレードされました。ゲーム開始時に「ゲームアシスタント」のカプセル通知をタップするか、ゲーム画面から下にスワイプすることで、アシスタントパネルを素早く開くことができます。
  • ゲームアシスタントパネルは便利なツールを提供します。「高性能モード」を選択してゲームパフォーマンスを向上させ、「ノック操作のブロック」や「おやすみモード」などを有効にして没入感のある体験を保証します。また、「コミュニティ」「イベント」「ギフト」などの豊富なゲームサービスが拡張され、攻略法や特典、最新情報の取得、ゲーム仲間との交流など、より充実したゲーム体験を提供します。

HarmonyOS CarLink

  • 新しいHarmonyOS CarLinkカードが追加されました。ホーム画面に追加し、サービスの切り替えを有効にすると、スマートフォンの地図アプリの住所やナビゲーション操作などがHuaweiスマートコックピットの中央制御画面に自動的に転送されます。（ホーム画面で2本の指を閉じる ＞ カード ＞ HarmonyOS CarLink）
  • 一部のシナリオにおいてシステム安定性が最適化されました。

通話およびゲームパフォーマンス

  • 一部のサードパーティ製アプリにおける通話体験が最適化されました。
  • 一部のゲームの滑らかさが最適化され、ゲーム体験が向上しました。

また、Huaweiの公式サイトでは、Changxiang 90シリーズ向けHarmonyOS 6.1の公開ベータテストへの参加者募集を開始しています。

System Update

Huawei has released version HarmonyOS 6.1.0.120 SP8 for the Changxiang 90 Pro Max smartphone. The system package size is approximately 1.52GB and introduces features such as Gallery Smart Cleanup and a new Game Assistant.

Gallery Features

  • A new "Smart Cleanup" feature has been added to easily organize duplicate or similar photos, allowing users to declutter their memories and save storage space efficiently. (Path: Gallery Album Page > Four-dot icon at the top right > Photo Cleanup)
  • Stickers have been added to photo editing, offering a variety of options including Emoji and Dance Master, as well as the ability to add custom stickers for more creative expression. (Path: Gallery > Edit Photo > Stickers)
  • The Doodle feature has been optimized, allowing users to manually add arrows, straight lines, squares, and circles to make annotations more convenient. (Path: Gallery > Edit Photo > Doodle)
  • Text features have been optimized with various floral patterns and text box styles for more personalized expression. (Path: Gallery > Edit Photo > Text)

Game Assistant

  • The Game Assistant has undergone a comprehensive upgrade. Users can quickly open the assistant panel by tapping the "Game Assistant" capsule notification when a game starts or by swiping down on the game screen.
  • The Game Assistant panel provides convenient tools: users can select "High Performance Mode" to boost performance, and enable "Block Knuckle Gestures" and "Do Not Disturb" for an immersive experience. Furthermore, expanded services such as "Community," "Events," and "Gifts" provide easy access to game guides, rewards, the latest information, and tools to find gaming friends.

HarmonyOS CarLink

  • A new HarmonyOS CarLink card has been added. By adding it to the home screen and enabling service transition, addresses and navigation tasks from mobile map apps can be automatically transferred to the Huawei Smart Cockpit center control screen. (Path: Pinch with two fingers on Home Screen > Card > HarmonyOS CarLink)
  • System stability has been optimized for certain scenarios.

Call and Game Performance

  • The calling experience for some third-party apps has been optimized.
  • Smoothness in several games has been improved to enhance the overall gaming experience.

Additionally, Huawei's official website has begun recruiting participants for the HarmonyOS 6.1 public beta test for the Changxiang 90 series.

Summary

The HarmonyOS 6.1.0.120 SP8 update for the Huawei Changxiang 90 Pro Max introduces significant enhancements to gallery management, a revamped Game Assistant with expanded community features, and improved integration via HarmonyOS CarLink. The update also focuses on optimizing system stability, third-party app call quality, and overall gaming performance.
