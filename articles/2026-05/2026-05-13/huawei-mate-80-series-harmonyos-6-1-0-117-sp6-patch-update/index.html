HarmonyOS 6.1 업데이트 및 패치 안내

IT之家에 따르면, Huawei는 지난 5월 12일 Mate 80 시리즈 스마트폰을 대상으로 최신 HarmonyOS 6.1.0.117 SP6 중요 패치 패키지를 배포했습니다. 이번 시스템 패키지 크기는 약 414.63MB이며, 일부 사용 시나리오에서의 사용자 경험을 개선하는 데 중점을 두었습니다.

주요 업데이트 내용: 지능형 이동 모드 (Smart Commuting)

이번 업데이트는 Mate 80 시리즈의 시스템 패치임에도 불구하고 '지능형 이동 모드(智感畅行)'라는 새로운 시나리오 기능을 탑재한 것이 특징입니다. 이 기능은 기존에 Huawei Sangxiang 90 Pro Max 모델에서 처음 선보인 것으로, Gaode 내비게이션과 연동하여 지능적인 도로 상황 및 신호등 알림을 제공합니다.

Huawei 공식 웹사이트를 통해 확인된 바에 따르면, '지능형 이동 모드'는 사용자들의 외근 작업 효율성을 높여주는 다양한 기능을 지원합니다. 이 모드를 활성화하면 기기가 자동으로 네트워크를 최적화하고 시스템 기능을 조정하며 다음과 같은 서비스를 제공합니다.

  • 지능형 도로 상황 알림: 실시간 창을 통해 신호등의 남은 시간을 보여주는 서비스가 제공됩니다.
  • 통화 자동 스피커폰 전환: 전화를 걸거나 받을 때 블루투스 등 외부 출력 장치에 연결되어 있지 않으면 자동으로 스피커폰 통화 모드로 전환됩니다.
  • 음성 알림 강화: 기기의 알림음과 벨소리 볼륨이 최대치로 조정됩니다.
  • 명확한 음성 안내: 앱 내의 내비게이션 정보나 주문 내용 등 애플리케이션 콘텐츠를 명확하게 들을 수 있도록 지원합니다.
  • 화면 밝기 유지 시간 연장: 기기는 사용 중인 앱의 상황에 따라 화면이 켜져 있는 시간을 늘려줍니다.
  • 지능형 지연 절전 모드: 화면 꺼짐 시간이 최대 10분까지 연장되며, 자전거 라이딩이나 운전 중에는 화면이 꺼지지 않도록 유지됩니다.

총평

이번 HarmonyOS 패치는 단순한 버그 수정 이상의 의미를 지니며, 특히 '지능형 이동 모드'를 통해 사용자의 일상적인 외출 및 작업 환경을 크게 개선했습니다. 실시간 교통 정보 연동, 자동 스피커폰 전환, 그리고 운전/라이딩 중 화면 유지 기능 등은 사용자 편의성을 극대화한 플래그십급 업데이트로 평가됩니다.

新增“智感畅行”功能

本次更新将此前仅在 Huawei 畅享 90 Pro Max 上首发的“智感畅行”模式下放到 Mate 80 系列。该功能可与高德导航联动，为用户提供智能路况提醒、清晰播报等户外工作辅助服务。

“智感畅行”具体功能列表

开启“智感畅行”模式后，设备将自动优化网络并调整相关系统功能：

  • 智能路况提醒：通过实况窗提供红绿灯读秒服务。
  • 通话自动免提：在未连接蓝牙等外接输出设备时，接听电话会自动切换至免提模式。
  • 声音提醒增强：将通知音和铃声自动调至最大。
  • 清晰播报：提升导航、订单等应用内容的语音播报清晰度。
  • 屏幕高亮时间延长：根据支持的应用情况，增加屏幕高亮显示时长。
  • 智能延迟熄屏：将熄屏时间延长至 10 分钟；在骑行或驾驶过程中保持不熄屏。

总结

Huawei 为 Mate 80 系列推送了 HarmonyOS 6.1.0.117 SP6 补丁包，核心内容是引入“智感畅行”功能。该功能通过与高德导航联动，为用户提供红绿灯读秒、自动免提及增强播报等一系列针对户外出行场景的优化服务。

HarmonyOS 6.1のアップデートおよびパッチ案内

IT之家の報道によると、Huaweiは5月12日、Mate 80シリーズ向けに最新のHarmonyOS 6.1.0.117 SP6重要パッチパッケージを配信しました。このシステムパッケージのサイズは約414.63MBで、特定の利用シナリオにおけるユーザー体験（UX）の向上に重点を置いています。

主なアップデート内容：スマート移動モード（Smart Commuting）

今回のアップデートはMate 80シリーズ向けのシステムパッチですが、「スマート移動モード（智感畅行）」という新しいシナリオ機能を搭載しているのが特徴です。この機能は以前Huawei Sangxiang 90 Pro Maxモデルで初めて導入されたもので、Gaodeナビゲーションと連携し、道路状況や信号機の通知をインテリジェントに提供します。

Huaweiの公式サイトで確認された情報によると、「スマート移動モード」はユーザーの外出時の作業効率を高めるための様々な機能をサポートします。このモードを有効にすると、デバイスは自動的にネットワークを最適化し、システム機能を調整した上で以下のサービスを提供します。

  • インテリジェントな道路状況通知： リアルタイムウィンドウを通じて信号機の残り時間を表示するサービスが提供されます。
  • 通話時の自動スピーカーフォン切替： 通話の際、Bluetoothなどの外部出力デバイスに接続されていない場合、自動的にスピーカーフォンモードに切り替わります。
  • 音声通知の強化： デバイスの通知音と着信のボリュームが最大に調整されます。
  • 明瞭な音声案内： アプリ内のナビゲーション情報や注文内容など、アプリケーションのコンテンツをよりクリアに聞き取れるようサポートします。
  • 画面の明るさ維持時間の延長： 使用中のアプリの状態に応じて、画面が点灯している時間を延長します。
  • インテリジェントな遅延スリープモード： 画面の消灯時間が最大10分まで延長され、自転車でのライディングや運転中には画面が消えないように維持されます。

総評

今回のHarmonyOSパッチは単なるバグ修正にとどまらず、特に「スマート移動モード」を通じてユーザーの日常的な外出や作業環境を大幅に改善しています。リアルタイムの交通情報との連携、自動スピーカーフォンへの切り替え、そして運転中やライディング中の画面維持機能などは、利便性を最大限に高めたフラッグシップ級のアップデートと評価されます。

まとめ

HuaweiはMate 80シリーズ向けにHarmonyOS 6.1を配信し、移動中の利便性を高める「スマート移動モード」を搭載しました。この機能により、ナビゲーション情報の最適化や音声通知の強化、運転中の画面維持など、外出時のユーザー体験が大幅に向上しています。単なる修正を超えた、フラッグシップモデルにふさわしい実用的なアップデートとなっています。

This feature was originally introduced on the Huawei Sangxiang 90 Pro Max and integrates with Gaode navigation to provide intelligent road conditions and traffic light notifications.

According to the official Huawei website, "Smart Commuting" supports various features designed to increase efficiency for users performing outdoor tasks. When this mode is activated, the device automatically optimizes network connectivity, adjusts system functions, and provides the following services:

  • Intelligent Road Condition Alerts: Provides a real-time window showing the remaining time for traffic lights.
  • Automatic Speakerphone Switch: Automatically switches to speakerphone mode when making or receiving calls if no external output devices, such as Bluetooth, are connected.
  • Enhanced Voice Notifications: Adjusts notification and ringtone volumes to the maximum level.
  • Clear Voice Guidance: Ensures that application content, such as navigation information or order details, can be heard clearly.
  • Extended Screen Brightness Time: Extends the duration the screen remains active based on the status of the app currently in use.
  • Intelligent Delayed Sleep Mode: Extends the screen timeout to up to 10 minutes and keeps the screen from turning off during activities like cycling or driving.

Overall Review

This HarmonyOS patch goes beyond simple bug fixes, significantly improving the daily experience for users on the go through the "Smart Commuting" mode. Features such as real-time traffic information integration, automatic speakerphone switching, and extended screen time during driving or riding are regarded as flagship-level updates that maximize user convenience.
