One UI 8.5 업데이트 및 개요

IT之家에 따르면, Samsung One UI 8.5 정식 버전이 지난 5월 11일부터 전 세계적으로 업데이트되기 시작했으며, 새로운 인터페이스 디자인을 선보였습니다. 현재 삼성 갤럭시 S25 시리즈 국내 모델에는 이미 해당 업데이트가 배포된 것으로 확인되었습니다.

새로운 기능: 과도한 광고 알림 차단

외신 SammyGuru의 보도에 따르면, Samsung One UI 8.5는 갤럭시 사용자들을 위해 새로운 기능을 도입했습니다. 이 기능은 지나치게 많은 광고성 알림으로 사용자를 방해하는 앱들의 괴롭힘을 줄여주는 역할을 합니다.

기능 구현 및 작동 방식

Samsung은 자체 애플리케이션인 Device Care(스마트폰 관리자 역할)를 13.8.80.7 버전으로 업데이트하며, "Block apps with excessive ads"라는 이름의 신규 기능을 추가했습니다. 이 기능은 과도한 광고 알림을 보내는 앱을 감지하고 차단할 수 있습니다.

이 기능은 두 가지 방식으로 작동합니다:

  • 기본 방식: Samsung이 자주 광고를 전송하는 앱을 식별하여 해당 알림을 차단합니다.
  • 스마트 방식: 스마트폰이 앱의 알림 내용을 자체적으로 분석하여 그것이 광고인지 판단하고, 너무 빈번하게 나타날 경우 차단 조치를 취합니다. 다만, 이 판단은 항상 정확하지 않을 수 있다는 점에 유의해야 합니다.

사용 가능 범위 및 주의사항

해당 기능의 출시가 단계적으로 진행되고 있어, 조건을 충족하는 사용자들은 며칠 또는 몇 주 동안 기다려야 할 수도 있습니다.

또한, 이 기능이 One UI 8.5에만 국한되는지 여부는 불분명하며, 현재로서는 최신 갤럭시 S26 시리즈에서 주로 사용 가능할 것으로 보입니다.

총평

이번 One UI 8.5 업데이트의 핵심은 사용자 경험 개선을 위한 광고 알림 차단 기능입니다. Device Care 앱에 도입된 이 신규 기능을 통해, 사용자들은 원치 않는 과도한 푸시 알림으로부터 기기를 보호할 수 있게 되었습니다. 다만, 해당 기능이 모든 모델에 즉시 적용되거나 One UI 8.5 전용이라고 단정하기는 어려우므로, 사용자는 공식 배포 일정을 기다려야 할 것입니다.

系统更新与推送

Samsung One UI 8.5 正式版于 5 月 11 日起开始全球推送。目前，国内用户可使用的 Samsung Galaxy S25 系列手机已获得该版本更新。

新增广告拦截功能

在 Device Care 应用（版本号 13.8.80.7）中，Samsung 引入了“Block apps with excessive ads”新功能。该功能旨在识别并阻止那些频繁发送广告通知的应用程序，减少对用户的干扰。

  • 基础方案：系统自动识别出频繁发送广告的应用并拦截其通知。
  • 智能方案：系统通过分析通知内容来判断是否为广告，若判定为广告且频率过高则进行拦截（该模式的判断准确率可能不完全一致）。

推送范围与可用性

该功能采取分阶段推送策略，符合条件的用户可能需要等待几天或几周才能启用。目前该功能似乎仅在最新的 Galaxy S26 系列上可用。

总结

Samsung One UI 8.5 更新引入了“Block apps with excessive ads”功能，通过基础和智能两种模式拦截高频广告通知。该功能目前主要出现在新款设备中，并采取分阶段推送策略。

新機能：過度な広告通知のブロック

外信SammyGuruの報道によると、Samsung One 8.5はGalaxyユーザー向けに新しい機能を導入しました。この機能は、過度な広告通知によってユーザーを邪魔するアプリによる妨害を軽減する役割を果たします。

機能の実装と動作原理

Samsungは自社アプリケーションであるDevice Care（スマートフォンの管理機能）をバージョン13.8.80.7にアップデートし、「Block apps with excessive ads」という名称の新機能を追加しました。この機能は、過度な広告通知を送信するアプリを検知し、ブロックすることが可能です。

この機能には2つの動作モードがあります：

  • 標準モード：Samsungが頻繁に広告を送信するアプリを特定し、該当する通知をブロックします。
  • スマートモード：スマートフォンがアプリの通知内容を自ら分析して広告かどうかを判断し、頻度が高すぎる場合にブロック措置を行います。ただし、この判定は常に正確ではない可能性があることに注意が必要です。

利用範囲と注意事項

この機能のリリースは段階的に進められており、条件を満たすユーザーであっても数日から数週間待つ必要がある場合があります。

また、この機能がOne UI 8.5に限定されるかについては不明ですが、現時点では主に最新のGalaxy S26シリーズで利用可能になる見込みです。

総評

今回のOne UI 8.5アップデートの核心は、ユーザー体験向上のための広告通知ブロック機能です。Device Careアプリに導入されたこの新機能により、ユーザーは不要な過度なプッシュ通知からデバイスを保護できるようになります。ただし、この機能がすべてのモデルに即座に適用されるか、あるいはOne UI 8.5専用であるかは断定できないため、ユーザーは公式の配信スケジュールを待つ必要があります。

まとめ

Samsung One UI 8.5では、Device Careを通じて過度な広告通知をブロックする新機能が導入されました。この機能には「標準」と「スマート」の2つのモードがあり、ユーザー体験の向上を目指しています。展開は段階的に行われるため、最新モデルを中心に順次適用される見込みです。
