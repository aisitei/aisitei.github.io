Samsung 📱 스마트폰

삼성 One UI 9, 미확인 앱 관리 기능 추가로 휴대폰 측설치 앱 통합 제어 가능

2026-05-15

One UI 9 주요 보안 기능 업데이트

Samsung이 Galaxy S26 시리즈를 대상으로 첫 번째 One UI 9 테스트 버전을 배포하며 여러 가지 안전 기능을 추가했습니다.

이번 버전에서는 기존의 자동 보호(Auto Blocker) 기능에 안전 보고서 기능이 추가되었으며, 최대 제한 모드에서 완전한 USB 연결 차단 설정이 복구되었습니다. 또한, 사용자가 출처를 알 수 없는 앱을 추적하고 관리할 수 있는 새로운 보안 기능도 도입되었습니다.

강화된 위험 감지 및 방어 시스템

Samsung은 One UI 9 테스트 버전 보도 자료를 통해 "One UI 9는 의심스러운 앱과 잠재적인 위험에 대한 보호 능력을 업그레이드했습니다. 새로운 고위험 앱이 감지되면, 시스템이 사용자에게 경고를 보내고 해당 앱의 실행 및 설치를 차단하며, 안전 정책 업데이트를 통해 사용자가 직접 제거하도록 권장합니다."라고 밝혔습니다.

미확인 출처 앱 관리 기능

첫 One UI 9 테스트 버전에서는 '설정 > 보안 및 개인 정보 보호 > 기타 보안 설정' 경로에 미확인 앱을 관리하는 메뉴가 새롭게 추가되었습니다.

이 기능을 이용하면 휴대폰에 설치된 모든 비공식 인증 출처의 앱 목록을 확인할 수 있습니다. 여기에는 Google Play 스토어나 Samsung 앱 스토어(Galaxy Store)를 통하지 않고 다운로드한 앱들이 포함됩니다. 이 기능은 기기에 측설치된 모든 앱을 한곳에 모아 보여주기 때문에, 사용자가 신뢰하지 않거나 알지 못하는 앱을 쉽게 제거할 수 있도록 돕습니다.

과거에는 사용자가 설치된 앱 목록을 일일이 확인하며 의심스러운 앱을 찾아내야 했지만, 스마트폰의 앱 개수가 수십 또는 수백 가지에 달해 수동으로 검토하기가 매우 번거로웠습니다. 하지만 '미확인 출처 앱 관리' 기능은 일부 보안 검토 권한을 Google Play 스토어와 Samsung 앱 스토어가 담당하게 함으로써(스토어 입점 앱은 해당 플랫폼의 안전 및 개인 정보 보호 규칙을 준수해야 함), 사용자는 간소화된 앱 목록만 확인하면 되므로 관리가 훨씬 수월해졌습니다.

현재 '미확인 출처 앱 관리' 기능은 One UI 9 테스트 버전에서 이미 활성화되었으며, 추후 공식 버전에도 포함될 것으로 예상됩니다.

총평

One UI 9의 이번 업데이트는 사용자 보안 강화에 초점을 맞추고 있으며, 특히 '미확인 출처 앱 관리' 기능은 사용자가 기기에 설치된 모든 앱을 한눈에 파악하고 위험 요소를 쉽게 제거할 수 있도록 큰 편의성을 제공합니다. 전반적으로 시스템 안정성과 개인 정보 보호 측면에서 사용자 경험이 크게 향상될 것으로 기대됩니다.

One UI 9 安全功能升级

Samsung 正向 Galaxy S26 系列推送首个 One UI 9 测试版。该版本在安全性方面进行了显著增强，重点优化了“自动防护（Auto Blocker）”功能及对未知来源应用的监控能力。

  • 自动防护（Auto Blocker）： 新增安全报告功能，并在最大限制模式下恢复完整的 USB 连接屏蔽设置。
  • 风险预警机制： 当系统检测到新增高风险应用时，将主动发出预警、阻止其运行与安装，并提供卸载建议。

管理未知来源应用

One UI 9 新增了专门的“管理未知应用”入口（路径：设置 > 安全和隐私 > 更多安全设置）。该功能旨在帮助用户更高效地识别非官方渠道安装的软件。

  • 过滤机制： 该页面仅展示非 Google Play 和 Samsung 应用商店（Galaxy Store）下载的侧载应用。
  • 简化排查： 通过将侧载应用统一汇总，用户无需在庞大的已安装列表中手动筛选，从而更便捷地卸载不信任或来源不明的应用。

总结

Samsung 的 One UI 9 测试版通过增强“自动防护”功能和新增“管理未知应用”入口，显著提升了系统的安全防御能力。该更新旨在简化用户对非官方渠道安装应用的排查流程，从而更有效地防范潜在的安全风险。

One UI 9の主要なセキュリティ機能アップデート

SamsungはGalaxy S26シリーズ向けにOne UI 9の最初のテストバージョンを配布し、複数の安全機能を搭載しました。

今回のバージョンでは、既存の「自動保護（Auto Blocker）」機能に「安全レポート」機能が追加され、最大制限モードにおいてUSB接続を完全に遮断する設定が復元されました。また、ユーザーが出所不明なアプリを追跡・管理できる新しいセキュリティ機能も導入されています。

強化されたリスク検知および防御システム

SamsungはOne UI 9のテストバージョンのプレスリリースを通じて、「One UI 9は、不審なアプリや潜在的なリスクに対する保護能力をアップグレードしました。新しい高リスクアプリが検知されると、システムがユーザーに警告を送り、該当するアプリの実行およびインストールをブロックします。さらに、安全ポリシーの更新を通じて、ユーザー自身による削除を促します」と述べています。

未確認ソースアプリ管理機能

One UI 9の最初のテストバージョンでは、以下のパスに「未確認アプリを管理」するメニューが新しく追加されました。

  • 設定 > セキュリティとプライバシー > その他のセキュリティ設定

この機能を利用することで、スマートフォンにインストールされているすべての非公式なソースからのアプリ一覧を確認できます。これには、Google Play ストアやSamsung アppストア（Galaxy Store）を経由せずにダウンロードされたアプリが含まれます。この機能は、デバイスにサイドロードされたすべてのアプリを一箇所にまとめて表示するため、ユーザーが信頼していない、あるいは正体を知らないアプリを簡単に削除できるように支援します。

従来、ユーザーはインストールされている全アプリのリストを手動で確認し、不審なものを探し出す必要がありましたが、スマートフォンのアプリ数が数十から数百に達する場合、手動での確認は非常に手間がかかっていました。しかし、「未確認ソースアプリ管理」機能は、一部のセキュリティ確認権限をGoogle Play ストアとSamsung アプリストアが担当させることで（ストア掲載アプリは各プラットフォームの安全およびプライバシー保護ルールを遵守しているため）、ユーザーは簡略化されたリストのみを確認すれば良くなり、管理が大幅に容易になりました。

現在、「未確認ソースアプリ管理」機能はOne UI 9のテストバージョンですでに有効化されており、今後の正式版にも搭載される見込みです。

まとめ

One UI 9のアップデートでは、特に「未確認ソースアプリ管理」機能の追加により、ユーザーがリスクのあるアプリを容易に特定し削除できる利便性が向上しています。これにより、デバイスのセキュリティ強化とプライバシー保護の両面で、より安全なユーザー体験が提供されることが期待されます。

One UI 9 Key Security Feature Updates

Samsung has released the first test version of One UI 9 for the Galaxy S26 series, incorporating several new security features.

This version introduces a "Safety Report" feature to the existing Auto Blocker and restores the setting to completely block USB connections in Maximum Mode. Additionally, a new security feature has been introduced to allow users to track and manage apps from unknown sources.

Enhanced Threat Detection and Defense Systems

In the press release for the One UI 9 test version, Samsung stated: "One UI 9 has upgraded its protection capabilities against suspicious apps and potential risks. When a new high-risk app is detected, the system alerts the user, blocks the execution and installation of that app, and recommends that the user remove it through safety policy updates."

Unverified Source App Management

In the first One UI 9 test version, a new menu for managing unverified apps has been added under:

  • Settings > Security and Privacy > Other Security Settings

This feature allows users to view a list of all applications installed from non-certified sources. This includes apps downloaded outside of the Google Play Store or the Samsung Galaxy Store (Galaxy Store). By gathering all sideloaded apps in one place, this feature helps users easily identify and remove applications they do not trust or recognize.

Previously, users had to manually check their entire list of installed apps to find suspicious ones, which was highly inconvenient when a device contained dozens or hundreds of applications. However, because the "Unverified Source App Management" feature allows Google Play and the Galaxy Store to handle security review permissions for store-listed apps (which must comply with the respective platforms' safety and privacy rules), users only need to check a simplified list, making management much more convenient.

The "Unverified Source App Management" feature is already active in the One UI 9 test version and is expected to be included in the official release.

Summary

The One UI 9 update focuses on strengthening user security by providing a streamlined way to identify and remove potentially dangerous apps from non-official sources. By integrating these features, Samsung aims to improve system stability and significantly enhance the overall privacy experience for users.

Samsung 正式向 Galaxy S26 系列推送首个 One UI 9 测试版。该版本重点强化了系统的安全防护能力，旨在提升用户对潜在风险的防御。

Auto Blocker 功能增强

在“自动防护（Auto Blocker）”功能中，One UI 9 带来了以下更新：

  • 新增安全报告功能。
  • 在最大限制模式下恢复了完整的 USB 连接屏蔽设置。

未知来源应用管理

One UI 9 推出了全新的安全机制来追踪并管控来自未知来源的应用。当系统检测到高风险应用时，会采取以下措施：

  • 向用户发出预警。
  • 阻止相关应用的运行与安装。
  • 通过安全策略更新建议用户卸载可疑应用。

在“设置 > 安全和隐私 > 更多安全设置”中，新增了“管理未知应用”入口。该功能会将所有非官方渠道（即非 Google Play 或 Samsung Galaxy Store）下载的侧载应用统一汇总展示。此举旨在简化用户排查并卸载不信任应用的流程，不再需要手动逐一核对庞大的安装列表。

总结

Samsung 在 One UI 9 测试版中为 Galaxy S26 系列引入了更强的安全防护功能。核心更新包括优化后的 Auto Blocker 以及全新的“管理未知应用”工具，旨在通过自动化预警和统一的侧载应用清单，提升用户对非官方渠道软件的安全管控能力。
