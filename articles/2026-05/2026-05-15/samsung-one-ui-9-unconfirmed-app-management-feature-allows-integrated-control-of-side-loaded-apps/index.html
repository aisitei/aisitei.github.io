Samsung 📱 스마트폰

Samsung One UI 9, 알 수 없는 앱 관리 기능 추가로 스마트폰 사이드로드 앱 집중 관리 가능

2026-05-15

새로운 보안 기능

Samsung이 Galaxy S26 시리즈에 첫 번째 One UI 9 베타 버전을 배포하고 있으며, 이 버전에는 여러 가지 새로운 보안 기능이 추가되었습니다.

자동 보호(Auto Blocker) 기능에 보안 보고 기능이 새로 추가되었으며, 최대 제한 모드에서 USB 연결 차단 설정이 완전히 복원되었습니다. One UI 9는 또한 사용자가 출처를 알 수 없는 앱을 추적하고 관리하는 데 도움이 되는 또 다른 새로운 보안 기능을 도입했습니다.

Samsung은 One UI 9 베타 버전 보도자료에서 "One UI 9는 의심스러운 앱과 잠재적 위험에 대한 보호 기능을 강화했습니다. 새로운 고위험 앱이 감지되면 시스템은 사용자에게 사전 경고를 보내고, 앱 실행 및 설치를 차단하며, 보안 정책 업데이트를 통해 앱 제거를 권장합니다."라고 밝혔습니다.

첫 번째 One UI 9 베타 버전에서는 설정 > 보안 및 개인 정보 보호 > 추가 보안 설정으로 이동하면 '알 수 없는 앱 관리' 항목이 새로 추가되었습니다.

스크린샷에서 볼 수 있듯이, '알 수 없는 앱 관리' 페이지에는 Google Play 스토어와 Samsung Galaxy Store 외의 비공식 인증 출처를 통해 설치된 모든 앱이 나열됩니다. 이 기능은 휴대폰에 사이드로드된 모든 앱을 한곳에 모아 표시하여 사용자가 신뢰할 수 없거나 알 수 없는 앱을 쉽게 제거할 수 있도록 합니다.

사용자는 기존에 설치된 앱 목록을 일일이 확인하여 의심스러운 앱을 찾아낼 수 있었지만, 휴대폰 앱은 수십 개에서 많게는 수백 개에 달하여 수동으로 확인하는 것이 매우 번거로웠습니다. '알 수 없는 앱 관리' 기능은 일부 보안 심사 권한을 Google Play 스토어와 Samsung Galaxy Store에 위임하여(스토어에 입점한 앱은 해당 플랫폼의 보안 및 개인 정보 보호 규칙을 준수해야 함) 간소화된 앱 목록만 확인하면 되므로 관리가 훨씬 쉬워집니다.

현재 '알 수 없는 앱 관리' 기능은 One UI 9 베타 버전에서 제공되고 있으며, One UI 9 정식 버전에도 포함될 것으로 예상됩니다.

총평

Samsung One UI 9 베타 버전은 '자동 보호' 기능 강화와 '알 수 없는 앱 관리'라는 새로운 보안 기능을 도입하여 사용자에게 향상된 보안 환경을 제공합니다. 이 기능은 비공식 경로로 설치된 앱을 쉽게 식별하고 관리할 수 있도록 돕습니다. 이를 통해 사용자는 잠재적 위험으로부터 더욱 안전하게 스마트폰을 사용할 수 있을 것으로 기대됩니다.
