OpenSearch-VL 개요 및 배경

Tencent Hunyuan은 UCLA, 홍콩중문대 등 유수 학부와 협력하여 오픈소스 멀티모달 학습 솔루션인 OpenSearch-VL을 공개했습니다. 이 솔루션은 강화 학습(RL) 기술을 활용하여 최첨단 능력을 갖춘 심층 검색 에이전트를 구축하는 것을 목표로 합니다.

멀티모달 검색 에이전트란 이미지, 텍스트 등 다양한 형태의 입력을 처리할 수 있으며, 외부 도구(검색 엔진, 이미지 처리 도구 등)를 능동적으로 호출하여 다단계 추론, 증거 검증 및 지식 검색을 수행하는 인공지능 시스템입니다. 이는 특히 지식이 집약된 복잡한 시각 질의응답 문제를 해결하기 위해 설계되었습니다.

이 연구는 고품질 데이터 파이프라인 구축을 통해 SearchVL-SFT-36k와 같은 데이터셋을 생성하여, 최첨단 멀티모달 심층 검색 에이전트 훈련에 사용됩니다. 연구진은 현재 이 분야의 발전을 가로막는 가장 큰 병목 현상은 바로 '고품질 학습 데이터'라고 지적했습니다. 기존 최고 수준의 시스템들은 상업 기업 주도로 운영되어 데이터 출처, 필터링 기준, 도구 사용 기록 등이 사유화되어 있어, 선진 능력을 재현하거나 체계적으로 연구하는 데 어려움이 있었습니다.

핵심 기술 구성 요소

OpenSearch-VL은 데이터부터 도구 환경, 훈련 알고리즘까지 전체 과정을 아우르는 완전한 오픈소스 솔루션을 제공합니다.

데이터 파이프라인 구축

  • 다단계 경로 샘플링: 위키피디아의 하이퍼링크 그래프를 활용하여 여러 단계를 거치는 개체 경로(multi-hop entity path)를 샘플링합니다.
  • 정보 정제 및 강화: 중간 단계의 개체를 모호한 설명으로 재작성하고, 앵커 포인트를 원본 이미지에 고정시킵니다. 이를 통해 에이전트가 단일 단계 검색 경로(shortcut)만 학습하는 것을 방지하고, 다단계 검색 및 추론 능력을 습득하도록 유도합니다.
  • 데이터셋 활용: 파이프라인을 통해 SearchVL-SFT-36k 데이터셋을 생성하여 지도 미세 조정(Supervised Fine-Tuning)에 사용하며, 평균적으로 각 궤적(trajectory)은 6.3회의 도구 호출을 포함합니다.
  • 강화 학습: 무작위로 선택된 10%의 데이터를 모호화하거나 다운샘플링하는 등 '저하 처리'를 적용하고, 쌍으로 강화된 도구를 결합하여 에이전트가 "생각하면서 이미지를 처리"하는 능력을 갖추도록 유도합니다.

통합 도구 환경

  • OpenSearch-VL의 도구 환경은 단순 검색을 넘어선 통합 기능을 제공합니다.
  • 지원 기능에는 텍스트 검색, 이미지 검색, OCR(광학 문자 인식), 자르기(Cropping), 선명화(Sharpening), 초해상도(Super-resolution), 원근 보정(Perspective Correction) 등이 포함됩니다.
  • 이 통합 환경 덕분에 에이전트는 외부 지식을 질의하기 전에 먼저 모호하거나 저해상도, 기울어진 시각적 입력을 처리할 수 있게 되어, 능동적인 인식과 지식 획득을 결합하는 것이 가능해졌습니다.

실험 결과 및 성능 향상

  • 성능 개선: OpenSearch-VL-30B-A3B 모델은 기준점(baseline) 평균 점수를 47.8점에서 61.6점으로 크게 끌어올렸으며, VDR, MMSearch 등 여러 벤치마크에서 현저한 성능 향상을 입증했습니다.
  • 구성 요소 기여도 검증: 제거 실험(Ablation experiment)을 통해 각 구성 요소의 중요성이 확인되었습니다. 원본 앵커 고정, 모호화 재작성, 또는 단계별 필터링 중 하나를 제거했을 때 평균 점수가 8.2점에서 11.5점까지 하락하는 것을 보여주었습니다.

총평

OpenSearch-VL은 멀티모달 검색 에이전트 개발의 핵심 난제였던 데이터와 도구 사용 과정을 오픈소스로 공개했다는 점에서 큰 의미가 있습니다. 특히 위키피디아 그래프를 활용한 다단계 경로 샘플링과 이미지 전처리 기능을 통합함으로써, 단순 지식 검색을 넘어선 복잡하고 능동적인 추론 능력을 에이전트에 부여했습니다.

이는 향후 AI 기반의 시각적 질의응답 시스템 및 플래그십 제품 개발에 있어 중요한 오픈소스 표준으로 자리매김할 것으로 기대됩니다.

  • 产出 SearchVL-SFT-36k 数据集，其中平均每条轨迹包含 6.3 次工具调用。
  • 通过对 10% 的数据进行降质处理（如模糊、下采样）并配对增强工具，诱导智能体在查询知识前先执行“边思考边处理图像”的动作。

工具环境与性能表现

OpenSearch-VL 提供了一个超越单纯检索的丰富工具环境，涵盖了从感知到处理的多种功能：

  • 支持的功能包括：文本搜索、图像搜索、OCR、裁剪、锐化、超分辨率以及透视校正。
  • 模型表现：OpenSearch-VL-30B-A3B 模型在 VDR 和 MMSearch 等基准测试中，将基线平均得分从 47.8 显著提升至 61.6。
  • 消融实验验证了源锚点锚定、模糊重写及分阶段过滤等关键组件对模型性能的贡献。

总结

Tencent Hunyan 等机构推出的 OpenSearch-VL 是一个旨在解决多模态搜索智能体训练数据匮乏问题的开源框架。通过创新的数据采样路径和丰富的工具链，该方案显著提升了模型在复杂视觉问答中的推理与检索能力。

Tencent Hunyuanは、UCLAや香港中文大学などの有力な学術機関と協力し、オープンソースのマルチモーダル学習ソリューション「OpenSearch-VL」を公開しました。このソリューションは、強化学習（RL）技術を活用して、最先端の能力を備えたディープサーチエージェントを構築することを目的としています。

マルチモーダル検索エージェントとは、画像やテキストなど多様な形態の入力を処理でき、外部ツール（検索エンジン、画像処理ツールなど）を能動的に呼び出して、多段階の推論、証拠検証、および知識検索を実行する人工知能システムです。これは特に、知識集約的な複雑な視覚的質疑応答（Visual QA）の問題を解決するために設計されています。

この研究では、高品質なデータパイプラインの構築を通じて「SearchVL-SFT-36k」などのデータセットを生成し、最先端のマルチモーダルディープサーチエージェントの訓練に使用します。研究チームは、この分野の発展を阻む最大のボトルネックは「高品質な学習データ」であると指摘しています。既存の最高レベルのシステムは商用企業主導で運営されているため、データの出所、フィルタリング基準、ツールの使用履歴などが非公開であり、高度な能力を再現したり体系的に研究したりすることが困難でした。

核心的な技術構成要素

OpenSearch-VLは、データからツール環境、訓練アルゴリズムに至るまで、プロセス全体を網羅する完全なオープンソースソリューションを提供します。

データパイプラインの構築

  • 多段階経路サンプリング： Wikipediaのハイパーリンクグラフを活用し、複数のステップを経るエンティティパス（multi-hop entity path）をサンプリングします。
  • 情報の精製と強化： 中間段階のエンティティを曖昧な説明で書き換え、アンカーポイントを元の画像に固定します。これにより、エージェントが単一ステップの検索経路（ショートカット）のみを学習するのを防ぎ、多段階の検索および推論能力を獲得するように導きます。
  • データセットの活用： パイプラインを通じて「SearchVL-SFT-36k」データセットを生成し、教師あり微調整（Supervised Fine-Tuning）に使用します。平均して各軌跡（trajectory）には6.3回のツール呼び出しが含まれます。
  • 強化学習： ランダムに選択された10%のデータを曖昧化またはダウンサンプリングする「劣化処理」を適用し、ペアで強化されたツールを組み合わせることで、エージェントが「思考しながら画像を処理する」能力を備えるよう促します。

統合ツール環境

  • OpenSearch-VLのツール環境は、単なる検索を超えた統合機能を提供します。
  • サポート機能には、テキスト検索、画像検索、OCR（光学文字認識）、クロッピング（Cropping）、シャープネス（Sharpening）、超解像（Super-resolution）、パースペクティブ補正（Perspective Correction）などが含まれます。
  • この統合環境により、エージェントは外部知識を照会する前に、曖昧または低解像度で傾いた視覚的入力を処理できるようになり、能動的な認識と知識獲得の融合が可能になりました。

実験結果および性能向上

  • 性能の改善： OpenSearch-VL-30B-A3Bモデルは、ベースラインの平均スコアを47.8点から61.6点へと大幅に引き上げ、VDR、MMSearchなど複数のベンチマークにおいて顕著な性能向上を実証しました。
  • 構成要素の寄与度の検証： 除去実験（Ablation experiment）を通じて、各構成要素の重要性が確認されました。元のアンカー固定、曖昧な書き換え、または段階的なフィルタリングのいずれかを除去すると、平均スコアが8.2点から11.5点まで低下することが示されました。

Overview and Background of OpenSearch-VL

Tencent Hunyuan, in collaboration with prestigious institutions including UCLA and the Chinese University of Hong Kong, has unveiled OpenSearch-VL, an open-source multimodal learning solution. This solution aims to construct state-of-the-art deep search agents by utilizing Reinforcement Learning (RL) techniques.

A multimodal search agent is an AI system capable of processing diverse inputs such as images and text while actively invoking external tools—such as search engines and image processing tools—to perform multi-step reasoning, evidence verification, and knowledge retrieval. It is specifically designed to solve complex visual question-answering problems involving dense information.

The research highlights that the primary bottleneck currently hindering progress in this field is the lack of "high-quality training data." Because existing top-tier systems are predominantly managed by commercial entities, critical information such as data sources, filtering criteria, and tool usage logs remain proprietary, making it difficult to replicate advanced capabilities or conduct systematic research.

Key Technical Components

OpenSearch-VL provides a comprehensive open-source solution covering the entire process from data pipelines to tool environments and training algorithms.

Data Pipeline Construction

  • Multi-hop Path Sampling: Utilizes Wikipedia hyperlink graphs to sample multi-hop entity paths involving multiple steps.
  • Information Refinement and Reinforcement: Rewrites ambiguous entities in intermediate steps and anchors them to the original images. This prevents the agent from learning "shortcuts" (single-step search paths) and encourages it to develop multi-step searching and reasoning capabilities.
  • Dataset Utilization: The pipeline generates the SearchVL-SFT-36k dataset for Supervised Fine-Tuning (SFT), where each trajectory includes an average of 6.3 tool calls.
  • Reinforcement Learning: Implements "degradation" by blurring or downsampling 10% of randomly selected data and combines paired tools to enable the agent to "think while processing images."

Integrated Tool Environment

  • The tool environment in OpenSearch-VL provides integrated functions that go beyond simple search.
  • Supported features include text search, image search, OCR (Optical Character Recognition), Cropping, Sharpening, Super-resolution, and Perspective Correction.
  • This integrated environment allows the agent to process ambiguous, low-resolution, or tilted visual inputs before querying external knowledge, enabling a combination of active perception and information acquisition.

Experimental Results and Performance Improvements

  • Performance Gains: The OpenSearch-VL-30B-A3B model significantly boosted the average score from 47.8 to 61.6, demonstrating substantial performance improvements across several benchmarks, including VDR and MMSearch.
  • Component Contribution Verification: Ablation experiments confirmed the importance of each component. Removing any single feature—such as original anchor fixing, ambiguous rewriting, or step-by-step filtering—resulted in average score drops ranging from 8.2 to 11.5 points.

Summary

OpenSearch-VL addresses a critical bottleneck in multimodal search agents by providing an open-source solution for high-quality data pipelines and integrated tool environments. By combining multi-hop path sampling with advanced image preprocessing, it enables AI models to perform complex reasoning rather than simple information retrieval. The project is expected to serve as a significant open-source standard for the development of future visual question-answering systems.

OpenSearch-VL Overview and Background

Tencent Hunyuan, in collaboration with leading institutions such as UCLA and HKUST, has released OpenSearch-VL, an open-source multimodal learning solution. This solution aims to build advanced deep search agents by utilizing Reinforcement Learning (RL) techniques.

A multimodal search agent is an artificial intelligence system capable of processing various types of input, including images and text, while actively invoking external tools such as search engines and image processing tools to perform multi-step reasoning, evidence verification, and knowledge retrieval. It is specifically designed to solve complex visual question-answering problems that require dense information.

The research identifies "high-quality training data" as the primary bottleneck currently hindering progress in this field. Because existing top-tier systems are predominantly operated by commercial entities, details such as data sources, filtering criteria, and tool usage logs remain proprietary, making it difficult to replicate or systematically study advanced capabilities. To address this, the researchers developed a high-quality data pipeline to generate datasets like SearchVL-SFT-36k for training state-of-the-art multimodal deep search agents.

Core Technical Components

OpenSearch-VL provides a comprehensive open-source solution covering the entire process from data pipelines to tool environments and training algorithms.

Data Pipeline Construction

  • Multi-hop Path Sampling: Utilizes Wikipedia hyperlink graphs to sample multi-hop entity paths involving several steps.
  • Information Refinement and Enhancement: Rewrites ambiguous entities in intermediate steps and anchors them to the original images. This prevents the agent from learning "shortcuts" (single-step search paths) and encourages it to acquire multi-step searching and reasoning capabilities.
  • Dataset Utilization: The pipeline generates the SearchVL-SFT-36k dataset for Supervised Fine-Tuning (SFT), where each trajectory includes an average of 6.3 tool calls.
  • Reinforcement Learning: Implements "degraded processing" by blurring or downsampling 10% of randomly selected data, and combines reinforced tools to enable the agent to "think while processing images."
