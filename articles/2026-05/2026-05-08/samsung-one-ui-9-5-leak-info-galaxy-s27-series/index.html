Samsung One UI 9.5 첫 포착, Galaxy S27 시리즈 스마트폰에 최초 탑재될 전망

2026-05-08

Samsung One UI 9.5 개발 소식

Erencan Yılmaz는 어제(5월 6일) X 플랫폼에 Samsung이 One UI 9.5 개발에 착수했으며, 이 버전은 안드로이드 17을 기반으로 제작될 것이라고 게시했습니다. Samsung의 차세대 비폴더블 플래그십인 Galaxy S27 시리즈에 이 새로운 버전이 처음으로 사전 설치될 것으로 예상됩니다.

소식통은 여러 One UI 버전이 언급된 코드 스니펫 스크린샷을 공유했으며, 이 스크린샷에는 One UI 9.5 버전이 명확하게 포함되어 있어 이 버전이 처음으로 공개되었습니다. IT之家는 관련 스크린샷을 첨부합니다.

현재 One UI 9.5의 구체적인 기능에 대한 확실한 정보는 없지만, Samsung의 과거 소프트웨어 발전 경로를 참고하면 사용자들은 더욱 간결하고 현대적인 인터페이스 디자인과 더 풍부한 맞춤 설정 옵션을 기대할 수 있습니다.

Samsung이 Galaxy AI에 지속적으로 투자함에 따라, One UI 9.5 시스템 업데이트는 Galaxy AI의 기능 범위를 더욱 확장하여 더욱 지능적인 상호작용 경험을 제공할 것으로 예상됩니다.

총평

Samsung이 안드로이드 17 기반의 One UI 9.5 개발을 시작했으며, Galaxy S27 시리즈에 처음 탑재될 예정입니다. 이 새로운 버전은 더욱 간결하고 현대적인 인터페이스 디자인과 풍부한 맞춤 설정 옵션을 제공할 것으로 기대됩니다. 또한, Galaxy AI 기능이 더욱 확장되어 사용자에게 더욱 지능적인 상호작용 경험을 선사할 것으로 전망됩니다.

系统更新动态

  • Samsung 已着手研发基于 Android 17 底层的 One UI 9.5 系统。
  • 相关代码片段已流出，这是该版本首次进入公众视野。

新机发布预测

  • 下一代非折叠旗舰 Galaxy S27 系列预计将首发预装 One UI 9.5 系统。

AI 与功能演进

随着 Samsung 对 Galaxy AI 的持续投入，One UI 9.5 预计将进一步扩展 Galaxy AI 的能力边界，提供更智能的交互体验以及更简洁现代的界面设计和定制选项。

总结

Samsung 正式进入 One UI 9.5 的研发阶段，该系统基于 Android 17 构建并计划在 Galaxy S27 系列上首发。新版本预计将深度整合 Galaxy AI 功能，并在用户交互体验与界面个性化方面带来显著提升。

Samsung One UI 9.5の開発情報

Erencan Yılmaz氏が昨日（5月6日）、Xプラットフォームにて、SamsungがAndroid 17をベースとした「One UI 9.5」の開発に着手したことを報告しました。この新バージョンは、次世代の非折りたたみフラッグシップモデルであるGalaxy S27シリーズに初めてプリインストールされる見込みです。

情報筋は、複数のOne UIバージョンが含まれるコードスニペットのスクリーンショットを公開しました。このスクリーンショットには「One UI 9.5」も明確に含まれており、同バージョンが初めて公に確認されました。IT之家（IT Home）が関連するスクリーンショットを添付しています。

現時点でOne UI 9.5の具体的な機能に関する確実な情報は得られていませんが、Samsungの過去のソフトウェア進化の傾向から、より洗練されたモダンなインターフェースデザインと、より豊富なカスタマイズオプションが提供されることが期待されます。

SamsungはGalaxy AIへの投資を継続しており、One UI 9.5のシステムアップデートではGalaxy AIの機能範囲がさらに拡大され、よりインテリジェントなインタラクション体験が提供されると予想されています。

まとめ

SamsungはAndroid 17ベースの「One UI 9.5」の開発を開始しており、次世代フラッグシップのGalaxy S27シリーズに初搭載される見込みです。この新バージョンでは、洗練されたUIデザインに加え、Galaxy AIの機能拡張によるより高度なユーザー体験が提供されることが期待されています。

One UI 9.5 Development News

Erencan Yılmaz shared on the X platform yesterday (May 6) that Samsung has begun development of One UI 9.5, which is expected to be based on Android 17. This new version is anticipated to debut as the pre-installed software for the Galaxy S27 series, Samsung's next-generation non-foldable flagship.

The source shared screenshots of code snippets mentioning various One UI versions; "One UI 9.5" was clearly visible in these images, marking its first public appearance in such leaks.

Expected Features and AI Integration

While specific details regarding the features of One UI 9.5 are not yet confirmed, Samsung's history of software evolution suggests that users can expect a cleaner, more modern interface design along with expanded customization options.

As Samsung continues to invest in Galaxy AI, the One UI 9.5 system update is expected to expand the scope of Galaxy AI capabilities to provide a more intelligent and interactive user experience.

Summary

Samsung has begun developing One UI 9.5 based on Android 17, which is slated for its debut on the Galaxy S27 series. The update is expected to feature a modernized interface with enhanced customization options and expanded Galaxy AI capabilities for more intelligent interactions.
