모토로라 Edge 70 Pro+ 스펙 및 성능 공개

IT之家에 따르면, 기술 매체 GSMArena가 모토로라 Edge 70 Pro+의 정보를 게이밍 벤치마크 사이트인 GeekBench에서 포착했다고 보도했습니다. 현재까지 총 3개의 기록이 확인되었으며, 멀티 코어 최고 점수는 6567점을 기록했습니다.

주요 성능 사양

해당 기기는 MediaTek MT6899 칩셋을 탑재한 것으로 알려졌습니다. 세부적인 CPU 구성과 GPU 정보는 다음과 같습니다.

  • CPU: MediaTek MT6899
  • 코어 구성 및 클럭 속도:
    • 4개 코어: 2.2GHz
    • 3개 코어: 3.2GHz
    • 1개 코어: 3.4GHz

    디자인 및 색상

    IT之家의 이전 보도에 따르면, 모토로라 Edge 70 Pro+는 총 다섯 가지 색상으로 출시될 예정입니다. 이 디자인은 기존 Edge 70 Pro와 거의 동일한 외관을 유지합니다.

    • 색상 구성: 화이트, 청록색(Teal Green), 딥 블루(Deep Blue), 레드, 브라운
    • 재질 특징:
      • 블루 및 청록색 버전: 패브릭 후면 커버 적용
      • 화이트 버전: 대리석 무늬 질감
      • 브라운 버전: 우드 그레인(나무 결) 질감 적용

      총평

      모토로라 Edge 70 Pro+는 MediaTek MT6899와 Mali-G720 MC8 GPU를 탑재하여 강력한 성능을 보여주며, GeekBench에서 높은 멀티 코어 점수를 기록했습니다. 또한, 화이트(대리석), 청록색/딥 블루(패브릭), 브라운(우드) 등 다양한 질감의 색상 옵션을 제공하며 디자인적인 완성도까지 높인 플래그십 모델로 평가됩니다.

      GeekBench 跑分表现

      Motorola Edge 70 Pro+ 近期出现在 GeekBench 跑分库中，目前共有 3 条记录。其中多核跑分的最高成绩为 6567 分。

      核心硬件参数

      该机型搭载 MediaTek MT6899（对应 Dimensity 8500）芯片，具体的硬件规格如下：

      • 处理器：MediaTek MT6899 / Dimensity 8500
      • CPU 配置：4核 2.2GHz、3核 3.2GHz、1核 3.4GHz
      • GPU：Mali-G720 MC8

      外观设计与配色

      Motorola Edge 70 Pro+ 的整体设计与 Edge 70 Pro 基本一致，并提供多种不同材质的配色方案：

      • 白色（大理石纹理）
      • 青绿色（织物后盖）
      • 深蓝色（织物后盖）
      • 红色
      • 棕色（木质纹理）

      总结

      Motorola Edge 70 Pro+ 已在 GeekBench 中现身，多核跑分最高达 6567 分。该机搭载 MediaTek Dimensity 8500 芯片，并提供包含大理石、织物和木质纹理等多种材质的丰富配色。
