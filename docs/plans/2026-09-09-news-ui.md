# News UI redesign implementation plan

**Goal:** Improve the existing GitHub Pages news reader on a separate development branch while preserving automatic publishing and historical article URLs.

**Architecture:** Keep Python and static HTML. Generate 24-item static pages plus an independent multilingual search index. Share versioned CSS and JavaScript across the home and existing article pages; migrate presentation idempotently without retranslating article content.

**Tech Stack:** Python standard library, HTML, CSS, vanilla JavaScript, unittest and Node's test runner.

## Approved design

Retain navy and blue, introduce a restrained editorial masthead, prominent search and horizontal categories. First page: one lead story and two supporting latest stories, followed by a three-column news grid. Mobile: compact header, language select and compact horizontal news rows. Article titles precede imagery; source information and navigation remain easy to find.

## Tasks

1. Add behavioral tests for bounded initial rendering, full search corpus, pagination links, category consistency and safe/idempotent article migration. Run and observe failures.
2. Implement `site_ui.py`, `assets/site.css`, `assets/news.js`, and `assets/article.js`. Replace the old home rendering entrypoint while retaining extraction and existing routes.
3. Update article template and migrate historical article presentation through `build.py`. Preserve all translated bodies and images. Add related reading and source visibility; unify language navigation.
4. Update automatic publishing staging to include generated search data, paginated pages, and migrated articles. Ensure build failure cannot publish stale output.
5. Run Python and JavaScript behavior tests, syntax checks, full static build and route/asset checks. Verify repeat builds do not introduce changes. Request independent code review and address material findings.
6. Keep changes committed on `codex/news-ui-redesign`, leave production main untouched, and provide a local preview. Do not publish or merge the development branch.

## Validation

`python3 -m unittest discover -s tests -v`

`node --test tests/news.test.cjs`

`node --check assets/news.js` and `node --check assets/article.js`

`python3 build.py` twice, compare generated file hashes for idempotence.

Verify every article keeps its original URL and translated body, and every generated article/card/local asset link resolves. Check initial home size and displayed article count.
